# README.md

## 写在一切开始之前

- 大家好我是 234211 李东骏，现在 42 系资料库的维护者。很荣幸能够在毕业之前能够开始承担起这样一项工作。
- 信息差是一柄双刃剑，一方面让更多拥有信息的人有更多选择，在一些场景下拥有优势；另一方面让一些没有更多渠道获取信息的人会在一些场景下做出更闭塞、更错误的选择。在当今 计算机、互联网、AI 越来越发达的时代，外界的信息越来越驳杂，而真正有价值的信息和思考会越来越金贵。因此高质量的开源工作更是很不可多得的。我是开源精神的坚定支持者，在我的实践过程中我也认识到缺乏信息会让人多走不少弯路，所以我能更清晰地知道如果在学习、发展的道路上，有清晰的指引会是一件非常幸福且珍贵的事情。因此，我想要借着还没毕业的时间，做出一些对于在校生比较有价值的开源工作，能够帮助大家在搜集信息、探索未知领域的路上尽可能少些阻碍。私心来说，也算是为我的本科生涯做一个比较有社会价值的终章，也算是做好人好事了吧（笑）。
- 以上说的是整体的目标，但是事情肯定得从小开始做。所以，我们从呼声最高也是需求量最大的资料库入手，从学业的角度先弥补一些资料上的空缺。后续可能会有的学院网站、博客建设，敬请期待。
- 无论是资料库、网站或是其他项目，最重要的不是形式，而是长期的维护和迭代，任何一个平台如果超过一段时间没有更新，那么一定会过时和被淘汰。所以如果你也有一颗开源精神的心，我们鼓励所有同学动动自己的小手多多保存自己年级的资料，或者是你认为很有价值的资料。
- 我很希望大家能够在这样的开源工作中得到自己想要的东西，如果有任何改进意见也可以联系我进行讨论。
