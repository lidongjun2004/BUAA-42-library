# 动力系统 第7章 极限环 作业答案（2025秋）

## 7.2 无振荡定理

### 题目

#### 7.2.10

证明系统 $\dot{x} = y - x^{3}$， $\dot{y} = -x - y^{3}$ 没有闭轨。选取合适的 $a$、 $b$，构造一个李雅普诺夫函数 $V = ax^{2} + by^{2}$。

#### 7.2.12

证明 $\dot{x} = -x + 2y^{3} - 2y^{4}$， $\dot{y} = -x - y + xy$ 没有周期解（提示：选择 $a$、 $m$ 和 $n$，令 $V = x^{m} + ay^{n}$ 为一个李雅普诺夫函数）。

#### 7.2.19

［对爱情故事《乱世佳人》（又译作《飘》）的建模］Rinaldi 等人在 2013 年建立了一个 Scarlett O'Hara 与 Rhett Butler 之间猛烈爱情的模型系统：

$$\dot{R} = -R + A_{S} + kSe^{-S}, \qquad \dot{S} = -S + A_{R} + kRe^{-R}$$

式中， $R$ 表示 Rhett 对 Scarlett 的爱； $S$ 表示 Scarlett 对 Rhett 的爱。参数 $A_{R}$、 $A_{S}$ 和 $k$ 都是正的。

a) 用浪漫的语言解释每个等式右边三项的意义。特别地，第三项函数项 $kSe^{-S}$ 和 $kRe^{-R}$ 是怎样表示 Scarlett 与 Rhett 相互爱慕的反应的？

b) 证明所有轨迹都从第一象限 $R, S \ge 0$ 开始，并永远在第一象限内，并且从心理学上阐释这一结果。

c) 用 Dulac 准则证明这个模型没有周期解（提示：能想出的最简单的 $g$ 会对其有所帮助）。

d) 用计算机画出系统的相图。假设参数值 $A_{R} = 1$， $A_{S} = 1.2$， $k = 15$，并假设当 Scarlett 与 Rhett 相见时相互并无好感，因此 $R(0) = S(0) = 0$。画出第一阶段他们俩发生关系的预测轨迹。

### 答案

#### 7.2.10

取 $a = b = 1$，

$$V = x^{2} + y^{2}$$

#### 7.2.12

取 $a = 1$， $m = 2$， $n = 4$，

$$V = x^{2} + y^{4}$$

#### 7.2.19

c) 取 Dulac 权函数 $g(R, S) = 1$。记

$$f(R, S) = -R + A_{S}S + kSe^{-S}, \qquad g(R, S) = -S + A_{R}R + kRe^{-R}$$

$$\frac{\partial f}{\partial R} = -1, \qquad \frac{\partial g}{\partial S} = -1$$

$$\therefore \frac{\partial (gf)}{\partial R} + \frac{\partial (gg)}{\partial S} = -2 < 0$$

恒成立， $\therefore$ 无周期解。

## 7.3 庞加莱-本迪克松定理

### 题目

#### 7.3.5

证明系统 $\dot{x} = -x - y + x(x^{2} + 2y^{2})$， $\dot{y} = x - y + y(x^{2} + 2y^{2})$ 至少拥有一个周期解。

### 答案

#### 7.3.5

$$\frac{\mathrm{d}r^{2}}{\mathrm{d}t} = 2x\dot{x} + 2y\dot{y} = -2r^{2} + 2r^{2}\left(x^{2} + 2y^{2}\right) = 2r^{2}\left(x^{2} + 2y^{2} - 1\right)$$

在圆 $r^{2} = \dfrac{1}{2}$ 上： $x^{2} + 2y^{2} \le 2r^{2} = 1$，故 $\dfrac{\mathrm{d}r^{2}}{\mathrm{d}t} \le 0$

在圆 $r^{2} = 1$ 上： $x^{2} + 2y^{2} \ge r^{2} = 1$，故 $\dfrac{\mathrm{d}r^{2}}{\mathrm{d}t} \ge 0$

$\therefore$ 环域 $\dfrac{1}{2} \le r^{2} \le 1$ 的两条边界上向量场都指向环域之外，环域内不含平衡点（唯一平衡点为原点， $r^{2} = 0$）。把时间反演 $t \to -t$ 后该环域成为通常意义下的捕获域，由庞加莱-本迪克松定理得至少 1 个周期解（不稳定极限环）。

## 7.4 李纳系统

### 题目

#### 7.4.1

证明当 $\mu > 0$ 时方程 $\ddot{x} + \mu(x^{2} - 1)\dot{x} + \tanh x = 0$ 恰好有一个周期解，并对它的稳定性进行分类。

### 答案

#### 7.4.1

令 $y = \dot{x}$，取

$$V(x, y) = \frac{1}{2}y^{2} + \int_{0}^{x} \tanh s \, \mathrm{d}s$$

$$\dot{V} = \frac{\partial V}{\partial x}\dot{x} + \frac{\partial V}{\partial y}\dot{y} = -\mu(x^{2} - 1)y^{2}$$

$\mu > 0$ 时， $\dot{V} \le 0$ 仅在 $|x| \ge 1$ 的区域成立（ $|x| < 1$ 时 $\dot{V} > 0$）。

$y > 0$ 时， $x > 0$， $(0, 0)$ 平衡。

$x = 1$ 时 $\dot{y} \ne 0$。

存在 1 个周期解。

$\therefore \|(x, y)\| \to \infty$ 时， $V \to \infty$。

$\therefore$ 唯一。

稳定。
