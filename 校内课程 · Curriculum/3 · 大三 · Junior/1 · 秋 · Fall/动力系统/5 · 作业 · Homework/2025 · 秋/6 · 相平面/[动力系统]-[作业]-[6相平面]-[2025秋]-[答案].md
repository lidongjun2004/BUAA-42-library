## 6.3 不动点与线性化

### 题目

对于以下每个系统，求出不动点，给它们分类，画出邻近的轨迹，并且试着填充相图的剩余部分。

#### 6.3.1

$$\dot{x} = x - y, \quad \dot{y} = x^{2} - 4$$

#### 6.3.3

$$\dot{x} = 1 + y - e^{-x}, \quad \dot{y} = x^{3} - y$$

#### 6.3.5

$$\dot{x} = \sin y, \quad \dot{y} = \cos x$$

#### 6.3.9

考虑系统 $\dot{x} = y^{3} - 4x$， $\dot{y} = y^{3} - y - 3x$。

a) 求出所有的不动点，并给它们分类。

b) 证明直线 $x = y$ 是不变的，即任意轨道的起始点都是它。

c) 证明对于所有的轨迹，当 $t \to \infty$ 时， $|x(t) - y(t)| \to 0$。（提示：形成一个关于 $x - y$ 的微分方程。）

d) 画出相图。

e) 如果使用计算机作图，在方形区域 $-20 \le x, y \le 20$ 画一个精确的图像。（由于具有较大的三次方非线性项，为了避免数值的不稳定性，你需要用一个非常小的步长。）注意当 $t \to -\infty$ 时，轨迹似乎接近一个确定的曲线；你可以直观地解释这个现象并且找到这个曲线的近似方程吗？

#### 6.3.13

（另一个线性中心实际上是非线性焦点）思考系统 $\dot{x} = -y - x^{3}$， $\dot{y} = x$。证明原点是一个焦点，尽管线性预测它是一个中心。

### 答案

#### 6.3.1

不动点为 $(-2, -2)$， $(2, 2)$。

#### 6.3.3

不动点为 $(0, 0)$。

#### 6.3.5

不动点为 $\left(\left(n_{1} - \dfrac{1}{2}\right)\pi,\ n_{2}\pi\right)$，其中 $n_{1}$、 $n_{2}$ 为整数。

#### 6.3.9

a) 不动点为 $(0, 0)$、 $(2, 2)$、 $(-2, -2)$；其中 $(0, 0)$ 为稳定结点， $(2, 2)$ 与 $(-2, -2)$ 为鞍点。

b) 取直线 $x = y$。在该直线上

$$\dot{x} = x^{3} - 4x = y^{3} - 4y = \dot{y}$$

故 $\dot{x} = \dot{y}$，直线 $x = y$ 不变，即 $\therefore x(t) = y(t)$。

c) 令 $u = x - y$，则

$$\dot{u} = \dot{x} - \dot{y} = y^{3} - 4x - (y^{3} - y - 3x) = -x + y = -u$$

$$\therefore u(t) = c e^{-t}, \qquad |x - y| = |c e^{-t}| \to 0$$

#### 6.3.13

令 $r^{2} = x^{2} + y^{2}$，两边对 $t$ 求导：

$$2 r \dot{r} = 2 x \dot{x} + 2 y \dot{y}$$

$$\dot{r} = \frac{x(-y - x^{3}) + yx}{\sqrt{x^{2} + y^{2}}} = \frac{-x^{4}}{\sqrt{x^{2} + y^{2}}} < 0$$

线性化矩阵

$$A_{(0,0)} = \begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix}$$

结论：原点是稳定焦点（线性化预测为中心）。

## 6.4 兔子与羊

### 题目

考虑以下的「兔子与羊」问题，其中 $x \ge 0$， $y \ge 0$。求出不动点，研究它们的稳定性，画出零点集，并画出合理的相图。指出任意稳定不动点的吸引域。

#### 6.4.1

$$\dot{x} = x(3 - x - y), \quad \dot{y} = y(2 - x - y)$$

### 答案

## 6.5 保守系统

### 题目

#### 6.5.1

考虑系统 $\ddot{x} = x^{3} - x$。

a) 求出所有的平衡点并进行分类。

b) 找到一个守恒量。

c) 画出相图。

#### 6.5.2

考虑系统 $\ddot{x} = x - x^{2}$。

a) 求出所有的平衡点并进行分类。

b) 画出相图。

c) 找到一个可以将闭合和非闭合的轨迹隔离开的同宿轨方程。

### 答案

#### 6.5.1

a) 平衡点为 $(-1, 0)$、 $(0, 0)$、 $(1, 0)$。

b) 守恒量

$$E = \frac{1}{2}\dot{x}^{2} + \frac{1}{2}x^{2} - \frac{1}{4}x^{4}$$

#### 6.5.2

a) 平衡点为 $(0, 0)$ 与 $(1, 0)$，其中 $(0, 0)$ 为鞍点， $(1, 0)$ 为中心。

c) 同宿轨方程

$$y^{2} = x^{2} - \frac{2}{3}x^{3}$$

## 6.8 指数理论

### 题目

#### 6.8.2

（不寻常不动点）对以下每个系统，找到不动点并计算相应的指数。（提示：画出围绕不动点的小闭轨 $C$，并检查 $C$ 上向量场的变化情况。）

$$\dot{x} = x^{2}, \quad \dot{y} = y$$

#### 6.8.4

（不寻常不动点）对以下每个系统，找到不动点并计算相应的指数。（提示：画出围绕不动点的小闭轨 $C$，并检查 $C$ 上向量场的变化情况。）

$$\dot{x} = y^{3}, \quad \dot{y} = x$$

#### 6.8.6

相空间中的一条闭轨包围了 $S$ 个鞍点、 $N$ 个结点、 $F$ 个焦点和 $C$ 个中心这些常见的类型。证明 $N + F + C = 1 + S$。

#### 6.8.13

（曲线指数的积分公式）考虑平面上一个光滑的向量场 $\dot{x} = f(x, y)$， $\dot{y} = g(x, y)$，令 $C$ 为一个简单的闭轨，且不穿过任意不动点。通常令 $\phi = \arctan(\dot{y}/\dot{x})$，如图 6.8.1 所示。

a) 证明 $\mathrm{d}\phi = (f\,\mathrm{d}g - g\,\mathrm{d}f)/(f^{2} + g^{2})$。

b) 导出积分公式

$$I_{C} = \frac{1}{2\pi}\oint_{C} \frac{f\,\mathrm{d}g - g\,\mathrm{d}f}{f^{2} + g^{2}}$$

#### 6.8.7

（排除闭轨道）利用指数理论去证明系统

$$\dot{x} = x(4 - y - x^{2}), \quad \dot{y} = y(x - 1)$$

不存在闭轨。

### 答案

#### 6.8.2

不动点为 $(0, 0)$，指数为 $0$。

#### 6.8.4

不动点为 $(0, 0)$，指数为 $-1$。

#### 6.8.6

闭轨的指数为 $1$，鞍点的指数为 $-1$，结点、焦点与中心的指数均为 $+1$，故

$$I = -S + N + F + C = 1$$

$$\therefore 1 + S = N + F + C$$

#### 6.8.13

a) 令 $u = \dfrac{g(x, y)}{f(x, y)}$，则 $\phi = \arctan u$。

$$\frac{\mathrm{d}}{\mathrm{d}u}(\arctan u) = \frac{1}{1 + u^{2}}$$

$$\frac{\partial u}{\partial x} = \frac{\dfrac{\partial g}{\partial x} f - g \dfrac{\partial f}{\partial x}}{f^{2}}$$

$$\therefore \frac{\partial \phi}{\partial x} = \frac{1}{1 + \dfrac{g^{2}}{f^{2}}} \cdot \frac{\dfrac{\partial g}{\partial x} f - g \dfrac{\partial f}{\partial x}}{f^{2}} = \frac{\dfrac{\partial g}{\partial x} f - g \dfrac{\partial f}{\partial x}}{f^{2} + g^{2}}$$

$$\therefore \frac{\partial \phi}{\partial y} = \frac{\dfrac{\partial g}{\partial y} f - g \dfrac{\partial f}{\partial y}}{f^{2} + g^{2}}$$

$$\therefore \mathrm{d}\phi = \frac{1}{f^{2} + g^{2}} (f\,\mathrm{d}g - g\,\mathrm{d}f) = \frac{f\,\mathrm{d}g - g\,\mathrm{d}f}{f^{2} + g^{2}}$$

#### 6.8.7

鞍点： $(2, 0)$、 $(0, 0)$

稳定螺旋： $(1, 3)$

稳定点： $(-2, 0)$

$\therefore$ 不存在闭轨。
