# 梯度下降法优化Beale函数实验报告

## 实验概述

本实验使用梯度下降法对Beale函数进行优化求解。Beale函数是一个经典的多元优化测试函数，其全局最小值点为(3, 0.5)，函数值为0。

## 实验目标

1. 实现Beale函数及其梯度的数学表达式
2. 使用梯度下降法寻找Beale函数的全局最小值
3. 分析梯度下降过程的收敛特性
4. 可视化优化过程和结果

## 数学基础

### Beale函数定义

Beale函数的数学表达式为：
$$
f(x_1, x_2) = (1.5 - x_1 + x_1x_2)^2 + (2.25 - x_1 + x_1x_2^2)^2 + (2.625 - x_1 + x_1x_2^3)^2
$$

### 梯度计算

Beale函数的梯度计算公式为：
$$
\frac{df}{dx_1} = 2a(-1 + x_2) + 2b(-1 + x_2^2) + 2c(-1 + x_2^3)
$$

$$
\frac{df}{dx_2} = 2ax_1 + 2b(2x_1x_2) + 2c(3x_1x_2^2)
$$

其中：

- $a = 1.5 - x_1 + x_1x_2$
- $b = 2.25 - x_1 + x_1x_2^2  $
- $c = 2.625 - x_1 + x_1x_2^3$

- 初始点： $(x_1, x_2) = (1.0, 1.0)$
- 学习率： $0.01$

- 优化目标：最小化Beale函数值
