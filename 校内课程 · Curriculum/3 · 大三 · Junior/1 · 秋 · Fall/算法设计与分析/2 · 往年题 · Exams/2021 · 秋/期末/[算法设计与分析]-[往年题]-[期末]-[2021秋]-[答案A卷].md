## 一、简答题（20 分）

### 题目

将下列两组函数按如下方式排序：如果 $f(n)=O(g(n))$，则 $f(n)$ 排在 $g(n)$ 前；当且仅当 $f(n)=\Theta(g(n))$ 时，函数 $f(n)$ 和函数 $g(n)$ 之间排序表示为 $\{f(n),\ g(n)\}$。如无特殊说明， $\log n=\log_2 n$。例：如果函数为

$$
n \qquad \sqrt{n} \qquad n+\sqrt{n}
$$

则正确的排序应为 $(\sqrt{n},\ \{n,\ n+\sqrt{n}\})$ 或 $(\sqrt{n},\ \{n+\sqrt{n},\ n\})$。

| A 组 | $(\log n)^{2022}$ | $n^2\log\left(n^{2022}\right)$ | $4n^{3/2}$ | $2.022^n$ | $n\log_4 n$ |
| --- | --- | --- | --- | --- | --- |
| B 组 | $2^{2^n}$ | $n^3$ | $\dbinom{n}{n/2}$ | $n!$ | $\dbinom{n}{3}$ |

提示：可以通过判断 $\log f(n)$ 和 $\log g(n)$、或 $2^{f(n)}$ 和 $2^{g(n)}$ 之间的关系来判断函数 $f(n)$ 和函数 $g(n)$ 间关系。

### 答案

A 组：先把各项化为标准形式

$$
n^2\log\left(n^{2022}\right)=2022\,n^2\log n=\Theta(n^2\log n),\qquad
n\log_4 n=\frac{n\log n}{\log 4}=\Theta(n\log n).
$$

按增长速度递增排序：

$$
\left((\log n)^{2022},\quad 4n^{3/2},\quad n\log_4 n,\quad n^2\log\left(n^{2022}\right),\quad 2.022^n\right)
$$

B 组：先把各项化为标准形式

$$
\binom{n}{3}=\frac{n(n-1)(n-2)}{6}=\Theta(n^3),\qquad
\binom{n}{n/2}=\Theta\!\left(\frac{2^n}{\sqrt{n}}\right).
$$

按增长速度递增排序：

$$
\left(\left\{n^3,\ \tbinom{n}{3}\right\},\quad \tbinom{n}{n/2},\quad n!,\quad 2^{2^n}\right)
$$

其中 $n^3$ 与 $\binom{n}{3}$ 同为 $\Theta(n^3)$，故用花括号并列； $\binom{n}{n/2}=\Theta(2^n/\sqrt n)$ 低于 $n!$； $2^{2^n}$ 为双指数增长，最高。

## 二、算法设计题（20 分）

### 题目

利用函数 $\mathrm{Test}(x,y)$，将 $n$ 个小球放进 $n$ 个不同的筐子里，使得每个小球都可以恰好找到合适的筐子。

$\mathrm{Test}(x,y)$： $x$ 是 1 个小球， $y$ 是一个筐子；返回值为“小球太大了”、“小球太小了”或“小球正合适”。

1. 设计一个最差时间复杂度为 $O(n^2)$ 的算法来匹配所有的小球和筐子。
2. 设计一个平均时间复杂度为 $O(n\log n)$ 的算法来匹配所有的小球和筐子。

### 答案

#### 1. 最差时间复杂度 $O(n^2)$ 的算法

依次处理每个小球：对当前小球，顺序测试所有尚未被占用的筐子，直到返回“小球正合适”为止。

```text
Match_Slow(balls[1..n], boxes[1..n]):
    used[1..n] <- false
    for i <- 1 to n:
        for j <- 1 to n:
            if not used[j]:
                r <- Test(balls[i], boxes[j])
                if r == "小球正合适":
                    pair[i] <- j
                    used[j] <- true
                    break
    return pair
```

每个小球最多测试 $n$ 个筐子，共 $n$ 个小球，最差时间复杂度 $O(n^2)$，空间 $O(n)$。

#### 2. 平均时间复杂度 $O(n\log n)$ 的算法

随机选一个小球作“主元”，用它把筐子和小球同时二分，再递归处理两侧。设当前待匹配的小球集合为 $B$、筐子集合为 $X$：

1. 从 $B$ 中随机取一个小球 $x$，把 $x$ 与 $X$ 中每个筐子做一次 $\mathrm{Test}$。此时恰好有一个筐子返回“小球正合适”，记为 $y$；同时把 $X\setminus\{y\}$ 分成 $X_<$（对 $x$ 返回“小球太大了”，即筐子比 $x$ 小）与 $X_>$（对 $x$ 返回“小球太小了”）。这一步 $O(|X|)$。
2. 把 $B\setminus\{x\}$ 中每个小球与 $y$ 做一次 $\mathrm{Test}$，分成 $B_<$（小球比 $y$ 小）与 $B_>$（小球比 $y$ 大）。这一步 $O(|B|)$。
3. 递归匹配 $(B_<,X_<)$ 与 $(B_>,X_>)$。

```text
Match_Fast(B, X):
    if B is empty: return
    x <- 随机取自 B 的一个小球
    X_less <- {}; X_greater <- {}; y <- null
    for each box z in X:
        r <- Test(x, z)
        if r == "小球正合适":   y <- z
        elif r == "小球太大了": X_less <- X_less + {z}      // 筐子 z 比小球 x 小
        else:                  X_greater <- X_greater + {z}
    B_less <- {}; B_greater <- {}
    for each ball w in B \ {x}:
        r <- Test(w, y)
        if r == "小球太小了": B_less <- B_less + {w}
        else:                 B_greater <- B_greater + {w}
    Match_Fast(B_less, X_less)
    Match_Fast(B_greater, X_greater)
```

正确性：比 $y$ 小的小球只能放进比 $y$ 小的筐子，而 $X_<$ 恰好是比 $x$ 小、由 $x$ 与 $y$ 的关系知也都比 $y$ 小的筐子集合；两侧规模之和为 $|B|-1$，且 $|B_<|=|X_<|$、 $|B_>|=|X_>|$，递归结构保持。

随机主元下期望递归式为 $T(n)=2T(n/2)+O(n)$，故平均时间复杂度 $O(n\log n)$。最差情况仍为 $O(n^2)$。

## 三、算法设计题（30 分）

### 题目

你正在为一次出行购买一件具有 $n$ 个零件（ $E_1,E_2,\dots,E_n$）的装备，然而经济和物流原因使得你每月只能购买其中 1 个零件。但你每推迟购买某零件 1 个月，这个零件的售价将以大于 1 的速度增加，即：若零件 $E_i$ 在首月购买需花费 100 元，则在第二个月购买需花费 $100\times r_i$，第三个月为 $100\times r_i^2$，以此类推。你可以按任意顺序购买这些零件。

1. 请举例说明贪心策略“优先购买具有最低的增长率 $r_i$ 的零件”无法使用最少花费买到全部零件。
2. 证明贪心策略“优先购买具有最高的增长率 $r_i$ 的零件”总是可以使用最少花费的买到全部零件。
3. 给出基于贪心策略“优先购买具有最高的增长率 $r_i$ 的零件”的零件购买顺序安排算法，并分析其时间复杂度。

### 答案

#### 1. 反例

取 $n=2$， $r_1=2$， $r_2=1.5$。

- 按“最低增长率优先”：第 1 个月买 $E_2$ 花 100 元，第 2 个月买 $E_1$ 花 $100\times 2=200$ 元，合计 300 元。
- 按“最高增长率优先”：第 1 个月买 $E_1$ 花 100 元，第 2 个月买 $E_2$ 花 $100\times 1.5=150$ 元，合计 250 元。

故“优先购买具有最低的增长率 $r_i$ 的零件”不能保证最少花费。

#### 2. 证明“最高增长率优先”最优

采用交换论证。设某最优购买顺序中，存在相邻的两个月 $k$ 与 $k+1$，第 $k$ 月买零件 $E_i$、第 $k+1$ 月买零件 $E_j$，且 $r_i<r_j$。

原顺序这两件零件的花费为

$$
100 r_i^{\,k-1}+100 r_j^{\,k}.
$$

交换后变为

$$
100 r_j^{\,k-1}+100 r_i^{\,k}.
$$

两者之差为

$$
100 r_i^{\,k-1}+100 r_j^{\,k}-100 r_j^{\,k-1}-100 r_i^{\,k}
=100\left[(r_j-1)r_j^{\,k-1}-(r_i-1)r_i^{\,k-1}\right].
$$

由于 $r_j>r_i>1$，函数 $h(r)=(r-1)r^{k-1}$ 在 $r>1$ 上严格递增，故上式为正，即交换后花费严格减少，与原顺序最优矛盾。

因此最优顺序中不可能出现“增长率低的排在增长率高的之前”的相邻对，即最优顺序必为按 $r_i$ 从大到小排列。证毕。

#### 3. 算法与复杂度

```text
Purchase_Order(E[1..n]):
    sort E by r descending          // 按增长率从大到小排序
    plan[1..n] <- E[1..n]           // 第 k 个月购买 plan[k]
    cost <- 0
    for k <- 1 to n:
        cost <- cost + 100 * plan[k].r ^ (k-1)
    return plan, cost
```

排序用归并排序或堆排序，时间复杂度 $O(n\log n)$；其后计算总花费为 $O(n)$。故总时间复杂度为 $O(n\log n)$，空间复杂度 $O(n)$。

## 四、算法设计题（30 分）

### 题目

在操作系统 Anix 中，一个文件可以被看作是有序字符串的集合，该文件内的第 $i$ 个字符串被称为该文件的第 $i$ 行。对于文件可以进行如下简单的变换操作：

- 在文件中插入新的一行
- 从文件中删除已有的一行
- 交换文件中相邻的两行

其中，交换两行的操作比较便宜（因为他们已经存在在文件中），而插入和删除相对较贵。

在 Anix 中，存在一个文件比较功能 $\mathrm{diff}(A,B)$，它可以通过将一系列变换操作应用在文件 $A$ 上使其转换为文件 $B$。

1. 给出求解此问题的动态规划递归公式。
2. 用循环实现基于该递归公式构造的动态规划算法伪代码。
3. 分析该伪代码的时间复杂度。

### 答案

#### 1. 动态规划递归公式

把“交换”视为代价为 0 的操作（因为它便宜），把“插入”“删除”视为代价为 1 的操作，目标是最小化插入与删除的总次数。

设 $A=a_1a_2\cdots a_n$， $B=b_1b_2\cdots b_n$。定义

$$
f(i,j)=\text{把 } A \text{ 的前 } i \text{ 行变换为 } B \text{ 的前 } j \text{ 行所需的最少插入/删除次数}.
$$

边界条件：

$$
f(0,0)=0,\qquad f(i,0)=i,\qquad f(0,j)=j .
$$

递归公式（ $i\ge 1,\ j\ge 1$）：

$$
f(i,j)=\min\begin{cases}
f(i-1,j)+1, & \text{（删除 } a_i\text{）}\\[2pt]
f(i,j-1)+1, & \text{（插入 } b_j\text{）}\\[2pt]
f(i-1,j-1), & \text{当 } a_i=b_j\ \text{（直接匹配）}\\[2pt]
f(i-2,j-2), & \text{当 } i\ge 2,\ j\ge 2,\ a_{i-1}=b_j \text{ 且 } a_i=b_{j-1}\ \text{（交换 } a_{i-1},a_i\text{）}
\end{cases}
$$

第四种情形正对应题设限制：被交换的两行 $a_{i-1},a_i$ 在 $A$ 中相邻，且它们在 $B$ 中也相邻（分别为 $b_{j-1},b_j$）并次序相反；由于 $f(i-2,j-2)$ 已把这对行整体消耗掉，每行最多只被交换一次。

所求答案为 $f(n,n)$。

#### 2. 循环实现的伪代码

```text
Diff(A[1..n], B[1..n]):
    f[0][0] <- 0
    for i <- 1 to n:  f[i][0] <- i
    for j <- 1 to n:  f[0][j] <- j
    for i <- 1 to n:
        for j <- 1 to n:
            best <- f[i-1][j] + 1                  // 删除 a_i
            if f[i][j-1] + 1 < best:
                best <- f[i][j-1] + 1              // 插入 b_j
            if A[i] == B[j] and f[i-1][j-1] < best:
                best <- f[i-1][j-1]                // 匹配
            if i >= 2 and j >= 2 and A[i-1] == B[j] and A[i] == B[j-1]
               and f[i-2][j-2] < best:
                best <- f[i-2][j-2]                // 交换相邻两行
            f[i][j] <- best
    return f[n][n]
```

#### 3. 时间复杂度

二重循环共 $(n+1)^2$ 个状态，每个状态的转移为 $O(1)$，故时间复杂度为 $O(n^2)$，空间复杂度为 $O(n^2)$（若只保留相邻两行可优化到 $O(n)$）。
