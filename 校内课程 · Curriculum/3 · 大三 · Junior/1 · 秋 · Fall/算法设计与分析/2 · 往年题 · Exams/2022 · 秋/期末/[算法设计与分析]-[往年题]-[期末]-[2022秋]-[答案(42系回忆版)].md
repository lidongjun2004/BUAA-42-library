## 三、大题

### 题目

#### 1. 01 串求和

有一个 01 串，串长 $n$，先 1 后 0 且 0/1 连续，即 1111100000 这种。

1. 在 $O(\log n)$ 时间求这个串的和；
2. 设和为 $k$，在 $O(\log k)$ 时间求这个和。

#### 2. 送牛吃草

有 $n$ 头牛，第 $i$ 头牛每天吃 $d_i$ 斤草，需要 $t_i$ 天送走，问你怎么送吃的草斤数最少。

#### 3. 哑铃排序

有 $n$ 个哑铃，有 $m$ 个关系，第 $i$ 个关系 $(a_i,b_i)$ 表示第 $a_i$ 个杠铃比第 $b_i$ 个杠铃轻，请按此将所有杠铃从小到大排序，若两个杠铃大小情况无法得到，则任意输出即可。

#### 4. 扎气球

有 $n$ 个气球，上面有数字 $a_i$，每次扎破一个，得分 $a_{左}\,a_i\,a_{右}$，即左右相邻的数字相乘再乘扎破气球的数字，问你怎么扎 $2\sim n-1$ 的球分数最高。

### 答案

#### 1. 01 串求和

设串为 $s_1s_2\cdots s_n$，由“先 1 后 0 且 0/1 连续”知存在分界点 $p$（ $0\le p\le n$），使得 $s_1=\cdots=s_p=1$， $s_{p+1}=\cdots=s_n=0$。所求“和”即 1 的个数 $p$。

**(1)** $O(\log n)$：在 $[0,n]$ 上二分， $s$ 按 $s_1..s_n$ 编号，答案 $p\in[0,n]$。取上中位 $mid=\lfloor(lo+hi+1)/2\rfloor$（保证 $mid\ge 1$，不会越界访问 $s_0$），若 $s_{mid}=1$ 则分界点在右半（ $lo\leftarrow mid$），否则在左半（ $hi\leftarrow mid-1$）。每次查询一个字符为 $O(1)$，共 $O(\log n)$ 次。

```text
Count_Ones_LogN(s[1..n]):
    lo <- 0; hi <- n
    while lo < hi:
        mid <- (lo + hi + 1) / 2
        if s[mid] == 1: lo <- mid
        else:           hi <- mid - 1
    return lo
```

**(2)** $O(\log k)$：先做指数（倍增）搜索确定上界，再在小区间内二分。依次查询 $s_1,s_2,s_4,s_8,\dots$，一旦遇到 $s_{2^t}=0$（或越界）即停止，此时 $k\in[2^{t-1},2^t)$，而 $t=\lceil\log_2(k+1)\rceil$，搜索步数为 $O(\log k)$；随后在长度为 $O(k)$ 的区间上二分，又是 $O(\log k)$ 步。

```text
Count_Ones_LogK(s[1..n]):
    if s[1] == 0: return 0
    lo <- 1; step <- 1
    while lo + step <= n and s[lo + step] == 1:
        lo <- lo + step
        step <- step * 2
    hi <- min(lo + step, n)          // 此时 s[hi] 为 0 或越界
    while lo < hi:
        mid <- (lo + hi + 1) / 2
        if s[mid] == 1: lo <- mid
        else:           hi <- mid - 1
    return lo
```

#### 3. 哑铃排序

把每个关系 $(a_i,b_i)$（ $a_i$ 比 $b_i$ 轻）看作有向边 $a_i\to b_i$，问题即对这张有向图做拓扑排序，拓扑序即为从小到大的重量次序。若图中存在环，则环内元素两两大小无法确定，此时对环内元素任意输出即可（拓扑排序失败时把剩余点按任意顺序追加）。

```text
Dumbbell_Sort(n, rel[1..m]):
    建图 G：for i <- 1 to m:  G.add_edge(rel[i].a, rel[i].b)
    indeg[1..n] <- 各点入度
    Q <- 所有入度为 0 的点（任意顺序入队）
    order <- []
    while Q 非空:
        u <- Q.pop()
        order.append(u)
        for each edge u -> v in G:
            indeg[v] <- indeg[v] - 1
            if indeg[v] == 0: Q.push(v)
    if len(order) < n:
        把剩余（处于环中的）点按任意顺序追加到 order
    return order
```

时间复杂度 $O(n+m)$（邻接表 + 队列），空间复杂度 $O(n+m)$。

#### 4. 扎气球

区间动态规划。题意要求扎破编号 $2\sim n-1$ 的气球（两端的 $a_1$、 $a_n$ 保留），扎破气球 $i$ 时得分为“当前左邻居数字 $\times a_i\times$ 当前右邻居数字”。

定义 $dp[i][j]$ 表示把开区间 $(i,j)$ 内的气球全部扎破所能得到的最高分（ $i<j$， $i$ 与 $j$ 是这段区间最终剩下的两端）。枚举最后一个被扎破的气球 $k$（ $i<k<j$），此时它的左右邻居恰好是 $a_i$ 与 $a_j$：

$$
dp[i][j]=\max_{i<k<j}\Big\{dp[i][k]+dp[k][j]+a_i\,a_k\,a_j\Big\},
$$

边界 $dp[i][i+1]=0$（区间内没有气球）。答案为 $dp[1][n]$。按区间长度从小到大递推即可。

```text
Burst_Balloons(a[1..n]):
    for len <- 2 to n-1:
        for i <- 1 to n - len:
            j <- i + len
            dp[i][j] <- -inf
            for k <- i+1 to j-1:
                dp[i][j] <- max(dp[i][j], dp[i][k] + dp[k][j] + a[i]*a[k]*a[j])
    return dp[1][n]
```

状态数为 $O(n^2)$，每个状态枚举 $O(n)$ 个决策点，时间复杂度 $O(n^3)$，空间复杂度 $O(n^2)$。
