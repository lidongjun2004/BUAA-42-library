## 〇、课程总览与学习路线图（Roadmap）

### 0.1 一句话概括这门课

传统控制（PID、经典/现代控制）依赖**被控对象的精确数学模型**，遇到非线性、强不确定、难建模、任务复杂的系统就力不从心。**智能控制**的思路是：把人类专家的经验、学习与推理能力「装进」控制器，让控制器自己去对付这些复杂系统。这门课就是带你认识「给控制器装智能」的几条主要技术路线，最后汇聚到当下最热的**具身智能 / VLA（视觉-语言-动作）模型**。

### 0.2 组织主线：人工智能三大主义 → 三类智能控制方法

整门课的方法，可以用人工智能的「三大主义」串起来（第一讲明确点出：三大主义在具身智能中很好地结合）：

| 主义 | 核心思想 | 对应的智能控制方法 | 一句话直觉 |
| --- | --- | --- | --- |
| 符号主义 | 用符号、规则、逻辑表达知识 | 专家系统、专家控制 | 让机器「讲道理、按规则办事」 |
| （模糊逻辑） | 用隶属度处理「模棱两可」 | 模糊控制、TSK 系统 | 让机器处理「差不多」「有点快」 |
| 连接主义 | 用网络从数据中学习 | 神经网络控制、RNN/LSTM、Transformer | 让机器「自己从数据里学」 |
| 行为主义 | 在与环境交互中试错优化 | 迭代学习控制、强化学习 | 让机器「边做边纠错」 |

模糊逻辑严格说不是三大主义之一，但它「基于规则」又「连续可微、能与神经网络等价」，正好是符号主义到连接主义之间的桥梁，所以单列一派。

## 第 0 节 · 导论：机器人、智能控制与具身智能

### 1. 从一个直觉开始：智能机器人到底「智能」在哪

课件用机器人春晚、武术机器人（《武 BOT》）等热点引出：现在的机器人已经不是「按固定程序动作的执行机器」，而是能**感知环境、理解指令、自主决策**的**具身智能体**。它们的关键能力体现在：低延迟交互、自主集群路径规划、情感化语境理解。

把「智能机器人」拆开，有四个基本要素，正好对应一个经典闭环 —— **OODA 循环**：

| 要素 | OODA 阶段 | 典型硬件/能力 |
| --- | --- | --- |
| 感知 Observation | 观察 | 摄像头、激光雷达 |
| 认知 Orientation | 判断 | 环境解析、情景判断 |
| 决策 Decision | 决策 | 路径规划、任务分配 |
| 执行 Action | 行动 | 协同控制、运动控制 |

**记住这个闭环**：感知 → 认知 → 决策 → 执行 → （反馈回感知）。后面所有方法，本质上都是在强化这个闭环里的某一环或整体。

### 2. 机器人的定义与分类

「机器人」没有全球统一定义，但各家定义能看出侧重：

- 《简明牛津字典》：貌似人、有智力、顺从于人但无人格的自动机。
- 美国机器人协会 RIA：可编程、多功能的机械手（manipulator），用于搬运材料/零件/工具。
- 日本 JIRA：带记忆装置和末端执行器（end effector）、能自动移动代替人力的通用机器。
- 美国国家标准局 NBS：能编程、在自动控制下执行操作与移动作业的机械装置。
- 我国定义：自动化机器 + **类人/仿生的智能能力**（感知、规划、执行、协同），强调高度灵活性。

**归纳**：国外定义强调「按程序执行任务」的能力；我国定义额外强调「智能属性」（仿生智能）。这其实预示了从「自动化」到「智能化」的演进。

机器人的三种分类依据：

1. 按**应用环境**：工业机器人 / 服务机器人。
2. 按**自主性**：遥控机器人 / 自主机器人。
3. 按**功能**：家用、医疗、农业、玩具、军事、空中机器人等。

### 3. 具身智能（Embodied Intelligence）

**定义**：概念最早可追溯到图灵（1950）。核心主张是 —— 智能不是只待在「算法/推理模块」里，而是由智能体的**物理身体、传感-运动回路、与环境的持续交互**共同塑造出来的。

两个关键词：

- **具身性**：认知与行为能力受身体结构、材料属性、驱动方式、传感配置的约束与塑形。
- **耦合**：智能体与环境通过力学交互 + 信息反馈形成动态闭环；智能表现为「闭环系统的稳定」。

**从算法智能走向闭环智能**：研究关注点从「离线的感知→决策→执行」转向「在线闭环」——实时交互、物理可实现性、任务导向的行为生成。

**机器人是具身智能的载体**，具备四性：

- 载体性：提供身体形态、执行器、接触界面，让「智能」具备物理可实现性。
- 闭环性：传感器 → 状态估计 → 策略/控制 → 执行器 → 环境反馈，构成在线闭环；用任务成功率、鲁棒性、安全性衡量性能。
- 约束性：真实世界的时延、饱和、摩擦、能量预算，要求决策满足稳定性、可控性、安全约束。
- 系统性：落地靠「算法 + 传感 + 执行 + 能源 + 管理」协同，而非单点模型指标。

**一个重要视角**：从系统论看，具身智能就是一个**广义控制问题** —— 在复杂不确定环境中做「信息-能量耦合调控」：

- 控制对象 = 具身系统；
- 控制目标 = 任务性能最优 + 约束满足；
- 控制手段 = 模型 + 反馈 + 优化 + 学习 的统一。

这句话很关键：它把「AI 的具身智能」和「控制论」直接焊在了一起，也是这门课为什么叫「智能**控制**与机器人」。

### 4. 为什么需要智能控制：传统控制的局限

传统控制 = 经典控制（如 PID、根轨迹、频域）+ 现代控制（如状态空间、最优控制）。它们的共同前提是：**有被控对象的精确数学模型**。这在实际中常常做不到：

1. 实际系统有复杂性、非线性、时变性、不确定性、不完全性，**拿不到精确数学模型**。
2. 某些含不确定性的过程**根本无法用传统数学模型描述**（建模问题）。
3. 传统方法常需要苛刻的**线性化假设**，与实际系统不符。
4. 面对智能机器人控制、社会经济系统等**复杂任务**，传统控制无能为力。

智能控制的研究对象因此有三个特点：**不确定性模型**（模型未知或参数大范围变化）、**高度非线性**、**复杂任务要求**（自规划、自决策、避障、故障诊断等）。

### 5. 智能控制的提出与定义（一段简史）

智能控制是「控制理论发展的高级阶段」，本质是一门**交叉学科**：

- 1966 年，J. M. Mendel 提出把人工智能技术用于飞船控制系统设计。
- 1971 年，美籍华人**傅京逊**教授首次提出「智能控制」概念，定义为**人工智能与自动控制的交叉**，并归纳了三类智能控制系统。
- 1977 年，G. N. Saridis 引入运筹学，提出著名的**三元交集结构**：

$$IC = AC \cap AI \cap OR$$

其中 $IC$ = 智能控制， $AC$ = 自动控制， $AI$ = 人工智能， $OR$ = 运筹学。

- $AI$：模拟人思维的知识处理系统（记忆、学习、信息处理、形式语言、启发推理）。
- $AC$：描述系统动力学特性，本质是动态反馈。
- $OR$：定量优化方法（线性规划、网络规划、调度、多目标优化）。

引入 $OR$ 的意义：在「智能 + 控制」之外，强调了更高层次的**调度、规划、管理**，为**递阶智能控制**提供理论依据。

**智能控制的定义**：设计一个控制器，使其具备**学习、抽象、推理、决策**功能，能根据环境信息变化做出适应性反应，完成原本需要人来完成的任务。

**三种类型的智能控制系统**：

1. 人作为控制器（具备自学习、自适应、自组织）。
2. 人-机结合作为控制器（机器做连续、快速的常规控制；人做任务分配、决策、监控）。
3. 无人参与的自主控制系统（多层智能控制，做问题求解、规划、环境建模、传感分析、底层反馈，如自主机器人）。

**学科形成标志**：1985 年 IEEE 成立智能控制专委会；1987 年第一次国际智能控制大会。神经网络、模糊数学、专家系统、进化论的发展给智能控制注入活力，催生各种智能控制方法。

### 6. 控制理论现状：四个有意思的观点（来自 2020 年综述）

课件引用 *Annual Reviews in Control*（2020）的产业调研，给了四个反直觉但重要的判断：

1. **控制理论在没落吗？没有。** 1960–2020 IFAC 论文数、全球「control systems」相关专利数都在稳步上升，学术界与工业界热度相当。
2. **学术界和工业界有分离吗？有。** 工业界人士在 IEEE 控制系统学会担任 leader 的比例和绝对数都在下降。
3. **现在和未来最有影响力的控制方法是什么？PID 仍稳居王座。** 其次是系统辨识；先进控制里最被看好的是 **MPC（模型预测控制）**。
4. **理论界和工业界看重的指标不同。** 理论界追求响应快、收敛快、鲁棒性好；工业界几乎压倒性地最看重**降本（cost reduction）**。

这组观点的价值：提醒你别把「智能控制」浪漫化 —— 工业落地里 PID 依然是主力，智能方法要解决的是 PID 们搞不定的那部分，且最终要算经济账。

### 7. 智能控制的五大分支（本课主线）

课件给出「常见智能控制方法」，正是后面各讲的主角：

1. **模糊控制**：精确量 → 模糊化 → 按模糊规则推理 → 解模糊为精确量 → 控制被控对象。
2. **神经网络控制**：利用神经网络的强非线性逼近与学习能力，在线调整网络权值，使反馈误差趋于零。
3. **智能搜索算法**：遗传算法、粒子群、差分进化等，模拟自然过程求解搜索/优化问题，不依赖问题模型本身特性。
4. **迭代学习控制**：利用先前控制经验和输出误差，每次迭代调整控制输入，随迭代次数增加逐渐把误差减到零（适合**重复性任务**）。
5. **强化学习控制**：智能体与环境交互，依据奖赏以「试错」方式调整策略，最大化长期累积奖赏。

加上第六讲的 **VLA（视觉-语言-动作）模型**：把视觉感知、语言理解、动作生成统一进一个神经网络，实现「看 + 听 → 行动」的端到端学习。

### 8. 智能控制的特点与应用

**四大特点**：

1. 学习功能：从环境信息中学习、积累知识，改善控制性能。
2. 适应功能：具备输入到输出的映射，可不依赖模型自适应；部分故障时仍能控制。
3. 自组织功能：对分布式信息自组织、协调；多目标冲突时能自行决策。
4. 优化能力：不断优化参数与结构，获得整体最优性能。

**典型应用**：

- 运动控制：机器人（Mamdani 于 1980s 初首次把模糊控制用于操作臂；Albus 1975 提出小脑模型 CMAC 神经网络做关节控制）、无人机（非线性多变量不确定对象，用神经网络逼近 + 反演控制）。
- 过程控制：石油化工、冶金、电力等（如神经网络用于炼油非线性工艺、专家控制用于轧钢、模糊控制用于乙烯工程）。

## 第 1 节 · 符号主义：专家系统与专家控制

### 1. 历史定位：AI 的「第二次崛起」与符号主义

专家系统是**符号主义**学派的代表作。符号主义相信：智能可以用符号、规则、逻辑显式地表达出来。

上世纪 80 年代，AI 迎来「第二次崛起」，标志性的三件事：

1. **专家系统**：模拟某领域专家决策能力的计算机系统，靠 `IF-THEN` 规则推理解决复杂问题。代表人物 **Edward Feigenbaum（费根鲍姆，「专家系统之父」，1994 年图灵奖）**。
2. **Hopfield 网络（1982）**：一种循环神经网络，结合了存储与数据处理模块，曾被用来求解 NP 难的旅行商问题（TSP）。
3. **BP 算法（1986，Rumelhart / Hinton / Williams）**：多层前馈神经网络的学习算法，理论上证明了「只含一个隐层的前馈网络能在闭区间上一致逼近任意连续函数」，是后来深度学习的里程碑。

> 注意：后两件事是**连接主义**的伏笔（第 3 节会展开）。这一节聚焦第一件事——符号主义的专家系统。

**AI 关键历史节点**（背景时间线）：

```text
1950 图灵《计算与智能》  →  1956 达特茅斯会议  →  1957 罗森布拉特「感知机」
  →  1974-1980 第一次低谷（明斯基《感知机》批判）  →  1980 XCON 专家配置系统
  →  1982 Hopfield 网络  →  1987-1993 第二次低谷  →  1997 深蓝击败卡斯帕罗夫
  →  2006 Hinton 开辟深度学习  →  2011 IBM Watson 夺冠 Jeopardy!  →  2016 AlphaGo 胜李世石
```

### 2. 专家系统的核心思想：把经验写成规则

**一句话**：专家系统 = 把专家经验写成 `IF-THEN` 规则 + 一个不知疲倦地循环匹配规则的推理机。

**定义**：一类包含知识和推理的智能计算机程序，内部含某领域专家水平的知识和经验，能解决专门问题。

自动驾驶的例子，规则本质上就是「人类驾驶经验的形式化」：

```text
规则1: IF 前方检测到红灯       THEN 减速并停车
规则2: IF 前方车距 < 安全距离   THEN 降低车速
规则3: IF 行人进入车道         THEN 紧急制动
```

工作流程（正向推理）：**环境感知 → 形成事实 → 匹配规则 → 产生控制决策**。

扫地机器人的推理机伪代码（推理机本质就是个无限循环）：

```python
while Robot_is_Running:
    front = read_sensor("Front")
    left  = read_sensor("Left")
    right = read_sensor("Right")

    if front == CLEAR:
        execute_action("前进")
    elif front == BLOCKED and left == CLEAR:
        execute_action("左转")
    elif front == BLOCKED and left == BLOCKED and right == CLEAR:
        execute_action("右转")
    else:
        execute_action("后退并调头")
```

关键认识：**专家系统的行为完全由规则库决定**——规则没覆盖到的情况，它就懵了。这是后面「衰落」的伏笔。

### 3. 专家系统的结构：知识库 + 推理机

专家系统主要由两大件构成：

- **知识库（Knowledge Base）**：存知识。包含三类知识——
  1. 基于专家经验的**判断性规则**；
  2. 用于推理、问题求解的**控制性规则**；
  3. 说明问题状态、事实、概念、常识的**数据**。
  知识库通过人机接口与领域专家沟通，完成**知识获取**。
- **推理机（Inference Engine）**：用知识库里的知识做推理得出结论的「思维机构」。

发展三阶段：

| 阶段 | 时间 | 代表系统 |
| --- | --- | --- |
| 初创期 | 1965-1971 | DENDRAL（化学分子结构，Feigenbaum）、MACSYMA（数学，MIT） |
| 成熟期 | 1972-1977 | MYCIN（血液感染诊断）、HEARSAY（语音识别） |
| 发展期 | 1978-至今 | 广泛应用，1987 年研制成功的就有 1000 种 |

### 4. 三种推理方式

- **正向推理**：从原始数据和已知条件出发，往前推得到结论（数据驱动）。扫地机器人就是正向推理。
- **反向推理**：先提出假设结论，再去找支持的证据；证据存在则假设成立（目标驱动）。MYCIN 就是反向推理。
- **双向推理**：用正向推理提出假设，再用反向推理证实。

### 5. 知识表示与确定性因子 CF（处理不确定性）

**知识表示方法**：产生式规则（最流行）、框架、语义网络、过程。用产生式规则表示的专家系统又称「基于规则的系统 / 产生式系统」。

产生式规则的标准形式：

```text
IF E THEN H WITH CF(E,H)
```

- `E`：前提条件（证据），可单独命题或复合命题；
- `H`：结论（假设）；
- `CF`：规则强度，反映「前提为真时，规则对结论的影响程度」。

**确定性因子 CF（Certainty Factor）**——专家系统的精髓之一：现实中专家知识往往不是绝对确定的（医学诊断、机器人感知），只能给「大概率成立」的判断。CF 就是用来量化这种可信度的：

$$-1 \le CF(E,H) \le 1$$

- $CF = 1$：完全确定；
- $CF = 0$：不确定；
- $CF = -1$：完全否定。

例（医疗经验）：`IF 病人持续高烧 THEN 可能细菌感染`，可信度约 70%，即 $CF = 0.7$。

CF 让专家系统能**处理不确定知识**——这是它比纯逻辑系统强的地方，也是 MYCIN 的首创贡献。

**开发与建立**：开发语言用 C / Prolog / Lisp；也可用专家系统开发工具（Shell，已建好知识表达 + 推理机框架，只需加领域知识）。建立步骤 = 知识库设计 + 推理机设计 + 人机接口设计。

### 6. 从「专家系统」到「专家控制」

K. J. Åström（瑞典）1983 年把专家系统引入控制领域，1986 年提出「**专家控制（Expert Control）**」概念。

**定义**：把专家系统的理论技术与控制理论方法结合，在未知环境下仿效专家经验实现控制。形象地说——**在传统控制基础上「加入」一个富有经验的控制工程师**。

**基本结构**：知识库 + 推理机 + 实时控制算法库，配合 A/D、D/A 与被控对象形成闭环。

**专家控制 vs 专家系统**（关键区别，常考）：

| 维度 | 专家系统 | 专家控制 |
| --- | --- | --- |
| 任务 | 辅助用户决策 | 独立、实时的自动决策 |
| 工作方式 | 离线 | **在线**（需在线获取反馈） |
| 可靠性/抗干扰 | 一般 | 要求**更高** |

一句话记忆：**专家系统是「顾问」，专家控制是「司机」**——顾问可以慢慢想，司机必须实时闭环。

**专家控制的数据库**分四类：事实（静态已知数据）、证据（动态测量值，常带噪声/延迟/冲突）、假设（由事实证据推出的中间结果）、目标（性能指标，可预定也可在线动态建立）。

### 7. 专家控制的分类

按在控制系统中的作用，分两大类：

- **直接型专家控制器**：直接**取代**常规控制器控制对象，模拟「操作工人」的智能。任务简单、需在线实时，知识库较简单（几十条产生式规则），便于增删改。**专家 PID 就是直接型。**
- **间接型专家控制器**：与常规控制器**结合**，做高层决策，模拟「控制工程师」的智能。又细分为：
  - 优化型（整定/优化参数）——在线实时；
  - 适应型（按运行状态调整控制规律）——在线实时；
  - 协调型（协调多个子控制器，实现大系统全局稳定）——可离线；
  - 组织型（组织各种常规控制器构成所需系统）——可离线。

**关键技术**：知识表达方法、从传感器获取定量信号、定性知识→定量信号转化、控制知识与规则的获取。

**特点**：灵活性（按状态选控制律）、适应性（调参适应变化）、鲁棒性（非线性大偏差下可靠工作）。

**工业案例 LINKMAN**（英国蓝圈水泥，1980s）：水泥回转窑多变量耦合、大延迟、强非线性，难建精确模型，PID 常失效。系统把老师傅「看火」经验提成规则，如 `IF 烧成带温度下降 AND 尾气氧含量偏高 THEN 增加煤粉进给量`，直接读传感器、推理、输出控制信号，是「专家系统 + 自动控制」结合最成功的早期工业案例，降低了燃耗、提升了质量一致性。

### 8. 专家 PID 控制（重点）

**思想**：基于受控对象和控制规律的各种知识，**无需精确模型**，用专家经验来设计/整定 PID 参数。它是一种**直接型专家控制器**。

要懂专家 PID，得先把这个公式从「PID 是什么」彻底讲清楚。

**PID 在干嘛**：控制问题就是让某个量（车速、温度、位置）达到目标。定义**误差** $e = $ 目标值 $-$ 当前值， $e(k)$ 是第 $k$ 个采样时刻的误差。控制器要根据误差算出控制量 $u$（油门、电压、阀门开度），把误差压到 0。PID 用三个视角看误差：

- **P 比例**：误差**现在多大**，大就使劲。像「离目标还远，踩深油门」。
- **I 积分**：误差**累计了多久**，专治「持续的小误差」（如上坡总差 2 km/h 到不了目标）。把历史误差累加、积少成多持续加码，直到误差归零，消除**稳态误差**。
- **D 微分**：误差**变化多快**，预测性地防冲过头（超调）。像「快到目标了提前收油」。

连续时间形式：

$$u(t) = k_p\,e(t) + k_i\int_0^t e(\tau)\,d\tau + k_d\frac{de(t)}{dt}$$

**数字化**：计算机每隔采样周期算一次，把积分换成「求和」、微分换成「差分」，得到**位置式 PID**（直接算当前 $u(k)$）：

$$u(k) = k_p\,e(k) + k_i\sum_{j=0}^{k} e(j) + k_d\,[e(k)-e(k-1)]$$

位置式的麻烦：要存从头到现在**所有**误差做累加（ $\sum$），积分项容易累成巨大值（积分饱和）。

**增量式**的巧思：不算「 $u$ 该是多少」，只算「这一步 $u$ 要在上一步基础上**增减多少**」，即 $\Delta u(k)=u(k)-u(k-1)$。把 $u(k)$ 和 $u(k-1)$ 两式相减，三项各自变成：

- P 项 → $k_p\,[e(k)-e(k-1)]$
- I 项 → $k_i\big[\sum_{j=0}^{k}e(j)-\sum_{j=0}^{k-1}e(j)\big] = k_i\,e(k)$（累加之差只剩**最新一项**，积分长尾巴消失）
- D 项 → $k_d\big\{[e(k)-e(k-1)]-[e(k-1)-e(k-2)]\big\} = k_d\,[e(k)-2e(k-1)+e(k-2)]$

合起来就是那个公式：

$$\Delta u(k) = k_p[e(k)-e(k-1)] + k_i\,e(k) + k_d[e(k)-2e(k-1)+e(k-2)]$$

$$u(k) = u(k-1) + \Delta u(k)$$

**每一项现在读作**： $k_p[e(k)-e(k-1)]$ 是误差这一步**变化了多少**（一阶差分 $\Delta e(k)$）； $k_i\,e(k)$ 是**当前误差本身**（累加和的新增项）； $k_d[e(k)-2e(k-1)+e(k-2)]$ 是误差的**二阶差分**，即 $\Delta e(k)-\Delta e(k-1)$，「这次变化」减「上次变化」= 误差曲线的弯曲/加速度。

**增量式三大好处**：① 只需最近 3 个误差，不存历史、无积分饱和；② 输出是增量，适合阀门/步进电机这类「在原位微调」的执行器，手自动切换冲击小；③ 单次误算只影响一步，安全。

一阶差分简记：

$$\Delta e(k) = e(k) - e(k-1)$$

专家 PID 的做法：观察典型二阶系统阶跃响应的误差曲线，按误差大小与变化趋势**分 5 种情况**切换控制策略（设阈值 $M_1 > M_2 > 0$，极小误差界 $\varepsilon$）：

1. **误差极大**： $|e(k)| > M_1$。不管趋势，输出取最大/最小（相当于开环 bang-bang），以最快速度把误差拉回。
2. **误差在恶化**： $e(k)\,\Delta e(k) > 0$ 或 $\Delta e(k)=0$（误差与其变化同号，正朝绝对值增大方向走）。再看大小：
   - 若 $|e(k)| \ge M_2$（误差也大）→ **强控制**，增量乘放大系数 $k_1>1$：
     $$\Delta u(k) = k_1\big\{k_p[e(k)-e(k-1)] + k_i e(k) + k_d[e(k)-2e(k-1)+e(k-2)]\big\}$$
   - 若 $|e(k)| < M_2$ → **一般控制**，用标准增量 PID。
3. **误差在好转 / 已平衡**： $e(k)\,\Delta e(k) < 0$ 且 $\Delta e(k)\,\Delta e(k-1) > 0$，或 $e(k)=0$（误差正朝减小方向变化）。**保持输出不变** $u(k)=u(k-1)$，别去干扰这个好趋势。
4. **误差处于极值（拐点）**： $e(k)\,\Delta e(k) < 0$ 且 $\Delta e(k)\,\Delta e(k-1) < 0$。设误差极值为 $e_m(k)$：
   - 若 $|e(k)| \ge M_2$ → 较强控制： $\Delta u(k) = k_1 k_p\, e_m(k)$；
   - 若 $|e(k)| < M_2$ → 较弱控制： $\Delta u(k) = k_2 k_p\, e_m(k)$（ $k_2 < 1$）。
5. **误差极小**： $|e(k)| \le \varepsilon$。加入积分作用，消除稳态误差。

核心直觉：**误差大→猛踩（甚至开环全力），误差在变好→别乱动，到极值→适度修正，误差很小→用积分抹平静差**。这正是一个老司机的「手感」，被翻译成了 5 条规则。

课件给的仿真例子是对三阶传递函数

$$G_p(s) = \frac{523500}{s^3 + 87.35\,s^2 + 10470\,s}$$

用采样周期 1 ms、上述 5 条规则做专家 PID，得到快速且平稳的阶跃响应曲线。

### 10. 反思：专家系统为什么「退场」了

三个根本困境：

1. **知识获取困境**：专家的隐性经验（直觉、手感）「只可意会，不可言传」，转成严谨的 `IF-THEN` 极其困难耗时。
2. **缺乏泛化能力**：规则库没覆盖的情况就不会处理，**不能举一反三**。
3. **难扩充维护**：规则从几十条涨到数万条（如 XCON），新规则极易与旧规则**逻辑冲突**，验证维护成本指数级上升。

2006 年 Hinton 开辟深度学习后，AI 主流范式从「人工编写规则」转向「让机器从数据自动学规律」——这正是后面几节（神经网络、强化学习）的故事。

但专家系统**没有消失**：它退居幕后变成企业的「业务规则管理系统」；在自动驾驶底层安全策略、医疗核心诊断等高安全领域，它作为「安全底线」与深度学习混合使用，即**神经符号系统（Neuro-Symbolic）**。

## 第 2 节 · 模糊逻辑：模糊控制

### 1. 为什么需要模糊控制（动机）

一个例子：几点睡算「熬夜」？23:00 几乎不算，00:00 有点熬，01:30 非常熬。但你定不出精确界线——难道 23:59 不算、00:01 就算？**「熬夜」本身是个模糊概念**。「模糊」指事物在中间过渡时界限不明显、「亦此亦彼」的性质，相对「精确」而言。「老师/学生」是精确概念；「高个子/热天气/年轻人」是模糊概念。

三条痛点逼出模糊控制：

- **传统控制的痛点**：极度依赖精确数学模型，难对付高复杂系统。
- **专家系统的局限**：虽引入经验，但 `IF-THEN` 非黑即白（如「IF 温度 > 100 THEN 关阀」）。
- **人类思维的真相**：熟练操作员的经验是**定性**的——「IF 温度有点高 THEN 把阀门关小一点」。

**核心思想**：用模糊数学，把人「不精确的自然语言经验」**定量化**，转成计算机能执行的控制算法。

五个特点：① **无模型**控制；② 贴近人类认知（用「高/中/低」推理）；③ 易理解（自然语言模糊规则）；④ 工程实现简单；⑤ 鲁棒性与适应性强（对大延迟、非线性、强干扰有效）。

### 2. 模糊集合：从「非 0 即 1」到「隶属度」

模糊数学由美国加州大学 **Zadeh（扎德）教授**提出，不是让数学变模糊，而是用数学工具**描述和分析模糊现象**。它在经典集合论基础上，引入**隶属函数**描述「事物从属于某模糊概念的程度」。

- **经典集合**：元素与集合的关系只有「属于(1)」或「不属于(0)」，分界线明确。
- **模糊集合**：用 **隶属度（Degree of membership）** 描述从属程度，是 $[0,1]$ 间**连续变化**的值。

为什么需要它？定义「舒适 = 15~25℃，冷 = 15℃以下」。按经典集合，14.99℃ 属于「冷」、15.01℃ 属于「舒适」——差 0.02 度感觉天壤之别？这跟人的真实感觉完全不符。模糊集合允许 15℃ 附近「既有点冷又有点舒适」。

**定义**：给定论域 $E$，模糊集 $A$ 指任意元素 $x \in E$ 都不同程度地属于它，程度用隶属函数 $\mu_A(x) \in [0,1]$ 表示。

经典案例（Zadeh 的「年轻」模糊集）：当 $0 \le x \le 25$ 时 $\mu_{\text{年轻}}(x)=1$（铁定年轻）；当 $25 < x \le 100$ 时按下式衰减：

$$\mu_{\text{年轻}}(x)=\left[\,1+\left(\frac{x-25}{5}\right)^{2}\,\right]^{-1}$$

代入 $x=30$：

$$\mu_{\text{年轻}}(30)=\left[\,1+\left(\frac{30-25}{5}\right)^{2}\,\right]^{-1}=\frac{1}{1+1}=0.5$$

即「30 岁属于年轻人的程度是 0.5」——模糊集合给出了「半个年轻人」这种符合直觉的描述。

### 3. 模糊集合的三种表示法

设论域有限，例 5 个人身高 {172,165,175,180,178}，对「高个子」隶属度 {0.8,0.78,0.85,0.9,0.88}。

1. **Zadeh 表示法**： $A = \dfrac{\mu(x_1)}{x_1} + \dfrac{\mu(x_2)}{x_2} + \cdots + \dfrac{\mu(x_n)}{x_n}$。注意「+」「/」只是**分隔符**，不是加和除。例：高个子 $= \frac{0.8}{172}+\frac{0.78}{165}+\frac{0.85}{175}+\frac{0.9}{180}+\frac{0.88}{178}$。
2. **序偶表示法**： $A = \{(x_1,\mu(x_1)),(x_2,\mu(x_2)),\dots\}$。例：高个子 $=\{(172,0.8),(165,0.78),(175,0.85),(180,0.9),(178,0.88)\}$。
3. **隶属函数描述法**：直接用隶属函数 $\mu_A(x)$ 表示（适合连续论域，如上面「年轻」的分段函数）。

三种只是写法不同，内核都是「每个元素配一个 $[0,1]$ 的隶属度」。

### 4. 模糊集合的交并补运算

模糊集也有交、并、补，只是把「非此即彼」换成隶属度的逐点运算（设 $A,B$ 在同一论域）：

- 交 $A\cap B$：逐点**取小**， $\mu_{A\cap B}(x)=\min(\mu_A(x),\mu_B(x))$，记作 $\wedge$；
- 并 $A\cup B$：逐点**取大**， $\mu_{A\cup B}(x)=\max(\mu_A(x),\mu_B(x))$，记作 $\vee$；
- 补 $\bar A$： $\mu_{\bar A}(x)=1-\mu_A(x)$。

例：论域 $\{a,b,c,d,e\}$， $A=(0.5,0.3,0.4,0.2,0.1)$， $B=(0.2,0.8,0.1,0.7,0.4)$： $A\cap B=(0.2,0.3,0.1,0.2,0.1)$、 $A\cup B=(0.5,0.8,0.4,0.7,0.4)$、 $\bar A=(0.5,0.7,0.6,0.8,0.9)$。

直觉：模糊逻辑里 **「且」= 取小**（一串条件里最弱一环决定整体，木桶效应）、**「或」= 取大**、**「非」= 1 减**。这三个算子是后面所有模糊推理的基础。

### 5. 模糊关系与合成

**模糊关系**描述两个论域元素「在多大程度上相关」，用矩阵表示， $r_{ij}=\mu_R(x_i,y_j)\in[0,1]$。例：子女与父母相貌相似度

| | 子 | 女 |
| --- | --- | --- |
| 父 | 0.8 | 0.3 |
| 母 | 0.5 | 0.9 |

**模糊关系合成（max-min 合成）**：算法像矩阵乘法，但**「乘」改取小 $\wedge$、「加」改取大 $\vee$**。例 $R_1\circ R_2$，其中

$R_1$:

| 0.3 | 0.7 | 0.2 |
| --- | --- | --- |
| 1.0 | 0.0 | 0.4 |
| 0.6 | 0.8 | 0.5 |

$R_2$:

| 0.1 | 0.5 | 0.6 |
| --- | --- | --- |
| 0.8 | 0.5 | 0.7 |
| 0.0 | 0.4 | 0.3 |

结果第 1 行第 1 列： $(0.3\wedge0.1)\vee(0.7\wedge0.8)\vee(0.2\wedge0.0)=0.1\vee0.7\vee0.0=0.7$。直觉：每条「通路」取最弱一环，多条通路取最强那条。

**模糊变换**是合成的特例（向量 ∘ 矩阵） $B=A\circ R$。例 $A=(0.3,0.8)$， $R=\{(0.4,0.5),(0.6,0.2)\}$： $B_1=(0.3\wedge0.4)\vee(0.8\wedge0.6)=0.6$， $B_2=(0.3\wedge0.5)\vee(0.8\wedge0.2)=0.3$，故 $B=(0.6,0.3)$。

### 6. 模糊推理：让「IF A THEN B」能算

模糊推理 = 用模糊关系把输入模糊集变成输出模糊集。一条规则「IF x is A THEN y is B」分两步：

1. **把规则编码成模糊关系** $R=A\times B$： $\mu_R(x,y)=\mu_A(x)\wedge\mu_B(y)$（逐对取小）。
2. **用实际输入做合成**：实际输入 $A'$，输出 $B'=A'\circ R$（max-min 合成）。

例（IF 温度低 THEN 开大阀门）：温度低 $A=(1.0,0.6,0.1)$，阀门开大 $B=(0.1,0.7,1.0)$。先求 $R=A\times B$：

| 0.1 | 0.7 | 1.0 |
| --- | --- | --- |
| 0.1 | 0.6 | 0.6 |
| 0.1 | 0.1 | 0.1 |

输入实际温度 $A'=(0.8,0.5,0.2)$，则 $B'=A'\circ R$： $B'_1=0.1$、 $B'_2=(0.8\wedge0.7)\vee(0.5\wedge0.6)\vee(0.2\wedge0.1)=0.7$、 $B'_3=(0.8\wedge1.0)\vee(0.5\wedge0.6)\vee(0.2\wedge0.1)=0.8$，得 $B'=(0.1,0.7,0.8)$。（ $R$ 与 $B'$ 的数值按标准 max-min 推理推导，课件只给了 $A,B,A'$。）**模糊关系就是模糊推理的桥梁。**

### 7. 模糊控制器：三件套 + 工作流程

```text
精确量 →①模糊化→ 模糊量 →②知识库+推理→ 模糊控制量 →③解模糊→ 精确控制量
```

**① 模糊化接口（Fuzzification）**：精确量 → 模糊量。步骤：定输入语言变量 → 定论域 → 定隶属函数 → 求精确量隶属度。常用**单点模糊集**（精确值映射成隶属度 = 1 的单点）。典型语言变量（描述误差，三角隶属函数，论域 $[-6,6]$）：**NB 负大 / NM 负中 / NS 负小 / ZO 零 / PS 正小 / PM 正中 / PB 正大**。

**② 知识库 = 数据库（存隶属函数）+ 规则库（存 IF-THEN 模糊规则）**。对称控制规则表（输入 $e$，输出 $u$）：

| IF e | NB | NM | NS | ZO | PS | PM | PB |
| --- | --- | --- | --- | --- | --- | --- | --- |
| THEN u | PB | PM | PS | ZO | NS | NM | NB |

含义：误差越偏，控制量越往反方向拉（对称负反馈；符号约定由设计者定，温度系统里也可定成「误差大→功率大」的同号规则）。

**③ 推理与解模糊接口**：推理用输入模糊量 + 知识库求出模糊控制量；**解模糊（Defuzzification）**把模糊量变回精确量，三法——① 最大隶属度法（取隶属度最大值，简单但粗）② **重心法**（取隶属度曲线质心，最常用、平滑）③ 加权平均法。

**完整实例（温度控制）**：目标 25℃、当前 23℃、误差 $e=2℃$； $e,u$ 论域均 $[-6,6]$；规则如「IF e is PB THEN u is PB」「IF e is PS THEN u is PS」。 $e=2$ 模糊化得到它对 PS/PM 的隶属度 → 触发规则推理出 $u$ 的模糊集 → 解模糊（重心法）得到精确加热功率。

### 8. 模糊控制器的设计步骤（二维模糊控制器）

工程最常用**单变量二维模糊控制器**：输入误差 $E$ 和误差变化 $EC$，输出控制量 $u$（本质是「模糊版 PD 控制」）。7 步：

1. **定义控制器**：选二维结构（输入 $E,EC$，输出 $u$）。
2. **定义模糊集与论域**： $E,EC,u$ 都取 7 档 $\{NB,NM,NS,ZO,PS,PM,PB\}$； $E,EC$ 论域 $\{-3,-2,-1,0,1,2,3\}$， $u$ 论域 $\{-4.5,-3,-1.5,0,1.5,3,4.5\}$。
3. **定义隶属函数**：给每个语言值定隶属函数（常用三角形）。
4. **建立模糊规则**：靠经验，按「误差 + 误差变化趋势」写。
5. **建立模糊控制表**：规则间是「或」，二维共 $7\times7=49$ 条（行 $E$、列 $EC$、格内 $u$）：

| E＼EC | NB | NM | NS | ZO | PS | PM | PB |
| --- | --- | --- | --- | --- | --- | --- | --- |
| NB | NB | NB | NM | NM | NS | NS | ZO |
| NM | NB | NM | NM | NS | NS | ZO | PS |
| NS | NM | NM | NS | NS | ZO | PS | PS |
| ZO | NM | NS | NS | ZO | PS | PS | PM |
| PS | NS | NS | ZO | PS | PS | PM | PM |
| PM | NS | ZO | PS | PS | PM | PM | PB |
| PB | ZO | PS | PS | PM | PM | PB | PB |

规律：对角对称，误差与误差变化越往一个方向偏，控制量越往对应方向给。

1. **模糊推理**：用推理算法 + 规则得模糊控制量。
2. **反模糊化（解模糊）**：模糊量转精确值。

**工程关键技巧——查询表（Look-up Table）**：把 49 条规则**离线**全部推理 + 解模糊，算成一张「 $E\times EC\to u$ 的数值表」（模糊响应表）；在线时直接**查表**，不实时推理，又快又稳。这是模糊控制能塞进单片机的原因。仿真示例：被控对象 $G(s)=\dfrac{400}{s^2+500s}$，位置指令 $0.5\sin(10t)$。

### 9. 解模糊的三种方法

- **最大隶属度法**：取隶属度最大的输出 $v_0=\arg\max_v\mu(v)$，并列则取平均。简单，但丢分布信息、易跳变。
- **重心法（最常用）**：取隶属度曲线与横轴围成面积的质心。离散式：

$$v_0=\frac{\sum_{k} v_k\,\mu(v_k)}{\sum_{k}\mu(v_k)}$$

输出平滑，输入微变输出也平滑变。

- **加权平均法**： $v_0=\dfrac{\sum_i k_i v_i}{\sum_i k_i}$，工业常用；权 $k_i$ 取 $\mu(v_i)$ 时退化为重心法。

### 10. 模糊自适应整定 PID（模糊 × PID）

**思想**：把「什么误差状况下 PID 三参数该怎么调」的经验写成模糊规则；运行时实时检测 $e,ec$，用模糊推理**在线整定** $k_p,k_i,k_d$：

$$k_p=k_{p0}+\Delta k_p,\quad k_i=k_{i0}+\Delta k_i,\quad k_d=k_{d0}+\Delta k_d$$

$\Delta k$ 由模糊规则表查得。配位置式离散 PID：

$$u(k)=k_p\,e(k)+k_i\,T\sum_{j=0}^{k}e(j)+k_d\,\frac{e(k)-e(k-1)}{T}$$

**三参数作用分析（重点，常考）**：

| 参数 | 作用 | 过大 | 过小 |
| --- | --- | --- | --- |
| $k_p$ 比例 | 加快响应、提高精度 | 超调、易不稳定 | 响应慢、精度低 |
| $k_i$ 积分 | 消除稳态误差 | 积分饱和、超调大 | 静差难消除 |
| $k_d$ 微分 | 改善动态、提前预报偏差 | 提前制动、延长调节、抗干扰差 | 动态改善不足 |

**工作流程**：取 $e(k),ec(k)$ → 模糊化 → 模糊整定 $k_p,k_i,k_d$ → 算 PID 输出 → 更新返回。

**对比专家 PID**（都不要精确模型）：专家 PID 用规则切换控制**策略**（5 种情况）；模糊 PID 用模糊推理在线调 PID **三个参数旋钮**。前者调「怎么打」，后者调「力度」。

### 11. 应用与发展概况

**应用**：① 家电——模糊电视（光线调亮度/距离调音量）、模糊空调（红外识别房间调温）、模糊洗衣机（识别衣物选水位时间）、微波炉、剃刀；② 机电——集装箱吊车、空间机器人柔性臂、电梯群控、无刷电机调速；③ 过程控制——工业炉（水泥窑/电弧炉）、石化（蒸馏塔/pH/污水）、煤矿、食品发酵。

**发展转折点**：1965 Zadeh 模糊集 → 1972 模糊控制原理 → 1977 最优模糊控制 → 1983 预测模糊控制 → 1985 稳定性 → **1992 L.X.Wang 模糊万能逼近器**（模糊系统能逼近任意连续函数，和神经网络一样）→ 1992 Yager 用神经网络学隶属函数 → 1993 自适应模糊控制。

**五大方向**：Fuzzy-PID 复合控制、自适应模糊控制、专家模糊控制、**神经模糊控制**（用神经网络学习能力获取/修正模糊规则与隶属函数）、多变量模糊控制。

> 加粗的**模糊万能逼近器 + 神经模糊控制**，正是「模糊」与「神经网络」深层相通的信号——这是下一段 TSK 模糊系统的主题，也是通往第 3 节连接主义的桥。

## 第 2 节（续）· 模糊系统优化：TSK 模糊系统

### 12. TSK 模糊系统：把规则后件从「模糊集」换成「函数」

**TSK** = Takagi–Sugeno–Kang，三位日本学者提出，非线性逼近能力很强，广泛用于系统辨识、模式识别、图像处理、数据挖掘。

它和 Mamdani 型的唯一区别在**后件**。一条二输入 TSK 规则长这样：

$$\text{IF } x_1 \text{ is } F_1 \text{ and } x_2 \text{ is } F_2,\ \text{THEN } y = a_1 x_1 + a_2 x_2 + c$$

- **前件（Antecedents）**：`x1 is F1 and x2 is F2`，和模糊控制一样，用隶属函数判断输入「有多符合这条规则」。
- **后件（Consequent）**：不再是「u is 正大」这种模糊集，而是一个**关于输入的函数** $y=a_1x_1+a_2x_2+c$。当 $a_1=a_2=0$ 时退化成常数（零阶 TSK），否则是一阶/非线性（高阶 TSK）。

直觉：Mamdani 是「每条规则投一个模糊标签，最后解模糊」；TSK 是「每条规则给一个小公式算出一个数，最后按隶属度加权平均」。后者天然就是可微的数值输出，省掉了解模糊那一步，也更好训练。

**设计 TSK 的三大挑战**：① **优化**——用进化算法 / 梯度下降 / 梯度下降+最小二乘（自适应模糊系统）来定参数；② **维数灾难**——每个输入都切几档模糊集，规则数随输入维度**指数爆炸**；③ **泛化**——和神经网络一样会过拟合，要靠正则化。

### 13. TSK 的「等价性」：它其实是五种机器学习模型的统一面孔

本节最重要的观点：**一个 TSK 模糊系统，在适当条件下，和下面五种主流机器学习模型功能等价**。理解这点，就能把神经网络那套成熟技术直接搬来优化模糊系统。

**① TSK ≈ RBF 神经网络（最直接的等价）**。RBFN 对输入 $x=(x_1,x_2)$，第 $k$ 个「感受野单元」用高斯响应：

$$f_k(x)=\exp\!\Big(-\tfrac{(x_1-m_{k,1})^2+(x_2-m_{k,2})^2}{\sigma_k^2}\Big)$$

网络输出是各单元按响应加权平均：

$$y(x)=\frac{\sum_{k} f_k(x)\,y_k}{\sum_{k} f_k(x)}$$

把它和模糊系统对照：**感受野单元数 = 模糊规则数**、规则前件用高斯隶属函数、后件取常数、用 t-范数做「and」、最后用同样的加权平均算输出——两者计算流程**逐字相同**（Jang & Sun, 1993 证明）。这就是「模糊系统是万能逼近器」和「RBFN 是万能逼近器」其实是同一件事。

**② TSK ≈ 多层感知机 / ANFIS**。把模糊推理的每一步画成一层神经元，就得到 **ANFIS（自适应网络模糊推理系统）**，见第 14 节。和 MLP 的区别：MLP 是全连接黑盒、每个节点都是「加权和+激活」；ANFIS 各层操作不同、更复杂，且**能按 IF-THEN 规则展开**，是白盒。

**③ TSK ≈ 混合专家模型（MoE）**。MoE 输出 $y_{ME}(x)=\sum_k f_k(x)\,y_k(x)$：一个「路由网络」决定每个专家 $y_k$ 的权重 $f_k$。对照 TSK——**每条规则就是一个局部专家**，前件隶属度就是路由权重。启发：可以借 MoE 的思想，让 TSK 规则之间更好地「合作与竞争」。

**④ TSK ≈ 分类回归树（CART）**。树的每条「根→叶」路径就是一条规则，叶子给输出。启发：可用 CART 为**高维问题更好地初始化** TSK 规则。

**⑤ TSK ≈ Stacking（堆叠集成）**。每条规则的后件是一个**基础回归模型**，前件隶属度决定它在堆叠里的**权重**。关键差别：普通 Stacking 的聚合权重是固定的；TSK 的聚合权重**依赖输入 $x$、随输入变化**——所以 TSK 本质是一个**自适应的堆叠回归模型**。启发：借集成学习提升泛化。

一句话总结这一节：**TSK 是 RBFN / MLP / MoE / CART / Stacking 的「最大公约数」**，于是这些模型的训练技巧（梯度下降、Dropout、归一化、聚类初始化）都能拿来优化它。

### 14. ANFIS：把模糊推理画成五层网络

**ANFIS（Adaptive-Network-based Fuzzy Inference System，Jang 1993）**把一次模糊推理拆成五层前馈计算，于是可以用反向传播训练：

| 层 | 干什么 |
| --- | --- |
| 第 1 层 | 计算每个输入对每个模糊集的**隶属度** |
| 第 2 层 | 把各输入隶属度相乘，得到每条**规则的激活强度** |
| 第 3 层 | 把所有规则激活强度**归一化**（除以总和） |
| 第 4 层 | 归一化激活强度 × 该规则后件函数值 |
| 第 5 层 | 把第 4 层结果**求和**，得到最终输出 |

和 MLP 比，ANFIS 第 4 层会用到原始输入 $x_1,x_2$（算后件函数），MLP 没有这种结构；而且 ANFIS 可解释（每个节点对应模糊推理的一步），MLP 是黑盒。这就是「神经模糊」的标准范式。

### 15. 怎么训练 TSK：回归与分类的优化套路

既然 TSK 等价于神经网络，就按神经网络的训练流水线来。**三步走：定义目标函数 → 初始化规则 → 微调规则**（代表作 MBGD-RDA，Wu et al. 2019）。

**第一步·目标函数加正则化**。回归用带 L2 正则的均方误差（ $N_{bs}$ 是 mini-batch 大小， $\lambda$ 是正则系数；注意后件常数项 $b_{r,0}$ 不正则化）：

$$L=\tfrac{1}{2}\sum_{n=1}^{N_{bs}}\big[y_n-y(x_n)\big]^2+\tfrac{\lambda}{2}\sum_{r=1}^{R}\sum_{m=1}^{M} b_{r,m}^2$$

分类则把输出过 softmax 得类概率、用**交叉熵**损失，并额外加一项「**均匀正则**」，强迫每条规则被触发的程度相近、对输出贡献大致相等，**缓解「富者更富」**（少数规则垄断）的问题。

**第二步·半随机初始化规则**。对每个输入维度 $m$：算训练集该维的最小/最大值，在区间内**均匀**放置各高斯隶属函数的中心；标准差初始化为该维的标准差；后件参数初始化为 0。分类问题则常用 **k-means 聚类**来初始化规则中心。

**第三步·微调规则**，针对三个工程难题各有对策：

- **大数据（样本多、维度高）→ Mini-Batch 梯度下降（MBGD）**：每次随机抽一小批样本算梯度更新参数 $\theta_k=\theta_{k-1}-\alpha\,\frac{\partial L}{\partial\theta}\big|_{k-1}$。 $N_{bs}=1$ 退化成随机 GD， $N_{bs}=N$ 变成批量 GD。
- **加速训练 → Adam / AdaBound**：Adam 自适应调学习率，AdaBound 再给学习率加上下界，避免后期震荡。
- **提高泛化 → DropRule / 归一化**：DropRule 是 Dropout 的模糊版——训练时**随机丢掉一些规则**防过拟合；高维回归再配 **Layer Normalization + ReLU**；分类则用 **Batch Normalization**。

**一张总表（回归 vs 分类）**：

| 步骤 | 回归 | 分类 |
| --- | --- | --- |
| 目标函数 | L2 正则 | L2 正则 + 均匀正则 |
| 初始化 | 半随机 | k-means 聚类 |
| 处理大数据 | MBGD | MBGD |
| 加速训练 | AdaBound | AdaBound |
| 提高泛化 | DropRule / Layer Norm | ReLU / Batch Norm |

### 16. Mamba / SSM：序列建模又「绕回」控制的状态空间法

专题最后抛出一个呼应全课主题的彩蛋：当下挑战 Transformer 的 **Mamba**，其内核 **SSM（状态空间模型）** 正是《自动控制原理》里的**状态空间法**。

**Transformer 的痛点**：自注意力对序列长度 $N$ 的复杂度是平方级

$$T(N)=l\times(24bNd^2+4bN^2 d)\sim O(N^2)$$

（ $l$ 层数、 $b$ batch、 $d$ 隐藏维），且有「窗口」概念，超长序列吃不消。

**Mamba（Gu & Dao, 2023）**不靠 attention，由多个 **S4 / S6（选择性扫描）**模块堆叠 + CUDA 优化：**训练时像 CNN（可并行）、推理时像 RNN（状态递推）**，吞吐量是 Transformer 的 5 倍，能处理 100 万+ token。它的家谱一路从控制理论长出来：

$$\text{状态空间法(Kalman,1960)} \to \text{HiPPO/LSSL} \to \text{S4} \to \text{S6/Mamba}$$

**等价对照**——机器学习的 SSM（Gu, ICLR 2022）写成连续状态方程 + 输出方程：

$$\dot h(t)=A\,h(t)+B\,u(t)$$

$$y(t)=C\,h(t)+D\,u(t)$$

这和自动控制原理的状态空间法**一模一样**：

$$\dot x = A x + B u,\qquad y = C x + D u$$

其中状态矩阵 $A$ 管「记忆怎么随时间演化」， $D$ 像残差/直通瓶颈。也就是说，**深度学习兜了一大圈，又回到了控制论 60 年前的语言**——这正是这门课「智能 × 控制」深层统一的最好注脚，也再次照应导论里那句「具身智能是广义控制问题」。

## 第 3 节 · 连接主义：神经网络控制

本节主线：机器学习三要素 → 神经元/前馈网络/激活函数 → 通用近似定理 → 反向传播 → 神经网络控制结构 → RBF 网络控制 → RNN → LSTM → Transformer。

### 1. 机器学习在「学」什么：构造一个映射函数

一句话本质：**机器学习 ≈ 构造一个映射函数** $f:x\mapsto y$。看图认猫（像素→是否猫）、自动驾驶转向（画面→方向盘转角）、控制（误差→控制量 $u$），剥到底都是找一个 $f$。传统编程是**人写死** $f$（PID 公式、模糊规则都是人写的 $f$）；机器学习是**给一堆 $(x,y)$ 例子，让机器自己拼出** $f$。

**机器学习三要素**（任何方法都是这三样的组合）：

1. **模型(Model)**：框定「 $f$ 长什么样」的候选函数家族 + 可调旋钮 $\theta$。
   - 线性模型 $f(x,\theta)=w^{\mathsf T}x+b$；
   - 广义线性模型 $f(x,\theta)=w^{\mathsf T}\phi(x)+b$。
   - **关键**：若基函数 $\phi(x)$ 本身是**可学习的非线性函数**，则 $f$ 就**等价于一个神经网络**。即：**神经网络 = 连基函数 $\phi$ 都让机器自己学的广义线性模型**（呼应第 2 节 TSK≈RBFN 的伏笔）。
2. **学习准则(Learning Criterion)**：用**损失函数**给「这套旋钮好不好」打分，目标是让期望风险最小：

$$\mathcal R(f)=\mathbb E_{(x,y)\sim p(x,y)}\big[\mathcal L(f(x),y)\big]$$

1. **优化方法(Optimization)**：怎么拧旋钮让损失最小——**梯度下降**。直觉是「蒙眼下山」：感知当前最陡下坡方向（负梯度），迈一小步，反复滚到谷底；步长由**学习率**控制。

### 2. 补讲：MBGD 与 TSK（两个之前记进笔记但没讲透的词）

**MBGD（Mini-Batch Gradient Descent，小批量梯度下降）**——梯度下降每走一步要算「损失对参数的梯度」，而损失定义在所有样本上，于是有「每步用多少样本」的选择：

| 方式 | 每步用多少样本 | 特点 |
| --- | --- | --- |
| 批量 GD | 全部 $N$ 个 | 方向最准，但百万样本走一步要遍历全集，太慢 |
| 随机 GD（SGD） | 1 个 | 快，但方向抖、噪声大 |
| **小批量 GD（MBGD）** | 一小撮（32/64…） | 又快又稳，**今天训练神经网络的标准做法** |

更新式不变，只是梯度用一小批估计： $\theta_k=\theta_{k-1}-\alpha\,\frac{\partial L}{\partial\theta}\big|_{k-1}$。

**TSK 先建立直觉**（深入留到 RBF 网络后回补）：Mamdani 型模糊规则后件是模糊集（「THEN u is 正大」，需解模糊）；**TSK 把后件换成一个具体函数**（「THEN $u=3e+0.5$」），一算就出数值，不用解模糊，且**对后件参数可微 → 能用梯度下降/MBGD 训练**。所以 TSK 是「长得像模糊系统、却能像神经网络一样被数据训练」的桥。它最精彩的「TSK≈RBF 网络」要等讲完 RBF 网络再回头看才有「啊哈」感。

### 3. 神经元与激活函数：神经网络这个 $f$ 怎么搭出来

神经网络 = 用「神经元」这种小积木堆成千上万个。**生物神经元**：树突收信号→细胞体汇总→超过阈值就「激活/放电」，否则沉默（只有激活/不激活两态）。

**人工神经元 = 两步**：

1. **加权求和**： $z=w_1x_1+w_2x_2+\cdots+w_nx_n+b$（ $w_i$ = 输入重要性， $b$ = 可调激活门槛）。
2. **过激活函数**： $y=\sigma(z)$。

例： $x=(2,4)$、 $w=(0.5,-0.3)$、 $b=0.1$ → $z=0.5\cdot2-0.3\cdot4+0.1=-0.1$ → $y=\sigma(-0.1)\approx0.475$。神经网络要学的旋钮 $\theta$ 就是所有神经元的 $w,b$。

**为什么必须有激活函数**：没有它，每个神经元只是线性变换，**线性套线性还是线性**，堆 100 层等价于 1 层，连异或都学不会。激活函数的唯一使命是**注入非线性**，让「多层堆叠」真正能逼近复杂弯曲函数。

三个常用激活函数：

- **Sigmoid/Logistic**： $\sigma(z)=\dfrac{1}{1+e^{-z}}$，压进 $(0,1)$，软开关。
- **Tanh**： $\tanh(z)=\dfrac{e^z-e^{-z}}{e^z+e^{-z}}$，压进 $(-1,1)$，以 0 为中心。
- **ReLU**： $\text{ReLU}(z)=\max(0,z)$，负的归零、正的放行，现在的默认选择。

**为什么从 Sigmoid/Tanh 改投 ReLU——梯度消失**：Sigmoid 在输入离 0 很远处曲线几乎水平、**导数趋近 0**。反向传播是一连串导数相乘，每层都乘一个趋近 0 的小导数，串起来很快衰减到 0，前面的层**收不到学习信号、训练停滞**。ReLU 在 $z>0$ 时导数恒为 1，连乘不缩水，梯度能传到很深——故深层网络默认用 ReLU。

### 4. 前馈神经网络与通用近似定理

**前馈神经网络(Feedforward NN)**：信号只朝一个方向走——输入层→输出层，不回头、不成环（有向无环图）。分层：

- **输入层**：接收原始输入 $x$，不计算，只递数据。
- **隐藏层**：一层或多层（「深度」的「深」=层数多），每个神经元做「加权和+激活」。
- **输出层**：吐最终结果 $y$。

同层神经元互不相连，相邻层通常全连接。整个网络 = **一串「加权和+激活」的嵌套复合函数**（5 层为例）：

$$y=f_5\big(f_4\big(f_3\big(f_2\big(f_1(x)\big)\big)\big)\big)$$

**通用近似定理(Universal Approximation Theorem)**：一个**线性输出层 + 至少一层带激活函数的隐藏层**的前馈网络，只要**隐藏层神经元够多**，就能以**任意精度**逼近定义在有界闭集上的**任意连续函数**。大白话：**单隐藏层网络只要神经元够多，就能模拟几乎任何函数**。

意义：它给「机器学习=找映射 $f$」发了**可行性证明**——不管目标 $f$ 多古怪，理论上都存在网络能逼近它。这就是神经网络叫「万能逼近器」的底气，也和第 2 节「1992 L.X.Wang 证明模糊系统是万能逼近器」**两边对上**——模糊系统与神经网络本质相通，这是「TSK≈RBF」「神经模糊」成立的根本。

**两个澄清**（防误解）：

1. **「存在」≠「找得到」**：定理只保证有那么个好网络，没说要多少神经元、权重取多少、怎么训练。「存在好网络」和「能学到它」是两码事，后者是优化问题（靠反向传播+梯度下降），常很难。
2. **「单层够用」≠「单层最好」**：单隐藏层可能需要多到不现实的神经元；**做深**（多隐藏层）往往用少得多的神经元达到同样效果——先学简单特征再拼复杂特征（边缘→轮廓→猫脸），更省更高效，这是用深度学习而非「单层胖网络」的原因。

### 5. 反向传播：神经网络怎么「学」出来

**反向传播(Backpropagation, BP)**，Rumelhart/Hinton/Williams 1986（第 1 节时间线里那个「深度学习里程碑」）。

**问题**：梯度下降要拧某个权重 $w$，就得知道它的梯度 $\frac{\partial L}{\partial w}$（「动这个权重一点点，最终损失变多少」）。难在网络层层嵌套，要调的权重可能埋在第一层，它对末端损失的影响「拐了好几道弯」。

**工具：链式求导法则**。网络是大复合函数，链式法则把「跨层总账」拆成「一串局部导数连乘」。直觉=**齿轮传动比相乘**：齿轮 1→2 传动比 $a$、2→3 传动比 $b$，则 1 对 3 的总影响 $=a\times b$。课件例子把 $f(x;w,b)$ 拆成 $h_1\to\cdots\to h_6$：

$$\frac{\partial f}{\partial w}=\frac{\partial f}{\partial h_6}\cdot\frac{\partial h_6}{\partial h_5}\cdot\frac{\partial h_5}{\partial h_4}\cdot\frac{\partial h_4}{\partial h_3}\cdot\frac{\partial h_3}{\partial h_2}\cdot\frac{\partial h_2}{\partial h_1}\cdot\frac{\partial h_1}{\partial w}$$

每项是相邻两步的局部导数，单独都好算；难算的总账=一串好算的小账连乘。

**两趟走**：

- **前向传播(Forward)**：输入 $x$ 一层层「加权和→激活」算到底得预测 $\hat y$，与真值 $y$ 比，算损失 $L$（从前往后）。
- **反向传播(Backward)**：上面连乘式从末端 $\frac{\partial f}{\partial h_6}$ 起一项项往前乘，所以**从输出层损失出发，把误差信号沿网络往回一层层倒推**：先算输出层梯度→把误差信号传前一层→前一层乘自己那环局部导数得自己的梯度→继续前传……传回输入层。「误差从后往前倒推」就是「反向」的由来。精妙在**复用后层已算结果、一趟回传算完全网络梯度**。

**循环**：前向算损失 → 反向算梯度 → 梯度下降更新权重，重复成千上万次（每次喂一个 mini-batch=MBGD），损失越降越低。

**接回梯度消失**：反向传播是一串局部导数连乘，用 Sigmoid 则每环贡献趋近 0 的小导数，连乘几层梯度消失、前层学不动；ReLU 正区间导数恒为 1，连乘不衰减。**梯度消失=反向传播的连乘链断在半路**。

### 6. 神经网络控制结构（第四讲重点，常考）

**顶层二分**：

- **神经控制(Neural Control)**：神经网络为主体，独立构成智能控制系统（网络就是控制器）。
- **混合神经网络控制(Hybrid)**：神经网络不单干，用其学习/优化能力改善传统控制器，或与模糊/专家系统结合。

注意：监督控制、直接逆控制、自适应（自校正/模型参考）、预测控制、自适应评判**都属于神经控制**；「混合控制」特指 NN 与模糊/专家系统**跨范式联姻**（≠监督控制里被取代的传统 PID）。

**① 监督控制**：NNC 在传统控制器旁并联，**学习传统控制器的输出**（拿它当标准答案做监督学习）。学成后 NNC 挑大梁、反馈控制器输出趋于零，但传统控制器留作**保底**（遇未学过的干扰立即兜底）。直觉：老司机带新手。本质=用传统控制器输出当监督信号。

**② 直接逆动态控制**：对象是映射 $y=G(u)$，**逆模型** $G^{-1}$ 即「给期望输出倒推该给的 $u$」。训练网络学 $G^{-1}$ 串在对象前，期望 $y_d$→网络算 $u$→对象产生 $y_d$， $G^{-1}$ 接 $G$ 正反抵消，**传递函数≈1**。直觉：英译中接中译英。软肋：**无反馈、鲁棒性差**，需加在线学习补救。

**③ 自适应控制**（对象会变，控制器实时跟着调）：

- **(a) 自校正(Self-Tuning)**：对象 $y(k+1)=f(y)+g(y)u(k)$，想要输出 $=r(k+1)$ 就把它当方程解出控制量（**确定性等价原则**）： $u(k)=\dfrac{r(k+1)-f(y)}{g(y)}$。 $f,g$ 未知时用神经网络在线辨识出 $N_f,N_g$ 代入： $u(k)=\dfrac{r(k+1)-N_f}{N_g}$。直觉：先学出对象参数，再解方程倒推 $u$。
- **(b) 模型参考(MRAC)**：先设一个**参考模型**（理想数学模型，规定「最理想响应曲线」=标准示范动作）；定义误差 $e_c=y_m-y$，NNC 实时调参把 $e_c$ 压到最小，强迫真实对象模仿理想榜样。分**直接**（NNC 直接按 $e_c$ 调）和**间接**（先用辨识器 NNI 学对象、再指导 NNC）。与监督控制区别：监督的标准答案是「另一个控制器的输出」，MRAC 的标准答案是「一条理想响应曲线」。

**④ 预测控制**（呼应第 0 节「工业界最看好 MPC」），三特征：**预测模型**（神经网络预测未来对象走向）、**滚动优化**（向前看一段、算最优控制、只执行第一步、下一时刻重新看重新优化）、**反馈校正**（用实测纠正预测偏差）。直觉：开车看前方一段规划，但只开几米再按新路况重规划。

**⑤ 自适应评判控制**（强化学习前身）：两网络分工——**评价网络(Critic，评委)** 按状态和外部再励信号 $r(t)$ 经奖惩学习，产生内部再励信号 $\hat r(t)$ 给控制效果打分；**控制选择网络(Actor，运动员)** 在 $\hat r(t)$ 指导下从允许动作集选下一步动作。直觉：运动员做动作、教练打分、按分调整。本质不同：前面结构都需「标准答案」，这里**没有标准答案、只有好坏评分，靠试错学策略**=强化学习核心。

**⑥ 混合控制**：神经网络 + 模糊→**模糊神经网络**（用网络学习能力自动获取/修正模糊规则与隶属函数，落地第 2 节「神经模糊」伏笔）；神经网络 + 专家系统→**神经网络专家系统**。目的：同时具备学习+推理+决策（会学 + 会讲道理）。

**收口对照表**：

| 结构 | 网络角色 | 直觉 | 归类 |
| --- | --- | --- | --- |
| 监督控制 | 偷师传统控制器 | 老司机带新手，学成取代、留保底 | 神经控制 |
| 直接逆控制 | 对象逆模型 $G^{-1}$ | 英译中接中译英，正反抵消 | 神经控制 |
| 自适应·自校正 | 辨识未知参数 $f,g$ | 学出参数再解方程倒推 $u$ | 神经控制 |
| 自适应·模型参考 | 逼对象模仿理想榜样 | 照标准示范曲线练、压小 $e_c$ | 神经控制 |
| 预测控制 | 预测未来的模型 | 看一段路、只走一步、滚动重规划 | 神经控制 |
| 自适应评判 | 评委+运动员 | 没标准答案、靠奖惩试错（→RL） | 神经控制 |
| 混合控制 | 与模糊/专家系统联姻 | 会学 + 会讲道理 | 混合控制 |

### 7. RBF 网络控制

**RBF = Radial Basis Function（径向基函数）**，控制领域最常用的神经网络。固定**三层**：输入→隐藏→输出，特别处在隐藏层用**高斯函数**当激活函数。

「径向基」拆名：**径向(Radial)**=只看距离——每个隐藏神经元揣一个**中心** $C_j$，输入 $r$ 进来只关心「离我中心多远」 $\|r-C_j\|$，方向无所谓；**基(Basis)**=构成函数的基本积木。

第 $j$ 个隐藏神经元（高斯）：

$$h_j=\exp\!\left(-\frac{\|r-C_j\|^2}{2b_j^2}\right)$$

行为=「以 $C_j$ 为圆心的钟形山包」：输入正好在中心→距离 0→ $h_j=1$（最强）；离中心越远→ $h_j\to0$（越弱）；**基宽** $b_j$ 控制山包胖瘦（大=宽广、小=尖锐）。直觉：每个隐藏神经元是「片区探测器」，只盯输入空间里以 $C_j$ 为中心的一小片。

输出层线性加权求和（无激活）： $u=\sum_{j=1}^{m}w_j h_j$。

**控制领域偏爱 RBF 的三理由**：① **局部响应→学得快、不互扰**（每个高斯只管一片，调一处不乱全局；Sigmoid 是全局响应），适合**在线实时**控制；② 结构简单单隐藏层，但仍是**万能逼近器**；③ 数学性质好，**便于稳定性分析**。

**控制器设计 + 权值更新**：网络输入误差相关量 $r(k)$，输出控制量 $u(k)=\sum_j w_j h_j$。权重靠**梯度下降**——先定性能指标 $E(k)=\frac12 e(k)^2$（平方不分正负、求导方便， $\frac12$ 约掉平方的 2），再更新：

$$w_j(k)=w_j(k-1)+\Delta w_j(k),\qquad \Delta w_j(k)=-\eta\frac{\partial E(k)}{\partial w_j}+\alpha\big(w_j(k-1)-w_j(k-2)\big)$$

$\eta$=学习率， $\alpha$=**动量因子**（让本步参考上步方向，带惯性、加速收敛减震荡）。本质和 3.4 反向传播同一回事（定损失→求梯度→更新），只是 RBF 单层梯度好算。进阶版连中心 $C_j$、基宽 $b_j$ 也一起在线梯度下降调（模型参考自适应）。

**Jacobian 信息** $\frac{\partial y}{\partial u}$=「对象输出对控制输入的敏感度」，算控制器梯度时需要，可由另一神经网络辨识；**精度要求不高**，不准部分靠权值调整修正。

**实例（横向自适应控制，p45-49）**：自动驾驶横向控制（方向盘转角跟踪参考轨迹），面临轮胎侧偏强非线性、参数时变（载重/重心/车速）、外部干扰（路面附着突变/侧风），传统线性控制器易模型失配。引入 RBF 做模型参考自适应：参考模型=理想车辆动力学，NNC=RBF 网络输出补偿转角，在线逼近未知车辆动态。横向系统用滑模控制 + RBF 估计未知项 $f(x)$，自适应律由 Lyapunov 函数推出，仿真位置指令 $x_d=\sin t$ 跟踪良好。

**实例谱系**：ALVINN（早期神经网络车辆控制，感知直接生成转向）→ DAVE-2（CNN 端到端，前视图像直接映射方向盘转角）→ RBF 极限工况横向稳定控制 → RBFNN-PID（转向执行层非线性补偿，作为传统控制器的增强模块嵌入底层回路）。

### 8. 回补：TSK 模糊系统 ≈ RBF 网络（第 2 节欠讲的回补）

第 2 节只建立了 TSK 直觉，这里在讲完 RBF 后正式证明「TSK≈RBF」，兑现回补。

**TSK 怎么算输出**（零阶，后件取常数）：规则 $j$「IF $x_1$ is $F_{j,1}$ AND $x_2$ is $F_{j,2}$ THEN $y_j$=常数」。两步：① 算点火强度 $f_j(x)$（输入多符合前件，隶属度相乘/取小）；② 按点火强度加权平均： $y(x)=\dfrac{\sum_j f_j(x)y_j}{\sum_j f_j(x)}$。

**关键一步——前件隶属函数选高斯**：则点火强度（两高斯相乘=指数相加）

$$f_j(x)=\exp\!\Big(-\frac{(x_1-m_{j,1})^2}{\sigma_j^2}\Big)\exp\!\Big(-\frac{(x_2-m_{j,2})^2}{\sigma_j^2}\Big)=\exp\!\Big(-\frac{(x_1-m_{j,1})^2+(x_2-m_{j,2})^2}{\sigma_j^2}\Big)$$

这正是 RBF 隐藏层那个「以 $(m_{j,1},m_{j,2})$ 为中心的钟形片区探测器」 $h_j$。两套输出公式并排：TSK $y=\frac{\sum_j f_j y_j}{\sum_j f_j}$ vs 归一化 RBF $y=\frac{\sum_j h_j w_j}{\sum_j h_j}$——**完全一样**。

**五条对应**（Jang & Sun 1993，「一定条件下 FS=RBFN」）：

| TSK 模糊系统 | RBF 网络 |
| --- | --- |
| 模糊规则条数 | 隐藏层神经元（感受野单元）个数 |
| 前件用**高斯**隶属函数 | 隐藏层用**高斯**激活 |
| 前件多条件用 **t-范数**（相乘/取小） | 高斯多维相乘 |
| 规则后件取**常数** | 输出层权重 $w_j$ |
| 按点火强度**加权平均** | 隐藏层响应**加权求和** |

**三层深意**：① 两个「万能逼近器」本质是一个——都是「用一堆局部钟形基函数分片拼出任意曲面」，模糊规则中心=RBF 探测器中心，呼应第 2 节「1992 模糊万能逼近」与 3.3「神经网络万能逼近」殊途同归；② **神经模糊(Neuro-Fuzzy)/ANFIS** 的价值：当模糊系统看=每个高斯是一条可读 IF-THEN 规则（白盒可解释），当 RBF 看=用梯度下降/反向传播自动训练中心/基宽/权重——**规则不用人写、数据训出来，还能翻译回人读的规则**，解决第 1 节「知识获取困境」；③ 回扣第 2 节「TSK=RBFN/MLP/MoE/CART/Stacking」表，RBFN 这条已逐行推完，其余同理，故那些模型的训练技巧（梯度下降/DropRule/归一化/聚类初始化）能搬来优化模糊系统。

### 9. RNN 循环神经网络：给网络装上「记忆」

**为什么需要**：前馈/RBF 网络假设「每次输入独立、输出只看当前输入」。但**序列问题**（文本、语音、音频、视频、物理过程——任何嵌在时间里的东西）前后有依赖、顺序有意义（「我不喜欢」vs「我喜欢」；轨迹下一秒依赖前几秒）。前馈网络两硬伤：① 输入输出维度固定，处理不了变长序列；② 没记忆，处理后面时忘了前面。

**猜晚饭例子**：晚饭在披萨/寿司/华夫饼轮换，用 **one-hot 向量**表示（披萨=(1,0,0)、寿司=(0,1,0)、华夫饼=(0,0,1)）。要预测今天必须知道昨天——**输出=f(当前输入, 上一步信息)**，这是序列模型雏形。

**RNN 核心结构**：加一条自反馈回路，把「这一刻的内部状态」留给「下一刻」用。这个不断后传的内部状态叫**隐藏状态** $h_t$（=记忆）。每个时间步：

$$h_t=\tanh\big(W_x x_t+W_h h_{t-1}+b\big)$$

大白话：这一刻记忆 = 当前输入 $x_t$ 和上一刻记忆 $h_{t-1}$ 混合后过 tanh 压一下。tanh 把值压进 $(-1,1)$ 防爆炸。 $h_{t-1}$ 里又揉着前天的记忆……故 $h_t$ 层层藏着从开头到现在的历史。

**两个关键概念**：① **时间展开(unrolling)**——把自环拉直，每个时间步画一个网络副本，看起来像「深度方向是时间」的深前馈网；② **参数共享**——所有时间步用**同一套权重** $W_x,W_h$，好处是能处理任意长度序列（参数量不变）+ 规律平移不变（「不」字在哪都用同一套权重理解），与 CNN 卷积核扫全图同理。

**致命伤——长程依赖 + 梯度消失/爆炸**：写儿童书例子（词典 {Doug,Jane,Spot,saw,.}，生成「Doug saw Jane. Jane saw Spot. Spot saw Doug.」），第三句主语依赖跨好多词，RNN 常栽在长距离依赖上（写出「Doug saw Doug.」）。根子：反向传播沿时间一路连乘，链很长——每环<1→连乘趋 0→**梯度消失**（早期步学不到，记不住长程，最常见）；每环>1→**梯度爆炸**（发散）。一句话：RNN 有记忆但记性短。

**输入输出形态**：多对一（情感分析）、一对多（看图说话）、多对多（机器翻译「你好吗」→「How are you」）。应用：文本生成、机器翻译、金融预测、**轨迹预测**（最贴控制）。

### 10. LSTM：给记忆装上「门」

**核心思路**：RNN 只有一条记忆通道 $h_t$，每步把新信息一股脑混入再整体压扁，旧信息被冲刷。**LSTM(Long Short-Term Memory, Hochreiter & Schmidhuber 1997)**：开一条「传送带」式**长期记忆**通道 $C_t$ 让信息原样流过多步不被冲刷，再用**三道闸门**精确控制忘/记/说。同时维护长期记忆 $C_t$ 和短期记忆（隐藏状态） $h_t$。

**门(gate)零件**：逐元素相乘 + Sigmoid。Sigmoid 把数压进 (0,1)：**0=闸门全关，1=全开**。一道门 = Sigmoid 算出 0~1 开合度向量，逐元素乘到信息流上，实现「有选择地让信息通过」。三道门管「忘、记、说」，都看 $[h_{t-1},x_t]$ 做决定。

- **① 遗忘门 $f_t$**（长期记忆里哪些擦掉）： $f_t=\sigma(W_f\cdot[h_{t-1},x_t]+b_f)$，逐元素乘到旧记忆 $C_{t-1}$。例：写完「Jane saw Spot.」句号一出，该清掉上句主语 Jane、宾语 Spot。
- **② 输入门 $i_t$**（新信息里哪些值得存）：先 tanh 生成候选新记忆 $\tilde C_t$，再 Sigmoid 门 $i_t$ 决定写多少。 $i_t=\sigma(W_i\cdot[h_{t-1},x_t]+b_i)$， $\tilde C_t=\tanh(W_C\cdot[h_{t-1},x_t]+b_C)$。例：新句「Spot saw...」开始，把「主语是 Spot」写进记忆。
- **③ 状态更新（心脏）**： $C_t=f_t\odot C_{t-1}+i_t\odot\tilde C_t$（先擦该忘的、再写该记的）。**打败梯度消失的关键**：旧记忆 $C_{t-1}$ 是被**加**进来（非反复乘权重压扁），遗忘门开着时几乎原样加过来，信息沿传送带畅通流过多步，梯度顺这条「加法高速路」回传不衰减。
- **④ 输出门 $o_t$**（这步对外说什么）： $o_t=\sigma(W_o\cdot[h_{t-1},x_t]+b_o)$， $h_t=o_t\odot\tanh(C_t)$。 $C_t$ 是「内心」，输出门筛出对外的 $h_t$，既是预测又传给下一时刻。

口诀：**遗忘门忘旧、输入门记新、输出门说话**； $C_t$ 传送带用加法保住长期记忆。**GRU(Gated Recurrent Unit)**=LSTM 简化版，三门精简为两门（合并遗忘门和输入门），参数少训练快、效果常相当。

### 11. Transformer：抛弃循环，改用注意力

**动机**：LSTM 解决了长程记忆，但和 RNN 共享缺陷——必须**按时间一步步算**（ $h_t$ 依赖 $h_{t-1}$），① 没法并行、序列长则训练极慢（浪费 GPU 并行）；② 超长依赖仍会衰减。**Transformer(2017)** 釜底抽薪：不要循环，让每个词「一步到位」直接看到所有其他词，用**注意力**决定重点看谁。无递推链→所有词并行计算，任意两词「直连」（距离=1 步），长程依赖迎刃而解。

顺课件小标题搭建：

**① 词→向量：One-hot → Embedding**。one-hot（每词一超长向量，自己位 1 其余 0）两毛病：太稀疏、任意两词正交算不出语义关系。**Embedding(词嵌入)**：可学习矩阵把 one-hot 压成低维（如 512 维）稠密向量，训练后意思相近的词向量也相近（猫≈狗，远离桌子）=词的数字身份证。

**② 注意力内核：点积算相关度**。点积=两向量逐元素相乘求和，方向越一致越大→**当相关度打分器**：A 该不该关注 B，就拿 A、B 向量点积，分高=该看。

**③ 为什么要「跳跃式」注意力**（first/second order sequence model + skips）：一阶=只看前一个词（马尔可夫/朴素 RNN）；二阶=看前两个（`battery ran down` vs `program ran`，预测 ran 后跟不跟 down 要回看主语）；带跳跃=关键依赖词在很远处（`Check the program/battery log ... whether it ran (down)`，决定 down 的词隔了一长串）。**结论**：该重点看的可能是很远处某个特定词→「跳过无关、精准盯远处关键词」=注意力。

**④ Q/K/V 机制**：对每个词用三个可学习矩阵造三向量——**Query(Q)**「我想关注什么」、**Key(K)**「我能提供什么信息（索引）」、**Value(V)**「我实际携带的内容」。比喻查字典：Q=要查的词条，K=词头索引，V=解释内容。三步（Attention as matrix multiplication + Softmax）：① 打分——当前词 Q 与所有词 K 点积；② 归一化——Softmax 变成和为 1 的**注意力权重**；③ 加权求和——用权重对所有词 V 加权求和得新表示。公式：

$$\text{Attention}(Q,K,V)=\text{Softmax}\!\left(\frac{QK^{\mathsf T}}{\sqrt{d_k}}\right)V$$

$QK^{\mathsf T}$=每词对每词点积打分一次矩阵乘算完（**注意力=矩阵乘法**，GPU 可大规模并行）； $\sqrt{d_k}$ 缩放防 Softmax 饱和；Softmax 归一；乘 V 加权求和。

**⑤ 补两零件**：**Masking(掩码)**——文本生成时预测第 $t$ 词不能偷看 $t$ 及以后（答案），打分后 Softmax 前把未来位置设 $-\infty$ 使权重为 0，保证因果性；**Positional Encoding(位置编码)**——抛弃循环后模型不知词序（「狗咬人」=「人咬狗」），给每词 embedding 加一个编码「第几位」的向量（不同频率正弦/余弦），既并行又不丢顺序。

**⑥ Multi-Head Attention(多头)**：一组 Q/K/V 只能学一种关注模式，但词间关系多维度（语法/语义/局部/全局）。多头=并行多套独立 Q/K/V，各学一种模式，结果拼接融合。比喻委员会同审一句话（语法委员/语义委员/语气委员各看一角度再汇总）。是表达力强的关键。

**⑦ De-embedding 收尾**：多层（多头注意力+前馈）加工后，每位置得浓缩全局信息的向量，用 De-embedding（嵌入逆操作）映射回词表每词分数，Softmax 成概率，挑最高词输出，逐词生成。

**收口呼应**：Transformer 强在并行 + 任意长程直连，但自注意力对序列长度 $O(N^2)$（两两打分），超长吃不消——正是第 2 节 **Mamba/SSM** 的动机，而 Mamba 内核绕回控制论状态空间法 $\dot h=Ah+Bu,\ y=Ch+Du$，闭环已合上。至此第 3 节连接主义讲完：从「神经元怎么算」到「Transformer 用注意力理解序列」，再回扣控制。

## 第 4 节 · 行为主义：迭代学习控制与强化学习

### 0. 行为主义总纲

两个主角：**迭代学习控制(ILC)** 针对重复性任务，用上一轮误差改进这一轮动作（吃一堑长一智）；**强化学习(RL)** 针对一般决策任务，用环境奖励试错出最优策略。引子——巴音布鲁克赛道：赛道在脑中练千万遍成「肌肉记忆」，靠的不是「遇弯才打方向盘」（传统反馈慢半拍）而是「用上一圈失败修正这一圈」（路书+前馈补偿）=ILC 灵魂。

### 1. 迭代学习控制 ILC

**定义**（Uchiyama 1978 提出，Arimoto 1984 开创）：基于经验积累、逐步改进——对每轮执行后数据归纳处理、反馈优化策略，在「执行→学习→调整」重复中提升性能。三特点：① **重复性任务**（相同条件反复执行：焊接/装配/巡逻/高铁固定路段，是前提）；② **逐步改进**（一轮比一轮好）；③ **无需精确模型**（靠执行数据学，与专家/模糊/神经网络控制一脉「免模型」）。

**核心直觉（传统反馈 vs ILC）**：

- 传统 PID = 盘山公路「见招拆招」：偏离车道才纠正，永远**滞后**；每天开同条路、同个急弯还犯同样错（没记忆），几乎不可能零误差。
- ILC = 赛道「刷圈速」：第 1 圈在 3 号弯偏离，第 2 圈开到弯前就**提前多打方向**（记得上圈栽过），把上轮失败转成这轮**前馈补偿**，重复到零误差。

一句话：PID 事后纠错（时间轴 $t$），ILC 事前预判（迭代轴 $k$）。

**「二维时间」视角（最精髓）**：普通控制只有一维时间 $t$（用 $t$ 误差修正 $t+1$ 动作，慢半拍）；ILC 引入第二维**迭代次数 $k$**——用上一圈同一时刻 $t$ 的误差 $e_k(t)$ 直接修正这一圈同一时刻的控制 $u_{k+1}(t)$。**不在 $t$ 轴纠错，在 $k$ 轴纠错**，同一个 $t=2s$ 点一圈比一圈好=真正的前馈预判。

**控制律**：最基础 **D 型**（Arimoto）： $u_{k+1}(t)=u_k(t)+\Gamma\dot e_k(t)$。统一 **PID 型**：

$$u_{k+1}(t)=u_k(t)+\Gamma\dot e_k(t)+\Phi e_k(t)+\Psi\int_0^t e_k(\tau)d\tau$$

只用 $e_k$=P 型、加导数=PD 型（提响应）、加积分=PID 型（消稳态误差）。**易混点必须分清**：普通 P 控制 $u(t)=K_p e(t)$ 用**现在**误差算**现在**控制量（同轮、时间轴反馈）；P 型 ILC $u_{k+1}(t)=u_k(t)+\Gamma e_k(t)$ 用**上一轮**误差加到**这一轮**（跨轮、迭代轴）。**ILC 本质是前馈控制**（把上轮误差当预判前馈到下轮）。按用哪轮误差：用 $e_k$=开环、用 $e_{k+1}$=闭环、都用=开闭环。

**收敛性推导**（线性例 $y=Pu$，误差 $e_k=y_d-Pu_k$，P 型律 $u_{k+1}=u_k+\Gamma e_k$）：

$$e_{k+1}=y_d-Pu_{k+1}=(y_d-Pu_k)-P\Gamma e_k=(I-P\Gamma)e_k$$

误差递推 $e_{k+1}=(I-P\Gamma)e_k$——每轮误差乘因子 $(I-P\Gamma)$，收敛条件：

$$|I-P\Gamma|<1$$

满足则误差像 $0.8^n$ 指数衰减到 0。读出精髓：① 增益 $\Gamma$ 要与对象 $P$ 的逆动态相似（ $\Gamma$ 起 $P^{-1}$ 作用，让 $P\Gamma$ 近 1）；② **不需精确模型**——只要 $\Gamma$ 方向定对、大小合理，误差就被强行压到零，要的是「正确的增益方向和范围」而非精确模型。

**四关键技术**：① 稳定性与收敛性（光稳定不够，必须收敛到真值才最优）；② 初始值问题（收敛证明要求每轮初始状态相同 $x_k(0)=x_d(0)$，否则归为鲁棒性，故实验强调起点一致）；③ 学习速度（收敛条件多在 $k\to\infty$ 给出，实际要更快——高阶迭代/遗忘因子/当前项反馈）；④ 鲁棒性（有界干扰下收敛到期望轨迹邻域，干扰消除后收敛到期望轨迹）。

**仿真实例**（自动驾驶重复过弯）：二阶非线性 $\ddot y_k=f(y_k,\dot y_k)+bu_k(t)+d(t)$， $f$=轮胎侧偏未建模非线性， $d(t)$=**重复性**外扰（坡度/风阻/附着，每圈一样故 ILC 能学会补偿），误差 $e_k(t)=y_d-y_k$。三阶段：第 1 次迭代过弯大超调；第 5 次记录误差曲线提前反向补偿、明显变好；第 30 次轨迹与期望几乎重合、误差近 0。即「刷圈」从生疏到肌肉记忆。

### 2. 强化学习 RL —— 框架与理论

**入门例子（倒立摆/平衡杆）**：杆铰接在小车上，左右推车让杆别倒。没人给「每刻推多大力」的标准答案（故不能监督学习），只能试错：立住=好、倒了=坏，摸索出策略。这种「靠好/坏反馈试错学策略」=强化学习。

**基本框架（两角色一循环）**：**智能体(Agent)** 感知状态、做动作、按奖励调策略；**环境(Environment)** 受动作影响改状态、反馈奖励。心跳循环：时刻 $t$ 看状态 $s_t$ →选动作 $a_t$ →环境转移到 $s_{t+1}$ 并给奖励 $r_{t+1}$ →智能体改策略→下一时刻……一句话：**不断与环境交互、按经验调策略、最大化长远累积奖励**（是「长远累积」非「眼前一步」）。

**MDP（马尔可夫决策过程）**——上述循环的数学骨架，要素：状态集 $S$、动作集 $A$、状态转移概率 $p(s'|s,a)$、即时奖励 $R$。**马尔可夫**假设：下一状态只取决于「当前状态+当前动作」，与更早历史无关（无记忆，如下棋只看当前棋盘）。马尔可夫家族定位（常考）：

| 模型 | 能否决策（动作） | 状态是否完全可观测 |
| --- | --- | --- |
| 马尔可夫链 MC | 否（纯随机演化） | 完全可观测 |
| 隐马尔可夫 HMM | 否（无决策） | 部分可观测 |
| 马尔可夫决策过程 MDP | **是** | 完全可观测 |
| POMDP | 是 | **部分可观测** |

记忆：有无动作=决策过程(MDP/POMDP) vs 纯过程(MC/HMM)；状态看全否=完全可观测(MC/MDP) vs 部分可观测(HMM/POMDP)。POMDP 最难，第 6 节具身智能用（摄像头只看局部=部分可观测）。

**策略/回报/折扣率**：策略 $\pi(a|s)$=状态 $s$ 下选各动作的概率（终极目标=找最优策略）。**总回报**=一条轨迹累积奖励，但加折扣：

$$G=r_1+\gamma r_2+\gamma^2 r_3+\cdots=\sum_{t=0}^{\infty}\gamma^t r_{t+1}$$

**折扣率** $\gamma\in[0,1]$：① 越远奖励越不确定越不值钱（明天的100不如今天的100）；② 调眼光—— $\gamma\to0$ 目光短浅（短期）， $\gamma\to1$ 重视长远。目标精确化=找 $\pi$ 使期望总回报最大。

**值函数/Q函数/贝尔曼方程**：

- **状态值函数 $V(s)$**：从 $s$ 按 $\pi$ 走的期望总回报（「我现在处境前景如何」）。
- **动作值函数 $Q(s,a)$**（Q=Quality）： $s$ 下先做 $a$ 再按 $\pi$ 走的期望总回报（「这个处境做这个动作前景如何」）。比 V 多「动作」维，更有用——挑 Q 最大的动作即可。
- **贝尔曼方程**（RL 最核心）：**当前状态期望回报 = 即时奖励 + 折扣后的下一状态期望回报**， $V(s)=\mathbb E[r+\gamma V(s')]$。重要性：把「算到天荒地老的无穷累积」变成「只关联当前与下一步」的递推（像数学归纳法，让相邻状态值自洽即可解出整张价值地图）。几乎所有 RL 算法本质都是反复用贝尔曼方程更新值函数到收敛。

**探索 vs 利用（核心矛盾）**：**利用(Exploitation)** 选已知最优动作（稳但可能错过更好）；**探索(Exploration)** 试没试过的动作（可能发现更优也可能受罚）。类比常去餐馆 vs 试新店。只利用→困在局部最优；只探索→学不到稳定策略。好算法须权衡，是 RL 标志性难题。

### 3. 强化学习的算法：从 Q-Learning 到 PPO/SAC

**大分类**：**无模型(Model-free)** 不建环境模型、纯交互试错（简单但费交互）；**有模型(Model-based)** 先学环境模型再规划（省交互但建准模型难）。无模型再分两主干：**基于值(Value-based)** 只学值函数、策略硬贪心 $\pi=\arg\max_a Q$、无独立策略网络（Q-Learning、DQN）；**基于策略(Policy-based)** 直接学策略（输出动作概率）（REINFORCE、策略梯度）。

**Q-Learning（基于值、无模型）——走房间例子**：5 房间+屋外(5)，抽象成图（房间=状态节点，门=动作边），目标从任意房间到屋外。奖励：直通目标的边=100、其他=0、不通=-1，状态 5 自环=100（**吸收目标**：到了就待着）。**Q 表**（行状态列动作，存 $Q(s,a)$）初始全 0，靠探索填。更新公式（贝尔曼实操版）：

$$Q(s,a)\leftarrow R(s,a)+\gamma\max_{a'}Q(s',a')$$

读法：在 $s$ 做 $a$ 的价值 = 即时奖励 $R(s,a)$ + 折扣 $\gamma$×新状态 $s'$ 最优动作价值。 $\max_{a'}Q(s',a')$ 是精髓（假设到下一状态后走最优路，把未来最优价值回传）。例（ $\gamma=0.8$）：状态 1 随机去 5， $Q(1,5)=R(1,5)+0.8\max Q(5,\cdot)=100+0.8\times0=100$，到目标则本 **episode(回合)** 结束、换起点重来。多个 episode 后 Q 表收敛，每步挑 Q 最大即最优路径。精髓：没人教最优路线，靠「反复试+奖励回传」自填价值地图， $\gamma$ 让价值像水波从目标倒扩散全图。

**DQN(深度Q网络, Mnih 2015)**：Q-Learning 死穴是用表存所有 $Q(s,a)$，现实状态（如像素）天文数字列不成表。DQN 用**神经网络代替 Q 表**（输入状态、输出各动作 Q 值，神经网络=万能逼近器）。首次 CNN+Q-Learning，从原始像素端到端到动作，Atari 夺冠，**标志深度 RL 主流化**。技巧**双网络**：**eval net** 每步更新算当前 Q；**target net** 每 $C$ 步才复制 eval net 参数、算目标值。原因：同一网络边算目标边更新=「追自己影子」会震荡发散，target net 滞后更新当稳定靶子。

**算法谱系（常以比较考）**——先懂 **Actor-Critic**：**Actor(演员)**=策略网络输出动作；**Critic(评论家)**=值函数网络给动作打分；**优势函数 $A(s,a)=Q(s,a)-V(s)$**（这动作比平均好多少，代替原始回报更新策略，**降梯度方差、训练更稳**）。Actor 主干学策略、Critic 辅助打分。

| 算法 | 动作空间 | 核心 | 定位 |
| --- | --- | --- | --- |
| A2C | 离散/连续 | 优势 AC **同步版**，多环境并行采样全采完统一更新 | 稳定基础版 |
| A3C | 离散/连续 | A2C **异步版**，多 worker 各自采样随时异步上传梯度 | 训练快、利用率高 |
| PPO | 离散/连续 | 加**裁剪 Clip** 限制新旧策略更新幅度 | **工业界万能基线**，ChatGPT RLHF 首选 |
| SAC | 连续 | **最大熵** RL，奖励+策略随机性(熵)→探索强鲁棒 | 连续控制(机械臂/无人机)天花板 |
| TD-MPC | 连续 | **有模型**，学隐变量世界模型+短期规划+长期价值 | 样本效率碾压无模型，科研前沿 |

记忆主线：AC→A2C→A3C→TRPO→**PPO**（离散连续通吃、最稳最通用、大模型训练首选）；DDPG→TD3→**SAC**（连续、最大熵、机器人控制专用）；传统 MPC+无模型价值→**TD-MPC**（模型基规划+学习融合、少数据）。**PPO=训练 ChatGPT 的 RLHF 算法**；SAC「最大熵」呼应探索 vs 利用。

**强化学习迭代控制（接最优控制）**：非线性系统 $\dot x=f(x)+g(x)u$，最优控制找 $u^*(x)$ 使性能函数 $V$（状态代价+控制代价累积）最小，变分法推出 **HJB(哈密顿-雅可比-贝尔曼)方程**=连续版贝尔曼方程，但是非线性偏微分方程**无解析解**。RL 提供「策略迭代」数值解法、无需精确模型逼近求解 HJB（策略评估↔策略改进反复到收敛）。即 **RL 本质=数据驱动求解最优控制**，再证智能方法与控制论相通。

**经典应用脉络**：① 倒立摆(1983, Barto/Sutton/Anderson)——RL 控制奠基，首次「以奖励学控制律」，动力学未知也能学会平衡（二人获 **2024 图灵奖**）；② DQN(2015)——深度 RL 主流化标志；③ AlphaGo(2016, Silver)——策略网络+价值网络+蒙特卡洛树搜索+自我博弈，标志 RL 从「学单一策略」到「表示学习+价值评估+规划搜索」综合决策；④ Roach(2021)——RL 专家(PPO 训练、可从零学)当「教练」监督端到端城市自动驾驶，迁移决策知识给单目摄像头学生模型，缓解模仿学习分布偏移。

### 4. 第 4 节收口：ILC vs RL 对照

| 维度 | 迭代学习控制 ILC | 强化学习 RL |
| --- | --- | --- |
| 适用任务 | **重复性**任务（同轨迹刷圈） | **一般决策**任务（状态多变） |
| 学习信号 | 上一轮**误差** $e_k(t)$ | 环境**奖励** $r$ |
| 学习维度 | 迭代轴 $k$（跨轮前馈） | 时间轴状态-动作序列 |
| 目标 | 零误差跟踪期望轨迹 | 最大化长远累积奖励 |
| 直觉 | 吃一堑长一智（刷圈速） | 试错+奖惩（学骑车） |
| 模型依赖 | 免精确模型（要 $\Gamma$ 方向对） | 无模型/有模型两支 |

一句话：**行为主义把「学习」从『有人教』推进到『自己试』——ILC 在重复中逼近完美，RL 在试错中逼近最优；两者都与最优控制相通，是通往具身智能的最后一块方法论拼图。**

## 第 5 节 · 感知基础：光流

### 1. 光流是什么

**定义**：光流是空间运动物体在观察成像平面上**像素运动的瞬时速度**。即描述「每个像素从当前帧到下一帧朝哪、移多快」的速度场。二维平面任一点光流为矢量 $(u,v)$（**光流矢量**）： $u$=水平速度分量、 $v$=垂直速度分量。直觉：坐车看窗外，近树飞掠、远山缓移，每点掠过的方向速度即光流。

按算多少点分两类：**稀疏光流**（只挑少数特征明显点算并跟踪，省算力，代表 LK 法）；**稠密光流**（算每个像素，映射 HSV 颜色空间可视化——颜色=方向、深浅=速度，信息全但费算力，代表 Farneback 法）。

### 2. 两条基本假设 + 核心约束方程

光流从两帧反推每像素速度，须立两假设：① **亮度恒定**——同一物体点相邻帧亮度基本不变；② **时间持续性（小运动）**——时间变化短、像素位置不剧烈跳变。

**推导核心约束**： $t$ 时刻 $(x,y)$ 像素亮度 $I(x,y,t)$， $t+dt$ 挪到 $(x+dx,y+dy)$。由假设一亮度相等： $I(x,y,t)=I(x+dx,y+dy,t+dt)$。由假设二小运动，右边泰勒展开留一阶：

$$I(x+dx,y+dy,t+dt)\approx I(x,y,t)+\frac{\partial I}{\partial x}dx+\frac{\partial I}{\partial y}dy+\frac{\partial I}{\partial t}dt$$

代回消去 $I(x,y,t)$、除以 $dt$，记 $u=\frac{dx}{dt}$、 $v=\frac{dy}{dt}$、 $I_x=\frac{\partial I}{\partial x}$、 $I_y=\frac{\partial I}{\partial y}$、 $I_t=\frac{\partial I}{\partial t}$，得**光流基本约束方程**：

$$I_x u+I_y v+I_t=0$$

致命问题： $I_x,I_y,I_t$ 可由图像算出，但**一个方程两个未知数 $u,v$，无法唯一求解**（=孔径问题）。三代算法的本质区别就是**各自补上这个缺失的约束**。

### 3. 第一代：Lucas-Kanade 法（传统稀疏）

LK 法（1981, Bruce Lucas & Takeo Kanade 金出武雄），最经典**稀疏**光流。补约束办法=**空间一致性假设**：像素点周围 $n\times n$ 邻域内所有像素光流值相同。**怎么破困境**：单像素 1 方程 2 未知数（欠定）；假设窗口 $n\times n$ 像素共享同一 $(u,v)$，则有 $n\times n$ 个方程、仍只 2 未知数，从欠定变**超定**，用最小二乘解。矩阵形式 $Ax=b$（ $A$=各点梯度 $[I_x,I_y]$ 堆叠， $x=[u,v]^{\mathsf T}$， $b$=各点 $-I_t$）：

$$x=(A^{\mathsf T}A)^{-1}A^{\mathsf T}b$$

只要 $A^{\mathsf T}A$ 可逆即可解。**孔径问题(Aperture Problem)**： $A^{\mathsf T}A$ 不可逆时多解。直觉=从小圆孔看移动斜条纹，「垂直移」和「斜移」看起来一样、分不清真实方向——无特征/单一边缘区域，沿边缘方向的分量测不出。原因：窗口只有一条直边时所有像素梯度方向相同、 $A^{\mathsf T}A$ 退化。**解法**：挑**角点**（两个方向边缘、梯度丰富、 $A^{\mathsf T}A$ 必可逆），配角点检测算法选点——这正是它「稀疏」的原因。（金出武雄名言：「像外行一样思考，像专家一样实践」。）

### 4. 第二代：Farneback 法（传统稠密）

Farneback 法（2003, Gunner Farneback），经典**稠密**光流。思路=**用二次多项式拟合局部图像**：每像素邻域灰度近似为

$$f(x,y)\approx r_1+r_2 x+r_3 y+r_4 x^2+r_5 y^2+r_6 xy=\mathbf X^{\mathsf T}A\mathbf X+b^{\mathsf T}\mathbf X+c$$

$A$ 对称矩阵、 $b$ 向量、 $c$ 标量，系数由加权最小二乘拟合邻域得到（把局部明暗近似成光滑二次曲面）。用「同一像素相邻帧外观不变」：设位移 $d$，则 $f_2(\mathbf X)=f_1(\mathbf X-d)$，两帧多项式系数对应相等，推出光流：

$$d=-\tfrac{1}{2}A^{-1}(b_2-b_1)$$

直觉：两帧各拟合一个二次曲面，比较系数差异（尤其一次项 $b$ 变化）反推位移；对每像素都算得稠密光流。

### 5. 第三代：FlowNet（深度学习）

前两代是手工设计（人工推假设列方程）。深度学习思路=让 CNN 从数据自己学「两帧→光流」映射（连接主义思想）。**FlowNet**=第一个用 CNN 预测光流的工作，两结构：**FlowNetSimple**（两帧直接叠一起输入网络）；**FlowNetCorr**（先各自卷积提特征、再用相关操作合并匹配）。

关键结构**收缩+扩张**：前期用**池化**聚合大区域信息（看得广）但分辨率降低（变糊）；后期用**扩张路径(refinement)** 恢复分辨率，把扩张特征图与前期高分辨率低层特征图融合——既保留粗糙图的高层语义、又找回低层的局部细节；重复 refine 四次，最后双线性上采样恢复原始大小。**FlowNet2**=优化版，由 FlowNetC/FlowNetS/FlowNet-SD 子网络堆叠应对不同物体运动，针对小位移改进（减小卷积核/stride 提分辨率、FlowNet-SD 让小位移输出更平滑）。

**工具箱**：OpenCV `cv2.calcOpticalFlowPyrLK()`（LK 稀疏）、`cv2.calcOpticalFlowFarneback()`（Farneback 稠密）；深度学习用 MMFlow。

### 6. 收口

主线：**光流=像素运动瞬时速度 $(u,v)$；地基=两假设（亮度恒定+小运动）推出核心约束 $I_x u+I_y v+I_t=0$，但一方程两未知数解不出（孔径问题）。三代算法各补缺失约束**：LK「邻域光流一致」凑超定方程组最小二乘解（稀疏、靠角点）；Farneback「二次多项式拟合局部图像」比较两帧系数（稠密）；FlowNet 用 CNN 从数据直接学（深度学习，收缩+扩张）。补上 OODA「感知」环，为第 6 节具身智能视觉导航铺路。

## 第 6 节 · 集大成：具身智能与 VLA 模型

### 1. 具身智能再深化：第一人称智能与 POMDP

**第三人称 vs 第一人称智能**：

| | 第三人称智能 | 第一人称智能（具身） |
| --- | --- | --- |
| 核心问题 | 「这是什么」（识别） | 「下一步怎么做」（决策） |
| 典型输入 | 静态图像、标签、语料 | 连续观测、历史状态、目标、约束 |
| 认识「盒子」 | 有人告诉我「这是盒子」 | 亲身体验——可打开、可装东西 |
| 优势/局限 | 语义强数据丰富/缺动作后果 | 考虑身体时间风险反馈 |

**两只猫实验(1963)**：两猫绑同一转盘看同样画面，主动猫能自己走（视觉变化由自己行为引起）、被动猫只被动被带走；结果主动猫学会正常行走、被动猫失去视觉引导行走能力。深意：**智能不是被动接收信息形成的，必须由「身体主动作用于世界」的行为塑造**（过去 5.4 亿年生物智能皆如此）。ChatGPT=典型第三人称（Sutton 批「互动时完全不学习」），具身要第一人称。

**POMDP（部分可观测马尔可夫决策过程）**——具身智能的数学形式。为何「部分可观测」：机器人摄像头只看局部、真实完整状态永远看不全（MDP 看完整状态 $s$，具身只能看观测 $o$，真实 $s$ 藏背后）。七元组 $M=(S,A,O,T,\Omega,R,\gamma)$： $S$ 真实状态（不可完全观测）、 $A$ 动作（离散前进转向/连续位姿力矩）、 $O$ 观测（相机深度触觉关节角语言指令，实际能拿到的）、 $T$ 转移（身体环境耦合动力学）、 $\Omega$ 观测概率函数（连接真实状态与所见）、 $R$ 奖励（成功碰撞能耗效率安全多目标加权）、 $\gamma$ 折扣。目标同 RL： $\max_\pi J(\pi)=\mathbb E_\pi[\sum_t\gamma^t r_t]$。四难点：① 部分可观测（目标可能暂不可见）；② 接触不确定（摩擦形变遮挡延迟放大误差）；③ 长时程依赖（当前动作影响数十步后）；④ 跨 embodiment 泛化（换相机/夹爪/底盘策略还能用吗）。家族定位：有动作+部分可观测=POMDP（最难格）。

**能力栈**（全课方法对号入座）：

| 层 | 干什么 | 对应本课 |
| --- | --- | --- |
| 目标与约束 | 语言指令、成功判据、安全边界 | VLA 的 Language |
| 感知与表征 | RGB-D/触觉/力觉/状态估计/场景图 | 第 5 节光流、视觉编码 |
| 记忆与世界模型 | 时序记忆、对象持久化、地图先验 | 第 3 节 RNN/LSTM/Transformer |
| 规划与推理 | 任务分解、因果判断、长时程搜索 | 符号主义 + LLM |
| 技能与策略 | 导航、抓取、操作、全身运动控制 | 第 4 节 RL/ILC |
| 控制与执行 | 轨迹跟踪、阻抗控制、接触稳定、急停 | 传统控制 + 神经网络控制 |

即**具身智能不是某种新方法，而是把全课方法按层次组装成的系统**，三大主义在此结合。

### 2. 从模块化到端到端：自动驾驶范式变革

**自动驾驶分级 L0-L5**（常考，记分界）：

| 级别 | 名称 | 谁控制 | 责任 |
| --- | --- | --- | --- |
| L0 | 完全人工 | 人全权 | 人 |
| L1 | 辅助驾驶 | 人为主+单一功能辅助(ACC/车道保持) | 人 |
| L2 | 部分自动化 | 人系统共享(同时管加减速+转向,如特斯拉) | 人 |
| L3 | 有条件自动化 | 系统为主人备用(特定条件接管) | 系统/人 |
| L4 | 高度自动化 | 系统完全控制(特定区域,如萝卜快跑) | 系统 |
| L5 | 完全自动化 | 系统完全控制(任何条件) | 系统 |

**分水岭=L2/L3 之间**（人负责 vs 系统负责）。

**传统四段式技术栈**：**感知→预测→规划→控制**（感知=眼睛识别车人；预测=猜他人轨迹；规划=大脑决策路径；控制=转成方向盘油门刹车）。**三致命伤**：① **链式误差传递（错进错出）**——模块串联、前一个微小误判被逐级放大，且模块割裂后面无法修正前面（最关键）；② 过度依赖人工规则（长尾场景穷举不完）；③ 泛化不足（OOD 未见情况易失效）。

**端到端变革**：不要割裂的中间模块，用统一神经网络把原始传感器数据**直接映射到动作**（传统四段→端到端「感知→动作」一步到位）。好处：减少信息损耗、简化架构、更强泛化（大数据训练适应雨雪雾）。是连接主义「端到端学映射」在自动驾驶的落地，通向 VLA 的最后一步。

### 3. VLA：视觉-语言-动作模型

**是什么**：融合视觉、语言、动作的统一智能模型，从感知到决策端到端学习。三词：**Vision** 基础输入（摄像头图像/视频）、**Language** 关键高层输入（解析指令/目标，理解抽象意图）、**Action** 最终输出（转向/加速控制）。核心思想：**用语言指导视觉理解，直接输出动作**——区别于普通端到端（图像→动作），VLA 多了语言高层指导。

**为什么需要 Language**（精髓）：① 提供任务目标（「直行」「左转」，避免无意义探索）；② 提供抽象语义（「前方施工绕行」「小心行人」，超越像素的高阶信息）；③ **支持泛化**（无需重训，靠指令快速适应新任务，最大价值）。语言=连接人类意图与机器行为的桥梁。

**五层架构**：① 输入层（图像+文本指令）；② 编码层（视觉编码器+语言编码器并行转特征向量）；③ **融合层（灵魂）**（Cross-Attention 让视觉语言深度交互）；④ 输出层/动作头（预测动作）。关键技术：

- **视觉编码器**：主流 **ViT**（图像切 Patch、线性投影+位置编码、送 Transformer 自注意力，即第 3 节 Transformer 应用、「词」换成「图像块」）；还有 SigLIP（Sigmoid 损失优化图文对齐）。当「视觉神经」。
- **语言编码器(LLM Backbone)**：Llama/Vicuna 等 LLM 当「大脑」，理解指令+常识推理，连接高层语义与底层动作。
- **Cross-Attention 融合（最关键）**：用第 3 节 Q/K/V——**语言特征当 Query 去关注视觉特征图相关区域**。指令「红色的车」→注意力自动聚焦图中红色车辆像素=「语言引导视觉」。融合后视觉 Token+语言 Token 拼成统一长序列送 Transformer 解码器生成动作。

**动作头（连续 vs 离散）**：连续头=MLP 回归直接输出连续控制量（方向盘/油门/刹车，精确平滑）；离散头=MLP+Softmax 从预定义集合选（直行/左转/加速，可解释易验证、易与规则系统结合）。

**两种训练方式**：**行为克隆**（模仿人类「图像-指令-动作」三元组监督学习，简单但上限受人类数据限制）；**强化学习**（环境交互+奖励优化，潜力超人但复杂不稳风险高）。**现状：以行为克隆为主、RL 辅助**（呼应第 4 节 RL 落地难）。

### 4. 典型 VLA 模型

时间线 RT-1(2022)→RT-2(2023)→OpenVLA(2024)→Pi0(2024)：

- **RT-2(Google DeepMind)**：**无需大量机器人演示，直接从互联网文本+图像学习**，极强泛化与常识推理，处理没见过的新物体新任务。「网络知识→物理世界直接迁移」。
- **OpenVLA(2024)**：开源 VLA（预训练模型+训练代码+评估基准），降门槛、促协同。
- **Pi0(Physical Intelligence)**：首个 VLA 基础模型，造控制多种机器人的通用大脑。**混合专家(MoE) Transformer** 架构（VLM 主干+轻量动作专家）+ **流匹配(Flow Matching)** 生成平滑连续动作。
- **Pi0.5**：解决 Pi0 的「**知识干扰**」（动作模块梯度反传破坏 VLM 预训练知识）。三创新：① **知识隔离**（梯度截断保护 VLM 知识）；② **分层推理**（先预测高层子任务「拿起杯子」再生成低层动作，「先思考后行动」）；③ **异构数据协同训练**（机器人+网页+语言指令）。效率比 Pi0 **快 7.5 倍**（20K vs 160K 步）。核心矛盾：端到端训练同时不破坏大模型语言/常识能力。

### 5. VLA 在自动驾驶 + SimLingo 实战

**VLA 位置**：① 替代规划模块（感知→VLA→控制）；② 替代整个端到端（原始数据+语言指令→VLA→控制）。**输入**：多摄像头 360° + **BEV 鸟瞰图**（统一鸟瞰视角增强空间理解）+ 多样文本任务。**输出**：直接控制量（高效风险高）/ 轨迹预测（未来位置点序列，易集成可解释安全）。

**SimLingo**（CVPR 2025 Spotlight、CARLA Challenge 2024 冠军）：纯视觉闭环自动驾驶（仅摄像头无 LiDAR/Radar）、1B 参数。架构 InternViT-300M + Qwen2-0.5B → 路径路点（横向）+ 速度路点（纵向），**LoRA 微调**（只训 2.72% 参数）。三任务协同：驾驶（输出路点）+ Commentary（自然语言描述驾驶行为，可解释）+ VQA（场景问答，增强语义）。**核心创新 Action Dreaming（语言-动作对齐）**：解决「嘴上说左转实际直行」的语言-行为脱节——合成指令→生成对应理想轨迹→联合训练强制一致→指令跟随成功率验证，成功率 **28.2%→72.9%**。指标：**ADE（平均位移误差）/FDE（终点位移误差）**；开环评估（离线比对、4GB 显存）vs 闭环评估（CARLA 真行驶有反馈、需更多显存）。

### 6. NaVILA：足式视觉语言导航（实验课）

**NaVILA**（RSS 收录），专为四足/人形足式机器人的端到端**视觉语言导航(VLN)** 系统。**核心架构：高层视觉语言理解 + 底层运动控制 解耦**——高层（VLA 模型 VILA）处理单视角图像+语言指令、生成**自然语言路径点指令**（「向前 2 米后左转」）；底层（运动策略）把路径点转成精准关节运动实时控制。正对应能力栈「规划推理」+「控制执行」分层，=全课主线「智能决策（高层）+精确控制（底层）」。

**VILA 三模块**：视觉编码器（图像→视觉词元）+ 投影层（下采样映射到语言空间）+ LLM（视觉+文本词元自回归生成）。视频按固定间隔均匀采样帧，序列并行训练最多 1024 帧。

**数据（从人类视频学导航）**：YouTube 2000 条第一人称巡游视频→熵采样成 20000 条导航轨迹；MASt3R 估计相机位姿提取分步动作，VLM 字幕+LLM 重述生成自然语言指令。**突破**：① 首次从人类日常视频学通用导航；② **零重训适配多款不同结构足式机器人**（跨 embodiment 泛化，呼应 POMDP 难点）；③ 强光/透明障碍物等纯视觉极易失效场景仍稳定。

**实验技术细节**：仿真 Habitat-Sim（渲染）+ Habitat-Lab（任务逻辑），3D 场景 Matterport3D(MP3D)，任务 R2R_VLNCE 数据集，权重基于 Llama-3-8B。工程点：官方 transformers 原只支持单图，NaVILA 创新在处理**连续 8 帧视频级画面**，故打补丁改底层注意力机制理解时空序列（第 3 节序列处理用到导航）。

### 7. 全课收束

> 控制本质是**让系统在不确定环境里达成目标**。对象简单 PID 足矣；对象复杂到拿不到精确模型，就给控制器装智能——**符号主义**用规则（专家系统）、**模糊逻辑**用隶属度（模糊控制）、**连接主义**用数据（神经网络/RNN/Transformer）、**行为主义**用试错（ILC/强化学习），加上**感知**（光流）这只眼睛。最终在**具身智能/VLA** 合流：一个「看(Vision)+听懂(Language)→行动(Action)」的端到端智能体，在 POMDP 描述的真实世界里用「高层语言决策+底层运动控制」完成复杂任务。归宿即导论那句：**具身智能是一个广义的控制问题。**

## 第 7 节 · 安全与伦理：给智能体套上缰绳

### 1. 全局框架：安全风险的「冰山模型」（总纲）

用一座冰山组织所有 AI 安全风险：**水上=衍生风险（看得见，对外部社会的影响，生成内容层面），水下=内生风险（看不见，AI 自身内在机理缺陷，是根子）**。

- **内生风险（水下，内在机理）**：鲁棒性、隐私性、透明性。
- **衍生风险（水上，生成内容）**：公平性、有害性、可靠性。

记忆：内生=模型「自身有病」（机理），衍生=模型「祸害社会」（影响）。

### 2. 衍生风险（水上）：对社会的影响

- **① 公平性**：模型偏差/滥用导致歧视性决策。例：AI 把非白人与负面形象关联；Waymo 因医生名字「像中东名」误识别为恐怖分子；大数据杀熟。根源常是训练数据带偏见。
- **② 有害性**：生成恶意/违背伦理内容。例：抑郁男子与 AI 聊天机器人 Eliza 聊后被其附和鼓励自杀身亡；**DeepFake 深度伪造**滥用——伪造奥巴马辱特朗普假视频、AI 换脸变声电信诈骗、伪造癌症影像骗医生、伪造战争照片制造虚假舆情。DeepFake 把危害升级到伪造证据/操纵舆论/危害国安。
- **③ 可靠性**：生成难以信任的内容。三表现：**错误/虚假输出**（大模型**幻觉 Hallucination**，编不存在的论文「查无此文」、违反物理定律）；**输出不一致**（与上下文矛盾或自相矛盾）；**谄媚性输出 Sycophancy**（迎合用户观点而非给正确信息）。警示：AI 因幻觉被告上法庭、获自主权后擅自高危操作致 AWS 中断 13 小时、忽视安全指令清空收件箱——可靠性不足的 AI 给越多自主权越危险。

### 3. 内生风险（水下）：模型自身机理缺陷（技术核心）

**① 鲁棒性 + 对抗样本（重中之重）**：鲁棒性风险=面对噪声/扰动/非理想环境无法保持性能（加雾天噪声认不出行人、贴对抗补丁「看不见」人）。最严峻挑战=**对抗攻击/对抗样本(Adversarial Examples)**。

定义：**精心设计、人眼几乎无差、却让 AI 彻底判错的输入**。经典例（Szegedy 2013 开山作）：熊猫照片正确识别，叠加人眼无法察觉的微小噪声后，AI 高置信度判成「长臂猿」。数学：找扰动 $r$ 使 $y\ne F(x+r)$ s.t. $\|r\|<\epsilon$（扰动小到察觉不到却让模型判错）。**可怕在普遍性**——非特定模型过拟合，是 DNN 普遍弱点（「任何用 DNN 分类的 AI 都可能被骗」，Nature 2019 专文）。

**两个世界**：**数字世界**（图像直接加扰动，环境简单固定、白盒、训练评测阶段、风险有限）；**物理世界 PAE**（现实环境实施、跨数字-物理鸿沟，须在真实光照角度下生效，难度威胁大得多）分三类：二维（打印图案/贴纸）、三维（3D 打印物/对抗眼镜框）、对抗光投影（光源/阴影）。实例：路牌贴补丁→多角度多距离都识别不出「限速 20」；车贴补丁→华为/海康威视监控认不出车——对自动驾驶（VLA）致命。差异：物理世界环境复杂、噪声自然、黑盒、风险巨大。其他新型攻击：数据投毒、模型后门（特殊触发器）、模型窃取、框架攻击。

**② 隐私性 + 三类隐私攻击**：风险=训练/部署/使用中泄露隐私（训练数据隐私+模型隐私）。例：GPT-2 被恶意前缀诱导吐训练数据里真实姓名/邮箱/手机号；Bing Chat 被诱导泄露提示词。三类经典攻击（常考）：① **成员推断攻击**（给定记录+黑盒访问，判断该记录是否在训练集——能推断「某人病历是否用于训练」）；② **模型反演攻击**（给定模型+辅助信息，反向恢复输入机密——从人脸识别模型反推还原训练人脸）；③ **模型窃取攻击**（无任何先验，只靠公开 API 黑盒访问，复制出高相似模型——偷走别人训练的模型）。可发生在训练/部署/测试各阶段。

**③ 透明性/可解释性**：风险=人类难理解模型为何如此决策（黑盒）。例：医疗 AI 给「季节性感冒」却说不出为什么，医生不敢信。**可解释性方法**：特征重要性、**SHAP**（算各特征对预测贡献）、**热力图/激活图/注意力**（看模型在看图哪块）、可视化。有趣发现——**CNN 感知偏差**：ImageNet 预训练 CNN 强烈偏向靠**纹理**而非形状识别物体（「猫形状+大象纹理」合成图被判成大象，人判成猫），揭示神经网络认知方式与人类根本不同，是它易被对抗样本骗、不可靠的深层原因。

### 4. 防范 + 评估

**防范（多层次体系）**：① 基于数据（提升训练数据质量从源头增强鲁棒）；② 基于模型（改进推理/结合外部参考补局限）；③ 基于训练策略（调整训练目标确保输出与人类期望对齐，即 RLHF 对齐思路，呼应第 4 节 PPO）。

**评估（全周期体系）**：量化评测「AI 安不安全」。从数据/模型、离线/在线、动态/静态、微观/宏观多维度，覆盖训练阶段（数据集评测）→验证阶段（算法评测）→测试阶段（功能/性能/安全测试）。模型质量标准：功能性/可靠性/效率/维护性。平台：北航参与的**启智·重明(AISafety)** 深度学习安全评测平台（「重明鸟」神话神鸟双瞳避灾，寓意火眼金睛识别安全隐患，一站式算法评测）。

### 5. 终极思考：AI 的「电车难题」

经典电车难题（失控电车冲向 5 人，扳道岔转向只有 1 人的轨道，扳不扳？）放到自动驾驶=**事故不可避免时该保护车内乘客还是车外行人、如何权衡**。背后两根本问题：① AI 应如何解决道德困境（道德能否/该否编码进算法、由谁定）；② AI 安全性与任务能力如何平衡（更安全=更保守能力受限，如何在「能干活」与「不闯祸」间取舍）。无标准答案，是这门课技术之外的终极拷问。

### 6. 收口

> AI 安全用**冰山模型**组织：水下**内生风险**（鲁棒性/隐私性/透明性）是机理缺陷根子，水上**衍生风险**（公平性/有害性/可靠性）是对社会危害。最经典**对抗样本**——人眼无差却让 AI 判错（熊猫→长臂猿）、有普遍性、能跨入物理世界（贴补丁让摄像头认不出车），对自动驾驶致命。隐私三攻击=成员推断/模型反演/模型窃取。防范靠数据/模型/训练策略三层+全周期评测。终极是电车难题伦理拷问。
