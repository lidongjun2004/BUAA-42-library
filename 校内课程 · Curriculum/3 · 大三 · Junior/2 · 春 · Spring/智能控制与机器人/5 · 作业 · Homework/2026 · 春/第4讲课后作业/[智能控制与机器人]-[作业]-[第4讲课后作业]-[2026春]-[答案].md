# 第四讲课后作业：基于 RBF 神经网络的自动驾驶转向辅助修正

> 课程：智能控制与机器人 · 第四讲（神经网络控制）

## 第四讲课后作业：基于 RBF 神经网络的自动驾驶转向辅助修正

### 题目

在自动驾驶车辆进行车道保持时，控制器需要根据车辆的横向偏差和航向角误差生成一个转向修正量。现采用一个简单的 RBF 神经网络对转向控制器进行辅助修正。

设输入为 $x = [e, \psi]^T$，其中： $e$ 表示车辆相对车道中心的横向偏差，单位为 m； $\psi$ 表示车辆航向角误差，单位为 rad。某一时刻，车辆状态为 $x = [0.2, 0.1]^T$，RBF 网络包含两个隐层节点，其高斯基函数分别为：

$$\phi_1(x) = \exp\left(-\frac{|x - c_1|^2}{2\sigma^2}\right), \quad c_1 = [0, 0]^T$$

$$\phi_2(x) = \exp\left(-\frac{|x - c_2|^2}{2\sigma^2}\right), \quad c_2 = [0.3, 0.1]^T$$

已知： $\sigma = 0.2$，输出层权值为： $w_1 = 0.5$， $w_2 = 1.0$；网络输出的转向辅助修正量为： $u = w_1\phi_1(x) + w_2\phi_2(x)$。

问题：

1. 计算当前输入下两个 RBF 节点的输出 $\phi_1(x)$ 和 $\phi_2(x)$；
2. 计算网络输出 $u$；
3. 根据结果简要说明：当前车辆状态更接近哪个隐层中心？这说明了 RBF 神经网络的什么特点？

### 答案

#### 二、解答

##### 第 1 步：计算输入到两个中心的距离平方

输入 $x = [0.2,\ 0.1]^T$。

对中心 $c_1 = [0,\ 0]^T$：

$$\lVert x - c_1 \rVert^2 = (0.2 - 0)^2 + (0.1 - 0)^2 = 0.04 + 0.01 = 0.05$$

对中心 $c_2 = [0.3,\ 0.1]^T$：

$$\lVert x - c_2 \rVert^2 = (0.2 - 0.3)^2 + (0.1 - 0.1)^2 = (-0.1)^2 + 0 = 0.01$$

基函数分母（ $\sigma = 0.2$）：

$$2\sigma^2 = 2 \times 0.2^2 = 2 \times 0.04 = 0.08$$

##### 第 2 步：计算两个基函数输出 φ₁、φ₂

$$\phi_1(x) = \exp\!\left(-\frac{0.05}{0.08}\right) = \exp(-0.625) \approx 0.5353$$

$$\phi_2(x) = \exp\!\left(-\frac{0.01}{0.08}\right) = \exp(-0.125) \approx 0.8825$$

##### 第 3 步：计算网络输出 u

$$u = w_1\phi_1 + w_2\phi_2 = 0.5 \times 0.5353 + 1.0 \times 0.8825$$

$$u = 0.2677 + 0.8825 \approx 1.15$$

##### 第 4 步：判断更接近的中心并分析

比较两个距离平方：

$$\lVert x - c_2 \rVert^2 = 0.01 \ < \ \lVert x - c_1 \rVert^2 = 0.05$$

因此**当前车辆状态 $x$ 更接近隐层中心 $c_2$**，对应地 $\phi_2 \approx 0.88 > \phi_1 \approx 0.54$，即 $c_2$ 节点的激活值更大、对网络输出 $u$ 的贡献也更大。

这体现了 RBF 神经网络的**局部响应特性（局部逼近能力）**：每个隐层节点只对其中心附近的输入强烈响应，输入越接近某个中心，对应节点激活值越大、影响越显著；离中心远的节点几乎不激活。正因如此，RBF 网络具有**局部可调、学习收敛快**的优点——调整某个中心的权值只影响其局部区域，不像 BP（全局逼近）那样牵一发而动全身。
