# 第五讲课后作业：P 型迭代学习控制（ILC）的收敛性与误差计算

> 课程：智能控制与机器人 · 第五讲（迭代学习与强化学习控制）

## 课后作业题目

### 题目

在固定测试中，车辆需要执行完全相同的循迹泊车任务。为了简化分析，将车辆的横向控制模型抽象为一个线性无记忆系统

$$y_k(t) = 2.5 \cdot u_k(t)$$

其中， $u_k(t)$ 为第 $k$ 次迭代时的方向盘转角指令， $y_k(t)$ 为实际横向位移。车辆的期望循迹轨迹为 $y_d(t)$。

系统采用 P 型迭代学习控制律：

$$u_{k+1}(t) = u_k(t) + \Gamma \cdot e_k(t)$$

其中 $e_k(t) = y_d(t) - y_k(t)$ 为跟踪误差。

1. 为保证车辆随着重复次数增加，横向跟踪误差 $e_k(t)$ 能够收敛到 0，请推导并求出学习增益 $\Gamma$ 的合理取值范围；
2. 假设工程师设定学习增益 $\Gamma = 0.2$，第 1 次迭代没有施加任何方向盘控制指令，即 $u_1(t) = 0$。已知在路线的 $t = 3\ \mathrm{s}$ 处，期望横向位移为 $y_d(3) = 5\ \mathrm{m}$。请计算第 1 次、第 2 次和第 3 次迭代时，在 $t = 3\ \mathrm{s}$ 处的跟踪误差，并说明误差的变化规律。

### 答案

#### 二、迭代学习控制（ILC）的核心思想

ILC 针对**重复执行同一任务**的系统：每完成一次任务，就把这次的跟踪误差 $e_k$ 用来修正下一次的控制指令 $u_{k+1}$，如此反复，让误差随迭代次数 $k$ 越来越小，最终逼近 0。它"在重复中学习"，不需要精确的系统模型。

本题系统是无记忆线性系统（增益 $p = 2.5$），控制律是 **P 型**（只用比例项 $\Gamma \cdot e_k$ 修正）。

#### 三、解答

##### 第（1）问：推导收敛条件与 Γ 的取值范围

**关键是导出"误差随迭代的递推关系" $e_{k+1}$ 与 $e_k$ 的关系。**

由误差定义：

$$e_{k+1}(t) = y_d(t) - y_{k+1}(t) = y_d(t) - 2.5\,u_{k+1}(t)$$

将控制律 $u_{k+1} = u_k + \Gamma e_k$ 代入：

$$e_{k+1} = y_d - 2.5\,(u_k + \Gamma e_k) = \underbrace{(y_d - 2.5\,u_k)}_{=\,e_k} - 2.5\,\Gamma e_k$$

得到**误差递推式**：

$$\boxed{e_{k+1}(t) = (1 - 2.5\,\Gamma)\,e_k(t)}$$

这是一个等比（几何）递推，公比为收敛因子 $\rho = 1 - 2.5\Gamma$。根据**压缩映射原理**，要使误差随 $k \to \infty$ 收敛到 0，必须满足 $|\rho| < 1$：

$$|1 - 2.5\,\Gamma| < 1$$

$$-1 < 1 - 2.5\,\Gamma < 1$$

$$0 < 2.5\,\Gamma < 2$$

$$\boxed{0 < \Gamma < 0.8}$$

即学习增益 $\Gamma$ 取值在 $(0,\ 0.8)$ 范围内时，跟踪误差才能收敛到 0。

> 补充：当 $\Gamma = 1/2.5 = 0.4$ 时 $\rho = 0$，理论上**一步收敛**（最快）；越偏离 0.4，收敛越慢； $\Gamma \ge 0.8$ 或 $\Gamma \le 0$ 则发散。

##### 第（2）问：Γ = 0.2 时各次迭代误差

代入 $\Gamma = 0.2$，收敛因子：

$$\rho = 1 - 2.5 \times 0.2 = 1 - 0.5 = 0.5$$

初始条件 $u_1(t) = 0$， $y_d(3) = 5\text{m}$。

**第 1 次迭代**（ $t = 3\text{s}$）：

$$e_1(3) = y_d(3) - y_1(3) = y_d(3) - 2.5\,u_1(3) = 5 - 2.5 \times 0 = 5\ \text{m}$$

**第 2 次迭代**：

$$e_2(3) = \rho \cdot e_1(3) = 0.5 \times 5 = 2.5\ \text{m}$$

**第 3 次迭代**：

$$e_3(3) = \rho \cdot e_2(3) = 0.5 \times 2.5 = 1.25\ \text{m}$$

##### 误差变化规律

| 迭代次数 $k$ | 跟踪误差 $e_k(3)$ |
| --- | --- |
| 1 | 5 m |
| 2 | 2.5 m |
| 3 | 1.25 m |
| $k$ | $5 \times 0.5^{\,k-1}$ m |

误差序列 $5,\ 2.5,\ 1.25,\ \dots$ 是一个**公比为 0.5 的等比数列**，随迭代次数呈**指数级衰减**并趋于 0。这说明在 $\Gamma = 0.2 \in (0, 0.8)$ 下控制律收敛，每迭代一次误差减半，验证了 P 型迭代学习控制的有效性。
