# 3.2 闭环评估（Closed-Loop Evaluation）

## 3.2.1 任务说明

闭环评估在 CARLA 仿真环境中，将 SimLingo 模型作为端到端驾驶 Agent 接入 Bench2Drive Leaderboard，在指定路线与交通场景下实时感知、推理并输出控制指令，由仿真器反馈下一帧状态，形成完整控制回路。

本组评估路线为 `bench2drive_00.xml`，对应场景 **ParkingCutIn_1**（路边停车切入），地图 **Town12**。

---

## 3.2.3 环境搭建与主要问题

### （1）CARLA 版本匹配

RTX 5090 + Python 3.11 需使用 **CARLA 0.9.16 服务端**，并安装对应 cp311 wheel：

```bash
pip install .../carla-0.9.16-cp311-cp311-manylinux_2_31_x86_64.whl
```

若使用 0.9.15 服务端 + 0.9.16 客户端，会在 `get_world()` 处 Segfault。

### （2）GPU 渲染

5090 上 `graphicsadapter=1` 易导致渲染崩溃，改为 `CARLA_GPU=0` 并加 `-opengl` 后稳定。

### （3）Agent 代码适配

对 `agent_simlingo.py` 做了以下修改：

- 支持本地 checkpoint 路径，避免 HuggingFace 校验错误；
- `control_pid()` 中将 numpy 标量转为 Python `float`，修复 PID 报错；
- `destroy()` 增加空指针保护；
- 开启 `DEBUG` 模式保存可视化帧，用于演示视频合成。

### （4）Leaderboard 启动参数

在 `leaderboard_evaluator.py` 中为 CARLA 增加 `-opengl` 与 `-quality-level Low`，降低离屏渲染负担。

### （5）其他依赖

补装 `pexpect`；合成视频需 `ffmpeg`（conda-forge 安装）。

| 测试项 | 结果 |
| --- | --- |
| 路线完成 | ✅ 通过（100%） |

## 3.2.5 结果分析

### （1）驾驶表现

SimLingo 在 Town12 的 ParkingCutIn 场景下**完整跑完全程**，无碰撞、无偏离、无交通违规。说明模型在闭环条件下具备基本感知-规划-控制能力，能处理路边车辆切入这一动态场景。

### （2）推理速度

实时比约 **0.026×**，即仿真 1 秒约需 38 秒墙钟时间，主要瓶颈在 InternVL2-1B 每步前向推理（约 2–3 s/步）。Leaderboard 以同步模式运行，仿真会等待 Agent 返回控制，因此评估耗时长，但不影响结果正确性。

### （3）与开环对比

| 维度 | 开环 | 闭环 |
| --- | --- | --- |
| 环境 | 预录数据集 | CARLA 实时仿真 |
| 评价指标 | ADE / FDE（轨迹误差） | Driving Score / Route Completion |
| 交互性 | 无（回放） | 有（控制影响后续状态） |
| 本组结果 | ADE≈0.043 m，FDE≈0.132 m | Driving Score 100，Route Completion 100% |

开环轨迹精度高，闭环也能成功跑通复杂场景，说明 SimLingo 从「预测准」到「控得住」的迁移在本路线下表现良好。

### （4）演示视频

录制了 487 帧 debug 可视化，合成 24.4 s、1920×1480 的 MP4（`bench2drive_00.mp4`）。视频使用第三人称追拍相机（`HD_VIZ`），在 ParkingCutIn 场景切换时，NPC 车辆会出现切入加速或场景结束被销毁（`ActorDestroy`）的现象，属 CARLA 场景设计行为，不影响评估 JSON 中的 100 分结果。
