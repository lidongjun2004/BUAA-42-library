# 模式识别与机器视觉课程复习知识点

## Lesson1：图像分类与 CNN

### 1. 图像分类任务

- 输入是一张图像，输出是给定类别集合中的一个类别标签。
- 计算机看到的图像是像素张量，例如 RGB 图像可表示为 `H×W×3`。
- 常见挑战：视角变化、光照变化、遮挡、形变、背景干扰、类内差异。

### 2. 最近邻与 K 近邻

- 最近邻分类器：找到与测试样本距离最近的训练样本，使用其标签作为预测结果。
- KNN：选择距离最近的 K 个样本，通过投票确定类别。
- 特点：几乎没有训练成本，但预测时需要与训练样本比较，预测较慢。
- 距离度量会影响结果，如 L1 距离、L2 距离。

### 3. 线性分类器

基本形式：

```text
f(x, W) = Wx + b
```

- `x` 是输入特征，`W` 是权重，`b` 是偏置。
- 每个类别可理解为一个学习得到的模板。
- 线性分类器只能形成线性决策边界，难以处理复杂的非线性数据分布。

### 4. Softmax 分类器

- Softmax 将原始分数转换为非负且总和为 1 的类别概率。
- 正确类别概率越大，交叉熵损失越小。
- 单样本交叉熵可写为：

```text
L = -log(p_y)
```

其中 `p_y` 为正确类别的预测概率。

### 5. 卷积神经网络

- 卷积核在局部区域滑动并进行加权计算，得到特征图 feature map。
- 同一个卷积核在不同位置共享参数，可以检测不同位置出现的同类特征。
- 多个卷积核可提取不同类型的特征。
- 浅层通常学习边缘、颜色和纹理；深层通常学习更抽象的语义特征。

卷积输出尺寸：

```text
输出尺寸 = floor((输入尺寸 + 2P - K) / S) + 1
```

其中 `P` 为 padding，`K` 为卷积核大小，`S` 为 stride。

### 6. 池化

- 最大池化 Max Pooling：取局部区域中的最大值。
- 平均池化 Average Pooling：取局部区域中的平均值。
- 作用：降低空间尺寸、减少计算量，使表征更易管理，并带来一定空间鲁棒性。
- 池化通常没有可学习参数。

## Lesson2：图像分割与上采样

### 1. 视觉任务的区别

- 图像分类：整张图像输出一个类别，不输出目标位置。
- 语义分割：为每个像素预测类别，不区分同类目标的不同实例。
- 目标检测：输出目标类别和边界框。
- 实例分割：既进行像素级分割，又区分不同目标实例。

### 2. 全卷积语义分割

- 语义分割需要输出与输入图像空间对应的像素级预测。
- 网络通常包含下采样和上采样：下采样获得高级语义，上采样恢复空间分辨率。
- 全卷积网络使用卷积产生 `C×H×W` 的类别分数图，再对每个像素选择类别。

### 3. 上采样方法

- 最近邻上采样：复制邻近值。
- 最大反池化：利用最大池化时记录的位置恢复特征。
- 转置卷积：使用可学习卷积核扩大特征图空间尺寸。

### 4. 转置卷积

- Transposed Convolution 常用于上采样或恢复特征图空间尺寸。
- 它不是严格意义上将普通卷积完全求逆，而是通过卷积形式实现从低分辨率到高分辨率的映射。
- 转置卷积产生重叠位置时，需要将重叠贡献相加。

## Lesson2与 Lesson3：目标检测

### 1. 目标检测的定义

目标检测同时解决：

- 分类：目标是什么类别。
- 定位：目标位于哪里，通常用边界框 `(x, y, w, h)` 表示。

多目标检测还需要处理目标数量不固定、尺度变化、遮挡和重复预测等问题。

### 2. 两阶段检测流程

基本流程：

1. 生成可能包含目标的候选区域 proposal。
2. 从候选区域提取固定尺寸特征。
3. 对候选区域进行类别预测和边界框回归。
4. 使用 NMS 去除重复框。

代表模型：R-CNN、Fast R-CNN、Faster R-CNN。

### 3. R-CNN 系列

#### R-CNN

- 使用选择性搜索生成候选区域。
- 将每个候选区域裁剪、缩放后分别送入 CNN。
- 使用分类器判断类别，并进行边界框回归。
- 缺点：每个区域都单独运行 CNN，计算重复，速度慢。

#### Fast R-CNN

- 整张图像只运行一次 CNN，得到共享特征图。
- 将 proposal 映射到特征图，再使用 RoI Pooling 得到固定尺寸特征。
- 共享卷积计算，比 R-CNN 更快。

#### Faster R-CNN

- 使用 RPN 代替外部选择性搜索，直接在共享特征图上生成 proposal。
- 第一阶段：Backbone + RPN 生成候选区域。
- 第二阶段：RoI Pooling/Align + 分类 + 边界框回归。

### 4. RPN

- RPN 全称 Region Proposal Network。
- 主要作用：在特征图上生成候选区域 proposal。
- 基于 anchor 判断该位置是否包含目标，并预测边界框坐标偏移。
- RPN 通常同时包含 object/non-object 分类损失和边界框回归损失。

### 5. RoI Pooling

基本步骤：

1. 将原图中的 proposal 映射到特征图。
2. 将对应 RoI 划分为固定数量的子区域 bin，如 `2×2` 或 `7×7`。
3. 在每个 bin 内进行最大池化。
4. 得到固定空间尺寸的 RoI 特征。

计算时要会：正确划分 bin，并分别取每个 bin 的最大值。

### 6. RoI Align

- RoI Pooling 对坐标进行取整，可能造成空间错位。
- RoI Align 不直接量化坐标，而使用双线性插值采样，提高位置精度。
- 常用于 Mask R-CNN 等对像素位置要求更高的任务。

### 7. 一阶段检测流程

- 不显式执行“先生成 proposal、再分类”的两阶段流程。
- 单个网络直接预测类别、边界框位置和置信度。
- 代表方法：YOLO、SSD、RetinaNet。
- 通常速度更快，适合实时检测。

### 8. YOLO v1

- YOLO 全称 You Only Look Once。
- 将图像划分为 `S×S` 网格。
- 目标中心落在哪个网格，该网格负责预测该目标。
- 每个网格预测若干边界框、置信度和类别概率。
- YOLO 不显式生成 region proposal，训练与推理都在单个网络中完成。

重点理解：

- 网格负责规则。
- 边界框参数和 confidence 的含义。
- 定位损失、置信度损失、分类损失。
- 多个预测框需要经过阈值筛选和 NMS。

### 9. IoU

IoU（Intersection over Union）用于衡量两个框的重叠程度：

```text
IoU = 交集面积 / 并集面积
并集面积 = 框A面积 + 框B面积 - 交集面积
```

### 10. 非极大值抑制 NMS

同一类别的标准 NMS 流程：

1. 删除置信度低于阈值的框。
2. 按置信度从高到低排序。
3. 保留当前置信度最高的框。
4. 计算该框与其余同类别框的 IoU。
5. 删除 IoU 超过阈值的重叠框。
6. 对剩余框重复上述过程。

注意：通常应按类别分别执行 NMS，不同类别的框一般不互相抑制。

## Lesson4：注意力机制与 Transformer

### 1. 为什么使用注意力和 Transformer

- RNN 按时间顺序串行计算，不利于并行，长距离信息传播路径较长。
- 注意力允许当前位置直接关注序列中的其他位置。
- Transformer 主要依赖注意力机制，可并行处理整个输入序列。

### 2. Q、K、V

由输入矩阵 `X` 通过三个可学习矩阵得到：

```text
Q = XW_Q
K = XW_K
V = XW_V
```

- Query：当前元素希望查询什么信息。
- Key：每个元素用于和 Query 匹配的索引特征。
- Value：匹配后真正被加权汇聚的信息。

### 3. 缩放点积注意力

```text
Scores = QK^T / sqrt(d_k)
Attention = softmax(Scores)
Y = Attention · V
```

对单个 query 可写为：

```text
e_ij = q_j^T k_i / sqrt(d_k)
a_ij = softmax_i(e_ij)
y_j = Σ_i a_ij v_i
```

理解重点：Q 与 K 决定“关注多少”，V 决定“汇聚什么内容”。

### 4. 多头注意力

- 多组 Q、K、V 在不同特征子空间中独立计算注意力。
- 不同头可以学习不同类型的关系。
- 各头输出拼接后再做线性变换。

### 5. Transformer Encoder

典型 Encoder Block 包含：

1. Multi-Head Self-Attention。
2. Add & Norm：残差连接和 Layer Normalization。
3. Feed-Forward Network。
4. 再次 Add & Norm。

### 6. 位置编码

- 纯自注意力本身不包含序列顺序信息。
- 需要把位置编码加入 token embedding。
- 原始 Transformer 使用正弦、余弦位置编码。

### 7. Transformer 训练与 BERT

- Decoder 使用 masked self-attention，防止当前位置看到未来 token。
- Teacher forcing：训练时向 Decoder 提供真实的前序 token。
- BERT 主要使用 Transformer Encoder，通过掩码语言建模学习双向上下文表示。

## Lesson5：Vision Transformer 与 Swin Transformer

### 1. ViT 输入过程

1. 将图像划分为固定大小、不重叠的 patches。
2. 将每个 patch 展平。
3. 通过可训练的线性映射得到 patch embedding。
4. 加入 position embedding，保留 patch 的空间位置信息。
5. 加入可学习的 class token。
6. 将序列输入 Transformer Encoder。
7. 使用最终 class token 的表示完成分类。

若图像大小为 `H×W`，patch 大小为 `P×P`，则 patch 数量为：

```text
N = (H/P) × (W/P)
```

若加入一个 class token，则输入序列长度为 `N+1`。

### 2. ViT 中各部分的作用

- Patch：把二维图像转化为序列单元。
- Patch embedding：将 patch 像素映射到统一的 D 维 token。
- Position embedding：表示 patch 在原图中的位置。
- Class token：汇聚全局信息，用于分类输出。
- Transformer Encoder：通过自注意力建模 patch 间关系。

### 3. ViT 与 CNN 的比较

- CNN 具有局部连接、权值共享等较强归纳偏置。
- ViT 的视觉归纳偏置更弱，通常更依赖大规模预训练数据。
- ViT 的自注意力可以直接建模全局 patch 关系。
- ViT 主要由矩阵运算构成，适合 GPU/TPU 并行计算。

### 4. Swin Transformer

- 使用层级结构，逐步降低特征图分辨率、增加通道数。
- Window Attention 只在局部窗口内计算注意力，降低高分辨率图像上的计算量。
- Shifted Window 在相邻层移动窗口，实现不同窗口间的信息交互。
- 层级、多尺度特征使 Swin 更适合作为检测和分割任务的 backbone。

## Lesson6：生成模型

### 1. 生成模型概念

- 生成模型试图学习数据分布，并从该分布采样生成新样本。
- 生成模型通常涉及密度估计和采样两个问题。
- 课件介绍的主要方法：VAE、GAN、Normalizing Flow、Diffusion。

### 2. VAE

- Encoder 将数据映射到隐变量分布。
- Decoder 从隐变量重建或生成数据。
- 使用变分推断近似难以计算的后验分布。
- 训练目标通常包含重建项和 KL 散度项，优化 ELBO。

### 3. GAN

- Generator：生成器，从随机噪声产生生成样本。
- Discriminator：判别器，区分真实样本和生成样本。
- 生成器尽量欺骗判别器；判别器尽量正确区分真假，两者形成极大极小博弈。

常见问题：

- 训练不稳定。
- 判别器过强导致生成器梯度消失。
- 模式崩溃：生成器只产生少数几种样本，缺乏多样性。

### 4. Normalizing Flow

- 使用一系列可逆、可求雅可比行列式的变换，将简单分布映射到复杂数据分布。
- 优点是可以计算精确似然。
- 核心限制是变换需要可逆，网络结构设计受到约束。

### 5. 扩散模型

- 前向加噪过程：逐步向真实数据加入噪声，使其最终接近高斯噪声。
- 反向去噪过程：训练神经网络逐步预测并去除噪声，从随机噪声恢复出样本。
- 不需要 GAN 式对抗训练，通常训练更稳定，且生成质量和多样性较好。
- 缺点是反向过程需要多步采样，速度通常较慢。

### 6. 四类生成模型比较

| 模型 | 核心思想 | 主要特点 |
| --- | --- | --- |
| VAE | 变分推断与隐空间 | 训练稳定，生成可能偏平滑 |
| GAN | 生成器与判别器对抗 | 采样快，但训练可能不稳定、模式崩溃 |
| Normalizing Flow | 可逆变换 | 可计算精确似然，但结构受可逆性限制 |
| Diffusion | 前向加噪、反向去噪 | 质量和多样性好，训练稳定，但采样较慢 |

## Lesson7：扩散模型应用与视频生成

### 1. DDPM 与 DDIM

- DDPM：通过多步随机反向过程逐步去噪，通常需要较多采样步。
- DDIM：允许跳过部分时间步，使用更少步骤完成生成，可提高采样速度。

### 2. Latent Diffusion 与 Stable Diffusion

- 像素空间扩散计算量大。
- Latent Diffusion 先用 Encoder 将图像压缩到隐空间，在隐空间完成加噪和去噪，再由 Decoder 恢复图像。
- Stable Diffusion 是典型的隐空间扩散模型，可进行有条件或无条件图像生成。

### 3. CLIP

- CLIP 包含图像编码器和文本编码器。
- 通过图文对比学习，使匹配的图像和文本特征更接近，不匹配的特征更远。
- 图像和文本被映射到同一个特征空间。

Zero-shot 图像分类流程：

1. 使用类别名称构造文本提示，如“a photo of a cat”。
2. 文本编码器得到各类别文本特征。
3. 图像编码器得到输入图像特征。
4. 计算图像与各文本特征的相似度。
5. 选择相似度最高的文本类别作为预测结果。

CLIP 还可为扩散模型提供文本条件，实现文本引导生成。

### 4. ControlNet

- 在预训练扩散模型基础上加入可训练控制分支。
- 可使用边缘、姿态、深度等条件控制生成结果。
- 目标是在保留原模型生成能力的同时增强可控性。

### 5. 视频生成

- 视频相比图像多出时间维度，需要同时保证单帧质量和跨帧一致性。
- 可将 2D 卷积扩展为空间卷积与时间卷积，即 `(2+1)D` 处理。
- 视频扩散模型可插入时间注意力层，建模不同帧之间的关系。
- 常见思路包括级联生成、复用文本到图像模型、在隐空间生成视频。

### 6. 视频生成评价指标

- FID：评价生成图像与真实图像在特征分布上的差异，通常越低越好。
- CLIP Similarity：评价生成内容与文本提示的语义一致性，通常越高越好。
- FVD：同时评价视频语义质量和时序一致性，通常越低越好。
- Frame Consistency CLIP Score：评价不同视频帧之间的语义一致性。

## Lesson8：大语言模型

### 1. Tokenizer

- 将原始文本转换为 token 和整数 ID 序列。
- 常见粒度：word、character、subword。
- Subword 在词表规模和序列长度之间折中。
- 常见算法：BPE、Unigram、SentencePiece。

### 2. 自回归解码

- 根据已有 token 预测下一个 token。
- Causal Mask 防止当前位置看到未来 token。
- 贪心解码：每步选择概率最高的 token。
- Beam Search：保留若干高概率候选序列。
- Temperature：越低输出越稳定，越高随机性越强。
- Top-k：只从概率最高的 k 个 token 中采样。
- Top-p：从累计概率达到 p 的最小候选集合中采样。

### 3. LLM 训练流程

- Pretraining：用大规模文本学习通用语言表示和知识。
- SFT：使用有监督指令数据，让模型学会按要求回答。
- RLHF：使用人类偏好训练奖励模型，再优化语言模型，使输出与人类偏好对齐。
- Scaling Laws：模型性能与参数量、数据量和计算量之间存在经验幂律关系。

### 4. LLaMA 结构要点

- Decoder-only 架构。
- RMSNorm：相比 LayerNorm 计算更简化。
- RoPE：将位置信息加入 Q 和 K，表达相对位置关系。
- 自回归推理可以使用 KV Cache 复用历史 K、V。

### 5. 参数高效微调 PEFT

目标：冻结大部分预训练模型参数，只训练少量新增参数，以降低计算和存储成本。

#### LoRA

- LoRA 全称 Low-Rank Adaptation。
- 冻结原始权重矩阵 `W`。
- 用两个低秩可训练矩阵近似权重增量：

```text
W' = W + BA
```

- `A` 通常负责降维，`B` 负责升维，低秩 `r` 远小于原维度。
- 训练参数量小；推理前可将低秩增量合并到原权重中。

#### Adapter Tuning

- 在 Transformer 模块中插入小型可训练网络。
- 冻结主干，只训练 Adapter 参数。

#### Prompt/Prefix Tuning

- 将提示表示为可训练的连续向量，而不是完全依赖人工编写的离散文本提示。
- 冻结大模型主体，仅优化软提示参数。

### 6. 推理加速

- KV Cache：缓存历史 token 的 K、V，以空间换时间。
- MQA/GQA：让多个 Query Head 共享部分或全部 K、V，降低缓存开销。
- FlashAttention：减少注意力计算中的显存读写和中间矩阵存储。
- 投机采样：小模型先生成多个候选 token，大模型一次验证，提高生成速度。

### 7. MoE 与 RAG

#### MoE

- 使用多个专家子网络。
- 路由网络只为每个 token 激活少数专家，降低实际计算量。
- 需要注意专家负载均衡问题。

#### RAG

- 全称 Retrieval-Augmented Generation，检索增强生成。
- 基本流程：文档分块与向量化 → 根据问题检索相关文档 → 将检索内容加入 prompt → LLM 生成回答。
- 作用：补充外部知识、降低知识过时和幻觉问题。
