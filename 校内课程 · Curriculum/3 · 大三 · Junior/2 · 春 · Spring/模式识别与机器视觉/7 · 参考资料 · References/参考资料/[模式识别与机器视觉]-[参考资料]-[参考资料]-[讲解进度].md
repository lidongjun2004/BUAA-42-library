## 已讲考点（去年考点 + 这份 PDF 全部）

1. 贝叶斯决策：最小错误率 + 最小风险（损失表 / 条件风险 / 白血病反转 / 0-1 损失退化）
2. MLE：五步法 + 高斯/伯努利/指数/泊松/均匀计算 + 有偏无偏（ $n-1$）
3. SVM：间隔最大化 → 规范化 → 基本型 → 拉格朗日对偶 → KKT → 支持向量 → 软间隔
4. PCA：最大方差 / 最小误差 → 协方差特征值；附 LDA（Fisher）对比
5. K均值：准则 $J$ → 两步 EM → 算法步骤 → 与 GMM 关系 → 肘部法则
