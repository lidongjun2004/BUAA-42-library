## 一、任务说明

知识抽取作业：在简历领域中文 NER 数据集 **ResumeNER** 上，实现并训练一个
**BiLSTM + CRF** 的序列标注模型，识别简历文本中的命名实体。

标注体系为 **BIO**（`B-` 实体首字，`I-` 实体内部，`O` 非实体），共 **8 类实体**：

| 缩写 | 含义 | 缩写 | 含义 |
| --- | --- | --- | --- |
| NAME | 人名 | TITLE | 职称/头衔 |
| CONT | 国籍 | EDU | 学历 |
| RACE | 民族 | PRO | 专业 |
| LOC | 籍贯 | ORG | 机构/组织 |

加上 `O` 共 **17 个标签**。

## 二、数据集

数据位于 `data_ner/`，每行 `字 标签`，空行分句：

| 文件 | 句子数 | 字符数 |
| --- | ---: | ---: |
| `train.txt` | 3821 | 124,099 |
| `dev.txt` | 463 | 13,890 |
| `test.txt` | 477 | 15,100 |

## 三、模型方法

整体结构：**字向量 → 双向 LSTM → 线性层（发射分数）→ CRF（标签转移约束）**。

```text
                ┌─────────────┐
  字符 id  ───▶ │  Embedding  │  (vocab=1794, dim=128)
                └──────┬──────┘
                       ▼
                ┌─────────────┐
                │  BiLSTM     │  (hidden=256, 双向各 128)
                └──────┬──────┘
                       ▼
                ┌─────────────┐
                │  Linear     │  → 每个位置 17 个标签的发射分数 (emission)
                └──────┬──────┘
                       ▼
                ┌─────────────┐
                │   CRF       │  学习标签转移矩阵，约束如 "I-ORG 不能跟在 B-NAME 后"
                └──────┬──────┘
                       ▼
                Viterbi 解码 → 最优标签序列
```

**为什么要加 CRF？** 单独用 BiLSTM 对每个字独立分类，无法建模标签之间的依赖
（例如 `I-NAME` 不应出现在 `B-ORG` 之后）。CRF 在整句上做全局归一化，用一个
可学习的转移矩阵 `transitions[i,j]`（从标签 i 到 j 的分数）显式建模这种约束，
解码时用 Viterbi 求全局最优路径。

**训练目标**：最大化金标签路径的对数似然
`log P(y|x) = Score(x, y) − log Σ_{y'} exp(Score(x, y'))`，
其中配分函数（分母）用**前向算法**计算，损失取负对数似然。

CRF 层（前向算法 + Viterbi）为**手写实现**（见 `model.py` 中 `CRF` 类），不依赖第三方 CRF 库。

## 五、运行方式

依赖：`torch`、`numpy`、`seqeval`（项目根 `作业/.venv` 已装好）。

```bash
# 训练 + 评估（约 10 分钟，CPU）
python train.py

# 用训练好的模型做推理 demo
python predict.py --text "高勇：男，中国国籍，汉族，本科学历，工程师。"
```

主要超参（可用命令行覆盖）：`emb_dim=128, hidden_dim=256, lr=1e-3, batch_size=64, epochs=40, dropout=0.5`，优化器 Adam，梯度裁剪 5.0，依据 dev 集 F1 做早停并保存最优模型。

## 七、结果分析

- 整体 F1 **0.93**，对一个**字符级、未使用预训练词向量**的 BiLSTM-CRF 是很扎实的结果。
- `CONT/RACE/NAME` 等模式规整、上下文线索强的类别接近满分；
- `ORG`（机构名长、变化多）和 `PRO`（样本少，仅 33 条）相对偏低，是误差主要来源，符合预期；
- CRF 的转移约束有效保证了输出序列合法（极少出现 `O I-XXX` 这类非法跳转）。

可进一步提升的方向：引入预训练字向量 / BERT 编码器、加入字形或词典特征、对低频类别做数据增强。
