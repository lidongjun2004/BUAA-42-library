2 知识图谱数据模型
◼   RDF图
    ◆   一个RDF图定义为三元组( S,P,O )的有限集
    ◆   每个三元组代表一个陈述句，称为陈述
        （Statement）
    ◆   多个语句的集合称为描述（Decription）
    ◆   S-主语，P-谓语，O-宾语
    ◆   ( S,P,O )表示
        ◆   S与O间有P关系
        ◆   S具有P属性，属性值为O
2 知识图谱数据模型
◼   属性图 由节点集和边集组成，且满足如下性质
    ◆   每个节点具有唯一的id
    ◆   每个节点具有若干条出边
    ◆   每个节点具有若干条入边
    ◆   每个节点具有一组属性，每个属性是一个键值对
    ◆   每条边具有唯一的id
    ◆   每条边具有一个头节点
    ◆   每条边具有一个尾节点
    ◆   每条边具有一个标签，表示联系
    ◆   每条边具有一组属性，每个属性是一个键值对

3 知识图谱查询语言
◼   Cypher基本语法
    ◆ 节点
    (variable:Label {propertyKey: ‘propertyValue’})
       ⚫   （）
       ⚫   ：Label
       ⚫   { propertykey: ‘value’}

    ◆ 关系
    (node1:LabelA)-[rel1:RELATIONSHIP_TYPE]->(node2:LabelB)
       ⚫   有向关系：-[]-> , <-[]-； 无向关系: –[]-
       ⚫   ：Label
       ⚫   { propertykey: ‘value’}
3 知识图谱查询语言
◼   Cypher基本语法
    ◆ Match all nodes
     MATCH (n) RETURN n
    ◆ Match nodes by label
     MATCH (a:Person) RETURN a
    ◆ Match nodes by label and property
     MATCH (a:Person {name:“Théo Gauchoux"}） RETURN a
3 知识图谱查询语言
◼   Cypher基本语法
    ◆ Match   nodes according to relationships
      MATCH (a)-[:KNOWS]-(b) RETURN a,b

    ◆ Match nodes with a WHERE clause
     MATCH (p:Person {name:“Alice"})
     -[s:LIVES_IN]->(city:City)
     WHERE s.since = 2015 RETURN p,city


     WHERE中的条件可精炼查询结果
3 知识图谱查询语言
◼   Cypher查询
    汤姆汉克斯（Tom Hanks）2000年之前演过的电影
    match (actor:Person )-[:ACTED_IN]->(movie:Movie)
    where actor.name = "Tom Hanks" and movie.released < 2000
    return movie,actor
    ◆   (演员)-[:ACTED_IN]->(电影)
    ◆   movie.released 电影的年份属性
    ◆   2000年之前的电影 movie.released < 2000

4 常见知识图谱存储方法
◼   基于关系型数据库的存储方案
    ◆   三元组表
        ⚫   缺点：大量自连接性能低下
        找“某人朋友所在公司的位置”
        等价逻辑：A --friendOf--> B --worksAt--> C --locatedIn--> D
        SELECT t3.o                     所有 JOIN 都是在同一张表上进行的
        FROM Triple t1                  （self-join）
        JOIN Triple t2 ON t1.o = t2.s   一个长度为 k 的路径需要 k 次 self-join
        JOIN Triple t3 ON t2.o = t3.s   复杂查询：
        WHERE t1.s = 'A'                • 5跳路径 → 5个JOIN
         AND t1.p = 'friendOf'
                                        • 图模式匹配 → 指数级组合
         AND t2.p = 'worksAt'
                                        如果：表大小 = N ，JOIN次数 = k
         AND t3.p = 'locatedIn';
                                        复杂度：O(N^k)
