## 开始前需要什么

这篇从第一次接触 C 程序开始。需要用到中学的加减乘除、大小比较，以及“某个条件成立或不成立”的认识。程序中有些符号看起来像数学符号，意思却不同，正文会逐个区分。

动手运行示例时，需要一个能编辑、编译和运行 C 程序的环境。

+ 编辑是写下并保存代码
+ 编译是让编译器检查代码，并把它变成计算机能够执行的形式
+ 运行是实际执行生成的程序。
+ 修改代码后，要重新编译，再运行新生成的程序。
  + 这就是为什么上机课时助教要求你点击“编译运行”。只点击“运行”可能会执行之前编译出的程序。

读完后，你应能按顺序说明变量的值如何改变，写出读入两个数并计算的程序，并使用条件和循环完成简单统计。

## 1. 从屏幕上出现一句话开始

### 1.1 先找到真正负责输出的一句

假设我们希望程序在屏幕上显示 `Hello, world!`。下面是一份完整的、可编译运行的程序，保存在一个 `.c` 文件里，例如 `hello.c`。先看整体，本节逐步解释每一部分。

```c
#include <stdio.h>

int main() {
    printf("Hello, world!\n");
    return 0;
}
```

程序输出为：

```text
Hello, world!
```

真正要求程序输出的是这一句：

```c
printf("Hello, world!\n");
```

`printf` 是 C 标准库提供的输出工具。标准库可以先理解为 C 环境为我们准备的一组常用功能。像 `printf` 这样有名字、可以要求它完成工作的功能，叫作**函数**（function），可以大致理解为一段有名字、可以被调用来完成某件事的代码。

写下函数名，再用小括号装入这次要交给它的信息，就是一次**函数调用**，意思是“现在请这个功能工作”。把这一句拆开读：

+ `printf` 请输出工具工作，大小写必须照写。这个名字是 print 和 format 的组合。
+ `(` 和 `)` 把这次交给 `printf` 的信息放在里面。
+ `"Hello, world!\n"` 要输出的文字和换行要求。
+ `;` 结束这一条指令。这样的指令称为**语句**。

双引号把一段文字括起来，这样的文字称为**字符串**。双引号在 C 语言中表示“这里是一段文字”，双引号是用来包住字符串的符号，不是字符串内容的一部分。

`\n` 由反斜杠 `\` 和字母 `n` 写成，用来表示一个换行字符。用反斜杠开头表示这类特殊字符的写法，叫作**转义字符**。这里输出的是一个换行，不是两个可见字符 `\` 和 `n`。

把原来的输出语句换成：

```c
printf("Hello!\n");
printf("C!\n");
```

程序先执行第一句，再执行第二句，输出为：

```text
Hello!
C!
```

如果第一句改为 `printf("Hello!");` 结果就是在同一行内输出 `Hello!C!`。源代码分成两行书写，不等于输出自动分行。输出的换行由 `\n` 字符控制。

### 1.2 为什么开头要有头文件

我们写下 `printf("Hello, world!\n");`，是在使用一个已经准备好的函数。编译器处理这句代码时，也需要有关于 `printf` 的说明，例如调用 `printf` 时需要交给它什么信息。程序开头的这一行把所需的说明包含进来，注意这一行最后没有分号：

```c
#include <stdio.h>
```

`stdio.h` 是一个文件的名字，这类供其他代码包含使用的文件叫作**头文件**。`#include` 要求在编译器处理你写的这份代码时，把指定的头文件的内容包含进来，`<` 和 `>` 在这里用于围住头文件名。

`stdio.h` 提供了使用 `printf` 所需的说明。至于 `printf` 里面具体怎样完成输出，C 标准库已经提供了相应的代码，我们不需要自己再写一份。

如果好奇里面的代码是什么样子，可以看看下面这个例子。这是一种环境中写在头文件里的 `printf` 代码，其他环境的头文件不一定采用这个写法。这段只供看一眼，不要复制进自己的程序，也不需要现在读懂其中的内容：

```c
__mingw_ovr
__MINGW_GNU_PRINTF(1, 2) __MINGW_ATTRIB_NONNULL(1)
int printf (const char *__format, ...)
{
  int __retval;
  __builtin_va_list __local_argv; __builtin_va_start( __local_argv, __format );
  __retval = __mingw_vfprintf( stdout, __format, __local_argv );
  __builtin_va_end( __local_argv );
  return __retval;
}
```

看不懂是非常正常的，放轻松（其实助教也看不懂）。虽然我们现在还看不懂这段代码，却已经知道怎样让 `printf` 输出一句话了。你可以修改双引号里的文字，可以用 `\n` 表示换行，然后运行程序，看看结果。这些事情都不需要你先弄明白 `printf` 里面发生了什么。

请注意：**知道怎样使用一个东西，和知道它里面怎样工作，是两件可以分开学习的事。**

比如学开车时，我们先学怎样转向、加速、刹车，不会要求先学会造发动机。发动机当然不是不重要，只是它可以由另外一些人负责研究和制造。驾驶员按照学过的操作方法开车，就可以使用他们造好的东西。

我很想在这里多说几句，因为这个道理远不止适用于 `printf`。你现在看到的一次屏幕输出，背后还有许多程序和硬件在一起工作。如果每做一件事，都必须先把背后的全部原理弄懂，那我们可能很久都写不出第一行程序。

好在我们可以一部分一部分地理解它。先知道某个功能能做什么、怎样使用，就能拿它继续做新的事情；等有了更多知识，或者真的好奇起来，再打开其中一部分，看看它是怎样做到的。那里面可能还用到了别的功能，也没有关系，我们可以继续往下追。

暂时只看怎样使用，不展开里面的做法，这就是把它当作一个“黑盒”。可以想象一个看不见内部的盒子：我们知道交给它什么、它会完成什么，却不看里面怎样完成。这里的盒子是个比喻，比如 `printf` 就可以是这样的黑盒。**黑盒不是不许打开的盒子，只是现在还没有打开而已。** 今天你用别人写好的 `printf`，以后你也会写出自己的函数，让别人不必读完里面的每一行，就能使用你写的函数。

### 1.3 这个代码框架是什么情况

`main` 其实也是一个函数，不过它的内容由我们来写。运行一个 C 语言程序时，一定会从 `main` 函数开始执行。再看前面程序中的这一部分：

```c
int main() {
    printf("Hello, world!\n");
    return 0;
}
```

`{` 和 `}` 一般叫大括号。一对大括号用于把一组代码包成一个整体，称为**代码块**。大括号可以嵌套。这里的代码块就是 `main` 的内容：先执行 `printf` 输出问候语；再执行 `return 0;` 结束 `main` 函数。

`return 0;` 里的 0 是交给运行环境（例如操作系统）的结果，表示程序正常结束。它一般来说不会显示在屏幕上，但是 Dev C++ 等会额外显示出来。开头的 `int` 表示这个函数结束时交回一个整数，末尾的 `return 0;` 就交回了整数 0。

再看 `main` 后面的 `()`。定义函数时，函数名后要写小括号；如果这个函数需要接收外面交来的信息，就在这里说明。目前我们的 `main` 函数不接收这样的信息，所以括号里留空，但括号不能省略。

现在要让程序多输出一句话，就把新的 `printf` 语句写在这对大括号内、`return 0;` 之前。执行到 `return`，这个程序就结束了，写在它后面的输出语句不会再执行。

### 1.4 半角字符？全角字符？

代码中的括号、双引号、逗号和分号使用英文半角符号。中文输入法中的 `“ ”`、`（ ）`、`；` 不能代替代码里的 `"`、`()`、`;`。

### 1.5 助教为什么看不懂我的代码？

## 2. 变量

### 2.1 变量到底是什么情况

我们用一个简单的例子来说明都发生了些什么。

```c
#include <stdio.h>

int main() {
    int a;
    scanf("%d", &a);
    a = a + 1;
    printf("%d", a);
    return 0;
}
```

首先第一句 `int a;` 我们称为对变量 `a` 的定义。变量必须要先被定义出来然后才能使用。

你可以把变量想象成一个小盒子，这个小盒子能且仅能且必须装有一个数字。当你定义一个变量 `a` 的时候，创造了一个小盒子出来，这个小盒子对应的就是变量 `a`。盒子里面必须有一个数字，所以即使是刚定义，这个小盒子里面也不是空的。里面会有一个数字，这个数字我们不知道是什么。你可以用这个数字参与运算或者把它输出，但是这一切都没有意义，因为这个未知的数字本身就没有意义。更明确的说法是：大多数时候你**可以**使用还没有被赋值的变量，但是绝对**不应该**这么做。

当程序运行到 `scanf("%d", &a);` 时，事情变得有趣了起来。`scanf` 也是一个函数，用来读入数据。这里我们传递进去了两个参数：第一个是字符串 `"%d"`，第二个参数是在 `a` 前面加了一个 `&` 符号代表 `a` 的地址。第一个参数代表着我们想要读入一个整数，于是 `scanf` 忠实地执行了要求，读入了一个整数。但是总不能读进来还没用就立刻扔掉吧？所以要找一个地方把刚刚读进来的数值存储起来，`scanf` 自然就需要你来告诉它把数值存到哪里，于是你把对应着 `a` 的那个小盒子的地址作为第二个参数提供给了 `scanf`。它一看，要存储到这个地方，于是就把读入的数值放进了小盒里。`scanf` 其实不知道变量 `a`，但是不影响它完成任务，毕竟你对它的要求就是“读进来一个整数，存储到**那个地方**”。

刚刚提到过，由于小盒能且仅能装一个数字，所以 `scanf` 这句结束后，小盒里之前的旧数字就直接消失了。

我们已经讲解了 `&a` 代表的是 `a` 对应的小盒的位置，那么单独写出一个 `a` 时它代表的是什么呢？它代表的是 `a` 对应的那个小盒里装着的数值。注意这是一个数值，你用一个数值参与运算并不会导致数值本身发生变化。就像是，你的答题卡上有某个未知数值 $x$，不会因为你写了个 $2x + 3$ 的代数式就导致 $x$ 的值发生了变化。

接下来会用到“表达式”这个词。在正式讲它之前，先按照你熟悉的代数式来理解：把字母换成变量当前的数值，再算出结果。例如 `a + 1`，在 `a` 当前为 5 时就是 `5 + 1`。单独一个数或变量名，例如 `5`、`a`，也可以是表达式。

下面一句，`a = a + 1;` 看起来很奇怪。这里的等号和数学上的相等符号完全不是一个意思。C 语言中这个符号的意思是赋值，一般我们形式化写成 $a \leftarrow a + 1$ 。对于赋值符号，首先计算机把右边的表达式算出结果，得到结果后，再把结果数字存储到左边的那个变量对应的小盒子里面。例如，`scanf` 读入了数字 5 之后，`a` 对应的小盒里面装的数字是 5。`a = a + 1;` 这句的操作过程是：首先算出右边 `a + 1` 的值，得到 6。此时 `a` 的小盒里装的依然是 5。然后赋值操作发生，把算出来的数字 6 存储到 `a` 对应的小盒子里面，从此 `a` 的值才变成 6。

最后，`printf("%d", a);` 把变量 `a` 的值打印了出来。`"%d"` 依然代表这里我们想要输出一个整数。这个整数是多少呢？我们直接把它的数值提供给了 `printf`，于是 `a` 的数值就被打印了出来。

你当然还可以写 `printf("%d", a * 2);` 这样的语句，因为不管是 `a` 还是 `a * a` 还是 `a * 2` 都是一个关于 `a` 的表达式，而每个表达式都有一个数值，提供给 `printf` 的恰恰就是这个数值。

此时可能就有人要问，`printf` 为什么不像 `scanf` 那样，也由我来提供一个小盒地址，然后它自己去那个地方去看看数值呢？也许上面的这一段可以解答你的疑问：`printf("%d", a * 2);` 时，`a * 2` 没有被保存在任何一个变量里，但是它依然是一个可以被提供给 `printf` 的数值。

### 2.2 不用 scanf 怎么给变量一个值

前面是通过 `scanf` 把输入的数存进 `a`。如果我们已经知道要存什么数，直接写出来就行。把前面 `main` 里的几句换成：

```c
int a = 5;
a = a + 1;
printf("%d", a);
return 0;
```

`int a = 5;` 做了两件事：定义变量 `a`，并让它从一开始就存着 5。这叫作**初始化**。接下来加一，`a` 变成 6，最后输出 6，整个过程都不需要键盘输入。

也可以把第一句拆成两句：

```c
int a;
a = 5;
```

第一句准备盒子。第二句求出右侧表达式 5 的值，再把这个值存入 `a`。执行完这两句之后，表达式 `a` 的值就是 5。

这里要分清 `int a = 5;` 和 `a = 5;`：前一句定义变量并给初始值，后一句给已经有的变量赋值。已经定义过 `a`，再修改它就不用加 `int` 了。在同一个代码块里又写一遍 `int a`，也不能得到“另一个同名盒子”，编译器会报重复定义的错误。

如果接着再改几次呢？看下面这几句的执行过程：

```c
int a = 5;
a = a + 1;
a = a * 2;
printf("%d", a);
```

执行 `a = a + 1;` 时，右侧表达式 `a + 1` 的值是 6，赋值后 `a` 变成 6。下一句求右侧表达式 `a * 2` 的值，得到 12，再把结果存入 `a`。因此输出的是 12。每一句都用变量当时的值求右侧表达式的值，不会因为最初写了 5，就一直拿 5 来计算。

### 2.3 b = a 后，两个变量会一起变吗

单独的 `a` 也是表达式，它的值就是 `a` 当前存着的数。因此，`b = a;` 和 `b = a + 1;` 按同一条规则执行：先求出右边表达式的值，再存进左边的变量。比如 `a` 是 3，前一句往 `b` 里存 3，后一句往 `b` 里存 4。

那么，执行 `b = a;` 后再修改 `a`，`b` 会跟着变吗？

```c
int a = 3;
int b = 0;
b = a;
a = 8;
printf("%d %d\n", a, b);
```

依然按照盒子模型去模拟一下。前两句准备了两个盒子：`a` 里是 3，`b` 里是 0。到了 `b = a;`，先求右侧表达式 `a` 的值，结果是 3，再把结果存入左侧变量 `b`。所以这句执行完，两个盒子里都是 3。

赋值存入的是表达式的求值结果，求值本身没有修改 `a`。两个盒子仍然是各自独立的，只是此时存着相同的数。

下一句 `a = 8;` 把右侧表达式 8 的求值结果存入 `a`。`b` 没有被修改，里面仍是 3。

最后的 `printf` 有两个 `%d`，分别对应后面的 `a` 和 `b`。中间的空格会照样输出，所以屏幕上显示 `8 3`，然后换行。

### 2.4 怎么交换两个变量里的数

有了两个盒子，就可以试着交换里面的数。比如，`a` 原来是 3，`b` 原来是 8，我们想让它们变成 8 和 3。

**练习：** 下面这样写能完成交换吗？如果不能，怎样才能？

```c
int a = 3;
int b = 8;
a = b;
b = a;
```

**答案与解释：**

先执行 `a = b;`，右侧表达式 `b` 的值是 8，把结果存入 `a`。这时两个盒子里都是 8，`a` 原来的 3 已经被覆盖了。

再执行 `b = a;`，右侧表达式 `a` 此时的值也是 8，把结果存入 `b`。因此两句执行完，`a`、`b` 都是 8，并没有交换成功。

问题就出在那个 3 丢得太早了。既然后面还要用它，就得在覆盖之前先找个地方保存。我们可以多准备一个变量：

```c
int a = 3;
int b = 8;
int temp = a;
a = b;
b = temp;
```

`temp` 是新变量的名字，取“临时保存”的意思。`int temp = a;` 用表达式 `a` 的值 3 初始化 `temp`。接着 `a = b;` 求出右侧表达式 `b` 的值 8，存入 `a`；`temp` 仍是 3。最后 `b = temp;` 求出右侧表达式 `temp` 的值 3，存入 `b`，就得到了我们想要的 `a` 为 8、`b` 为 3。

这种“先留一份再覆盖”的想法不只用来交换。只要后面还需要某个旧值，就要想一想：我把它改掉以后，还能从哪里找到它？

对变量的不当修改会导致很多可能的 bug。比如有两个变量 `L` 和 `R`，约定 $L<R$，后面所有的代码都一直按照 $L<R$ 来处理，若某些修改打破了这个约定，后续的代码又没有放弃这个约定，就会出问题。这也是为什么有些编程语言会默认不允许修改变量的值：希望你在修改之前，多考虑一下它会影响什么。

### 2.5 变量名怎么取

上一节出现了 `temp` 变量，变量的名字都是我们自己取的，C 语言有没有什么限制？

变量名称可以包含英文字母、数字和下划线 `_`。C 语言要求取名时以字母或者下划线开头，例如 `count`、`score2`、`student_count`、`__my_hash`。数字不能在最前面，所以 `2score` 不行；名字中也不能加空格或减号，`student count`、`student-count` 都不能当作一个变量名。

不过，符合上面的拼写规则，还不代表这个名字就留给我们使用。**自己取的变量名强烈不建议以下划线开头**，因为其中一些名字留给了编译器和标准库。一般来说，以两个下划线开头，就属于这类保留的名字，不要拿来定义自己的变量。

大小写有区别。`count` 和 `Count` 是两个不同的名字，写错大小写并不是“差不多也能认出来”。

还有一些词已经有特定用途，叫作**关键字**，例如 `int`、`return`，不能拿来给变量取名。也不要占用 `printf`、`scanf` 这些已有函数的名字。

至于叫什么更好，要看你在写什么。一个很短的算式可能用 `a`、`b` 就够了，如果算式是 $F = ma$ 就建议使用 `F`、`m`、`a` 做变量名；需要记数量时，可以用 `count`，记总和可以用 `sum`。过几天再看自己的代码，还知道每个变量存的是什么，这个名字就帮上忙了。

### 2.6 盒子模型在计算机里是什么

前面的小盒子，对应的是程序运行时用来存数据的一块空间。这些数据存放在**内存**（memory）里。变量的名字是我们写代码时用来指明它的，地址则用来指出它在内存里的位置。

比如，执行 `a = 8;`，是在 `a` 原来的位置写入 8。这次赋值没有给变量改名字，也没有把它搬到别处，改变的是那块空间里的内容。

不过，计算机并不是直接把我们纸上写的数字塞进内存。它用只能取 0 或 1 的小单位记录数据，一个这样的单位叫作**位**（bit）。一个位只有两种可能；两个位就有 `00`、`01`、`10`、`11` 四种组合。把更多位放在一起，就能区分更多数值。

用哪种组合表示哪个数，要有一套约定，这套规则叫作**编码**。所以我们说“盒子里存着 5”，实际上是盒子里的这些位按约定记录了整数 5。

若干个位组成一个**字节**，常见电脑上的一个字节是 8 位。一个 `int` 常见会占 4 字节，也就是用 32 位共同保存一个整数；把它画成一个盒子，是把这一整块空间放在一起看。

能用的位数有限，组合就有限：32 位一共有 $2^{32}$ 种不同的位组合，所以 32 位的 `int` 也不能装下任意大的整数。接下来讲不同类型时，这就是我们需要考虑的事情之一。

## 3. 类型：同样是存数，规则可以不同

### 3.1 类型规定怎样保存和使用值

变量的**类型**规定它能保存哪些值、占用多少空间，以及怎样参与运算。32 位的 `int` 可以保存 $[-2^{31},2^{31}-1]$ 内的整数；需要保存小数时，我们一般使用 `double`。

例如，分别定义一个整数变量和一个浮点数变量：

```c
int count = 3;
double weight = 0.75;
```

`double` 是一种用于表示浮点数的类型。**浮点数**可以先理解为用有限空间表示一定范围、一定精度的数的办法，能表示许多带小数部分的数。它也能表示 `3.0` 这样的整数值。

定义后的 `count` 是 `int`，`weight` 是 `double`。后来换一个数值，不会顺便把变量类型也换掉。

### 3.2 `int`、`long long`、`float` 和 `double`

| 类型 | 保存什么 | 定义示例 |
| --- | --- | --- |
| `int` | 整数 | `int count = 3;` |
| `long long` | 整数，通常比 `int` 的范围大 | `long long sum = 0;` |
| `float` | 浮点数 | `float weight = 0.75;` |
| `double` | 浮点数，通常比 `float` 精度高 | `double weight = 0.75;` |

记录数量、编号时可以用 `int`；整数较大、`int` 装不下时，可以用 `long long`（但 long long 一般也只有 64 位，依然不是无限）；需要小数时，可以用 `double`。

常见环境里 `int`、`long long`、`float`、`double` 分别占 4、8、4、8 字节。

`long long` 中间有一个空格，两个单词合起来是一个类型名。例如，要保存三十亿，可以在 `main` 里写：

```c
long long count = 3000000000;
```

常见的 4 字节 `int` 最大只能保存 2147483647，装不下三十亿；`long long` 可以。它仍然保存整数，只是能表示的范围更大，并不是用来保存小数的。

运算结果超出类型能表示的范围，叫作**溢出**。使用 `int` 计算时，要让中间结果和最终结果都在它能表示的范围内。例如，求许多数的总和时，除了看每个数有多大，还要看加起来有多大。

### 3.3 统一看整数和浮点数

两者都要把数变成位的组合，存进有限空间，再按规定解释这些位。

可以按三个问题认识一种数值类型：

1. 用多少空间保存？
2. 哪些数能够表示，范围有多大？
3. 在范围内，哪些值能够精确表示，相邻可表示的值隔多远？

整数类型在可表示范围内，能够逐个精确表示整数，例如 3、4、5。它并没有为 3.5 这样的值提供一个整数位置。

浮点数的常见表示方法类似科学计数法：用一部分信息记录有效数字，用另一部分记录数的尺度。例如，十进制的 $1.25 \times 10^2$ 表示 125；常见计算机浮点表示采用相应的二进制规则。

常见的 64 位 `double`，能表示的最小有限值约为 $-1.79769 \times 10^{308}$，最大有限值约为 $1.79769 \times 10^{308}$。但 64 个位最多只有 $2^{64}$ 种组合，也就是说，能表示的不同数值最多只有 $2^{64}$ 个。这么大的范围里有无穷多个实数，有限种组合不可能一一表示它们，只能选取其中一些数，其余的用接近的数来表示。这就是精度限制的来由。设计上，这些数整体上离零越近分布越密，能区分的数值差别也越小。

**占多少空间和怎样解释这些空间，是两件事。** 常见环境中，整数类型 `int` 和浮点数类型 `float` 都可能占 4 字节，但它们使用不同的编码规则。

回想前面的 `printf("%d", a);` 和 `scanf("%d", &a);`：我们除了提供数值或地址，还写了 `%d`，告诉函数这里要输出或读入一个 `int` 整数。换成 `long long`，输入和输出都用 `%lld`。例如，定义 `long long a;` 后，读入写 `scanf("%lld", &a);`，输出写 `printf("%lld", a);`。

处理浮点数时，也要用对应的格式：输出用 `%f`，读入 `float` 用 `%f`，读入 `double` 用 `%lf`。尤其是输入，光有地址还不够，`scanf` 还得知道按哪种规则把数写进去。两个变量即使占同样多的字节，也不能因此混用输入格式。

### 3.4 小数不是“想写多精确就能多精确”

十进制里， $\frac{1}{3}$ 不能写成有限位小数；在常见二进制浮点表示里，十进制的 $0.1$ 也不能被精确表示，只能保存一个接近的值。

因此，在常见二进制浮点表示中，`double price = 0.1;` 保存的是接近十分之一的一个值。

通常 `double` 比 `float` 能保存更多有效数字，但 `double` 仍有范围和精度限制。

### 3.5 把值存入另一种类型时会怎样

把一种类型的值按另一种类型表示，叫作**类型转换**。例如：

```c
int count = 3.9;
double value = 3;
```

第一句要存入 `int`，小数部分被去掉，`count` 得到 3，不是四舍五入得到 4。第二句让 `double` 保存整数值 3，之后可以按浮点格式输出。

负数也是去掉小数部分，例如把 -3.9 存入 `int` 得到 -3，不是 -4。如果去掉小数部分后仍超出目标整数类型的范围，就不能按这个例子安全转换。

请抓住两点：转换的是准备存入的值；变量本身的类型仍是定义时的类型。

**练习：** 执行 `int a = 4.8; double b = a;` 后，`a` 和 `b` 的数值各是多少？`b` 能把已经丢掉的 `.8` 找回来吗？

**答案与解释：**

`a` 为 4，`b` 保存的数值也是 4。第一句存入 `int` 时已经去掉小数部分，第二句只读取此时 `a` 中的整数 4。`double` 有能力表示许多小数，不代表它能猜回原来被丢掉的小数部分。

## 4. 输入与输出

### 4.1 把数值放进要输出的文字里

输出不一定只有一个数，也可以把文字和数值放在一起。例如：

```c
int count = 3;
printf("count = %d\n", count);
```

输出为：

```text
count = 3
```

第一个字符串规定了输出怎么排列，叫作**格式字符串**。里面的 `count =` 是照样输出的文字，`%d` 这个位置放后面提供的整数，`\n` 要求换行。`%d` 这样的写法叫作**格式说明符**。

注意，字符串里的 `count` 和后面的变量 `count` 不是一回事。即使把字符串里的文字改成 `number =`，后面仍然可以用 `count` 提供数值。如果只写 `printf("count");`，输出的就是字母组成的 `count`，不会替你查找同名变量。

要输出多个数，就按顺序给出多个位置：

```c
int a = 3;
int b = 8;
printf("a = %d, b = %d\n", a, b);
```

第一个 `%d` 对应 `a`，第二个对应 `b`，所以输出 `a = 3, b = 8` 后换行。双引号里面的逗号是要显示的文字，外面的逗号则用来分开参数。

### 4.2 控制显示的样子

`%f` 默认显示小数点后六位。比如 `1.2` 会显示成 `1.200000`。如果想只显示两位，可以在 `%` 和 `f` 中间写上 `.2`：

```c
double weight = 1.2;
printf("%.2f\n", weight);
```

输出 `1.20` 后换行。小数位不足会补零，多了则会舍入到指定的位数。这只改变显示的样子，不会把 `weight` 里面的值也改掉。

还有两种写法可以用来排版：

| 写法 | 用途 |
| --- | --- |
| `%4d` | 整数至少占四个字符的位置，不足时在左边补空格 |
| `%%` | 输出一个百分号，不需要为它再提供一个数值 |

例如：

```c
int count = 7;
printf("[%4d]\n", count);
printf("100%%\n");
```

输出为：

```text
[   7]
100%
```

这里特意加上方括号，是为了看清 7 前面补了三个空格。如果数本身已经有五位，`%4d` 就让它占五位，不会把数字截掉。

### 4.3 一次读入多个数

如果要读两个整数，一个存进 `a`，另一个存进 `b`，就给 `scanf` 两个 `%d`，再按顺序提供两个变量的地址：

```c
#include<stdio.h>

int main() {
    int a;
    int b;
    scanf("%d %d", &a, &b);
    printf("%d %d\n", a, b);
    return 0;
}
```

运行时输入：

```text
3 8
```

`scanf` 先按第一个 `%d` 读到 3，存到第一个地址 `&a` 指定的位置；再按第二个 `%d` 读到 8，存到 `&b` 指定的位置。于是 `a` 是 3，`b` 是 8，后面的 `printf` 输出：

```text
3 8
```

这里是按位置一一对应的：第一个 `%d` 对应第一个地址，第二个 `%d` 对应第二个地址。假如把后面的地址顺序改成 `&b, &a`，输入仍是 `3 8`，那就会往 `b` 里存 3、往 `a` 里存 8。

写成 `scanf("%d%d", &b, &a);` 也可以读入 `3 8`：第一个 `%d` 读到 3，存进 `b`；第二个 `%d` 会跳过输入中的空格，再读到 8，存进 `a`。格式字符串里没有空格，不代表输入中不能有空格。反过来，如果输入 38，第一个 `%d` 会把它整个读成整数 38，然后等着你输入第二个整数，不会因为格式里有两个 `%d` 就自动拆成 3 和 8。

这一次读两个数，也可以拆成两次读。把程序里的那句 `scanf` 换成：

```c
scanf("%d", &a);
scanf("%d", &b);
```

输入同样的 `3 8`，结果不变。第一次读走 3，第二次接着读到 8。

这两种写法都不要求输入的两个数必须在同一行。你可以输入 `3 8` 后按回车，也可以输入 3 后按回车，再输入 8。读下一个整数时，`%d` 会跳过前面的空格和换行，直到遇到要读的数。

### 4.4 不同类型可以一起读

前面用过的输入、输出格式放在一起是这样：

| 变量类型 | 输入格式 | 输出格式 |
| --- | --- | --- |
| `int` | `%d` | `%d` |
| `long long` | `%lld` | `%lld` |
| `float` | `%f` | `%f` |
| `double` | `%lf` | `%f` |

例如，同时读一个很大的整数和一个小数，可以写成：

```c
#include<stdio.h>

int main() {
    long long count;
    double weight;
    scanf("%lld %lf", &count, &weight);
    printf("%lld %.2f\n", count, weight);
    return 0;
}
```

输入为：

```text
3000000000 1.2
```

输出为：

```text
3000000000 1.20
```

`%lld` 对应 `count`，`%lf` 对应 `weight`。输出时仍按相同顺序提供数值，只是把 `weight` 的显示方式设成了两位小数。

格式要跟类型相配。把 `double` 的输出写成 `%d`，并不会替你把小数转换成整数，而是用错了格式。另一个容易看错的地方是字母：`%lf` 里有一个小写 `l`，`%lld` 里有两个。

## 5. 运算：先得到一个值，再决定存在哪里

我们终于要涉及一直憋着没讲的领域：表达式了。前面先借用了你熟悉的代数式来理解它：取变量当前的值，算出一个结果。这个办法能帮助我们理解前面的加法和乘法，但 C 的表达式还可以表示比较、赋值等操作。接下来就逐步看看它们与数学里的写法有哪些区别。

在开始之前，有一点需要尤其强调：表达式一般来说都有一个具体的值，这个值也有类型，可能是 `int`，也可能是 `double` 等等。求出一个表达式的值，不代表要把这个值存回某个变量。例如，`a + b` 得到两者的和，但不会因此修改 `a` 或 `b`。

### 5.1 把熟悉的算式写成 C

表示计算或其他操作的符号叫作**运算符**。例如，`+` 计算两边数值的和；要保存结果，再用 `=` 赋值。

```c
int a = 3;
int b = 8;
int sum = 0;
sum = a + b;
```

执行最后一句时，先求右侧表达式 `a + b` 的值。此时 `a` 是 3，`b` 是 8，所以结果是 11；再把结果存入左侧变量 `sum`。`a`、`b` 当然没有因此改变。

下面介绍加减乘除运算符：

| C 写法 | 含义 | 小例子及结果 |
| --- | --- | --- |
| `+` | 加 | `3 + 8` 得 11 |
| `-` | 减 | `3 - 8` 得 -5 |
| `*` | 乘 | `3 * 8` 得 24 |
| `/` | 除 | `8 / 3` 得整数 2 |
| `%` | 求整数除法的余数 | `8 % 3` 得 2 |

乘法必须写 `*`，不能把数学的 $2x$ 原样放进代码，要写 `2 * x`。算平方可以写 `x * x`。

`-` 还可以放在一个数前面表示取相反数，例如 `-a`。例如 `a` 是 3 时，`-a` 得到 -3，但表达式 `-a` 不会把 `a` 改成 -3，这是我们一直在强调的。

### 5.2 除法有些特殊

在 C 中，两个整数相除，得到的仍是整数结果，小数部分被去掉。例如 `7 / 2` 得 3。

```c
double first = 7 / 2;
double second = 7.0 / 2;
printf("%.1f %.1f\n", first, second);
```

`%.1f` 与 `%.2f` 的规则相同，只是改成显示一位小数。输出为：

```text
3.0 3.5
```

第一句先算整数除法 `7 / 2`，得到 3，再转换成 `double` 保存。左边用了 `double`，不能倒过来改变已经完成的整数除法。

第二句中的 `7.0` 是一个 `double` 值。小数点使这个写法与整数 7 的类型不同；由于发生了一个 `double` 和一个 `int` 做除法，那个整数会被转换成 `double` 类型后参与除法，得到 3.5。

所以想计算两个整数的平均值，可以这样写：

```c
double average = (a + b) / 2.0;
```

先算括号里的整数和，得到一个 `int` 类型的结果，再除以 `2.0`，进行浮点除法。

### 5.3 余数可以回答什么问题

若有 8 个苹果，每 3 个装一袋，`8 / 3` 告诉我们能装满 2 袋，`8 % 3` 告诉我们还剩 2 个。对这里的非负整数与正除数，有：

$$
8 = 2 \times 3 + 2
$$

也就是：原数量等于完整袋数乘以每袋数量，再加上剩余数量。

`%` 在 C 表达式中表示求余。例如，对非负整数 `n`，`n % 2` 为 0 就表示它能被 2 整除。

`%` 的两边必须是整数，不能写 `3.5 % 2`。做除法和求余时，先确认除数不为 0。

**练习：** 已知 $x$ 是非负整数，如何把 $x$ 分钟转化为 $h$ 小时 $m$ 分钟的形式？

**答案与解释：**

`x / 60` 得到 `h`，`x % 60` 得到 `m`。由于余数的机制，分钟数 $m$ 一定在 $[0,59]$ 之内，这与我们的习惯是相符合的。

### 5.4 先算谁：优先级和小括号

在 C 表达式 `2 + 3 * 4` 中，先乘后加，得到 14。这类规定不同运算怎样组合的规则叫作**优先级**。

用小括号可以明确把哪部分作为一个整体：`(2 + 3) * 4` 先得到括号内的 5，最终得 20。同一级别的普通加减按从左向右组合，`10 - 3 - 2` 相当于 `(10 - 3) - 2`，得 5。

小括号要放在真正需要的位置。计算两个数的平均值：

+ `(a + b) / 2.0`：先求两个数的和，再除以二。
+ `a + b / 2.0`：先把 `b` 除以二，再加 `a`。

若 `a` 为 4、`b` 为 8，前者得 6，后者得 8，它们不是同一件事。

写较长的算式，或者拿不准优先级时，最好用小括号直接标明哪些部分要合在一起计算。

### 5.5 复合赋值、自增与自减

再介绍几个运算符。依旧是加减乘除，但是有几个功能实在是太常用了，所以 C 语言提供了更方便的写法。

比如下面两句，`a`、`b` 是已经有值的整数变量：

```c
a = a + 10;
b = b * 2;
```

它们有一个共同点：右侧表达式用到了左侧变量的当前值，算完以后，结果又存回这个变量。第一句给 `a` 加十，第二句把 `b` 乘二。

这种“算完再存回自己”的操作很常见，可以分别缩写成：

```c
a += 10;
b *= 2;
```

`+=` 把加法和赋值合在一起，`*=` 把乘法和赋值合在一起，这类写法叫作**复合赋值**。对这里的整数变量，`a += 10;` 和 `a = a + 10;` 做的是同一件事：假如 `a` 当前是 3，计算 `a + 10` 得到 13，再把结果存入 `a`。

同样还有 `-=`、`/=`、`%=`。例如，`a -= 2;` 给 `a` 减二，`a /= 2;` 把 `a` 除以二再存回去，`a %= 2;` 则把求余的结果存回去。运算规则仍然是前面讲过的规则：如果 `a` 是值为 7 的 `int`，执行 `a /= 2;` 后就是 3。

而 `a += 1;` 和 `a -= 1;` 又实在太常用了，C 还给它们各准备了一个更短的写法：`a++;` 和 `a--;`。`++` 叫作**自增**，给变量加一；`--` 叫作**自减**，给变量减一。

看下面几句的执行过程：

```c
int count = 3;
count += 2;
count++;
printf("%d\n", count);
count--;
printf("%d\n", count);
```

`count` 从 3 开始，先加二变成 5，再加一变成 6，所以第一行输出 6。接着减一变成 5，第二行就输出 5。

注意，`count + 1` 只是计算一个结果，`count++` 则包含了修改 `count` 的动作。这是两种不同的运算，不能因为都写了加号就混在一起。`count++;` 实际上约等于 `count = count + 1;`

## 6. 条件：逻辑表达式

### 6.1 用表达式表示条件

“分数至少为 60”是一个条件，在 C 中可以写成 `score >= 60`。它和前面的 `a + b` 一样，也是一个表达式，只不过这里是一个逻辑表达式，表达式的结果表示条件是否成立。

先介绍几个比较运算符，用来表示大小、相等与不等这些条件：

| 写法 | 含义 |
| --- | --- |
| `a < b` | `a` 小于 `b` |
| `a <= b` | `a` 小于或等于 `b` |
| `a > b` | `a` 大于 `b` |
| `a >= b` | `a` 大于或等于 `b` |
| `a == b` | `a` 等于 `b` |
| `a != b` | `a` 不等于 `b` |

比如 `3 < 8`，这个条件成立，表达式的结果就是**真**；`3 > 8` 不成立，结果就是**假**。我们用这样的表达式表示条件，用求出的逻辑值表示条件的真假。这些比较得到的真用 1 表示，假用 0 表示，所以用 `%d` 输出时，看到的就是 1 或 0。

所以，`score >= 60` 和 `score + 1` 一样，都可以求出一个值，再交给 `printf`，或者存进变量里。看下面几句的执行过程：

```c
int score = 75;
int pass = (score >= 60);
printf("%d %d", pass, score == 100);
```

`score >= 60` 比较的是 75 和 60，结果为真，用 1 表示，于是 `pass` 的初始值是 1。`score == 100` 比较的是 75 和 100，结果为假，用 0 表示。最终输出 `1 0`。

这里没有任何操作修改 `score`，它仍然是 75。尤其要分清 `=` 和 `==`：一个等于号表示赋值，两个等于号表示判断是否相等。`score = 60;` 把右侧表达式的值 60 存进 `score`；`score == 60` 则比较两边的值，结果是真或假。

比较的两边也可以是更复杂的表达式。例如 `a + b > 10`，就是求出 `a + b` 的值，再和 10 比较。

### 6.2 把几个条件组合起来

如果想判断 `score` 是否在 0 到 100 之间，就需要它既不小于 0，又不大于 100。这是两个条件，用 `&&` 把表示它们的表达式连起来就可以：

```c
score >= 0 && score <= 100
```

`&&` 表示“并且”，两边都为真，整个表达式才为真。假如 `score` 是 75，左边 `score >= 0` 为真，右边 `score <= 100` 也为真，整个表达式就为真。如果 `score` 是 120，右边为假，整个表达式就为假。

这种按照真假进行的运算叫作**逻辑运算**，组合得到的仍然是表达式，叫作**逻辑表达式**。常用的逻辑运算符有三个：

| 写法 | 含义 | 结果为真的情况 |
| --- | --- | --- |
| `A && B` | 并且 | `A`、`B` 都为真 |
| `A \|\| B` | 或者 | `A`、`B` 至少有一个为真 |
| `!A` | 非，也就是“不” | `A` 为假 |

其余情况结果为假。这里的 `A`、`B` 代表参与逻辑运算的表达式，换成 `score >= 0` 之类的式子就可以。`&&` 是两个 `&`，`||` 是两个竖线，不能只写一个。

例如下面几句：

```c
int score = 75;
printf("%d\n", score < 0 || score > 100);
printf("%d\n", !(score >= 60));
```

第一个 `printf` 输出“分数超出了范围”这个条件的求值结果。75 既不小于 0，也不大于 100，两个比较都为假，所以整个表达式为假，输出 0，表示这个条件不成立。

第二个 `printf` 中，`score >= 60` 为真，前面的 `!` 把真变成假，所以也输出 0。因此程序输出两行 0。如果 `score` 是 50，括号内为假，`!` 就会把它变成真。

普通的数值也可以当作条件，C 按照**零为假、非零为真**来理解它们。所以 `3 && -2` 为真，`!3` 为假，`!0` 为真。逻辑运算得到的真和假，也还是用 1 和 0 表示。

`!` 的优先级比较高，这里用小括号把整个比较包起来，说明我们要否定的是 `score >= 60` 的结果。把括号去掉写成 `!score >= 60`，就变成了先算 `!score`，再与 60 比较，意思完全不同。

比较运算的优先级高于 `&&` 和 `||`，所以开头的式子相当于 `(score >= 0) && (score <= 100)`。`&&` 又比 `||` 优先级高；组合较多时，可以直接用小括号说明关系，例如 `((x >= 0) && (x <= 10)) || (x == 20)`，表示 `x` 在 0 到 10 之间，或者等于 20。

### 6.3 为什么不能照搬连续不等式

数学里可以写 $0 \le x \le 10$，但把它照写成 C 表达式 `0 <= x <= 10`，计算过程就和我们想的不一样。下面是一种错误的区间判断：

```c
// 错误示范！
int x = 20;
printf("%d\n", 0 <= x <= 10);
```

两个 `<=` 按从左向右组合，这个式子相当于 `(0 <= x) <= 10`。

先看括号内，`0 <= 20` 成立，得到 1。接下来比较的是 `1 <= 10`，当然也成立，于是最终得到 1。虽然 20 不在这个范围内，程序却输出了 1。

我们真正想要的是让两个比较同时成立，所以应该写：

```c
0 <= x && x <= 10
```

仍然取 `x` 为 20，左边比较为真，右边比较为假，`&&` 最终得到假，这才符合我们的意思。

**练习：** `x` 是一个已经有值的整数变量。写出两个表达式，分别判断“`x` 小于 0 或大于 10”和“`x` 在 `[0, 10]` 之间且不等于 5”

**答案与解释：**

第一个表达式为：

```c
x < 0 || x > 10
```

只要一个比较为真，整个表达式就为真。

第二个表达式为：

```c
x >= 0 && x <= 10 && x != 5
```

三个比较都为真，整个表达式才为真。比如 `x` 是 5 时，前两个比较都为真，但 `x != 5` 为假，所以整个表达式为假。

### 6.4 逻辑表达式不一定每一部分都求值

`&&` 和 `||` 有一个特别的规则：先求左边表达式的值，如果已经能确定整个表达式的结果，就不再求右边的值。这叫作**短路求值**。

对于 `A && B`，如果 `A` 为假，不管 `B` 是真是假，都不可能满足“两边都为真”，所以结果直接确定为假，不再计算 `B`。对于 `A || B`，如果 `A` 为真，就已经满足“至少有一个为真”，所以结果直接确定为真，也不再计算 `B`。

这个规则会影响哪些运算实际发生。例如：

```c
int count = 0;
printf("%d", count != 0 && 100 / count > 2);
```

先算左边的 `count != 0`，得到假。到这里整个表达式的结果就确定为假，右边的 `100 / count > 2` 不会求值，其中的除法也不会发生，所以不会发生除以零的问题，输出的是 0。

如果把 `count` 的初始值改成 4，左边为真，还不能确定整个表达式的结果，就继续求右边的值。`100 / 4` 得到 25，`25 > 2` 为真，于是整个表达式为真，输出 1。

因此，这个例子里的两边不能随便交换。如果写成 `100 / count > 2 && count != 0`，当 `count` 为 0 时，程序一开始就会执行除以零，程序可能会得到意料之外的结果，甚至直接崩溃。

## 7. `if` 与 `else`：这一刻选择做什么

### 7.1 条件成立做一组，否则做另一组

`if(条件)` 在条件为真时执行后面大括号里的语句；`else` 指定条件为假时执行的另一组语句。两组只执行一组。

下面是局部片段：

```c
int score = 75;
if(score >= 60) {
    printf("Pass\n");
} else {
    printf("Not yet\n");
}
printf("Done\n");
```

`75 >= 60` 成立，输出为：

```text
Pass
Done
```

把初始值改成 50，就输出 `Not yet` 和 `Done`，各占一行。

`printf("Done\n");` 在条件判断结构之后，不会受到影响。

### 7.2 没有 `else` 时会怎样

若只希望分数低于 60 时显示一条提醒，其他情况继续往下走，可以省略 `else`：

```c
if(score < 60) {
    printf("Review this topic\n");
}
printf("Done\n");
```

当 `score` 为 75，条件不成立，跳过提醒，仍会输出 `Done`。省略 `else` 不表示条件为假就结束程序。

`if` 只在执行到它时判断一次。即使它内部后来改了变量，也不会因为条件变化而自动退出来或重新判断。例如：

```c
int x = 3;
if(x == 3) {
    x = 4;
    printf("%d\n", x);
}
```

进入大括号时条件成立，于是执行里面的语句。修改成 4 后，继续输出；不会因为 `x` 发生了修改就第二次触发 `if` 判断。

### 7.3 有三种情况时怎样依次排除

希望把输入分成“不在范围内”“至少 60 分”“其余分数”，可以按下面的顺序判断：

```c
if(score < 0 || score > 100) {
    printf("Out of range\n");
} else if(score >= 60) {
    printf("Pass\n");
} else {
    printf("Not yet\n");
}
```

`else if` 是“前一个条件没成立，再判断这个条件”。例如 `score` 为 120，第一组执行后，整串选择结束，不再进入 `Pass` 那组。

若 `score` 为 50，第一项不成立，第二项也不成立，执行最后一组。到最后一组时，已经知道分数在 0 到 100 之间且小于 60。

再举一个例子：

```c
if(score >= 60) {
    printf("Pass\n");
}
if(score >= 90) {
    printf("Excellent\n");
}
```

这是两个独立判断，彼此之间没有任何联系。`score` 为 95 时会输出两行，`score` 为 70 时只输出 `Pass`，`score` 为 45 的时候一行都不会输出。

**练习：** 判断整数 `x` 是正数、零还是负数，第一行分别输出 `Positive`、`Zero`、`Negative`，第二行输出 `x` 的绝对值。

**答案与解释：**

```c
if(x > 0) {
    printf("Positive\n");
    printf("%d\n", x);
} else if(x == 0) {
    printf("Zero\n");
    printf("%d\n", x);
} else {
    printf("Negative\n");
    printf("%d\n", -x);
}
```

正数和零的绝对值就是它本身，负数的绝对值是它的相反数，所以负数分支输出 `-x`。例如，`x` 为 -3 时，先输出 `Negative`，再换行输出 3。再次强调，这里的 `-x` 只作为一个表达式表示相反数，并没有修改 `x`。

### 7.4 为什么要同时认真看分号和大括号

前面一直用大括号把条件成立时要执行的语句组成一块。如果里面只有一条语句，也可以省略大括号：

```c
if(score >= 60)
    printf("Pass\n");
```

条件成立时执行这条输出语句，不成立就跳过。如果在后面再写一条呢？

```c
if(score >= 60)
    printf("Pass\n");
    printf("Done\n");
```

`if` 只控制紧跟着的那条语句，所以无论分数是多少，都会输出 `Done`。即使把这一行看起来已经向右缩进，执行过程也不会改变。事实上这是一个不合理的缩进，正确的缩进长这样：

```c
if(score >= 60)
    printf("Pass\n");
printf("Done\n");
```

如果希望真的两句都只在条件成立时执行，就用大括号把它们组成一个代码块：

```c
if(score >= 60) {
    printf("Pass\n");
    printf("Done\n");
}
```

`if` 后面接一条语句，大括号把里面的多条语句组成一个整体，于是可以一起受条件控制。`else` 后面也是一样的规则。

下面的是一个错误示例，写法多了一个分号：

```c
// 错误示例！
if(score >= 60);
{
    printf("Pass\n");
}
```

`if` 后面多出的分号自己形成一条什么都不做的语句，叫作**空语句**。条件控制的是这条空语句；后面的大括号已经是另一个部分，因此即使分数为 50，也会输出 `Pass`。

同样，不要把判断相等误写成赋值。下面是一个错误示例：

```c
// 错误示例！
if(score = 60) {
    printf("Exactly 60\n");
}
```

它会先把 `score` 赋值成 60。赋值也是一个表达式，这个表达式的结果是 60，作为 `if` 的条件，非零看作真，于是进入大括号，输出 `Exactly 60`。

这个错误非常常见，而且不容易发现，请一定小心。

### 7.5 代码块里的变量能在哪里用

还可以在代码块里面定义变量。例如，想看看及格的分数比 60 高多少：

```c
int score = 75;
if(score >= 60) {
    int extra = score - 60;
    printf("%d\n", extra);
}
printf("%d\n", score);
```

条件成立，进入代码块后定义 `extra`，用 `score - 60` 的值 15 初始化它，再输出 15。离开这对大括号后，还可以使用外面定义的 `score`，所以最后输出 75。

但如果把 `printf("%d\n", extra);` 移到大括号外面，就会编译报错：`extra` 是在里面定义的，出了这一块，就不能再用这个名字。

变量名能使用的范围叫作**作用域**。这里的 `extra` 从定义它的地方开始，到所在代码块的右大括号为止；`score` 定义在外层，所以里面和后面都能用。大括号代码块引出的变量作用域功能并非 `if else` 结构的专利，事实上这项规则与 `if else` 结构是完全独立的，只是我觉得比较适合放在这儿讲。

### 7.6 输入成功了吗：函数也能把结果交回来

这一段在上机过程中可能不会碰到，你可以跳过不看。因为每道题目的出题人都会保证输入数据的形式是正确的，所以在 Accoding 平台上，你的程序不会遇到意料之外的输入。

前面使用 `scanf` 时，我们一直按要求输入数。现在已经会写 `if`，可以回头看看：如果本来要输入一个整数，却输入了字母，程序怎样知道这次没有读到整数？

一个函数做完事情以后，还可以把一个结果交回调用它的地方，这个结果叫作**返回值**。你已经见过 `main` 里的 `return 0;`：它结束 `main`，把 0 交给运行环境，也就是你电脑的操作系统。`scanf` 也会交回一个整数，只不过它交给的是程序中调用它的地方，而且这个整数有自己的含义。

先看这个局部片段：

```c
int a;
int received = scanf("%d", &a);
```

第一句准备变量 `a`。第二句先让右边的 `scanf` 工作，再把它交回的整数存进 `received`。这和先算出 `3 + 5`，再把结果存进变量的顺序相同，只是右边这次要做的是调用函数。

对于这里读入一个整数的写法，`scanf` 成功把整数存进 `a`，就返回 1。例如输入 25，`a` 得到 25，`received` 得到 1。这两个数不是同一回事：一个是读到了什么，另一个是成功读入并存好了几个数。

如果输入 `hello`，开头的字母不能按 `%d` 读成整数，`scanf` 返回 0，也没有往 `a` 里存入新的整数。对于这个只要求读一个整数的例子，只要返回值不是 1，就是没有完成我们要的输入。

现在可以写一份完整程序，只在成功读入后输出这个数：

```c
#include<stdio.h>

int main() {
    int a;
    int received = scanf("%d", &a);
    if(received == 1) {
        printf("%d\n", a);
    } else {
        printf("Input failed\n");
    }
    return 0;
}
```

输入 25，输出 25。输入 `hello`，输出 `Input failed`，意思是输入失败，然后程序结束。这一版先不尝试让用户重新输入，因为没有读走的字母还在那里，直接再调用一次相同的 `scanf`，并不会自动把它们清掉。

原来只写 `scanf("%d", &a);` 时，输入工作照常进行，函数也照常交回结果，只是我们没有把这个结果保存下来。返回值也不一定要先存进变量；理解上面的两步以后，可以把条件直接写成 `if(scanf("%d", &a) == 1)`：先调用，再拿交回的数与 1 比较。

**练习：** 把输入改成 `scanf("%d%d", &a, &b)`，应该用返回值等于几来判断两个整数都读好了？如果输入 `3 hello`，返回值是多少，哪些变量得到了输入的数？这里假设 `a`、`b` 已经定义为 `int`。

**答案与解释：** 两个都成功读入时，返回值为 2。输入 `3 hello` 时，第一个整数读入成功，`a` 得到 3；第二个没有读入成功，`b` 没有得到新的整数，返回值为 1。所以返回值不是简单地用零和非零表示全部失败或全部成功，要与这次准备读入的数量比较。

## 8. `while`：简单循环

### 8.1 做完以后，再判断一次

前面的 `if` 会根据条件决定要不要执行一块代码。`while` 和它很像，只是执行完这一块以后，会回到条件处，再判断一次。这样让一组代码反复执行，就叫作**循环**，被反复执行的那一块叫作**循环体**。

先给 `while` 的两部分标上编号，方便和图对应。这里的 ⑤、⑥ 代表相应位置的代码。注意 ⑤ 是一个条件/逻辑表达式，或者说会被看作一个条件/逻辑表达式。

```text
while(⑤) {
    ⑥
}
```

从图中的 Start 开始，沿箭头走，先到⑤，求出条件表达式的值。

+ 条件为真，沿 yes 走到 ⑥，执行循环体。
+ ⑥ 执行完，沿上面的箭头回到 ⑤，重新求条件表达式的值。
+ 条件为假，沿 no 离开循环，接着执行循环后面的代码。

图中的 End 表示离开这个循环，不是结束整个程序。

所以执行的顺序是⑤、⑥、⑤、⑥……每次走到 ⑤，都用变量此时的值判断。要是第一次判断就为假，⑥ 一次也不会执行。

### 8.2 把代码放到图里走一遍

我们想依次输出 1、2、3：

```c
int i = 1;
while(i <= 3) {
    printf("%d\n", i);
    i++;
}
printf("Done\n");
```

图中的 ⑤ 对应 `i <= 3`，⑥对应大括号里的两句：输出 `i`，再让 `i` 增加一。`int i = 1;` 在循环外，不在图示流程里面。之后才开始沿图中的箭头走。

第一次到 ⑤ 时，`i` 是 1，`i <= 3` 为真，于是走进 ⑥。先输出 1，再执行 `i++`，`i` 变成 2。⑥ 执行完了，箭头让程序回到 ⑤，而不是继续去输出 `Done`。

第二次到 ⑤ 时，`i` 已经是 2。同一个表达式 `i <= 3`，这次比较的是 2 和 3。条件仍然为真，就再执行一次 ⑥，输出 2，然后把 `i` 改成 3。

第三次到 ⑤ 时，`i` 是 3。同一个表达式 `i <= 3`，这次比较的是 3 和 3。条件仍然为真，就再执行一次 ⑥，输出 3，然后把 `i` 改成 4。

第四次到 ⑤ 时，`i` 是 4。同一个表达式 `i <= 3`，这次的结果是假，于是离开循环。

最终变量 `i` 的值是 4。

然后执行输出 `Done` 的语句。

最终输出：

```text
1
2
3
Done
```

注意：输出 3 以后，还会执行 `i++`，还会回到⑤判断。正是 `4 <= 3` 为假，程序才沿 no 离开。因此，循环结束时 `i` 是 4。

如果把最开始的 `int i = 1;` 改成 `int i = 5;`，那第一次到⑤就走 no，直接输出 `Done`。

### 8.3 箭头不会替我们修改变量

图里从 ⑥ 回到 ⑤ 的箭头，只负责让程序再判断一次。`i` 会增加，是因为我们在 ⑥ 里写了 `i++`。

如果删掉 `i++`，`i` 就一直是 1。每次到 ⑤，条件都为真；每次到 ⑥，都输出 1，然后又回到 ⑤。这个循环会一直重复下去，叫作**死循环**。

另一个容易想错的地方是：条件并不会在循环体执行期间被不停检查。看这个例子：

```c
int i = 1;
while(i <= 3) {
    i = 10;
    printf("%d\n", i);
}
printf("Done\n");
```

第一次判断为真，进入 ⑥。`i = 10;` 虽然已经让条件不成立了，但程序此时还在 ⑥ 里面，所以接下来仍会输出 10。走完 ⑥，回到 ⑤，才发现条件为假，离开循环并输出 `Done`。

这和 `if` 里面修改变量时一样：程序执行到判断的位置，才会判断。看图时，就看现在沿箭头走到了哪里。

**练习：** 把输出 1、2、3 的循环改成输出 3、2、1。循环结束时，`i` 是多少？

**答案与解释：**

```c
int i = 3;
while(i >= 1) {
    printf("%d\n", i);
    i--;
}
printf("Done\n");
```

从 3 开始，每轮减一，条件是 `i >= 1`。输出 1 后，`i--` 把 `i` 改成 0，再回到 ⑤，条件为假，循环结束。最后输出 `Done`。循环结束的时候 `i` 变量的值是 0。

### 8.4 循环里可以做什么：求和

循环体里当然不必只有输出。例如，求 $1+2+3$，可以先记一个总和 0，依次把 1、2、3 加进去：

```c
int i = 1;
int sum = 0;
while(i <= 3) {
    sum += i;
    i++;
}
printf("%d\n", sum);
```

还是同一张图。⑤ 仍然是 `i <= 3`，⑥ 里原来的输出换成了 `sum += i;`，每次把当前的 `i` 加进总和，再让 `i` 增加一。

| 进入 ⑥ 时 `i` 的值 | 执行 `sum += i;` | 执行 `i++;` 后 |
| --- | --- | --- |
| 1 | `sum` 从 0 变成 1 | `i` 为 2 |
| 2 | `sum` 从 1 变成 3 | `i` 为 3 |
| 3 | `sum` 从 3 变成 6 | `i` 为 4 |

随后回到 ⑤，条件为假，离开循环，输出总和 6。

这里需要两个变量，因为要记住两件不同的事：`i` 表示这轮要加哪个数，`sum` 保存已经加过的数的总和。每轮的 `i` 都不同，但总和要接着上一轮的结果继续加。

因此，`int sum = 0;` 写在循环外。如果放进 ⑥，每次沿箭头走进来，都会重新定义 `sum` 并从 0 开始，总和就积累不起来；出了代码块，也不能再使用里面定义的 `sum`。

### 8.5 每读一个数，记住目前的最高分

先看一个小问题：依次读入三个 0 到 100 的整数分数，输出其中的最高分。比如分数是 80、90、70，我们怎样一个一个地看？

+ 看到 80，目前只看过它，最高分就是 80。
+ 再看到 90，它比记住的 80 大，所以改为记住 90。
+ 再看到 70，它没有超过 90，所以仍然记住 90。

我们不需要把每个分数都留着，只需要一个变量 `max_score`，记住已经看过的分数里最高的那个。新读到的分数用 `score` 保存；如果它更大，就替换 `max_score`，否则保持原来的值。

开始还没读任何分数，该让 `max_score` 存多少呢？这里的分数都不小于 0，可以先存 0。第一个分数如果大于 0，就会替换它；如果等于 0，保留的 0 也正好是这个分数。

下面是一份完整程序：

```c
#include<stdio.h>

int main() {
    int max_score = 0;
    int i = 0;
    while(i < 3) {
        int score;
        scanf("%d", &score);
        if(score > max_score) {
            max_score = score;
        }
        i++;
    }
    printf("%d\n", max_score);
    return 0;
}
```

`i` 从 0 开始，记录已经读完几个分数。每轮先读一个分数，比较并决定要不要替换最高分，最后给 `i` 加一。读完三个，`i` 变成 3，循环结束。

输入 `80 90 70` 时，可以这样跟着变量走：

| 刚读到的 `score` | 比较前的 `max_score` | 要替换吗 | 本轮后的 `max_score` |
| --- | --- | --- | --- |
| 80 | 0 | `80 > 0`，替换 | 80 |
| 90 | 80 | `90 > 80`，替换 | 90 |
| 70 | 90 | `70 > 90` 不成立，保留 | 90 |

每做完一轮，`max_score` 都是已经读过的分数中最高的那个。因此，读完全部分数后，输出的 90 就是全部分数的最高分。

`max_score` 定义在循环外，才能留下前几轮的结果。`score` 则可以每轮读一个新的值：旧分数已经与最高分比较过了，下一轮不必再拿它比较。

**练习：** 有 15 个评委打分，读入 15 个 0 到 100 的整数。去掉一个最高分和一个最低分，求剩下 13 个分数的平均分，保留两位小数。如果最高分或最低分有多个，只去掉一个。

**答案与解释：**

不用真的把某个分数删掉。先求出 15 个分数的总和，再减去一个最高分和一个最低分，得到的就是剩下 13 个分数的总和。

因此，除了总和，还需要记住目前读到的最高分和最低分。每读入一个分数，就把它加进总和，再分别与这两个值比较：比最高分大，就更新最高分；比最低分小，就更新最低分。

```c
#include<stdio.h>

int main() {
    int sum = 0;
    int max_score = 0;
    int min_score = 100;
    int i = 0;

    while(i < 15) {
        int score;
        scanf("%d", &score);
        sum += score;
        if(score > max_score) {
            max_score = score;
        }
        if(score < min_score) {
            min_score = score;
        }
        i++;
    }

    double average = (sum - max_score - min_score) / 13.0;
    printf("%.2f\n", average);
    return 0;
}
```

分数都在 0 到 100 之间，所以最高分先记为 0，最低分先记为 100。例如，先读到 80，最高分和最低分都更新为 80；再读到 90，最高分更新为 90，最低分仍然是 80。这两个比较分别用一个 `if`，因为同一个分数可能需要同时更新两者。

`i` 记录已经读了几个分数，每轮读入一个，再加一。`i` 变成 15 时，循环结束，`sum`、`max_score`、`min_score` 就分别保存全部分数的总和、最高分和最低分。

最后只减去一次 `max_score`、一次 `min_score`，所以即使有多个相同的最高分或最低分，也不会多减。除以 `13.0` 是为了进行浮点除法，`%.2f` 则让结果保留两位小数。

## 9. `for`：把开始、判断和更新写在一起

### 9.1 四个位置，按什么顺序执行

再看刚才输出 1、2、3 的循环：开始时令 `i = 1`，每轮判断 `i <= 3`，做完一轮再执行 `i++`。`for` 可以把这三件事写到一起：

```c
int i;
for(i = 1; i <= 3; i++) {
    printf("%d\n", i);
}
printf("Done\n");
```

给四个位置标上编号：

```text
for(①; ②; ③) {
    ④
}
```

这次从 Start 出发，先走到①，再走到②。②为真，就依次走④、③，再回到②；②为假，就沿 no 离开循环。

把上面的代码对应进去：

| 图中的位置 | 对应的代码 | 做什么 |
| --- | --- | --- |
| ① | `i = 1` | 开始时让 `i` 为 1 |
| ② | `i <= 3` | 判断要不要执行这一轮 |
| ③ | `i++` | 做完一轮，让 `i` 增加一 |
| ④ | `printf("%d\n", i);` | 输出当前的 `i` |

小括号里的两个分号把 ①、②、③ 隔开。虽然代码里 ③ 写在 ④ 前面，**执行时却是先 ④，再 ③**，要沿图里的箭头看。

第一次走的是①、②、④、③。之后箭头回到②，所以重复的是②、④、③，直到某次②为假。①不在这条绕回来的路上，只执行一次。

### 9.2 和 `while` 对照着看

仍然取刚才的例子。① 让 `i` 变成 1，② 判断为真，然后 ④ 输出 1，③ 把 `i` 改成 2，回到②。

下一轮输出 2，再把 `i` 改成 3；再下一轮输出 3，把 `i` 改成 4。这时回到②，`4 <= 3` 为假，才离开循环，输出 `Done`。

这和第八章的 `while` 例子做的是同一件事：

```c
int i = 1;
while(i <= 3) {
    printf("%d\n", i);
    i++;
}
printf("Done\n");
```

对照两张图看，`for` 的 ② 对应 `while` 的 ⑤；`for` 的 ④ 和 ③，合起来对应 `while` 的 ⑥。`for` 把每轮最后的 `i++` 单独写在 ③ 的位置。

所以改成 `for` 以后，④ 里就不用再写一次 `i++` 了。两边都写的话，每轮会增加两次，这个例子就只输出 1、3。

再看 ①：如果每次回到 ② 之前都重新执行 `i = 1`，`i` 就永远走不到 4。图里回去的箭头不会经过 ①，正是这个原因。

**练习：** 执行下面的代码，输出什么？①、②、③、④分别执行了几次？

```c
int i;
for(i = 5; i <= 3; i++) {
    printf("%d\n", i);
}
printf("Done\n");
```

**答案与解释：**

只输出 `Done`。先执行①，令 `i = 5`；再到②，条件为假，沿 no 离开。①、②各执行一次，③、④都没有执行。

### 9.3 在 `for` 里定义变量

前面先定义 `i`，再在 ① 里给它赋值。也可以直接在 ① 里定义：

```c
for(int i = 1; i <= 3; i++) {
    printf("%d\n", i);
}
```

`int i = 1` 仍然只在开始时执行一次，不会每轮重新定义。这里定义的 `i` 可以在条件 ②、更新 ③ 和循环体 ④ 里使用，但离开这个 `for` 循环后，就不能再用这个名字了。

把 `i` 定义在 ① 里时，其作用域就只有 ①②③④。如果循环结束后还想用 `i`，就像前面那样，把它定义在循环外。

### 9.4 从一个数走到另一个数

知道执行顺序以后，就可以根据想做的事情调整 ①、②、③。

下面介绍几个常见写法，你可以把它们抽象成某种模块，拿来改改数就可以用。

例如，要依次输出 2、3、4、5：

```c
for(int i = 2; i <= 5; i++) {
    printf("%d\n", i);
}
```

① 决定从 2 开始，③ 决定每轮加一，② 允许 `i` 等于 5 时再执行一轮。输出 5 后，③ 仍会把 `i` 改成 6，下一次 ② 才为假。

若把 `i <= 5` 改成 `i < 5`，到 `i` 为 5 时就不能进入 ④，所以只输出到 4。要不要包含末尾的数，就体现在这个条件里。

想倒着输出 5、4、3、2，就一起改起点、条件和更新方向：

```c
for(int i = 5; i >= 2; i--) {
    printf("%d\n", i);
}
```

③ 也不必每次只加一或减一。例如每次加二，就可以依次处理偶数。

**练习：** 用 `for` 计算 $2+4+6+8+10$。

**答案与解释：**

```c
int sum = 0;
for(int i = 2; i <= 10; i += 2) {
    sum += i;
}
printf("%d\n", sum);
```

进入 ④ 时，`i` 依次为 2、4、6、8、10，把它们加到 `sum`，最终输出 30。最后一次③把 `i` 改成 12，回到 ② 时才结束循环。

### 9.5 只关心重复多少次

有时我们不需要用到每轮的编号，只想让某件事做 `n` 次。例如输出三次 `Hello`：

```c
int n = 3;
for(int i = 0; i < n; i++) {
    printf("Hello\n");
}
```

进入 ④ 时，`i` 分别为 0、1、2，一共三次。`i` 变成 3 时，② 为假，循环结束。

这里可以把 `i` 理解成已经做完的次数：最开始做完了零次；每执行一次 ④，就在 ③ 里加一；做完 `n` 次，就不再进入 ④。`n` 为 0 时，一次也不做，也符合这个意思。

因此，“从 0 开始，到 `n` 之前”为止，是让一件事重复 `n` 次的一种常见写法。④ 里面可以换成读入一个数、处理一份数据，或者其他要重复的操作。

如果把 `i < n` 写成 `i <= n`，那就会额外多执行一次，因为从 $0$ 到 $n$ 总共有 $n + 1$ 个整数。

这是很常用的写法，相当建议你在脑子里将它模块化。

### 9.6 逐个试除数：求最大公约数

现在用循环做一件稍微复杂的事：读入两个**正整数** `a`、`b`，求最大公约数。

能同时整除两个数的正整数，叫作它们的**公约数**，其中最大的就是**最大公约数**。例如 6 和 8 的公约数是 1、2，最大公约数就是 2。

我们可以从 1 开始，一个一个试。对于 6 和 8，试到 6 就够了：一个比 6 还大的正整数，已经不可能整除 6，也就不可能是两者的公约数。一般来说，试到 `a`、`b` 中较小的那个数即可。

用 `limit` 记住这个上界：

```c
int limit = a;
if(b < limit) {
    limit = b;
}
```

然后用 `i` 表示这次要试的数。`a % i == 0` 表示 `i` 是 `a` 的因数；两个数都能被整除，就写成 `a % i == 0 && b % i == 0`。

把这个过程放进 `for` 的四个位置：

+ ①：`int i = 1`，定义 `i`，从 1 开始试。
+ ②：`i <= limit`，还没超过上界就继续。
+ ③：`i++`，下一轮试下一个数。
+ ④：检查 `i` 是否为公约数，如果是，就把它存进 `g`。

最大公约数的英文缩写是 gcd，这里用变量 `g` 保存答案。先让它为 1，因为 1 一定是两个正整数的公约数。

```c
#include<stdio.h>

int main() {
    int a, b;
    scanf("%d%d", &a, &b);

    int limit = a;
    if(b < limit) {
        limit = b;
    }

    int g = 1;
    for(int i = 1; i <= limit; i++) {
        if(a % i == 0 && b % i == 0) {
            g = i;
        }
    }

    printf("%d\n", g);
    return 0;
}
```

输入 `6 8`，输出 2。跟着④里的判断看：

| 本轮的 `i` | 是公约数吗 | 本轮结束后的 `g` |
| --- | --- | --- |
| 1 | 是 | 1 |
| 2 | 是 | 2 |
| 3 | 否，不能整除 8 | 2 |
| 4 | 否，不能整除 6 | 2 |
| 5 | 否 | 2 |
| 6 | 否，不能整除 8 | 2 |

这里为什么找到一个公约数，就直接用它覆盖 `g`？因为我们从小到大试，新找到的公约数总比前一个大。试完以后，最后保存的那个自然就是最大的。

④ 中的 `if` 判断为假，只是跳过 `g = i;`，不会结束外面的循环。走完 ④，仍然到 ③ 增加 `i`，再回到 ② 判断要不要继续试。

这种把可能的答案逐个试一遍的做法叫作**枚举**，也常叫作**暴力求解**。在这里，我们用循环负责逐个试，用 `if` 负责判断，用变量记住结果。

**练习：** 输入 `8 12` 时，哪些轮会执行 `g = i;`？如果把 `&&` 改成 `||`，最后输出什么？

**答案与解释：**

`i` 为 1、2、4 时，它能同时整除两个数，`g` 依次被赋值为 1、2、4，最后输出 4。

改成 `||` 后，只要能整除其中一个数就会更新。试过的 1 到 8 中，1、2、3、4、6、8 都满足条件，最后输出 8。但 8 不能整除 12，所以这个结果不是公约数。

### 9.7 综合练习

#### 9.7.1 读入一批数，求和并统计

**练习：** 先读入数量 `n`，再读入 `n` 个整数，输出它们的总和，以及其中有几个正数。

例如输入：

```text
3
5 -2 0
```

应输出：

```text
3 1
```

**答案与解释：**

每读到一个数，就把它加进总和，再判断它是不是正数。用 `sum` 保存总和，`count` 保存正数个数，两者都从 0 开始。

```c
#include<stdio.h>

int main() {
    int n;
    scanf("%d", &n);

    int sum = 0;
    int count = 0;
    for(int i = 0; i < n; i++) {
        int x;
        scanf("%d", &x);
        sum += x;
        if(x > 0) {
            count++;
        }
    }

    printf("%d %d\n", sum, count);
    return 0;
}
```

每次进入 ④，都读入一个数，完成加法和判断，再到 ③ 增加 `i`。读到 -2 时，里面的 `if` 为假，只会跳过 `count++;`，不会结束外面的循环。

| 本轮的 `i` | 读到的 `x` | 本轮后的 `sum` | 本轮后的 `count` |
| --- | --- | --- | --- |
| 0 | 5 | 5 | 1 |
| 1 | -2 | 3 | 1 |
| 2 | 0 | 3 | 1 |

`i` 记已经处理了几个数，`count` 记其中有几个正数，所以两者不一定相等。

`sum` 和 `count` 定义在循环外，下一轮才能接着上一轮的结果继续累加，循环结束后也能输出它们。`x` 只用来处理这一轮的数据，可以定义在循环体里面，每轮读一个新的数。

如果把 `int count = 0;` 移进循环体，每轮都会从零开始数，前几轮的统计就没有留下来。`n` 为 0 时，循环一次也不执行，外面的 `sum`、`count` 仍然为 0，输出 `0 0`。

#### 9.7.2 比前一个数大了几次

**练习：** 先读入一个正整数 `n`，再按顺序读入 `n` 个整数。从第二个数开始，与紧挨着它的前一个数比较，统计有多少次后一个数更大。相等不算。

例如输入：

```text
7
3 5 5 2 4 1 6
```

应输出 3，因为 `3 → 5`、`2 → 4`、`1 → 6` 这三处是后一个数更大。只有一个数时，没有可以比较的相邻两个数，输出 0。

**答案与解释：**

这一题不能只看刚读到的数，还要记住前一个数。用 `prev` 保存前一个数，`x` 保存刚读到的数。

先读入第一个数，存进 `prev`。接下来每读一个数，就比较 `x > prev`，成立时让计数加一。比较完，再把 `x` 的值存进 `prev`，留给下一轮使用。

```c
#include<stdio.h>

int main() {
    int n;
    scanf("%d", &n);

    int prev;
    scanf("%d", &prev);

    int count = 0;
    for(int i = 1; i < n; i++) {
        int x;
        scanf("%d", &x);
        if(x > prev) {
            count++;
        }
        prev = x;
    }

    printf("%d\n", count);
    return 0;
}
```

第一个数已经在循环外读过，所以 `i` 从 1 开始，循环再读 `n - 1` 个数。

样例中，`prev` 最初是 3。读到 5，比较 `5 > 3`，计数变成 1，然后把 `prev` 更新为 5。再读到一个 5，两者相等，计数不变。接着读到 2，虽然 `2 > 5` 不成立，仍然要把 `prev` 更新成 2，这样下一轮读到 4 时，才会比较 4 和 2。

注意 `prev = x;` 要放在比较之后。如果先更新，比较的就变成了刚读到的数和它自己。

#### 9.7.3 连续正数最长有多少个

**练习：** 先读入数量 `n`，再按顺序读入 `n` 个整数。求最长的一段连续正数有多少个；如果没有正数，输出 0。

例如输入：

```text
11
1 2 -1 3 4 2 5 0 6 7 8
```

应输出 4。其中 `1 2`、`3 4 2 5`、`6 7 8` 是三段连续正数，长度分别为 2、4、3。

**答案与解释：**

只统计正数总数已经不够了。遇到负数或零，连续的一段就断了，下一次读到正数时要重新计数。但之前出现过的最长长度不能跟着清零，因此需要分别保存：

+ `len`：以刚读到的数结尾，连续有多少个正数。
+ `best`：到目前为止，最长的一段有多少个正数。

读到正数，就给 `len` 加一；否则把 `len` 清零。每处理一个数，再比较 `len` 和 `best`，如果当前这一段更长，就更新 `best`。

```c
#include<stdio.h>

int main() {
    int n;
    scanf("%d", &n);

    int len = 0;
    int best = 0;
    for(int i = 0; i < n; i++) {
        int x;
        scanf("%d", &x);

        if(x > 0) {
            len++;
        } else {
            len = 0;
        }
        if(len > best) {
            best = len;
        }
    }

    printf("%d\n", best);
    return 0;
}
```

例子中，读完 `1 2`，`len` 和 `best` 都是 2；读到 -1，`len` 变成 0，`best` 仍然是 2。接着读到 `3 4 2 5`，`len` 依次变成 1、2、3、4，`best` 更新到 4。读到 0，`len` 清零，`best` 保持为 4。最后读完 `6 7 8`，`len` 为 3，没有超过此前的最长长度，所以最终输出 4。

每读一个数就更新一次 `best`，所以最后一段即使一直延续到输入结束，也不会漏掉。不需要等到遇见负数或零，才知道这一段已经有多长。

如果只输出最后的 `len`，求出的就只是末尾那一段的长度。这个样例最后的 `len` 为 3，但最长长度 `best` 为 4，两者并不相同。

#### 9.7.4 输出一个矩形

**练习：** 读入一个正整数 `n`，输出一个 $n \times n$ 的星号矩形，也就是 `n` 行，每行 `n` 个星号。输入 3 时应输出：

```text
***
***
***
```

**答案与解释：**

先想一行怎么输出：输出一个星号，重复 `n` 次，再换行。

```c
for(int j = 0; j < n; j++) {
    printf("*");
}
printf("\n");
```

这里的 `printf("*");` 没有换行，所以星号会接在同一行。里面的循环结束后，才执行后面的换行。

现在想把“一行”重复 `n` 次。把刚才这几句一起放进另一个循环的 ④ 就可以：

```c
#include<stdio.h>

int main() {
    int n;
    scanf("%d", &n);

    for(int i = 0; i < n; i++) {
        for(int j = 0; j < n; j++) {
            printf("*");
        }
        printf("\n");
    }

    return 0;
}
```

循环体里面有另一个循环，这种一层里面还有一层的写法叫作**嵌套**。`i` 所在的循环是外层，`j` 所在的循环是内层。前面在循环里面放 `if`，也是把一组结构放进另一组里。

取 `n = 3`，仍然沿着 `for` 的图走，只是外层的 ④ 现在包含了一个完整的内层循环：

+ 外层 `i` 为 0，进入 ④，开始执行内层循环。
+ 内层 `j` 从 0 开始，分别在 0、1、2 时输出星号。`j` 变成 3，内层循环结束。
+ 接着执行换行。这时外层的 ④ 才执行完，轮到外层的 ③，让 `i` 变成 1。
+ 再次进入外层的 ④，又遇到内层的 `for`，从它的 ① 开始执行，重新定义 `j = 0`，再输出三个星号，然后换行。
+ 外层 `i` 为 2 时，同样输出第三行。之后 `i` 变成 3，外层条件为假，全部结束。

外层每执行一轮，内层都要从开始到结束走一遍。外层做 `n` 轮，每轮内层做 `n` 轮，所以总共输出 $n \times n$ 个星号。

我们前面说 ① 只执行一次，是指每次开始执行这个 `for` 时执行一次。内层的 `for` 被外层执行了 `n` 次，所以内层的 ① 也执行了 `n` 次。

#### 9.7.5 每行多一个星号

**练习：** 读入一个正整数 `n`，输出 `n` 行星号，第 1 行一个，第 2 行两个，依次增加。输入 3 时应输出：

```text
*
**
***
```

**答案与解释：**

外层用 `i` 表示当前是第几行，从 1 到 `n`。第 `i` 行要输出 `i` 个星号，所以内层重复的次数用 `i` 来决定：

```c
#include<stdio.h>

int main() {
    int n;
    scanf("%d", &n);

    for(int i = 1; i <= n; i++) {
        for(int j = 0; j < i; j++) {
            printf("*");
        }
        printf("\n");
    }

    return 0;
}
```

`i` 为 1 时，内层执行一次；`i` 为 2 时，内层执行两次；`i` 为 3 时，内层执行三次。内层执行期间，外层还在做自己的 ④，没有走到外层的 ③，所以 `i` 在这一行里保持不变。

每一行结束后才换行，因此 `printf("\n");` 放在内层循环外、外层循环内。如果放到内层循环里面，就会变成每输出一个星号都换行。

#### 9.7.6 输出一个菱形

**练习：** 读入一个正整数 `n`，输出一个星号菱形。从第一行到中间一行共有 `n` 行，星号数量从 1 开始，每行增加两个；随后每行减少两个，直到只剩一个。输入 3 时应输出：

```text
  *
 ***
*****
 ***
  *
```

**答案与解释：**

先看每行要输出什么。为了让星号居中，先输出一些空格，再输出星号，最后换行。`n = 3` 时，各行的数量是：

| 行 | 开头的空格数 | 星号数 |
| --- | --- | --- |
| 第 1 行 | 2 | 1 |
| 第 2 行 | 1 | 3 |
| 第 3 行 | 0 | 5 |
| 第 4 行 | 1 | 3 |
| 第 5 行 | 2 | 1 |

可以把图案分成两部分。上半部分包含中间最宽的一行，用 `i` 从 1 走到 `n`。第 `i` 行先输出 $n-i$ 个空格，再输出 $2i-1$ 个星号。

下半部分就是把上面的行倒着输出，但不要再输出一次中间行。因此，让 `i` 从 $n-1$ 走到 1，每行仍然输出 $n-i$ 个空格和 $2i-1$ 个星号。

```c
#include<stdio.h>

int main() {
    int n;
    scanf("%d", &n);

    for(int i = 1; i <= n; i++) {
        for(int j = 0; j < n - i; j++) {
            printf(" ");
        }
        for(int j = 0; j < 2 * i - 1; j++) {
            printf("*");
        }
        printf("\n");
    }

    for(int i = n - 1; i >= 1; i--) {
        for(int j = 0; j < n - i; j++) {
            printf(" ");
        }
        for(int j = 0; j < 2 * i - 1; j++) {
            printf("*");
        }
        printf("\n");
    }

    return 0;
}
```

每轮外层循环里，两个内层循环依次执行：先把空格输出完，再输出星号，然后换行。它们共同组成这一轮的 ④。

`n = 3` 时，上半部分的 `i` 依次为 1、2、3，下半部分为 2、1。整个图案有 $2n-1$ 行，中间一行也有 $2n-1$ 个星号。`n = 1` 时，只输出一个星号，下半部分一次也不执行。

## 10. 写循环时，先想一轮，再看怎么重复

写循环时，可以先拿一个数试着做，确定这一轮要完成什么。比如读入一个数后，是直接输出，还是加进总和，还是判断它是否符合某个条件？这些就是循环体里要写的内容。

再想下一轮和这一轮有什么不同。是 `i` 要增加一，换一个候选答案？还是要再次读入，换一份数据？程序不会因为“又循环了一次”就自动替我们换数，变化来自我们写下的那些语句。

最后决定什么时候继续、什么时候结束。把条件放进图里的判断位置，沿箭头走一遍，尤其看清第一轮怎么进入，最后一轮做完以后又发生了什么。

如果执行过程和想的不一样，就先用两三个数，记下当前变量的值，沿着箭头逐步走。不要一下盯着整段程序猜结果，先找出究竟是哪一步开始和预想不同。

## 附录：前面几种说法的边界

正文里有些地方先借用了你熟悉的东西，为了减少负担，没有一次讲完所有区别。这部分把这些区别补上，不读暂时也没有影响。

### A. 刚准备好的盒子里，到底有什么

前面用“盒子里已经有一个不知道的数”帮助理解：定义一个变量，并不等于把那个位置清空，更不等于自动放入了题目需要的数。

在常见机器上，一块实际用来存数据的内存已有由 0 和 1 组成的内容。但这不等于 C 语言保证：读取一个还没有给初始值的局部整数变量，就会得到某个固定、只是我们不知道的整数。

例如，在 `main` 中只写 `int a;`，就立刻计算 `a + 1`，不能保证只是“把原来那个未知的数加一”。C 对这样的程序可能不规定结果，这叫作**未定义行为**。即使某次运行打印出了一个数，也不能由此推断下一次、换一个编译器，或者修改其他代码后仍会按同样的方式工作。它也不适合拿来产生随机数。

这里讨论的是例子中写在 `main` 或其他代码块里的普通局部变量。其他位置或其他写法的变量，初始值规则可能不同，不能把上述内容推广到所有情况。

### B. 声明、定义与头文件

假如我们想写一个叫作 `add` 的函数，让它接收两个整数，把它们的和交回来。先看下面这一行，它可以写在 `main` 前面：

```c
int add(int a, int b);
```

这一行告诉编译器：有一个函数叫作 `add`，调用时要提供两个 `int` 整数，调用结束后会交回一个 `int` 整数。这就是函数的**声明**。最前面的 `int` 说明返回值的类型，小括号里的两个 `int` 说明接收的数据类型。

有了这份说明，编译器看到 `add(3, 5)` 时，就知道该怎样理解这次调用。但是只看上面这一行，还不知道 `add` 里面究竟做什么。名字叫 `add`，并不会让计算机自动替我们写好加法。

具体做法要这样写，同样放在 `main` 外面：

```c
int add(int a, int b) {
    return a + b;
}
```

这就是函数的**定义**。它不仅说明名字、接收什么和交回什么，还给出了大括号里的代码，说明这个函数实际怎样完成工作。末尾不再是前面那一个分号，而是一整个函数体。

调用 `add(3, 5)` 时，`a` 接到 3，`b` 接到 5，函数执行 `return a + b;`，算出 8 并交回调用处。例如，在 `main` 里写 `int sum = add(3, 5);`，`sum` 就得到 8。这里的 `return` 结束的是 `add` 这次调用，程序随后继续执行 `main` 中的下一句。

**声明告诉编译器怎样使用这个函数，定义把函数的具体做法写出来。** 定义同时也起到了声明的作用，所以如果把上面的函数定义放在 `main` 前面，就不必再单独写一行声明。如果把定义放在 `main` 后面，就可以先在 `main` 前面写声明，让编译器读到调用时已经知道它怎样使用。

回到 `#include <stdio.h>`：头文件提供了 `printf`、`scanf` 等函数的声明。我们因此可以调用这些函数，而具体做法由标准库提供，不需要自己再写一份。生成可执行程序时，把我们写的代码和所需的库代码连接起来，这一步叫作**链接**；平时使用的编译运行工具通常会替我们完成它。

头文件也可以包含函数定义。正文展示的就是一种环境中 `printf` 的定义：它在函数体里继续调用 `__mingw_vfprintf` 完成工作。其他环境的 `stdio.h` 可能只在这里提供声明，因此不能把正文那份代码当作所有头文件的固定样子。

声明与定义这两个词也用于变量。正文在 `main` 中写的 `int a;`，既告诉编译器 `a` 是一个 `int` 变量，也为它准备存储空间，所以它是定义，同时也是声明。

### C. 表达式与代数式，哪些地方相同，哪些不同

对于前面的 `a + 1`、`a * 2`，把变量当前的值代进去再计算，和熟悉的代数式很接近。计算这些式子本身，不会修改 `a`。

但我们后来见到的 `a++`、`a = 5` 也是 C 表达式，它们包含修改变量的动作。不能把“算出一个值”和“不改变任何变量”当作同一件事。`scanf("%d", &a)` 也能作为表达式使用：它按规则读入并存放数据，同时把成功存好的数量等结果交回来。

即使只是四则运算，也要遵守 C 的类型规则。例如 `7 / 2` 是整数除法，结果为 3；整数计算还受存储范围限制。这些地方要使用正文已经讲过的 C 规则，不能直接照搬数学中对所有实数成立的做法。

### D. 题目里的整数，仍然要装得下

正文说过，整数类型能表示的范围有限。这个限制也包括中间的计算和循环最后的更新，不只是最终输出。

例如，`(a + b) / 2.0` 先做整数加法。即使平均值并不大，`a + b` 也可能先超出范围。常见的 32 位 `int` 中，两个 2000000000 各自都装得下，它们的整数和却装不下。可以先让一个数按 `double` 参与计算，例如 `(a + 0.0 + b) / 2.0`；这时也要接受浮点数本身的精度限制。

求绝对值时也有边界。在正文采用的常见 32 位 `int` 范围中，最小值是 -2147483648，其相反数 2147483648 超出了这个类型的最大值。因此，正文直接输出 `-x` 的做法，要求相反数也在 `int` 范围内。

同样，`for(int i = 1; i <= n; i++)` 在处理完 `n` 后，还要执行一次 `i++`。即使 `n` 本身装得下，也要给这次加一留出余地。前面求最大公约数时的 `limit`，以及输出图案时的 `n`，都要考虑这个条件；菱形还需要保证 `2 * i - 1` 的中间计算装得下。
