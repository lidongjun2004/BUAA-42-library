## 共性问题

1. 再次强调：**非必要**（即不在下一行首先处理字符时）不要在scanf("")里面加 `'\n'` 。

2. 数组定义不要用变量，且若不放在全局记得必要时候初始化。

   ```c
   #define maxn 10086
   int a[maxn];//也可以直接int a[10086];
   /*
   const int maxn = 10086;
   int a[maxn];
   这种（被注释掉的）定义方法在本地以及其他大部分OJ上是可行的，但我们的OJ不行(逃)
   */
   int main(){
       //int a[maxn];
       /*注意定义在局部的数组是未被初始化的,直接读入可以不用，但若使用例如a[5]++这样的操作，需注意a[5]在未初始化的情况下初始值不为0，而放在全局定义则不需要顾虑*/
   }
   ```

3. 对于随循环多次使用的不被直接赋值的变量，需要随着循环进行初始化。

   ```c
   int t = 0;//在这里初始化只适用于i = 1这一次循环
   for(int i = 1; i <= n; i++){
       t = 0;//需要在这里初始化
       for(int j = 1; j <= n; j++){
           t += a[j];
           ...
       }
       printf("case #%d : %d\n", i, t);
   }
   ```

4. 再次建议形成良好的代码风格，尤其循环嵌套要写出层次感，将括号对齐或与循环语句对齐(~~全部代码左对齐也打shi~~)
