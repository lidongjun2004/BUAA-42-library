## D - 旋转矢量法

$$
A = \sqrt{x^2+y^2} \\
\varphi_0 = \arctan \frac{y}{x}
$$

注意 $\varphi_0$ 前面的符号，如果是非负数要额外输出 `+`。

可以使用 `printf("%+.2f")` 来避免判断正负号和额外输出（注意加号位置）。

`atan(double k)` 返回斜率为 `k` 的直线对应的倾斜角，范围是 $[-\dfrac{\pi}{2}, \dfrac{\pi}{2}]$。

`atan2(double y, double x)` 返回点 $(x,y)$ 的极角，范围是 $[-\pi, \pi]$。

## EF

注意**函数**在使用时（尤其多次套用时）要与定义的参数数量、类型一致。例：

```c
int f(int a, char c, double x){
    int res = 0;
    //do something
    return res;
}
int main(){
    int a;
    char c;
    double x;
    int ans = f(f(f(a, c, x), c, x), c, x);
    printf("%d\n", ans);
}
```

## G - 多项式相加

### 首先说明一个问题

* 题目通常给出的内存限制为 `65536kb`。
* 一个 `int` 型数据所占空间为 `4` 字节。
* `1kb` = `1024` 字节。
* **那么，仅开一个 `int` 型数组，其最大限度为 $\frac{1024}{4} \times 65536 = 16,777,216$ (约为 $1.6 \times 10^7$)。**

由于本题指数和系数均在 `int` 范围内（即 `-2147483648` 到 `2147483647`），故**不可**有如下写法：

```c
for(int i = 1; i <= n; i++){
 scanf("%d%d", &x, &t);
 a[t] = x;
}//要么RE，要么MLE
```

因为两个多项式严格降序，所以可以考虑按下面的方法：

令 $i, j$ 遍历两多项式的 **指数** （ $1 \le i \le n, 1 \le j \le m$），

设系数数组为 $a[100005], b[100005]$ ，指数数组为 $x[100005], y[100005]$。

* 若 $x[i] > y[j]$ 输出 `a[i] x[i]​`； $i++$
* 若 $x[i] < y[j]$ 输出 `b[j] y[j]`； $j++$
* 若 $x[i] == y[j]$ 判断 $a[i] + b[j]$ 是否为零，不为零则输出； $i++, j++$

注意遍历结束后可能有 $i < n$ **或** $j < m$ ，余下未输出的项依次输出即可。
