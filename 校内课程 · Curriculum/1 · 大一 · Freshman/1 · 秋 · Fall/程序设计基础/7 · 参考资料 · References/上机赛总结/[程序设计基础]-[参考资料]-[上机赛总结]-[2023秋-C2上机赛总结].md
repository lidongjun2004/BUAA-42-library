## C2-总结

### 再出现抄代码情况，就该酌情约谈了

### A

#### 1.字符转义

- % $->$ %%
- \  $->$ \\\\
- '   $->$ \\'
- "  $->$ \\"

#### 2.不要乱动空格，直接复制粘贴

#### 3.转义快速处理：回想一下演示过程。（比如复制粘贴，一键替换）

### B

#### 1.const double pi = 3.1415926 也可以

#### 2. $4 / 3 * pi * r * r * r$ 会错， $\dfrac {4}{3}$被算作整形，值为1

#### 3.scanf("%f", &r);中%f用于读float型，精度较低，一般不使用

#### 4.无论 float 还是 double ，均用%f输出

### C

#### 1.数组下标从 $0$ 开始，int a[6]; 可没有 a[6]

#### 2 (a == b)+(c == d)等于2。助教上课说错了Ծ‸Ծ

### D

#### 1.注意 $int$ 范围

#### 2.max和min一定要依照数据范围初始化

#### 3.数组通常不要超过 $a[10^7]$​

#### 4. long 在当前编译环境中等同于 int，懒得写long long可以用宏定义

#### 5.数组开大一点准没错 ( $int \ arr[MAXN + 5];$)

### E

#### 1.字母判断

- $ASCII$码比较
- <ctype.h>中的isalpha() 或 islower()
- 直接比较与 'a' , 'z' 的大小关系

#### 2. （ch - 'a' - k）% 26 可能为负，可以先+26再取模

#### 3. scanf("%s", s)不可用

#### 4.gets()可用，但要while(gets(s) != *NULL*)或者不加!=NULL

#### 5.输入第一个整数k之后有一个换行，如果不处理会在后续作为字符被读入，进而出错

#### 需要getchar();读掉末尾换行符，或者直接scanf("%d\n", &k);读掉

### F

#### 1.考虑到 $a, b, c$ 均为整数，运算时应转型为浮点数，或直接按浮点数读入

#### 2.可在表达式第一个整型变量前加 `1.0*` 或(double)进行转换

### G

#### 1.别  用  goto

#### 2.（尤其是在数位很大或者不确定的时候）一种按位处理数字的方法

```c
int a = 0, b = 1;
while(num > 0){
    a = a + (num % 10);//取末尾最后一位数，比如23456就取6
    b = b * (num % 10);
    num = num / 10;//整形除法，不会产生进位，会直接抹除最后一位，如23456变成2345
}
```

### H

#### 按照题意细心模拟即可，数据够小不需要顾虑

### I

#### 1.思路：把今天距离0000年1月1日一共多少天算出来

#### 2.没有星期 零

#### 3.0000年也是闰年

#### 4.注意多组数据

### J

#### 思路：由于每次调换操作都只会在奇数位( $i = 1, 3, 5...$)或偶数位( $i = 2, 4, 6...$)进行，其相互独立(如 $i = 3$ 则调换 $a[2], a[4]$)，所以判断是否可行只需判断奇数和偶数是否分别在对应奇偶位置上。而统计答案则需求出所有奇数位及偶数位的逆序对数量即可

#### 可先自行考虑正确性，详细证明见题解

## *亿点建议*

### 1.变量名字问题

- 题中给出的最好直接用（如t, n, m等)，题中那么用总是有道理的，总用abcd很容易造成混乱。
- 循环变量通常为 $i, j, k$ 。
- 记数 $cnt(count)$ ，求和 $sum(summary)$ ，总计 $tot(total)$ ，临时变量 $tmp(temp)$ ，最值 $max(min)$ ，标记 $tag(flag)$ ......

#### 2.TLE注意数据范围以及代码死循环问题

#### 3.先过样例，但样例不代表一切

#### 4.DevC++编译运行之后会默认中文输入法，中英文下很多符号不同，易疏忽

#### 5.最好带鼠标 + 电脑网页看题 + 插电，不然很浪费时间

#### 6.每次上机赛后总结尽量看看，有很多常见问题都包含在内

#### 7.代码最好有层次感，而不是靠某一个位置对齐，这样会很难分辨多个”{“ ，”}“的嵌套
