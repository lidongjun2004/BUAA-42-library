## E

这题非常巧妙，可以联想 C3 的 Overflow 那题，可以使用下面的代码避免复杂的高精度乘法：

```c
#include <stdio.h>
#include <assert.h> 
typedef unsigned long long ull;
ull Max = 0xFFFFFFFFFFFFFFFF;
int main() {
 ull T, a, b, ovf;
 scanf("%llu", &T);
 assert(1 <= T && T <= 10000);
 while(T--) {
  scanf("%llu%llu", &a, &b);
  if (!a || !b) {
   ovf = 0;
  } else {
   ull Lib = Max / b;
   ovf = a <= Lib;
  }
  puts(ovf ? "But it is the same for mudulo 2^64." : "Here's where the parade begins!");
 }
 return 0;
}
```

## 总结

1. 能用 `scanf("%s", s)` 就用，必须用  `gets()` 了才用，如果先给出行数 $n$ 再给出 $n$ 行数据，记得要用如下操作：

   ```c
   scanf("%d", &n);
   getchar();
   while(n--) gets(s);
   ```

2. 多重循环时 `i,j,k` 不要混用！！！

3. 手感非常重要，两周后就要考试，这两周一定要保证每天练习量！！！如果 16 场比赛的题目全刷光了，可以去洛谷刷。

4. 代码老 WA 不知道哪里错了怎么办，直接贴代码到 gitee 或发给助教可能很难得到有效回复，最高效的方法是写一个数据生成器，然后和室友的正确代码或者题解代码对拍！！

5. 期末考试时必须用机房电脑，且不能上其它网站，只能上 `accoding.cn`，如果养成查百度的“好”习惯，一定要戒掉！！另外，如果机房电脑的编辑器和自己的编辑器设置不同，一定要记住如何更改！！

6. 大家从现在开始要准备纸质资料，又称“模板”，平时一些随手复制的代码段（比如快速排序，冒泡排序）可以准备好打印出来，带到考场中，能带多少带多少，有备无患！!（当然你得拿得下）
