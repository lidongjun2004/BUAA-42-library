#### 2. 运算过程中的精度变化问题

```c
int a = 2147483647;
long long b = a + 1;//要把 a 转化成 longlong 型，结果才会正确
printf("%lld", b);
---------------------
//输出结果为-2147483648
```

## D - 最长字符串 + G - Woof! Woof

1. `strlen` 返回值为 `unsigned int` 型，与**负数**比较是无效的，会被当做负溢出处理。
