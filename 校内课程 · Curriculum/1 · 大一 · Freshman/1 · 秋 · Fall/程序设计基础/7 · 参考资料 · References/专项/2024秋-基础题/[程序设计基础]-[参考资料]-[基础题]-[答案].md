## A 剪刀 石头 布

| 难度 | 考点 |
| --- | --- |
| 2 | 分支语句，循环语句 |

### 题目

#### 题目描述

三位玩家一起玩石头剪刀布，用 $0$ 表示剪刀、 $1$ 表示石头、 $2$ 表示布。游戏共进行 $m$ 个回合，每个回合三人各出一个手势，按下面的规则计分：

- 三人出的手势两两不同：三人均不加分；
- 三人出的手势完全相同：三人均不加分；
- 场上只出现了剪刀和石头：出石头的玩家各加 $1$ 分；
- 场上只出现了剪刀和布：出剪刀的玩家各加 $1$ 分；
- 场上只出现了布和石头：出布的玩家各加 $1$ 分。

求 $m$ 个回合结束后三位玩家各自的得分。

#### 输入格式

第一行一个整数 $m$ ，表示回合数。

接下来 $m$ 行，每行三个整数 $a$ 、 $b$ 、 $c$ ，分别表示三位玩家在该回合出的手势。

#### 输出格式

一行三个整数，用空格分隔，依次表示三位玩家的总分。

#### 样例输入

```text
3
0 1 2
1 1 1
0 0 1
```

#### 样例输出

```text
0 0 1
```

### 答案

### 题目分析

本题需要根据每位玩家展示的物品进行分类讨论，分别包括

- 三位玩家选择的物品都不相同（均不加分）

- 三位玩家选择的物品都相同（均不加分）

- 场上只出了 “剪刀” 和 “石头” （出“石头”的玩家加分）

- 场上只出了 “剪刀” 和 “布” （出“剪刀”的玩家加分）

- 场上只出了 “布” 和 “石头” （出“布”的玩家加分）

### 示例代码

```c
#include<stdio.h>

int main() {
    int m;
    scanf("%d", &m);//输入m,表示有m个回合
    int asum = 0, bsum = 0, csum = 0;//三个玩家的分数
    for (int i = 0; i < m; ++i) {
        int a, b, c;
        scanf("%d%d%d", &a, &b, &c);
        if (a != b && a != c && b != c)//三者出拳均不同，不加分
            continue;//代表不执行下面的循环代码，直接返回到for循环位置，执行++i并判定循环条件是否成立
        if (a == b && b == c)//三者出拳相同，不加分
            continue;
        if (a != 2 && b != 2 && c != 2)//如果场上只出了 “剪刀” 和 “石头” (即没人出布)，则出“石头”1的玩家获胜
        {
            if (a == 1)
                asum++;
            if (b == 1)
                bsum++;
            if (c == 1)
                csum++;
        }
        if (a != 1 && b != 1 && c != 1)//如果场上只出了 “剪刀” 和 “布” ，则出“剪刀”0的玩家获胜
        {
            if (a == 0)
                asum++;
            if (b == 0)
                bsum++;
            if (c == 0)
                csum++;
        }
        if (a != 0 && b != 0 && c != 0)//如果场上只出了 “布” 和 “石头” ，则出“布”2的玩家获胜
        {
            if (a == 2)
                asum++;
            if (b == 2)
                bsum++;
            if (c == 2)
                csum++;
        }

    }
    printf("%d %d %d", asum, bsum, csum);

}
```

## B 身份证号验证

| 难度 | 考点 |
| --- | --- |
| 3 | 数组 循环 |

### 题目

#### 题目描述

身份证号共 $18$ 位，前 $17$ 位是数字，第 $18$ 位是校验码，取值为数字或大写字母 X。

校验方法是把前 $17$ 位分别乘以系数

$$
7, 9, 10, 5, 8, 4, 2, 1, 6, 3, 7, 9, 10, 5, 8, 4, 2
$$

并求和，再把和对 $11$ 取余，余数与校验码的对应关系为

$$
0 \to 1,\ 1 \to 0,\ 2 \to X,\ 3 \to 9,\ 4 \to 8,\ 5 \to 7,\ 6 \to 6,\ 7 \to 5,\ 8 \to 4,\ 9 \to 3,\ 10 \to 2
$$

给定 $n$ 个身份证号，逐个判断它们的校验码是否正确。

#### 输入格式

第一行一个整数 $n$ 。

接下来 $n$ 行，每行一个长度为 $18$ 的身份证号字符串。

#### 输出格式

对每个身份证号输出一行，校验码正确输出 YES，否则输出 NO。

#### 样例输入

```text
2
11010519491231002X
110105194912310021
```

#### 样例输出

```text
YES
NO
```

### 答案

### 题目分析

首先，我们需要读入身份证号。由于我们需要处理每一位身份证号，而且身份证号并非纯数字，所以我们使用字符数组 `id` 去存储身份证号。

依据题意，我们需要将身份证号码 前 $17$ 位数分别乘以不同的系数并求和。这里我们采用 $Hint$ 中的“数组+循环”的方法实现。用数组 $w$ 储存系数 $7, 9, 10, 5, 8, 4, 2, 1, 6, 3, 7, 9, 10, 5, 8, 4, 2$。

计算出的结果除余后与校验码存在着对应关系，这个对应关系也可以使用数组进行对应，具体实现方式详见代码。

### 示例代码

```c
#include <stdio.h>

int main() {
    int w[30] = {0, 7, 9, 10, 5, 8, 4, 2, 1, 6, 3, 7, 9, 10, 5, 8, 4, 2};//不同位数对应的不同系数，w[1]对应第1位，以此类推
    int yu[30] = {1, 0, 10, 9, 8, 7, 6, 5, 4, 3, 2};//余数与验证码对应关系
    int n;
    char id[30];
    scanf("%d", &n);
    getchar();
    while (n--) {
        gets(id + 1); //id+1可以让读入的字符串从id[1]开始往后存。
        int sum = 0;
        for (int i = 1; i <= 17; ++i) {
            sum += ((id[i] - '0') * w[i]);//数组+循环 求和
        }
        sum %= 11;
        sum = yu[sum];//利用数组，将余数映射成校验码
        if (sum == id[18] - '0' || (sum == 10 && id[18] == 'X')) {
            printf("YES");
        } else {
            printf("NO");
        }
        printf("\n");
    }
}
```

## C nbnhhsh？

### 题目

#### 题目描述

把一段文本里每个单词的首字母取出来，拼成它的缩写。

单词以空格分隔。对每个单词只保留它的第一个字符：如果这个字符是字母就输出它，如果这个字符是撇号则不输出；单词其余字符全部丢弃。文本中既不是字母也不是撇号的字符（标点、换行等）原样输出，并且它同时标志着一个单词的结束。

#### 输入格式

一段文本，读到文件结束（EOF）为止。

#### 输出格式

处理后的文本。

#### 样例输入

```text
na bu neng hao hao shuo hua
```

#### 样例输出

```text
nbnhhsh
```

### 答案

### 题目分析

考虑以变量 wordFlag 记录连续的单词，当 wordflag = 0 时遇到第一个字母或符号需要输出；
`wordflag = 0` 时遇到的第一个字母需要将 wordFlag 置为 1 。

### 示例代码1

```c
#include <stdio.h>
#include <ctype.h>
int main()
{
    char c;
    int wordFlag = 0;
    while ((c = getchar()) != EOF)
    {
        if (wordFlag == 0 && (isalpha(c) || c == '\''))
        {
            wordFlag = 1;
            if (c != '\'')
            {
                putchar(c);
            }
        }
        else if (c == ' ')
        {
            wordFlag = 0;
            continue;
        }
        else if (isalpha(c) == 0 && c != '\'')
        {
            wordFlag = 0;
            putchar(c);
        }
    }
    return 0;
}
```

## D tux 的飞行编队安排

| 难度 | 考点 |
| --- | --- |
| 5 | 循环，字符画 |

### 题目

#### 题目描述

tux 要把 $n$ 架飞机排成一个字符画编队。图案的规模 $k$ 取满足 $8k - 6 \le n$ 的最大整数，也就是

$$
k = \left\lfloor \frac{n + 6}{8} \right\rfloor
$$

图案共 $2k - 1$ 行，每行由左、中、右三段拼成，左段固定占 $k$ 个字符：

- 第 $1$ 行： $k$ 个 `*` 、 $k$ 个空格、 $k$ 个 `*` 。
- 第 $2$ 行到第 $2k - 1$ 行，左段是一个随行数增加不断向左移动的「7」：第 $i$ 行先输出 $\left\lfloor (2k - i + 1) / 2 \right\rfloor$ 个空格，再输出一个 `*` ，然后用空格把左段补齐到 $k$ 个字符。
- 左段之后：第 $2$ 行到第 $k$ 行以及第 $2k - 1$ 行输出 $k$ 个空格；第 $k + 1$ 行到第 $2k - 2$ 行输出 $2k - 1$ 个空格。
- 右段：第 $2$ 行到第 $k - 1$ 行输出一个 `*` ；第 $k$ 行和第 $2k - 1$ 行输出 $k$ 个 `*` ；第 $k + 1$ 行到第 $2k - 2$ 行输出一个 `*` 。

#### 输入格式

一行一个整数 $n$ 。

#### 输出格式

按上述规则输出 $2k - 1$ 行字符画。

#### 样例输入

```text
30
```

#### 样例输出

```text
****    ****
   *    *
   *    *
  *     ****
  *        *
 *         *
 *      ****
```

### 答案

### 题目分析

本题是典型的 ”字符画“，要求在屏幕上打印出某个图案，且图案的规模需要根据输入的数据来决定。

首先寻找 $n$ 和 $k$ 的关系，不难得到， $n = 8k - 6$。

那么， $k = \left\lfloor \frac{n+6}{8} \right\rfloor$，即为飞机不超过 $n$ 架的最大规模。

接下来开始逐行打印图案：

- 第一行的打印较为简单，依次打印 $k$ 个星号、 $k$ 个空格、 $k$ 个星号

- 第二行开始到结束：

  - “7” 图案为随行数增加不断向左移动的一个星号；

    - 可以使用一个变量 $cnt$，初始为 $2k - 1$，每打印一行， $cnt$ 减一，而每行星号前面的空格个数即为 $cnt/2$（整除）；
      **或者**：推算得到第 $i$ 行开头的空格个数为 $(2k - i + 1)/2$（整除），直接输出这么多个空格

    - 接着输出一个星号

    - 接下来用空格将 “7” 在这一行占的字符个数补齐到 $k$ 个即可，循环的下标可以接续上一个循环的继续计算

  - 中间为 $k$ 个空格；

  - “5” 图案可以分为第 $2$ 到 $k - 1$ 行、第 $k$ 行、第 $k + 1$ 到 $2k - 2$ 行、第 $2k - 1$ 行：

    - 第 $2$ 到 $k - 1$ 行：仅有一个星号

    - 第 $k$ 行： $k$ 个星号

    - 第 $k + 1$ 到 $2k - 2$ 行：先打印 $k - 1$ 个空格，再打印一个星号

    - 第 $2k - 1$ 行： $k$ 个星号

具体的程序实现可以参考代码。

### 示例代码

```c
#include <stdio.h>

int n;

int main() {
    scanf("%d", &n);
    int k = (n + 6) / 8;

// LINE 1

    for(int i = 1; i <= k; ++i) printf("*");
    for(int i = 1; i <= k; ++i) printf(" ");
    for(int i = 1; i <= k; ++i) printf("*");
    printf("\n");

// LINE 2 ~ k-1

    int cnt = 2 * k - 1;

    for(int i = 1; i <= k - 2; ++i) {

        int j;
        for(j = 1; j <= cnt / 2; ++j) printf(" ");
        printf("*");
        for(; j <= k - 1; ++j) printf(" ");
        --cnt;

        for(int j = 1; j <= k; ++j) printf(" ");

        printf("*\n");
    }

// LINE k

    int j;
    for(j = 1; j <= cnt / 2; ++j) printf(" ");
    printf("*");
    for(; j <= k - 1; ++j) printf(" ");
    --cnt;

    for(int i = 1; i <= k; ++i) printf(" ");

    for(int i = 1; i <= k; ++i) printf("*");
    printf("\n");

// LINE k+1 ~ 2*k-2

    for(int i = 1; i <= k - 2; ++i) {

        int j;
        for(j = 1; j <= cnt / 2; ++j) printf(" ");
        printf("*");
        for(; j <= k - 1; ++j) printf(" ");
        --cnt;

        for(int j = 1; j <= 2 * k - 1; ++j) printf(" ");

        printf("*\n");
    }

// LINE 2*k-1

    for(j = 1; j <= cnt / 2; ++j) printf(" ");
    printf("*");
    for(; j <= k - 1; ++j) printf(" ");
    --cnt;

    for(int i = 1; i <= k; ++i) printf(" ");

    for(int i = 1; i <= k; ++i) printf("*");
    printf("\n");
}
```

## E 拾贝

| 难度 | 考点 |
| --- | --- |
| 2 | 数组，循环 |

### 题目

#### 题目描述

给出 $n$ 个数 $a_1, a_2, \dots, a_n$ 。有 $t$ 次询问，每次给出一个 $k$ ，求前 $k$ 个数中最大值的第一次出现的位置。

#### 输入格式

第一行两个整数 $n$ 和 $t$ 。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$ 。

接下来 $t$ 行，每行一个整数 $k$ 。

#### 输出格式

每次询问输出一行一个整数，表示前 $k$ 个数中最大值第一次出现的下标（下标从 $1$ 开始）。

#### 样例输入

```text
5 3
1 5 3 5 2
1
3
5
```

#### 样例输出

```text
1
2
2
```

### 答案

### 题目分析

题目大意：给出一个数组 a[] ，找到它前 $k$ 项最大值**第一次**出现的位置。

可以在 $t$ 次询问之前用一个数组 `max_id[]` 来储存答案，每读入一个数更新一次 `max_id[]` 数组。

具体办法为：每读入一个数 `a[i]` ，判断这个数是否严格大于前一项 `max_id[i-1]` 这个位置的值 `a[max_id[i-1]]` ，如果严格大于， `max_id[i]` 就是当前的 `i` ，否则就是前一项的位置 `max_id[i-1]` 。

### 示例代码

```c
#include <stdio.h>
int a[200005];
int max_id[200005];
int main(){
    int n,t;
    scanf("%d%d",&n,&t);
    for(int i=1;i<=n;i++){
        scanf("%d",&a[i]);
        if(a[i]>a[max_id[i-1]]){
            max_id[i]=i;
            //i从1开始，这样max_id[0]的值是0，a[max_id[0]]也是0，一定比a[1]小。
        }
        else{
            max_id[i]=max_id[i-1];
        }
    }
    while(t--){
        int k;
        scanf("%d",&k);
        printf("%d\n",max_id[k]);
    }
    return 0;
}
```

## F 生日悖论

| 难度 | 考点 |
| --- | --- |
| 1 | 浮点数运算，循环 |

### 题目

#### 题目描述

一年按 $365$ 天算。 $n$ 个人的生日互不相同的概率为

$$
p = \frac{365}{365} \times \frac{364}{365} \times \frac{363}{365} \times \cdots \times \frac{366 - n}{365}
$$

给定 $t$ 组询问，每组给出一个 $n$ ，求对应的 $p$ 。

#### 输入格式

第一行一个整数 $t$ 。

接下来 $t$ 行，每行一个整数 $n$ 。

#### 输出格式

每组询问输出一行一个浮点数，保留 $6$ 位小数。

#### 样例输入

```text
2
1
23
```

#### 样例输出

```text
1.000000
0.492703
```

### 答案

### 题目分析

从第一个人开始考虑，目前，365 个生日无人占用，那么他可以在这 365 天里任选一天作为生日。对于第二个人，由于前一个人已经占用了 1 天，因此第二个人不可以选择这天作为生日，只有 364 天可以选择。推广到第 $i$ 个人，由于前 $i - 1$ 个人已经占用了 $i - 1$ 天，因此第 $i$ 个人只有 $366 - i$ 天可以选作自己的生日。因此我们可以得到，对于 $n$ 个人来说，他们的生日互不相同的概率为：

$$
p = \frac{365}{365} \times \frac{364}{365} \times \frac{363}{365} \times \cdots \times \frac{366 - n}{365}
$$

注意在 C 语言中，两个整型相除得到的是整型。因此如果要得到浮点数需要将分子或分母强制转换为浮点型。

### 示例代码

```c
#include <stdio.h>
int main(void)
{
    int t, n;
    scanf("%d", &t);
    while (t--)
    {
        scanf("%d", &n);
        double ans = 1;
        for (int i = 0; i < n; i++)
        {
            ans *= (365 - i) / 365.0; // 注意这里要使用 double 类型的除法
        }
        printf("%.6f\n", ans);
    }

    return 0;
}
```

## G 奇迹！下雪啦！

| 难度 | 考点 |
| --- | --- |
| 3 | 二维数组 |

### 题目

#### 题目描述

雪花一层层落下。第 $\mathit{iter}$ 层（ $\mathit{iter}$ 从 $0$ 开始）落下时，先把已有的图案整体旋转 $90^\circ$ ，即新图案第 $i$ 行第 $j$ 列取旧图案第 $\mathit{width} - j - 1$ 行第 $i$ 列的值，再在新图案的最后一行填入本层的编号 $\mathit{iter} + 1$ 。

一共落 $n$ 层，输出最终图案。最终图案有 $\left\lceil \frac{n+1}{2} \right\rceil$ 行、 $\left\lfloor \frac{n+1}{2} \right\rfloor$ 列。

#### 输入格式

一行一个整数 $n$ 。

#### 输出格式

按行输出最终图案，每行从左到右输出该行的数字，每个数字后面跟一个空格。

#### 样例输入

```text
7
```

#### 样例输出

```text
6 5 5 5 
6 2 1 4 
6 3 3 4 
7 7 7 7 
```

### 答案

### 题目分析

考虑两个数组 arr 和 \_arr ，每次将 arr 中的元素翻转 $90^\circ$ 置入 \_arr ，满足

$$
\_arr(i, j) = arr(width - j - 1, i)
$$

并在 \_arr 最后一行加入最新的一层雪，每次 iter 结束后，将 \_arr 中的元素复制到 arr 中并清空。

### 示例代码 1

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int main()
{
    int n;
    int arr[100][100];
    int _arr[100][100];
    scanf("%d", &n);
    for (int iter = 0; iter < n; iter++)
    {
        int width = 1 + iter / 2;
        int height = 1 + (iter + 1) / 2;
        if (height == 1 && width == 1)
        {
            arr[0][0] = 1;
            _arr[0][0] = 1;
        }
        for (int i = 0; i < height - 1; i++)
        {
            for (int j = 0; j < width; j++)
            {
                _arr[i][j] = arr[width - j - 1][i];
            }
        }
        for (int i = 0; i < width; i++)
        {
            _arr[height - 1][i] = iter + 1;
        }
        if (iter == n - 1)
        {
            for (int i = 0; i < height; i++)
            {
                for (int j = 0; j < width; j++)
                {
                    printf("%d ", _arr[i][j]);
                }
                printf("\n");
            }
            return 0;
        }
        memcpy(arr, _arr, 100 * 100 * sizeof(int));
        memset(_arr, 0, 100 * 100 * sizeof(int));
    }
    return 0;
}
```

### 思路 2（By Moca）

对于输入的一个 $n$，不难发现最后答案的行数是 $\left\lceil \frac{n+1}{2} \right\rceil$，列数是 $\left\lfloor \frac{n+1}{2} \right\rfloor$；每次从右下角开始（这个元素是 $n$）往内圈走，每转一次弯就要将对应的数字 $-1$，这个思路就与蛇形数组非常相似了，可以参考 P5731 蛇形方阵 的题解（各位同学也可以尝试做一下这道题），区别仅仅在于初始元素的位置不同，以及我们这道题是转一次弯输出元素才 $-1$；这样的做法只需要最多将每个位置遍历一次，不需要数组的拷贝，更加高效。

## I Hide an integer

| 难度 | 考点 |
| --- | --- |
| 3 | 进制转换 |

### 题目

#### 题目描述

平衡五进制的每一位取自 $\{-2, -1, 0, 1, 2\}$ ，其中 $-1$ 用 A 表示， $-2$ 用 B 表示。

给定 $T$ 个非负整数 $n$ ，分别输出它们的平衡五进制表示。 $n = 0$ 时输出 0。

#### 输入格式

第一行一个整数 $T$ 。

接下来 $T$ 行，每行一个非负整数 $n$ 。

#### 输出格式

每行一个字符串，表示对应 $n$ 的平衡五进制表示。

#### 样例输入

```text
4
0
5
8
2024
```

#### 样例输出

```text
0
10
2B
1B110A
```

### 答案

### 题目分析

首先，把一个数转化为五进制表示是容易的，只需要每次取出该数除以 $5$ 的余数作为新的数位（从低位到高位填写），再把该数除以 $5$ 即可。

然后，考虑平衡五进制和五进制的关系。我们考虑从低位到高位扫描数位，进行这样一个过程：

- 如果当前数位为 $0, 1, 2$，则当前数位保持不变。

- 如果当前数位为 $3, 4, 5$，则当前数位上的数字减去 $5$，高一位数位上的数字加上 $1$。（如果不存在高一位是数位，则手动扩充一下）

最后从高位到低位按要求输出即可。

注意以上过程中对 $0$ 的特判。

### 示例代码

```c
#include <stdio.h>

int main() {
    int T, n;
    scanf("%d", &T);
    for (int i = 1; i <= T; ++i) {
        scanf("%d", &n);
        if (n == 0) { //对0特判
            printf("0\n");
        } else {
            int digit[20];//存放各数位
            int digit_count = 0;
            while (n > 0) {//逐步转化为五进制
                digit[digit_count] = n % 5;
                n /= 5;
                ++digit_count;
            }
            for (int i = 0; i < digit_count; ++i) {//转化为平衡五进制
                if (digit[i] >= 3) {
                    if (i + 1 == digit_count) {
                        digit[i + 1] = 0;
                        ++digit_count;
                    }
                    digit[i] -= 5;
                    digit[i + 1] += 1;
                }
            }
            for (int i = digit_count - 1; i >= 0; --i) {//输出
                if (digit[i] == -2) {
                    printf("B");
                } else if (digit[i] == -1) {
                    printf("A");
                } else {
                    printf("%d", digit[i]);
                }
            }
            printf("\n");
        }
    }
    return 0;
}
```

### Extra

实际上，本题一开始是想出成包含负数的情况的，虽然最后并没有出现，但是你可以思考这样一个问题：平衡五进制下，一个数的负数的表示和这个数本身的表示有什么联系？

样例里加密了一个单词：Hyacinth。

## O 更好的isprime

| 难度 | 考点 |
| --- | --- |
| 5 | 函数 |

### 题目

#### 题目描述

题目给出了快速幂函数 qpow 和素性测试函数 Miller_Rabin_check(a, n)，后者表示以 $a$ 为基底对 $n$ 做一次 Miller-Rabin 素性测试。

对范围 $[1, 2^{32}]$ 内的整数，只要它能分别通过以 $2$ 、 $7$ 、 $61$ 为基底的 Miller-Rabin 素性测试，它就一定是素数。请利用给出的函数实现素数判断。

本题时限 1500ms，恰好是标程运行时间的两倍，使用传统的 $O(\sqrt{n})$ 判断方法无法通过；即使使用 Miller_Rabin_check 也不要做过多无用功，否则可能被卡常。

#### 输入格式

第一行一个整数 $t$ 。

接下来 $t$ 行，每行一个整数 $n$ 。

#### 输出格式

每行一个字符串， $n$ 是素数输出 Yes，否则输出 No。

#### 样例输入

```text
3
2
7
9
```

#### 样例输出

```text
Yes
Yes
No
```

#### 数据范围

$1 \le n \le 2^{32}$

### 答案

### 题目分析

本题主要考察函数调用，无需真正理解函数内部实现过程，而只需考虑外部包装。

> 不过对于范围 $[1, 2^{32}]$ 的数字，只要它能分别通过 $2, 7, 61$ 这三个数为基底的 Miller-Rabin 素性测试，它就一定是素数。

所以，你只需要调用三次 `Miller_Rabin_check` ，对传进来的数字进行以这三个数为基底的 Miller-Rabin 素性测试即可。

注意，本题时限 1500ms 恰好是 std 运行时间的两倍，所以使用传统的 $O(\sqrt{n})$ 的判断方法是无法通过的。就算使用 `Miller_Rabin_check` ，也不要做过多的无用功，否则可能会被卡常。

### 示例代码

```c
#include <stdio.h>
int qpow(int a, long long n, int mod)
{
    int ans = 1;
    int base = a;
    while (n > 0)
    {
        if (n & 1)
        {
            ans = ans * (long long)base % mod;
        }
        base = (long long)base * base % mod;
        n >>= 1;
    }
    return ans;
}

int Miller_Rabin_check(int a, int n) // a是基底，n是你拿来进行素性测试的数
{
    int u = n - 1;
    while (u % 2 == 0)
    {
        u /= 2;
    }
    int v = qpow(a, u, n);
    if (v == 1)
        return 1;
    while (u <= n - 1)
    {
        if (v == n - 1)
            return 1;
        if (v == 1)
            return 0;
        v = 1ll * v * v % n;
        u *= 2;
    }
    return 0;
}
int isprime(int n)
{
    if (n == 2 || n == 7 || n == 61)
        return 1;
    if (n % 2 == 0)
        return 0;
    return Miller_Rabin_check(2, n) && Miller_Rabin_check(7, n) && Miller_Rabin_check(61, n);
}
int main(void)
{
    int n, t;
    scanf("%d", &t);
    while (t--)
    {
        scanf("%d", &n);
        if (isprime(n))
        {
            printf("Yes\n");
        }
        else
        {
            printf("No\n");
        }
    }
    return 0;
}
```

## BE Deadline 的艺术（进阶版）

### 题目

#### 题目描述

给定一个起始日期（用 $8$ 位数字表示，例如 20240101 表示 2024 年 1 月 1 日）和一个操作编号 $b$ ：

- $b = 0$ ：再读入一个整数 $c$ ，输出起始日期之后第 $c$ 天的日期；
- $b = 1$ ：再读入一个 $8$ 位日期，输出它与起始日期相差的天数（后一个日期减前一个日期，可以为负数）；如果后一个日期不是合法日期，输出 WR0NG DATE!!!；
- $b = 2$ ：输出 qwq。

#### 输入格式

第一行一个整数 $t$ ，表示数据组数。

每组数据先是一个 $8$ 位数字的起始日期，接着一个整数 $b$ ；当 $b = 0$ 时再跟一个整数 $c$ ，当 $b = 1$ 时再跟一个 $8$ 位数字的日期。

#### 输出格式

每组数据输出一行。 $b = 0$ 时按 %04d-%02d-%02d 的格式输出日期， $b = 1$ 时输出相差的天数或 WR0NG DATE!!!， $b = 2$ 时输出 qwq。

#### 样例输入

```text
4
20240101 0 30
20240101 1 20240301
20240101 1 20240230
20240101 2
```

#### 样例输出

```text
2024-01-31
60
WR0NG DATE!!!
qwq
```

### 答案

### 题目分析

一道乏善可陈的日期题，根据题意解决问题即可。

### 示例代码

```c
#include <stdio.h>

int isLeapYear(int year)
{
    if ((year % 4 == 0 && year % 100 != 0) || year % 400 == 0)
        return 1;
    return 0;
}

const int mon[13] = { 0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31 };

int checkDate(int year, int month, int day)
{
    if (day > 31 || month < 1 || month > 12 || day < 1)
        return 0;
    if (isLeapYear(year)) {
        if ((month == 2 && day > 29) || (month != 2 && day > mon[month]))
            return 0;
    } else {
        if (day > mon[month])
            return 0;
    }
    return 1;
}

int getDaysCount(int year, int month, int day)
{
    int tot = 0;
    for (int i = 1; i < month; ++i) {
        tot += mon[i] + (i == 2 && isLeapYear(year) ? 1 : 0);
    }
    tot += day;
    return tot;
}

int main()
{
    int t;
    scanf("%d", &t);
    while (t--) {
        int year, month, day;
        scanf("%4d%2d%2d", &year, &month, &day);
        int b;
        scanf("%d", &b);
        if (b != 2) {
            if (b == 0) {
                int c;
                scanf("%d", &c);
                while (c > 0) {
                    int dayCount = mon[month] + (month == 2 && isLeapYear(year) ? 1 : 0);
                    if (day + c <= dayCount) {
                        day += c;
                        c = 0;
                    } else {
                        c -= (dayCount - day + 1);
                        day = 1;
                        ++month;
                        if (month > 12) {
                            month = 1;
                            ++year;
                        }
                    }
                }
                printf("%04d-%02d-%02d\n", year, month, day);
            } else {
                int yy, mm, dd;
                scanf("%4d%2d%2d", &yy, &mm, &dd);
                if (checkDate(yy, mm, dd) == 0) {
                    printf("WR0NG DATE!!!\n");
                } else {
                    int cnt1 = (isLeapYear(year) ? 366 : 365) - getDaysCount(year, month, day);
                    int cnt2 = getDaysCount(yy, mm, dd);
                    int tot = cnt1 + cnt2;
                    for (int y = year + 1; y < yy; ++y) {
                        tot += isLeapYear(y) ? 366 : 365;
                    }
                    tot -= (year == yy ? (isLeapYear(year) ? 366 : 365) : 0);
                    printf("%d\n", tot);
                }
            }
        } else {
            printf("qwq\n");
        }
    }
}
```

## BT mod 2024

| 难度 | 考点 |
| --- | --- |
| 3 | 字符串，高精度 |

### 题目

#### 题目描述

$n$ 是一个位数可达 $10^6$ 的超长整数，int、long long、unsigned long long 都无法存储，需要用字符串读入。给定 $m$ 和 $n$ ，求 $n \bmod m$ 。

由于 $n$ 太长，无法直接计算，可以利用

$$
(10k + b) \bmod m = (10 (k \bmod m) + b) \bmod m
$$

从高位到低位逐位处理，其中 $0 \le b \le 9$ 是当前最低位。每次算出的中间结果都不超过 $m$ ，重复枚举每一位即可。

#### 输入格式

第一行一个整数 $m$ 。

接下来是一个超长整数 $n$ ，以字符流的形式给出，读到文件结束为止。

#### 输出格式

一行一个整数，表示 $n \bmod m$ 。

#### 样例输入

```text
2024
123456789012345678901234567890
```

#### 样例输出

```text
1602
```

#### 数据范围

$n$ 的位数不超过 $10^6$

### 答案

### 题目分析

输入的时候， $n$ 最长可能有 $10^6$ 位，而不论是 `int` 、 `long long` 、还是 `unsigned long long` ，显然都无法存储这么多位。于是我们想到可以拿字符串来存储 $n$。如果用字符串来存储 $n$，那么该如何计算 $n \bmod m$ 呢。我们想，因为 $n$ 太长了，所以我们一定没有办法直接计算 $n \bmod m$，有没有什么办法把我们无法计算的东西转化成我们能计算的东西呢？

我们不难发现，对于 $(10 * k + b) \bmod m$，其中 $0 \le b \le 9$（代表最低位），有

$$
(10 * k + b) \bmod m = (10 * (k \bmod m) + b) \bmod m
$$

每次计算出的结果都能保证不大于 $m$，乘 $10$ 也是我们能用 `long long` 或者 `unsigned int` 来表示的，就这样重复的枚举每一位，就能求出一个超长的 $n$ 对一个不太大（起码我们能直接用基本数据类型标识）的 $m$ 取模的结果。

### 示例代码

```c
#include <stdio.h>
int main() {
    long long n = 0, mod;
    char c;
    scanf("%lld\n", &mod);
    while (scanf("%c", &c) != EOF) {
        n = (n * 10 + c - '0') % mod;
    }
    printf("%lld", n);
    return 0;
}
```
