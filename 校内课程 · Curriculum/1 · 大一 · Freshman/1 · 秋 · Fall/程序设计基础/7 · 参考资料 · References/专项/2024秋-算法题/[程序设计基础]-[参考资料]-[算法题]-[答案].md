## H 吉他与孤独与蓝色星球！

| 难度 | 考点 |

| 5 | 双指针 |

### 题目

#### 题目描述

给出一个长度为 $n$ 的整数序列，每一个数都在 $[1, m]$ 中。求有多少个长度为 $m$ 的子段恰好是 $1 \sim m$ 的一个排列。

把子段 $[l_0, r_0]$ 向右移动一位得到 $[l_0+1, r_0+1]$ 时，真正改变的只有 $l_0$ 与 $r_0+1$ 两个位置，其余计数可以继承，因此用双指针即可做到 $O(n)$ 。

#### 输入格式

第一行两个整数 $n$ 和 $m$ 。第二行 $n$ 个整数。

#### 输出格式

一行一个整数。

#### 样例输入

```text
5 3
1 2 3 2 1
```

#### 样例输出

```text
2
```

#### 数据范围

$1 \le n, m \le 10^6$ 。

### 答案

### 题目分析

> 给出长度为 $n$ 的整数序列，每一个数都在 $[1, m]$ 中，求有多少个长度为 $m$ 的子段是一个 $m$ 的排列。
>
> $1 \le n, m \le 10^6$

#### 88 %

枚举每一个长度为 $m$ 的子段，这样的子段一共有 $n - m + 1(m \le n)$ 个。对于每一个子段，都从头到尾扫一遍，并使用数组统计每种数出现的个数，从而判断出该子段是否符合要求。时间复杂度 $O(nm)$。

#### 100%

观察发现，对于一个长度为 $m$ 的子段 $[l_0, r_0]$，将其向右移动一位，就得到另一个长度为 $m$ 的子段 $[l_0 + 1, r_0 + 1]$。而真正发生“改变”的位置只有 $l_0$ 和 $r_0 + 1$，其余位置的数据都可以继承。于是我们可以从子段 $[1, m]$ 开始，每次向右移动得到 $[2, m + 1], [3, m + 2], \cdots$，每次移动都只需要关注两个位置的改变，从而避免了重复统计。时间复杂度 $O(n)$。

### 示例代码

```c
#include <stdio.h>
#include <string.h>
#define N 1000005
    int a[N], cnt[N];
int main() {
    int n = 0, m = 0;
    scanf("%d%d", &n, &m);
    for (int i = 1; i <= n; i++)
        scanf("%d", &a[i]);
    if (n < m) {
        printf("0\n");
        return 0;
    }
    int tot = 0;
    for (int i = 1; i <= m; i++) {
        if (cnt[a[i]] == 1) tot--;
        cnt[a[i]]++;
        if (cnt[a[i]] == 1) tot++;
    }
    int res = 0;
    for (int i = 1; i + m <= n; i++) {
        if (tot == m) res++;
        if (cnt[a[i]] == 1) tot--;
        cnt[a[i]]--;
        if (cnt[a[i]] == 1) tot++;

        if (cnt[a[i + m]] == 1) tot--;
        cnt[a[i + m]]++;
        if (cnt[a[i + m]] == 1) tot++;
    }
    if (tot == m) res++;
    printf("%d\n", res);
    return 0;
}
```

### 题目

#### 题目描述

数织（Nonogram）。给定一个 $n \times n$ 的方格，第 $i$ 行的提示给出该行从左到右每一段连续涂色格子的长度，第 $j$ 列的提示给出该列从上到下每一段连续涂色格子的长度。输出一组合法的涂色方案。

#### 输入格式

第一行一个整数 $n$ 。接下来 $n$ 行，每行若干个整数，依次是第 $1$ 行到第 $n$ 行的提示；再接下来 $n$ 行，每行若干个整数，依次是第 $1$ 列到第 $n$ 列的提示。

#### 输出格式

$n$ 行，每行一个长度为 $n$ 的 `01` 串， `1` 表示该格涂色， `0` 表示未涂色。

#### 样例输入

```text
3
1 1
3
1 1
3
1
3
```

#### 样例输出

```text
101
111
101
```

#### 数据范围

强数据点为 $15 \times 15$ 的方格，涂色数量为 $114 / 225$ ；参考代码基本能保证涂色数量大于等于 $100 / 225$ 的所有情况。

### 答案

### 题目分析

本题的强数据点（数据点 2）的涂色数量为 114 / 225，密度并不算低，参考代码在 OJ 评测机上运行时间为 1ms。本题时限 3000ms 是考虑剪枝本身的不确定性，因此放出更多时限。实际上，参考代码仍无法保证 3000ms 内解决数据范围内的所有可能情况，但基本能保证涂色数量大于等于 100 / 225 的所有情况。

此题一个最朴素最暴力的做法，就是枚举行的情况，验证列的情况。可是，这个做法过于暴力，是无法通过的。

那么，一个较好的剪枝思路是，一旦出现列无法通过的情况，就立刻停止当前行的枚举，回溯。

标程的剪枝方法是，对每个格子分出两种情况：可能涂色吗？可能不涂色吗？对一个格子涂色之后，会对这个格子所在行和列的部分格子是否可能涂色的状况产生影响。在搜索到一个格子后，如果它所在行或列告诉它不能涂色，就剪掉涂色的枝。如果它所在行或所在列告诉它不能不涂色，就剪掉不涂色的枝。

### 示例代码

```c
#include <stdio.h>
#include <stdlib.h>
typedef struct
{
    int block[20]; // 原始数据，常量
    int num;       // 目前读到原始数据的第几位，变量
    int wid;       // 目前遍历到当前位置之后，剩下部分的宽度
} Data;
struct Cases
{
    int color;   // 为 1，则有涂色这个情况是不可能的
    int nocolor; // 为 1，则无涂色这个情况是不可能的
};
typedef struct
{
    struct Cases row[30];
} Row;
typedef struct
{
    struct Cases column[30];
} Column;
Data r[30], c[30];
int nono[30][30];
Row row[30];
Column column[30];
int n;
void dfs(int, int);
void printnono(int[30][30]);
void getData(Data *);
int next_int(char **p);
int main(void)
{
    int i;
    scanf("%d", &n);
    getchar();
    for (i = 0; i < n; i++)
        getData(&r[i]);
    for (i = 0; i < n; i++)
        getData(&c[i]);
    dfs(0, 0);
    return 0;
}
void dfs(int i, int j)
{
    int len1, len2;
    if (i == n)
    {
        printnono(nono);
        exit(0);
        return;
    }

    // begin set
    if (j == 0 || nono[i][j - 1] == 0)
    {
        if (r[i].wid == n - j)
            row[i].row[j].nocolor = 1;
        if (r[i].wid == 0)
            row[i].row[j].color = 1;
    }
    if (i == 0 || nono[i - 1][j] == 0)
    {
        if (c[j].wid == n - i)
            column[j].column[i].nocolor = 1;
        if (c[j].wid == 0)
            column[j].column[i].color = 1;
    } // end set
    if (!row[i].row[j].color && !column[j].column[i].color) // 该点涂色的情况可能出现吗？
    {
        nono[i][j] = 1;
        r[i].wid--;
        c[j].wid--;

        // begin set
        if (j == 0 || nono[i][j - 1] == 0) // 这代表该点是主动涂色，需要带动后面的一些点被动涂色
        {
            len1 = r[i].block[r[i].num];
            for (int k = 1; k < len1; k++)
                row[i].row[j + k].nocolor = 1;
            if (j + len1 < n)
                row[i].row[j + len1].color = 1;
            r[i].num++;
        }
        if (i == 0 || nono[i - 1][j] == 0)
        {
            len2 = c[j].block[c[j].num];
            for (int k = 1; k < len2; k++)
                column[j].column[i + k].nocolor = 1;
            if (i + len2 < n)
                column[j].column[i + len2].color = 1;
            c[j].num++;
        } // end set
        if (j == n - 1)
            dfs(i + 1, 0);
        else
            dfs(i, j + 1);
        r[i].wid++;
        c[j].wid++;

        // begin reset
        if (j == 0 || nono[i][j - 1] == 0)
        {
            for (int k = 1; k < len1; k++)
                row[i].row[j + k].nocolor = 0;
            if (j + len1 < n)
                row[i].row[j + len1].color = 0;
            r[i].num--;
        }
        if (i == 0 || nono[i - 1][j] == 0)
        {
            for (int k = 1; k < len2; k++)
                column[j].column[i + k].nocolor = 0;
            if (i + len2 < n)
                column[j].column[i + len2].color = 0;
            c[j].num--;
        } // end reset
    }
    if (!row[i].row[j].nocolor && !column[j].column[i].nocolor) // 该点不涂色的情况可能出现吗？
    {
        nono[i][j] = 0;
        int flag1 = 0, flag2 = 0;
        // begin set
        if (j > 0 && nono[i][j - 1] == 1 && r[i].wid > 0) // 这代表该点是被动不涂色
        {
            r[i].wid--;
            flag1 = 1;
        }
        if (i > 0 && nono[i - 1][j] == 1 && c[j].wid > 0)
        {
            c[j].wid--;
            flag2 = 1;
        } // end set

        if (j == n - 1)
            dfs(i + 1, 0);
        else
            dfs(i, j + 1);

        // begin reset
        if (flag1)
            r[i].wid++;
        if (flag2)
            c[j].wid++;
        // end reset
    }
    // begin reset
    if (j == 0 || nono[i][j - 1] == 0)
    {
        if (r[i].wid == n - j)
            row[i].row[j].nocolor = 0;
        if (r[i].wid == 0)
            row[i].row[j].color = 0;
    }
    if (i == 0 || nono[i - 1][j] == 0)
    {
        if (c[j].wid == n - i)
            column[j].column[i].nocolor = 0;
        if (c[j].wid == 0)
            column[j].column[i].color = 0;
    } // end reset
}
void getData(Data *p)
{
    char str[128], *ptr;
    gets(str);
    ptr = str;
    int i = 0, sum = 0, val;
    while ((val = next_int(&ptr)) != -1)
    {
        p->block[i++] = val;
        sum += val;
    }
    p->num = 0;
    sum += i - 1;
    p->wid = sum;
}
int next_int(char **p)
{
    while (**p < '0' || **p > '9')
    {
        if (**p == 0)
            return -1;
        (*p)++;
    }
    int val = 0;
    while (**p >= '0' && **p <= '9')
    {
        val = val * 10 + **p - '0';
        (*p)++;
    }
    return val;
}
void printnono(int nono[30][30])
{
    int i, j;
    for (i = 0; i < n; i++)
    {
        for (j = 0; j < n; j++)
        {
            putchar(nono[i][j] + '0');
        }
        putchar('\n');
    }
}
```

## BQ 身高问题(concert)

| 难度 | 考点 |
| --- | --- |
| 8 | 数论，概率 |

### 题目

#### 题目描述

对 $1 \sim n$ 的全排列 $P$ ，记 $\tau(P)$ 为 $P$ 的逆序对个数。给定 $n$ 和 $k$ ，求

$$\sum_P k^{\tau(P)} + \sum_P \tau(P)^2$$

对 $10^9+7$ 取模的结果，其中求和遍历 $1 \sim n$ 的全部 $n!$ 个排列。

把 $i$ 加入 $1 \sim i-1$ 的排列时，可以贡献 $0$ 到 $i-1$ 个逆序对，因此

$$\sum_P k^{\tau(P)} = \frac{k^i-1}{k-1} \cdot \sum_{P'} k^{\tau(P')}$$

而 $\sum_P \tau(P)$ 与 $\sum_P \tau^2(P)$ 也可以同样递推。

#### 输入格式

第一行一个整数 $t$ ，表示数据组数。接下来 $t$ 行，每行两个整数 $n$ 和 $k$ 。

#### 输出格式

每组数据输出一行一个整数。

#### 样例输入

```text
1
2 2
```

#### 样例输出

```text
4
```

### 答案

### 题目分析

首先肯定是分成两部分求。考虑推式子：

1. 设 $f(i) = \sum_P k^{\tau(P)}$， $P$ 是一个 1 到 $i$ 的序列。考虑加入 $i$ 可以贡献的逆序对个数。

   $$
   f(i) = \sum_{j=0}^{i-1} k^j f(i-1) = \frac{k^i - 1}{k - 1} f(i-1)
   $$

2. 设 $f(i) = \sum_P \tau^2(P)$， $g(i) = \sum_P \tau(P)$， $P$ 是一个 1 到 $i$ 的序列。考虑加入 $i$ 可以贡献的逆序对个数。

   $$
   \begin{aligned}
   f(i) &= \sum_{j=0}^{i-1} \sum_{P'} (\tau(P') + j)^2 \\
   &= \sum_{j=0}^{i-1} \sum_{P'} (\tau^2(P') + j^2 + 2j\tau(P')) \\
   &= i \times f(i-1) + \square_{i-1} \times (i-1)! + i(i-1)g(i-1)
   \end{aligned}
   $$

   $$
   g(i) = \sum_{j=0}^{i-1} \sum_{P'} (\tau(P') + j) = i \times g(i-1) + i(i-1)/2 \times (i-1)!
   $$

### 示例代码

```c
#include<stdio.h>
#include<string.h>
#include<math.h>
#include<stdlib.h>

typedef long long ll;
const ll p = 1e9+7;

ll inv(ll x)
{
    ll ans=1,a=x,b=p-2;
    for(; b; b>>=1,(a*=a)%=p)
    if(b&1) (ans*=a)%=p;
    return ans;
}
void work()
{
    ll n,k;

    scanf("%lld%lld", &n, &k);

    ll ans1=1, e=1, in=inv(k-1);
    for(int i=1; i<=n; i++)
    e=e*k%p, ans1=ans1*(e-1+p)%p*in%p;

    ll ans2=0, g=0, jie=1, seq=0;
    for(ll i=1; i<=n; i++)
    {
        ans2=(i*ans2+jie*seq+i*(i-1)%p*g)%p;
        seq=(seq+i*i)%p;
        g=(g*i+i*(i-1)/2%p*jie)%p;
        jie=jie*i%p;
    }
    printf("%lld\n", (ans1+ans2)%p);
}
int main()
{
    int t;
    cin>>t;
    while(t-->0) work();
    return 0;
}
```

## BR 捅似你喵

| 难度 | 考点 |

| 7 | 贪心，前缀和，差分 |

### 题目

#### 题目描述

给定一个 $n$ 行 $m$ 列的矩阵，每个格子上有一个整数分数。你可以选定一个 $x \times y$ 的子矩阵大小，选定之后不能再更改；每次操作把某个 $x \times y$ 子矩阵内每个格子的分数都减去 1 。求最多能进行多少次操作。

对第一个格子，只能以它为子矩阵左上角的操作才能清除它；其余格子在它前面的格子都清零之后，若它还没有清零，也只能以它为左上角操作。因此对固定的 $x, y$ 可以按顺序扫描判断能否清零。

又因为 $x \times 1$ 与 $1 \times y$ 的子矩阵都能清零时， $x \times y$ 的子矩阵同样能清零，所以只需分别求出最大的可行 $x$ 与 $y$ ，答案即 $\frac{\sum a_{i,j}}{xy}$ 。

#### 输入格式

第一行两个整数 $n$ 和 $m$ 。接下来 $n$ 行，每行 $m$ 个整数。

#### 输出格式

一行一个整数，表示最多操作次数。

#### 样例输入

```text
2 2
1 1
1 1
```

#### 样例输出

```text
1
```

#### 数据范围

$n, m \le 200$ 。

### 答案

### 题目分析

> 这道题由于助教的疏忽，搬题修改题面的时候改错了题面的意思（原题意应该是下面的“子矩阵大小经选定就**不能再更改**”），给一些同学造成了困扰，在这里向各位同学诚挚道歉，以后我会多加注意的🥺。

注意：题目中的子矩阵大小经选定就**不能再更改**，在最初的题面中， `任意一个子矩阵` 的描述为 `选定一个` $x*y$ `大小的房间`

- 首先考虑在子矩阵大小确定的情况下，如何判断能否清零

  - 对于第一个格子，只能以它为子矩阵的左上角操作才能清除

  - 对于其他格子，在清除前面的格子后，如果这个格子还没有清零，只能以这个位置为左上角操作才能消除

  - 所以一种直观的判断能否清零的方法是：枚举每个格子，如果 $a_{i,j} > 0$，则使 $a_{i \sim i+x-1, j \sim j+y-1}$ 减去 $a_{i,j}$；如果 $a_{i,j} < 0$ 或 $a_{i,j} > 0 \wedge (i + x - 1 > n \vee j + y - 1 > m)$，则无法清零

- 于是暴力思路就是枚举每一种 $x, y$，再枚举判断能否敲完，时间复杂度 $O(n^3 m^3)$。（实际上求解时，由于可以事先判断 $x \times y$ 能否整除 $\sum a_{i,j}$，且如果不能清零会很快跳出，所以实际消耗的时间远小于理论复杂度，于是在使用二维树状数组优化减去 $a_{i,j}$ 的过程后就能通过本题）

- 进一步观察发现，由于枚举过程是从前到后的，我们没有必要实时地对每个 $a$ 都减去 $a_{i,j}$，只需要使用差分数组维护枚举过程中的修改操作，并同时维护当前位置的前缀和，就能做到 $O(1)$ 的单次修改，将时间复杂度降低到 $O(n^2 m^2)$

- 接下来不难发现，如果使用 $x \times 1$ 的子矩阵可以清零，同时使用 $1 \times y$ 的子矩阵可以清零，则使用 $x \times y$ 的子矩阵同样可以清零，简略证明如下

  - 每次选择的子矩阵左上角的点是目前分数非 0 的位置组成的图形中最上一行最左一列的点，我们设这个点还有 $s$ 分。

  - 以这个点为左上端点，对一个 $x \times 1$ 的矩阵中的每个点减去 $s$ 是合法的；

  - 于是在这个矩阵中，每个点都看作一个 $1 \times y$ 的矩阵的左上端点，对这 $x$ 个矩阵的所有点都减去 $s$ 也是合法的；

  - 所以 $x \times y$ 的矩阵是合法的

- 这种做法的时间复杂度为 $O((n+m)nm)$

### 示例代码

```c
#include<stdio.h>
#define N 210

long long n,m,a[N][N],c[N][N],x,y,t,sum;

int main()
{
    scanf("%lld%lld",&n,&m);
    for(long long i=1;i<=n;++i)
        for(long long j=1;j<=m;++j)
            scanf("%lld",&a[i][j]),sum+=a[i][j];
    for(x=n;x>=1;--x)
    {
        long long f=1;
        for(long long i=1;i<=n;++i)
            for(long long j=1;j<=m;++j)
                c[i][j]=0;
        for(long long i=1;i<=n;++i)
            for(long long j=1;j<=m;++j)
            {
                c[i][j]+=c[i-1][j];
                if(c[i][j]>a[i][j])
                {
                    f=0;
                    break;
                }
                if(c[i][j]<a[i][j])
                {
                    if(i+x-1>n)
                    {
                        f=0;
                        break;
                    }
                    else
                    {
                        t=a[i][j]-c[i][j];
                        c[i][j]+=t;
                        c[i+x][j]-=t;
                    }
                }
            }
        if(f)
            break;
    }
    for(y=m;y>=1;--y)
    {
        long long f=1;
        for(long long i=1;i<=n;++i)
            for(long long j=1;j<=m;++j)
                c[i][j]=0;
        for(long long i=1;i<=n;++i)
            for(long long j=1;j<=m;++j)
            {
                c[i][j]+=c[i][j-1];
                if(c[i][j]>a[i][j])
                {
                    f=0;
                    break;
                }
                if(c[i][j]<a[i][j])
                {
                    if(j+y-1>m)
                    {
                        f=0;
                        break;
                    }
                    else
                    {
                        t=a[i][j]-c[i][j];
                        c[i][j]+=t;
                        c[i][j+y]-=t;
                    }
                }
            }
        if(f)
            break;
    }
    printf("%lld",sum/(x*y));
    return 0;
}
```

## BS Contrasty Angeles

| 难度 | 考点 |

| 5 | 动态规划、后缀和 |

### 题目

#### 题目描述

一个环上有 $n$ 条边，每条边的长度可以是 $1 \sim m$ 中的任意整数。给定环上的两个点 $s$ 与 $t$ ，它们之间有且只有两条路径。求在所有边长赋值方案中，这两条路径长度较小者的总和，对 $10^9+7$ 取模。

记两条路径的边数分别为 $l_1 = t-s$ 与 $l_2 = n-(t-s)$ ，两条路径互不干扰。设 $dp[i][j]$ 为 $i$ 条边总长为 $j$ 的方案数，则

$$dp[i][j] = \sum_{k=\max\{j-m,0\}}^{j-1} dp[i-1][k],\qquad dp[0][0] = 1$$

记 $f[i] = dp[l_1][i]$ 、 $g[j] = dp[l_2][j]$ ，答案即

$$\sum_{i=1}^{nm} \sum_{j=1}^{nm} f[i]g[j]\min\{i, j\}$$

#### 输入格式

一行四个整数 $n$ 、 $m$ 、 $s$ 、 $t$ ，用空格分隔。

#### 输出格式

一行一个整数，表示答案对 $10^9+7$ 取模的结果。

#### 样例输入

```text
4 2 1 3
```

#### 样例输出

```text
42
```

### 答案

### 题目分析

我们发现环上 $s, t$ 的路径有且只有两条：顺时针和逆时针。

因此， $distance(s,t) = \min\{e_s + \cdots + e_{t-1}, e_t + \cdots + e_n + e_1 + \cdots + e_{s-1}\}$
进一步发现，**两条路径互不干扰。** 一条长度 $l_1 = t - s$，另一条长度 $l_2 = n - (t-s)$。

然后我们就发现问题和环没有关系了。

#### Phase 0: 纯暴力

不贴代码了。有 30% 的分数。

#### Phase 1: dp

我们记 $dp[i][j]$ 表示有 $i$ 条边时，长度为 $j$ 的方案数。易得

$$
\begin{cases}
dp[i][j] &= \sum_{k=\max\{j-m,0\}}^{j-1} dp[i-1][k] \\
dp[0][0] &= 1
\end{cases}
$$

求出 $dp[n][nm]$ 的复杂度为 $O(n^2 m^2)$。

显然，填充第一条路径需要填充 $l_1$ 条边，于是我们记 $f[i] = dp[l_1][i]$ 为**第一条路径长度为 $i$ 的方案数**。因此总共有 $m^{l_1}$ 种方法，即 $\sum_{i=l_1}^{l_1 \times m} = m^{l_1}$。由于第一条路径的长度在 $[l_1, l_1 \times m]$ 之间，其余的长度不可能取到，它们的 $f[i] = 0$。

我们记 $dp[l_2][i] = g[i]$ 为**第二条路径长度为 $i$ 的方案数**。显然， $f$ 和 $g$ 互不干扰。

我们做两次dp，总复杂度 $O((l_1)^2 m^2 + (l_2)^2 m^2) = O(n^2 m^2)$。

#### Phase 2: 统计答案

于是，我们枚举这些方案： $f[i] \times g[j]$ 表示**第一条路径长度为 $i$ 时，第二条路径长度为 $j$ 时，它们的总方案数**。它们的长度**均为** $\min\{i, j\}$。此时， $i \in [l_1, l_1 \times m], j \in [l_2, l_2 \times m]$。

$$
ans = \sum_{i=l_1}^{l_1 \times m} \sum_{j=l_2}^{l_2 \times m} f[i]g[j] \times \min\{i, j\}
$$

为了方便边界判定，我们发现如果 $i \notin [l_1, l_1 \times m]$ 时，长度不可能取到， $f[i] = 0$，对答案没有影响，所以为方便写代码，可以写 $i \in [1, nm]$ （ $l_1 \le n$）。同理， $j \in [1, nm]$。

$$
ans = \sum_{i=1}^{nm} \sum_{j=1}^{nm} f[i]g[j] \min\{i, j\}
$$

直接双重循环计算，它的复杂度为 $O(n^2 m^2)$。

### 示例代码1 (70%)

可以实现出 70% 的解法 $O(n^2 m^2)$：

```c
#include <stdio.h>

const long long p=1000000007;
long long dp[50+10][50*50+10];
int main()
{
    int n,m,s,t;
    scanf("%d%d%d%d",&n,&m,&s,&t);
    int l[2]={t-s,n-(t-s)};
    // Phase 1: dp
    dp[0][0]=1;
    for(int i=1;i<=n;i++)
        for(int j=0;j<=n*m;j++)
            for(int k=j-m;k<=j-1;k++)
                if(k>=0)
                {
                    dp[i][j]+=dp[i-1][k];
                    dp[i][j]%=p;
                }
    // Phase 2: answer
    long long ans=0;
    for(int i=0;i<=n*m;i++)
        for(int j=0;j<=n*m;j++)
        {
            int min;
            if(i<j) min=i;
            else min=j;
            ans+=dp[l[0]][i]*dp[l[1]][j]%p*min%p;
            ans%=p;
        }
    printf("%lld\n",ans);
    return 0;
}
```

#### Phase 3: 小技巧优化

此时我们发现，可以通过**滑动窗口**和**后缀和**优化的方式优化dp：

观察 Phase 1 中的状态转移方程式：

记 $sum[i][j] = \sum_{k=0}^{j} dp[i][k]$，

$$
\begin{aligned}
dp[i][j] &= \sum_{k=\max\{j-m,0\}}^{j-1} dp[i-1][k] \\
&= sum[i-1][j-1] - sum[i-1][j-m-1]
\end{aligned}
$$

可优化为 $O(n^2 m)$。

观察 Phase 2 中的统计式：

$$
\begin{aligned}
ans &= \sum_{i=1}^{nm} \sum_{j=1}^{nm} f[i]g[j] \min\{i, j\} \\
&= \sum_{k=1}^{nm} \sum_{i=1}^{nm} \sum_{j=1}^{nm} f[i]g[j][\min\{i, j\} = k] \\
&= \sum_{k=1}^{nm} \sum_{i,j \in [1,nm], \min\{i,j\}=k} f[i]g[j] \\
&= \sum_{k=1}^{nm} \left( f[k]g[k] + \sum_{i=k+1}^{nm} f[i]g[k] + \sum_{j=k+1}^{nm} f[k]g[j] \right)
\end{aligned}
$$

转化为连续和形式，可优化为 $O(nm)$。当然也可以容斥。

### 示例代码2 (100%)

Phase 1 采用滑动窗口优化，Phase 2 采用二维后缀和容斥优化。

总复杂度 $O(n^2 m + nm) = O(n^2 m)$，空间复杂度 $O(5nm) = O(nm)$。

```c
#include <stdio.h>
#include <string.h>

const long long p=1000000007;
int f[2][250010];
int sum[2][250010];
int temp[250010];
int main()
{
    int n,m,s,t;
    scanf("%d%d%d%d",&n,&m,&s,&t);
    int target[2]={t-s,n-(t-s)};
    for(int id=0;id<=1;id++)
    {
        int d=target[id],lim=d*m;
        f[id][0]=1;
        for(int i=1;i<=d;i++)
        {
            long long sum=0;
            memcpy(temp,f[id],sizeof(temp));
            for(int j=0;j<=lim;j++)
            {
                f[id][j]=sum%p;
                sum+=temp[j];
                if(j-m>=0)
                    sum-=temp[j-m];
            }
        }
        for(int i=n*m;i>=0;i--)
            sum[id][i]=(sum[id][i+1]+f[id][i])%p;
    }
    long long ans=0;
    for(int i=1;i<=n*m;i++)
        ans+=(((1ll*sum[0][i]*sum[1][i]-1ll*sum[0][i+1]*sum[1][i+1])%p+p)%p)*i%p;
    printf("%lld\n",ans%p);
    return 0;
}
```

总复杂度 $O(n^2 m)$，空间复杂度 $O(nm)$。

## BW WC，盒

| 难度 | 考点 |
| --- | --- |
| 9 | 动态规划，前缀和，矩阵加速 |

### 题目

#### 题目描述

在一个 $n$ 行 $m$ 列的网格上，从第 1 列的第 $sy$ 行出发。每一步向右走奇数格，行号可以不变、减 1 或加 1 ，且不能越出网格。求走到第 $m$ 列第 $sy$ 行的方案数，对 $10^6$ 取模。

设 $dp_{i,j}$ 为走到第 $i$ 行第 $j$ 列的方案数。因为每步只能走奇数格，同奇偶性的列转移形式相同，用前缀和的思想可得

$$dp_{i,j} = dp_{i-1,j-1} + dp_{i,j-1} + dp_{i+1,j-1} + dp_{i,j-2}$$

再用矩阵快速幂加速，总复杂度 $O(n^3 \log m)$ 。

#### 输入格式

一行三个整数 $n$ 、 $m$ 、 $sy$ ，用空格分隔。

#### 输出格式

一行一个整数，不足 6 位时补前导零。

#### 样例输入

```text
2 3 1
```

#### 样例输出

```text
000002
```

#### 数据范围

$n \le 55$ 。

### 答案

### 题目分析

- 暴力的 dp 转移并不难想

  - 设 $dp_{i,j}$ 表示跳到第 $i$ 行第 $j$ 列的方案数；

  - 对于第 $i$ 行，他只能从 $i - 1, i, i + 1$ 行转移，同时又因为只能跳奇数格， $j$ 只能从 $j - 1, j - 3 \ldots j - 2 \times k + 1$ 转移，于是就有了最暴力的转移方程

    $$
    dp_{i,j} = dp_{i-1,j-1} + dp_{i,j-1} + dp_{i+1,j-1} + dp_{i-1,j-3} + \cdots
    $$

  - 由于每次都只能向前走奇数格，于是奇偶性相同列的转移方程有相似之处，我们可以使用类似于前缀和的思想，转移方程就变为了

    $$
    dp_{i,j} = dp_{i-1,j-1} + dp_{i,j-1} + dp_{i+1,j-1} + dp_{i,j-2}
    $$

  - 于是我们就有了时间复杂度 $O(nm)$ 的动态规划算法

- 考虑使用矩阵加速

  - 定义初始矩阵为

    $$
    (dp_{1,j} \quad dp_{2,j} \quad \cdots \quad dp_{n,j} \quad dp_{1,j+1} \quad \cdots \quad dp_{n-1,j+1} \quad dp_{n,j+1})_{1 \times 2n}
    $$

  - 则转移矩阵为

    $$
    \begin{pmatrix}
    0 & 0 & 0 & \cdots & 0 & 1 & 0 & 0 & \cdots & 0 \\
    0 & 0 & 0 & \cdots & 0 & 0 & 1 & 0 & \cdots & 0 \\
    0 & 0 & 0 & \cdots & 0 & 0 & 0 & 1 & \cdots & 0 \\
    \vdots & \vdots & \vdots & \ddots & \vdots & \vdots & \vdots & \vdots & \ddots & \vdots \\
    0 & 0 & 0 & \cdots & 0 & 0 & 0 & 0 & \cdots & 1 \\
    1 & 0 & 0 & \cdots & 0 & 1 & 1 & & & \\
    0 & 1 & 0 & \cdots & 0 & 1 & 1 & 1 & & \\
    0 & 0 & 1 & \cdots & 0 & & 1 & \ddots & \ddots & \ddots \\
    \vdots & \vdots & \vdots & \ddots & \vdots & & & \ddots & \ddots & 1 \\
    0 & 0 & 0 & \cdots & 1 & & & & 1 & 1
    \end{pmatrix}_{2n \times 2n}
    $$

  - 最后答案为 $dp_{y,m}$，时间复杂度 $O(n^3 \log m)$。

### 十分重要的细节

- 以 $y = 1$ 为例，在初始化时，我们通常会使 $dp_{1,1} = 1$，但是在转移 $dp_{1,3}$ 时，注意方程 $dp_{1,3} = dp_{1,2} + dp_{2,2} + dp_{1,1}$，转为最初的方程， $dp_{1,3} = dp_{1,2} + dp_{2,2} + dp_{1,0} + dp_{2,0}$，这里的 $dp_{1,1}$ 就是 $dp_{1,0} + dp_{2,0}$，实际上应该是 0，但初始化为了 1。

- 如何避免？可以在定义初始矩阵的时候使用第 2, 3 列的值，从而避免了第 1 列的调用。

- 同时还应注意， $n, y$ 的值不同，初始矩阵的初始化也不同。

### 示例代码

```c
#include<stdio.h>
#include<string.h>

const long long P=1000000;
long long n,m,sy,ans;

typedef struct matrix
{
    long long h,l,a[110][110];
}matrix;

matrix fir,trans;

void init_(matrix *x,long long hh,long long ll,long long kind)
{
    x->h=hh,x->l=ll;
    memset(x->a,0,sizeof(x->a));
    if(kind)
        for(long long i=1;i<=x->h;++i)
            x->a[i][i]=1;
}

matrix mul(matrix a,matrix b)
{
    matrix ret;
    init_(&ret,a.h,b.l,0);
    for(long long i=1;i<=ret.h;++i)
        for(long long j=1;j<=ret.l;++j)
            for(long long k=1;k<=a.l;++k)
                ret.a[i][j]+=a.a[i][k]*b.a[k][j],ret.a[i][j]%=P;
    return ret;
}

matrix mpow(matrix a,long long b)
{
    matrix ret;
    init_(&ret,a.h,a.h,1);
    for(;b;b>>=1)
    {
        if(b&1) ret=mul(ret,a);
        a=mul(a,a);
    }
    return ret;
}
void Init()
{
    init_(&fir,1,n*2,0),init_(&trans,n*2,n*2,0);
    switch(n)
    {
        case 1:
            fir.a[1][1]=fir.a[1][n+1]=1;
            break;
        case 2:
            fir.a[1][1]=fir.a[1][2]=1;
            fir.a[1][n+1]=fir.a[1][n+2]=2;
            break;
        default:
            if(sy==1)
            {
                fir.a[1][1]=fir.a[1][2]=fir.a[1][n+3]=1;
                fir.a[1][n+1]=fir.a[1][n+2]=2;
            }
            else if(sy==n)
            {
                fir.a[1][n]=fir.a[1][n-1]=fir.a[1][n+n-2]=1;
                fir.a[1][n+n]=fir.a[1][n+n-1]=2;
            }
            else
            {
                fir.a[1][sy]=fir.a[1][sy+1]=fir.a[1][sy-1]=1;
                fir.a[1][n+sy]=3;
                fir.a[1][n+sy-1]=fir.a[1][n+sy+1]=2;
                if(sy-2>=1)
                    fir.a[1][n+sy-2]=1;
                if(sy+2<=n)
                    fir.a[1][n+sy+2]=1;
            }
            break;
    }
    for(long long i=1;i<=n;++i)
        trans.a[i][n+i]=trans.a[n+i][i]=trans.a[n+i][n+i]=1;
    for(long long i=2;i<n;++i)
        trans.a[n+i-1][n+i]=trans.a[n+i+1][n+i]=1;
    trans.a[n+2][n+1]=trans.a[n*2-1][n*2]=1;
}

int main()
{
    scanf("%lld%lld%lld",&n,&m,&sy);
    if(m==2)
    {
        printf("%06lld",1);
        return 0;
    }
    Init();
    trans=mpow(trans,m-3);
    fir=mul(fir,trans);
    printf("%06lld",fir.a[1][n+sy]);
    return 0;
}
```
