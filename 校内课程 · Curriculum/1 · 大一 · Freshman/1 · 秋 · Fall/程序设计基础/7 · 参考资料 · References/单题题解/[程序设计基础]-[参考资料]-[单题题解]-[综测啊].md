# 综测啊

| 难度 | 考点 |
| --- | --- |
| 1 | 不定组输入、分支判断、浮点输出 |

## 题目

### 题目描述

综测分数 $Y$ 由原始总分 $X$ 按所在区间换算得到：

| 区间 | 计算方式 |
| --- | --- |
| $0 \le X \le 100$ | $Y = X$ |
| $100 < X \le 150$ | $Y = 100 + 0.8(X-100)$ |
| $150 < X \le 200$ | $Y = 140 + 0.5(X-150)$ |
| $200 < X \le 300$ | $Y = 165 + 0.1(X-200)$ |

边界值 $X = 100$ 、 $150$ 、 $200$ 分别归入前三个区间，对应的 $Y$ 为 $100.0$ 、 $140.0$ 、 $165.0$ 。

### 输入格式

若干行，每行一个整数 $X$ ，读到文件结束为止。题目不给出数据组数。

### 输出格式

每组数据输出一行，保留一位小数。

### 样例输入

```text
90
120
218
```

### 样例输出

```text
90.0
116.0
166.8
```

### 数据范围

$0 \le X \le 300$ 。

## 题目分析

输入的 $X$ 就是原始总分。对于每组数据，只需判断 $X$ 所在的区间，再代入相应的公式计算 $Y$。

按区间上界从小到大判断，可以写成一条 `if`、`else if`、`else` 分支链：

| 判断条件 | 对应区间 | 计算方式 |
| --- | --- | --- |
| `x <= 100` | $0\le X\le 100$ | $Y=X$ |
| `x <= 150` | $100<X\le 150$ | $Y=100+0.8(X-100)$ |
| `x <= 200` | $150<X\le 200$ | $Y=140+0.5(X-150)$ |
| `else` | $200<X\le 300$ | $Y=165+0.1(X-200)$ |

执行到第二个分支时，第一个条件已经不成立，所以此时一定有 $X>100$，只需再判断 `x <= 150`。后面的分支同理。这样每组数据只会执行一个分支，而且能够覆盖所有合法的 $X$。注意不能将这几个条件写成互相独立的 `if`，否则较小的 $X$ 可能满足多个条件，导致结果被后面的计算覆盖。

边界值 $X=100$、 $150$、 $200$ 分别归入前三个区间，对应的 $Y$ 为 $100.0$、 $140.0$、 $165.0$。例如， $X=218$ 属于最后一个区间，因此 $Y=165+0.1\times(218-200)=166.8$。

本题没有给出数据组数，需要一直读到文件结束。`scanf("%d", &x)` 成功读入一个整数时返回 $1$，因此使用 `while (scanf("%d", &x) == 1)`，每次读入后计算并输出一次即可。

实际得分可能包含小数，应使用 `double` 保存，并用 `printf("%.1f\n", y)` 保留一位小数。由于 $X$ 为整数，各段公式的准确结果最多只有一位小数，在本题范围内直接计算并按这一格式输出即可。

每组数据只进行常数次判断和运算，时间复杂度为 $O(1)$，额外空间复杂度为 $O(1)$。

### 示例代码

```c
#include <stdio.h>

int main() {
    int x;
    while (scanf("%d", &x) == 1) {
        double y;
        if (x <= 100) {
            y = x;
        } else if (x <= 150) {
            y = 100 + 0.8 * (x - 100);
        } else if (x <= 200) {
            y = 140 + 0.5 * (x - 150);
        } else {
            y = 165 + 0.1 * (x - 200);
        }
        printf("%.1f\n", y);
    }
    return 0;
}
```
