# 两种整包

| 难度 | 考点 |
| --- | --- |
| 5 | 整数运算、等量替换、枚举范围、向上取整 |

## 题目

### 题目描述

需要 $n$ 件物品。商店只整包出售：甲种包装每包 $a$ 件、价格 $p$ ；乙种包装每包 $b$ 件、价格 $q$ 。可以买任意多包，允许买到的件数超过 $n$ 。求总价最低的购买方案。

总价相同时，取买到件数最少的方案；件数也相同时，取甲包数最少的方案。

由等量替换可知，若 $bp < aq$ ，最优方案一定满足乙包数 $y < a$ ；若 $bp > aq$ 或 $bp = aq$ ，最优方案一定满足甲包数 $x < b$ 。因此分别枚举 $0 \le x < b$ 和 $0 \le y < a$ 即可，时间复杂度 $O(a+b)$ 。

### 输入格式

一行五个整数 $n$ 、 $a$ 、 $b$ 、 $p$ 、 $q$ ，用空格分隔。

### 输出格式

一行三个整数，用空格分隔，依次是最小总价、甲包数、乙包数。

### 样例输入

```text
10 3 4 4 5
```

### 样例输出

```text
13 2 1
```

### 数据范围

$n$ 可达 $10^{12}$ ，总价可达 $10^{18}$ ，输入量、包数与乘积都需要用 `long long` 保存。

## 题目分析

需求 $n$ 很大，不能逐个枚举可能达到 $10^{12}$ 的包数。也不能只选择每件单价更低的包装，因为整包购买时，多买出的物品可能让总价反而更高。

注意， $b$ 包甲和 $a$ 包乙都含有 $ab$ 件物品，价格分别为 $bp$ 和 $aq$。据此可以限制最优方案中的一种包数。

如果 $bp<aq$，任何包含至少 $a$ 包乙的方案都可以把其中 $a$ 包乙换成 $b$ 包甲，保持物品数不变而降低价格。因此最优方案一定满足 $y<a$。

如果 $bp>aq$，对称地可以证明最优方案一定满足 $x<b$。

如果 $bp=aq$，把 $b$ 包甲换成 $a$ 包乙会保持价格和物品数不变，但减少甲包数。根据最后一条择优规则，所求最优方案仍然必须满足 $x<b$。

所以，无论属于哪一种情况，分别枚举 $0\le x<b$ 和 $0\le y<a$，至少有一轮会覆盖所求答案。代码用两轮循环统一这两种枚举，第一轮枚举甲包数，第二轮枚举乙包数。

固定 $x$ 时，剩余需求为 $n-ax$。如果已经非正，取 $y=0$；否则需要

$$
y=\left\lceil\frac{n-ax}{b}\right\rceil.
$$

对于正整数剩余需求 $r$，可以用 `(r+b-1)/b` 实现向上取整。价格均为正，所以固定 $x$ 后，额外购买更多乙包装只会增加总价，不可能改善答案。固定 $y$ 的情况同理。必须先判断剩余需求是否为正，不能让公式产生负的购买包数。

对每个候选，计算总价和总件数，按照“总价、总件数、甲包数”依次比较；总件数和甲包数确定后，乙包数唯一。用只购买甲的合法方案初始化答案，可以避免依赖特殊的极大值。

两轮枚举共 $a+b$ 次，每次做常数次运算，时间复杂度为 $O(a+b)$，额外空间复杂度为 $O(1)$。无需把需求大小 $n$ 作为循环上界。总价可达 $10^{18}$；当前枚举产生的候选计算也均在有符号 64 位整数范围内，输入量、包数和乘积统一使用 `long long`。

### 示例代码

```c
#include <stdio.h>

int main(void) {
    long long n, a, b, p, q;
    scanf("%lld%lld%lld%lld%lld", &n, &a, &b, &p, &q);
    long long best_x = (n + a - 1) / a, best_y = 0;
    long long best_cost = best_x * p, best_items = best_x * a;
    for (int type = 0; type < 2; type++) {
        long long limit = b;
        if (type == 1) {
            limit = a;
        }
        for (long long cnt = 0; cnt < limit; cnt++) {
            long long x, y, need;
            if (type == 0) {
                x = cnt;
                y = 0;
                need = n - a * x;
                if (need > 0) {
                    y = (need + b - 1) / b;
                }
            } else {
                y = cnt;
                x = 0;
                need = n - b * y;
                if (need > 0) {
                    x = (need + a - 1) / a;
                }
            }
            long long cost = p * x + q * y;
            long long items = a * x + b * y;
            if (cost < best_cost ||
                (cost == best_cost && (items < best_items ||
                (items == best_items && x < best_x)))) {
                best_cost = cost;
                best_items = items;
                best_x = x;
                best_y = y;
            }
        }
    }
    printf("%lld %lld %lld\n", best_cost, best_x, best_y);
    return 0;
}
```
