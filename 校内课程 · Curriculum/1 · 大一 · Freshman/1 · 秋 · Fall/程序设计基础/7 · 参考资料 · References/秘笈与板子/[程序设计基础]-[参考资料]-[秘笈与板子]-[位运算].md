## lowbit函数

```c
f(x)=lowbit(x),，函数值为x的二进制最低位的1所对应的值。

为得到lowbit的值，我们只需得到最低位的1的位置，将其余位置全部置0即可，下面介绍两种方式：
1. x&(x^(x-1))
对 的取值进⾏讨论：
若x为奇数，显然运算结果为1，符合要求；
若x为偶数，那么 x-1会将x从最低位的1开始⼀直到最右位全部取反，即得到⼀个前面不变，后面为011...的串，与 x进⾏按位异或，得到⼀个前面为0 ，后⾯为111... 的串，
再与x进⾏按位与，即得到 lowbit。
2. x&- x
我们知道，⼀个负数的补码是其绝对值的原码取反加⼀，有了这个前置知识，这个运算的实现


运算有很多⽤途，⽐如可以⽤来统计⼀个数的⼆进制位为1的个数：
while (x)
{
x -= x & -x;
cnt++;
}
```

## m与n位互换

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <math.h>

int main()
{
    int a,m,n;
    int p=0;
    int q=0;
    
    while(scanf("%d %d %d",&a,&m,&n)!=EOF)//m，n位互换 
    {
        if((a&(1<<m))==0)//注意运算优先级 
        {
            p=0;
         }
        else
        {
            p=1;
        }
    
        
        if((a&(1<<n))==0)
        {
            q=0;
         }
        else
        {
            q=1;
        }
        
        if(p==q)
        printf("%d\n",a);
        else
        printf("%d\n",a^((1<<m)|(1<<n)));
    }
    
    return 0;
}
```

{
    int t;

        int m=0;;
        int sum=0;

        for(int i=0;i<7;i++)
        {

            {
                m++;
            }
        }

        {
            printf("%d\n",n);
        }
        else//14位二进制翻转（颠倒） 
        {
            for(int i=0;i<7;i++)
            {
                sum=sum|((n&(1<<i))<<(13-2*i));
            }
            
            for(int i=7;i<14;i++)
            {
                sum=sum|((n&(1<<i))>>(2*i-13));
            }
            
            printf("%d\n",sum);
        }
        
     } 

    
    return 0;
}

汉明码

unsigned int f(unsigned int x) {
    unsigned int c = 32;
    x &= -x;
    if (x) c--;
    if (x & 0x0000FFFF) c -= 16;
    if (x & 0x00FF00FF) c -= 8;
    if (x & 0x0F0F0F0F) c -= 4;
    if (x & 0x33333333) c -= 2;
    if (x & 0x55555555) c -= 1;

}

unsigned int nextpower(unsigned int x) {
    --x;
    x |= (x >> 1);
    x |= (x >> 2);
    x |= (x >> 4);
    x |= (x >> 8);
    x |= (x >> 16);
    ++x;
    return x;
}
/*交换 x 中两部分位的值, 给定两个起始位置 i, j 和需要交换的位数 n, 不得重叠*/
unsigned int reverse_bits(unsigned int x, int i, int j, int n) {
    temp = ((x >> i) ^ (x >> j)) & ((1U << n) - 1);
    x ^= ((temp << i) | (temp << j));
    return x;
}
/*反转 x 的所有位, 若为 64 位整型则需要把所有 int 换为 long long*/
unsigned int reverse(unsigned int x) {
    unsigned int s = sizeof(x) * CHAR_BIT;
    unsigned int mask = ~0;
    while((s >>= 1) > 0) {
        mask ^= (mask << s);
        x = ((x >> s) & mask) | ((x << s) & ~ mask);
    }
    return x;
}
/*交错位, 即将 16 位整型变量 x 和 y 的位交错排放在一起, 组成一个 32 位整型*/
unsigned int interleave(unsigned short x, unsigned short y) {
    unsigned int z = 0, i;
    for(i = 0; i < sizeof(x) * CHAR_BIT; i++) {
        z |= (x & 1U << i) << i | (y & 1U << i) << (i + 1);
    }
    return z;
}
/*将 x 中所有的 1 作为一个排列, 按照字典序计算下一个排列*/
unsigned int next_permutation(unsigned int x) {
    temp = (x | (x - 1)) + 1;  
    x = temp | ((((temp & -temp) / (x & -x)) >> 1) - 1);
    return x;
}
/*输出 x 的二进制表示*/
void write_binary(unsigned int x) {
    int i, s = sizeof(x) * CHAR_BIT - 1;
    for(i = s; i >= 0; --i ) {
        putchar(((x >> i) & 1) + '0');
    }
}

/*Stockholm 很喜欢数字 2，因此他决定把所有正整数都展开为 2 的幂次表示。

再进一步，0=0 ，1=2(0) ，2=2(1)=2(2(0)) ，3=2+1=2(2(0))+2(0) ，因此 13=2(2(2(0))+2(0))+2(2(2(0)))+2(0)。

## 按位异或和按位与大于0的最小正整数

```c
Ran 告诉了 Cirno 一个正整数 x，让她找到一个满足下列条件的最小正整数 y：
x and y>0
x xor y>0
此处 and表示按位与，xor 表示按位异或。
问题分析
题意很清晰，我们应当使 和 的⼆进制位上⾄少有⼀位相同（按位与），有⼀位不同（按位异
或），那么我们可以对 的值进⾏分类讨论：
1. 若x=1 ，显然 y=3；
2. 若 的⼆进制位上只有⼀位为1 ，由于 x≠1，仅需令y=x+1 即可满⾜题意；
3. 若 的⼆进制位上有多个 1，只需取 的最低位的 1赋给 y即可。
#include <stdio.h>
int main()
{
int T, x, i, y;
scanf("%d", &T);
while (T--)
{
scanf("%d", &x);
if (x == 1)
y = 3;
else
{
for (i = 0; i < 32; i++)
{
if ((x >> i) & 1) //x的二进制位为1的最低位
{
y = (1 << i);
break;
}
}
if (y == x) //x仅有一位二进制位为1
y++;
}
printf("%d\n", y);
}
return 0;
}
```

## 汉明距离

```c
在信息论中，两个等长字符串之间的汉明距离(Hamming Distance)是两个字符串对应位置不同的字符的个数。换句话说，它表示通过替换字符，将一个字符串更改为另一个字符串所需的最小替换次数。
给出若干个等长字符串，进行若干次询问，每次询问请你计算两个字符串之间的汉明距离。
输入
输入共 1+n+m 行。
第一行三个正整数：每个字符串的长度 len，字符串的个数 n，询问的次数 m，保证均不大于 1000。
接下来 n行，每行一个长度为 len的字符串，保证仅由小写字母组成。
接下来 m行，每行两个正整数 i,j，表示此次询问需要计算第 i个字符串和第 j个字符串之间的汉明距离，保证 1≤i,j≤n。
输出
输出共 m行。对于每次询问，输出一行一个非负整数，表示该次询问两个字符串的汉明距离。

#include <stdio.h>

int HammingDistance(char a[], char b[], int len) {
    int distance = 0;
    for (int i = 0; i < len; i++) {
        if (a[i] != b[i]) {
            distance++;
        }
    }
    return distance;
}
char s[1005][1005];
int main()
{
    int len, n, m;
    scanf("%d%d%d", &len, &n, &m);
    for(int i = 1; i <= n; i++)
        scanf("%s", s[i]);
    while(m--) 
    {
        int i, j;
        scanf("%d%d", &i, &j);
        printf("%d\n", HammingDistance(s[i], s[j], len));

    }
    return 0;
}
```
