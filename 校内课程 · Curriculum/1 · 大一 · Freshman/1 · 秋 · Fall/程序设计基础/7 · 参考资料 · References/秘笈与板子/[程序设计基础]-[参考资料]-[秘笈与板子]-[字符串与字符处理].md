## String头函数

```c

strlen()
功能：计算字符串的长度。
参数：接收一个字符指针（char*），指向要计算长度的字符串。
返回值：返回字符串的长度，不包括终止字符\0。

strcpy()
功能：复制字符串。

返回值：返回目标字符串的指针。
示例：
c`char dest[50];  
char src[] = "Hello, World!";  
strcpy(dest, src); // dest 现在包含 "Hello, World!"`

strncpy()
功能：复制字符串的前n个字符。
参数：接收三个参数，第一个是指向目标字符串的指针，第二个是指向源字符串的指针，第三个是要复制的字符数。
返回值：返回目标字符串的指针。

参数：接收两个字符指针，第一个指针指向目标字符串数组，第二个指针指向要连接的源字符串。
返回值：返回目标字符串的指针。
示例：
c`char str1[50] = "Hello, ";  
char str2[] = "World!";  
strcat(str1, str2); // str1 现在包含 "Hello, World!"`
`
strchr()
功能：在字符串中查找第一次出现指定字符的位置。
参数：接收两个参数，第一个是指向要搜索的字符串的指针，第二个是要查找的字符。
返回值：如果找到该字符，则返回指向该字符在字符串中首次出现的位置的指针；否则返回NULL。
示例：
复制代码
c`char str[] = "Hello, World!";

strcmp()
功能：比较两个字符串。
参数：接收两个字符指针，分别指向要比较的两个字符串。
返回值：如果两个字符串相等，返回0；如果第一个字符串小于第二个字符串，返回一个负值；否则返回一个正值。
示例：
c`char str1[] = "apple";

返回值：如果找到子字符串，则返回指向子字符串在主字符串中首次出现的位置的指针；否则返回NULL。
示例：
c`char str[] = "Hello, World!";

memcpy(), memmove(), memcmp() 等其他函数也常用于字符串和内存的操作，但它们更侧重于内存级别的操作，而不仅仅是字符串操作。

请注意，在使用这些函数时要确保目标缓冲区有足够的空间来存储数据，以避免缓冲区溢出等安全问题。同时，在处理字符串时要特别注意字符串的终止字符\0，以确保字符串的正确打印和处理。
```

## memcpy和memove

```c
符文 s由数字和字母组成，给定子串 s1和子串 s2，将 s中的所有子串 s1都替换为 s2，即可完成一次解密。多次解密后，你就可以得到这段符文的原始内容。

输入
第一行一个整数 n。 1≤n≤10
第二行为一个仅有字母和数字组成的长度在 1000以内的非空字符串，代表符文 s。
接下来 2n行，每两行为一组，第一行为子串 s1，第二行为子串 s2。（保证在解密过程中子串 s1在 s中不会重叠出现）
s1,s2均为长度不超过 10的由数字和字母组成的非空字符串。
保证在解密过程中s的长度不会超过 104。

输出
一行字符串，代表 s 经过 n次解密后的原始内容。
#include <stdio.h>
#include <string.h>

int main() {
    int n;
    char s[2002];
    scanf("%d", &n);
    scanf("%s", s);
    char s1[11], s2[11];
    for (int i = 0; i < n; ++i) {
        scanf("%s", s1);
        scanf("%s", s2);
        char *pos = s;
        while ((pos = strstr(pos, s1)) != NULL) {
            memmove(pos + strlen(s2), pos + strlen(s1), strlen(pos + strlen(s1)) + 1);
            memcpy(pos, s2, strlen(s2));
            pos += strlen(s2);
        }
    }
    printf("%s\n", s);
    return 0;
}

memmove 和 memcpy 是 C 语言标准库中的两个函数，用于在内存中复制数据。尽管它们的目的都是复制数据，但它们在某些使用场景上有所不同。

1. memcpy
memcpy 函数用于从源内存块复制指定数量的字节到目标内存块。源内存块和目标内存块不能重叠，否则会导致未定义的行为。

函数原型：

c
复制代码
void *memcpy(void *dest, const void *src, size_t n);
dest：指向目标内存块的指针。
src：指向源内存块的指针。
n：要复制的字节数。
示例：

c
复制代码
#include <stdio.h>  
#include <string.h>  
  
int main() {  
    char src[] = "Hello, World!";  
    char dest[20];  
      
    memcpy(dest, src, 13); // 复制前13个字符  
    dest[13] = '\0'; // 添加字符串结束符  
      
    printf("Copied string: %s\n", dest); // 输出: Copied string: Hello, Worl  
    return 0;  
}
2. memmove
memmove 函数也用于从源内存块复制指定数量的字节到目标内存块，但与 memcpy 不同的是，它允许源内存块和目标内存块重叠。如果它们重叠，memmove 会确保正确地复制数据。

函数原型：

c
复制代码
void *memmove(void *dest, const void *src, size_t n);
dest：指向目标内存块的指针。
src：指向源内存块的指针。
n：要复制的字节数。
示例：

c
复制代码
#include <stdio.h>  
#include <string.h>  
  
int main() {  
    char str[] = "Hello, World!";  
      
    memmove(str + 7, str, 5); // 将 "Hello" 移动到 "World" 的位置  
      
    printf("Moved string: %s\n", str); // 输出: Moved string: Hello, Hello!  
    return 0;  
}
注意事项
使用这两个函数时，请确保目标内存块有足够的空间来容纳要复制的数据，否则可能会导致缓冲区溢出。
这两个函数都不会检查源内存块和目标内存块是否有效或是否可访问，因此在使用之前，请确保指针指向有效的内存区域。
这两个函数返回目标内存块的指针，这在某些情况下可能很有用，但在大多数情况下，可以忽略这个返回值。
```

```c
int main()
{
    char str[BUFSIZ], substr[BUFSIZ], *p;
    scanf("%s%s", str, substr);
    //使用strstr查询子串，返回子串在主串中的位置
    if ((p = strstr(str, substr)) != NULL)

void rev(char *first, char *last)
{
    int tmp;
//比较指针的值
    while (first < last)
    {//交换字符
        tmp = *last;
        *last = *first;
        *first = tmp;
        first++;//从前往后
        last--;//从后往前
    }
}
```

```c
#include <stdio.h>
#include <math.h>

int main() 
{
    unsigned long long n, k, a;
    while (scanf("%llu %llu %llu", &n, &k, &a) != EOF) 
    {
        
        k = k % n;
        
        for(int i=0;i<k;i++)
        {

            {
                a=(a<<1)|1;
            }
```

```c
题目描述
给出一个字符串 s和若干个字符。对于每个字符 c，请按以下要求进行输出：

输入共两行。

}
```
