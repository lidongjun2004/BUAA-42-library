## 1 计算成绩平均数

### 题目

#### 待改错的程序

```c
/**
 * 这个程序想要计算n位同学的成绩的平均数，并保留两位小数输出
 * 数据范围：人数: 0 < n < 50, 成绩: 0 < a <= 100，均为整数
 * 请找到这个程序的3个bug并改正使之能够完成原有目的
 */

#include <stdio.h>
int mian(void)
{
    int n, i, sum, a;
    scanf("%d", &n);
    for (i = 0; i < n; i++)
    {
        scanf("%d", &a);
        sum += a;
    }
    printf("%.2f", sum / n);
    return 0;
}
```

### 答案

### 带答案注释的程序

```c
/**
 * 这个程序想要计算n位同学的成绩的平均数，并保留两位小数输出
 * 数据范围：人数: 0 < n < 50, 成绩: 0 < a <= 100，均为整数
 * 请找到这个程序的3个bug并改正使之能够完成原有目的
 */

#include <stdio.h>
int mian(void) // 是main不是mian!!
{
    int n, i, sum, a; // sum需要初始化啊, sum = 0;
    scanf("%d", &n);
    for (i = 0; i < n; i++)
    {
        scanf("%d", &a);
        sum += a;
    }
    printf("%.2f", sum / n); // 需要进行类型强制转换, (double)sum / n;
    return 0;
}
```

### 三个 bug

1. `int mian(void)` 应为 `int main(void)`。
2. `sum` 没有初始化，应改为 `int n, i, sum = 0, a;`。
3. `sum / n` 是整数除法，需强制类型转换，应改为 `(double)sum / n`。

## 2 统计数字中 0 的个数

### 题目

#### 待改错的程序

```c
/**
 * 这个程序的目的是接受一个很大的十进制数字，看这个数字共有多少位0
 * 数字位数不超过1000
 * 请找到这个程序的2个bug并改正使之能够完成原有目的
 */

#include <stdio.h>
int main(void)
{
    int c;
    int count = 0;
    while ((c = getchar()) != EOF)
    {
        if (c = 0)
            count++;
    }
    printf("%d", count);
    return 0;
}
```

### 答案

### 带答案注释的程序

```c
/**
 * 这个程序的目的是接受一个很大的十进制数字，看这个数字共有多少位0
 * 数字位数不超过1000
 * 请找到这个程序的2个bug并改正使之能够完成原有目的
 */

#include <stdio.h>
int main(void)
{
    int c;
    int count = 0;
    while ((c = getchar()) != EOF)
    {
        if (c = 0) // 这一个语句中有两个错误，一个是把赋值号当作逻辑等号使用，另一个是把数字0和字符'0'搞混
            count++;
    }
    printf("%d", count);
    return 0;
}
```

### 两个 bug

两个错误都在 `if (c = 0)` 这一条语句里：

1. 把赋值号 `=` 当作了逻辑等号 `==`。
2. 把数字 `0` 和字符 `'0'` 搞混了（要统计的是字符 `'0'`）。

## 3 输出无符号整数的 32 位二进制编码

### 题目

#### 待改错的程序

```c
/**
 * 这个程序的作用是录入一个无符号整型范围的数据a，输出它的32位二进制编码
 * 如输入16，输出应为00000000000000000000000000010000
 * 请找到这个程序的2个bug并改正使之能够完成原有目的
 */

#include <stdio.h>
int main(void)
{
    unsigned int a, b;
    scanf("%u", &a);
    int i = 31;
    while (i >= 0);
    {
        b = a >> i;
        if (b & 1 == 0)
            putchar('0');
        else
            putchar('1');
        i--;
    }
    return 0;
}
```

### 答案

### 带答案注释的程序

```c
/**
 * 这个程序的作用是录入一个无符号整型范围的数据a，输出它的32位二进制编码
 * 如输入16，输出应为00000000000000000000000000010000
 * 请找到这个程序的2个bug并改正使之能够完成原有目的
 */

#include <stdio.h>
int main(void)
{
    unsigned int a, b;
    scanf("%u", &a);
    int i = 31;
    while (i >= 0); // 这里不能加分号
    {
        b = a >> i;
        if (b & 1 == 0) // 运算符优先级问题，逻辑等优先级比按位与高，应该写成if ((b & 1) == 0)
            putchar('0');
        else
            putchar('1');
        i--;
    }
    return 0;
}
```

### 两个 bug

1. `while (i >= 0);` 末尾多了一个分号，导致循环体为空、成了死循环。
2. `if (b & 1 == 0)` 有运算符优先级问题：`==` 的优先级比按位与 `&` 高，应写成 `if ((b & 1) == 0)`。

## 4 计算两点距离

### 题目

#### 待改错的程序

```c
/**
 * 这个程序的作用是读取两个点的x, y坐标(可为小数)，计算两个点的距离并保留3位小数输出
 * 为了少写一点代码，这段代码使用宏定义来计算一个数的平方
 * 请找到这个程序的2个bug并改正使之能够完成原有目的
 */

#include <stdio.h>
#include <math.h>
#define SQ(x) (x * x)
int main(void)
{
    double x1, y1, x2, y2;
    scanf("%f%f%f%f", &x1, &y1, &x2, &y2);
    double dist = sqrt(SQ(x1 - x2) + SQ(y1 - y2));
    printf("%.3f", dist);
    return 0;
}
```

### 答案

### 带答案注释的程序

```c
/**
 * 这个程序的作用是读取两个点的x, y坐标(可为小数)，计算两个点的距离并保留3位小数输出
 * 为了少写一点代码，这段代码使用宏定义来计算一个数的平方
 * 请找到这个程序的2个bug并改正使之能够完成原有目的
 */

#include <stdio.h>
#include <math.h>
#define SQ(x) (x * x) // 带参数的宏定义最好把参数加上括号，写成((x) * (x))
int main(void)
{
    double x1, y1, x2, y2;
    scanf("%f%f%f%f", &x1, &y1, &x2, &y2); // 读入double类型的数据应该用%lf
    double dist = sqrt(SQ(x1 - x2) + SQ(y1 - y2));
    printf("%.3f", dist);
    return 0;
}
```

### 两个 bug

1. 带参数的宏定义没有给参数加括号，`#define SQ(x) (x * x)` 应写成 `#define SQ(x) ((x) * (x))`。
2. 读入 `double` 类型的数据应该用 `%lf`，不能写成 `%f`。

## 5 求最大值与平均数

### 题目

#### 待改错的程序

```c
/**
 * 这个程序的目的是找出一组数据中的最大值并计算这组数据的平均数(保留2位小数)
 * 这组数据范围为 0 < x < 1000000 的整数，最后以0作为输入结束标志
 * 数据个数不少于1个，不超过10000个
 * 请找到这个程序的2个bug并改正使之能够完成原有目的
 */

#include <stdio.h>
int main(void)
{
    int a, max, sum, count;
    max = 0, sum = 0, count = 0;
    while (a != 0)
    {
        scanf("%d", &a);
        if (a != 0)
        {
            sum += a;
            count++;
        }
        if (a > max)
            max = a;
    }
    printf("%d %.2lf", max, (double)sum / count);
    return 0;
}
```

### 答案

### 带答案注释的程序

```c
/**
 * 这个程序的目的是找出一组数据中的最大值并计算这组数据的平均数(保留2位小数)
 * 这组数据范围为 0 < x < 1000000 的整数，最后以0作为输入结束标志
 * 数据个数不少于1个，不超过10000个
 * 请找到这个程序的2个bug并改正使之能够完成原有目的
 */

#include <stdio.h>
int main(void)
{
    int a, max, sum, count;
    max = 0, sum = 0, count = 0;
    while (a != 0) // 这里要先对a进行初始化，否则如果a的初始值就是0的话就会出问题
    {
        scanf("%d", &a);
        if (a != 0)
        {
            sum += a;  // 注意题目数据范围，int范围是不够的！应该将sum声明为long long或者double
            count++;
        }
        if (a > max)
            max = a;
    }
    printf("%d %.2lf", max, (double)sum / count);
    return 0;

```

### 两个 bug

1. `while (a != 0)` 在 `a` 被赋值之前就判断，若 `a` 的初始值恰好是 0 就会直接跳出循环；应先对 `a` 初始化（或先读入再判断）。
2. `sum += a;` 处要注意题目数据范围，`int` 范围不够，应把 `sum` 声明为 `long long` 或者 `double`。
