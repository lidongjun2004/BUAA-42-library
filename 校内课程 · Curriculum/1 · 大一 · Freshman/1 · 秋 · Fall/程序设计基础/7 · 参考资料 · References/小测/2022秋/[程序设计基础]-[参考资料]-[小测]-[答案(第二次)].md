## 1 用循环实现斐波那契数列

### 题目

#### 题目描述

斐波那契数列，又称“兔子数列”，其递推公式为 $f(n) = f(n - 1) + f(n - 2)$

若使用递归来实现，其时间复杂度为 $O(2^n)$ ，一旦 $n$ 变大一点就跑不动了

但是如果使用循环解决这个问题，效率就会高很多，请使用循环的思路来解决斐波那契数列

#### 待补充的程序

```c
#include <stdio.h>
long long slow_fibonacci(int);
long long quick_fibonacci(int);
int main(void)
{
    printf("%lld\n", quick_fibonacci(60));
    printf("%lld\n", slow_fibonacci(60));
    return 0;
}
long long slow_fibonacci(int n)
{
    if (n <= 2)
        return 1;
    else
        return slow_fibonacci(n - 1) + slow_fibonacci(n - 2);
}
long long quick_fibonacci(int n)
{
    // 请补充你的代码
}
```

### 答案

```c
#include <stdio.h>
long long slow_fibonacci(int);
long long quick_fibonacci(int);
int main(void)
{
    printf("%lld\n", quick_fibonacci(60));
    printf("%lld\n", slow_fibonacci(60));
    return 0;
}
long long slow_fibonacci(int n)
{
    if (n <= 2)
        return 1;
    else
        return slow_fibonacci(n - 1) + slow_fibonacci(n - 2);
}
long long quick_fibonacci(int n)
{
    long long i = 0, j = 1, temp;
    while (n--)
    {
        temp = i + j, i = j, j = temp;
    }
    return i;
}
```

## 2 strlen 与 sizeof

### 题目

#### 题目描述

请判断这两行代码分别会输出什么？

#### 程序

```c
#include <stdio.h>
#include <string.h>
int main(void)
{
    char str[20] = "abcdef";
    printf("%d\n", strlen(str));
    printf("%d\n", sizeof(str));
    return 0;
}
```

### 答案

```text
6
```

6（字符串的长度为 6）

```text
20
```

20（字符数组的大小为 20）

## 3 字符数组作为函数参数

### 题目

#### 题目描述

如果将上一题的字符串以参数形式传递到函数中去（如图）请问又分别会输出什么？（编译器已经在警告你了）

#### 程序

```c
#include <stdio.h>
#include <string.h>
void f(char[]);
int main(void)
{
    char str[20] = "abcdef";
    f(str);
    return 0;
}
void f(char str[])
{
    printf("%d\n", strlen(str));
    printf("%d\n", sizeof(str));
}
```

### 答案

```text
6
```

6

```text
8
```

8（这是字符指针的大小，若为 32 位系统则输出为 4。传给函数的不是整个字符数组，而是字符数组首元素的地址，因此 str 变量在函数中不是数组而是指针）

## 5 冒泡排序改错

### 题目

#### 题目描述

冒泡排序是排序的最经典的算法，虽然其效率极其低下，但是代码实现简单。快速排序效率高，但是代码实现较为复杂，不太适合在上机的时候当场编写（第 8 章会学到的 C 库自带的 qsort 函数可以解决这个问题，感兴趣的同学可以提前学习）现在请找出此冒泡排序函数中的两个错误并改正

#### 待改错的程序

```c
#include <stdio.h>
void bubble_sort(int[], int);
int main(void)
{
    int num[10] = {4, 5, 2, 9, 3, 1, 0, 8, 7, 6};
    bubble_sort(num, 10);
    for (int i = 0; i < 10; i++)
        printf("%d ", num[i]);
    return 0;
}
void bubble_sort(int number[], int len)
{
    int i, j;
    int swapped = 1;
    for (i = len; i > 0 && swapped; i++)
    {
        for (swapped = 0, j = 0; j < i; j++)
        {
            if (number[j + 1] < number[j])
            {
                int temp = number[j];
                number[j] = number[j + 1];
                number[j + 1] = temp;
                swapped = 1;
            }
        }
    }
}
```

### 答案

### 带答案注释的程序

```c
void bubble_sort(int number[], int len)
{
    int i, j;
    int swapped = 1;
    for (i = len; i > 0 && swapped; i++) // 此处应该为i--
    {
        for (swapped = 0, j = 0; j < i; j++) // 此处应该是j < i - 1
        {
            if (number[j + 1] < number[j])
            {
                int temp = number[j];
                number[j] = number[j + 1];
                number[j + 1] = temp;
                swapped = 1;
            }
        }
    }
}
```

### 两个错误

1. 外层循环 `for (i = len; i > 0 && swapped; i++)` 的步进写成了 `i++`，应为 `i--`。
2. 内层循环的边界 `j < i` 会让 `number[j + 1]` 越界，应改为 `j < i - 1`。
