## 3 输出无符号整数的 32 位二进制编码

### 待改错的程序

```c
/**
 * 这个程序的作用是录入一个无符号整型范围的数据a，输出它的32位二进制编码
 * 如输入16，输出应为00000000000000000000000000010000
 * 请找到这个程序的2个bug并改正使之能够完成原有目的
 */

#include <stdio.h>
int main(void)
{
    unsigned int a, b;
    scanf("%u", &a);
    int i = 31;
    while (i >= 0);
    {
        b = a >> i;
        if (b & 1 == 0)
            putchar('0');
        else
            putchar('1');
        i--;
    }
    return 0;
}
```

## 4 计算两点距离

### 待改错的程序

```c
/**
 * 这个程序的作用是读取两个点的x, y坐标(可为小数)，计算两个点的距离并保留3位小数输出
 * 为了少写一点代码，这段代码使用宏定义来计算一个数的平方
 * 请找到这个程序的2个bug并改正使之能够完成原有目的
 */

#include <stdio.h>
#include <math.h>
#define SQ(x) (x * x)
int main(void)
{
    double x1, y1, x2, y2;
    scanf("%f%f%f%f", &x1, &y1, &x2, &y2);
    double dist = sqrt(SQ(x1 - x2) + SQ(y1 - y2));
    printf("%.3f", dist);
    return 0;
}
```

## 5 求最大值与平均数

### 待改错的程序

```c
/**
 * 这个程序的目的是找出一组数据中的最大值并计算这组数据的平均数(保留2位小数)
 * 这组数据范围为 0 < x < 1000000 的整数，最后以0作为输入结束标志
 * 数据个数不少于1个，不超过10000个
 * 请找到这个程序的2个bug并改正使之能够完成原有目的
 */

#include <stdio.h>
int main(void)
{
    int a, max, sum, count;
    max = 0, sum = 0, count = 0;
    while (a != 0)
    {
        scanf("%d", &a);
        if (a != 0)
        {
            sum += a;
            count++;
        }
        if (a > max)
            max = a;
    }
    printf("%d %.2lf", max, (double)sum / count);
    return 0;
}
```
