### 题目

#### 题目描述

读入四个整数 $r$ 、 $m$ 、 $s$ 、 $v$ 。先算出 $t = 6r \div v$ （整数除法），再把 $m$ 分钟换算成秒并入 $s$ ，得到总秒数 $S$ 。

先输出 $t$ 并换行，再比较 $t$ 与 $S$ ，按三种情况输出不同的字符串。

#### 输入格式

一行四个整数 $r$ 、 $m$ 、 $s$ 、 $v$ ，用空格分隔。

#### 输出格式

第一行一个整数 $t$ 。第二行按下面的规则输出：

- $t < S$ ： `Easy! %%%`
- $t = S$ ： `Lucky! '\(^_^)/'`
- $t > S$ ： `Ohn0! (T_T)`

#### 样例输入

```text
10 0 30 2
```

#### 样例输出

```text
30
Lucky! '\(^_^)/'
```

### 答案

### 问题分析

本题考查简单的计算，分支判断和转义字符的输出。

### 参考代码

```c
#include <stdio.h>

int main()
{
    int r, m, s, v, t;
    scanf("%d%d%d%d", &r, &m, &s, &v);
    s += m * 60;
    t = 6 * r / v;
    printf("%d\n", t);
    if (t < s)
        printf("Easy! %%%%%%");
    else if (t == s)
        printf("Lucky! \'\\(^_^)/\'");
    else
        printf("Ohn0! (T_T)");
    return 0;
}
```

### 答案

### 问题分析

本题考查简单循环书写，分支判断。

### 参考代码

```c
#include <stdio.h>
#include <string.h>

int main()
{
    int n;
    scanf("%d", &n);
    for (int i = 0; i < n; i++)
    {
        for (int j = 0; j < n - 1 - i; j++)
            putchar(' ');
        for (int j = 0; j < 2 * i + 1; j++)

}
```

## C 比身高

| 难度 | 考点 |
| --- | --- |
| 1 | 线性查找 |

### 题目

#### 题目描述

给定 $n$ 个人的身高 $a_1, a_2, \ldots, a_n$ 与 $T$ 次询问。每次询问给出区间 $[l, r]$ ，求该区间内第三大的身高。区间内不足三个数的位置按 0 计。

数据范围很小，直接线性查找即可：每次询问前把三个最大值初始化为 0 ，再从 $a_l$ 遍历到 $a_r$ 依次更新。

#### 输入格式

第一行两个整数 $n$ 和 $T$ 。第二行 $n$ 个正整数。接下来 $T$ 行，每行两个整数 $l$ 和 $r$ 。

#### 输出格式

每次询问输出一行一个整数。

#### 样例输入

```text
5 2
1 5 3 2 4
1 3
2 5
```

#### 样例输出

```text
1
3
```

### 答案

### 问题分析

本题的数据范围很小，所以可以采用线性查找。

定义三个变量来维护当前区间最大的三个数，每次询问前初始化为 0，因为 $a_i$ 的范围为正整数。

对于 $a_i$，用如下代码来更新最大值：

```c
if (a[i] > max0)
{
    max2 = max1;
    max1 = max0;
    max0 = a[i];
}
else if (a[i] > max1)
{
    max2 = max1;
    max1 = a[i];
}
else if (a[i] > max2)
    max2 = a[i];
```

每次询问从 $a_l$ 遍历到 $a_r$ 即可。

### 参考代码

```c
#include <stdio.h>

int main()
{
    int n, T, a[1005] = {0}, i, l, r, max0, max1, max2;
    scanf("%d%d", &n, &T);
    for (i = 1; i <= n; i++)
        scanf("%d", &a[i]);
    while (T--)
    {
        scanf("%d%d", &l, &r);
        max0 = max1 = max2 = 0;
        for (i = l; i <= r; i++)
        {
            if (a[i] > max0)
            {
                max2 = max1;
                max1 = max0;
                max0 = a[i];
            }
            else if (a[i] > max1)
            {
                max2 = max1;
                max1 = a[i];
            }
            else if (a[i] > max2)
                max2 = a[i];
        }
        printf("%d\n", max2);
    }
    return 0;
}
```

## D Squeeze the Sequence!!!

| 难度 | 考点 |
| --- | --- |
| 2 | 分支 字符与ASCII码 |

### 题目

#### 题目描述

读入 $n$ 个整数，把每个整数按下面的规则映射成字符并依次输出：

- $10 \le x \le 35$ ：输出字母 `A` 之后第 $x-10$ 个字母；
- $0 \le x \le 9$ ：直接输出该数字；
- $-10 \le x \le -1$ ：输出 `!@#$%^&*()` 中的第 $-x$ 个字符；
- 其余情况：输出 `z` 往前第 $x+36$ 个字符。

#### 输入格式

第一行一个整数 $n$ 。第二行 $n$ 个整数。

#### 输出格式

一行，按上述规则映射后得到的字符串，末尾不换行。

#### 样例输入

```text
5
0 10 -1 -10 -11
```

#### 样例输出

```text
0A!)a
```

### 答案

### 问题分析

本题考察分支和ASCII码，我们可以将待输出的字符按题意分为 4 类进行判断，非特殊字符可以利用其排列的连续性，结合ASCII码输出；特殊字符可以利用数组预先连续储存，从而可以类似地连续输出避免在特殊字符上进行多次判断。

### 参考代码

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <math.h>

typedef long long ll;//相当于#define ll long long int
int n;
int arr[105];
char s[20] = "!@#$%^&*()";//预先按照题意连续地储存
int main(void)
{
    scanf("%d", &n);
    ll ans = 0;
    for (int i = 0; i < n; i++)
    {
        int temp;
        scanf("%d", &temp);
        if (temp >= 10 && temp <= 35)
            printf("%c", temp - 10 + 'A');
        else if (temp >= 0 && temp <= 9)
            printf("%d", temp);
        else if (temp >= -10 && temp <= -1)
            printf("%c", s[-temp - 1]);
        else
            printf("%c", 'z' - (temp + 36));
    }
}
```

## E 湖中舟

| 难度 | 考点 |
| --- | --- |
| 2 | 模拟 |

### 题目

#### 题目描述

给定起点 $(x_1, y_1)$ 、终点 $(x_2, y_2)$ 与一串方向指令（`N` 北、`S` 南、`E` 东、`W` 西）。从起点出发按指令依次行走：只有当该方向能让坐标更接近终点时才移动，否则原地不动。判断能否到达终点，能到达时输出所用步数。

#### 输入格式

第一行一个整数 $T$ ，表示数据组数。每组数据第一行四个整数 $x_1$ 、 $y_1$ 、 $x_2$ 、 $y_2$ ；第二行一个由 `N`、`S`、`E`、`W` 组成的字符串。

#### 输出格式

每组数据输出一行：能到达终点则输出步数，否则输出 `We want to live in Gensokyo forever...` 。

#### 样例输入

```text
2
0 0 2 0
EEXX
0 0 5 0
EE
```

#### 样例输出

```text
2
We want to live in Gensokyo forever...
```

### 答案

### 问题分析

直接根据题意模拟即可；或记录各字符的个数，通过坐标差来判断是否能抵达终点。

### 参考代码 #1

```c
#include <stdio.h>
#include <string.h>

int main()
{
    int x1, x2, y1, y2, T, cnt, len, i;
    char s[1005];
    scanf("%d", &T);
    while (T--)
    {
        scanf("%d%d%d%d", &x1, &y1, &x2, &y2);
        scanf("%s", s);
        len = strlen(s);
        cnt = 0;
        for (i = 0; i < len; i++)
        {
            if (s[i] == 'N' && y1 < y2)
            {
                y1++;
                cnt++;
            }
            else if (s[i] == 'S' && y1 > y2)
            {
                y1--;
                cnt++;
            }
            else if (s[i] == 'W' && x1 > x2)
            {
                x1--;
                cnt++;
            }
            else if (s[i] == 'E' && x1 < x2)
            {
                x1++;
                cnt++;
            }
            if (x1 == x2 && y1 == y2)
                break;
        }
        if (x1 == x2 && y1 == y2)
            printf("%d\n", cnt);
        else
            printf("We want to live in Gensokyo forever...\n");
    }
    return 0;
}
```

### 参考代码 #2

## F 矩阵的幂次 mini

| 难度 | 考点 |
| --- | --- |
| 3 | 数组 循环 |

### 题目

#### 题目描述

给定 $m \times p$ 矩阵 $A$ 与 $p \times m$ 矩阵 $B$ ，令 $C = A \times B$ ，求 $C^n$ 。矩阵乘法按

$$C_{ij} = \sum_{k=1}^{p} A_{ik} B_{kj}$$

计算。把矩阵乘法封装成函数多次调用即可，注意二维数组的传参。

#### 输入格式

第一行三个整数 $m$ 、 $p$ 、 $n$ 。接下来 $m$ 行，每行 $p$ 个整数，是矩阵 $A$ 。再接下来按列给出矩阵 $B$ ：共 $m$ 组，每组 $p$ 个整数，依次是 $B$ 的第 1 列到第 $m$ 列。

#### 输出格式

$m$ 行，每行 $m$ 个整数，每个整数后面跟一个空格。

#### 样例输入

```text
2 2 2
1 0
0 1
1 2 3 4
```

#### 样例输出

```text
7 15 
10 22 
```

#### 数据范围

$m, p, n \le 10$ 。

### 答案

### 问题分析

由题意，可以将矩阵乘法封装成一个函数，多次调用即可。矩阵 $C$ 计算方式如下：

$$C_{ij}=\sum_{k=1}^{p}A_{ik}B_{kj}$$

使用三层 for 循环，第一层枚举 $C(A)$ 行下标 $i$，第二层枚举 $C(B)$ 列下标 $j$，第三层枚举 $A$ 列下标（ $B$ 行下标） $k$。

注意二维数组的传参。

### 参考代码 #1

```c
#include <stdio.h>
#include <string.h>

int m, p, n, A[10][10], B[10][10], C[10][10];

void mult(int A[][10], int B[][10], int C[][10], int r, int c)
{
    for (int i = 0; i < r; i++)
    {
        for (int j = 0; j < r; j++)
        {
            C[i][j] = 0;
            for (int k = 0; k < c; k++)
                C[i][j] += A[i][k] * B[k][j];
        }
    }
}

int main()
{
    scanf("%d%d%d", &m, &p, &n);
    for (int i = 0; i < m; i++)
        for (int j = 0; j < p; j++)
            scanf("%d", &A[i][j]);
    for (int j = 0; j < m; j++)
        for (int i = 0; i < p; i++)
            scanf("%d", &B[i][j]);
    mult(A, B, C, m, p);
    memcpy(B, C, sizeof(C));
    n--;
    while (n--)
    {
        mult(B, C, A, m, m);
        memcpy(B, A, sizeof(A));
    }
    for (int i = 0; i < m; i++)
    {
        for (int j = 0; j < m; j++)
            printf("%d ", A[i][j]);
        printf("\n");
    }
    return 0;
}
```

由于本题对空间要求较小，亦可直接开多个数组循环。

### 参考代码 #2

```c
#include <stdio.h>

int m, p, n, A[10][10], B[10][10], ans[10][10][10];

int main()
{
    scanf("%d%d%d", &m, &p, &n);
    for (int i = 0; i < m; i++)
        for (int j = 0; j < p; j++)
            scanf("%d", &A[i][j]);
    for (int j = 0; j < m; j++)
        for (int i = 0; i < p; i++)
            scanf("%d", &B[i][j]);
    for (int i = 0; i < m; i++)
        for (int j = 0; j < m; j++)
            for (int k = 0; k < p; k++)
                ans[0][i][j] += A[i][k] * B[k][j];
    for (int t = 1; t < n; t++)
        for (int i = 0; i < m; i++)
            for (int j = 0; j < m; j++)
                for (int k = 0; k < m; k++)
                    ans[t][i][j] += ans[t - 1][i][k] * ans[0][k][j];
    for (int i = 0; i < m; i++)
    {
        for (int j = 0; j < m; j++)
            printf("%d ", ans[n - 1][i][j]);
        printf("\n");
    }
    return 0;
}
```

## G 寻找小兰花

| 难度 | 考点 |
| --- | --- |
| 3 | 递归 |

### 题目

#### 题目描述

一张有向无环图有 $n$ 个点、 $m$ 条单向路，第 $i$ 条路从 $u$ 指向 $v$ 、长度为 $w$ 。从点 1 出发，每次等概率地从当前点的所有出边中选择一条继续走。保证每条不同的路线最终都能到达点 $n$ 。求到达点 $n$ 时所走路程的期望。

递归时状态由当前所在点、已走路程、当前路线的概率三者确定，到达点 $n$ 时把「概率 $\times$ 路程」累加进答案即可。

#### 输入格式

第一行两个整数 $n$ 和 $m$ 。接下来 $m$ 行，每行三个整数 $u$ 、 $v$ 、 $w$ 。

#### 输出格式

一行一个数，四舍五入保留两位小数。

#### 样例输入

```text
4 4
1 2 1
1 3 2
2 4 3
3 4 4
```

#### 样例输出

```text
5.00
```

#### 数据范围

$n \le 100$ 。

### 答案

### 问题分析

本题是一个简化的“有向无环图”问题，有关图的存储、处理方式，在下学期可能会有的数据结构课程上，会系统地学习。

这里希望同学们能提前感受一下图的处理思路，以便适应下学期的进一步学习。

本题需要注意的地方有：

1. 有向：每条路是单向路，只能从规定的一个端点，走向另一个端点，不可以双向往返；
2. 无环：不存在任何一种会回到已经路过点的路线选择方式，即不会在某几个点之间不停兜圈；
3. 保证每一条不同的路线都能够最终到达终点，则无需判断并去除无法到达目的地的路线；
4. Hint中提示的是一种存储小型图的方式，该方法利用牺牲一定的空间，来达到简化代码的作用。

思路：

- 按照要求读入所有变量：

```c
scanf("%d%d",&n,&m);
for(i=1;i<=m;i++)
  {
      scanf("%d%d",&u,&v);
      scanf("%d",&a[u][v]);
  }
```

  `a[u][v]` 表示存在一条从点 $u$ 指向点 $v$ 长度为 $a[u][v]$ 的路

- 求出到达各点之后，有几条路从改点出发，即求出每个点的 $k$：

```c
for(i=1;i<=n;i++)
  {
      for(j=1;j<=n;j++)
      {
          if(a[i][j]!=0)
              a[i][0]++;//用a[i][0]记录一共有多少条路
      }
  }
```

  用 `a[i][0]` 记录点 $i$ 的 $k$ 值

- 【重点】编写递归函数：

  1. 每个状态由 当前所在点 `nowAddress`、已经经过的路程 `length`、当前路线到当前该点的概率 `percent` 三个因素确定；
  2. 递归方程是 `search(i,length+a[nowAddress][i],percent*(1.0/a[nowAddress][0]));`
  3. 递归截止返回条件是 `nowAddress==n`

```c
void search(int nowAddress,int length,double percent)
{
    if(nowAddress==n)
    {
        sum+=(percent*length);
    }
    else
    {
        int i;
        for(i=1;i<=n;i++)
        {
            if(a[nowAddress][i]!=0)
            {
                search(i,length+a[nowAddress][i],percent*(1.0/a[nowAddress][0]));
            }
        }
    }
    return;
}
```

- 最后注意下四舍五入，保留两位小数输出

### 参考代码


## H 简单浮点数

| 难度 | 考点 |
| --- | --- |
| 4 | 二进制表示 浮点数 |

### 题目

#### 题目描述

给定一种自定义浮点数的二进制表示：最高位是符号位（1 表示负数），随后 $k$ 位是阶码 $E$ ，其余 $n$ 位是尾数。尾数满足

$$(x)_{10} = 1 + \sum_{j=0}^{n-1} 2^{j-n} f_j$$

偏置量 $bias = 2^{k-1} - 1$ ，记按上式换算出的尾数值为 $F$ ，则最终数值为

$$result = (-1)^{\text{符号}} \times F \times 2^{E-bias}$$

#### 输入格式

第一行一个二进制串，依次是符号位、阶码位与尾数位。第二行起若干个整数 $k$ ，读到文件结束为止，每个 $k$ 表示阶码的位数。

#### 输出格式

对每个 $k$ 输出一行，保留 8 位小数。

#### 样例输入

```text
010001
3
```

#### 样例输出

```text
2.50000000
```

### 答案

### 问题分析

按照题意描述，利用公式计算即可

注意小数二进制表示 $(1.f_{n-1}\ldots\ldots f_1f_0)$ 的含义满足

$$(x)_{10}=1+\sum_{k=0}^{n-1}2^{k-n}*f_k$$

解答给出最基本的转换方式。

在期中考试，通常有可能遇到陌生背景问题，这个时候需要有耐心，认真思考。

### 参考代码

```c
#include <stdio.h>
#include <math.h>
int a[1000];
int main(void)
{
    int m=0;
    int k,n;
    char c;
    scanf("%c",&c);
    while(c!='\n')
    {
        a[m]=c-48;
        m++;
        scanf("%c",&c);
    }//录入数据，二进制数每一位数字用数组存储
    while(~scanf("%d",&k))
    {
        n=m-1-k;
        int bias;
        bias=pow(2,k-1)-1;//算bias
        int E=0;
        for(int i=1;i<=k;i++)
        {
            E+=a[i]*pow(2,k-i);
        }//算E
        float F=1;
        for(int j=m-1;j>=m-n;j--)
        {
            F+=a[j]*pow(2,m-n-1-j);
        }//算F
        float result;
        if(a[0]==1)
        {
            result=(-1)*F*pow(2,E-bias);
        }
        else
        {
            result=F*pow(2,E-bias);
        }
        //由公式算出结果
        printf("%.8f\n",result);
    }
    return 0;
}
```

### 题目

#### 题目描述

给定一个只含非负整数、`+` 与 `*` 的表达式，按通常的运算优先级（先乘后加）求它的值。

用加号把表达式划分成若干段，每段内部只有乘号，段内把各数字连乘后再把各段相加即可。

#### 输入格式

#### 输出格式

一行一个整数。

#### 样例输入

```text
1+2*3+4
```

```text
11
```

#### 数据范围

表达式长度不超过 1000 ；结果可能超出 `int` 范围，需要使用 `long long` 。

### 答案

### 问题分析

用加号划分段，段内只有乘号，统计数字然后乘起来，注意使用 long long

### 参考代码

```c
#include<stdio.h>
#include<stdlib.h>
#include<math.h>
#include<ctype.h>
#include<string.h>
#include<time.h>
#define REP(i,a,b) for(register int i=a;i<=b;i++)
//这个register int中的register 表示使用cpu内部寄存器（寄存器是中央处理器内的组成部分。寄存器是有限存贮容量的高速存贮部件）的变量，而平时的int是把变量放在内存中，存到寄存器中可以加快变量的读写速度
//请注意某些版本可能不支持register
#define PER(i,a,b) for(register int i=a;i>=b;i--)
typedef long long LL;
//做法：用加号划分区间，计算内部的连乘
char s[1010];
LL solve(int l,int r,int flag){//对l~r区间的表达式求值
    LL res=0;
    if(flag){//加法乘法混合
        int lastpos=0;
        for(int i=l;i<=r;i++){
            if(s[i]=='+'){
                res+=solve(lastpos,i-1,0);
                lastpos=i+1;
            }
        }
        res+=solve(lastpos,r,0);
        return res;
    }
    LL tmp=0;
    res=1;
    for(int i=l;i<=r;i++)
        if(s[i]>='0'&&s[i]<='9')
            tmp=tmp*10ll+s[i]-'0';
        else
            res*=tmp,tmp=0;
    res*=tmp;
    return res;
}
```

## J 高高地飞起来吧，北京五号！

| 难度 | 考点 |
| --- | --- |
| 5 | 0-1背包 模拟 |

### 题目

#### 题目描述

给定 $n$ 条操作，每条操作由类型 $op$ 与数值 $dis$ 给出：

- $op = 1$ ：向前走 $dis$ ，累计前向距离 $x$ ；
- $op = 2$ ：向后走 $dis$ ，累计后向距离 $y$ ；
- $op = 3$ ：原地转向 $dis$ 度；
- $op = 4$ ：原地转向 $360 - dis$ 度。

转向角度对 $360$ 取模，每个角度最多使用一次，用 0-1 背包求出能让最终朝向最接近 $180^\circ$ 的角度组合，记与 $180^\circ$ 的最小差为 $\theta$ ，则水平距离由余弦定理给出

$$res = \sqrt{x^2 + y^2 - 2xy\cos\left((180^\circ - \theta)\right)}$$

若 $\lfloor res \rfloor$ 为奇数输出 `SHIE` ，否则输出 `CHUANYUAN` 。

#### 输入格式

第一行一个整数 $n$ 。接下来 $n$ 行，每行两个整数 $op$ 和 $dis$ 。

#### 输出格式

第一行 `SHIE` 或 `CHUANYUAN` ，第二行 $res$ 。

#### 样例输入

```text
2
1 3
2 1
```

#### 样例输出

```text
CHUANYUAN
2.000000
```

### 答案

### 问题分析

要想飞的远，即要尽可能的往前走，尽可能减少向后走产生的反面影响。所以我们总可以按下面四个步骤走：

- 走完向前的距离。
- 尽可能往180度方向调整。
- 走完向后的距离。
- 原地转完剩余的角度。

那么我们核心就是使用这些角度能形成最接近180度（取模后）的角度。这里我们使用的递推的思想，遍历每种角度用或不用（也被称作01背包），进而获得所有可以达到的角度，得到最接近的角度。最后使用余弦定理计算距离出发点的水平距离。

### 参考代码

```c
#include <stdio.h>
#include <math.h>
#define PI acos(-1)
#define N 10010
#define min(x,y) (((x)<(y)) ? (x) : (y))
int n, op, x, y, dis, minn = 180, a[N], f[N];

int main() {
    scanf("%d", &n);
    for (int i = 1; i <= n; ++i) {
        scanf("%d%d", &op, &dis);
        if (op == 1)
            x += dis;
        if (op == 2)
            y += dis;
        if (op == 3)
            dis %= 360, a[dis]++;
        if (op == 4)
            dis %= 360, a[360 - dis]++;
    }
    f[0] = 1;
    for (int i = 0; i < 360; ++i)
        while (a[i]--)
            for (int j = 720; j >= 0; --j)
                if (f[j])
                    f[(j + i) % 720]++, minn = min(minn, abs((i + j) % 360 - 180));
    double res = sqrt(1ll * x * x + 1ll * y * y - 2ll * x * y * cos((180 - minn) * PI / 180));
    if ((int)res % 2)
        puts("SHIE");
    else
        puts("CHUANYUAN");
    printf("%lf", res);
    return 0;
}
```
