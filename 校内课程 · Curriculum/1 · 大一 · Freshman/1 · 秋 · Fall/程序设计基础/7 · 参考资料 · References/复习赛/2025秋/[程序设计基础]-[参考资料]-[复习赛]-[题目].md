## L Newton 迭代法

| 难度 | 考点 |
| --- | --- |
| 1 | 函数调用 |

### 题目

#### 题目描述

用 Newton 迭代法求方程

$$
A e^x + B x^3 + C x + D = 0
$$

的根。记 `f(x) = A e^x + B x^3 + C x + D` ，则 `f'(x) = A e^x + 3 B x^2 + C` ，迭代公式为

$$
x_{k+1} = x_k - \frac{f(x_k)}{f'(x_k)}
$$

初值取 `x_0 = 0` ，当 `|x_{k+1} - x_k| < 10^{-7}` 时停止迭代。

#### 输入格式

一行四个实数 `A` 、 `B` 、 `C` 、 `D` 。

#### 输出格式

一行一个实数，为求得的根，保留六位小数。

#### 样例输入

```text
1 0 0 -2
```

#### 样例输出

```text
0.693147
```
