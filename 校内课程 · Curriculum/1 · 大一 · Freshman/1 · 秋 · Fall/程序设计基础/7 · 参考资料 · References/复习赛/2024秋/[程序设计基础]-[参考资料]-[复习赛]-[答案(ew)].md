| 难度 | 考点 |

### 题目

#### 题目描述

给定一个整数 `x` ，求满足 `x \mathbin{|} y = x` 的非负整数 `y` 的个数。

#### 输入格式

一行一个整数 `x` 。

#### 输出格式

一行一个整数，为满足条件的 `y` 的个数。

#### 样例输入

```text
5
```

#### 样例输出

```text
4
```

#### 数据范围

`0 \le x < 2^{63}`

### 答案

### 题目分析

即使程设课结束了，相信同学们还是 **一回眸** 满眼幸福的诗篇。

考虑或运算的性质，逐位考虑。如果 $a$ 的某一位是 `1`，那么 $x$ 的这一位可以是 `0` 也可以是 `1`，不然 $x$ 的这一位只能是 `0`。

### 示例代码

```c
#include<stdio.h>
long long x;
int cnt=0;
int main(){
    scanf("%lld",&x);
    for(int i=0;i<=62;++i){
        if((x>>i)&1){
            cnt++;
        }
    }
    printf("%lld",(1ll<<cnt));
    return 0;
}
```

## B 日花的序列划分

| 难度 | 考点 |
| --- | --- |
| 6 | 位运算，贪心 |

### 题目

#### 题目描述

给定一个长度为 `n` 的序列 `a_1, a_2, \dots, a_n` 和一个整数 `m` 。

把序列划分成 `m` 个连续的非空段，每一段的价值定义为这一段中所有元素按位或的结果。求这 `m` 个段的价值的按位与的最大值。

#### 输入格式

第一行两个整数 `n` 和 `m` 。

第二行 `n` 个整数 `a_1, a_2, \dots, a_n` 。

#### 输出格式

一行一个整数，为所求的最大值。

#### 样例输入

```text
5 2
7 3 5 6 1
```

#### 样例输出

```text
7
```

#### 数据范围

`1 \le m \le n \le 2 \times 10^5` ， `a_i < 2^{31}`

### 答案

### 题目分析

从高位到低位考虑，看能不能塞到答案里，能塞就塞。

假设现在枚举到第 $i$ 位，当前答案是 $ans$，那就是看 $ans|(1 << i)$ 是否可行，记为 $tmp$。

$tmp$ 可行当且仅当，凡是 $tmp$ 有的 1，每个段的价值 $x$ 都有，也就是 $x \& tmp = tmp$。

贪心地去分段，因为 $x$ 或上 $a_i$ 不会让 $x$ 的性质变劣，所以一直或到上式成立就停。

显然这样分出来的段数是最多的，所以段数 $\geq k$ 时 $tmp$ 就可行，否则肯定不可行。

### 示例代码

```c
#include<stdio.h>
#define N 200010
int n,m,ans,a[N];
int main(){
    scanf("%d%d",&n,&m);
    for(int i=1;i<=n;i++)scanf("%d",&a[i]);
    for(int i=30;i>=0;i--){
        int tmp=ans|(1<<i),cnt=0,x=0;
        for(int j=1;j<=n;j++){
            x|=a[j];
            if((x&tmp)>=tmp)cnt++,x=0;
        }if(cnt>=m)ans=tmp;
    }printf("%d",ans);
}
```

## C 仙人的异或数组

| 难度 | 考点 |
| --- | --- |
| 6 | 异或，贪心 |

### 题目

#### 题目描述

给定 `n` 个非负整数 `a_1, a_2, \dots, a_n` ，你可以把其中任意一个 `a_i` 改小成 `0` 到 `a_i` 之间的任意非负整数，也可以不改。求修改之后所有元素异或和的最大值。

多组数据，读到文件结束为止。

#### 输入格式

若干组数据。每组数据第一行一个整数 `n` ，第二行 `n` 个非负整数 `a_1, a_2, \dots, a_n` ，读到文件结束为止。

#### 输出格式

每组数据输出一行一个整数，为最大的异或和。

#### 样例输入

```text
3
3 5 6
2
1 2
```

#### 样例输出

```text
7
3
```

#### 数据范围

`n \le 10^5` ， `a_i < 2^{36}`

### 答案

### 题目分析

对于位运算求最值的问题，我们按位考虑，即优先满足高位为 `1`。

再由异或的性质，当 $a_i, i = 1 \cdots n$ 中有奇数个第 $j$ 位为 `1` 时即可使异或和此位为 `1`，这里可以想到一个很明显的贪心策略：因为 $a$ 数组的数可以为 `0`，所以我们对于当前考虑的位，只需要使其中一个 $a_i$ 的当前位为 `1`，其他数的当前位均设为 `0` 即可。

因此，我们从最高位开始向低位考虑，若当前位 $b$ 有多个位置可以取到，即满足 $a[i] \geq (1 << b)$ 那么我们选择哪个位置？

- 若满足条件的 $i$ 仅有一个，那么由异或的性质，一定要取
- 若满足条件的 $i$ 有多个，我们任意选择一个位置取，那么，易知，剩下的数一定可以取到 $(1 << b) - 1$

因此，我们最终的贪心策略就得出了：**从高到低按位考虑，对于当前位 $b$，在数组 $a$ 中有 $a_i$ 可以取，即满足 $a_i \geq (1 << b)$，那么我们优化答案，并将 $a_i$ 进行更新**。

### 示例代码

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <math.h>

#define ll long long
#define maxn 100005
#define BIT 35

ll n, arr[maxn];
ll ans;

int main() {

    while(scanf("%lld", &n) != EOF) {
        ans = 0;

        for(int i = 1; i <= n; i++)
            scanf("%lld", &arr[i]);

        for(int b = BIT; b >= 0; b--) {
            for(int i = 1; i <= n; i++) {
                if((1ll << b) <= arr[i]) {
                    arr[i] -= (1ll << b);
                    ans += (1ll << b);
                    break;
                }
            }
        }

        printf("%lld\n", ans);
    }

    return 0;
}
```

## D Baymax的密码宝藏

| 难度 | 考点 |
| --- | --- |
| 4 | 二进制、双进位判断溢出 |

### 题目

#### 题目描述

用 `n` 位补码表示两个整数，输入给出它们的 `n` 位二进制形式，最高位是符号位。

判断这两个整数相加的结果是否溢出：两个正数相加得到负数称为「上溢」，两个负数相加得到正数称为「下溢」，两者都算溢出。

#### 输入格式

第一行两个整数 `t` 和 `n` 。

接下来每组数据两行，分别是两个整数的 `n` 位二进制表示。

#### 输出格式

每组数据输出一行。溢出输出 `OverFLOW!` ，否则输出 `Not OverFLOW` 。

#### 样例输入

```text
2 4
0111
0001
0011
0010
```

#### 样例输出

```text
OverFLOW!
Not OverFLOW
```

#### 数据范围

`t` 组数据， `n \le 10^5`

### 答案

### 题目分析

计算机采用补码运算时，若结果的数值超过了补码所能表示的数据范围，则计算结果错误，这种情况称为溢出。比如，对于 `char` 类型变量而言，其所能表示的范围为 $-128 \sim 127$，所以当计算 $127 + 1$ 时，便会得到错误的结果。

直观上来说，溢出有两种情况：

- 当两个较大正数相加时，产生 **正数 + 正数 = 负数** 的现象，这种情况称为「上溢」。
- 当两个较小的负数相加时，产生 **负数 + 负数 = 正数** 的现象，这种情况称为「下溢」。

那么应该如何判断溢出呢？

首先我们先看「上溢」。两个正数相加，它们的符号位都是 0，如果它们数值位的最高位都是 1，则会导致相加时向符号位进位，从而导致和的符号位为 1，和为负数；如果它们数值位最高位一个为 1，另一个为 0，则我们应该继续看数值位的下一位，直到数值位相同时停止，并据此判断数值位最高位是否进位。

对于「下溢」，两个负数相加，它们的符号位都是 1，相加时符号位会进位变为 0，如果数值位最高位相加时不向符号位进位，则和将变为正数，导致错误结果。

所以，**当且仅当符号位与数值位最高位同时进位或者同时不进位时**，相加才不会溢出。

### 示例代码 1

```c
//从后往前判断
#include <stdio.h>
int num1[100005];
int num2[100005];
int main()
{
    int t,n,c1,c2,flag;//flag标记下次运算时是否进位
    scanf("%d%d", &t, &n);
    while (t--)
    {
        for (int i = 0;i<n;i++)
            scanf("%1d", &num1[i]);
        for (int i = 0; i < n; i++)
            scanf("%1d", &num2[i]);
        c1=c2=flag = 0;
        for (int i = n - 1; i >= 0;i--) //从最低位开始进行相加
        {
            if((num1[i]==1 && num2[i]==1) || ((num1[i] + num2[i]) == 1 && flag)) //本次运算时进位
            {
                flag = 1;
                if(i==0) //符号位进位
                    c1 = 1;
                if(i==1) //数值位最高位进位
                    c2 = 1;

            }
            else
                flag = 0;
        }
        if(c1^c2) //不同时进位
            printf("OverFLOW!\n");
        else  //同时进位
            printf("Not OverFLOW\n");
    }
}
```

### 示例代码 2

```c
//从前住后进行判断
#include <stdio.h>
int num1[10005], num2[10005];
int main()
{
    int t, n, flag,i;
    scanf("%d%d", &t, &n);
    while (t--)
    {
        flag = 0;
        for (int i = 0; i < n; i++)
            scanf("%1d", &num1[i]);
        for (int i = 0; i < n; i++)
            scanf("%1d", &num2[i]);
        if (num1[0] == num2[0]) //符号位相同
        {
            for (i = 1; i < n; i++)
            {
                if (num1[i] == num2[i]) //找到第一个数值相同位
                {
                    if (num1[i] != num1[0]) //该数值位和符号位不相同则溢出
                        flag = 1;
                    break;
                }
            }
            if(i==n) //如果除了符号位相同外，每一个数值位都不同，则溢出取决于符号位
                flag = num1[0];
        }
        if (flag)
            printf("OverFLOW!\n");
        else
            printf("Not OverFLOW\n");
    }
    return 0;
}
```

## E Raynor 的 scanf

| 难度 | 考点 |

| 4 | 字符串处理 |

### 题目

#### 题目描述

给定一个 `scanf` 的格式字符串，把它按下面的规则逐项翻译并输出：

- 空格、`\n` 、 `\t` 都输出 `space` ；
- `\\` 输出一个反斜杠， `\"` 输出一个双引号；
- `%%` 输出 `%` ；
- `%d` 输出 `int` ， `%f` 输出 `float` ， `%s` 输出 `char[]` ， `%c` 输出 `char` ；
- 其余可见字符输出它的 ASCII 码。

若 `\` 或 `%` 后面跟的字符不在上面列出的范围之内，则格式字符串非法，此时只输出一行 `FORMAT STRING ERR0R` 。

#### 输入格式

一行，一个格式字符串。

#### 输出格式

格式字符串合法时，每一项输出一行；非法时只输出一行 `FORMAT STRING ERR0R` 。

#### 样例输入

```text
a %d b
```

#### 样例输出

```text
97
space
int
space
98
```

### 答案

### 题目分析

只需按照题目中给出的方法进行判断即可。需要注意的是，当字符串错误时，应该输出且只输出一行字符串，不应该输出其他信息。因此不能边读入边输出或边处理边输出，而应该在处理时，将准备输出的内容存储起来，避免后续字符串错误时额外输出其他信息。

### 示例代码

```c
#include<stdio.h>
#include<string.h>
char s[10086];
int ans[10086],cnt;//用于保存输出信息
int isError=0;//字符串是否错误
int main(){
    gets(s);
    for ( int i=0,size=strlen(s) ; i<size && isError==0 ; i++ ){
        if ( s[i]=='\\' ){
            switch ( s[i+1] ){
                case '\\':ans[++cnt]=1;break;
                case '"':ans[++cnt]=2;break;
                case 'n':ans[++cnt]=0;break;
                case 't':ans[++cnt]=0;break;
                default:isError=1;break;
            }
            i++;//不要忘记跳过后面的字符
        }
        else if ( s[i]=='%' ){
            switch ( s[i+1] ){
                case '%':ans[++cnt]=3;break;
                case 'd':ans[++cnt]=4;break;
                case 'f':ans[++cnt]=5;break;
                case 's':ans[++cnt]=6;break;
                case 'c':ans[++cnt]=7;break;
                default:isError=1;break;
            }
            i++;
        }
        else if ( s[i]==' ' )
            ans[++cnt]=0;
        else
            ans[++cnt]=s[i];
    }
    if ( isError ){//错误，不输出其他信息
        puts("FORMAT STRING ERR0R");
        return 0;
    }
    for ( int i=1 ; i<=cnt ; i++ )
        if ( ans[i]>=32 )//可见字符，输出 ascii 码
            printf("%d\n",ans[i]);
        else//特殊字符或类型或空白，根据之前的赋值输出
            switch ( ans[i] ){
                case 0:puts("space");break;
                case 1:puts("\\");break;
                case 2:puts("\"");break;
                case 3:puts("%");break;
                case 4:puts("int");break;
                case 5:puts("float");break;
                case 6:puts("char[]");break;
                case 7:puts("char");break;
            }
    return 0;
}
```

## F 最大向量价值

| 难度 | 考点 |
| --- | --- |
| 6 | 状态压缩 |

### 题目

#### 题目描述

给定 `n` 个 `m` 维向量。从中选取任意多个向量求和，得到和向量

$$
\vec{v} = (v_1, v_2, \dots, v_m)
$$

对和向量构造符号数列 `b` ：

$$
b_i = \begin{cases}
1 & , v_i \ge 0 \\
-1 & , v_i < 0
\end{cases}
$$

和向量的向量价值定义为

$$
value = \sum_{i=1}^{m} b_i v_i = \sum_{i=1}^{m} |v_i|
$$

求所能得到的最大向量价值。

#### 输入格式

第一行两个整数 `m` 和 `n` ，分别是向量的维数和向量的个数。

接下来 `n` 行，每行 `m` 个整数，依次是一个向量的各维分量。

#### 输出格式

一行一个整数，为最大的向量价值。

#### 样例输入

```text
2 3
1 -2
-3 4
2 2
```

#### 样例输出

```text
7
```

#### 数据范围

`m \le 8` ，答案可能超过 `int` 的表示范围

### 答案

### 题目分析

假设我们已经选取了 $k$ 个 $m$ 维向量 $\overrightarrow{a[1]}, \overrightarrow{a[2]}, \ldots, \overrightarrow{a[k]}$，得到了一个和向量
$$\vec{v} = (v_1, v_2, \cdots, v_m) = (a[1]_1 + a[2]_1 + \ldots + a[k]_1, a[1]_2 + a[2]_2 + \ldots + a[k]_2, \ldots, a[1]_m + a[2]_m + \ldots + a[k]_m) $$
；对应于数列 $v$，我们构造一个符号数列 $b$，如下：

$$
b_i = \begin{cases}
1 & , v_i \geq 0 \\
-1 & , v_i < 0
\end{cases}
$$

则 $\vec{v}$ 对应的向量价值为

$$
value = \sum_{i=1}^{m} b_i v_i = \sum_{i=1}^{m} b_i (a[1]_i + a[2]_i + \ldots + a[k]_i) = \sum_{j=1}^{k} (b_1 a[j]_1 + b_2 a[j]_2 + \ldots + b_m a[j]_m)
$$

。

简单来说，如果我们确定了最后求出的和向量各维度符号为 $(b_1, b_2, \ldots, b_m)$，那么被选中的某个向量 $\vec{a} = (a_1, a_2, \ldots, a_m)$ 对于这个和向量向量价值的贡献为 $cont = b_1 a_1 + b_2 a_2 + \ldots + b_m a_m$；如果 $cont > 0$，那么就说明这个被选中的向量对和向量做了正贡献，使其向量价值增大；如果 $cont < 0$，那么就说明这个被选中的向量对和向量做了负贡献，使其向量价值减小；如果 $cont = 0$，那么就说明无论选不选这个向量都不会影响最后的向量价值。

对于某个确定的维度 $m$，选取若干向量求得的和向量的符号序列 $(b_1, b_2, \ldots, b_m)$ 有多少种可能呢？很显然，每一位都可以取到 $-1$ 或 $1$，故最后的符号序列一共有 $2^m$ 种可能。对于某确定的符号序列，符合这个符号序列的和向量的**可能**的最大向量价值是多少呢？我们可以遍历向量数组，用这个符号序列计算每个向量对于这种符号序列的和向量的贡献值，如果贡献值大于 0，那么就把它加入到和向量中。于是，我们得到了所有 $2^m$ 情况对应的**可能**的最大值，然后我们就可以遍历 $2^m$ 个情况和向量的最大值中选出一个最大的，作为选取若干向量组成和向量的最大向量价值。

这里需要特别说明的是，**每种情况求出的可能的最大向量价值是不一定取的到的，但是所有情况里最大的可能的向量价值是一定取的到的。** 例如只有一个二维向量 $(-3, 7)$ 对于和向量符号情况 $(1, 1)$ 和 $(-1, 1)$ 都是有正贡献的，但是和向量是根本不可能取到 $(1, 1)$ 的，但是**一定能取到所有情况中能得到最大向量价值的情况**。这是因为

$$
|a| + |b| = max(a, -a) + max(b, -b) = max(a + b, a - b, -a + b, -a - b)
$$

，取最大值时 $a$ 和 $b$ 前的符号与 $a$ 和 $b$ 的符号相对应，对于更多项的公式也是类似的。故和向量各维度绝对值之和取最大值时，各维度的符号一定与该符号序列状态的各维度（也就是公式中每个项前面的正负符号）相对应。

最后考虑具体实现，实际上，我们用一个正整数就能表示和向量的符号序列。比如知道所有向量维度是 3，那么就可以用 6，即 110 表示符号序列 $(-1, -1, 1)$；用 1，即 001 表示符号序列 $(1, 1, -1)$ 等。我们用数组元素 $val_i$ 表示对应符号序列为 $i$ 的和向量的向量价值。每读入一个向量，我们就看看它对所有 $2^m$ 个状态是否有正贡献，如果有正贡献，就把对应的贡献值加到 $val_i$ 上。处理完所有向量后，最大的 $val$ 值就是选取若干向量可能得到的最大的向量价值。

因为根据数据范围最大的值可能超过 int，所以用 long long 类型保存 $val$ 数组。

### 示例代码

```c
#include <stdio.h>
#include <string.h>

long long val[1 << 8];  // 向量最大维度 8 维，最多 1<<8 种状态
int vec[10];

int main()
{
    int n,m;
    scanf("%d%d",&m,&n);
    int sta = 1 << m;   // 状态数

    // 处理每个向量
    for(int i = 1;i <= n;i++)
    {
        // 读入某向量的全部 m 个维度, 这里会覆盖上一次读入的数据
        for(int j = 1;j <= m;j++)
        scanf("%d",&vec[j]);

        // 依次遍历每一种可能的符号序列状态
        for(int j = 0;j < sta;j++) {
            // 计算对该状态的贡献
            int con = 0;
            for(int k = 1;k <= m;k++) {
                // 从状态里取出符号
                int op;
                if(((j >> (k-1)) & 1) == 0) {
                    op = 1;
                } else {
                    op = -1;
                }
                con += op * vec[k];
            }
            if(con > 0) val[j] += con; // 正贡献就加入
        }
    }

    // 开始找所有状态里的最大值
    long long maxVal = -1;
    for(int i = 0;i < sta;i++){
        if(val[i] > maxVal) {
            maxVal = val[i];
        }
    }

    printf("%lld\n",maxVal);
    return 0;
}
```

| 难度 | 考点 |

| 5 | 分治 递归 |

### 题目

#### 题目描述

给定 `n` 个互不相同的整数和一个整数 `k` ，求其中第 `k` 小的数。

要求用题目给出的 `SELECT` 伪代码实现：以区间最后一个元素为基准做划分，只递归进入包含第 `k` 小元素的那一侧。

#### 输入格式

第一行两个整数 `n` 和 `k` 。

第二行 `n` 个互不相同的整数。

#### 输出格式

一行一个整数，为第 `k` 小的数。

#### 样例输入

```text
5 3
5 2 8 1 9
```

#### 样例输出

```text
5
```

#### 数据范围

`n \le 5 \times 10^6`

### 答案

### 题目分析

其实实现本题所有的思路在题目描述中已经尽数给出了，我们要做的就是把两段伪代码转化成 C 语言代码而已，这里不再赘述了。

我们已经提到过，题目中的实现只是**期望时间**为线性，对于一些特殊的输入最坏情况下算法的复杂度为平方级。我们在交换过程中每次都选取最后一个元素作为基准，所以可以使用一些构造样例的手段让我们的复杂度达到最坏。其实正确的做法是每次在要分割的数组中随机地选取一个元素作为用来分割的元素，也就是把它变成一个随机算法。

其次，题目中保证了所有元素互不重复，可以思考一下当可能有很多元素重复时会发生什么，我们的算法效率会比较低下，因为 `SELECT` 每次可能只移动一位。更好的做法是分割时把区间分成三段，小于一段，等于一段和大于一段；比较的时候也用区间判断。但是因为上述的两种更好的做法实现起来太过复杂，在这里我们只把它们放在题解中，仅作为一些扩展。

最后要注意的一点是交换时不要使用异或三次的做法，即 `i ^= j;j ^= i;i ^= j;` 这样在两个数的地址相同时就会出问题。

### 示例代码

```c
#include <stdio.h>
int A[5000005];

void swap(int i,int j)
{
    int tem = A[i];
    A[i] = A[j];
    A[j] = tem;
}

int partition(int *A, int p, int r)
{
    int x = A[r];
    int i = p - 1;
    for (int j = p; j <= r - 1; j++)
        if (A[j] <= x)
        {
            i = i + 1;
            swap(i , j);
        }
    swap(i + 1, r);
    return i + 1;
}

int select(int *A, int p, int r, int i)
{
    if (p == r)
        return A[p];
    int q = partition(A, p, r);
    int k = q - p + 1;
    if (i == k)
        return A[q];
    else if (i < k)
        return select(A, p, q - 1, i);
    else
        return select(A, q + 1, r, i - k);
}

int main()
{
    int n, k;
    scanf("%d%d", &n, &k);
    for (int i = 1; i <= n; i++)
        scanf("%d", &A[i]);
    printf("%d\n", select(A, 1, n, k));
    return 0;
}
```

## I CVBB&QLV

| 难度 | 考点 |
| --- | --- |
| 6 | 数论 |

### 题目

#### 题目描述

从点 `(1, 1)` 出发，可以进行下面四种操作，其中 `a` 是给定的素数：

- `(x, y) \to (x - y, y)`
- `(x, y) \to (x, y - x)`
- `(x, y) \to (a \times x, y)`
- `(x, y) \to (x, a \times y)`

给定 `n` 组询问，每组给出 `a` 和目标点 `(x, y)` ，判断该点能否从 `(1, 1)` 到达。

#### 输入格式

第一行一个整数 `n` 。

接下来 `n` 行，每行三个数 `a` 、 `x` 、 `y` 。

#### 输出格式

每组询问输出一行。可以到达输出 `iloveyou` ，否则输出 `seeyouagain` 。

#### 样例输入

```text
3
2 6 4
2 6 9
3 9 27
```

#### 样例输出

```text
iloveyou
seeyouagain
iloveyou
```

#### 数据范围

`a` 为素数， `x` 、 `y` 用 `long long` 表示

### 答案

### 题目分析

本题的关键在于对题目条件的转化。观察题目描述的操作，有 $x -= y$ 和 $y -= x$，不难联想到经典的辗转相除求最大公约数。

注意到点 $(x, y)$ 可以到达当且仅当 $x$ 和 $y$ 的最大公约数是 $a$ 的 $k$ 次幂，即 $\gcd(x, y) = a^k$，其中 $a$ 为素数，下证明其充分必要性。

<!-- markdownlint-disable-next-line MD036 -->
**必要性**

- 使用秘术 1,2，即从 $(x, y)$ 移动到 $(x - y, y)$ 或 $(x, y - x)$， $\gcd(x, y)$ 保持不变。
- 使用秘术 3,4，即从 $(x, y)$ 移动到 $(a \times x, y)$ 或 $(x, a \times y)$， $\gcd(x, y)$ 不变或变为 $a \times \gcd(x, y)$。

若一个点 $(x, y)$ 能从点 $(1, 1)$ 到达，则必然有 $\gcd(x, y) = a^k \times \gcd(1, 1) = a^k$。

<!-- markdownlint-disable-next-line MD036 -->
**充分性**

若一个点 $(x, y)$ 满足 $\gcd(x, y) = a^k$，下归纳证明其必能从点 $(1, 1)$ 到达。

(1) 当 $x + y = 2$ 时， $(x, y)$ 为 $(1, 1)$，显然可以到达。

(2) 假设对于所有满足 $x + y \leq n - 1$ 且 $\gcd(x, y) = a^k$ 的点均能从点 $(1, 1)$ 到达，证明对于所有满足 $x + y = n$ 且 $\gcd(x, y) = a^k$ 的点也可到达，其中 $n > 2$。

- 若 $x$ 和 $y$ 中至少有一个为 $a$ 的倍数，不妨设 $x$ 为 $a$ 的倍数，根据归纳假设，点 $(\dfrac{x}{a}, y)$ 可到达，故点 $(x, y)$ 也可到达。
- 若 $x$ 和 $y$ 均不为 $a$ 的倍数且 $x \neq y$，不妨设 $x > y$，存在 $0 \leq m \leq a - 1$，使得 $a \mid x + my$。构造点 $(\dfrac{x+my}{a}, y)$，则 $\dfrac{x+my}{a} + y < x + y = n$ 且 $\gcd(\dfrac{x+my}{a}, y) = a^{k'}$，根据归纳假设，点 $(\dfrac{x+my}{a}, y)$ 可到达，故点 $(x, y)$ 也可以到达。
- 若 $x$ 和 $y$ 均不为 $a$ 的倍数且 $x = y$，则 $\gcd(x, y) = x = y = a^k = a^0 = 1$，此时 $n = x + y = 2$ 与 $n > 2$ 的假设矛盾。

综上所述，对于给定点 $(x, y)$，只需通过辗转相除法求出 $\gcd(x, y)$，再判断 $\gcd(x, y)$ 是否为 $a$ 的 $k$ 次幂即可。

时间复杂度： $O(n \times \log(\min\{x, y\}))$

空间复杂度： $O(\log(\min\{x, y\}))$

### 示例代码

```c
#include <stdio.h>
long long gcd(long long a, long long b) {
    return b == 0 ? a : gcd(b, a % b);
}

int isReachable(int a, long long x, long long y) {
    long long g = gcd(x, y);
    while (g % a == 0) {
        g /= a;
    }
    return g == 1;
}

int main() {
    int n, a;
    long long x, y;
    scanf("%d", &n);
    for (int i = 0; i < n; i++) {
        scanf("%d %lld %lld", &a, &x, &y);
        if (isReachable(a, x, y)) {
            printf("iloveyou\n");
        } else {
            printf("seeyouagain\n");
        }
    }
    return 0;
}
```

若干行，每行形如 `x+y: n=a+b` ，其中 `x` 、 `y` 分别是 `a` 、 `b` 的素因子个数，按 `a` 从小到大输出。

### 题目分析

基本思路是枚举法，枚举 $a$，进而判断 $a$ 和 $b = n - a$ 是否为素数或半素数。然后按照输出要求输出即可。

因此，我们需要构造能够判断一个数是否为素数或半素数的函数。

### 思路 1

书上例题中就有判断是否为素数的函数，如下方代码：

```c
int is_prime(int num) //判断num是否为素数
{
    if (num < 2) return 0;
    for (int i = 2; i * i <= num; i++) //枚举至根号num即可
        if (num % i == 0) return 0;
    return 1;
}
```

我们可以利用该函数写出判断是否为半素数的函数：

```c
int is_semiprime(int num) //判断num是否为半素数
{
    for (int i = 2; i * i <= num; i++)
    {
        if(num % i == 0) //i为num的约数，即num = i * (num / i)
        {
            if(is_prime(i) && is_prime(num / i)) //若num可以分解为两个素数相乘，说明是半素数
                return 1;
        }
    }
    return 0;
}
```

### 题目

#### 题目描述

把一根长度为 `x` 的木棍分成 `k` 段，设第 `i` 段的长度为 `a_i` ，要求

$$
a_i \ge 1, i \le 2
$$

$$
a_i \ge a_{i-1} + a_{i-2}, i \ge 3
$$

求最大的 `k` 。

#### 输入格式

第一行一个整数 `T` ，表示数据组数。

接下来 `T` 行，每行一个整数 `x` 。

#### 输出格式

每组数据输出一行一个整数，为最大的段数 `k` 。


#### 样例输出


### 答案

### 题目分析

若木棍可以分为 $k$ 段，设 $a_i$ 为第 $i$ 段木棍长度，则不妨令这 $k$ 段木棍的长度单调不减，即 $a_1 < a_2 < \ldots\ldots < a_k$。

由题，对于第 $i$ 段，总有：

$$
a_i \geq 1, i \leq 2
$$

$$
a_i \geq a_{i-1} + a_{i-2}, i \geq 3
$$

当取等号时，木棍各段之和最小。

故可先预处理出每个段数木棍最小长度，然后对于每一个 $x$，查找木棍段数之和不大于 $x$ 的最大段数，此段数即为答案。

```c
        {

            {

            }
```

### 题目分析

假设一种颜色的球可以被取走 $mid$ 个，由贪心原则，在取这些球时，所有球数不小于 $mid$ 个的颜色最多被取走 $mid$ 个球，小于 $mid$ 个的颜色最多将所有的球取走。计算此时被取走球的总数 $sum$，可证明当 $sum \geq (k - 1) * mid$，则此时该种球可以被取走 $mid$ 个，反之不可。

在计算总数时，需要使用前缀和以节省时间，而不能直接遍历。同时，可以再次二分以确定不小于 $mid$ 个球的分界点，此时时间复杂度为 $O(nlognlogn)$，可通过此题；也可以在第一次二分时就将分界点确定，此时时间负责度为 $O(nlogn)$。

## M Baymax的糖果王国

| 难度 | 考点 |
| --- | --- |
| 4 | 模拟，约瑟夫环 |

### 题目

#### 题目描述

`n` 颗糖果围成一圈，编号为 `1` 到 `n` 。两位官员轮流取糖果：

- 官员 BBetula 从 `1` 号糖果开始顺时针数 `k` 颗（已被取走的糖果跳过），取走数到的第 `k` 颗；
- 官员 CBetula 从 `n` 号糖果开始逆时针数 `m` 颗（已被取走的糖果跳过），取走数到的第 `m` 颗。

若两人这一轮取到同一颗糖果，则这一轮只取走一颗。每轮结束后输出本轮被取走的糖果编号，然后换行。重复上述过程直到糖果被取完。

#### 输入格式

一行三个整数 `n` 、 `k` 、 `m` 。

#### 输出格式

若干行，每行为该轮取走的糖果编号；同一轮取走两颗时，两个编号之间用一个空格分隔。

#### 样例输入

```text
5 2 3
```

#### 样例输出

```text
2 3
5 4
1
```

#### 数据范围

`n \le 1000`

### 答案

### 题目分析

本题考查用代码模拟题目描述的能力。

根据游戏规则，我们可以做出下述处理：

- 根据 $n \leq 1000$，创建一个大小为 1005 的数组 `a[1005]`，用于储存糖果的编号并标记糖果是否被带离。
- 对于编号为 `i`（ $1 \leq i \leq n$）的糖果，可令 `a[i] = i`，当该糖果被带离时，为了避免移动数组元素，用 `a[i] = 0` 代表该糖果已经不在数组中。
- 对于每个轮次，可以用 `while` 循环模拟官员带离糖果的过程，当数到 `a[i] = 0` 的糖果时，跳过该糖果即可。每个轮次结束后，输出被带离糖果编号。

### 示例代码

```c
#include <stdio.h>
int a[1005]; //储存糖果的编号并标记糖果是否被带离
int main()
{
    int n, k, m, left;
    scanf("%d%d%d", &n, &k, &m);
    for (int i = 1; i <= n; i++) //初始化每个糖果的编号
        a[i] = i;
    left = n; //储存当前剩余糖果的数目
    int front = n, back = 1; //初始时两个官员数糖果的位置
    while (left > 0)  //当还有糖果未被带离时，游戏继续进行
    {
        int kk = k, mm = m;
        while (kk--) //逆时针数k个
        {
            do
            {
                front = front % n + 1;
            } while (a[front] == 0); //跳过已经被带离的糖果
        }
        while (mm--) //顺时针数m个
        {
            do
            {
                back = (back - 2 + n) % n + 1;
            } while (a[back] == 0);
        }
        printf("%d ", front); //输出官员BBetula带离的糖果编号
        left--;
        if (back != front)
        {
            printf("%d ", back); //当两个官员选中不同糖果时，输出官员CBetula带离的编号
            left--;
        }
        printf("\n");
        a[front] = a[back] = 0; //将对应元素置0，标记对应糖果已被带离
    }
}
```

## N 水獭密码

| 难度 | 考点 |

| 3 | 二维数组 |

### 题目

#### 题目描述

水獭把一个长度为 `len` 的字符串按行写入一个 `n \times n` 的方阵中，其中 `n` 是满足 `n \times n \ge len` 的最小正整数：字符串的第 `pos` 个字符放在第 `pos / n` 行、第 `pos \bmod n` 列（行列都从 `0` 开始计数），方阵中没有被填到的位置保持为空。

随后水獭按列读出这个方阵：先读第 `0` 列的第 `0` 行到第 `n-1` 行，再读第 `1` 列，依此类推，跳过空的位置。把读出的字符依次连接起来就是密码。

给定原字符串，求密码。

#### 输入格式

一行，一个不含空格的字符串。

#### 输出格式

一行，为按上述规则得到的密码。

#### 样例输入

```text
abcdefg
```

#### 样例输出

```text
adgbecf
```

### 答案

### 题目分析

本题考察同学们对于二维数组的基本使用 ，我们只需要开辟一个大小足够的二维数组，然后将读入的字符串按行放入这个二维数组中，再按列依次进行输出即可。如果二维数组成功初始化的话，实际上我们在输出字符时并不需要特判是不是空字符，因为空字符本来就是没有输出的（你可以运行 `printf("%c",(char)0);` 观察结果，注意字符 `'0'` 和空字符的区别）。

要注意的是有同学的做法是先求出满足 $n \times n \geq k$ 的最小正整数 $n$，然后再找到 $n \times n$ 矩阵中每个位置对应原字符位置的值，但是这样可能带来的一个问题就是访问的一位数组下标可能超出 100000（为大于 100000 的最小完全平方数），所以一维数组不开大一点采用这种方法就会越界。

### 示例代码

```c
#include <stdio.h>
#include <math.h>
#include <string.h>

char c[100010];
char c2[320][320];

int main()
{
    scanf("%s",c);
    int len = strlen(c);
    int n = ceil(sqrt(len));    // ceil 是取上整函数

    int pos = 0;
    while(pos < len) {
        int i = pos / n ;
        int j = pos % n ;   // 按行放置
        c2[i][j] = c[pos];
        pos++;
    }

    for(int j = 0;j < n;j++) {
        for(int i = 0;i < n;i++) {
            printf("%c",c2[i][j]);
        }
    }

    return 0;
}
```

也有同学使用一维数组计算应该输出的下标的方法做的，这样当然也可以，但是可以比较一下是不是使用二维数组之后逻辑更简单了。

## O Baymax 的破旧键盘

| 难度 | 考点 |
| --- | --- |
| 6 | 字符串，数组复杂应用 |

### 题目

#### 题目描述

Baymax 的键盘上， `[` 键把光标移到显示屏的最前面， `]` 键把光标移到显示屏的最后面，其余字符在光标所在位置之后插入。

给定输入的按键序列，求显示屏上最终显示的内容。

多组数据，读到文件结束为止。

#### 输入格式

若干行，每行一个不含空格的字符串，表示一次按键序列，读到文件结束为止。

#### 输出格式

每组数据输出一行，为显示屏上最终显示的内容。

#### 样例输入

```text
ab[cd]ef
```

#### 样例输出

```text
cdabef
```

### 答案

### 题目分析

本题最简单的想法就是用一个数组来保存输入的字符串，然后用一个变量 `pos` 保存「光标位置」。这样，输入一个字符相当于在数组中插入一个字符。

但很可惜，这样的代码会超时。因为每输入一个字符都可能会引起大量字符移动。在极端情况下，例如输入 2500000 个 a 和 `[` 交替出现，则一共需要 $0 + 1 + 2 + \cdots + 2499999 = 6 \times 10^{12}$ 次字符移动。

这个问题该如何解决呢？我们可以创建一个 `next` 数组来记录输入字符的位置。设输入字符串为 `s[1~n]` ，则可以用 `next[i]` 表示在当前显示屏中 `s[i]` 右边的字符位置。

为了方便起见，假设字符串 `s` 的最前面还有一个虚拟的 `s[0]`，则 `next[0]` 就可以表示显示屏中最左边的字符。再用一个变量 `cur` 表示光标位置：即当前光标位于 `s[cur]` 的右边。`cur=0` 说明光标位于 `s[0]` 的右边，即显示屏的最左边。为了移动光标，还需要一个 `last` 变量表示显示屏的最后一个字符是 `s[last]`。代码如下：

### 示例代码

```c
#include <stdio.h>
#include <string.h>
#define maxn 100005
int next[maxn], last, cur;
char s[maxn];

int main()
{
    while (scanf("%s", s + 1) != EOF)
    {
        last = cur = 0; //初始化last和cur
        next[0] = 0;
        int len = strlen(s + 1);
        for (int i = 1; i <= len; i++)
        {
            if (s[i] == '[') //将光标移动到最前端
                cur = 0;
            else if (s[i] == ']') //将光标移动到最后端
                cur = last;
            else
            {
                next[i] = next[cur]; //将字符接在当前光标的下一个位置
                next[cur] = i;
                if (cur == last) //更新最后一个字符的编号
                    last = i;
                cur = i; //移动光标
            }
        }
        for (int i = next[0]; i != 0; i = next[i])
            putchar(s[i]);
        printf("\n");
    }
}
```

## P 摩卡与水獭乐团派对

| 难度 | 考点 |
| --- | --- |
| 4 | malloc，指针，指针数组 |

### 题目

#### 题目描述

摩卡邀请了 `n` 只水獭参加派对，每只水獭有一个名字，名字可能包含空格。

接下来进行 `m` 次交换，每次给出两个编号 `u` 和 `v` ，交换这两个位置上水獭的名字。输出最终每个位置上的名字。

#### 输入格式

第一行两个整数 `n` 和 `m` 。

接下来 `n` 行，每行一只水獭的名字。

接下来 `m` 行，每行两个整数 `u` 和 `v` 。

#### 输出格式

`n` 行，依次为最终每个位置上的名字。

#### 样例输入

```text
3 2
Alice
Bob Smith
Carol
1 2
2 3
```

#### 样例输出

```text
Bob Smith
Carol
Alice
```

#### 数据范围

`n \le 10^4` ，所有名字的总长度不超过 `4.5 \times 10^5`

### 答案

### 题目分析

下面为大家提供两种思路：

第一种思路基本就是 Hint 想要告诉大家的了，如果直接开二维数组的话，第二个维度太大许多空间就被浪费了（对于这道题会 MLE）；第二维开的太小的话又存不下最长的字符串，所以我们想到用 malloc 为每个水獭的名字动态分配空间。我们要开一个数组存所有水獭的名字，换句话说，数组中的每个元素是一个长度不定的字符数组，所以想到了开一个指针数组。关于一些细节问题比如申请的空间要比 $len$ 多一位，用来存字符串最后的 `\0`；还比如空格（用 gets 读入）和换行（第一行后面的）的处理；水獭名字的交换（交换两个指针实现）。

第二种思路由助教 Gino 启发得到，实际上我们不需要使用 malloc。这种思路的观点是我们可以连续地读入一个又一个字符串（别忘了字符串是以最后的空字符为界的），每次只需要记录每个字符串的起始地址。具体实现上来说还是开一个指针数组，每用 $str$ 读入一个水獭名字之后，就将其首地址赋给对应的指针元素，然后将 $str$ 向后移动，直到指向与前一个名字没有重叠的位置（不重叠包括前一个字符串最后的空字符，字符串以空字符为界，如果覆盖掉这个空字符就没法正确地分离出水獭的名字了），再重复上述过程。最后的交换过程还是通过交换两个指针。

具体实现参考下面的实例代码，示例一对应着思路一，示例二对应着思路二。

### 示例代码1

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

char *otter[10005];
char str[1005];

int main()
{
    int n,m;
    scanf("%d%d",&n,&m);
    getchar();  // 吃掉换行符

    for(int i = 1;i <= n;i++) { // 读入每只水獭的名字
        gets(str);
        int len = strlen(str);
        otter[i] = (char*)malloc(len*sizeof(char) + 1); // 多开一位存空字符，sizeof(char) 实际上就是 1
        strcpy(otter[i],str);
    }

    for(int i = 1;i <= m;i++) { // 交换水獭
        int u,v;
        scanf("%d%d",&u,&v);

        char *x = otter[u];
        otter[u] = otter[v];
        otter[v] = x;
    }

    for(int i = 1;i <= n;i++) {
        puts(otter[i]);
        free(otter[i]); //有借有还
    }

    return 0;
}
```

## Q 摩卡与昵称检验

| 难度 | 考点 |
| --- | --- |
| 3 | 日期处理，字符串解析 |

### 题目

#### 题目描述

摩卡的昵称必须满足下面两个条件：

- 前半部分是回文串，可以为空；
- 后半部分恰好是 `8` 位数字，组成一个合法日期 `yyyymmdd` 。

分界线是字符串末尾往前 `8` 个字符的位置。给定 `n` 个字符串，逐个判断是否为合法昵称。

#### 输入格式

第一行一个整数 `n` 。

接下来 `n` 行，每行一个字符串。

#### 输出格式

每组数据输出一行，符合要求输出 `Yes` ，否则输出 `No` 。

#### 样例输入

```text
4
aba20240229
ab20240229
aa20230229
20240229
```

#### 样例输出

```text
Yes
No
No
Yes
```

#### 数据范围

字符串长度不超过 `1000`

### 答案

### 题目分析

本题思路很清晰，但是有不少琐碎的细节需要处理好。

首先不难发现，我们可以分别判断:

- 输入字符串的前半部分是否符合回文要求
- 输入字符串的后半部分是否符合合法日期要求

若两个条件都满足，则说明符合题目要求的格式。

因此首先我们可以将字符串 s 的前半和后半部进行拆分，以 `strlen(s) - 8` 为分界线，然后分别对前后进行检验：

### 后半部分检验

1. 有个小细节，题目并没说 s 的最后一定跟了8个数字，甚至不保证 `s` 的长度大于等于8，所以 `strlen(s) - 8` 可能是负数，这时应及时反馈 `格式检查不通过` 的结果（`return 0;`），避免代码运行时访问负数数组下标而越界。
2. 在满足上述条件的情况下，我们确保了我们检查的对象是8位的。但是却并不一定是合法日期，首先不难想到这8位应该全是数字才行，因此我们做数字检查，若有其他字符出现则 `return 0;`。
3. 在满足上述条件的情况下，我们确保了我们检查的对象是8位纯数字。这时候就要考察日期的知识了。
   - 首先我们要做字符串解析将字符串日期转换成 `int` 类型方便处理（具体参见示例代码，有注释）。（如：`int y = 2024, m = 9, d = 1;`）
   - 然后我们判断当年是否是闰年：`闰年 <==> (年份能被4整除 && 不能被100整除) || (年份能被400整除)`，关于闰年的判断方式请同学们熟记，是一个很常见的考点。
   - 然后判断月日是否符合格式，月份很简单，保证其在区间 `[1, 12]` 即可。日 则稍微复杂，因为每个月的天数都不一样，如果用条件分支去列举12个月份分别判断的话则会有些冗余，可以通过定义一个数组来较为优雅地解决 `days[20] = {0, 31, x, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31}`，数组元素含义：`days[i]` 表示i月份的总天数，其中2月份的天数值要根据我们刚才判断出来的平闰年来填充（闰年是29天，平年28天）。然后便可不需冗余代码，直接判断 `if (!(d <= days[i] && d >= 1)) return 0;`
   - 上面的检查均通过后即可说明字符串的后半部分是合法的日期。

### 前半部分检验

这个很简单，对前半部分从头到尾扫一遍，判断对称位置的两个元素是否均相等即可。注意一点：**前半部分可能为空** 以及 **前半部分不一定全是字母, 有可能有数字**（因此不可以从前向后扫，将扫到的第一个非字母位置作为前半后半部分的分界点）。

### 示例代码（By shtog）

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
char s[1003]; // 正处理的字符串
int b; // s[b]为年份的第一个字符，b是分界线
int len; // 正处理的字符串的长度

int ok1() { // 判断前半部分是否符合回文的要求
    if (b < 0) return 0;
    int i = 0;
    for (; i < b; ++i) {
        // s[i]和s[b - i - 1]是对称位置上的两个字符, 一旦发现有一对儿不相等则返回0
        if (!(s[i] == s[b - i - 1])) return 0;
    }
    return 1;
}

int isLeap(int y) { // 是闰年返回1，否则0
    return y % 400 == 0 || (y % 4 == 0 && y % 100 != 0);
}

int day[20] = {0, 31, 29, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31}; // day[i]表示 i月份的天数，其中day[2]表示2月份的天数，要根据闰平年来具体化

int okdate(int y, int d, int m) { // 判断年月日是否是符合格式的
    if (isLeap(y)) day[2] = 29; // 将2月份的天数根据闰平年调整
    else day[2] = 28;
    if (m == 0 || m > 12) return 0; // 确保月份在[1, 12]之间
    if (!(d >= 1 && d <= day[m])) return 0; // 确保日期在[1, 该月上限]之间
    return 1;
}

int ok2() { // 判断后半部分是否满足格式要求
    if (b == len) return 0;
    // 是8个数字
    if (len - b != 8) return 0;
    int j = 0;
    while (b + j < len) { // 要保证后8位是纯数字，否则不符合格式
        if (!(s[b + j] <= '9' && s[b + j] >= '0')) return 0;
        j++;
    }
    int y = 0, m = 0, d = 0;
    int i = 0;
    // 下面几行将字符串解析为int类型的年月日
    while(i < 4) y = 10 * y + s[b + (i++)] - '0';
    i = 0;
    while(i < 2) m = 10 * m + s[b + 4 + (i++)] - '0';
    i = 0;
    while(i < 2) d = 10 * d + s[b + 4  + 2 + (i++)] - '0';
    return okdate(y, d, m); // 调用函数判断int类型的年月日是否合法
}

void judge() { // 判断当前读入的字符串是否符合格式要求
    b = len - 8;
    if (ok1() && ok2()) printf("Yes\n");
    else printf("No\n");
}

int main() {
    int n;
    scanf("%d", &n);
    gets(s);
    while (n--) {
        gets(s);
        len = strlen(s);
        judge();
    }
    return 0;
}
```

## S 尽善尽美

### 题目

#### 题目描述

称一个数组是「完美」的，当且仅当它能通过循环移位使得所有前缀和都非负；可以证明这等价于数组中所有元素之和 `sum \ge 0` 。

给定一个数组和三个整数 `p` 、 `q` 、 `r` ，可以进行下面三种操作：

- 花 `p` 元把某个元素增加 `1` ；
- 花 `q` 元删除某个元素，数组不能删空；
- 花 `r` 元进行第三种操作，它不会改变数组元素之和，对答案没有影响。

求使数组完美的最小代价。

#### 输入格式

第一行四个整数 `n` 、 `p` 、 `q` 、 `r` 。

第二行 `n` 个整数，为数组的各个元素。

#### 输出格式

一行一个整数，为最小代价。

#### 样例输入

```text
3 2 5 1
-5 1 1
```

#### 样例输出

```text
5
```

#### 数据范围

`n \le 10^5`

### 答案

### 题目分析

我们尝试证明结论：**一个数组是“完美”的，当且仅当** $\sum_{i=0}^{n-1} a_i \geq 0$

**充分性：**

对于当前数组，我们求取前缀和，假设前缀和最小值所对应位置位 $k$，值为 $pre_k$，因为 $sum = \sum_{i=0}^{n-1} a_i \geq 0$ 故 $sum - pre_k \geq 0$，当我们把位置 $[k+1, n]$ 的数组移至组首时（更新数组下标），我们易证 $\forall 0 \leq i < n, pre'_i \geq 0$，即可得数组为“完美”

**必要性：**

当数组“完美”时，易知对于任意连续的 $n$ 个数，其和为 $sum$，一定有 $sum \geq 0$

<!-- markdownlint-disable-next-line MD036 -->
**证毕**

因此，我们可以得到，操作三（代价 $r$ 的操作）其实无意义，仅需要考虑前两个操作即可

对于初始数组 $sum \geq 0$ 的情况，我们直接输出 0 即可

对于 $sum < 0$ 的情况，我们将其降序排序，考虑直接删除当前数更优还是逐点增加更优

<!-- markdownlint-disable-next-line MD036 -->
**Attention：数组不能删空**

### 示例代码

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <math.h>
#include <ctype.h>

#define ll long long
#define max(a, b) (((a) > (b)) ? (a) : (b))
#define min(a, b) (((a) < (b)) ? (a) : (b))
#define rep(i, a, b) for(int i = a; i <= b; i++)
#define per(i, a, b) for(int i = a; i >= b; i--)
#define maxn 100005

int arr[maxn], n;
int p, q, r;

int comp(const void * p, const void * q) {
    int * a = (int *)p;
    int * b = (int *)q;
    return (*a) - (*b);
}

int main() {
    scanf("%d %d %d %d", &n, &p, &q, &r);
    ll sum = 0;
    rep(i, 1, n) {
        scanf("%d", &arr[i]);
        sum += arr[i];
    }
    if(sum >= 0) { puts("0"); return 0; }
    if(n == 1) { printf("%lld\n", p * llabs(sum)); return 0; }
    qsort(arr + 1, n, sizeof(arr[0]), comp);
    ll ans = 0;
    rep(i, 1, n) {
        if(i != n) ans += min(q, min(llabs(sum), llabs(arr[i])) * p);
        else ans += llabs(arr[i]) * p;
        sum -= arr[i];
        if(sum >= 0) break;
    }
    printf("%lld\n", ans);
    return 0;
}
```

## T 农的新手教程

| 难度 | 考点 |
| --- | --- |
| 6 | 数组，排序，贪心 |

### 题目

#### 题目描述

妲己的攻击力为 `ATK` ，每秒攻击一次，每次攻击一名小兵。场上有 `n` 个小兵，第 `i` 个小兵的血量为 `HP_i` ，每秒造成的伤害为 `DAM_i` 。

消灭一个小兵需要的攻击次数为 `k_i = \lceil HP_i / ATK \rceil` 。在消灭所有小兵的过程中，妲己每秒受到场上所有存活小兵的伤害。求她所受总伤害的最小值。

#### 输入格式

第一行两个整数 `ATK` 和 `n` 。

第二行 `n` 个整数，依次为各小兵的 `DAM_i` 。

第三行 `n` 个整数，依次为各小兵的 `HP_i` 。

#### 输出格式

一行一个整数，为所受总伤害的最小值。

#### 样例输入

```text
2 2
3 1
4 4
```

#### 样例输出

```text
10
```

#### 数据范围

`n \le 10^5` ， `DAM_i` 、 `HP_i` 可达 `10^9`

### 答案

### 题目分析

本题主要运用数组排序和贪心策略。

根据常识，**逐个击破**（一直攻击同一单位，消灭一个换一个）比 **雨露均沾**（来回攻击多个单位，但是一个没消灭）好，因为这样被攻击的次数更少，在此不再赘述。

再根据常识，优先 **集火 $C$ 位**（攻击伤害高、血量少的“脆皮”单位）比优先 **打前排**（攻击伤害低、血量高的“肉坦”单位）好，下证明：

**设有两个小兵 $A$ 和 $B$。**

击杀 $A$ 需要攻击的次数为：

$$
k_A = \lceil \frac{H_A}{A} \rceil = \lfloor \frac{H_A - 1}{A} \rfloor + 1
$$

同理可得击杀 $B$ 需要的攻击次数 $k_B$。

若先击杀 $A$，再击杀 $B$，则受到的总伤害为：

$$
k_A \times D_A + (k_A + k_B) \times D_B
$$

若先击杀 $B$，再击杀 $A$，则受到的总伤害为：

$$
k_B \times D_B + (k_A + k_B) \times D_A
$$

不妨设先击杀 $A$ 再击杀 $B$ 更好，则有：

$$
k_A \times D_A + (k_A + k_B) \times D_B < k_B \times D_B + (k_A + k_B) \times D_A
$$

化简得：

$$
k_A \times D_B < k_B \times D_A
$$

所以，应当优先击杀 $\frac{D}{k}$ 更大的小兵，也就是 **集火 $C$ 位**。

**推广到更多的小兵。**

可以对小兵的 $\frac{D}{k}$ 排序，然后按顺序击杀，再用一个变量 $t$ 维护从开始到击杀当前小兵所用的秒数，把 $t \times D_i$ 加入受到的总伤害，即得所求结果。

注 1：小兵数量 $n$ 可以达到 $10^5$，使用低时间复杂度的排序算法。

注 2： $D$ 和 $k$ 可以达到 $10^9$，为避免浮点运算精度丢失，通过 **交叉相乘** 来比较两个分数的大小。

常见排序算法的性能比较表

### 示例代码 1

```c
#include <stdio.h>
#include <stdlib.h>

// 定义全局指针 g_k 和 g_DAM，以便在 cmp 中访问
int *g_k, *g_DAM;

// 比较两个小兵对象的 DAM/k 比值（使用交叉相乘避免浮点运算精度丢失）
int cmp(const void* a, const void* b) {
    int i = *(int*)a;
    int j = *(int*)b;
    long long tmp1 = (long long)g_DAM[i] * g_k[j];
    long long tmp2 = (long long)g_DAM[j] * g_k[i];
    // 返回比较结果，确保 qsort 从大到小排序
    return (tmp1 > tmp2) ? -1 : 1;
}

long long minDAM(int ATK, int* DAM, int* HP, int n) {
    int* k = (int*)malloc(n * sizeof(int));
    // 计算每个小兵的 k 值（攻击次数）
    for (int i = 0; i < n; i++) {
        k[i] = (HP[i] - 1) / ATK + 1;
    }
    // 创建索引数组 index，用于间接排序
    int* index = (int*)malloc(n * sizeof(int));
    for (int i = 0; i < n; i++) {
        index[i] = i;
    }
    // 设置全局指针 g_k 和 g_DAM，以便在 cmp 中访问
    g_k = k;
    g_DAM = DAM;
    // 对 index 数组进行排序
    qsort(index, n, sizeof(int), cmp);
    // 计算妲己受到的最小总伤害
    long long sumDAM = 0, t = 0;
    for (int i = 0; i < n; i++) {
        int idx = index[i];
        t += k[idx];             // 累计经过秒数（即攻击次数）
        sumDAM += t * DAM[idx];  // 累计受到的总伤害
    }
    free(k);
    free(index);
    return sumDAM;
}

int main() {
    int ATK, n;
    scanf("%d %d", &ATK, &n);
    int* DAM = (int*)malloc(n * sizeof(int));
    int* HP = (int*)malloc(n * sizeof(int));
    for (int i = 0; i < n; i++) {
        scanf("%d", &DAM[i]);
    }
    for (int i = 0; i < n; i++) {
        scanf("%d", &HP[i]);
    }
    printf("%lld\n", minDAM(ATK, DAM, HP, n));
    free(DAM);
    free(HP);
    return 0;
}
```

## U 奇怪的秒表

### 题目

#### 题目描述

一个奇怪的秒表第 `n` 次跳动发生在

$$
a_n = 1 + \frac{1}{2} + \frac{1}{3} + \dots + \frac{1}{n}
$$

秒。给定 `t` 组询问，每组给出一个 `n` ，求 `a_n` 。

当 `n` 较小时直接累加；当 `n` 较大时用 `\sum_{i=1}^{n} \frac{1}{i} - \ln n = \gamma` 近似，其中 `\gamma \approx 0.577215665` 。

#### 输入格式

第一行一个整数 `t` 。

接下来 `t` 行，每行一个整数 `n` 。

#### 输出格式

每组询问输出一行一个实数，保留两位小数。

#### 样例输入

```text

1
5
2000
```

#### 样例输出

```text
1.00
2.28
8.18
```

#### 数据范围

`n \le 1000` 时精确计算， `n` 更大时用近似公式

### 答案

### 题目分析

可证明：

$$
a_n = 1 + \frac{1}{2} + \frac{1}{3} + \ldots\ldots + \frac{1}{n}
$$

提示1：可先求 $a_n - a_{n-1}$ 的值，最后结果不要包含 $a_n$、 $a_{n-1}$。

当 $n$ 趋于无穷时，有 $\sum_{i=1}^{n} \frac{1}{i} - \ln(n) = \gamma$，可用此式计算当 $n$ 较大时的结果。

提示2：当 $n$ 较小时，上式计算结果有较大误差，此时要用遍历计算结果。

第一行一个正整数 `n` 。

第二行 `n` 个由空格分开的正整数 `P_i` 。

#### 输出格式

一行一个整数，为需要支付的价钱对 `998244853` 取模的结果。

#### 样例输入

```text
2
3 4
```

#### 样例输出

```text
42
```

#### 数据范围

累加过程中每次的值不到 `10^8`

### 答案

### 题目分析

本题数据范围较大，如果提交 E3 G 题的 AC 代码，会运行超时。

注意到，我们需要算的是所有可能的选择，因此对于每种配料，我们只需要算出，所有煎饼中，它产生的价格是多少即可。

对于第 $k$ 种配料，它作为倒数第 $i(1 \leq i \leq k)$ 种配料被加入的煎饼共有 $2^{n-k} \times C_{k-1}^{i-1}$ 种，因此它产生的总价格就是 $P_i \times 2^{n-k} \times \sum_{i=1}^{k} i C_{k-1}^{i-1}$，由 Hint 知这个数等于 $P_i \times (k+1) \times 2^{n-2}$。

因此所有配料在所有煎饼中产生的总价格为 $\sum_{k=1}^{n} P_k \times (k+1) \times 2^{n-2} = 2^{n-2} \times \sum_{k=1}^{n} P_k \times (k+1)$。

再加上每张煎饼的底价 6 元，共计 $6 \times 2^n$ 元，因此最后总共的花费是 $(24 + \sum_{k=1}^{n} P_k \times (k+1)) \times 2^{n-2}$ 元。

需要注意的是，当 $n = 1$ 时， $2^{n-2} = 2^{-1} = \frac{1}{2}$，使用循环进行乘法并不会除以 2，因此需要特判。

### 示例代码

```c
#include<stdio.h>
int n,t,s=24;//初始化 s=24 。每次累加的值不到 1e8 ，MOD*2 不超过 INT_MAX ，因此不会溢出。
const int MOD=998244853;
int main(){
    scanf("%d",&n);
    if ( n==1 ){//特判 n=1
        scanf("%d",&t);
        printf("%d",t+12);
    }
    else{
        for ( int i=1 ; i<=n ; i++ ){
            scanf("%d",&t);
            s=(s+t*(i+1))%MOD;//累加
        }
        for ( int i=3 ; i<=n ; i++ )//乘 2 的 n-2 次方
            s=(s*2)%MOD;
        printf("%d",s);
    }
    return 0;
}
```

## W 助教机器人

| 难度 | 考点 |

### 题目

#### 题目描述

助教机器人会对下面五个问题给出固定的回答：

| 问题 | 回答 |
| --- | --- |
| `My dear TA, my code sample is correct, why did it get WA?` | `If it's right locally, you got WA means there's something wrong with the review machine!` |
| `My dear TA, why is my code can't pass the sample test cases?` | `You can output some variables.` |
| `My dear TA, my code gets TLE for large cases. What should I do?` | `Looks like your algorithm is too slow or you have an Endless loop.` |
| `My dear TA, why does my program end without output?` | `Maybe you accessed an illegal space.` |
| `I see! Thank you, my dear TA!` | `You're welcome!` |

对其他任何问题，一律回答 `Wait a minute, let me have a look.` 。

给定若干行问题，逐行输出回答。

#### 输入格式

若干行，每行一个问题，读到文件结束为止。

#### 输出格式

每个问题输出一行，为对应的回答。

#### 样例输入

```text
My dear TA, my code sample is correct, why did it get WA?
Hello
```

#### 样例输出

```text
If it's right locally, you got WA means there's something wrong with the review machine!
Wait a minute, let me have a look.
```

### 答案

### 题目分析

根据对应的输入进行输出即可。

再强调一遍如果用 `scanf` 读入字符串的话，那么读到空格就会停止；要是想完整读入一行，需要使用 `gets` 。

比较的时候使用 `strcmp`，返回值为 0 说明比较的两个串相等。

### 示例代码

```c
#include <stdio.h>
#include <string.h>

int read() {
    int tem;
    scanf("%d",&tem);
    return tem;
}

char str[105];
char question[][105] = {
    "My dear TA, my code sample is correct, why did it get WA?",
    "My dear TA, why is my code can't pass the sample test cases?",
    "My dear TA, my code gets TLE for large cases. What should I do?",
    "My dear TA, why does my program end without output?",
    "I see! Thank you, my dear TA!"
};
char answer[][205] = {
    "If it's right locally, you got WA means there's something wrong with the review machine!",
    "You can output some variables.",
    "Looks like your algorithm is too slow or you have an Endless loop.",
    "Maybe you accessed an illegal space.",
    "You're welcome!"
};

int main() {
    while(gets(str)) {
        int flag = 0;
        for(int i = 0; i < 5 ;i++) {
            if(!strcmp(question[i], str)) {
                flag = 1;
                printf("%s\n", answer[i]);
            }
        }
        if(!flag)
            printf("Wait a minute, let me have a look.\n");
    }

    return 0;
}
```

## X 四进制位运算

| 难度 | 考点 |
| --- | --- |
| 3 | 位运算、流程控制 |

### 题目

#### 题目描述

把两个整数 `a` 、 `b` 的十进制写法看作四进制数，按四进制逐位进行运算：

- `a & b` 的每一位等于两个对应位中的较小者；
- `a | b` 的每一位等于两个对应位中的较大者。

输出运算结果，结果同样按四进制写法以十进制形式输出。

多组数据，读到文件结束为止。

#### 输入格式

若干行，每行两个整数和一个运算符，形如 `a op b` ，其中 `op` 为 `&` 或 `|` ，读到文件结束为止。

#### 输出格式

每组数据输出一行一个整数。

#### 样例输入

```text
12 & 13
12 | 13
```

#### 样例输出

```text
12
13
```

#### 数据范围

结果不超过 `16` 位四进制

### 答案

### 题目分析

不难发现，对于 A, B 四进制下的每一位 a, b ：

- `a & b = min(a, b)`
- `a | b = max(a, b)`

先进制转换再逐位计算再进制转换计算即可。

### 示例代码

```c
#include <stdio.h>
#include <string.h>

int min(int a, int b) {
    return a < b ? a : b;
}

int max(int a, int b) {
    return a > b ? a : b;
}

int main() {
    unsigned int a, b;
    char op;
    while(~scanf("%u %c %u", &a, &op, &b)) {
        unsigned int x = 0;
        unsigned int bit[20];
        if(op == '&') {
            for(int i = 0; i <= 15 ;i++)
                bit[i] = min(a % 4, b % 4), a /= 4, b /= 4;
        } else if(op == '|') {
            for(int i = 0; i <= 15 ;i++)
                bit[i] = max(a % 4, b % 4), a /= 4, b /= 4;
        }

        for(int i = 15; i >= 0 ;i--) {
            x *= 4;
            x += bit[i];
        }
        printf("%u\n", x);
    }
    return 0;
}
```

## Y maxStr

### 题目

#### 题目描述

给定两个长度相同的字符串 `a` 和 `b` ，逐位比较，取两个字符中较大的那一个组成新字符串并输出。

多组数据，读到文件结束为止。

#### 输入格式

若干行，每行两个不含空格的等长字符串，读到文件结束为止。

#### 输出格式

每组数据输出一行一个字符串。

#### 样例输入

```text
abc bca
```

#### 样例输出

```text
bcc
```

### 答案

### 题目分析

先获取串的长度，再对于每一位，逐位比较后赋值到新串上，最后再输出即可。
也可以不用字符串，直接比较一位输出一位。

### 示例代码

```c
#include <stdio.h>
#include <string.h>

char a[1005], b[1005];
char max(char a, char b) {
    return a > b ? a : b;
}

int main() {
    while (~scanf("%s%s", a, b)) {
        int len = strlen(a);
        for(int i = 0; i < len ;i++)
            putchar(max(a[i], b[i]));
        printf("\n");
    }

    return 0;
}
```

## Z 最小的K个数

| 难度 | 考点 |
| --- | --- |
| 3 | 排序 |

### 题目

#### 题目描述

给定 `n` 个整数和一个正整数 `K` ，按从小到大的顺序输出其中最小的 `K` 个数。

#### 输入格式

第一行两个正整数 `n` 和 `K` 。

第二行 `n` 个整数。

#### 输出格式

一行 `K` 个整数，为最小的 `K` 个数，按从小到大排列，相邻两数之间用一个空格分隔。

#### 样例输入

```text
5 3
5 2 8 1 9
```

#### 样例输出

```text
1 2 5
```

#### 数据范围

`n \le 10^6` ，对整个数组使用 `qsort` 会超时

### 答案

### 题目分析

- <https://visualgo.net/zh/sorting> 可以前往这个网站观看各类排序的过程。

在进行从大到小的冒泡排序的第 1 轮，会把最小的数放在位置 $n$，第 2 轮，会把第二小的数放在位置 $n - 1$，因此进行 $K$ 轮冒泡排序即可得到前 $K$ 小的数。具体见示例代码-1。

也可使用选择排序的思路，进行从小到大的选择排序，第 1 轮，会把最小的数放在位置 1，第 2 轮，会把第二小的数放在位置 2，进行 $K$ 轮，同样可以得到前 $K$ 小的数。

还可以使用插入排序的思路，维护一个最大大小为 $K + 1$ 的升序数组 $[a_0, a_1, \cdots, a_K]$，每次读入一个数直接替换掉其中最大的数，然后再将其插入到前面正确的位置。

本题使用 `qsort` 函数进行排序会超时，因为无需排序整个数组。但是也可以使用快速排序的思想实现本题（但有些大材小用），具体见示例代码-2。

### 示例代码 1 冒泡排序

```c
#include <stdio.h>
#define N 1000005
int a[N];
int main() {
    int n, K;
    scanf("%d%d", &n, &K);
    for(int i = 1; i <= n; i ++)
        scanf("%d", &a[i]);
    for(int i = 1; i <= K; i ++)
        for(int j = 1; j <= n - i; j ++)
            if(a[j] < a[j + 1]) {
                int t = a[j];
                a[j] = a[j + 1];
                a[j + 1] = t;
            }
    for(int i = 0; i < K; i ++)
        printf("%d ", a[n - i]);
    return 0;
}
```

### 示例代码 2 插入排序

```c
#include <stdio.h>
int main()
{
    int n, K;
    int a[6], num = 0; // num记录当前有效数据的个数
    scanf("%d%d", &n, &K);
    for(int i = 0; i < n; i++)
    {
        scanf("%d", &a[num]);
        for(int j = num - 1; j >= 0; j--)
            if(a[j] > a[j + 1])
            {
                int temp = a[j];
                a[j] = a[j + 1];
                a[j + 1] = temp;
            }
        if(num < K) num++;
    }
    for(int i = 0; i < K; i++)
        printf("%d ", a[i]);
    return 0;
}
```

### 示例代码 3 快速排序

```c
#include <stdio.h>
int a[1000005], n, k;
//仅供参考，快速排序选择轴值的时候没有随机选择，因此在某些极端数据的情况下可能会退化造成超时
void f(int l, int r)
{
    int x = l, y = r;
    while(l < r)
    {
        while(l < r && a[r] >= a[l]) r--;
        int t = a[l];
        a[l] = a[r];
        a[r] = t;
        while(l < r && a[l] < a[r]) l++;
        t = a[l];
        a[l] = a[r];
        a[r] = t;
    }
    if(l > x) f(x, l - 1);
    if(l < k) f(l + 1, y);
}
int main()
{
    scanf("%d%d", &n, &k);
    for(int i = 1; i <= n; ++i)
        scanf("%d", &a[i]);
    f(1, n);
    for(int i = 1; i <= k; ++i)
        printf("%d ", a[i]);
    return 0;
}
```
