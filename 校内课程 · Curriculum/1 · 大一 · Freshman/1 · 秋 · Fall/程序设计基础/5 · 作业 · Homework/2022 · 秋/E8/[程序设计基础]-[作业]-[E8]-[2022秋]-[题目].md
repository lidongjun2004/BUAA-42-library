# 程序设计基础 E8 题目（2022秋）

## A 怎么想都进不去吧

### 题目

#### 题目描述

门禁记录由若干行组成，每行形如 `[i:j]` 。两个数之差的绝对值加 1 就是需要尝试的次数：若这个次数不超过 32 ，输出它；否则输出 `Too Big!` 。

#### 输入格式

若干行，每行形如 `[i:j]` ，其中 $i, j$ 为整数，读到文件结束为止。

#### 输出格式

共若干行，每行为尝试次数或 `Too Big!` 。

#### 样例输入

```text
[1:5]
[10:2]
```

#### 样例输出

```text
5
9
```

## B 别忘了说再见

### 题目

#### 题目描述

给定 $n$ 句告别词与 $m$ 个名字。若某个名字没有出现在任何一句告别词中，说明这个人忘了说再见，请把他输出。

若所有名字都出现在告别词中，则输出 `Enjoy the scenery and we'll meet again.` 。

#### 输入格式

第一行两个正整数 $n, m$ 。

接下来 $n$ 行，每行一句告别词（可能含空格）。

接下来 $m$ 行，每行一个不含空格的字符串，表示一个名字。

#### 输出格式

按上述规则输出：若存在没出现过的名字，输出这些名字（用空格分隔）；否则输出 `Enjoy the scenery and we'll meet again.` 。

#### 样例输入

```text
2 2
goodbye alice
see you bob
alice
carol
```

#### 样例输出

```text
carol
```

## C 多项式求导

### 题目

#### 题目描述

给定一个多项式的 $n$ 项，每项由系数与指数两个整数给出。请对多项式求导，并按原顺序输出求导后系数不为 0 的项（每项输出新的系数与新的指数）。

求导公式： $(a x^k)' = ak x^{k-1}$ 。

#### 输入格式

第一行一个正整数 $n$ 。

接下来 $n$ 行，每行两个整数，依次为该项的系数与指数。

#### 输出格式

一行，按顺序输出求导后系数不为 0 的项，每项为两个整数（系数与指数），用空格分隔。

#### 样例输入

```text
3
3 2
5 1
7 0
```

#### 样例输出

```text
6 1 5 0
```

## D Rex的隐身

### 题目

#### 题目描述

给定一个只含大小写英文字母的字符串。请在字符串中按顺序找出 `R` 、 `e` 、 `x` 三个字母（忽略大小写），每找出一组就把这三个字母删除；重复这个过程直到找不出为止。

最后输出删除后剩下的字符串。

#### 输入格式

一行，一个只含大小写英文字母的字符串。

#### 输出格式

一行，为删除后剩下的字符串。

#### 样例输入

```text
aReXbRex
```

#### 样例输出

```text
ab
```

## E 魔法币-Magic

### 题目

#### 题目描述

有两台魔法机器，从 0 个魔法币开始：

- 机器 1 会让魔法币数量变成 $2n + 1$ ；
- 机器 2 会让魔法币数量变成 $2n + 2$ 。

给定最终需要的魔法币数量 $n$ ，请求出一组使用机器的顺序（按使用顺序输出机器编号）。

#### 输入格式

一行一个正整数 $n$ 。

#### 输出格式

一行，为使用机器的顺序（机器编号依次相连，中间没有分隔符）。

#### 样例输入

```text
5
```

#### 样例输出

```text
21
```

## F 分解，分解，还是分解

### 题目

#### 题目描述

给定正整数 $n$ 与 $k$ ，请把 $n$ 写成 $k$ 进制下各数位展开的形式：

$$n = x_0 k^0 + x_1 k^1 + \cdots$$

输出时按指数从大到小排列，跳过系数为 0 的项，每项形如 `系数*k^指数` ，项之间用 `+` 连接。

#### 输入格式

一行两个正整数 $n, k$ 。

#### 输出格式

一行，形如 `n=项+项+...` 。

#### 样例输入

```text
10 2
```

#### 样例输出

```text
10=1*2^3+1*2^1
```

## G 魔法实验 3.0

### 题目

#### 题目描述

有 $n$ 个水晶排成一列，其中 $f$ 个已经附魔为「火」、 $w$ 个已经附魔为「水」（位置互不相同），其余水晶为空。

现在要给所有空水晶附魔，要求最终相邻的两个水晶元素不同（水火间隔）。请求出最少需要重新附魔的水晶数量。

#### 输入格式

第一行三个正整数 $n, f, w$ 。

第二行 $f$ 个整数，为已附魔为火的水晶位置。

第三行 $w$ 个整数，为已附魔为水的水晶位置。

#### 输出格式

一行一个整数，为最少需要重新附魔的水晶数量。

#### 样例输入

```text
4 1 1
1
3
```

#### 样例输出

```text
1
```

## H 哪吒的区间合并（2）

### 题目

#### 题目描述

给定若干个区间，每个区间形如 `[l,r]` 、 `(l,r]` 、 `[l,r)` 或 `(l,r)` ，其中 `[` 、 `]` 表示闭端点， `(` 、 `)` 表示开端点。

请把所有相交的区间合并（两个区间在端点处相接时，只有至少一方在该端点是闭的才算相交），并按左端点从小到大输出合并后的区间。

#### 输入格式

若干行，每行一个区间，读到文件结束为止。

#### 输出格式

每行一个合并后的区间，格式与输入相同，按左端点从小到大排列。

#### 样例输入

```text
[1,3]
(2,6]
[8,10)
```

#### 样例输出

```text
[1,6]
[8,10)
```

## I 猜牌游戏

### 题目

#### 题目描述

牌堆中有 $n$ 张牌，每张牌由两个字符表示：第一个字符是点数（ `2` 到 `9` 、 `T` 、 `J` 、 `Q` 、 `K` 、 `A` ），第二个字符是花色。目标牌是其中的一张。

空只知道目标牌的花色，荧只知道目标牌的点数。两人轮流推理（空先手）：每轮中，若自己知道的那一类（花色或点数）在剩余的牌中只剩一张，则立刻猜出答案；否则把所有只剩一张牌的花色（或点数）整体排除。

请求出猜出答案时一共经过了多少次发言；若某一轮两人都无法排除任何牌（永远猜不出），输出 0。

#### 输入格式

第一行一个正整数 $n$ 。

接下来 $n$ 行，每行一张牌（两个字符）。

接下来一行一个字符串，为目标牌。

#### 输出格式

一行一个整数，为发言次数；无法猜出时输出 0。

#### 样例输入

```text
4
2W
3W
4X
5X
3W
```

#### 样例输出

```text
2
```

## J 工科元素分析-草

### 题目

#### 题目描述

模拟元素反应。给定角色的攻击力 $atk$ 、暴击率 $cr$ 、暴击伤害 $cd$ 与元素精通 $em$ ，以及 $N$ 次攻击每次附着的元素：

| 编号 | 元素 |
| --- | --- |
| 0 | 无 |
| 1 | 草 |
| 2 | 水 |
| 3 | 雷 |
| 4 | 火 |
| 5 | 激 |

伤害公式（其中 $base = 1446.853458$ ）：

- 普通伤害 $D = atk \times (1 + cr \times cd)$ ；
- 绽放爆炸伤害 $B(em, t) = t \times base \times \left(1 + \dfrac{16em}{2000 + em}\right)$ ；
- 激化强化伤害 $I(em, t) = D\left(atk + t \times base \times \left(1 + \dfrac{5em}{1200 + em}\right)\right)$ ，草激化取 $t = 1.15$ ，雷激化取 $t = 1.25$ 。

敌人身上最多附着一种元素（激元素记为 5），场上最多同时存在 5 个草原核。反应规则：

1. 本次攻击不附着元素时，只结算一次普通伤害；
2. 若场上存在草原核且本次附着雷或火，则发生超绽放（雷）或烈绽放（火）：伤害增加「核数 × $B(em, 3)$」，对应计数增加核数，草原核清零；
3. 若敌人当前没有附着元素，则附着本次元素，只结算一次普通伤害；
4. 若敌人附着激元素且本次为草或雷，则发生草激化或雷激化：伤害增加 $I(em, 1.15)$ 或 $I(em, 1.25)$ ，对应计数加 1；
5. 其余情况先结算一次普通伤害，再按下列顺序处理：激元素遇水生成草原核、激元素遇其他元素则清除；相同元素无反应；草与水相遇生成草原核并清除附着；草与雷相遇生成激元素；其他组合清除附着。生成草原核时若场上已有 5 个，则立即爆炸并增加 $B(em, 2)$ 点伤害，否则核数加 1；
6. 所有攻击结束后，剩余的草原核全部爆炸，伤害增加「核数 × $B(em, 2)$」。

请求出总伤害（保留 1 位小数），以及雷激化次数、草激化次数、草原核生成次数、超绽放次数、烈绽放次数。

#### 输入格式

第一行一个正整数 $N$ 与四个实数 $atk, cr, cd, em$ 。

接下来 $N$ 行，每行一个整数，为本次攻击附着的元素编号。

#### 输出格式

一行六个数：总伤害（保留 1 位小数）与五个次数，均用空格分隔。

#### 样例输入

```text
3 1000 0.5 1.0 100
1
2
0
```

#### 样例输出

```text
9598.4 0 0 1 0 0
```
