# 程序设计基础 E5 题目（2022秋）

## A 蓝的无幂之夜

### 题目

#### 题目描述

给定若干组整数 $a, b$ ，对每组数据求 $|a^b - b^a|$ 。

本题禁止在提交的代码中出现 `math.h` 、 `pow` 、 `abs` 这三个字符串，因此不能调用 `math.h` 中的 `pow` 与 `fabs` 、 `stdlib.h` 中的 `abs` ，需要自己实现乘方与取绝对值。

#### 输入格式

多组数据输入，每组数据为一行两个整数 $a, b$ ，读到文件结束为止。

#### 输出格式

对每组数据输出一行一个整数，为 $|a^b - b^a|$ 。

#### 样例输入

```text
2 5
5 2
```

#### 样例输出

```text
7
7
```

## B 计算闪耀值

### 题目

#### 题目描述

闪耀值由两个量决定：

$$ans_1 = \left\lfloor \frac{a! \bmod c}{b} \right\rfloor, \qquad ans_2 = \left\lfloor \frac{b! \bmod c}{a} \right\rfloor$$

先输出 $ans_1$ 与 $ans_2$ ；若两者之差的绝对值大于 9 ，再输出一行 `Mabushi~` 。

注意阶乘增长极快，计算 $n! \bmod c$ 时必须每乘一步就取一次模。

#### 输入格式

一行三个正整数 $a, b, c$ 。

#### 输出格式

第一行两个整数 $ans_1, ans_2$ ，用空格分隔；若两者之差的绝对值大于 9 ，再输出一行 `Mabushi~` 。

#### 样例输入

```text
10 2 1000
```

#### 样例输出

```text
400 0
Mabushi~
```

## C Josephus函数

### 题目

#### 题目描述

定义 Josephus 函数 $J$ ：给定常数 $k$ 与两个长度为 $k$ 的数组 $a_0, \cdots, a_{k-1}$ 与 $b_0, \cdots, b_{k-1}$ ，

$$J(N) = \begin{cases} a_N, & N < k \\ k \times J\left(\left\lfloor N/k \right\rfloor\right) + b_{N \bmod k}, & N \ge k \end{cases}$$

给定 $t$ 次询问，每次给出一个 $N$ ，请求出 $J(N)$ 。

#### 输入格式

第一行两个正整数 $k, t$ 。

第二行 $k$ 个整数 $a_0, \cdots, a_{k-1}$ 。

第三行 $k$ 个整数 $b_0, \cdots, b_{k-1}$ 。

接下来 $t$ 行，每行一个非负整数 $N$ 。

#### 输出格式

共 $t$ 行，每行一个整数，为 $J(N)$ 。

#### 样例输入

```text
2 2
0 1
1 0
5
3
```

#### 样例输出

```text
6
2
```

## E 毕业，但是忘记了总学分

### 题目

#### 题目描述

毕业要求总学分为 $s$ 、平均绩点为 $m$ 。成绩与绩点的换算关系为

$$gpa(x) = \begin{cases} 0, & x < 60 \\ 4 - \dfrac{3(100-x)^2}{1600}, & x \ge 60 \end{cases}$$

已经修完 $n - 1$ 门课，第 $i$ 门的学分为 $w_i$ 、成绩为 $x_i$ 。最后一门课的学分 $i$ 可以取从 $s - \sum w_i$ 开始、每次增加 0.5 直到 6.0 的任意值。

对每个可行的学分 $i$ ，求出这门课需要考多少分（由绩点反解得到）才能让总平均绩点达到 $m$ ，并输出学分与所需成绩。若反解出的成绩不在 $(0, 100)$ 内，则不输出。

#### 输入格式

第一行一个正整数 $n$ 与两个实数 $m, s$ 。

接下来 $n - 1$ 行，每行两个实数 $w_i, x_i$ 。

#### 输出格式

每行两个实数，依次为学分与所需成绩，学分保留 1 位小数，成绩保留 3 位小数。

#### 样例输入

```text
2 3.0 10
8 90
```

#### 样例输出

```text
2.0 52.390
2.5 56.182
3.0 58.904
3.5 60.964
4.0 62.583
4.5 63.893
5.0 64.976
5.5 65.888
6.0 66.667
```

## G 哪吒的水题（二）

### 题目

#### 题目描述

Simon 家与哪吒家分别位于 $(x_1, y_1)$ 与 $(x_2, y_2)$ ，两家的横坐标满足 $x_1 < x_2$ 。现在要在 $x$ 轴上（横坐标为 $x$ ， $x_1 \le x \le x_2$ ）修建一个供水站。

铺设管道到 Simon 家的单位长度费用为 $s_1$ ，到哪吒家的单位长度费用为 $s_2$ ，总费用为

$$s(x) = s_1\sqrt{(x-x_1)^2 + y_1^2} + s_2\sqrt{(x-x_2)^2 + y_2^2}$$

求使总费用最小的供水站横坐标 $x$ ，以及此时的最小总费用。

#### 输入格式

一行 6 个实数 $x_1, y_1, x_2, y_2, s_1, s_2$ 。

#### 输出格式

一行两个实数，分别为最优横坐标 $x$ 与最小总费用 $s(x)$ ，均保留 3 位小数，用空格分隔。

#### 样例输入

```text
0 1 4 2 1 2
```

#### 样例输出

```text
2.926 7.632
```

## H 前往苍盐海

### 题目

#### 题目描述

前往苍盐海需要走 $n$ 公里，计划用 $m$ 到 $l$ 天（含两端）中的某一天数到达。

对每一个天数 $d$ （ $m \le d \le l$ ），请输出所有合法的赶路方案：把 $n$ 公里分配到 $d$ 天，每天的公里数是非负整数，且不能在第 $d$ 天之前就走完全程（即前 $d - 1$ 天都不能把剩余公里数走完）。

最后输出方案总数。

#### 输入格式

一行三个正整数 $n, m, l$ 。

#### 输出格式

先按天数从小到大、每天公里数从小到大的顺序输出每一个方案，每个方案占一行，为 $d$ 个非负整数，用空格分隔；最后一行输出方案总数。

#### 样例输入

```text
3 2 2
```

#### 样例输出

```text
0 3
1 2
2 1
3
```

## I 反约瑟夫

#### 题目描述

约瑟夫问题中， $n$ 个人围成一圈，从第 1 个人开始报数，报到 $m$ 的人出列，再从下一个人重新报数。

本题是它的逆问题：已知出列的顺序依次是 $1, 2, \cdots, n$ ，请求出初始时这 $n$ 个位置上的编号。

#### 输出格式

```text
5 3
```

#### 样例输出

```text
2 4 1 5 3
```

## J 二百由旬之一闪

### 题目

#### 题目描述

有 $n$ 棵树，第 $i$ 棵树需要锋利度至少为 $a_i$ 才能被砍倒。剑的初始锋利度为 $S$ ，砍树时：

- 若当前锋利度不小于 $a_i$ ，可以直接砍倒这棵树，锋利度不变；
- 否则需要消耗 1 点锋利度才能砍倒它，砍倒后锋利度减 1。

你可以选择砍或不砍每一棵树（按顺序考虑）。请求出一个砍树方案，使得被砍倒的树最多。

#### 输入格式

第一行一个正整数 $T$ ，表示数据组数。

每组数据占两行：第一行两个正整数 $n, S$ ，第二行 $n$ 个正整数 $a_1, \cdots, a_n$ 。

#### 输出格式

共 $T$ 行，每行一个长度为 $n$ 的 01 串，第 $i$ 位为 1 表示砍第 $i$ 棵树，为 0 表示不砍。

#### 样例输入

```text
1
5 2
5 1 2 2 2
```

#### 样例输出

```text
01111
```

## K 岩王爷没有摩拉

### 题目

#### 题目描述

岩王爷手上有 $n$ 个数，第 $i$ 个数为 $a_i$ （ $1 \le a_i \le 1500$ ）。

请求出所有无序数对的 $|x + y - 1000|$ 之和，其中 $x, y$ 都取自这 $n$ 个数（允许 $x$ 与 $y$ 是同一个数）。

#### 输入格式

第一行一个正整数 $n$ 。

第二行 $n$ 个正整数 $a_1, \cdots, a_n$ 。

#### 输出格式

一行一个整数，为所求的和。

#### 样例输入

```text
2
100 200
```

#### 样例输出

```text
2100
```

#### 数据范围

- $1 \le a_i \le 1500$
- 答案可能超出 `int` 范围，需要用 `long long`
