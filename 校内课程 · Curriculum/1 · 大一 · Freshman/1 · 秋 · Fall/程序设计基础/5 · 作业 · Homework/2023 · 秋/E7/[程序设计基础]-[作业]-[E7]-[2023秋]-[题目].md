# 程序设计基础 E7 题目（2023秋）

## A 解锁战利品

### 题目

#### 题目描述

给定若干个字符串，判断每个字符串是否为回文串。

若一个字符串正着读和反着读完全相同，则它是回文串。对于不是回文串的字符串，统计它对称位置上字符不同的对数。

#### 输入格式

多组数据输入，每组数据为一个不含空格的字符串，读到文件结束为止。

#### 输出格式

对每个字符串输出一行：若是回文串，输出 `yes` ；否则输出 `no` 与对称位置字符不同的对数，用一个空格分隔。

#### 样例输入

```text
aba
abc
```

#### 样例输出

```text
yes
no 1
```

## B 小亮学矩阵乘法

### 题目

#### 题目描述

给定一个 $m$ 行 $n$ 列的矩阵 $A$ 与一个 $n$ 行 $k$ 列的矩阵 $B$ ，求它们的乘积 $C = A \times B$ ，其中

$$c_{ij} = \sum_{l=1}^{n} a_{il} b_{lj}, \quad i = 1, \cdots, m, \quad j = 1, \cdots, k$$

#### 输入格式

第一行三个正整数 $m, n, k$ 。

接下来 $m$ 行，每行 $n$ 个整数，为矩阵 $A$ 。

接下来 $n$ 行，每行 $k$ 个整数，为矩阵 $B$ 。

#### 输出格式

共 $m$ 行，每行 $k$ 个整数，为矩阵 $C$ ，同一行的整数之间用一个空格分隔。

#### 样例输入

```text
2 2 2
1 2
3 4
5 6
7 8
```

#### 样例输出

```text
19 22
43 50
```

#### 数据范围

- 计算结果可能超出 `int` 范围，需要用 `long long`

## C 画画字符画画

### 题目

#### 题目描述

给定一幅字符画（若干行，每行可能含有空格以及 `\` 、 `'` 、 `"` 等特殊字符），请生成一段 C 语言代码：这段代码用 `puts` 逐行输出这幅字符画。

生成的代码框架如下：

```c
#include<stdio.h>
int main()
{
    puts("第 1 行");
    puts("第 2 行");
    ...
    return 0;
}
```

其中每一行原样放入字符串字面量中，但字符 `\` 、 `'` 、 `"` 前面需要各加一个反斜杠转义。

#### 输入格式

若干行字符，读到文件结束为止。

#### 输出格式

按上述格式生成的 C 语言代码。

#### 样例输入

```text
He said "hi"
back\slash
```

#### 样例输出

```text
#include<stdio.h>
int main()
{
    puts("He said \"hi\"");
    puts("back\\slash");
    return 0;
}
```

## D 自定义格式化

### 题目

#### 题目描述

给定一个字符串 `str` 与一个格式串 `format`（例如 `%s` 、 `%5s` ），先用 `sscanf` 按照 `format` 从 `str` 中读出一个字符串 $s$ ，再按照宽度 $k$ 、精度 $x$ 的格式输出 $s$ ，即等价于 `printf("%k.xs", s)` 。

#### 输入格式

第一行为字符串 `str` 。

第二行为格式串 `format` 。

第三行两个整数 $k, x$ 。

#### 输出格式

一行，按宽度 $k$ 、精度 $x$ 格式化后的字符串（不足宽度时在左侧补空格，超过精度时截断）。

#### 样例输入

```text
hello world
%s
10 3
```

#### 样例输出

```text
       hel
```

## E 摩卡与数独

#### 题目描述

- 初始局面中非 0 的位置必须与填完后的数字相同；

## F 川川爱爬山

```text

6

```

```text
4 3
-1

```

## G 破壁计划

### 题目

#### 题目描述

面壁计划的加密方式是：先把原字符串 $p$ 中所有 `eto` 替换成 `et0` ，再把替换后的串按位置奇偶拆开——偶数位（下标 $0, 2, 4, \cdots$ ）的字符组成串 $s_1$ ，奇数位（下标 $1, 3, 5, \cdots$ ）的字符组成串 $s_2$ ；把 $s_2$ 逆序、并把其中每个小写字母换成它的镜像字母（ `a` 与 `z` 互换， `b` 与 `y` 互换，依此类推）得到 $s_2'$ ；最终把 $s_1$ 与 $s_2'$ 拼接起来作为加密结果 $e$ 。

由于 $e$ 中 $s_1$ 与 $s_2'$ 携带的信息本质相同，解密时只使用前半部分 $s_1$ ，并按下述步骤还原原字符串（设 $e$ 的长度为 $L$ ，位置从 0 开始计数）：

1. 把 $e$ 中所有 `et0` 替换成 `eto` ，记为 $s$ ；
2. 令 $t$ 为把 $s$ 逆序后、再把每个小写字母换成镜像字母得到的字符串；
3. 对每个位置 $j$ ： $j$ 为偶数时取 $s$ 的第 $j/2$ 个字符， $j$ 为奇数时取 $t$ 的第 $(j-1)/2$ 个字符。

给定加密后的字符串，请输出解密得到的原字符串。

#### 输入格式

一行，一个加密后的字符串。

#### 输出格式

一行，解密得到的原字符串。

#### 样例输入

```text
hloov
```

#### 样例输出

```text
hello
```

## H 编撰幻想乡缘起

### 题目

#### 题目描述

维护一个初始字符串，然后依次处理若干条操作（下标均从 0 开始计数）：

| 操作 | 含义 |
| --- | --- |
| `1 s` | 把字符串 $s$ 拼接在末尾 |
| `2 i` | 截断字符串，只保留下标 $0$ 到 $i-1$ 的部分 |
| `3 i s` | 把字符串 $s$ 插入到下标 $i$ 之后 |
| `4 i j` | 删除下标 $i$ 到 $j$ 之间的部分（闭区间） |
| `5 i j s` | 把下标 $i$ 到 $j$ 之间的部分替换为字符串 $s$ |
| `6 s` | 在当前字符串中查找 $s$ 第一次出现与最后一次出现的下标 |

操作 `6` 若找不到 $s$ ，输出一行 `NULL` ；否则输出一行两个整数，分别为第一次与最后一次出现的下标。

每次操作之后输出当前字符串，全部操作结束后再输出一次最终字符串。

#### 输入格式

第一行为初始字符串（不含空格）。

接下来若干行，每行一条操作，读到文件结束为止。

#### 输出格式

按上述规则输出。

#### 样例输入

```text
abcdef
1 ghi
3 2 XYZ
4 0 1
6 cd
```

#### 样例输出

```text
abcdefghi
abcXYZdefghi
cXYZdefghi
NULL
cXYZdefghi
cXYZdefghi
```

## J 有理数2023

### 题目

#### 题目描述

实现一个有理数计算器。计算器中有一组用单个大写字母命名的变量，每个变量存放一个有理数（以约分后的分数形式保存）。

按行读入命令并执行：

| 命令 | 含义 |
| --- | --- |
| `INPUT v x` | 把变量 $v$ 赋值为 $x$ |
| `ADD v w` | $v \leftarrow v + w$ |
| `SUB v w` | $v \leftarrow v - w$ |
| `MUL v w` | $v \leftarrow v \times w$ |
| `DIV v w` | $v \leftarrow v \div w$ ，若 $w$ 为 0 则不执行 |
| `EQU v w` | 判断 $v$ 与 $w$ 是否相等 |
| `OUTPUT v` | 以分数形式输出 $v$ |
| `OUTPUT n v` | 以小数形式输出 $v$ ，保留 $n$ 位小数 |

其中 `INPUT` 的 $x$ 可以写成整数（如 `-3` ）、有限小数（如 `0.325` ）、循环小数（如 `0.14(43)` ，括号内为循环节）或分数（如 `1/3` ）。

除法时若除数为 0 ，输出一行 `LINE c DIV BY ZERO!` ，其中 $c$ 是该命令的行号（从 1 开始计数）。判等时输出一行 `v == w` 或 `v != w` 。以分数形式输出时，若值为 0 输出 `0` ，若分母为 1 输出整数，否则输出 `分子/分母` 。以小数形式输出时四舍五入到 $n$ 位小数。

若某一行命令无法识别，输出 `Error in input!` 加上该行内容。

#### 输入格式

若干行命令，读到文件结束为止。

#### 输出格式

按上述规则输出。

#### 样例输入

```text
INPUT A 0.5
INPUT B 1/3
ADD A B
OUTPUT A
OUTPUT 4 A
EQU A B
DIV A B
OUTPUT A
```

#### 样例输出

```text
5/6
0.8333
A != B
5/2
```
