# 程序设计基础 E1 题目（2023秋）

## A 带鱼除法

### 题目

#### 题目描述

有 $x$ 个带鱼，每天吃掉 $y$ 个。求这些带鱼能吃多少天，以及最后还剩多少个。

#### 输入格式

一行，两个整数 $x$ 和 $y$。

#### 输出格式

两行：第一行一个整数，表示能吃的天数；第二行一个整数，表示剩下的个数。

#### 样例输入

```text
17 5
```

#### 样例输出

```text
3
2
```

## C 摩卡与小学期

### 题目

#### 题目描述

Moca 团队在小学期里完成了若干需求。第 $i$ 个需求的贡献值为 $a_i$，老师发布的需求总数为 $need$。

若贡献值之和不大于 $0$，说明一个需求也没有完成，输出 $0$ 和 `Moca finish 0 requirement!`；若贡献值之和大于等于 $need$，说明全部需求都完成了，输出 $need$ 和 `Moca finish all requirements!`；否则输出贡献值之和。

#### 输入格式

第一行一个整数 $n$，表示贡献值的个数。

第二行 $n$ 个整数，依次表示 $a_1,a_2,\dots,a_n$。

第三行一个整数 $need$。

#### 输出格式

第一行一个整数，表示完成的需求数；若一个需求也没完成或全部完成，再输出第二行对应的提示语。

#### 样例输入

```text
3
1 2 3
10
```

#### 样例输出

```text
6
```

#### 样例输入2

```text
2
-1 -2
5
```

#### 样例输出2

```text
0
Moca finish 0 requirement!
```

#### 样例输入3

```text
2
5 5
8
```

#### 样例输出3

```text
8
Moca finish all requirements!
```

## D czx 的出游计划

### 题目

#### 题目描述

czx 计划出游三处景点。第 $i$ 处景点带来的兴奋值增量为 $a_i$，愉悦系数为 $b_i$。游览顺序由 $op$ 决定： $op=1$ 时顺序为 $1,2,3$； $op=2$ 时顺序为 $2,3,1$； $op=3$ 时顺序为 $3,2,1$。

初始兴奋值 $x$ 和愉悦值 $res$ 都为 $0$。每到一处景点 $i$，先令 $x$ 增加 $a_i$，再令 $res$ 增加 $x\times b_i$。求最终的愉悦值。

#### 输入格式

一行，七个整数，依次为 $a_1,b_1,a_2,b_2,a_3,b_3,op$。

#### 输出格式

一行，一个整数，表示最终的愉悦值。

#### 样例输入

```text
1 2 3 4 5 6 1
```

#### 样例输出

```text
72
```

## E 阶乘对对碰

### 题目

#### 题目描述

给定两个小于 $10$ 的非负整数 $a$ 和 $b$，求 $a$ 的阶乘 $a!$ 与 $b$ 的双阶乘 $b!!$，并比较两者的大小。双阶乘的定义为： $b$ 为奇数时 $b!!=b\times(b-2)\times\cdots\times 1$， $b$ 为偶数时 $b!!=b\times(b-2)\times\cdots\times 2$。特别地， $0!=0!!=1$。

#### 输入格式

一行，两个整数 $a$ 和 $b$。

#### 输出格式

第一行两个整数，用空格分隔，依次为 $a!$ 和 $b!!$。

第二行输出比较结果：`a!>b!!`、`a!<b!!` 或 `a!=b!!`。

#### 样例输入

```text
3 4
```

#### 样例输出

```text
6 8
a!<b!!
```

```text
60 70 80 50 -1
```

#### 样例输出

```text
2 66 75
```

## G czx 与优购超市

### 题目

#### 题目描述

超市里有 $a$ 个苹果和 $b$ 个香蕉，苹果单价 $3$ 元，香蕉单价 $2$ 元。czx 带了 $x$ 元，手上苹果和香蕉的数量初始都是 $0$。接下来有 $n$ 次操作，每次给出两个整数 $u$ 和 $v$： $u=0$ 表示购买， $u\ne 0$ 表示吃掉； $v=0$ 表示苹果， $v\ne 0$ 表示香蕉。

购买成功需要钱够且超市还有剩余，成功后扣除钱和超市库存、czx 手上对应水果加 $1$；吃掉成功需要 czx 手上有对应水果，成功后数量减 $1$。每次操作成功输出 `Ok!`，失败输出 `Failed!`。最后输出超市剩余的苹果数、香蕉数和 czx 剩余的钱。

#### 输入格式

第一行四个整数 $n,x,a,b$。

接下来 $n$ 行，每行两个整数 $u$ 和 $v$。

#### 输出格式

前 $n$ 行，每行 `Ok!` 或 `Failed!`。

最后一行三个整数，用空格分隔，依次为剩余苹果数、剩余香蕉数和剩余的钱。

#### 样例输入

```text
3 10 1 1
0 0
0 1
1 0
```

#### 样例输出

```text
Ok!
Ok!
Ok!
0 0 5
```

## J 基于快速数论变换的加密算法

### 题目

#### 题目描述

加密算法对四个小于 $5$ 的自然数 $a,b,c,d$ 做如下变换（所有运算对 $5$ 取模）：

$$
e=(a+c)\bmod 5,\quad f=(b+d)\bmod 5,\quad g=(a+4c)\bmod 5,\quad h=(b+4d)\bmod 5
$$

$$
i=(e+f)\bmod 5,\quad j=(e+4f)\bmod 5,\quad k=(g+2h)\bmod 5,\quad l=(g+3h)\bmod 5
$$

现在给出密文 $i,j,k,l$，求明文 $a,b,c,d$。

#### 输入格式

一行，四个整数，依次为 $i,j,k,l$。

#### 输出格式

一行，四个整数，用空格分隔，依次为 $a,b,c,d$。

#### 样例输入

```text
0 3 4 2
```

#### 样例输出

```text
1 2 3 4
```
