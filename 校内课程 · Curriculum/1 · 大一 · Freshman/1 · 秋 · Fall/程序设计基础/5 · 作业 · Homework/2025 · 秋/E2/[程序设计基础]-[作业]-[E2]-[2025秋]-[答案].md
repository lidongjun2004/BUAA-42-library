## B 小忆的元音统计

| 难度 | 考点 |
| --- | --- |

### 题目

#### 题目描述

读入一段文本，统计其中元音字母（ `a` 、 `e` 、 `i` 、 `o` 、 `u` 以及它们的大写形式）的个数。

#### 输入格式

若干字符，读到文件结束（EOF）为止，其中可能包含空格和换行。

#### 输出格式

一行一个整数，表示元音字母的个数。

#### 样例输入

```text
Hello World
```

#### 样例输出

```text
3
```

### 答案

### 题目分析

我们不停从输入读取字符，直到读取到末尾。

然后使用判断语句判断字符是否是元音，如果是元音就把计数器增加。

最后，等输入结束后，输出这个计数器即可。

### 示例代码 1

```c
#include <stdio.h>

int main(){
    int cnt=0;
    char ch;
    while(~scanf("%c",&ch)){
        if(ch=='a'||ch=='e'||ch=='i'||ch=='o'||ch=='u') cnt++;
        if(ch=='A'||ch=='E'||ch=='I'||ch=='O'||ch=='U') cnt++;
    }
    printf("%d\n",cnt);
    return 0;
}
```

### 示例代码 2

```c
#include <stdio.h>

int main()
{
    int cnt = 0;
    char ch;
    while (scanf("%c", &ch) != EOF)

            cnt++;
        if (ch == 'A' || ch == 'E' || ch == 'I' || ch == 'O' || ch == 'U')
            cnt++;
    }
    printf("%d\n", cnt); // 文末回车不影响评测结果，去掉也通过
    return 0;

```

## C 点灯

| 难度 | 考点 |
| --- | --- |
| 1 | 数组 |

### 题目

#### 题目描述

$n$ 盏灯围成一个环，编号 1 到 $n$ ，初始都是熄灭的（记为 0）。接下来有 $m$ 次操作，每次给出一个编号 $k$ ，把 $k$ 号灯以及与它相邻的两盏灯的状态全部取反（亮变灭、灭变亮），其中 1 号灯与 $n$ 号灯相邻。求所有操作结束后每盏灯的状态。

#### 输入格式

第一行两个整数 $n$ 和 $m$ 。接下来 $m$ 行，每行一个整数 $k$ 。

#### 输出格式

一行 $n$ 个整数，依次是 1 到 $n$ 号灯的最终状态，1 表示亮、0 表示灭，相邻两数之间用一个空格分隔。

#### 样例输入

```text
5 2
1
3
```

#### 样例输出

```text
1 0 1 1 1
```

### 答案

### 题目分析

对于本题目，我们可以使用一个数组，用于储存灯的状态。然后每次输入，改变数组值。

特别的，因为按照题干灯布置成环状，所以其实 $1$ 号灯和 $n$ 号灯是相邻的。

所以我们应当在执行变灯操作时，应该对 $n$ 和 $1$ 进行特判，可以使用两个 `if` 进行该操作。

$PS$：这个题完美体现了全局变量在初始化方面的绝对优势，定义在 `int main` 前数组内值自动为 $0$。请大家在后续编写代码时将主要数组定义为全局变量。

### 示例代码

```c
#include<stdio.h>
int a[1010];
int main ( )
{
    int n,m;
    scanf("%d%d",&n,&m);
    for(int i=0;i<m;i++)
    {
        int k;
        scanf("%d",&k);
        a[k]=(a[k]+1)%2;
        if(k==1)
        {
            a[2]=(a[2]+1)%2;
            a[n]=(a[n]+1)%2;
        }
        else if(k==n)
        {
            a[n-1]=(a[n-1]+1)%2;
            a[1]=(a[1]+1)%2;
        }
        else
        {
            a[k+1]=(a[k+1]+1)%2;
            a[k-1]=(a[k-1]+1)%2;
        }
    }
    for(int i=1;i<=n;i++)
    printf("%d ",a[i]);
}
```

## D remove R in English!

| 难度 | 考点 |
| --- | --- |
| 2 | 数组，循环 |

### 题目

#### 题目描述

读入一段文本，把其中紧跟在元音字母 `a` 、 `e` 、 `i` 、 `o` 、 `u` 后面的字母 `r` 删掉，其余字符原样输出。

#### 输入格式

若干字符，读到文件结束（EOF）为止，其中可能包含空格和换行。

#### 输出格式

删除之后的文本。第一个字符前面没有字符，直接输出。

#### 样例输入

```text
car and bar
```

#### 样例输出

```text
ca and ba
```

### 答案

### 题目分析

依次读入单词中的字母并存入数组中，遍历每一个字符：

- 如果不是 `r`，则正常输出；
- 如果是 `r`，则比对前一个字符是否为元音字母（`a`、`i`、`u`、`e`、`o`）。若不是元音字母，照常输出字母 `r`，否则不输出 `r`。

<!-- markdownlint-disable-next-line MD036 -->
**详见示例代码1**

#### 进一步分析

字母 r 是否删除只与前一个字符有关，与更早读入的字符无关，所以实际上**不需要数组**将所有字符存起来，而只需要将前一个字符和当前字符存起来就可以实现功能。不用数组可以让程序占用更少的内存，在空间复杂度上是更优的。

<!-- markdownlint-disable-next-line MD036 -->
**详见示例代码2**

### 示例代码1

```c
#include <stdio.h>

char str[100010];
int main()
{
    int c, n = 0;
    while ((c = getchar()) != EOF)
    {
        str[n++] = c;
    }
    printf("%c", str[0]); // 第一个字符前面没有字符，直接输出
    for (int i = 1; i < n; i++)
    {
        if (str[i] != 'r')
            printf("%c", str[i]);
        else if (str[i - 1] != 'a' && str[i - 1] != 'e' && str[i - 1] != 'i'
                && str[i - 1] != 'o' && str[i - 1] != 'u')
        {
            printf("%c", str[i]);
        }
    }
    return 0;
}
```

### 示例代码2

```c
#include <stdio.h>

int main()
{
    int pre = 0, cur, n = 0; //cur记录当前字符 pre记录前一个字符
    while ((cur = getchar()) != EOF)
    {
        if (pre == 0)
            printf("%c", cur);
        else if (cur != 'r')
            printf("%c", cur);
        else if (pre != 'a' && pre != 'e' && pre != 'i'
                && pre != 'o' && pre != 'u')
```

## E 快速dropout

| 难度 | 考点 |
| --- | --- |
| 2 | 一维数组 |

### 题目

#### 题目描述

一层神经网络有 $n$ 个神经元，第 $i$ 个的值是 $a_i$ 。现在要 dropout 掉其中 $k$ 个神经元（题目会给出它们的位置），被 dropout 的神经元输出 0，其余照常输出。

#### 输入格式

第一行两个整数 $n$ 和 $k$ 。第二行 $n$ 个整数，表示各神经元的值。接下来 $k$ 行，每行一个整数，表示被 dropout 的神经元位置。

#### 输出格式

一行 $n$ 个整数，被 dropout 的位置输出 0，其余位置输出原值，相邻两数之间用一个空格分隔。

#### 样例输入

```text
5 2
1 2 3 4 5
2
4
```

#### 样例输出

```text
1 0 3 0 5
```

### 答案

### 题目分析

需要使用数组记录下来原始的值，也需要数组记录下来哪些神经元被 $dropout$ 了

### 示例代码

```c
#include <stdio.h>

int a[105];
int dropout[105];
int main() {
    int n, k;

    // 读取
    scanf("%d %d", &n, &k);

    for (int i = 1; i <= n; i++) {
        scanf("%d", &a[i]);
    }

    for (int i = 0; i < k; i++) {
        int pos;
        scanf("%d", &pos);
        dropout[pos] = 1;      // 标记被dropout的神经元
    }

    for (int i = 1; i <= n; i++) {
        if (dropout[i] == 1) {
            printf("0 ");
        } else {
            printf("%d ", a[i]);
        }
    }

    return 0;
}
```

## F 客运地铁

| 难度 | 考点 |
| --- | --- |
| 4 -> 2 | 前缀和 |

### 题目

#### 题目描述

地铁线路有 $n$ 座车站，第 $i$ 站到第 $i+1$ 站的行驶里程是 $d_i + 190$ 。给出 $q$ 次询问，每次给出起点站 $s$ 和终点站 $t$ ，求从 $s$ 站开到 $t$ 站的总行驶里程。

#### 输入格式

第一行一个整数 $n$ 。接下来 $n - 1$ 个整数，依次是 $d_1$ 到 $d_{n-1}$ 。接下来一行一个整数 $q$ 。接下来 $q$ 行，每行两个整数 $s$ 和 $t$ 。

#### 输出格式

每次询问输出一行一个整数，表示总行驶里程。

#### 样例输入

```text
3
10 20
2
1 3
2 3
```

#### 样例输出

```text
410
210
```

#### 数据范围

$n, q$ 可达 $10^{5}$ ，里程之和需要用 `long long` 存储。每次询问都用循环累加会超时，应先预处理出每座车站到第 1 站的行驶距离，之后每次询问只做一次减法。

### 答案

### 题目分析

根据题意，我们不难写出一个暴力方法，每次询问 $s$ 到 $t$，就从 $s$ 循环到 $t$，累加中间的行驶里程。

```c
#include <stdio.h>
int d[100010];

int main() {
    int n, q, s, t;
    scanf("%d", &n);
    for ( int i = 1; i < n; i++ )
        scanf("%d", d + i);
    long long sum = 0;
    for ( scanf("%d", &q); q--; sum = 0 ) {
        scanf("%d%d", &s, &t);
        for ( int i = s; i < t; i++ )
            sum += d[i] + 190;
        printf("%lld\n", sum);
    }
    return 0;
}
```

于是我们就得到了 $0.6TLE$ 的结果。

根据初版 $Hint$，我们可以计算第 $1$ 座车站到第 $s, t$ 座车站之间的行驶距离 $L_s, L_t$，询问结果即是 $L_t - L_s$。但这里是需要每次都使用循环计算吗？如果使用循环计算，那么每次询问都要循环 $s + t - 2$ 次，与现在的 $t - s$ 次相比，反而效率更低。

我们不妨思考一下，这个真的有必要每次循环计算吗？ $L_i, i \in \{2, 3, \cdots, n\}$ 总共只有 $n - 1$ 项，那么我们是不是可以考虑预先计算出这 $n - 1$ 个数？这样对于每次询问，我们只需要做一次减法即可，于是就避免了 $TLE$ 的问题。

那么怎么计算 $L_i$ 呢？如果每次从 $1$ 循环，那还是会超时。由于我们已经计算出来了 $L_{i-1}$，那么我们只需要在上一站的基础上，加上从上一站开过来的行驶里程即可。即有递推公式 $L_i = L_{i-1} + d_{i-1} + 190, i \in \{2, 3, \cdots, n\}$。

利用此方法可以 $AC$。

### 示例代码

```c
#include <stdio.h>
int d[100010];

long long L[100010]; // L[i] 表示第 1 站到第 i 站的行驶距离

int main() {
    int n, q, s, t;
    scanf("%d", &n);
    for ( int i = 1; i < n; i++ )
        scanf("%d", d + i);

    // 预计算出 L[i] 的值。L[1] 由于开在全局，自动初始化为 0 ，符合题意
    for ( int i = 2; i <= n; i++ )
        L[i] = L[i - 1] + d[i - 1] + 190;

    scanf("%d", &q)
    while ( q-- ) {
        scanf("%d%d", &s, &t);
        printf("%lld\n", L[t] - L[s]); // 每次询问直接做减法，避免重复循环
    }
    return 0;
}
```

### 注

这道题可能打破了大家对 TLE 也就是 `Time Limit Exceeded` 这一评测结果的认识。

在 C1 和 E1 系列赛中，助教告诉大家，`TLE` 意味着你的程序陷入了死循环。纠正了这一问题就可以在规定时间运行出正确结果。

但事实并非如此。计算机在一秒内能够进行的计算次数是有限的，大概在 $10^7 \sim 10^8$ 这个数量级。这意味着当数据规模达到 $10^5$ 级别时，朴素的双层循环就无法在时限内输出结果了。因此我们需要在逻辑上对程序的运行效率进行优化。

我们通常用时间复杂度这一概念衡量程序所需的计算次数，篇幅所限此处不会展开叙述，但希望同学们有最基本的估计能力，并养成拿到题目时先关注数据范围的习惯。

程序设计在大多数时间里正是一门压缩程序运行时间的艺术。日后同学们可能还要学习各种各样的算法、数据结构。这一切往往都是为了帮助大家删去代码中暴力冗余的双层循环部分，而用效率更高的线性对数结构，或是更优雅的线性解法代替它。

了解了这些之后，恭喜你！程序设计的大门朝你打开了。

## G 一元二次方程求解2025秋

| 难度 | 考点 |
| --- | --- |
| 3 | 浮点数的操作 |

### 题目

#### 题目描述

解一元二次方程 $ax^2 + bx + c = 0$ ，按下面的规则输出。若 $a \ne 0$ ，先算 $\delta = b^2 - 4ac$ ：若 $|\delta|$ 足够小（不超过 $10^{-9}$ ）则有两个相同的根，输出 `The same two roots: x` ；若 $\delta > 0$ 则有两个相异的实根，从大到小输出两个根，用空格分隔；否则输出 `No Root` 。若 $a = 0$ 且 $b \ne 0$ ，方程只有一个实根，输出 `Just one root: x` 。若 $a$ 、 $b$ 、 $c$ 全为 0，方程有无穷多个根，输出 `Infroots` 。若 $a = 0$ 、 $b = 0$ 但 $c \ne 0$ ，方程无解，输出 `No Root` 。

#### 输入格式

一行三个实数 $a$ 、 $b$ 、 $c$ ，用空格分隔。

#### 输出格式

一行，按上述规则输出，其中所有实数都保留小数点后 2 位。

#### 样例输入

```text
1 -3 2
```

#### 样例输出

```text
2.00 1.00
```

#### 数据范围

判断 $\delta$ 是否为 0 必须写成 `fabs(delta) <= eps` 的形式并且放在分支的最前面，否则会因浮点误差出错，例如 `2 0.4 0.02` 这组数据在数学上只有一个解，但直接计算得到的 $\delta$ 并不精确等于 0。

### 答案

### 题目分析

体面意思很简单，就是让大家去解一个一元二次方程，注意条件的判断

代码思路：

1. 用 `"%lf"` 读入三个浮点数 `a`, `b`, `c`

2. 判断 `a` 是否为 `0`

    计算 `delta = b * b - 4 * a * c`

    1. 判断 `fabs(delta) <= eps` 两个相同的根
    2. 判断 `delta > 0` 两个相异的根，注意从大到小输出
    3. 否则没有实根

3. `a` 为 `0`，`b` 不为 `0`，一个实根

4. `a`, `b`, `c` 均为 `0` 无数个实根

5. 否则没有实根

学会使用 `if`，`else if`，`else` 的多级逻辑关系，帮助你理清思路，代码思路简介明了。

**易错点1**：`a==0 && b==0 && c!=0` 的时候，此时是无解而非无穷解。

**易错点2**：`a<0` 时，`x1` 与 `x2` 的大小关系会改变。

**易错点3**：需要使用 `fabs` 来判断 `delta` 与 `0` 的大小关系。其中，判断 `delta` 是否等于 `0` 一定要放在分支的最前面，且一定要写成 `fabs(delta) <= eps`。

值得注意的是，`a`, `b`, `c` 不需要使用 `fabs` 进行判断，因为只有经过浮点数计算得到的 `0` 才有精度问题，而从输入中获得的浮点数 `0` 是精确的。

**叉掉 200 人的神秘数据点：**

```text
2 0.4 0.02
```

虽然在数学上，此方程毫无疑问只有一个解，但使用浮点数计算之后会发现，此处的 `delta` 计算出来并不是精确的 `0`。此处产生了浮点数的精度问题，可以使用 `printf("%.20f", delta)` 查看程序认为此时 `delta` 的值是多少。

### 示例代码

```c
#include <stdio.h>
#include <math.h>
#define eps 1e-9

int main()
{
    double a, b, c, delta;

    scanf("%lf%lf%lf", &a, &b, &c);

    if(a != 0)
    {
        delta = b * b - 4 * a * c;
        if(fabs(delta) <= eps) printf("The same two roots: %.2lf\n", -b / (2 * a));
        else if(delta > 0)
        {
            double x1 = (-b + sqrt(delta)) / (2 * a);
            double x2 = (-b - sqrt(delta)) / (2 * a);
            if(x1 > x2) printf("%.2f %.2f\n", x1, x2);
            else printf("%.2f %.2f\n", x2, x1);
        }
        else printf("No Root\n");
    }
    // 隐含了 a == 0
    else if(b != 0) printf("Just one root: %.2f\n", -c / b);
    // 隐含了 a == 0 && b == 0
    else if(c == 0) printf("Infroots\n");
    // 隐含了 a == 0 && b == 0 && c != 0
    else printf("No Root\n");

    return 0;
}
```

## H 可以和我刷一辈子 TD 吗？

| 难度 | 考点 |
| --- | --- |
| 3 | 数组，前缀和 |

### 题目

#### 题目描述

给出一个只含 0 和 1 的序列 $a_1, \ldots, a_n$ 。接下来有 $m$ 次询问，每次给出一个数 $k$ ，求从右往左数第 $k$ 个 1 所在的位置；若序列中 1 的总数不足 $k$ 个，输出 `No Way!` 。题目保证各次询问的 $k$ 单调不减。

#### 输入格式

第一行一个整数 $n$ 。第二行 $n$ 个整数，表示序列。接下来一行一个整数 $m$ 。接下来 $m$ 行，每行一个整数 $k$ 。

#### 输出格式

每次询问输出一行：存在时输出从右往左数第 $k$ 个 1 的位置，否则输出 `No Way!` 。

#### 样例输入

```text
5
1 0 1 1 0
3
1
2
4
```

#### 样例输出

```text
4
3
No Way!
```

#### 数据范围

$n, m \le 2 \times 10^{5}$ 。每次询问都从末尾重新扫描会超时，可以利用 $k$ 单调不减的性质让指针只向左移动，或者预处理出后缀和。

### 答案

### 解题思路

我们可以把题意转化为每次寻找倒数第 $k_i$ 个 $1$ 的位置，如果不存在则输出 `No Way!`。

同学们很容易写出这样一段代码：

```c
#include <stdio.h>

int main() {
    int n, m, k;
    int a[200005];
    scanf("%d", &n);
    for (int i = 1; i <= n; i++) {
        scanf("%d", &a[i]);
    }
    scanf("%d", &m);
    while (m--) {
        scanf("%d", &k);
        int cnt = 0;
        for (int i = n; i >= 1; i--) {
            cnt = cnt + a[i];
            if (cnt == k) {
                printf("%d\n", i);
                break;
            }
        }
        if (cnt < k) {
            printf("No Way!\n");
        }
    }
    return 0;
}
```

但是交到OJ上会发现 `TLE` 了...这是因为这个程序的效率太低了！每次都从最后开始重新计数，并没有很好地利用到前面已经经历的计算结果。

我们发现题目中给定了 $k_i$ 单调不减的条件。这告诉我们，我们的答案也一定是逐渐减小的。因此我们每次只需在前一问的基础上向左移动即可。下面是改进之后的代码。

### 示例代码1

```c
#include <stdio.h>

int main() {
    int n, m, k, sum = 0;
    int a[200005];
    scanf("%d", &n);
    for (int i = 1; i <= n; i++) {
        scanf("%d", &a[i]);
        sum += a[i];
    }
    scanf("%d", &m);
    int cnt = 0, lst_i = n;
    while (m--) {
        scanf("%d", &k);
        if (k > sum) {
            printf("No Way!\n");
        } else if (k == cnt) {
            printf("%d\n", lst_i);
        } else {
            for (int i = lst_i - 1; i >= 1; i--) {
                cnt = cnt + a[i];
                if (cnt == k) {
                    printf("%d\n", i);
                    lst_i = i;
                    break;
                }
            }
        }
    }
    return 0;
}
```

当然，我们也可以运用刚在 `F` 题中学到的前缀和技巧。通过预处理，来降低循环层数。

此处我们预处理出后缀和数组 `suf`，用 `suf[i]` 表示 $a_i$ 和 $a_n$ 之间 $1$ 的个数。利用答案单调不增的特性，用单向左移的 `pos` 变量寻找答案。以下给出代码实现：

### 示例代码2

```c
#include <stdio.h>

int n, m;
int a[200005], suf[200005];

int main() {
    scanf("%d", &n);
    for (int i = 1; i <= n; i++) {
        scanf("%d", &a[i]);
    }
    suf[n] = a[n];
    for (int i = n - 1; i >= 1; i--) {
        suf[i] = suf[i + 1] + a[i];
    }
    scanf("%d", &m);
    int pos = n;
    while (m--) {
        int k; scanf("%d", &k);
        while (suf[pos] < k && pos >= 1) pos--;
        if (pos == 0) printf("No Way!\n");
        else printf("%d\n", pos);
    }
    return 0;
}
```

这两份用不同的方式达到了减少重复计算的目的。此外方法还有很多，比如先预处理出所有可能提问的答案，询问时直接查表等等，此处不做赘述。

### 题目

#### 题目描述

给定一个长度为 $n$ 的数组和 $q$ 次操作，每次操作由 `op` 、 `x` 、 `y` 三个数描述： `op = 1` 时令 $a_x = a_y$ ； `op = 2` 时交换 $a_x$ 和 $a_y$ ； `op = 3` 时令 $a_x = a_x + y$ ； `op = 4` 时令 $a_x = y$ ； `op = 5` 时输出 $a_x - a_y$ ； `op = 6` 时输出 $a_x$ 到 $a_y$ 的和。

#### 输入格式

第一行两个整数 $n$ 和 $q$ 。第二行 $n$ 个整数，表示数组的初始值。接下来 $q$ 行，每行三个整数 `op` 、 `x` 、 `y` 。

#### 输出格式

对于 `op = 5` 和 `op = 6` 的操作，各输出一行一个整数。

#### 样例输入

```text
5 4
1 2 3 4 5
5 1 2
6 1 3
3 1 10
6 1 3
```

#### 样例输出

```text
-1
6
16
```

### 答案

### 题目分析

根据题目要求模拟即可。

### 示例代码

```c
#include <stdio.h>

int a[1005];
int main(){
    int n,q;
    scanf("%d%d",&n,&q);
    for(int i=1;i<=n;i++) scanf("%d",&a[i]);
    while(q--){
        int op,x,y;
        scanf("%d%d%d",&op,&x,&y);
        if(op==1){
            a[x]=a[y];
        } else if(op==2) {
            int t=a[x];
            a[x]=a[y];
            a[y]=t;
        } else if(op==3) {
            a[x]=a[x]+y;
        } else if(op==4) {
            a[x]=y;
        } else if(op==5) {
            printf("%d\n",a[x]-a[y]);
        } else if(op==6) {
            int s=0;
            for(int i=x;i<=y;i++) s+=a[i];
            printf("%d\n",s);
        }
    }
    return 0;
}
```

## J DESTRUCTION 3,2,1

### 题目

#### 题目描述

求满足下列条件的长度为 $n$ 的数列个数：每一项都在 1、2、3 中取值；相邻两项不相同；任意连续三项既不严格递增也不严格递减，也就是说 1, 2, 3 和 3, 2, 1 这两种连续三项都不允许出现。答案对 998244353 取模。

#### 输入格式

一行一个整数 $n$ 。

#### 输出格式

一行一个整数，表示满足条件的数列个数对 998244353 取模的结果。

#### 样例输入

```text
3
```

#### 样例输出

```text
10
```

#### 数据范围

$n \le 2 \times 10^{5}$ 。记 $f[i]$ 为长度为 $i$ 时的答案，则 $f[3] = 10$ ， $f[4] = 16$ ，且对 $i \ge 5$ 有 $f[i] = f[i-2] + f[i-1]$ 。

### 答案

### 题解 1

本题性质很好，满足无后效性与最优子结构，因此可以动态规划。

可以证明的是，如果 $[a_1, \cdots, a_{i-1}, a_i]$ 是不卡手的序列，那么 $[a_1, \cdots, a_{i-1}]$ 也是不卡手的序列。因此，我们的基础思路是从长度为 $3$ 开始，不断计算长度为 $4, 5, 6, \cdots$，一直到 $n$ 的答案。

但是长度增加的过程中，我们必须知道对于长度为 $i - 1$ 的序列，它的 $a_{i-2}, a_{i-1}$ 两项到底是什么，我们才能知道 $a_i$ 有多少种填法。因此，我们需要在递推式中把这两项记录出来。

记 $f_{r,s}[i]$ 为一共有多少个长度为 $i$ 的序列满足它是不卡手的，且最后两项 $a_{i-1}, a_i$ 为 $r, s$。

现在我们枚举序列的最后两项 $r, s$，我们看它的下一项 $t$ 可以是几：

1. $(r, s) = 1, 2$，此时 $t \in \{1\}$。
2. $(r, s) = 1, 3$。此时 $t \in \{1, 2\}$。
3. $(r, s) = 2, 1$。此时 $t \in \{2, 3\}$。
4. $(r, s) = 2, 3$。此时 $t \in \{1, 2\}$。
5. $(r, s) = 3, 1$。此时 $t \in \{2, 3\}$。
6. $(r, s) = 3, 2$。此时 $t \in \{3\}$。

应用加法原理，我们如果已知了 $f_{r,s}[i - 1]$，我们就可以用递推式知道 $f_{s,t}[i]$。

答案即为 $f_{r,s}[n]$ 对所有 $r, s$ 求和模 $998244353$。

### 题解 2

如果记数列共 $i (i \ge 5)$ 项时的答案是 $f[i]$，使用惊人的注意力可以观察到 $f[i] = f[i-2] + f[i-1]$。此时题目样例已经给出了 $3, 4$ 时的答案，直接做首项为 $10, 16$ 的斐波那契数列即可。

更进一步集中注意力，注意到斐波那契数列中，第 $n + 2$ 项的 $2$ 倍即为答案。

### 示例代码 1

```c
#include <stdio.h>

#define ll long long
ll p=998244353;

int n;
ll f12[200005],f13[200005],f21[200005];
ll f23[200005],f31[200005],f32[200005];
int main() {
    scanf("%d",&n);
    f12[2]=f13[2]=f21[2]=f23[2]=f31[2]=f32[2]=1;
    for(int i=3;i<=n;i++){
        // (r,s) == (1,2)
        f21[i]+=f12[i-1];
        // (r,s) == (1,3)
        f31[i]+=f13[i-1];
        f32[i]+=f13[i-1];
        // (r,s) == (2,1)
        f12[i]+=f21[i-1];
        f13[i]+=f21[i-1];
        // (r,s) == (2,3)
        f31[i]+=f23[i-1];
        f32[i]+=f23[i-1];
        // (r,s) == (3,1)
        f12[i]+=f31[i-1];
        f13[i]+=f31[i-1];
        // (r,s) == (3,2)
        f23[i]+=f32[i-1];
        f12[i]%=p; f13[i]%=p; f21[i]%=p;
        f23[i]%=p; f31[i]%=p; f32[i]%=p;
    }
    ll ans=f12[n]+f13[n]+f21[n]+f23[n]+f31[n]+f32[n];
    ans%=p;
    printf("%lld",ans);
    return 0;
}
```
