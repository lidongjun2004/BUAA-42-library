## A 简单的函数调用

### 题目

#### 题目描述

题目给出下面两个函数：

```c
int f1(int x) { return -~x++; }
int f2(int x) { return ~-x++; }
```

对每个输入的整数 $x$ ，输出 $f_1(x)$ 和 $f_2(x)$ 。注意不能把两个函数调用写在同一个表达式里（那样是未定义行为），也不要把两个位运算表达式直接写在同一个 `printf` 中。

#### 输入格式

若干个整数，每行一个，读到文件结束（EOF）为止。

#### 输出格式

每个输入对应一行，两个整数 $f_1(x)$ 和 $f_2(x)$ ，用空格分隔。

#### 样例输入

```text
5
10
```

#### 样例输出

```text
6 4
11 9
```

## B 快速幂2025

### 题目

#### 题目描述

题目给出一个快速幂函数 `qpow(a, b, p)` ，它返回 $a^b \bmod p$ 。给定若干组 $a$ 、 $b$ 、 $p$ ，调用该函数并输出结果。

#### 输入格式

第一行一个整数 $t$ 。接下来 $t$ 行，每行三个数：整数 $a$ 、整数 $b$ 、整数 $p$ ，用空格分隔。

#### 输出格式

每组输出一行一个整数，表示 $a^b \bmod p$ 。

#### 样例输入

```text
2
2 10 1000
3 5 7
```

#### 样例输出

```text
24
5
```

#### 数据范围

$b$ 需要用 `long long` 存储。

## C 角子角子角角子 1

### 题目

#### 题目描述

给定三维空间中的三个点 $A$ 、 $B$ 、 $C$ ，求 $\angle ABC$ 的大小（用弧度表示）。先用两点间距离公式求出三边长 $AB$ 、 $BC$ 、 $AC$ ，再用余弦定理求出 $\angle ABC$ 的余弦值，最后用反余弦函数得到角度。

#### 输入格式

第一行一个整数 $n$ ，表示数据组数。接下来 $n$ 行，每行 9 个整数，依次是点 $A$ 、 $B$ 、 $C$ 的坐标 $x_A, y_A, z_A, x_B, y_B, z_B, x_C, y_C, z_C$ ，用空格分隔。

每组输出一行一个实数，表示 $\angle ABC$ 的弧度值，保留小数点后 5 位。

#### 样例输入

```text
1
0 0 0 1 0 0 0 1 0
```

#### 样例输出

```text
0.78540
```

## D 刨冰猜想（单询问）

### 题目

#### 题目描述

定义如下迭代过程：若当前数 $n$ 是合数，就把它除以它的最小质因数；若 $n$ 是质数，就令 $n = (n \mathbin{|} 2n) + 1$ 。不断重复，直到 $n$ 变成 2 的幂为止。请求出最终的 $n$ 以及迭代的次数。可以证明，从任何大于 1 的数出发最终都会进入 $16 - 8 - 4 - 2 - 7$ 这样的循环，因此一定会到达 2 的幂。

#### 输入格式

一行一个整数 $n$ 。

#### 输出格式

一行两个整数，用空格分隔：最终的 $n$ 和迭代次数。

#### 样例输入

```text
6
```

#### 样例输出

```text
8 2
```

#### 数据范围

$n \le 10^{7}$ 。迭代过程中出现的最大值不超过初始值的 4 倍，用 `int` 即可。判断一个数是否为 2 的幂可以用 `n & (n - 1) == 0` 。

## E 核金汉诺塔

### 题目

#### 题目描述

汉诺塔问题：有 $diskCount$ 个碟片叠在 $source$ 柱上，要求借助 $spare$ 柱把它们全部移到 $destination$ 柱，每次只能移动一个碟片，且任何时候都不能把大盘子放在小盘子上面。请按标准递归解法的顺序输出每一次移动。

#### 输入格式

一行四个整数 $diskCount$ 、 $source$ 、 $destination$ 、 $spare$ ，用空格分隔，分别是碟片数量、起始柱、目标柱和辅助柱的编号。

#### 输出格式

每行输出一次移动，格式为 `Electromagnet move disk d from x to y` ，其中 $d$ 是碟片编号， $x$ 和 $y$ 分别是移动前后的柱子编号。

#### 样例输入

```text
2 1 3 2
```

#### 样例输出

```text
Electromagnet move disk 1 from 1 to 2
Electromagnet move disk 2 from 1 to 3
Electromagnet move disk 1 from 2 to 3
```

## F 递归整数划分

### 题目

#### 题目描述

定义整数 $x$ 的递归划分表达式 $f(x)$ ：若 $x = 1$ 则 $f(x)$ 就是 `1` ；否则 $f(x)$ 为 `(` + $f(\lfloor x/2 \rfloor)$ + `+` + （当 $x$ 为奇数时额外插入 `1+` ）+ $f(\lfloor x/2 \rfloor)$ + `)` 。给定若干个 $n$ ，输出对应的表达式。

#### 输入格式

第一行一个整数 $t$ 。接下来 $t$ 行，每行一个整数 $n$ 。

#### 输出格式

#### 样例输入

```text
2
5
1
```

#### 样例输出

```text
((1+1)+1+(1+1))
1
```

## G 三角地划分 -RESURRECTION-

### 题目

#### 题目描述

题目给出一个带记忆化开关的递归函数 `f(n, tabs)` ，要求输出调用 `f(n, 0)` 的完整过程。函数的行为如下：

1. 每进入一次 `f(n, tabs)` ，先输出 $tabs$ 个 「竖线加三个空格」 ，再输出 `calculate begin f(n)` 并换行；
2. 若 `memory[n]` 非 0 且 `use_memory` 为 1，则再输出 $tabs$ 个 「竖线加三个空格」 和 `calculated before return f(n) = 值` 并换行，然后直接返回 `memory[n]` ；
3. 否则计算返回值 $fn$ ：当 $n = 3$ 时 $fn = 1$ ；否则对 $i$ 从 3 到 $n$ 求和，其中 $i = 3$ 或 $i = n$ 时加上 `f(n-1, tabs+1)` ，其余情况加上 `f(n-i+2, tabs+1)` 与 `f(i-1, tabs+1)` 的乘积。算完后把 $fn$ 存入 `memory[n]` ，再输出 $tabs$ 个 「竖线加三个空格」 和 `calculate end return f(n) = fn` 并换行，然后返回 $fn$ 。

所有递归调用都使用同一个全局计数器统计调用次数。

#### 输入格式

一行两个整数 `use_memory` 和 $n$ ，用空格分隔。

#### 输出格式

先按上述格式输出递归调用的完整过程，然后输出一行 `answer f(n) = 值` ，最后输出一行 `total function invoked count = 次数` 。

#### 样例输入

```text
0 4
```

#### 样例输出

```text
calculate begin f(4)
|   calculate begin f(3)
|   calculate end return f(3) = 1
|   calculate begin f(3)
|   calculate end return f(3) = 1
calculate end return f(4) = 2
answer f(4) = 2
total function invoked count = 3
```

## H 羊圈面积

### 题目

#### 题目描述

给定一个多边形的 $n$ 个顶点坐标，求它的面积。顶点按顺序给出。面积一定是 0.5 的整数倍，要求精确输出，不要使用浮点数计算：可以用向量叉积求出每个三角形面积的两倍并累加，最后根据累加值的奇偶决定小数部分是 `.0` 还是 `.5` 。

#### 输入格式

第一行一个整数 $n$ 。接下来 $n$ 个点的坐标，每个点的格式为 `(x,y)` ，相邻两个点之间用一个空格或换行分隔。

#### 输出格式

一行，即多边形的面积，形如 `整数部分.0` 或 `整数部分.5` 。

#### 样例输入

```text
4 (0,0) (4,0) (4,3) (0,3)
```

#### 样例输出

```text
12.0
```

#### 数据范围

坐标的绝对值与面积都可能很大：面积最大可达 $4 \times 10^{18}$ ，必须全程用 `long long` 计算，`double` 的有效位数不足以精确表示。

## I b50里有终点

### 题目

#### 题目描述

有 $n$ 个函数，第 $i$ 个函数由它的类型 `op[i]` 决定：

- `op = 1` ，读入 $a_i$ ，表示 $f_i(x) = x + a_i$ ；
- `op = 2` ，读入 $b_i$ ，表示 $f_i(x) = b_i \times x$ ；
- `op = 3` ，读入 $c_i, d_i$ ，表示 $f_i(x) = f_{c_i}(f_{d_i}(x))$ ；
- `op = 4` ，读入 $c_i, d_i$ ，表示 $f_i(x) = f_{c_i}(x) + f_{d_i}(x)$ 。

接下来有 $q$ 次询问，每次给出 $j$ 和 $x$ ，求 $f_j(x)$ 对 998244353 取模的结果。可以证明每个函数都是 $kx + m$ 的形式，因此可以记忆化地求出每个函数的 $k$ 和 $m$ 。

#### 输入格式

第一行一个整数 $n$ 。接下来 $n$ 行，每行描述一个函数：先是一个整数 `op` ，然后按上述规则给出对应的参数。接下来一行一个整数 $q$ 。接下来 $q$ 行，每行两个数：整数 $j$ 和整数 $x$ 。

#### 输出格式

每次询问输出一行一个整数，表示 $f_j(x) \bmod 998244353$ 。

#### 样例输入

```text
4
1 5
2 3
3 1 2
4 1 2
2
1 10
3 10
```

#### 样例输出

```text
15
35
```

## K 黑暗决斗

### 题目

#### 题目描述

有一场黑暗决斗，初始有 $n$ 个数构成的序列（原序列）。决斗中所有可能的伤害值恰好是原序列的全部子集和，一共有 $2^n$ 个（可以重复）。现在只给出这 $2^n$ 个伤害值，请还原出任意一个可能的原序列。

#### 输入格式

第一行一个整数 $n$ 。接下来一行 $2^n$ 个整数，表示所有子集和构成的可重集，顺序任意。

#### 输出格式

一行 $n$ 个整数，表示还原出的原序列，相邻两数之间用一个空格分隔。

#### 样例输入

```text
2
0 1 2 3
```

#### 样例输出

```text
1 2
```

#### 数据范围

$n \le 16$ 。原序列中可能有负数，此时最小的伤害值就是所有负数之和。
