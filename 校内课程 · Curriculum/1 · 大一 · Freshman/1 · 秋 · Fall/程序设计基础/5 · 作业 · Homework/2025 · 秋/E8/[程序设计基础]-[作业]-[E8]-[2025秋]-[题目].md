# 程序设计基础 E8 题目（2025秋）

## A 十六进制速算

### 题目

#### 题目描述

把十六进制数转换成二进制数输出。十六进制的每一位恰好对应二进制的四位，只需把每一位展开成对应的四位二进制即可。

#### 输入格式

第一行一个整数 $n$ ，表示数据组数。接下来 $n$ 行，每行一个以 `0x` 开头的十六进制数（实际数据中每行数字后面还跟有 3 个空格）。

#### 输出格式

每组输出一行，把每一位十六进制数字展开成四位二进制数字，每四位之间用一个空格分隔。

#### 样例输入

```text
1
0x0000000000000001
```

#### 样例输出

```text
0000 0000 0000 0000 0000 0000 0000 0000 0000 0000 0000 0000 0000 0000 0000 0001
```

## B Miyabi 的修行 1

### 题目

#### 题目描述

给定 $n$ 个字符串，把它们按字典序从小到大排序后输出。

#### 输入格式

第一行一个整数 $n$ 。接下来 $n$ 行，每行一个不含空白字符的字符串。

#### 输出格式

$n$ 行，按字典序从小到大输出这 $n$ 个字符串。

#### 样例输入

```text
3
banana
apple
cherry
```

#### 样例输出

```text
apple
banana
cherry
```

#### 数据范围

$n \le 10^{4}$ 。使用冒泡排序会超时，应使用 `qsort` ；给 `qsort` 传入比较字符串的 `cmp` 时，类型转换应写成 `(char *)a` 。

## C AI 的元音游戏

### 题目

#### 题目描述

你和「NAK 02」轮流从一个字符串中取走字符，取走最后一个字符的人获胜。若字符串中至少含有一个元音字母（ `a` 、 `e` 、 `i` 、 `o` 、 `u` ），你就能获胜；否则你开局就无法行动而落败。请判断每局你是否能获胜。

#### 输入格式

第一行一个整数 $n$ ，表示字符串个数。接下来 $n$ 行，每行一个不含空白字符的字符串。

#### 输出格式

每个字符串输出一行：能获胜输出 `Turing Complete!` ，否则输出 `Ex Machina` 。

#### 样例输入

```text
2
hello
xyz
```

#### 样例输出

```text
Turing Complete!
Ex Machina
```

#### 数据范围

本题的内存限制很小，无法把整个字符串一次读入，这提示取胜条件只与字符串的局部性质有关。

## D 快子通讯

### 题目

#### 题目描述

把一个 57 位的数据编码成 64 位的扩展汉明码。64 个二进制位中，第 0 位是总校验位，第 1、2、4、8、16、32 位是校验位，其余 57 个位置按从低到高的顺序填入数据位。第 $2^i$ 位（ $i$ 从 0 到 5 ）的校验值，等于所有下标 $j$ （ $1 \le j \le 63$ ）中第 $i$ 位为 1 的那些位上数据的按位异或；第 0 位的总校验值等于全部 64 位的按位异或。

#### 输入格式

第一行一个整数 $n$ ，表示数据组数。接下来 $n$ 行，每行一个 64 位无符号整数，表示待编码的数据。

#### 输出格式

每组输出一行一个 64 位无符号整数，表示编码结果。

#### 样例输入

```text
2
0
1
```

#### 样例输出

```text
0
15
```

#### 数据范围

数据按 64 位无符号整数读入，可用 `unsigned long long` 存储；用 `(n >> i) & 1` 可以取出 $n$ 的第 $i$ 位。

## E Contrasty Angeles [Sprinkle Lv.9]

### 题目

#### 题目描述

定义函数 $S(x)$ ：从 2 枚举到 $\sqrt{x}$ ，找出 $x$ 的所有因数中最大的那个 $p$ 。若不存在这样的 $p$ （即 $x$ 是质数或 $x = 1$ ），直接输出 $x$ ；否则先输出 $S(p)$ ，再输出 `*` ，最后输出 $S(x/p)$ 。给定若干个 $x$ ，输出对应的结果。

#### 输入格式

第一行一个整数 $t$ ，表示数据组数。接下来 $t$ 行，每行一个整数 $x$ 。

#### 输出格式

#### 样例输入

```text
3
12
7
1
```

#### 样例输出

```text
3*2*2
7
1
```

#### 数据范围

不需要单独开字符数组保存结果，直接在递归过程中输出即可。

## F 错误的乘法算式

### 题目

#### 题目描述

有人写了一个错误的乘法算式 `A * B = C` ，其中每个数字都被替换成了一个「代号」。已知 0 到 9 这十个数字与十个代号之间存在一个一一对应的映射关系，请求出一组映射，使得这个算式成立，并输出填好之后的算式。

#### 输入格式

一行，格式为 `A * B = C` ，其中 `A` 、 `B` 、 `C` 都是由数字组成的字符串，分别表示被乘数、乘数和积。

#### 输出格式

一行，格式为 `a * b = c` ，即把代号替换回真实数字后成立的算式。

#### 样例输入

```text
0 * 1 = 0
```

#### 样例输出

```text
0 * 1 = 0
```

#### 数据范围

计算过程会超出 `int` 范围，需要用 `long long` 。枚举全部 $10!$ 种映射即可。

## G 何意味

### 题目

#### 题目描述

题目给出下面两个函数，其中 `n` 和 `d` 是全局变量：

```c
long long f(long long a) {
    if (a == 0) return d;
    long long b = a--;
    long long c = f(a);
    return b * (d ^ n) + c + (b - a) * d * d - (f(a) << 1);
}

long long g(long long *a) {
    if ((*a) == 0) return d;
    long long b = (*a)--;
    long long c = g(a);
    return b * (d ^ n) + c + (b - (*a)) * d * d - (g(a) << 1);
}
```

对每组输入的 $n$ 和 $d$ ，先读入全局变量 `n` 和 `d` ，然后分别输出 `f(n)` 和 `g(&n)` 的值。注意 `g` 通过指针修改了全局变量 `n` ，因此两个函数的实际行为并不相同。

#### 输入格式

若干行，每行两个整数 $n$ 和 $d$ ，读到文件结束（EOF）为止。

#### 输出格式

每组输出一行两个整数，用空格分隔，依次是 `f(n)` 和 `g(&n)` 的返回值。

#### 样例输入

```text
4 2
```

#### 样例输出

```text
14 46
```

#### 数据范围

结果可能很大，需要用 `long long` 。计算 `g(&n)` 时应先算出 $\frac{n(n+1)}{2}$ 再乘以 $d(d+1)$ ，否则中间结果会溢出。

## H 扫描障碍

### 题目

#### 题目描述

给定一条长度为 $L$ 的线段和 $n$ 个区间 $[l_i, r_i]$ ，请求出用最少的区间（每次选中的区间必须与已覆盖的部分相接）覆盖 $[0, L]$ 所需的区间数。如果无法完全覆盖，输出无法被覆盖的长度。

#### 输入格式

第一行两个整数 $L$ 和 $n$ 。接下来 $n$ 行，每行两个整数 $l_i$ 和 $r_i$ ，表示一个区间。

#### 输出格式

若能完全覆盖 $[0, L]$ ，先输出一行 `YE5` ，再输出最少需要的区间数；否则先输出一行 `N0` ，再输出无法被覆盖的长度。

#### 样例输入

```text
10 2
0 5
4 10
```

#### 样例输出

```text
YE5
2
```

#### 数据范围

$n$ 可达 $3 \times 10^{5}$ ，冒泡排序会超时，应使用 `qsort` 按左端点升序排序。当 $n = 0$ 时输出 `N0` 和 $L$ 。

## I FFT

### 题目

#### 题目描述

给定两个用二进制表示的大整数（位数可达 $2 \times 10^{5}$ ），求它们的乘积，并以二进制输出。

#### 输入格式

两行，每行一个只含字符 `0` 和 `1` 的字符串，分别表示两个乘数。

#### 输出格式

一行，即乘积的二进制表示（不含前导零）。

#### 样例输入

```text
101
11
```

#### 样例输出

```text
1111
```

#### 数据范围

两个数的位数之和可达 $4 \times 10^{5}$ ，直接按竖式做双重循环会超时。可以把相邻的 $B$ 位压成一个整数当作 $2^B$ 进制一起运算，取 $B = 25$ 时最大的中间结果不会超过 `unsigned long long` 的范围。

## J Construction 1,2,3

### 题目

#### 题目描述

称一个只含字符 `1` 、 `2` 、 `3` 的字符串是「好谱」，当且仅当它任意相邻两个字符都不相同。现在给定一个字符串，你可以选择其中一个连续区间并把区间内的字符任意重排（也可以不操作）。若字符串本身已经是好谱，输出 `OHHHH` ；若无论如何都无法变成好谱，输出 `NOOOO` ；否则输出你选择的最短区间的左右端点，以及重排之后的字符串。

#### 输入格式

第一行一个整数 $t$ ，表示数据组数。每组数据第一行一个整数 $n$ ，第二行一个长度为 $n$ 的只含 `1` 、 `2` 、 `3` 的字符串。

#### 输出格式

每组输出：本身已是好谱输出一行 `OHHHH` ；无解输出一行 `NOOOO` ；否则先输出一行两个整数，表示所选区间的左右端点，再输出一行重排后的字符串。

#### 样例输入

```text
3
4
1231
3
112
2
11
```

#### 样例输出

```text
OHHHH
2 3
121
NOOOO
```

#### 数据范围

$n$ 可达 $10^{6}$ 。一个长度为 $n$ 的字符串能重排成相邻字符两两不同的充要条件是：出现次数最多的字符的出现次数不超过 $\lceil n/2 \rceil$ 。可以用二分或双指针求出最短的合法区间。
