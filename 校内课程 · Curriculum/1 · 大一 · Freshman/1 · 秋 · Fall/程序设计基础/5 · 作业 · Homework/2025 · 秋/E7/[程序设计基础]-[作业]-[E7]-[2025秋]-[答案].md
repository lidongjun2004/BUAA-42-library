## A 小小的我

| 难度 | 考点 |
| --- | --- |
| 1 | 字符串 |

### 题目

#### 题目描述

给定若干组数据，每组给出一个整数 $k$ 和一个字符串 $s$ ，输出 $s$ 的末 $k$ 个字符。 $s$ 中可能含有空格。

#### 输入格式

第一行一个整数 $T$ ，表示数据组数。接下来 $T$ 行，每行先是一个整数 $k$ ，然后是一个字符串 $s$ ，两者之间用一个空格分隔。

#### 输出格式

每组输出一行，即 $s$ 的末 $k$ 个字符。

#### 样例输入

```text
2
3 abc
2 hello world
```

#### 样例输出

```text
abc
ld
```

#### 数据范围

字符串长度不超过 1000。字符数组要开得比 1000 大一些，以容纳结尾的 `\0` 。不保证最后一组数据末尾有换行符。

### 答案

### 题目分析

> 本题原对标 C6B 难度。

本题较为简单，使用 `strlen` 获取字符串长度后按要求输出即可。

需要注意的是若尝试使用 `scanf("%d ", &k)` 滤去空格可能会导致 $s$ 开头的空格同样被滤去，这是因为 `scanf` 中格式字符串的空白字符会吸收所有连续的空白字符，导致 $s$ 的长度小于预期，解决方案有：

1. 使用 `getchar()` 吸收恰好一个空格；
2. 不吸收空格，视为 $s$ 的一部分（由于只涉及末 $k$ 个字符所以不影响输出结果）。

同时应当将字符数组开大一些，避免存不下第 1001 位的 `\0` 导致输出时的错误。

输出时可以逐字符输出，也可以直接传入对应位置的指针。

此外，不保证最后一组数据末尾有换行符，请不要基于此对字符串进行操作。

### 代码示例

```c
#include<stdio.h>
#include<string.h>
int main() {
    int T, k;
    char s[1008];
    scanf("%d", &T);
    while(T--) {
        scanf("%d", &k);
        gets(s);
        printf("%s\n", s + strlen(s) - k);
    }
}
```

## B Lazy 排序

| 难度 | 考点 |
| --- | --- |
| 1 | 数组作为函数参数，参数的按指针传递 |

### 题目

#### 题目描述

Lazyfish 写了一个名为臭皮匠排序（stooge sort）的排序函数，并用一个返回 `int` 的比较函数 `compare(a, b)` 来判断两个数的大小：

```c
int compare(long long a, long long b) {
    return a - b;
}
```

请按他给出的实现对输入的数组排序并输出结果。注意这个比较函数在两个数相差很大时会因为返回值溢出 `int` 而给出错误的比较结果，这正是本题要模拟的行为。

#### 输入格式

第一行一个整数 $n$ 。接下来 $n$ 行，每行一个整数，表示数组的各个元素。

#### 输出格式

一行 $n$ 个整数，表示排序后的数组，相邻两数之间用一个空格分隔。

#### 样例输入

```text
5
5
3
1
4
2
```

#### 样例输出

```text
1 2 3 4 5
```

#### 数据范围

元素需要用 `long long` 存储。当两个元素的差超出 `int` 范围时，`compare` 的返回值会溢出，排序结果就会与真正的升序不同。

### 答案

### 题目分析

本题的 `stoogeSort` 函数实现了一种名为臭皮匠排序的低效排序算法。其时间复杂度为 $O(n^{\frac{\log 3}{\log 3 - \log 2}})$，大约为 $O(n^{2.71})$，非常非常慢。

数组作为函数参数

如果将一维数组作为函数参数，函数头需要这样写：

```c
void stoogeSort(long long array[], int arraySize);
```

或者这样写：

```c
void stoogeSort(long long* array, int arraySize);
```

两种写法完全等价。

实际上，数组作为函数参数时，会被隐式转换为指向数组首个元素的指针，这也是我们需要一个额外的参数传递数组的大小的原因。

即使是把数组大小写在函数参数里面，编译器也会忽略它：

```c
void stoogeSort(long long array[42], int arraySize);    // 42 被忽略，仍然和前面两种写法等价
```

在函数参数内传递多维数组会涉及数组指针，多重指针等较复杂的知识点。因此，不建议在函数参数里面传递多维数组，请尽可能使用全局数组代替。

```c
void testFunction1(int array[][]);                      // 编译错误！
void testFunction2(int array[42][]);                    // 编译错误！
void testFunction3(int array[][42]);                    // 数组指针，这里的 42 不会被忽略，是有意义的
void testFunction4(int (*array)[42]);                   // 数组指针，等价于前一种写法
void testFunction5(int** array);                        // 二重指针，需要传递数组的长宽两个参数
```

按指针传递

一个错误的 `swap` 函数示例如下：

```c
void swap(long long a, long long b) {
    long long temp = a;
    a = b;
    b = temp;
}
```

由于 `a` 和 `b` 仅仅是对真正传入的值的拷贝，这个函数无法真正调换原来的两个变量的值。

如果使用指针传递参数：

```c
void swap(long long* a, long long* b) {
    long long temp = *a;
    *a = *b;
    *b = temp;
}
```

指针 `a` 和 `b` 获得了真正要被调换的两个变量的地址，因此可以真正修改它们。

### 示例代码

```c
#include <stdio.h>

void swap(long long* a, long long* b) {
    long long temp = *a;
    *a = *b;
    *b = temp;
}

int compare(long long a, long long b) {
    return a - b;
}

void stoogeSort(long long array[], int arraySize) {
    if (compare(array[0], array[arraySize - 1]) > 0) {
        swap(&array[0], &array[arraySize - 1]);
    }
    if (arraySize >= 3) {
        int third = arraySize / 3;
        stoogeSort(array, arraySize - third);
        stoogeSort(array + third, arraySize - third);
        stoogeSort(array, arraySize - third);
    }
}

int main() {
    int n = 0;
    scanf("%d", &n);
    long long array[1010];
    for (int i = 0; i < n; i++) {
        scanf("%lld", &array[i]);
    }
    stoogeSort(array, n);
    for (int i = 0; i < n; i++) {
        printf("%lld ", array[i]);
    }
    return 0;
}
```

### 附注

对于这组测试数据

```text
10
-2305843009213693951 -379076 -228917 4611686018427387903 -613617 -4611686018427387903 584409 740912 2305843009213693951 -652794
```

标答的输出结果是

```text
-652794 -613617 -379076 -228917 4611686018427387903 2305843009213693951 -4611686018427387903 -2305843009213693951 584409 740912
```

而正确的排序结果是

```text
-4611686018427387903 -2305843009213693951 -652794 -613617 -379076 -228917 584409 740912 2305843009213693951 4611686018427387903
```

可见，Lazyfish 的排序方法的确有问题！

具体来说，问题出在哪里呢？

考察这部分代码：

```c
int compare(long long a, long long b) {
    return a - b;
}

void stoogeSort(long long array[], int arraySize) {
    if (compare(array[0], array[arraySize - 1]) > 0) {
        swap(&array[0], &array[arraySize - 1]);
    }
    // Others...
}
```

`stoogeSort` 的比较逻辑依赖于比较函数 `compare`，而 `compare` 计算两个 `long long` 变量的差作为结果 —— 却返回一个 `int`！

于是，`compare` 函数的返回值发生了溢出，这就造成了排序错误。

如果把 `compare` 函数修改成

```c
int compare(long long a, long long b) {
    return a > b ? 1 : 
           a < b ? -1 :
           0 ;
}
```

比较就正确了。

之后同学们会学会使用 `stdlib.h` 中的 `qsort` 函数，此函数需要接收一个返回 `int` 的函数作为自定义比较逻辑，就有一部分同学容易出现 Lazyfish 的错误。

要牢记正确的写法！

| 2 | 指针、内存访问 |

### 题目

#### 题目描述

「周星星」执行秘密任务时要经过若干块地砖，每块地砖的编号是一个 `int` 类型的整数。每个 `int` 在内存中由 4 个字节组成，其中值为 114 的字节代表「香蕉皮」。请求出所有整数的所有字节中，值为 114 的字节总共有多少个。可以把整数的地址强制转换为 `unsigned char *` 来逐字节访问它的存储。

#### 输入格式

第一行一个整数 $n$ 。接下来 $n$ 行，每行一个 `int` 范围内的整数。

#### 输出格式

一行一个整数，表示值为 114 的字节个数。

#### 样例输入

```text
3
114
29184
1
```

#### 样例输出

```text
2
```

#### 数据范围

不同平台的大小端顺序可能不同，但统计结果不受影响。

### 答案

### 题目分析

「周星星」在执行秘密任务时需要经过若干块地砖，每块地砖的编号是一个 `int` 类型整数。

每个整数在内存中由 4 个字节组成，而值为 114 的字节代表「香蕉皮」。

现在要求统计所有整数的所有字节中，字节值等于 114 的数量。

本题的关键在于理解：一个 `int` 占 4 个字节，我们可以通过指针直接访问其底层存储结构。

将整数 `x` 的地址强制转换为 `unsigned char *` 类型：

```c
unsigned char *p = (unsigned char *)&x;
```

这样 `p[0]` 至 `p[3]` 就依次对应了整数的四个字节。

遍历这些字节并统计值为 114 的数量即可。

这种写法自然展示了 C 语言中指针直接访问内存的特性。

不同平台的字节顺序（大小端）可能不同，但统计的结果不会受到影响。

### 示例代码

```c
#include <stdio.h>

int main() {
    int n;
    scanf("%d", &n);
    int x, count = 0;
    for (int i = 0; i < n; i++) {
        scanf("%d", &x);
        unsigned char *p = (unsigned char *)&x;
        for (int j = 0; j < 4; j++) {
            if (p[j] == 114) count++;
        }
    }
    printf("%d\n", count);
    return 0;
}
```

## D 这个数很长很长很长

| 难度 | 考点 |

| 3 | 进制转换，取模 |

### 题目

#### 题目描述

给定若干个 $m$ 进制的整数（位数最多可达 $10^5$ ，无法用常规整数类型存储）和一个模数 $k$ ，求这个 $m$ 进制数对 $k$ 取模的结果。可以在读入每一位的过程中边乘边取模：读到新的一位时令 $ans = (ans \times m + \text{这一位}) \bmod k$ 。

#### 输入格式

第一行一个整数 $n$ ，表示数据组数。接下来 $n$ 行，每行两个整数 $m$ 和 $k$ ，然后是一个字符串，表示 $m$ 进制下的整数，三者用空格分隔。

#### 输出格式

每组输出一行一个整数，表示该 $m$ 进制数对 $k$ 取模的结果。

#### 样例输入

```text
1
8 3 7503
```

#### 样例输出

```text
1
```

#### 数据范围

$m$ 进制的位数最多 $10^5$ ， $k \le 10^{6}$ ，因此中间结果最大约为 $10^{7}$ ，用 `int` 即可。

### 答案

### 题目分析

根据题目描述，考虑先将 $m$ 进制整数先转化成十进制，再进行取模运算得到结果。但是又注意到该 $m$ 进制数的位数最多达到了 $10^5$，转化成十进制后的数用常规的方法如 `long long` 都存不下。

由于同余运算对加乘运算封闭，因此我们可以把 $m$ 进制整数转成十进制这一过程拆分，先计算高位取模的结果，再依次拓展低位、合并计算结果。比如样例第三行的数可以这样理解：

$$
(7503)_8 = 7 \times 8^3 + 5 \times 8^2 + 0 \times 8^1 + 3
$$

$$
= ((7 \times 8 + 5) \times 8 + 0) \times 8 + 3
$$

依次读入字符串 $s$ 的过程中，读到 7，先计算 7 对 3 取模的结果，得到 1。然后再读入下一个字符 5，计算 $1 \times 8 + 5$ 对 3 取模的结果，以此类推即可得到答案。

注意到模数 $k$ 的上界范围是 $10^6$，因此过程中出现的数据最大为 $(k - 1) \times m + (m - 1) \le 10^7$，不需要使用 `long long`。

### 参考代码

```c
#include<stdio.h>
char s[100005];
int main() {
    int n;
    scanf("%d", &n);
    while (n--) {
        int m, k;
        scanf("%d%d%s", &m, &k, s);
        int ans = 0;
        for (int i = 0; s[i] != '\0'; i++) {
            ans = (ans * m + s[i] - '0') % k;
        }
        printf("%d\n", ans);
    }
    return 0;
}
```

### 题目

#### 题目描述

给定一个 $n \times n$ 的整数矩阵，用行列式的定义计算它的值：枚举 $1$ 到 $n$ 的所有排列 $\sigma$ ，对每个排列求 $\mathrm{sgn}(\sigma) \prod_{i=1}^{n} A_{i,\sigma(i)}$ 并累加，其中 $\mathrm{sgn}(\sigma)$ 由排列的逆序对个数的奇偶性决定（奇数个逆序对取 $-1$ ，偶数个取 $1$ ）。

#### 输入格式

第一行一个整数 $n$ 。接下来 $n$ 行，每行 $n$ 个整数，表示矩阵 $A$ 。

#### 输出格式

一行一个整数，表示矩阵的行列式。

#### 样例输入

```text
2
1 2
3 4
```

#### 样例输出

```text
-2
```

#### 数据范围

$n \le 8$ 。题目保证计算过程和结果都在 `int` 范围内。

### 答案

### 题目分析

计算行列式有多种方法，本题数据范围允许使用定义方法，并且给出生成下一个排列的函数，只需要根据提示进行计算即可。不过，由于该方法复杂度较高，实际计算行列式时，我们通常使用效率更高的方法，例如高斯消元法，这里不过多介绍。

计算下一个排列的函数这里也不再介绍原理，感兴趣的同学可以自行研究。

此外，本题保证了此方法计算过程及结果在 `int` 范围内。事实上，在题目的数据范围内，即使没有该保证，答案绝对值也有上确界 $(\sqrt{8 \times 10^2})^8 = 4.096 \times 10^{11}$。

### 示例代码

```c
#include <stdio.h>
int next_permutation(int j[], int n) {
    int l, r;
    for ( l = n - 1; l > 0 && j[l] > j[l + 1]; l-- );
    if ( l == 0 )
        return 0;
    for ( r = n; j[r] < j[l]; r-- );
    int tmp = j[l];
    j[l] = j[r];
    j[r] = tmp;
    for ( l++, r = n; l < r; l++, r-- ) {
        tmp = j[l];
        j[l] = j[r];
        j[r] = tmp;
    }
    return 1;
}
int main() {
    int J[10];
    int n;
    scanf("%d", &n);
    int A[10][10];
    for ( int i = 1; i <= n; i++ )
        for ( int j = 1; j <= n; j++ )
            scanf("%d", &A[i][j]);
    int ans = 0;
    for ( int i = 1; i <= n; i++ )
        J[i] = i;
    do {
        int cnt = 0, mul;
        for ( int i = 1; i < n; i++ )
            for ( int j = i + 1; j <= n; j++ )
                if ( J[i] > J[j] )
                    cnt++; // 计算逆序对数
        mul = cnt % 2 ? -1 : 1;
        for ( int i = 1; i <= n; i++ )
            mul *= A[i][J[i]]; // 计算该排列对应的乘积
        ans += mul;
    } while ( next_permutation(J, n) );
    printf("%d", ans);
    return 0;
}
```

## F 新品上市 2

| 难度 | 考点 |
| --- | --- |
| 4 | 动态内存管理/字符串哈希 |

### 题目

#### 题目描述

蔬菜店要维护一份蔬菜名单，支持三种操作：操作 1 给出一个蔬菜名，若它还不在名单中就把它加入并输出 `Delicious!` ，否则输出 `Not Applicable` ；操作 2 给出一个蔬菜名，若它在名单中就把它删除；操作 3 给出两个字符串，把名单中名字等于第一个字符串的蔬菜改名为两个字符串拼接后的结果。蔬菜的最终名字长度可能接近 10000，而所有名字的长度之和不超过 400000，直接开大二维数组会超出内存限制，需要用指针数组配合动态内存分配（或字符串哈希）。

#### 输入格式

第一行一个整数 $n$ ，表示操作次数。接下来 $n$ 行，每行以一个整数 `op` 开头： `op = 1` 或 `op = 2` 时后面跟一个蔬菜名； `op = 3` 时后面跟两个字符串。

#### 输出格式

对于每个 `op = 1` 的操作，输出一行 `Delicious!` 或 `Not Applicable` 。其余操作不产生输出。

#### 样例输入

```text
6
1 apple
1 apple
3 apple pie
1 applepie
2 applepie
1 applepie
```

#### 样例输出

```text
Delicious!
Not Applicable
Not Applicable
Delicious!
```

#### 数据范围

蔬菜数量不超过 1000，单个名字长度不超过 10000，所有名字长度之和不超过 400000。测试数据中包含针对弱哈希的 hack 数据。

### 答案

### 题目分析

您希望下个月的早餐、午餐和晚餐吃些什么？在第三天的晚餐喝多少盎司的牛奶？在第 15 天的早餐中需要在麦片中添加多少葡萄干？如果您与大多数人一样，就会等到进餐时再做决定。

——《C++ Primer Plus》，第 12 章。

如果我们还像新品上市 1 一样简单的开一个二维数组来存储蔬菜名称，为了保证能把最长的名字存下，我们不得不把数组开的非常大，这样就会造成 MLE。

由于蔬菜的最终名字长度不超过 10000，而所有的蔬菜名称长度和不超过 400000，我们可以合理推断，大部分蔬菜的名字都非常短，只有少数几个蔬菜名称接近 10000 的上限，可见在大数组中，绝大部分空间是被浪费了的。

为了节省下这部分空间，我们可以使用一个指针数组替代大数组，等到需要把字符串存进去的时候，再用 `malloc` 分配恰好能存下字符串的内存，并且在删除蔬菜时及时用 `free` 归还内存。

示例代码见 “示例代码 - 动态内存管理”。

如果你知道字符串 hash 是什么，你也可以用 hash 的办法解决本题。注意本题的测试点中存在一定量的 hack 数据，太弱的 hash 算法可能无法通过本题。

### 示例代码 - 动态内存管理

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

char* vegetable[1010];
int vegetableCount = 0;

int hasFoundVegetable(const char vegetableName[]) {
    for (int i = 0; i < vegetableCount; i++) {
        if (!strcmp(vegetable[i], vegetableName)) {
            return 1;
        }
    }
    return 0;
}

void addVegetable(const char vegetableName[]) {
    if (hasFoundVegetable(vegetableName)) {
        printf("Not Applicable\n");
    } else {
        vegetable[vegetableCount] = (char*)malloc(strlen(vegetableName) + 10);
        strcpy(vegetable[vegetableCount++], vegetableName);
        printf("Delicious!\n");
    }
}

void removeVegetable(const char vegetableName[]) {
    for (int i = 0; i < vegetableCount; i++) {
        if (!strcmp(vegetable[i], vegetableName)) {
            free(vegetable[i]);
            vegetable[i] = vegetable[--vegetableCount];
            return;
        }
    }
}

void extendVegetableName(const char vegetableName[], const char extend[]) {
```

## G 更简单的24点

| 难度 | 考点 |
| --- | --- |
| 4 | 回溯递归 |

### 题目

#### 题目描述

给定四个整数，要求把它们全部用上（每个数恰好用一次），只通过加、减、乘、除和括号，构造出一个值为 24 的整数倍的算式。若存在这样的算式，输出 `YE5` 以及构造方案；否则输出 `N0` 。构造方案用三行描述，每行形如「运算符 第一操作数的位置 第二操作数的位置」：位置 1 到 4 分别是输入的四个数，位置 5、6、7 分别是第一、二、三步运算的结果。

#### 输入格式

第一行一个整数 $t$ ，表示数据组数。接下来 $t$ 行，每行四个整数。

#### 输出格式

每组先输出一行：存在方案输出 `YE5` ，否则输出 `N0` 。输出 `YE5` 时，再输出三行，每行是一个运算符和两个位置编号，用空格分隔。

#### 样例输入

```text
1
1 2 3 4
```

#### 样例输出

```text
YE5
+ 1 2
+ 3 5
* 4 6
```

#### 数据范围

本题使用 special judge，只要输出格式正确且构造的算式成立即可。判断两个实数是否相等时应使用不小于 $10^{-10}$ 的误差界。

### 答案

### 题目分析

本题只需要同学们按照题意进行枚举计算即可。对于每种情况（整数个数，整数具体值），可以先枚举选哪两个数，再枚举这两个数用哪种运算。注意因为减法与除法没有交换律，因此若枚举的数不带顺序的话运算至少要枚举 6 种运算。题目中给定计算结果之间的差不超过 $10^{-10}$ 所以使用 $eps$ 判等时至少是这个数。

考虑到同学们很少写回溯递归，因此只要输出格式正确， $spj$ 大概率（除非因为一些问题导致输出格式乱掉了）会给出同学们具体错误点，并也会提示 `YES` 与 `YE5` 的错误。

在做完本题后，同学们可以证明一下以下命题：

对于任意 4 个整数，一定能够通过加、减、乘与换位得到 24 的整数倍。

本题可以做到 $O(T)$ 的复杂度。

### 示例代码

```c
#include <stdio.h>
#include<math.h>
const double eps=1e-10;
double s1[8];
int s2[8];
char c_0[3];
int op_1[3];
int op_2[3];
char may_c[4]={'+','-','*','/'};
void cal(int op1,int op2,int x,char c)
{
    s2[op1]=0;
    s2[op2]=0;
    s2[x]=1;
    if(c=='+')s1[x]=s1[op1]+s1[op2];
    else if(c=='-')s1[x]=s1[op1]-s1[op2];
    else if(c=='*')s1[x]=s1[op1]*s1[op2];
    else if(c=='/')s1[x]=s1[op1]/s1[op2];//由于double的性质，除以0也不会报错 
    c_0[x-5]=c;
    op_1[x-5]=op1;
    op_2[x-5]=op2; 
}
void decal(int op1,int op2,int x,char c)
{
    s2[op1]=1;
    s2[op2]=1;
    s2[x]=0;
}
int dfs(int x)
{
    int i,j,k;
    if(x==8)
    {
        int ans=round(s1[7]);
        if(fabs(ans-s1[7])>eps)return 0;
        if(ans%24!=0)return 0;
         
        printf("YE5\n");
        for(i=0;i<3;i++)
        {
            printf("%c %d %d\n",c_0[i],op_1[i],op_2[i]);
        }
        return 1;
    }
    for(i=1;i<=6;i++)
    {
        if(s2[i]==0)continue;
        for(j=1;j<=6;j++)
        {
            if(i==j||s2[j]==0)continue;
            for(k=0;k<4;k++)
            {
                cal(i,j,x,may_c[k]);
                if(dfs(x+1))return 1;
                decal(i,j,x,may_c[k]);
            }
        }
    }
    return 0;
}
int main(){
    int t;
    scanf("%d",&t);
    while(t--)
    {
        int a,b,c,d,i;
        scanf("%d%d%d%d",&a,&b,&c,&d);
        s1[1]=a;
        s1[2]=b;
        s1[3]=c;
        s1[4]=d;
        for(i=0;i<8;i++)
        {
            if(i>0&&i<=4)s2[i]=1;
            else s2[i]=0;
        }
        if(dfs(5)==0)
        {
            printf("N0\n");
        }
    }
    return 0; 
}
```

## H 美丽花园

| 难度 | 考点 |
| --- | --- |
| 5 | 二分答案，贪心 |

### 题目

#### 题目描述

花园里有 $n$ 朵花排成一列，第 $i$ 朵的品种是 $a_i$ 。要把花园划分成 $k$ 个连续的花圃，一个花圃的丰度是它包含的不同品种数，花园的美丽程度是所有花圃丰度的最小值。求花园美丽程度的最大可能值。

#### 输入格式

第一行一个整数 $t$ ，表示数据组数。每组数据第一行两个整数 $n$ 和 $k$ ，第二行 $n$ 个整数，表示每朵花的品种。

#### 输出格式

每组输出一行一个整数，表示最大的美丽程度。

#### 样例输入

```text
1
6 2
1 2 1 3 2 3
```

#### 样例输出

```text
2
```

#### 数据范围

$1 \le a_i \le n$ 。答案具有单调性，可以二分答案并用贪心在 $O(n)$ 时间内验证；每次验证时要注意高效地清空标记数组。

### 答案

### 题目分析

这题直接从花园中得出最大可能的美丽程度是很困难的。反过来考虑，给定一个美丽程度 $x$，能否验证花园是否存在一种划分方案，使得其美丽程度不低于 $x$ 呢？

显然，如果花园的美丽程度不低于 $x$，那么其每个花圃的丰度都不能低于 $x$。于是我们有一种贪心策略，从花园的第一朵花开始扩展花圃，只要花圃的丰度刚好达到 $x$ 就将这个花圃隔离开，如此进行下去直到遍历完整个花园，记录想要美丽程度不低于 $x$，那么至多可以分隔出多少个花圃。如果这个数字不足 $k$，显然就不存在一种划分方式使得花园的美丽程度不低于 $x$。否则我们一定能找到一种方式将花园划分为 $k$ 个花圃，其中最小的丰度为 $x$，即花园的美丽程度为 $x$。

又注意到如果可以划分得到美丽程度为 $x$ 的花圃，那么也一定能得到美丽程度小于 $x$ 的花圃，于是答案具有了二分性，可以使用二分答案来解决这个问题。

具体实现的时候需要注意如何去记录每个花圃的丰度，如何高效的清空 `vis` 数组，确保每次 `check` 的时间复杂度为 $O(n)$，才能保证最后的时间复杂度为 $O(n \log n)$

### 示例代码

```c
#include <stdio.h>
#include <string.h>
#include <assert.h>
int a[200015];
int vis[200015];
int stk[200015];
int check(int n, int k, int m)
{
    memset(vis, 0, (n + 5) * 4);
    int cnt = 0, d = 0;
    for (int i = 0; i < n; i++)
    {
        if (vis[a[i]] == 0)
        {
            vis[a[i]] = 1;
            stk[cnt++] = a[i];
        }
        if (cnt == m)
        {
            d++;
            for (int j = 0; j < cnt; j++)
            {
                vis[stk[j]] = 0;
            }
            // 不可直接对 vis 进行 memset 操作，效率过低。memset 至少需要对 n 个 vis 位置进行清空，而这样操作只需要对 m 个 vis 位置清空。
            cnt = 0;
        }
    }
    return d >= k;
}
void solve()
{
    int n, k;
    scanf("%d%d", &n, &k);
    for (int i = 0; i < n; i++)
    {
        scanf("%d", &a[i]);
        assert(1 <= a[i] && a[i] <= n);
    }
    int l = 1, r = n + 2;
    while (r - l > 1)
    {
        int mid = (r + l) / 2;
        if (check(n, k, mid))
        {
            l = mid;
        }
        else
        {
            r = mid;
        }
    }
    printf("%d\n", l);
}
int main(void)
{
    int t;
    scanf("%d", &t);
    while (t--)
    {
        solve();
    }
    return 0;
}
```

## I n维数组遍历

| 难度 | 考点 |
| --- | --- |
| 6 | 贪心 |

### 题目

#### 题目描述

有一个 $n$ 维数组，第 $i$ 维的大小是 $d_i$ ，元素总数 $m = \prod_{i=1}^{n} d_i$ 。这些元素按一维方式存放，第 $i$ 维的下标每增加 1，存放位置就前进 $\prod_{k=i+1}^{n} d_k$ 个单位（也就是说最后一维变化最快）。现在给定一个遍历顺序，依次指明每一层循环对应哪一维，最先给出的维度是最内层、变化最快的维度。请按这个遍历顺序输出所有元素。

#### 输入格式

第一行一个整数 $n$ 。第二行 $n$ 个整数，依次是 $d_1$ 到 $d_n$ 。第三行 $m$ 个整数，是按上述方式存放的数组元素。最后一行 $n$ 个整数，表示遍历时各层循环对应的维度，最前面的是最内层。

#### 输出格式

一行 $m$ 个整数，表示按给定顺序遍历得到的结果，相邻两数之间用一个空格分隔。

#### 样例输入

```text
2
2 3
1 2 3 4 5 6
2 1
```

#### 样例输出

```text
1 2 3 4 5 6
```

#### 数据范围

各维大小的乘积 $m$ 可达 $5 \times 10^{5}$ 。逐层修改全部 $n$ 个下标的朴素做法会超时；由于大小为 1 的维度下标只能是 0，可以把它们从遍历中剔除，这样非 1 的维度数量不超过 $\log_2 m$ 。

### 答案

### 题目分析

1. 用一维数组存 $n$ 维数组：

由于题目中的 $n$ 维数组数组个数不确定，我们无法将其直接地存在 $n$ 维数组内。此时，我们可以考虑仅用一个一维数组 $s_i$ 来存这些数。由题意，我们按照第 $n$ 维到第 1 维的顺序进行遍历，故较大维度每次增加的量在 $s_i$ 中变化量较少。对于第 $i$ 维，其下标的每次增加会导致 $s_i$ 变化 $\prod_{k=i+1}^{n} a_i$ 位置，特殊的，当 $i = n$ 时，只会变化 1。所以我们可以先预处理出每次增加量，然后使用下标直接计算出 $s_i$ 存储下标，用该位置进行存储与读取

1. 时间优化：

如果我们暴力的枚举出遍历 $n$ 维数组的过程，最后会得到 0.5 分的 $TLE$。原因在于每次枚举下一个下标位置时，我们最多要改变 $n$ 个下标的值，导致时间复杂度到达 $O(n^2)$。可观察到，若某一维度的大小为 1，我们没有必要改变这个下标的值，因为该下标的值只能为 0。于是，我们可以将遍历中所有大小为 1 的维度去除，将该维度的前缀和后缀直接相连。在做如此剪枝操作之后，我们可以发现已经可以通过此题了。因为此时任意维度的大小均大于 1，而总大小为 $m$，故最多有 $log_2 m$ 个不为 1 的维度，时间复杂度会降至 $O(n log m)$ 可通过此题。

### 示例代码

```c
#include<stdio.h>

int d[500010];//维度大小
int d_mult[500010];//维度连乘
int element[500010];//元素
int seq[500010];//维度遍历顺序
int tra[500010];//遍历时使用的临时变量，类似于i
int main()
{
    int n;
    scanf("%d",&n);
    int i,j,m=1;
    for(i=1;i<=n;i++)
    {
        scanf("%d",&d[i]);
        m*=d[i];
    }
    d_mult[n]=1;
    for(i=n-1;i>=1;i--)
    {
        d_mult[i]=d_mult[i+1]*d[i+1];
    }
    for(i=0;i<m;i++)
    {
        scanf("%d",&element[i]);
    }
    int len=0;
    for(i=0;i<n;i++)
    {
        scanf("%d",&seq[len]);
        if(d[seq[len]]>1)//仅大小为1的维度进入到遍历数组内，否则直接被替代
            len++;
    }
    int now=0;
    for(i=0;i<m;i++)
    {
        printf("%d ",element[now]);
        for(j=0;j<len;j++)
        {
            tra[seq[j]]++;
            now+=d_mult[seq[j]];
            if(tra[seq[j]]>=d[seq[j]])
            {
                now-=d_mult[seq[j]]*d[seq[j]];
                tra[seq[j]]=0;
            }
            else break;
        }
    }
    return 0;
}
```

## J 一只蚂蚁 1

| 难度 | 考点 |
| --- | --- |
| 6 | 打表 |

### 题目

#### 题目描述

一只蚂蚁在无限大的方格纸上移动。初始时所有格子都未被访问，蚂蚁位于原点，初始朝向为 $y$ 轴正方向。每一步的规则是：若当前格子被访问过奇数次（视为黑色）则左转 90°，否则右转 90°；然后把当前格子的访问次数加一，再沿朝向前进一格。给定若干个坐标，求每个坐标被访问了多少次。

#### 输入格式

第一行一个整数 $q$ ，表示询问次数。接下来 $q$ 行，每行两个整数 $x$ 和 $y$ ，表示一个格子的坐标。

#### 输出格式

每次询问输出一行一个整数，表示该格子被访问的次数；从未被访问过则输出 0。

#### 样例输入

```text
3
0 0
1 0
30 30
```

#### 样例输出

```text
29
33
0
```

#### 数据范围

蚂蚁在约 9976 步后进入周期为 104 的循环，此后沿 $y = x + 18$ 与 $y = x + 28$ 之间的带状区域向西南方向不断前进。坐标可能很大，需要利用这一循环性质；前 9976 步内 $|x|, |y| \le 30$ ，小范围内直接模拟即可。

### 答案

### 题目分析

本题灵感来源：一只蚂蚁。

本题结论是在 9976 步后进入以 104 步为周期的循环，值得注意的是：

1. 循环的是蚂蚁的朝向而不是位置，蚂蚁进入循环后会在 $y = x + 18$ 和 $y = x + 28$ 之间（含）向西南方不断移动；
2. 由于方向只取决于访问次数的奇偶，因此前几次循环时点的访问次数可能与之后的略有不同。

在 9976 步内，蚂蚁的坐标 $(x, y)$ 满足 $|x|, |y| \le 30$，因此我们只需要在较小的平面范围内进行模拟，并在输入较大时判断是否位于循环路径上即可（若在则输出对应位置的访问次数）。

### 示例代码

```c
#include<stdio.h>
#include<stdlib.h>
const int dx[] = {0, 1, 0, -1};
const int dy[] = {1, 0, -1, 0};
int mat[80][80]; // 没有负数下标，需要偏移
int main() {
    long long x = 40, y = 40, p = 0;
    for (int i = 0; i < 11111; ++i) { // 进行 11111 步的模拟
        if (mat[x][y] & 1) {
            p = (p + 3) % 4;
        }
        else {
            p = (p + 1) % 4;
        }
        mat[x][y]++;
        x += dx[p];
        y += dy[p];
    }
    int q;
    scanf("%d", &q);
    while(q--) {
        scanf("%lld%lld", &x, &y);
        if (llabs(x) < 30 && llabs(y) < 30) { // |x|,|y| <= 30 时，直接输出模拟结果
            printf("%d\n", mat[x + 40][y + 40]);
        }
        else if (x < -25 && 18 <= y - x && y - x <= 28) { // x < -25 且在循环路径上时，输出对应已模拟的结果
            printf("%d\n", mat[x + (-25 - x) / 2 * 2 + 40][y + (-25 - x) / 2 * 2 + 40]);
        }
        else { // 未访问
            printf("0\n");
        }
    }
}
```
