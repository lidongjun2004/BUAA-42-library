### 题目

#### 题目描述

石头剪刀布中，用 1 表示布、2 表示剪刀、3 表示石头。输入对方出的手势编号，输出能够战胜它的手势编号。

#### 输入格式

一行一个整数，取值是 1、2、3 中的一个。

    }

## B a+b a-b a*b a/b a%b problem

| 难度 | 考点 |
| --- | --- |
| 1 | 输入输出 |

### 题目

#### 题目描述

给定两个整数 $a$ 和 $b$ ，依次输出 $a+b$ 、 $a-b$ 、 $a \times b$ 、 $a / b$ 、 $a \bmod b$ 的结果，其中除法是整数除法。用 `printf` 输出百分号时需要写成两个百分号。

#### 输入格式

一行两个整数 $a$ 和 $b$ ，用空格分隔。

#### 输出格式

五行，依次是五个运算的结果，每行格式为「算式=结果」，运算符两侧不加空格。

#### 样例输入

```text
7 3
```

#### 样例输出

```text
7+3=10
7-3=4
7*3=21
7/3=2
7%3=1
```

### 答案

### 题目分析

给出 $a, b$，要求输出 `a+b, a-b, a*b, a/b, a%b`。

本体没啥难度，只需要额外注意用 `printf` 输出百分号 `%` 时要用两个百分号。

### 示例代码

```c
#include <stdio.h>

int main()
{
    int a, b;
    scanf("%d%d", &a, &b);
    printf("%d+%d=%d\n", a, b, a + b);
    printf("%d-%d=%d\n", a, b, a - b);
    printf("%d*%d=%d\n", a, b, a * b);
    printf("%d/%d=%d\n", a, b, a / b);
    printf("%d%%%d=%d\n", a, b, a % b);
    return 0;
}
```

## C Nick of Time

| 难度 | 考点 |
| --- | --- |
| 2 | 输入输出 |

### 题目

#### 题目描述

给出初始位置 $(x_0, y_0)$ 、速度 $(v_x, v_y)$ 和时间 $t$ ，求 $t$ 时刻的位置 $(x_t, y_t)$ ，其中 $x_t = x_0 + v_x t$ ， $y_t = y_0 + v_y t$ 。

#### 输入格式

第一行两个整数 $x_0$ 和 $y_0$ 。第二行两个整数 $v_x$ 和 $v_y$ 。第三行一个整数 $t$ 。

#### 输出格式

一行两个整数 $x_t$ 和 $y_t$ ，用空格分隔。

#### 样例输入

```text
0 0
1 2
5
```

#### 样例输出

```text
5 10
```

### 答案

### 题目分析

给出 $(x_0, y_0), (v_x, v_y), t$，求 $(x_t, y_t)$。

根据我们中学学过的公式，有

$$
\begin{cases}
x_t = x_0 + v_x t \\
y_t = y_0 + v_y t
\end{cases}
$$

直接输出即可。

### 示例代码

```c
#include <stdio.h>

int main(){
    int x0,y0;
    int vx,vy;
    int t;
    scanf("%d%d",&x0,&y0);
    scanf("%d%d",&vx,&vy);
    scanf("%d",&t);
    int xt=x0+vx*t;
    int yt=y0+vy*t;
    printf("%d %d",xt,yt);
    return 0;
}
```

## D 肥宅快乐水

| 难度 | 考点 |
| --- | --- |
| 2 | 循环 |

### 题目

#### 题目描述

BVVD 手上有 $n$ 个瓶盖，每 5 个瓶盖可以兑换 1 瓶快乐水，喝完之后又能得到 1 个瓶盖。求他最多能喝到多少瓶快乐水。

#### 输入格式

一行一个整数 $n$ ，表示初始的瓶盖数。

#### 输出格式

一行一个整数，表示最多能兑换并喝掉的快乐水瓶数。

#### 样例输入

```text
104
```

#### 样例输出

```text
25
```

### 答案

### 解法1

首先我们考虑模拟的方法解决这道题。

我们可以在代码中模拟这样的一个过程：**每次将手中瓶盖最大数量的兑换快乐水，然后将这批快乐水喝掉，新的到一批快乐水，如此往复，直到瓶盖剩余不足以兑换一瓶快乐水。**

例如手中原来有 104 个瓶盖。

在第一回合，BVVD使用 104 个瓶盖中的 100 个，兑换了 20 瓶快乐水，剩余 4 个瓶盖。

在他喝完兑换的 20 瓶快乐水后，他新得到 20 个瓶盖，总共有 24 个瓶盖。

第二回合，BVVD用手上的 24 个瓶盖中的 20 个，兑换了 4 瓶快乐水，剩余 4 个瓶盖。

喝完后新得到 4 个瓶盖，总共剩余 8 个。

第三回合，使用 8 个瓶盖中的 5 个，兑换 1 瓶快乐水，剩余 3 个。

喝完后新的到 1 个，总共剩余 4 个，无法再次兑换，结束循环。

总结一下，我们应该在循环中维护以下变量：

$rest\_cap$：在该轮开始前剩余瓶盖数。

$new\_cap$：该轮兑换得到的快乐水（瓶盖）。

$sum\_cola$：总共兑换的快乐水数量。

对每个回合，有如下维护：

$new\_cap = rest\_cap/5$

$sum\_cola = sum\_cola + new\_cap$

$rest\_cap = rest\_cap \bmod 5 + new\_cap$

回合结束的条件自然是 $new\_cap == 0$

附上代码：

```c
#include <stdio.h>
int main()
{
    int n;
    scanf("%d", &n);
    int new_cap;
    int rest_cap = n;         // 初始的剩余瓶盖就是输入的n
    int sum_cola = 0;         // 注意初始化
    new_cap = rest_cap / 5; // 计算初值，防止while循环无法进入
    while (new_cap != 0)
    {
        new_cap = rest_cap / 5;
        sum_cola = sum_cola + new_cap;
        rest_cap = rest_cap % 5 + new_cap;
    }
    printf("%d", sum_cola);
}
```

### 解法2

其实这道题我们可以考虑一些数学方法。

其实每兑换一瓶快乐水，我们消耗了 5 个瓶盖，新的到了 1 个瓶盖，净失去 4 个瓶盖。

**所以我们可以认为，其实是 4 个瓶盖兑换一瓶没有瓶盖的快乐水。**

但是这两个问题并不等价，**因为如果BVVD只有 4 个瓶盖，他是无法通过借一个瓶盖来兑换快乐水的。** 为了解决这一问题，我们不妨认为一直有一个瓶盖被BVVD留下，从而使每次能够用 4 个瓶盖兑换一瓶可乐。

附上代码：

```c
#include<stdio.h>
int main()
{
    int n;
    scanf("%d", &n);
    printf("%d", (n - 1) / 4);
}
```

## E AI 训练

| 难度 | 考点 |
| --- | --- |
| 2 | 取模，分类讨论 |

### 题目

#### 题目描述

员工有初始预算 $n$ 。老板每天给员工 $m$ 的花费预算，员工当天花掉 $m$ ，剩下的钱成为新的预算，如此重复。若某天员工本日的花费预算为 0，老板就认为他已完成所有任务并收回全部剩余预算。特别地，若 $m = 0$ ，老板第一天就会收回全部预算。求最终收回的预算。

#### 输入格式

一行两个整数 $n$ 和 $m$ ，用空格分隔。

#### 输出格式

一行一个整数，表示最终收回的预算。

#### 样例输入

```text
10 3
```

#### 样例输出

```text
1
```

### 答案

### 题目分析

我们可以手动模拟一下员工每天花预算的情况，这样可以注意到，员工最终剩下的预算正好就是初始预算对每次划分预算取模的结果，于是答案就是 $n \bmod m$。结束了吗？

并没有！再仔细看看数据范围， $m$ 是可以等于 $0$ 的！每次计算任务可以是免费的！那这个情况我们显然不能进行取模操作。此时仔细看题目描述的加粗部分：

> 老板如果在某天发现**员工本日花费预算为 0**，就会认为这位员工已经完成了他所有的任务，并收回所有剩余的预算。

也就是说如果 $m = 0$，那么老板第一天就会收回所有预算，答案为 $n$。

至此，此题的所有情况都被我们解决了。

### 示例代码

```c
#include <stdio.h>
int main(void)
{
    int n, m;
    scanf("%d%d", &n, &m);
    if (m == 0)
        printf("%d", n);
    else
        printf("%d", n % m);
    return 0;
}
```

## F 迎新志愿者

| 难度 | 考点 |
| --- | --- |
| 2 | 输入输出，条件判断 |

### 题目

#### 题目描述

学号是一个 8 位数字，前 4 位固定为 2537，第 5 位是 1 或 3：1 表示该同学来自 `chuanyuan` ，3 表示来自 `shie` 。后 3 位的取值范围是 001 到 999。请按学院名和后三位输出志愿者的信息，后三位不足 3 位时要在前面补 0。

#### 输入格式

第一行一个整数 $t$ ，表示数据组数。接下来 $t$ 行，每行一个 8 位学号。

#### 输出格式

每组输出一行：先输出学院名（ `chuanyuan` 或 `shie` ），再输出补齐到 3 位的后三位，两者之间用一个空格分隔。

#### 样例输入

```text
2
25371001
25373012
```

#### 样例输出

```text
chuanyuan 001
shie 012
```

### 答案

### 题目分析

学号可看成一个 `8` 位的数字，前 `4` 位固定为 `2537`，第 `5` 位是 `1` 或者 `3`，可以根据这个来判断是输出 `chuanyuan` 还是 `shie`。后面的 `3` 位取值范围是 `001-999`，将这后三位输出即可。但是要注意对于小于 `100` 的数字需要输出前导 `0`。可以使用格式化输出，但这还没学，因此推荐使用 `if` 进行条件判断。分成 **小于10**，**大于等于10，小于100**，**大于等于100** 三种情况讨论即可。

### 示例代码

```c
#include<stdio.h>

int main()
{
    int t;
    scanf("%d",&t);
    while(t--) // 多组输入
    {
        int x;
        scanf("%d",&x); // 读入学号
        int y = x / 1000;
        int z = x % 1000;
        // 根据前5位判断学院
        if(y == 25371)printf("chuanyuan ");
        else printf("shie ");

        // 条件判断输出后三位
        if(z < 10)printf("00%d",z);
        else if(z < 100)printf("0%d",z);
        else printf("%d",z);
        // 注意回车
        printf("\n");
    }
    return 0;
}
```

## G 取糖果

| 难度 | 考点 |
| --- | --- |
| 2 | 博弈论 |

### 题目

#### 题目描述

桌上有 $n$ 颗糖果，Alice 和 Bob 轮流取，每次只能取 1 颗或 3 颗，不能不取，取走最后一颗糖果的人获胜。两人都足够聪明，Alice 先手。求最终谁会获胜。

#### 输入格式

第一行一个整数 $t$ ，表示数据组数。接下来 $t$ 行，每行一个整数 $n$ 。

#### 输出格式

每组输出一行：Alice 获胜输出 `Alice` ，否则输出 `Bob` 。

#### 样例输入

```text
3
1
2
5
```

#### 样例输出

```text
Alice
Bob
Alice
```

### 答案

### 题目分析

A，B 两人取糖果，每次只能取 1 或 3 个，且不能不取。二者都足够聪明，取走最后一个糖果的人获胜。

可以注意到，不管是拿 1 个还是拿 3 个，都是拿奇数个。也就是说，在两个人取糖果的过程中，糖果的数量总是会有奇偶交替的过程：奇数 $\to$ 偶数 $\to$ 奇数 $\to$ 偶数 $\to \cdots$

而糖果数量最终总是会归零的，也就是说糖果数量最终一定是偶数，于是总结一下可以得到结论：初始值为奇数时先手必胜，初始值为偶数时后手必胜。

### 示例代码

```c
#include <stdio.h>
int main()
{
    int t;
    scanf("%d", &t);
    while (t--)
    {
        int n;
        scanf("%d", &n);
        if (n % 2 == 1)
        {
            printf("Alice\n");
        }
        else
        {
            printf("Bob\n");
        }
    }
    return 0;
}
```

## H 我去，麦！

| 难度 | 考点 |
| --- | --- |
| 2 | 循环，输出 |

### 题目

#### 题目描述

一条路的两端各有一个字母 `M` ，中间由若干节组成，第 $i$ 节是 $d_i$ 个下划线接一个 `M` 。请输出这条路的样子。

#### 输入格式

第一行一个整数 $n$ 。接下来 $n - 1$ 个整数，依次是 $d_1$ 到 $d_{n-1}$ 。

#### 输出格式

一行：先输出一个 `M` ，再依次输出 $n - 1$ 组「 $d_i$ 个下划线 + `M` 」。

#### 样例输入

```text
3
2 1
```

#### 样例输出

```text
M__M_M
```

### 答案

### 解题思路

由于保证路的两端一定有 `M`。我们可以在输出最左端的 `M` 后，将剩下的路以 $n - 1$ 个 `___M` 的形式输出。其中第 $i$ 节中下划线的数量为 $d_i$。用简单的循环控制这个过程即可。

### 示例代码1

```c
#include <stdio.h>

int main() {
    int n, d;
    scanf("%d", &n);
    printf("M");
    int i = 1;
    while (i <= n) {
        scanf("%d", &d);
        int j = 1;
        while (j <= d) {
            printf("_");
            j = j + 1;
        }
        printf("M");
        i = i + 1;
    }
}
```

### 注

可能有的同学看到控制台中第一个 `M` 和后续输出没在一行，觉得不对。但其实这是无所谓的。

因为控制台用同一个窗口显示输入和输出。当你边读入边输出时，如果你输入的内容夹在两个输出中间，可能会使你觉得输出被截断了。

而电脑评测的时候，是将一个 `.in` 文件作为你代码的读入，再用一个 `.out` 文件来接收你的输出。也就是说二者是分开的。只有你代码中输出换行符时，才会反映到 `.out` 文件中显示换行。因此不会出现控制台中视觉上的问题。

或者这里也有一个满足强迫症的写法：

### 示例代码2

```c
#include <stdio.h>
int main(void)
{
    int n;
    scanf("%d", &n);
    for (int i = 0; i < n - 1; i++)
    {
        int m;
        scanf("%d", &m);
        printf("M");
        while (m > 0)
        {
            printf("_");
            m--;
        }
    }
    printf("M");
    return 0;
}
```

## I 数字翻转

| 难度 | 考点 |
| --- | --- |
| 3 | 循环 |

### 题目

#### 题目描述

给定一个整数，把它的各位数字反转后输出，反转后可能出现的前导零要去掉。输入可能是正数、负数或 0。

#### 输入格式

一行一个整数 $a$ 。

#### 输出格式

一行，即反转之后的整数。输入为负数时结果带负号；输入为 0 时输出 0。

#### 样例输入

```text
-12300
```

#### 样例输出

```text
-321
```

#### 数据范围

$-10^{9} \le a \le 10^{9}$ ，反转后的结果不会超出 `int` 范围。

### 答案

### 问题分析

这个问题要求我们将一个整数的各位数字进行反转，并去除可能的前导零。需要注意的是：

1. 输入可能是正数、负数或零
2. 反转后如果最高位是0（除原数为0的情况外）需要去除
3. 输入范围在 $-10^9$ 到 $10^9$ 之间，反转后的数字不会超过int范围，不需要使用long long类型（当然也可以无脑long long）

### 解题思路

1. 处理特殊情况：如果输入为0，直接输出0
2. 处理负数：记录负号并将负数转为正数处理
3. 数字反转：通过循环取原数的最后一位，逐步构建反转后的数字

### 代码实现

```c
#include <stdio.h>
int main()
{
    int a, b = 0;
    scanf("%d", &a);
    if (a == 0) // 需要单独判断0的情况
    {
        printf("0");
        return 0;
    }
    if (a < 0) // 若小于零，取负号后可转化为大于零的情况
    {
        printf("-");
        a = -1 * a;
    }
    while (a != 0)
    {
        if (a % 10 != 0)
        {
            b = 1;
        }
        if (b == 1)
        {
            printf("%d", a % 10);
        }
        a /= 10;
    }
}
```

## J a-b problem 但是分数

| 难度 | 考点 |
| --- | --- |
| 3 | gcd，分类讨论 |

### 题目

#### 题目描述

给定两个分数 $\frac{a}{b}$ 和 $\frac{c}{d}$ ，求它们的差 $\frac{a}{b} - \frac{c}{d}$ 。若结果可以化成整数，就输出这个整数；否则把结果约分到最简分数后以 `p/q` 的形式输出。

#### 输入格式

第一行两个整数 $a$ 和 $b$ 。第二行两个整数 $c$ 和 $d$ 。

#### 输出格式

一行：结果为整数时输出该整数，否则输出形如 `p/q` 的最简分数。

#### 样例输入

```text
1 2
1 3
```

#### 样例输出

```text
1/6
```

#### 数据范围

分子可能是负数，枚举最大公约数时不能从两个数中较小的那个开始，否则会永远找不到结果；以分母为起点即可。

### 答案

### 题目分析

由小学知识，两个分数相减的得数为：

$$
\frac{a}{b} - \frac{c}{d} = \frac{ad - bc}{bd}
$$

于是我们计算出 $ad - bc$ 与 $bd$，如果有 $(ad - bc) \equiv 0 \pmod{bd}$，即 `(a * d - b * c) % (b * d) == 0`，则说明得数可以化作一个整数。

否则，令 $x := ad - bc, y := bd$，我们只需要求出 $\gcd(x, y)$，即可得到 $p = \frac{x}{\gcd(x,y)}, q = \frac{y}{\gcd(x,y)}$。

求两个数的最大公约数，可以直接暴力，但是要注意，此时不能像课件中那样取两个数中的更小的那一个作为查找的起点，因为此时分子有可能为负数，导致永远找不到最大公约数。举个例子，如果有 $x = -7, y = 9$，而且从 $-7$ 开始一个一个往小了找的话，你会发现你检查的数的绝对值其实是越来越大的，因此你永远也找不到他们的最大公约数，也就是 $1$。

为了解决这个问题，我们要确保我们的查找起点是一个正整数。也就是说，只要我们直接以分母 $y$ 作为查找起点，就一定能找到 $x, y$ 的最大公约数。

此外，求 $\gcd$ 还有一种更加高效的方法：辗转相除法。这会在未来的课程中学到，感兴趣的同学可以提前学习。

### 示例代码

```c
#include <stdio.h>
int main(void)
{
    int a, b, c, d;
    scanf("%d%d", &a, &b);
    scanf("%d%d", &c, &d);
    int x = a * d - b * c, y = b * d;

    if (x % y == 0)
    {
        printf("%d", x / y);
    }
    else
    {
        int g = y;
        while (x % g != 0 || y % g != 0)
        {
            g--;
        }
        int p = x / g;
        int q = y / g;
        printf("%d/%d", p, q);
    }
    return 0;
}
```
