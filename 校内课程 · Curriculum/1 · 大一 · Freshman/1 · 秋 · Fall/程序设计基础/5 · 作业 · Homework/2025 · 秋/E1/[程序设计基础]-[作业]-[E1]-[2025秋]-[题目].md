# 程序设计基础 E1 题目（2025秋）

## A AI 的石头剪刀布

### 题目

#### 题目描述

石头剪刀布中，用 1 表示布、2 表示剪刀、3 表示石头。输入对方出的手势编号，输出能够战胜它的手势编号。

#### 输入格式

一行一个整数，取值是 1、2、3 中的一个。

#### 输出格式

一行一个整数，表示能战胜对方手势的编号。

#### 样例输入

```text
1
```

#### 样例输出

```text
3
```

## B a+b a-b a*b a/b a%b problem

### 题目

#### 题目描述

给定两个整数 $a$ 和 $b$ ，依次输出 $a+b$ 、 $a-b$ 、 $a \times b$ 、 $a / b$ 、 $a \bmod b$ 的结果，其中除法是整数除法。用 `printf` 输出百分号时需要写成两个百分号。

#### 输入格式

一行两个整数 $a$ 和 $b$ ，用空格分隔。

#### 输出格式

五行，依次是五个运算的结果，每行格式为「算式=结果」，运算符两侧不加空格。

#### 样例输入

```text
7 3
```

#### 样例输出

```text
7+3=10
7-3=4
7*3=21
7/3=2
7%3=1
```

## C Nick of Time

### 题目

#### 题目描述

给出初始位置 $(x_0, y_0)$ 、速度 $(v_x, v_y)$ 和时间 $t$ ，求 $t$ 时刻的位置 $(x_t, y_t)$ ，其中 $x_t = x_0 + v_x t$ ， $y_t = y_0 + v_y t$ 。

#### 输入格式

第一行两个整数 $x_0$ 和 $y_0$ 。第二行两个整数 $v_x$ 和 $v_y$ 。第三行一个整数 $t$ 。

#### 输出格式

一行两个整数 $x_t$ 和 $y_t$ ，用空格分隔。

#### 样例输入

```text
0 0
1 2
5
```

#### 样例输出

```text
5 10
```

## D 肥宅快乐水

### 题目

#### 题目描述

BVVD 手上有 $n$ 个瓶盖，每 5 个瓶盖可以兑换 1 瓶快乐水，喝完之后又能得到 1 个瓶盖。求他最多能喝到多少瓶快乐水。

#### 输入格式

一行一个整数 $n$ ，表示初始的瓶盖数。

#### 输出格式

一行一个整数，表示最多能兑换并喝掉的快乐水瓶数。

#### 样例输入

```text
104
```

#### 样例输出

```text
25
```

## E AI 训练

### 题目

#### 题目描述

员工有初始预算 $n$ 。老板每天给员工 $m$ 的花费预算，员工当天花掉 $m$ ，剩下的钱成为新的预算，如此重复。若某天员工本日的花费预算为 0，老板就认为他已完成所有任务并收回全部剩余预算。特别地，若 $m = 0$ ，老板第一天就会收回全部预算。求最终收回的预算。

#### 输入格式

一行两个整数 $n$ 和 $m$ ，用空格分隔。

#### 输出格式

一行一个整数，表示最终收回的预算。

#### 样例输入

```text
10 3
```

#### 样例输出

```text
1
```

## F 迎新志愿者

### 题目

#### 题目描述

学号是一个 8 位数字，前 4 位固定为 2537，第 5 位是 1 或 3：1 表示该同学来自 `chuanyuan` ，3 表示来自 `shie` 。后 3 位的取值范围是 001 到 999。请按学院名和后三位输出志愿者的信息，后三位不足 3 位时要在前面补 0。

#### 输入格式

第一行一个整数 $t$ ，表示数据组数。接下来 $t$ 行，每行一个 8 位学号。

#### 输出格式

每组输出一行：先输出学院名（ `chuanyuan` 或 `shie` ），再输出补齐到 3 位的后三位，两者之间用一个空格分隔。

#### 样例输入

```text
2
25371001
25373012
```

#### 样例输出

```text
chuanyuan 001
shie 012
```

## G 取糖果

### 题目

#### 题目描述

桌上有 $n$ 颗糖果，Alice 和 Bob 轮流取，每次只能取 1 颗或 3 颗，不能不取，取走最后一颗糖果的人获胜。两人都足够聪明，Alice 先手。求最终谁会获胜。

#### 输入格式

第一行一个整数 $t$ ，表示数据组数。接下来 $t$ 行，每行一个整数 $n$ 。

#### 输出格式

每组输出一行：Alice 获胜输出 `Alice` ，否则输出 `Bob` 。

#### 样例输入

```text
3
1
2
5
```

#### 样例输出

```text
Alice
Bob
Alice
```

## H 我去，麦！

### 题目

#### 题目描述

一条路的两端各有一个字母 `M` ，中间由若干节组成，第 $i$ 节是 $d_i$ 个下划线接一个 `M` 。请输出这条路的样子。

#### 输入格式

第一行一个整数 $n$ 。接下来 $n - 1$ 个整数，依次是 $d_1$ 到 $d_{n-1}$ 。

#### 输出格式

一行：先输出一个 `M` ，再依次输出 $n - 1$ 组「 $d_i$ 个下划线 + `M` 」。

#### 样例输入

```text
3
2 1
```

#### 样例输出

```text
M__M_M
```

## I 数字翻转

### 题目

#### 题目描述

给定一个整数，把它的各位数字反转后输出，反转后可能出现的前导零要去掉。输入可能是正数、负数或 0。

#### 输入格式

一行一个整数 $a$ 。

#### 输出格式

一行，即反转之后的整数。输入为负数时结果带负号；输入为 0 时输出 0。

#### 样例输入

```text
-12300
```

#### 样例输出

```text
-321
```

#### 数据范围

$-10^{9} \le a \le 10^{9}$ ，反转后的结果不会超出 `int` 范围。

## J a-b problem 但是分数

### 题目

#### 题目描述

给定两个分数 $\frac{a}{b}$ 和 $\frac{c}{d}$ ，求它们的差 $\frac{a}{b} - \frac{c}{d}$ 。若结果可以化成整数，就输出这个整数；否则把结果约分到最简分数后以 `p/q` 的形式输出。

#### 输入格式

第一行两个整数 $a$ 和 $b$ 。第二行两个整数 $c$ 和 $d$ 。

#### 输出格式

一行：结果为整数时输出该整数，否则输出形如 `p/q` 的最简分数。

#### 样例输入

```text
1 2
1 3
```

#### 样例输出

```text
1/6
```

#### 数据范围

分子可能是负数，枚举最大公约数时不能从两个数中较小的那个开始，否则会永远找不到结果；以分母为起点即可。
