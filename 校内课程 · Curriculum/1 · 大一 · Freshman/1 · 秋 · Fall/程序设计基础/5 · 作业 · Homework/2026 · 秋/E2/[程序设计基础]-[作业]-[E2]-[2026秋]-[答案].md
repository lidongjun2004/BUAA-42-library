FSY 最讨厌算数了！
现在她要求你帮她写一个程序，她给定你两个数 a,b，你需要算出 a+b,a-b,a × b, [ a/b ] 和 a mod b 的值。其中， [ x ] 表示小于等于 x 的最大的整数。a mod b 表示 a 除以 b 的余数。保证 a,b 都是 int 范围内的自然数。

#### 输入格式

#### 输出格式

特别的，如果 b=0，则 [ a/b ] 和 a mod b 两处都输出 Hello, FSY~。

```text
3
```

#### 输出样例 1

```text
8
2
15
1
2
```

#### 输入样例 2

```text
6
8
```

#### 输出样例 2

```text

```

#### 输入样例 3

```text
5

```

```text

FSY~
```

#### Hint

int 和 int 相加，结果可不一定是 int 哦。

### 答案

### 题目分析

只要知道加减乘除模分别是 `+,-,*,/,%` 问题就不大。

题目里说了，int 和 int 之间运算结果不一定是 int，因此计算机中的数都是有范围的，除了除法和取模，剩下三种运算理论上都是可以爆 int 的，解决方法就是开 long long。

### 示例代码

```c
#include <stdio.h>
int main(){
    int a, b;
    long long add, minus, times, div, mod;
    scanf("%d%d", &a, &b);
    add = 1ll * a + b;
    minus = 1ll * a - b;
    times = 1ll*a*b;
    if (b == 0) printf("%lld\n%lld\n%lld\nHello, FSY~\nHello, FSY~", add, minus, times);
    else{
        div = a / b;
        mod = a % b;
        printf("%lld\n%lld\n%lld\n%lld\n%lld", add, minus, times, div, mod);
    }
    return 0;
}
```

开 long long 有两种方法：

1. 直接把 $a, b$ 两个变量也设置为 long long，理论上这是最保险的方法。

1. 第二种就是需要的地方再进行强制类型转化，把 int 转化为 long long 也有两种方法：

   1. `(long long)a` 。比如 `(long long)a+b` 或者 `(long long)a*b` 。这样写好像也不怎么美观。

   1. 用 `1ll*` 转化， `1ll` 表示 long long 类型下的 $1$ ， `ll` 后缀表示类型为 long long。按照 C 的语法，long long 类型和 int 类型相运算（加减乘除模），结果返回 long long。这样 `1ll*a` 就返回了一直大小为 $a$ 但类型为 long long 的中间结果，实现了间接类型转化。这是最优美的方法。

#### 输入

```text

```

#### 输入样例 2

```text
More!Jump!More!Pastel*Palettes
```

```text
settelaP*letsaP!eroM!pmuJ!eroM
```

Author：LH132

### 答案

### 题目分析

题目要求把输入的字符串倒过来输出。例如，字符串 `abcde` 的最后一个字符是 `e` ，倒过来后它应该被第一个输出，因此只需要从字符串的末尾向开头遍历即可。

用字符数组 `s` 保存输入，用 `len` 记录已经读入了多少个字符。每次用 `scanf("%c", &c)` 读入一个字符：如果读到文件末尾或换行符，输入就结束；否则将它存入 `s[len]` ，再把 `len` 加 $1$ 。

读入完成后，最后一个字符保存在 `s[len - 1]` 中。因此从 `len - 1` 遍历到 $0$ ，依次输出 `s[i]` ，就能得到逆序后的结果。题目保证输入长度不超过 $10^5$ ，所以开一个大小为 `100005` 的字符数组足够使用。

设字符串长度为 $n$ ，时间复杂度为 $O(n)$ ，空间复杂度为 $O(n)$ 。

### 示例代码

```c
#include <stdio.h>
char s[100005];
int main()
{
    char c;
    int len = 0;

    while (scanf("%c", &c) != EOF && c != '\n')
    {
        s[len] = c;
        len++;
    }

    for (int i = len - 1; i >= 0; i--)
    {
        printf("%c", s[i]);
    }
    printf("\n");

    return 0;
}
```

## C 小天才的数字还原

| 难度 | 考点 |

| 2 | 浮点数输入输出、 sqrt 的嵌套调用、多组数据处理 |

### 题目

#### 题目背景

准备程设习题时，dxb 正拿着计算器试数。他输入了一个非负数，随后连续按了两次「平方」键。每按一次，计算器都会把当前的数乘以它自己。 muzermat 凑过来看了一眼：「结果记下来了，最开始输入的数呢？」 dxb 看了看屏幕，又看了看空白的草稿纸：「忘了。不过我记得，它是个非负数。」 muzermat 把草稿纸推了回去：「本来是让你出题，这下倒好，先给自己出了一道。」两位助教决定请你写一个程序，根据最后的结果还原最开始的数。

#### 题目描述

给定一个非负实数 a，求满足 x4 = a 的非负实数 x。

#### 输入

第一行一个整数 T，表示数据组数。
接下来 T 行，每行一个实数 a，表示连续两次平方后的结果。
对于全部数据，1 ≤ T ≤ 104，0 ≤ a ≤ 106。a 使用普通十进制表示，至多有 8 位小数。

#### 输出

对于每组数据，输出一行一个实数，表示对应的 x。
你的答案与正确答案的绝对误差不超过 10-6 时，即视为正确。建议保留至少 8 位小数。

#### 输入样例 1

```text
7
0
16
0.0625
2
81
0.00000001
1000000
```

#### 输出样例 1

```text
0.0000000000
2.0000000000
0.5000000000
1.1892071150
3.0000000000
0.0100000000
31.6227766017
```

#### 样例解释

样例 1：第二组中，2 第一次平方得到 4，第二次平方得到 16，所以答案为 2。第三组中，0.5 第一次平方得到 0.25，第二次平方得到 0.0625，所以答案为 0.5。

#### Hint

C 语言中，包含头文件 <math.h> 后，可以使用 sqrt(x) 计算非负实数 x 的平方根。后记 dxb 是一位长得十分帅气的程设助教，真的很帅气

Author: muzermat

### 答案

### 题目分析

已知 $x^4 = a$ 且 $x \ge 0$ ，两边先开一次平方，得到 $x^2 = \sqrt{a}$ ；再开一次平方，得到

$$
x = \sqrt{\sqrt{a}}.
$$

因此，连续调用两次 `sqrt` 即可求出答案。只开一次平方得到的是 $x^2$ ，还不是所求的 $x$ 。当 $a = 0$ 时，上式仍然成立，不需要单独处理。

使用 `double` 保存输入和结果，读入时使用 `%lf` ，输出时使用 `%.10f` 保留小数点后十位。本题中 $x$ 不超过 $\sqrt{1000}$ ，两次开平方均不会越过定义域或发生溢出， `double` 的计算精度足以满足误差要求。

每组数据的时间复杂度为 $O(1)$ ，处理全部数据的时间复杂度为 $O(T)$ ，额外空间复杂度为 $O(1)$ 。

### 示例代码

```c
#include <stdio.h>
#include <math.h>
int main() {
    int t;
    scanf("%d", &t);
    while (t--) {
        double a;
        scanf("%lf", &a);
        double ans = sqrt(sqrt(a));
        printf("%.10f\n", ans);
    }
    return 0;
}
```

## D 小火苗的减肥计划

| 难度 | 考点 |

| 2 | 模拟，浮点数计算 |

### 题目

#### 题目描述

小火苗最近在尝试减肥。
为了判断自己是不是真的瘦了，他记录了最近 n 次测量的身高和体重。对于每次记录，你需要计算他的 BMI，并与上一次记录的 BMI 进行比较，判断 BMI 是上升还是下降。设身高为 h 米、体重为 m 千克，则 BMI=m/h2 请使用双精度浮点数进行计算。

#### 输入

第一行包含一个整数 n， (1≤ n≤ 105) 。
接下来 n 行，每行包含两个浮点数 h,m，分别表示本次记录的身高（米）和体重（千克），0<h,m≤ 1 000 。输入数据均可用 double 正常表示，所有计算结果均在 double 的有效表示范围内。对于任意相邻两次记录，其 BMI 一定不相等，并且数据保证 double 可以正确区分二者的大小关系。

#### 输出

共输出 n 行。
第一行只输出第一次记录的 BMI。
对于第 i 次记录（2≤ i≤ n），输出本次记录的 BMI 和一个符号：
· 如果本次 BMI 大于上一次 BMI，输出 +；
· 如果本次 BMI 小于上一次 BMI，输出 -。
所有 BMI 在输出时均保留一位小数。考虑到double精度问题，评测时，BMI 数值允许有不超过 0.1 的绝对误差。 ---

#### 输入样例

```text
3
1.75 70
1.75 71.5
1.8 72
```

#### 输出样例

```text
22.9 23.3 + 22.2 -
```

#### 输入样例 2

```text
3
1 1.00000001
1 1.00000002
1 1.00000001
```

#### 输出样例 2

```text
1.0 1.0 + 1.0 -
```

#### Hint

你可能会注意到身高体重的数据范围包括一些荒谬的数值，你无需在意，按照题目要求计算即可。

Author: The__Flames

### 答案

### 题目分析

根据题意直接模拟即可。每次读取身高 (h) 和体重 (m)，利用公式 (BMI = \frac{m}{h^2}) 计算本次的 BMI。

对于第一条记录，直接输出 BMI 并保留一位小数。从第二条记录开始，需要和上一次的 BMI 进行比较：

- 如果本次 BMI 大于上一次，输出本次 BMI 和一个 `+` 号；

- 如果本次 BMI 小于上一次，输出本次 BMI 和一个 `-` 号。

题目保证了相邻两次记录的 BMI 一定不相等，所以不需要考虑相等的情况。输出时使用 `printf("%.1f", bmi)` 即可保留一位小数，符合题目允许的误差范围。

### 示例代码

```c
#include <stdio.h>
int main() {
    int n;
    scanf("%d", &n);

    double prev_bmi;
    for (int i = 0; i < n; i++) {
        double h, m;
        scanf("%lf %lf", &h, &m);
        double bmi = m / (h * h);

        if (i == 0) {
            printf("%.1f\n", bmi);
        } else {
            if (bmi > prev_bmi) {
                printf("%.1f +\n", bmi);
            } else {
                printf("%.1f -\n", bmi);
            }
        }
        prev_bmi = bmi;
    }
    return 0;
}
```

## E 第九乐章

| 难度 | 考点 |
| --- | --- |
| 3 | ascii 码 |

### 题目

#### 题目描述

Gino 获取了第九乐章的残卷，但上面全是难以理解的乱码。经过研究，他发现这些“乱码”实际上是密文，为了解密，只需要按照如下方式操作即可： · 字母表中的第 i 个字母替换为其对应大小写的倒数第 i 个字母。例如：A 应该被替换为 Z，y 应该被替换为 b · 其它字符保持原样请你帮他解密这段文字吧！

#### 输入

一行若干字符，仅由大小写字母和空格组成，字符数目 n 满足 1 ≤ n ≤ 1000。

#### 输出

解密后的文字

#### 输入样例

```text
Lmob Xszlh xzm hszggvi gsv nriztv
gszg koztfvh gsv rtmlizmg Ullo
```

#### 输出样例

```text
Only Chaos can shatter the mirage
that plagues the ignorant Fool
```

### 答案

### 题目分析

题目要求把每个字母换成字母表中与它首尾对称的那个字母（第一个换最后一个，第二个换倒数第二个……），其它字符原样保留。这种「首尾互换」的替换方式有个学名叫 Atbash 密码。

最容易想到的做法是打一张表： `a` 对 `z` 、 `b` 对 `y` ……但这要手写 $52$ 行映射，既麻烦又容易写错。其实字母在计算机里本来就是整数（也就是大家熟悉的 ASCII 码），因此对称字母完全可以用算术直接算出来，不用背表。

先看大写字母。 `'A'` 的 ASCII 码是 $65$ ， `'Z'` 是 $90$ 。 `'A'` 与 `'Z'` 关于中点对称，所以 `c` 的对称字母就是「 `'Z'` 减去二者之间的距离」，写成表达式就是

```c
'A' + 'Z' - c
```

小写字母完全同理，只是两端换成了 `'a'` 和 `'z'` ：

```c
'a' + 'z' - c
```

实现时注意三点：

1. **大小写要分开判断。** 题目要求不改变大小写，即大写只能映射到大写、小写只能映射到小写，不能用一个公式同时处理两个区间。

1. **只变换字母。** 空格等其它字符必须原样输出，所以要用 `if` / `else if` / `else` 把三种情况分清楚。

1. **输入里有空格**，所以不能用 `scanf("%s", s)` （它读到空格就停下），而要逐个字符读。用 `scanf("%c", &c)` 循环读到文件结束即可： `scanf` 在读到文件末尾时会返回 `EOF` ，把它作为循环条件， `%c` 连空格也一并读进来。

对每个读入的字符，大写走第一个公式、小写走第二个公式、其余直接输出，按顺序打印就得到了答案。

### 示例代码

```c
#include <stdio.h>
int main(void)
{
    char c;
    while (scanf("%c", &c) != EOF)
    {
        if ('A' <= c && c <= 'Z')
        {
            printf("%c", 'A' + 'Z' - c);
        }
        else if ('a' <= c && c <= 'z')
        {
            printf("%c", 'a' + 'z' - c);
        }
        else
        {
            printf("%c", c);
        }
    }
    return 0;
}
```

## F 快递分拣

| 难度 | 考点 |
| --- | --- |
| 3 | 取模、数组、循环 |

### 题目

#### 题目描述

快递分拣中心有 m 个桶，编号为 0 到 m-1。编号为 x 的快递应该放入编号为 x mod m 的桶中。请统计每个桶中的快递数量，并找出快递数量最多的桶。如果有多个桶的数量相同，输出编号最小的桶。

#### 输入

第一行，一个整数 T，表示数据组数。
对于每组数据：
第一行两个整数 n 和 m，分别表示快递数量和桶的数量。
第二行 n 个非负整数 x1,x2,...,xn，表示快递编号。

数据范围：

· 1≤T≤100；

- 1≤n≤1000，1≤m≤100；
- 0≤xi≤109。

#### 输出

对于每组数据输出两行。
第一行输出 m 个整数，依次表示编号为 0 到 m-1 的桶中的快递数量。
第二行输出两个整数，分别表示快递数量最多的桶的编号和其中的快递数量。数量相同时选择编号较小的桶。

#### 输入样例

```text
1
7 4 4 8 12 16 1 5 9
```

#### 输出样例

```text
4 3 0 0 0 4
```

#### 样例解释

编号为 4、8、12、16 的快递都进入 0 号桶，编号为 1、5、9 的快递都进入 1 号桶，因此四个桶中的数量分别为 4、3、0、0。数量最多的是 0 号桶。

#### Hint

可以用数组记录每个桶的数量，编号为 x 的快递对应 x mod m。x mod m 表示 x 除以 m 后的余数。注意数量相同时要选择编号较小的桶。

author:auining

### 答案

### 题目分析

快递编号 $x$ 除以桶数 $m$ 的余数，就是它应进入的桶号。用数组 `count` 保存每个桶中的快递数量，读到一个编号后执行 `count[x % m]++` 。

每组数据开始时都要把计数数组清零。统计完毕后，按桶号从小到大输出数量，再遍历一次数组找出最多的桶。让 `best` 从 $0$ 号桶开始，只在发现**严格更多**的快递时更新它；这样数量并列时，自然保留编号更小的桶。

例如样例中， $4$ 、 $8$ 、 $12$ 、 $16$ 除以 $4$ 的余数都是 $0$ ，所以 $0$ 号桶的数量为 $4$ 。

### 示例代码

```c
#include <stdio.h>
int main()
{
    int T;
    scanf("%d", &T);
    while (T--)
    {
        int n, m;
        int count[100] = {0}; // 每组数据重新计数
        scanf("%d%d", &n, &m);

        for (int i = 0; i < n; i++)
        {
            int x;
            scanf("%d", &x);
            count[x % m]++;
        }

        for (int i = 0; i < m; i++)
            printf("%d%c", count[i], i + 1 == m ? '\n' : ' ');

        int best = 0;
        for (int i = 1; i < m; i++)
        {
            if (count[i] > count[best]) // 相等时不更新，保留较小编号
                best = i;
        }
        printf("%d %d\n", best, count[best]);
    }
    return 0;
}
```

#### Hint

### 答案

### 题目分析

首先需要意识到，要让所有充电桩到中继器 $p$ 的距离之和 $\sum_{i=1}^{n} |x_i - p|$ 最小， $p$ 应该选在这些点的**中位数**位置。

由于输入的 $x_1, x_2 \ldots x_n$ 已经是从小到大排好序的，奇数个点时，我们直接取中间位置的数作为 $p$ 即可（即下标为 $n/2$ 的元素）。如果是偶数个点，选中间两个数任意一个作为 $p$ ，计算出的距离和都是相同的最小值，这里取偏右的 $n/2$ 。

确定 $p$ 后，直接遍历数组累加每个点到 $p$ 的绝对值即可。

数据范围 $n \le 10^5$ ， $x_i \le 10^5$ ，最大距离和可能达到 $10^{10}$ ，因此计算答案时需要使用 `long long` 防止溢出。

### 示例代码

```c
#include <stdio.h>
int x[100005];
int main()
{
    int n;
    scanf("%d", &n);

    for (int i = 0; i < n; i++)
    {
        scanf("%d", &x[i]);
    }

    int p = x[n / 2];
    long long ans = 0;

    for (int i = 0; i < n; i++)
    {
        if(x[i] > p)
            ans += (x[i] - p);
        else
            ans += (p - x[i]);
    }

    printf("%lld\n", ans);
    return 0;
}
```

当然你也可以使用1作为数组下标的起点，中位数下标可以取 $n/2 + 1$ 或者 $(n+1)/2$ 。

### 题目

#### 题目描述

#### 样例解释

#### Hint

例如，当 n=4、m=4 时，网格中各个格子的访问编号如下。访问编号从 1 开始，编号相邻的格子就是机器人连续访问的格子：

可以先把每个坐标转换为蛇形路径中的访问编号。正常相邻记录的编号相差 1，出现相差 2 的位置即可确定丢失的编号，最后再将编号转换回坐标。

### 答案

### 题目分析

先把每个格子的坐标换成机器人访问它的编号。设行号为 $r$ 、列号为 $c$ ，每行有 $m$ 个格子：

- 若 $r$ 为奇数，这一行从左到右访问，编号为 $(r - 1)m + c$ ；

- 若 $r$ 为偶数，这一行从右到左访问，编号为 $(r - 1)m + (m - c + 1)$ 。

原路径连续，因此相邻两条记录的访问编号通常相差 $1$ 。由于恰好丢失了一条中间记录，**只有跨过丢失位置的那一对记录相差 2**。找到这一对后，丢失编号就是前一条记录的编号加 $1$ 。这个方法在换行处同样成立：例如 $4 \times 4$ 的网格中， $(1,4)$ 的编号为 $4$ ，紧接着访问的 $(2,4)$ 编号为 $5$ 。

把丢失编号 `missing` 减去 $1$ ，得到从 $0$ 开始的偏移量 `offset` 。 `offset / m + 1` 是行号， `offset % m` 是该行内从访问起点数起的偏移。奇数行从左往右数，偶数行从右往左数，即可求出列号。

### 示例代码

```c
#include <stdio.h>
int main()
{
    int T;
    scanf("%d", &T);
    while (T--)
    {
        int n, m, q;
        scanf("%d%d%d", &n, &m, &q);

        int previous = 0;
        int missing = 0;
        for (int i = 0; i < q; i++)
        {
            int row, col, current;
            scanf("%d%d", &row, &col);
            if (row % 2 == 1)
                current = (row - 1) * m + col;
            else
                current = (row - 1) * m + (m - col + 1);

            if (i > 0 && current - previous == 2)
                missing = previous + 1; // 两条记录之间少了一个格子
            previous = current;
        }

        int offset = missing - 1;
        int row = offset / m + 1;
        int col;
        if (row % 2 == 1)
            col = offset % m + 1;
        else
            col = m - offset % m;

        printf("%d %d\n", row, col);
    }
    return 0;
}
```

### 答案

### 题目分析

首项和公差可以取任意整数，不能直接枚举它们的全部取值。换一个角度，枚举最终等差数列中两个没有被修改的位置。

首先证明至少能保留两个位置。任取原序列中相邻的两个数，它们的差是整数，因此以这两个数为相应位置，可以确定一个整数首项、整数公差的等差数列。修改其他位置即可得到代价至多 $n - 2$ 的方案。所以最优方案必定至少保留两个位置。

使用从 $0$ 开始的下标，假设位置 $i < j$ 都不修改，则

$$
d = \frac{a_j - a_i}{j - i}, \qquad b = a_i - id.
$$

题目要求公差为整数，因此只有 $a_j - a_i$ 能被 $j - i$ 整除时才产生合法候选。不要用浮点数判断整除；整数除法和取余即可完成，负差值也同样适用。

得到候选 $b, d$ 后，遍历全部位置。对于位置 $p$ ，它在目标数列中的值为 $b + pd$ ；如果与原来的 $a_p$ 不同，就必须修改这个位置。这样得到该候选的准确修改代价。按“修改数更少、首项更小、公差更小”的顺序更新答案。

因为最优方案至少保留两个位置，它一定会在某次枚举时被确定；每个候选又都是一个合法整数等差数列，因此枚举不会遗漏所需最优方案。两项择优规则给出的首项和公差确定后，整个答案也唯一。允许公差为零或负数，修改后的数不受输入数值范围限制。

位置对至多有 $n(n-1)/2$ 个，每个候选比较 $n$ 个位置，时间复杂度为 $O(n^3)$ ； $n \le 200$ 时最多约 $3.98 \times 10^6$ 次元素比较。数组空间复杂度为 $O(n)$ 。差值绝对值至多 $2 \times 10^6$ ，公差和候选项的计算使用 `long long` ，无需浮点数。

### 示例代码

```c
#include <stdio.h>

int main() {
    int n;
    long long a[200];
    scanf("%d", &n);
    for (int i = 0; i < n; i++) {
        scanf("%lld", &a[i]);
    }
    int best = n;
    long long best_b = 0, best_d = 0;
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
            long long diff = a[j] - a[i];
            if (diff % (j - i) == 0) {
                long long d = diff / (j - i);
                long long b = a[i] - i * d;
                int changes = 0;
                for (int pos = 0; pos < n; pos++) {
                    if (a[pos] != b + pos * d) {
                        changes++;
                    }
                }
                if (changes < best ||
                    (changes == best && (b < best_b ||
                    (b == best_b && d < best_d)))) {
                    best = changes;
                    best_b = b;
                    best_d = d;
                }
            }
        }
    }
    printf("%d %lld %lld\n", best, best_b, best_d);
    return 0;
}
```

### 题目分析

引理：删除的两个数一定是 $4p+1$ 和 $4q+2$ 。

证明：记 $n_r = \#\{a_i : 1 \le i \le 4m+2 \wedge i \bmod 4 = r\}$ 表示原下标模 $4$ 余数等于 $r$ 的数的数量。

考虑一个长度为 $4$ 的等差数列 $r, r+d, r+2d, r+3d$ 。若 $d \bmod 2 = 1$ ，那么这四个数恰好构成模 $4$ 剩余类；若 $d \bmod 4 = 2$ ，那么这四个数模 $4$ 得到的可重集一定是 $\{0,0,2,2\}$ 或 $\{1,1,3,3\}$ ；若 $d \bmod 4 = 0$ ，那么四个数模 $4$ 相等。由此可知，能被划分的序列一定有 $n_0 \equiv n_2,\ n_1 \equiv n_3 \pmod 4$ 。

然而未删除数字时 $n_0 = m,\ n_1 = m+1,\ n_2 = m+1,\ n_3 = m$ ，因此删除的两个数模 $4$ 必须为 $1, 2$ 。得证。

先判断 $i, j$ 是不是 $4p+1, 4q+2$ 的形式，若不是必定无解。否则对 $p, q$ 进行分类讨论：

$$

$$

容易可以构造划分：

$$
\begin{aligned}

&\cup \{(4k+3, 4k+4, 4k+5, 4k+6) : q \le k < m\}
\end{aligned}

$$
p \ge q + 2

记 $s = p - q \ge 2$ ，那么可以构造划分：

\begin{aligned}

p = q + 1

- 从 $T(q,r)$ ，末尾追加连续四个整数，即可构造出 $T(q,r+1)$ ；

- 从 $T(q,r)$ ，将所有 $x \mapsto 4q + 4r + 7 - x$ ，即可构造出 $T(r,q)$ 。

```c
                            a = 4 * q + t;
                        }
                    } else {
                        if (k >= m - suffix) {
                            a += 2;
                        } else if (k >= prefix) {
                            int t = off[type] + k - prefix;
                            a = 4 * prefix + ga[t];
                            d = gd[t];
                        }
                        if (reflected) a = 4 * m + 3 - (a + 3 * d);
                    }
                    printf("%d %d %d %d\n", a, a + d, a + 2 * d, a + 3 * d);
                }
            }
        }
    }
    return 0;
}
```
