## A 密码强度检测器

### 题目

#### 题目描述

娜娜 同学正在写一个“密码强度检测器”的小工具。一般来说，密码里用到的字符种类越多就越难被
猜到，所以娜娜 首先要统计一个密码里大写字母、小写字母、数字字符、其它字符各有多少个。
给定的密码字符串不含空白符，只由大写字母 A~Z、小写字母 a~z、数字 0~9 和可见的标点符号组成
。
其中可见标点符号的定义为： ASCII 码在 [33, 126] 区间，且不属于字母或数字的字符，如 , . ! ? \_ - @ # 等请你帮忙统计一下这四类字符的个数。

#### 输入

一行，一个字符串 s，保证不含空格等空白字符，长度 n 满足 1 ≤ n ≤ 1000，且只包含大小写英文字母、数字和可见标点符号。

#### 输出

一行，四个整数，用空格分隔，依次表示：

1. 大写字母的个数2. 小写字母的个数3. 数字字符的个数4. 其它字符（即既不是字母也不是数字的字符，例如标点符号）的个数

#### 输入样例

```text

```

#### 输出样例


#### 样例解释

NaNa2026,happy! 中：
· 大写字母有 N、N，共 2 个；

- 小写字母有 a、a、h、a、p、p、y，共 7 个；
- 数字有 2、0、2、6，共 4 个；
- 其它字符有 ,、!，共 2 个。

## B IPv6 Traffic Class

### 题目

#### 题目描述

HzL 在给 IPv6 的 QoS 网关写报文处理模块。IPv6 报文首部的前 4 字节是一个32位数字，转化为二进制后由三段构成：

字段 占用的二进制位 位数 取值范围

版本 第 31~28 位 4 0~15

流量类别 第 27~20 位 8 0~255

流标签 第 19~0 位 20 0~1048575

在实际 IPv6 协议中，并非所有取值范围内的值都能取到。但在此题中，我们认为所有取值范围内的值都有可能取到 IPv6 使用大端序，高位在前。例如 1803625285，写成二进制是 0110 1011 1000 0001 0010 0011 0100 0101 此时有： · 版本 = 0110 = 6 · 流量类别 = 1011 1000 = 184 · 流标签 = 0001 0010 0011 0100 0101 = 74565 现在 HzL 要对这样的32位数字 x 做两件事： 1. 拆包：解析三个字段，并以十进制输出；2. 重标记：将流量类别字段改写成新值 t，其余位保持不变。请你写一个程序帮 HzL 得到三个解析好的字段，以及重标记后的32位数字 newx。

#### 输入

第一行一个整数 T（1 ≤ T ≤ 105），表示上述部分报文首部的数量。接下来 T 行，每行两个整数 x 和 t，以一个空格分隔： · x 表示要处理的数字，以十进制给出， (0 ≤ x ≤ 4294967295)； · t 表示要替换的新值， (0 ≤ t ≤ 255)。

#### 输出

共 T 行，
每行包含四个十进制整数，以空格分隔，依次为版本、流量类别、流标签和修改后的 newx。

#### 输入样例

```text
3
1803625285 40
0 255
4294967295 0
```

#### 输出样例

```text
6 184 74565 1652630341
0 0 0 267386880
15 255 1048575 4027580415
```

#### 样例解释

第 1 组：x = 1803625285，二进制为 0110 1011 1000 0001 0010 0011 0100 0101。拆出三个字段： · 版本 = 0110 = 6， · 流量类别 = 1011 1000 = 184， · 流标签 = 0001 0010 0011 0100 0101 = 74565。要把流量类别改写成 t = 40（00101000），其余位保持不变，得到 newx = 0110 0010 1000 0001 001 0 0011 0100 0101 = 1652630341。

hint

当最高位为 1 时，newx 的值会超过 231-1，考虑使用 unsigned int 读入和输出，对应的格式说明符是 %u
