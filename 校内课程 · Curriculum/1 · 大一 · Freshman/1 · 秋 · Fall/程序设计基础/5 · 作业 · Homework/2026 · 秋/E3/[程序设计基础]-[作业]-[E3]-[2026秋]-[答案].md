## A 密码强度检测器

| 难度 | 考点 |
| --- | --- |
| 1 | 字符与 ASCII 码、分支、计数 |

### 题目

#### 题目描述

娜娜 同学正在写一个“密码强度检测器”的小工具。一般来说，密码里用到的字符种类越多就越难被
猜到，所以娜娜 首先要统计一个密码里大写字母、小写字母、数字字符、其它字符各有多少个。
给定的密码字符串不含空白符，只由大写字母 A~Z、小写字母 a~z、数字 0~9 和可见的标点符号组成
。
其中可见标点符号的定义为： ASCII 码在 [33, 126] 区间，且不属于字母或数字的字符，如 , . ! ? \_ - @ # 等请你帮忙统计一下这四类字符的个数。

#### 输入

一行，一个字符串 s，保证不含空格等空白字符，长度 n 满足 1 ≤ n ≤ 1000，且只包含大小写英文字母、数字和可见标点符号。

#### 输出

一行，四个整数，用空格分隔，依次表示：

1. 大写字母的个数2. 小写字母的个数3. 数字字符的个数4. 其它字符（即既不是字母也不是数字的字符，例如标点符号）的个数

#### 输入样例

```text
NaNa2026,happy!
```

#### 输出样例

```text
2 7 4 2
```

#### 样例解释

NaNa2026,happy! 中：
· 大写字母有 N、N，共 2 个；

- 小写字母有 a、a、h、a、p、p、y，共 7 个；
- 数字有 2、0、2、6，共 4 个；
- 其它字符有 ,、!，共 2 个。

### 答案

### 解题思路

此题是课件 P3 例 3-11 的简化版，解题思路也显而意见：从头到尾扫一遍字符串，看每个字符属于哪一类，给对应的计数器 +1 。

### 示例代码 1

```c
#include <stdio.h>

int main()
{
    char s[1005];
    int upper = 0, lower = 0, digit = 0, other = 0; // 记得初始化计数变量为0
    /*
    因为题目标明s不含空白符，所以可以直接用scanf("%s", s)读入字符串
    也可以像PPT中写成while(scanf("%c", &ch) != EOF)或while ((ch = getchar()) != EOF)
    */
    scanf("%s", s);
    for (int i = 0; s[i] != '\0'; i++)
    {
        if (ch >= 'A' && ch <= 'Z') upper++;
        else if (ch >= 'a' && ch <= 'z') lower++;
        else if (ch >= '0' && ch <= '9') digit++;
        else other++;
    }
    printf("%d %d %d %d\n", upper, lower, digit, other);
    return 0;
}
```

By the way, 头文件 `<ctype.h>` 存有**字符分类、字符大小写转换**的库函数。
巧用库函数，可以减少代码量并规避一些错误，同学们可以多多了解常用的库函数。

## B IPv6 Traffic Class

| 难度 | 考点 |
| --- | --- |
| 2 | 位运算、无符号整数 |

### 题目

#### 题目描述

HzL 在给 IPv6 的 QoS 网关写报文处理模块。IPv6 报文首部的前 4 字节是一个32位数字，转化为二进制后由三段构成：

字段 占用的二进制位 位数 取值范围

版本 第 31~28 位 4 0~15

流量类别 第 27~20 位 8 0~255

流标签 第 19~0 位 20 0~1048575

在实际 IPv6 协议中，并非所有取值范围内的值都能取到。但在此题中，我们认为所有取值范围内的值都有可能取到 IPv6 使用大端序，高位在前。例如 1803625285，写成二进制是 0110 1011 1000 0001 0010 0011 0100 0101 此时有： · 版本 = 0110 = 6 · 流量类别 = 1011 1000 = 184 · 流标签 = 0001 0010 0011 0100 0101 = 74565 现在 HzL 要对这样的32位数字 x 做两件事： 1. 拆包：解析三个字段，并以十进制输出；2. 重标记：将流量类别字段改写成新值 t，其余位保持不变。请你写一个程序帮 HzL 得到三个解析好的字段，以及重标记后的32位数字 newx。

#### 输入

第一行一个整数 T（1 ≤ T ≤ 105），表示上述部分报文首部的数量。接下来 T 行，每行两个整数 x 和 t，以一个空格分隔： · x 表示要处理的数字，以十进制给出， (0 ≤ x ≤ 4294967295)； · t 表示要替换的新值， (0 ≤ t ≤ 255)。

#### 输出

共 T 行，
每行包含四个十进制整数，以空格分隔，依次为版本、流量类别、流标签和修改后的 newx。

#### 输入样例

```text
3
1803625285 40
0 255
4294967295 0
```

#### 输出样例

```text
6 184 74565 1652630341
0 0 0 267386880
15 255 1048575 4027580415
```

#### 样例解释

第 1 组：x = 1803625285，二进制为 0110 1011 1000 0001 0010 0011 0100 0101。拆出三个字段： · 版本 = 0110 = 6， · 流量类别 = 1011 1000 = 184， · 流标签 = 0001 0010 0011 0100 0101 = 74565。要把流量类别改写成 t = 40（00101000），其余位保持不变，得到 newx = 0110 0010 1000 0001 001 0 0011 0100 0101 = 1652630341。

hint

当最高位为 1 时，newx 的值会超过 231-1，考虑使用 unsigned int 读入和输出，对应的格式说明符是 %u

### 答案

### 解题思路

这道题涉及两个步骤：按位段拆出三个字段，再把 流量类别 这 $8$ 位改成新值 $t$ 。

拆解字段就是要取一段连续的二进制位，可以分两步：
（1） **右移**，把目标位段挪到最低位；
（2）**与掩码**，掩码是「低 $k$ 位全 $1$ ，其余位全 $0$ 」的数，将右移后的数与掩码与起来，即可把需要的位段以外的高位清掉。

`0xFFu` 是无符号整数常量的十六进制写法， `0x` 开头表示该整数以十六进制来书写。掩码写成十六进制，是因为一位十六进制数字正好对应 $4$ 位二进制： `0xF` = `1111` = $15$ ， `0xFF` = `11111111` = $255$ ， `0xFFFFF` 就是 $20$ 位全 $1$ 。所以数一数 `F` 的个数就能知道掩码有多宽。结尾的 `u` 是表示无符号的后缀，写 `0xFFu` 、 `0xFFFFFu` 就是在告诉编译器这个字面量按 `unsigned int` 参与运算，不带 `u` 时默认会按 `int` 类型参与运算。

改指定位置的值用的是「先清零、再置位」的思路：先用 `0xFFu << 20` 构造出正好盖住流量类别这 $8$ 位的掩码（ `0x0FF00000` ），取反得到 `0xF00FFFFF` ，它与 $x$ 相与便只把那 $8$ 位清成 $0$ 、其余位不动；再把 $t$ 左移 $20$ 位挪到流量类别的位置上或进去，即 `newx = (x & ~(0xFFu << 20)) | (t << 20)` 。

由于 $x$ 最大可能达到 $4294967295$ ，超出了 `int` 的上限 $2^{31} - 1$ ，应该使用 `unsigned int` 类型存储变量。

### 示例代码

```c
#include <stdio.h>

int main()
{
    int T;
    scanf("%d", &T);
    while (T--) {
        unsigned int x, t;
        scanf("%u%u", &x, &t);

        /* 拆包：先右移到该位段的最低位，再用掩码取位段本身 */
        unsigned int version = (x >> 28) & 0xFu;         /* 第 31~28 位 */
        unsigned int tclass   = (x >> 20) & 0xFFu;       /* 第 27~20 位 */
        unsigned int flow     =   x        & 0xFFFFFu;   /* 第 19~ 0 位 */
        /* 先把原流量类别的 8 位清零，再或上新值 */
        unsigned int newx = (x & ~(0xFFu << 20)) | (t << 20);

        printf("%u %u %u %u\n", version, tclass, flow, newx);
    }
    return 0;
}
```

## C AT赛

### 题目

#### 题目背景

FlyCatcher 正在测试她新设计的“纸飞机导弹”。这枚导弹不会拐弯，只会沿着一条直线向前飞行；不过它飞得够快，理论上还是有机会追上 Osprey Navy Issue。 Osprey Navy Issue 一开始位于导弹前方，并且也会沿直线匀速移动。它可能继续向前逃跑，也可能掉头朝导弹开来。现在已知导弹和 Osprey Navy Issue 的速度，以及导弹最多能飞行的时间。请判断：在导弹飞行结束前或结束时，它能否碰到 Osprey Navy Issue。

#### 题目描述

建立一条数轴：
· 导弹从位置 0 出发，始终沿正方向飞行；
· Osprey Navy Issue 初始位于位置 d，其中 d>0；
· 导弹的速度为 v；
· Osprey Navy Issue 的速度为 vt；
· 导弹最多飞行 t 个时间单位。
其中，Osprey Navy Issue 的速度 vt 可以为负数：
· vt>0：它和导弹同向移动；
· vt=0：它停在原地；
· vt<0：它朝导弹方向移动。
若存在某个时刻 x，满足 0≤ x≤ t，且导弹与 Osprey Navy Issue 的位置相同，则认为导弹成功命中目标。请输出导弹能否命中目标。

#### 输入

第一行输入一个整数 T，表示测试数据组数。
接下来 T 行，每行输入四个整数 v , t,d, vt，分别表示导弹速度、导弹最大飞行时间、目标初始位置和目标速度。保证： 1≤ T≤10 对于每组测试数据： 1≤ v,t,d≤106 -106≤ vt≤106

#### 输出

对于每组测试数据，输出一行结果。
如果导弹能在飞行结束前或结束时命中目标，输出 Hit，否则输出 Miss。

#### 输入样例

```text
3
10 5 30 4
5 3 20 5
6 2 20 -5
```

#### 输出样例

```text
Hit
Miss
Hit
```

### 答案

### 解题思路

这是一个追及问题。

导弹和目标的初始距离为 `d` ，导弹相对于目标的速度为：

```c
vm - vt
```

只有当 `vm > vt` 时，导弹才有可能追上目标。追上目标所需的时间满足：

```c
(vm - vt) * x = d
```

导弹最多飞行 `t` 个时间单位，因此只需要判断：

```c
(vm - vt) * t >= d
```

如果成立则输出 `Hit` ，否则输出 `Miss` 。

### 注意事项

虽然输入数据最大只有 `10^6` ，但乘法结果最大可能达到： $(10^6 - (-10^6)) * 10^6 = 2 * 10^{12}$

这个结果超出了 `int` 的范围，所以相关变量必须使用 `long long` 。

### 示例代码

```c
#include <stdio.h>

int main(void) {
    int n;
    scanf("%d", &n);

    while (n--) {
        long long vm, t, d, vt;
        scanf("%lld%lld%lld%lld", &vm, &t, &d, &vt);

        if (vm > vt && (vm - vt) * t >= d) {
            printf("Hit\n");
        } else {
            printf("Miss\n");
        }
    }

    return 0;
}
```


#### 样例输出

```text
00000000000000000000000000000000 00000000000000000000000000000000 00000000000000000000000000
000000
00000000000000000000000001111011 00000000000000000000000001111011 00000000000000000000000001
111011
10111011100000000000000000000001 11000100011111111111111111111110 11000100011111111111111111

```

#### Hint

输入保证 -231<x<231，因此不需要考虑 x=-231 的情况，此时 x 在 32 位二进制表示下不存在原码和反码。

Author: WinResearcher

### 答案

### 解题思路

这三问中，最简单的是补码。因为整数在计算机中本来就以补码存储，所以直接从高到低输出 $x$ 的每一个二进制位即可，可参考 T 赛的 P 题。这里我们使用 `(x>>i)&1` 取出 $x$ 的第 $i$ 位。

原码和反码可通过定义求出。如果 $x \ge 0$ ，则 $x$ 的原码、反码均和补码相同。如果 $x < 0$ ，则 $x$ 的原码为符号位 $1$ 跟着 $|x|$ 的二进制表示， $x$ 的反码为 $|x|$ 的原码取反后的结果。只需求出 $|x| = -x$ ，然后按需输出其二进制位即可。可参考课件第一节。

取 $x$ 的二进制位时，尽管 `x>>i&1` 也是正确的，但我们推荐同学们写成 `(x>>i)&1` ，在位运算表达式里多使用括号，以避免意料外的优先级问题。

### 示例代码

```c
#include<stdio.h>

int T,x;
int main(){
    scanf("%d",&T);
    while(T--){
        scanf("%d",&x);
        if(x>=0){
            for(int k=1;k<=3;k++){
                for(int i=31;i>=0;i--){//原码、反码均与补码相同
                    printf("%d",(x>>i)&1);
                }
                printf("\n");
            }
        }else{
            int y=-x; //y = |x|

            //原码
            printf("1");
            for(int i=30;i>=0;i--){
                printf("%d",(y>>i)&1);
            }
            printf("\n");

            //反码
            for(int i=31;i>=0;i--){
                if((y>>i)&1) printf("0");
                else printf("1");
            }
            printf("\n");

            //补码
            for(int i=31;i>=0;i--){
                printf("%d",(x>>i)&1);
            }
            printf("\n");
        }
    }
}
```

## E 二进制回文

| 难度 | 考点 |

### 题目

#### 题目描述

给你一个 32 位无符号整数 n ，你需要判断其 32 位二进制表示是否是回文的。一个序列被称为回文的，当且仅当这个序列翻转后（或从后往前读）仍与原来保持一致。

#### 输入

第一行为一个正整数 Tspace (1 ≤ T ≤ 105) ，表示数据组数。对于每组数据，输入一行一个整数 n ，保证是一个 32 位无符号整数。

#### 输出

对于每组数据，输出一行，如果其 32 位二进制表示是回文的，则输出 YES ，否则输出 NO 。

#### 输入样例

```text
2
1
4294967295
```

#### 输出样例

```text
NO
YES
```

#### Hint

对于 32 位无符号整数，可以使用 unsigned int 定义，输入输出占位符使用 %u 。

author: 只只小木条

### 答案

### 解题思路

对于一个 $32$ 位二进制数，只要判断它的第 $i$ 位和第 $32 - i + 1$ 位是否都相同，就可以判断是否是一个回文数。

具体而言，通过 `(n>>i)&1` 来取出第 $32 - i$ 位，通过 `(n>>(31-i))&1` 来取出第 $i + 1$ 位，判断是否相同即可。

当且仅当第 $1$ 至 $16$ 位分别与第 $32$ 至 $17$ 位相同时为回文数。有任何一位不同都不是。

### 示例代码

```c
#include<stdio.h>
int main(){
    int T;
    scanf("%d",&T);
    while(T--){
        unsigned int n;
        int flag=1;
        scanf("%u",&n);
        for (int i=0;i<16;i++){
            unsigned int l=(n>>i)&1;
            unsigned int r=(n>>(31-i))&1;
            if(l!=r){
                flag=0;
                break;
            }
        }
        if(flag) puts("YES");
        else puts("NO");
    }
    return 0;
}
```

## F rex

### 题目

mathbb{R}∈ X LUNATiCA

#### 题目描述

给定一个整数 n 和一个长度为 2n 的整数序列 f0,f1,…,f2^n-1。
对于每个 0≤ S<2n，定义
gS=∑T包含于 S fT.
这里 T包含于 S 表示：T 的二进制表示中所有为 1 的位置，在 S 的二进制表示中也均为 1。请你求出 g0,g1,…,g2^n-1。

#### 输入

第一行，一个正整数 n，满足 1≤ n≤ 13。
第二行，包含 $2^n$ 个非负整数 $f_0,f_1,…,f_{2^n-1}$，满足 0≤ fi≤ 109。

#### 输出

输出一行 2n 个整数，依次表示 g0,g1,…,g2^n-1，相邻两个整数之间用一个空格分隔。

#### 输入样例 1

```text
3
1 2 3
4 5 6
7 8
```

#### 输出样例 1

```text
3 4 10 6 14 16 36
```

#### 样例解释

例如，当 S=3 时，3 的二进制表示为 011。它的子集为 0,1,2,3，因此 g3=f0+f1+f2+f3=1+2+3+4=10.

### 答案

### 解题思路 1： $O(4^n)$ 做法

本题有三种解法，这里按照复杂度从高到低的顺序说明。

先枚举 $S$ ，再枚举 $T$ ，判断是否有 $T \subseteq S$ 。如果是的话就执行 `g[S] += f[T]` 。

至于如何判断 $T \subseteq S$ ，可以使用这样的位运算判断： `(T | S) == S` 。证明考虑对于每一位去看，如果出现了 $T_i = 1, S_i = 0$ 的情况，那么这个式子显然不成立，也就是说不可能出现 $T$ 里面有的元素 $S$ 里面没有，也即 $T \subseteq S$ 。

#### 示例代码 1

```c
#include <stdio.h>

#define MAXM (1 << 13)

typedef long long ll;

ll f[MAXM], g[MAXM];

int main()
{
    int n, m;
    scanf("%d", &n);

    m = 1 << n;

    for(int i = 0; i < m; i ++ )
        scanf("%lld", &f[i]);

    for(int s = 0; s < m; s ++ )
    {
        for(int t = 0; t < m; t ++ )
        {
            if((t & s) == t)
                g[s] += f[t];
        }
    }

    for(int i = 0; i < m; i ++ )
        printf("%lld ", g[i]);

    return 0;
}
```

### 解题思路 2： $O(3^n)$ 做法

我们发现复杂度瓶颈在于会枚举到很多没用的 $T$ ，有没有快速的办法遍历 $S$ 的所有子集，然后直接求和呢？

有的，使用这样的代码就可以遍历到 $S$ 的所有子集：

```c
int T = S;
while(T)
{
    /*
    do something
    */
    T = (T - 1) & S;
}
```

证明如下（难度较大，可略过）：

初始时 $T = S$ ，显然 $T$ 是 $S$ 的子集。

假设当前 $T$ 是 $S$ 的子集。更新后有

$$
T' = (T - 1) \& S.
$$

由于按位与运算不会产生 $S$ 中不存在的二进制 $1$ ，因此 $T' \& S = T'$ ，即 $T'$ 仍是 $S$ 的子集。

由数学归纳法可知，算法产生的所有 $T$ 均为 $S$ 的合法子集。

设当前 $T > 0$ ，其最低位的 $1$ 位于第 $k$ 位。

执行 $T - 1$ 后：

- 第 $k$ 位从 $1$ 变为 $0$ ；

- 第 $k$ 位以下的所有位从 $0$ 变为 $1$ ；

- 第 $k$ 位以上的所有位保持不变。

因此 $T - 1 < T$ 。由于按位与 $S$ 只可能清除二进制中的 $1$ ，不会使整数增大，所以

$$
T' = (T - 1) \& S \le T - 1 < T.
$$

故算法产生的子集编号严格递减，不会重复。

下面证明 $T'$ 是所有严格小于 $T$ 的合法子集中最大的一个。

设 $T$ 的最低位 $1$ 位于第 $k$ 位。由于 $T$ 是 $S$ 的子集，因此 $S$ 的第 $k$ 位也必然为 $1$ 。

更新 $T' = (T - 1) \& S$ 后：

- 高于第 $k$ 位的部分与 $T$ 完全相同；

- 第 $k$ 位变为 $0$ ；

- 低于第 $k$ 位的部分保留 $S$ 中所有的 $1$ 。

考虑任意合法子集 $U \subseteq S$ ，满足 $U < T$ 。

若 $U$ 与 $T$ 在第 $k$ 位以上存在不同，则在最高的不同位上， $U$ 必然为 $0$ ，而 $T$ 为 $1$ 。由于 $T'$ 与 $T$ 的高位相同，因此 $U < T'$ 。

否则， $U$ 与 $T$ 在第 $k$ 位以上完全相同。由于 $U < T$ ，且 $T$ 的低 $k$ 位全部为 $0$ ，因此 $U$ 的第 $k$ 位必然为 $0$ 。

在此条件下，为使 $U$ 尽可能大，应当将低 $k$ 位中所有属于 $S$ 的位均置为 $1$ 。这恰好得到 $T'$ 。

因此，对任意满足 $U \subseteq S$ 且 $U < T$ 的整数 $U$ ，都有 $U \le T'$ 。

又因为 $T'$ 本身是合法子集且 $T' < T$ ，所以 $T'$ 正是严格小于 $T$ 的最大合法子集。

这说明每次更新都恰好转移到下一个合法子集，不会遗漏任何子集。

证毕。

因为每个元素在枚举的过程中都会有三种状态：同时在 $S$ 和 $T$ 里、在 $S$ 里不在 $T$ 里、都不在，因此虽然有两层循环，但是总复杂度为 $O(3^n)$ 。

### 解题思路 3： $O(n2^n)$ 做法

这个做法难度非常大。

首先我们通过之前的题目知道了前缀和（也即数列前 $n$ 项和）的概念： $s_n = \sum_{i=1}^{n} a_i$ ，如果我们把数列扩展成一个二维矩阵，我们也可以定义前缀和为：

$$
s_{n,m} = \sum_{i=1}^{n}\sum_{j=1}^{m} a_{i,j}
$$

二维前缀和的求法有两种：一种使用容斥原理，利用 $s_{n,m} = a_{n,m} + s_{n-1,m} + s_{n,m-1} - s_{n-1,m-1}$ 来求，还有一种做法是先对第一维求出前缀和：

$$
s'_{n,m} = \sum_{i=1}^{n} a_{i,m}
$$

然后再对第二维求前缀和：

$$
s_{n,m} = \sum_{j=1}^{m} s'_{n,j} = \sum_{j=1}^{m}\sum_{i=1}^{n} a_{i,j}
$$

有了二维的情况，也就可以扩展到一个 $n$ 维空间的前缀和。但是这和本题有什么关系呢？

我们可以把一个 $n$ 位二进制数看作一个 $n$ 维空间的坐标，每一维的值域是 $\{0, 1\}$ 。而子集的关系 $T \subseteq S$ 也就等价于：对于二进制下每一位来说，都满足 $T_i \le S_i$ 。于是我们对于每一维做一遍前缀和即可。

#### 示例代码 3

```c
#include <stdio.h>

#define MAXM (1 << 13)

typedef long long ll;

ll g[MAXM];

int main()
{
    int n, m;
    scanf("%d", &n);

    m = 1 << n;

    for(int i = 0; i < m; i ++ )
        scanf("%lld", &g[i]);

    for(int i = 0; i < n; i ++ )
    {
        for(int s = 0; s < m; s ++ )
        {
            if(s & (1 << i))
                g[s] += g[s ^ (1 << i)];
        }
    }

    for(int i = 0; i < m; i ++ )
        printf("%lld ", g[i]);

    return 0;
}
```

### 答案

### 解题思路

枚举每个空位，分别假设 istina 或电脑在这里落子，判断是否会出现连续五子。

设：

- `A` ：istina 能立即获胜的空位数量；

- `B` ：电脑能立即获胜的空位数量。

如果 `B > 0` ，电脑可以直接获胜，答案为 `NO` 。

如果 `A < 2` ，电脑可以堵住 istina 的全部获胜位置，答案也为 `NO` 。

只有 `B == 0` 且 `A >= 2` 时，答案为 `YES` 。

判断位置 `p` 是否获胜时，从 `p` 向左、向右分别统计连续的同色棋子，再加上 `p` 本身。总数不少于 `5` 就算获胜。

### 示例代码

```c
#include <stdio.h>

int n, cntA, cntB;
int a[1005];

int main() {
    scanf("%d", &n);
    for (int i = 1; i <= n; i++) scanf("%d", &a[i]);
    for (int i = 1; i <= n; i++) {
        if (a[i] != 0) continue;
        int L = 0, R = 0;
        while (i - L - 1 >= 1 && a[i - L - 1] == 1) L++;
        while (i + R + 1 <= n && a[i + R + 1] == 1) R++;
        if (L + R + 1 >= 5) cntA++;
        L = 0, R = 0;
        while (i - L - 1 >= 1 && a[i - L - 1] == 2) L++;
        while (i + R + 1 <= n && a[i + R + 1] == 2) R++;
        if (L + R + 1 >= 5) cntB++;
    }
    if (cntB != 0) printf("NO\n");
    else {
        if (cntA > 1) printf("YES\n");
        else printf("NO\n");
    }
}
```

### 解题思路

#### 逻辑简化

读完题目之后大家可能会感觉到：其实 $4$ 个 $op$ 的差别并不大，背后也许有一个统一的逻辑。

我们可以先用一段类似这样的代码处理 $4$ 个 $op$ ：

```c
// 这些是待会儿会用到的神秘妙妙工具
int dir; // dir 代表方向 direction
if (op <= 2) {// op = 1, 2 时
    dir = 1;    // 移动方向向右
} else {          // op = 3, 4 时
    dir = -1; // 移动方向向左
}
char c0, c1;      // 两种字符，其中 c0 为终止字符，c1 为另一种字符
if (op & 1) { // op 为奇数时
    c0 = 'N'; // 终止字符为 'N'
    c1 = 'H';
} else {          // op 为偶数时
    c0 = 'H'; // 终止字符为 'H'
    c1 = 'N';
}
// 在 dir 方向上，以 c0 为终止字符进行 k 次过程
```

这样就解耦了 $op$ ，后面只需要对着 `dir` `c0` 等进行代码编写即可。

#### 朴素处理

有很多同学会自然地模拟 $k$ 次过程，写出类似这样的代码：

```c
// 在 dir 方向上，以 c0 为终止字符进行 k 次过程
for(long long i = 1; i <= k; ++i) {
    int cur = p;
    while(1 <= cur && cur <= n   // 在 1~n 之间，不能越界
    && s[cur] != c0) {           // 当前位置不是终止字符
        s[cur] = c0;             // 翻转当前位置字符
        cur += dir;              // 向对应方向移动 1 个位置
    }
    if (1 <= cur && cur <= n) { // 退出 while 时 cur 还在 1~n 之间，也就是遇到了终止字符
        s[cur] = c1;           // 翻转当前位置字符，过程结束
    }
    // else                      // 退出 while 时 cur 越界了，此时不用进行任何处理，过程结束
}
```

但是这样大概率会喜提 TLE，原因在于 $k$ 的数据范围： $0 \le k_i \le 10^{18}$ 。

我们需要一个更快的办法，最好能把 $k$ 次过程一起执行了，但是应该怎么实现呢……

#### 关键观察

回看题目提示， `Urara` 让我们找一找位运算在哪。

纸条上只有两种字符 `N` 和 `H` ，确实有点像二进制只有两个数码 `0` 和 `1` 。

那么「位」姑且算是找到了，剩下的对这些位的操作应该就是「运算」了。

以终止字符为 `H` 为例，一次过程就是把 `HNN...NN` 变成 `NHH...HH` 。

🤔

再比如，观察样例的第 $5$ 次操作 `4 4 3` ，我们忽略在此次操作中不受影响的位置 $5$ ，观察 $3$ 次过程前后的 $4$ 个状态：

- `HHNN`

- `HNHH`

- `HNHN`

- `HNNH`

🤔

🤓☝️ 俺寻思这个就像每次过程 $+1$ ，你看：

- `HHNN` $\rightarrow (0011)_2$

- `HNHH` $\rightarrow (0100)_2$

- `HNHN` $\rightarrow (0101)_2$

- `HNNH` $\rightarrow (0110)_2$

每次过程就像是在给这个数 $+1$ ，如果把终止字符视为 $0$ ，另一个字符视为 $1$ ，那么一次过程就是在进行 $(011\ldots11)_2 \xrightarrow{+1} (100\ldots00)_2$ 。

所以 $k$ 次过程就是在这个数上 $+k$ ，如 $(0011)_2 \xrightarrow{+3} (0110)_2$ 。

因此，我们似乎确实能把 $k$ 次过程一起执行了。

#### 优化处理

在正式开始写代码之前，我们还需要考虑一些细节：

- 越界怎么办？

  - 直接把多余的位舍弃就好了，参见样例第 $4$ 次操作。

- 应该选用什么数据类型？

  - $k$ 的上界高达 $10^{18}$ ，必须使用 `long long` 。

- 我们应该如何实现加法？

  - 采用类似竖式的方式模拟，一位一位地处理加法和进位。

```c
while(1 <= p && p <= n        // 在 1~n 之间，不能越界
&& k != 0) {                  // 还需要进行加法（k=0 时后续无需进行加法，此条件忽略亦可）
    int sum = 0;              // 考虑当前位上 s 和 k 的加法
    if (s[p] == c1) {         // 当前位置不是终止字符
        sum = 1;              // 视为 1
    }
    // else                   // 当前位置是终止字符，视为 0，但对 sum 的值无影响
    sum += k & 1;             // k 的当前位
    k = k >> 1;               // k 舍弃当前位，准备考虑下一位，也可写作 k >>= 1
    if (sum == 0) {           // 0+0
        s[p] = c0;            // 当前位的新值为 0，对应终止字符
    } else if (sum == 1) {    // 0+1 或 1+0
        s[p] = c1;            // 当前位的新值为 1，对应非终止字符
    } else {                  // 1+1
        k++;                  // 出现进位，需要记录在下一位
        s[p] = c0;            // 当前位的新值为 0，对应终止字符
    }
    p += dir;                 // 向对应方向移动 1 个位置
}
```

当然，我们也可以不用新建 `sum` 这个变量，直接在 `k` 上修改，示例代码中就采用了这种写法，大家可以对比学习。

#### 题目描述

小火苗很喜欢收集带有不同颜色的木棍，但是“事不过三”，因此每一种木棍他都想要收集3个。但是有时候小火苗会忘记自己收集过什么颜色的木棍，那样他就会再收集3个，导致一种颜色的木棍可能会有3个、6个、9个...也就是3的倍数个。然而，昨天晚上，小火苗梦见一只伪装成木棍的，颜色不明的毛毛虫钻进了他收集的木棍里... 被吓醒之后，他开始把所有木棍倒出来，仔细地排查每个木棍的颜色，试图找出其中的毛毛虫或是确认没有毛毛虫。你能帮帮他吗？

#### 输入

第一行一个整数为木棍根数 n，1 ≤ n ≤ 106 。
第二行n个整数 a1,a2...an，1≤ a1,a2...an≤ 109。ai 表示第 i 根木棍的颜色代号。不同的颜色代号指代不同的颜色，毛毛虫的颜色可能与某几根木棍相同。

#### 输出

一行一个整数 s，表示可能存在的毛毛虫的颜色代号，若不存在毛毛虫输出-1。

#### 输入样例

```text
4
5
5
7
5
```

#### 输出样例

```text
7
```

#### 输入样例 2

```text
6
4
4
4
8
8
8
```

#### 输出样例 2

```text
-1
Author:The__Flames
出题人自从被树上掉下来的毛毛虫砸到之后，已经应激两周了...
```

### 答案

### 解题思路

首先需要意识到，正常情况下每种颜色的木棍数量都是 3 的倍数。如果有一只毛毛虫混入，那么它对应的颜色会多出现一次，即出现次数为 $3k + 1$ 。

本题空间限制为 **3072 KB** ，而 $n \le 10^6$ ，保存全部颜色的 `int` 数组就需要约 3906 KB，因此不能使用保存数组后排序统计的做法。我们可以边读取颜色，边统计每个二进制位上出现了多少个 1。

对于某个二进制位，一种正常颜色如果在这一位上是 1，那么它对计数的贡献就是其出现次数，也就是 3 的倍数；如果这一位是 0，贡献就是 0。因此，**将这一位上 1 的总数对 3 取模，就能消去所有正常木棍的贡献，只留下毛毛虫在这一位上的值。**

例如，输入中有三个 5 和一个 7。5 的二进制是 `101` ，7 的二进制是 `111` ，从低位到高位，三个位置上 1 的数量分别为 4、1、4。对 3 取模后都为 1，还原得到 `111` ，即毛毛虫的颜色 7。

由于 $a_i \le 10^9 < 2^{30}$ ，只需统计第 0 位到第 29 位。读取每个颜色 `x` 时，使用 `(x >> b) & 1u` 取出第 `b` 位并累加。最后，如果某一位的计数除以 3 余 1，就使用 `ans |= 1u << b` 将答案的对应位设为 1。

如果没有毛毛虫，每一位的计数都是 3 的倍数，还原出的答案为 0。题目保证颜色代号至少为 1，所以答案为 0 时输出 `-1` 即可。这里不能直接异或全部颜色，因为异或只能消去出现偶数次的数，而 $x \oplus x \oplus x = x$ ，出现三次的正常颜色不会被消去。

每个颜色处理 30 个二进制位，时间复杂度为 $O(30n)$ ，额外空间只需一个长度为 30 的计数数组，为 $O(1)$ 。每一位的计数最多为 $10^6$ ，使用 `int` 足够。

此外，还有一种做法是模拟二进制的异或，实现一种三进制的不进位加法，将所有颜色相加结果即是答案，该方法的原理和实现同学们可以自行思考。

### 示例代码

```c
#include <stdio.h>

int main()
{
    int n;
    scanf("%d", &n);

    int count[30] = {0};
    int ans = 0;

    for (int i = 0; i < n; i++)
    {
        int x;
        scanf("%d", &x);

        for (int b = 0; b < 30; b++)
        {
            count[b] += (x >> b) & 1;
        }
    }

    for (int b = 0; b < 30; b++)
    {
        if (count[b] % 3 == 1)
        {
            ans |= 1 << b;
        }
    }

    if (ans == 0)
        printf("-1\n");
    else
        printf("%d\n", ans);

    return 0;
}
```

### 题目

不——但她如此想到。
不可能是她想的那样。这不可能便是事实——她只需要在另一端相信，便足够了，这便足够了。即使这再荒唐，Arcaea也会听见。心愿，即使埋在心中，从未说出口，也足够了…… 本为一体的两颗心终会相遇——在心灵天生的联结中重逢。上古之力的体现，静默神明的不忍——摩耶与维塔啊，又有谁听见了你们…… 而现在，便交由对方来继续书写这段佳话吧。

#### 题目描述

给定一个长度为 n 的非负整数序列 a1,a2,…,an。
对于所有满足 1 ≤ i < j ≤ n 的数对 (i,j)，计算 ai 与 aj 的按位与、按位或和按位异或之和。（这里使用 ⊕ 符号表示异或）即定义三个量： SAND=∑1≤ i<j≤ n(aimathbin{&}aj), SOR=∑1≤ i<j≤ n(aimathbin{|}aj), SXOR=∑1≤ i<j≤ n(aimathbin{⊕}aj). 请你求出 SAND、SOR 和 SXOR。

#### 输入

第一行，一个整数 n，表示序列长度，满足 2 ≤ n ≤ 105。
第二行，包含 n 个由空格分隔的非负整数 a1,a2,…,an，满足 0 ≤ ai < 230。

#### 输出

输出一行三个由空格分隔的非负整数，依次表示 SAND、SOR 和 SXOR。保证答案不超过 long long 存储范围。

#### 输入样例 1

```text
3
1
2
3
```

#### 输出样例 1

```text
3
9
6
```

#### 样例解释

共有三个数对。
对于数对 (1,2)，有 1mathbin{&}2=0、1mathbin{|}2=3、1mathbin{⊕}2=3。对于数对 (1,3)，有 1mathbin{&}3=1、1mathbin{|}3=3、1mathbin{⊕}3=2。对于数对 (2,3)，有 2mathbin{&}3=2、2mathbin{|}3=3、2mathbin{⊕}3=1。因此三个答案分别为 3、9、6。

### 答案

### 解题思路

直接枚举所有数对需要 $O(n^2)$ 的时间，在 $n = 10^5$ 时无法通过。

按位与、按位或和按位异或都有一个共同特点：每个二进制位之间互不影响。因此，可以分别计算每一位对答案的贡献。

考虑第 $k$ 个二进制位，它的权值为 $2^k$ 。设这一位为 $1$ 的数有 $c_1$ 个，为 $0$ 的数有 $c_0 = n - c_1$ 个。

#### 按位与

只有两个数的第 $k$ 位都为 $1$ 时，按位与结果的第 $k$ 位才为 1。

这样的无序数对有

$$
\binom{c_1}{2} = \frac{c_1(c_1 - 1)}{2}
$$

个，所以这一位对 $S_{\mathrm{AND}}$ 的贡献为

$$
\binom{c_1}{2} 2^k.
$$

#### 按位异或

两个数的第 $k$ 位不同的时候，按位异或结果的第 $k$ 位为 1。

从 $c_0$ 个第 $k$ 位为 $0$ 的数中选一个，再从 $c_1$ 个第 $k$ 位为 $1$ 的数中选一个，一共有 $c_0c_1$ 对。

因此这一位对 $S_{\mathrm{XOR}}$ 的贡献为

$$
c_0c_1 2^k.
$$

#### 按位或

所有无序数对共有

$$
\binom{n}{2}
$$

个。

只有两个数的第 $k$ 位都为 $0$ 时，按位或结果的第 $k$ 位才为 0。这样的数对有 $\binom{c_0}{2}$ 个。

所以结果的第 $k$ 位为 $1$ 的数对有

$$
\binom{n}{2} - \binom{c_0}{2}
$$

个，这一位对 $S_{\mathrm{OR}}$ 的贡献为

$$
\left(\binom{n}{2} - \binom{c_0}{2}\right) 2^k.
$$

因此枚举第 $0$ 位到第 $29$ 位。对于每一位：

1. 扫描整个序列，统计这一位为 $1$ 的数的数量 $c_1$ ；

1. 令 $c_0 = n - c_1$ ；

1. 根据上面的三个公式分别累加 AND、OR、XOR 的贡献。

因为对于任意一对 $(i, j)$ ，其 AND、OR、XOR 的结果都等于各个二进制位独立计算后的加权和。

上述算法对于每一个二进制位，分别准确统计了这一位在所有无序数对中结果为 $1$ 的次数，并乘以该位的权值 $2^k$ 。把第 $0$ 位到第 $29$ 位的贡献全部相加，就恰好得到三个运算在所有数对上的总和。

时间复杂度为 $O(n \log a)$ 。

### 示例代码

```c
#include <stdio.h>

#define N 100005

int a[N];

int main() {
    int n;
    scanf("%d", &n);

    for (int i = 0; i < n; i++) {
        scanf("%d", &a[i]);
    }

    long long ans_and = 0;
    long long ans_or = 0;
    long long ans_xor = 0;
    long long tot = 1LL * n * (n - 1) / 2;

    for (int k = 0; k < 30; k++) {
        long long c1 = 0;
        for (int i = 0; i < n; i++) {
            if ((a[i] >> k) & 1) {
                c1++;
            }
        }

        long long c0 = n - c1;
        long long w = 1LL << k;

        ans_and += c1 * (c1 - 1) / 2 * w;
        ans_or += (tot - c0 * (c0 - 1) / 2) * w;
        ans_xor += c0 * c1 * w;
    }

    printf("%lld %lld %lld\n", ans_and, ans_or, ans_xor);
    return 0;
}
```
