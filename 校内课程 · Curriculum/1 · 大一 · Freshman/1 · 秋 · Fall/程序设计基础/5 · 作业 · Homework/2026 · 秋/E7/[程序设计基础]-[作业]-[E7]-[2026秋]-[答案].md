### 题目

#### 题目背景

题目背景和解题没有任何关系，可以直接跳过该部分。
2026 年 6 月 29 日，数据结构与算法基础课程期末考试。
OZDY（小声抱怨）：网络怎么又崩溃了？

#### 题目描述

自从 OZDY 在宿舍里分享了这件事之后，President K. 深深迷上了 3088，尤其是尾号为 3088 的字符串。给定若干个字符串 s，你需要判断 s 是否以 3088 结尾。即判断 s 的最后四个字符是否为 3088。

#### 输入格式

接下来 n 行，每行输入一个字符串 si，表示待询问的字符串。

### 答案

### 解题思路

只需要判断字符串最后四个字符是不是 `3088` 即可。

注意这题输入字符串可能含有空格，因此不能用 `scanf` 输入。要么用 `fgets` 要么用 `gets`。

- `fgets` 比较安全，但是会把 `\n` 保存到输入字符串里（如果本行末尾存在换行符）。需要手动删除末尾可能的 `\n` 和 `\r`。
- `gets` 不安全，不过不会把 `\n` 保存到字符串里，但是会把 `\r` 保存到字符串里。

我们发现 `\r` 在这里很讨厌，但是你放心好了，助教会帮你把测试点中的 `\r` 删除。因此在 OJ 上用 `gets` 是很方便的（毕竟字符串总长是限制了的，不会发生访问越界的问题啊）。

本题输出要注意转义字符哦。

读入 $n$ 之后，一定要先把这一行剩下的换行符吃掉，再去读第一个字符串。用 `scanf("%d\n", &n)` 可以让 `scanf` 顺带吃掉换行；用 `scanf("%d", &n)` 则要自己用 `getchar` 循环读到换行为止。否则第一次整行读入会立刻遇到这个换行而什么都没读进来。这是重点，从往年情况来看，死的人很多！！！

如果不放心助教有没有帮你清理 `\r`，可以在读入之后手动把末尾的 `\r\n` 都去掉：

```c
int len = strlen(s);
while ( len > 0 && (s[len - 1] == '\n' || s[len - 1] == '\r') )
    s[--len] = '\0';
```

这样就手动把讨厌的 `\r\n` 都处理掉了！

#### 解法一：fgets 读整行

读完 $n$ 后，先消耗首行剩余字符，再用 `fgets` 逐行读入字符串。只去掉行尾的回车和换行，保留内部空格。若长度至少为 4，从倒数第 4 个字符起与 `"3088"` 比较。用 `%%` 输出百分号，未匹配时在 `a` 前插入 `"not "`。

总字符数为 $L$、最长字符串长度为 $m$ 时，时间 $O(L)$，空间 $O(m)$。

```c
#include <stdio.h>
#include <string.h>

int main() {
    int n;
    char s[2003];
    scanf("%d", &n);
    int ch;
    while ((ch = getchar()) != '\n' && ch != EOF) {
    }

    printf("Dear President K., for all the %d strings you asked me, "
           "now here are the answers:\n", n);
    for (int i = 0; i < n; i++) {
        fgets(s, sizeof(s), stdin);
        size_t len = strcspn(s, "\r\n");
        s[len] = '\0';
        int matches = len >= 4 && strcmp(s + len - 4, "3088") == 0;
        printf("%% %s: It's %sa \"3088-string\".\n",
               s, matches ? "" : "not ");
    }
    return 0;
}
```

#### 解法二：gets 读整行，下标从 0 开始

`fgets` 会保存换行符，`gets` 不会。

```c
#include <stdio.h>
#include <string.h>

char s[2020];

int main() {
    int n;
    scanf("%d\n", &n); // 注意，这里一定要把末尾的换行吃掉
    printf("Dear President K., for all the %d strings you asked me, now here are the answers:\n",n);

    while ( n-- ) {
        gets(s); // fgets 会保存换行符，gets 不会
        int len = strlen(s), flag = 1;

        if ( len < 4 || s[len - 4] != '3' || s[len - 3] != '0' || s[len - 2] != '8' || s[len - 1] != '8')
            printf("%% %s: It's not a \"3088-string\".\n", s);
        else
            printf("%% %s: It's a \"3088-string\".\n", s);
    }

    return 0;
}
```

#### 解法三：gets 读整行，下标从 1 开始

有些助教认为字符串最好从下标 0 开始。其实无所谓，毕竟 C 语言中处理字符串也是一个一个字符处理的，那就和普通数组没有太多区别；处理普通数组肯定下标从 1 开始比较符合人的直觉。

```c
char s[2020];
int n,len,flag;

int main(){
    scanf("%d\n",&n);
    //注意，这里一定要把末尾的换行吃掉

    printf("Dear President K., for all the %d strings you asked me, now here are the answers:\n",n);

    for(int i=1;i<=n;i++){
        gets(s+1);
        //fgets 会保存换行符，gets 不会

        len=strlen(s+1);

        if (len<4) flag=0;//长度都不够肯定不是
        else{
            if (s[len-3]=='3'&&s[len-2]=='0'&&s[len-1]=='8'&&s[len]=='8') flag=1;
            else flag=0;
        }

        if (flag) printf("%% %s: It's a \"3088-string\".\n",s+1);
        else printf("%% %s: It's not a \"3088-string\".\n",s+1);
    }

    return 0;
}
```


## B 大大大肥鱼！

| 难度 | 考点 |
| --- | --- |
| 3 | 数组区间复制、重叠区间 |

### 题目

#### 题目背景

小M在电脑上养了一只蓝色大肥鱼！
结果没过几天，小M发现周围人的电脑上都被蓝色大肥鱼传染了。小M希望你帮忙分析这种传染的过程。

#### 题目描述

给定长度为 n 的整数数组，下标从 1 开始。按顺序执行 q 次复制操作，每次用三个整数 s,t,k 表示：将从下标 s 开始的 k 个元素复制到从下标 t 开始的 k 个位置。一次操作中，复制的所有数均取自这次操作开始前的数组。 源区间和目标区间可以重叠，也可以完全相同。每次操作实际改变数组，后续操作基于改变后的数组进行。例如，对 1 2 3 4 5 执行 s=1,t=2,k=4，结果为 1 1 2 3 4。

#### 输入

本题为单组数据。第一行两个整数 n,q，表示数组长度和操作数，1≤ n≤1000，0≤ q≤1000。
第二行 n 个整数 ai，-109≤ ai≤109。
接下来 q 行，每行三个整数 s,t,k，满足 1≤ s,t≤ n，1≤ k≤ n，s+k-1≤ n，t+k-1≤ n。

#### 输出

输出一行 n 个整数，按下标从小到大表示最终数组，相邻整数以一个空格分隔。

#### 输入样例

```text
5
2 1 2
3 4 5
1 2 4
4 1 2
```

#### 输出样例

```text
3
4
2
3
4
```

author: 只只小木条

### 答案

### 解题思路

每次操作从修改前的数组取出 $k$ 个源元素，再写到目标区间。源区间和目标区间可能重叠，因此不能边读边写：必须先把这一轮的 $k$ 个源元素整体保存下来，再一次性写入目标区间，否则会误用本轮已经更新过的元素。下一次操作则使用已经更新过的数组。

时间 $O(n + \sum k)$，空间 $O(n)$。

#### 解法一：临时数组

```c
#include <stdio.h>
int A[1010], tmp[1010];
int main() {
    int n, q;
    scanf("%d%d", &n, &q);
    for ( int i = 1; i <= n; i++ ) // 本题下标从 1 开始，因此我们也使用数组下标的 1 ~ n 即可
        scanf("%d", &A[i]);
    while ( q-- ) {
        int s, t, k;
        scanf("%d%d%d", &s, &t, &k);
        for ( int i = 0; i < k; i++ )
            tmp[i] = A[s + i];
        for ( int i = 0; i < k; i++ )
            A[t + i] = tmp[i];
    }
    for ( int i = 1; i <= n; i++ )
        printf("%d ", A[i]);
    return 0;
}
```

#### 解法二：memmove

`memmove` 保证重叠区间也能正确复制，依次传入目标地址、源地址和字节数 `k * sizeof(a[0])`。

```c
#include <stdio.h>
#include <string.h>

int main() {
    int n, q, a[1001];
    scanf("%d%d", &n, &q);
    for (int i = 1; i <= n; i++) {
        scanf("%d", &a[i]);
    }
    for (int i = 0; i < q; i++) {
        int s, t, k;
        scanf("%d%d%d", &s, &t, &k);
        memmove(a + t, a + s, k * sizeof(a[0]));
    }
    for (int i = 1; i <= n; i++) {
        printf("%d%c", a[i], i == n ? '\n' : ' ');
    }
    return 0;
}
```

## C 你会数数吗？

| 难度 | 考点 |

| 2 | 字符串、数字段解析 |

### 题目

#### 题目背景

muzermat 做了 ExplodingKonjac 的「我会数数」，然后觉得这道题对于小登来说实在是太不友好了。于是，我们可爱又迷人的 muzermat 助教为你准备了一道简单的「数数题」

#### 题目描述

给定字符串 s，仅包含大小写英文字母和数字。
将每一段连续且无法向两端延长的数字看作一个十进制非负整数，求这些整数的和。数字段可以包含前
导零。若字符串中没有数字，和为 0。
例如，ab12c003d4 中的三个数字段分别为 12、003 和 4，对应的整数为 12、3 和 4。

#### 输入

输入共一行，为字符串 s。字符串仅包含大小写英文字母和数字，1 ≤ |s| ≤ 1000，其中 |s| 表示字符串的长度。保证每段连续数字的长度不超过 6。

#### 输出

输出一行，一个整数，表示所有数字段对应整数的和。

#### 输入样例 1

```text
ab12c003d4
```

#### 输出样例 1

```text
19
```

#### 输入样例 2

```text
abcDEF
```

#### 输出样例 2

```text
0
```

#### 输入样例 3

```text
123456
```

#### 输出样例 3

```text
123456
```

#### 样例解释

样例 1：三个整数的和为 12 + 3 + 4 = 19。样例 2：字符串中没有数字，输出 0。样例 3：整个字符串是一个数字段，对应的整数为 123456。

Author: muzermat

### 答案

### 解题思路

从左到右扫描字符串，用 `num` 保存当前数字段已经读入的值，用 `sum` 保存已经结束的数字段之和。

读到数字字符时，先将字符减去 `'0'` 得到对应数字，再执行 `num = num * 10 + digit`。这个运算把已有数值向高位移动一位，并加入当前位；前导零会自然得到正确结果。

读到字母时，当前数字段结束，把 `num` 加入 `sum`，随后将 `num` 清零。连续字母只会重复加零。扫描结束后还要再加一次 `num`，否则字符串以数字结尾时，最后一个数字段会被漏掉。没有数字时，所有累加项都是零。

每个数字段的值不超过 $999999$。长度不超过 $1000$ 的字符串至多包含 $500$ 个数字段，因此总和不超过 $500 \times 999999 = 499999500$，使用 `int` 足够。

设字符串长度为 $n$，时间复杂度为 $O(n)$，存储字符串需要 $O(n)$ 空间。

#### 解法一：手写范围判断

```c
#include <stdio.h>

int main() {
    char s[1005];
    scanf("%1000s", s);

    int sum = 0, num = 0;
    for (int i = 0; s[i] != '\0'; i++) {
        if (s[i] >= '0' && s[i] <= '9') {
            num = num * 10 + s[i] - '0';
        } else {
            sum += num;
            num = 0;
        }
    }
    sum += num;

    printf("%d\n", sum);
    return 0;
}
```

#### 解法二：isdigit

```c
#include <stdio.h>
#include <string.h>
#include <ctype.h>

char s[1005];
int main() {
    scanf("%s", s);
    int len = strlen(s), sum = 0, num = 0;
    for ( int i = 0; i < len; i++ )
        if ( isdigit(s[i]) )
            num = num * 10 + s[i] - '0';
        else {
            sum += num;
            num = 0;
        }
    sum += num;
    printf("%d\n", sum);
    return 0;
}
```

### 题目

#### 题目背景

破译·噪域
收集时间：773.A.P.??.??
保管单位：鸠
等级：key
好奇不可避免。鸠张开手，轻轻接住其中一束，任其在掌心闪动变化，抽长压扁，断续重聚，又展开为赤色的数据流过，不似任何一种编码语言，形态的转换令她想起终端中收集物的存取，但又太混乱，太怪异，太不和谐，如同旋律中的杂音般躁动着。这些“杂音”无处不在，勉强称得上任由摆弄，但鸠始终无法理解其展现的信息，仿佛仅仅是作为某种阻碍存在。

#### 题目描述

给定定义在 (0,+∞) 上的函数 h(x)=ecos x+sinsqrt x + 2x + √x+1 + ln(x+1)。
给定 h(x)，求解 x。
可以证明，h'(x)>2-efrac{sqrt5-12}sqrt{frac{sqrt5-1}2}>0.5，因此 h(x) 在定义域内是增函数。 [图]

#### 输入

第一行一个整数 T 表示数据组数。
接下来 T 行，每行一个浮点数 h(x)。
数据保证 1≤ T≤ 2×105,h(x)∈[4,100]，且 h(x) 的小数点后位数不超过 6。

#### 输出

每行一个浮点数表示答案。保留 9 位小数。
数据保证精确答案 x 满足 存在 λ∈mathbb Z,|x-10-9λ|<10-10。

#### 输入样例

```text
5
4.000001
20.000000
31.000000
50.000000
99.999992
```

#### 输出样例

```text
0.030992564
6.055692760
11.660150322
21.356771487
43.440493584
```

#### 样例解释

例如，当 h(x)=50 时，方程的解约为x=21.356771486911…，保留 9 位小数后为 21.356771487。

#### 提示

直接算出解析式 h-1(x) 是困难的。我们考虑不求精确解，只求数值解。
考虑到如果已知 x0，计算 h(x0) 是简单的，我们可以利用这个性质。
由于 h(x) 是增函数，a<b 当且仅当 h(a)<h(b)。
因此，如果我们现在知道 h(x)=y 的解 x 在区间 [l,r] 内部，我们计算区间中点 mid=frac{l+r}2，然后判断 h(mid) 和 h(x) 的大小。如果 h(mid)>y，则 mid>x，故 x∈[l,mid]。如果 h(mid)≤ y，则 mid≤ x，故 x∈[mid,r]。可见，取一次中点判断一次，x 的可行域都缩减到原来的一半。那么我们只需要最开始时编写一个足够包括所有题目可能出现的 x 的区间 l,r 即可，然后不断进行迭代。此题的精度要求为 10-9，为避免舍入误差，我们保险起见可以迭代到 10-12，当区间长度 |r-l|< 10-12 时跳出循环即可。这种方法叫做折半查找，即每次将区间缩小一半。 [图]

Author: Windowsredstone playing Phigros

### 答案

### 解题思路

设输入为 $y$。函数 $h$ 严格递增，延拓到 0 后有 $h(0) = e + 1 < 4$。又因为 $h(50) > 100$，所以解在 $[0, 50]$ 内。每次取中点，若 $h(mid) < y$ 则更新左端点，否则更新右端点。

二分 46 次后区间宽度小于 $10^{-12}$。题面保证精确解距离九位小数的舍入分界至少 $4 \times 10^{-10}$，用 `double` 计算后将区间中点保留九位小数即可。

每组计算 46 次 $h$，额外空间 $O(1)$。

### 示例代码

```c
#include <math.h>
#include <stdio.h>

double h(double x) {
    return exp(cos(x)) + sin(sqrt(x)) + 2 * x + sqrt(x + 1) + log1p(x);
}

int main() {
    int t;
    scanf("%d", &t);
    while (t--) {
        double y;
        scanf("%lf", &y);
        double lo = 0, hi = 50;
        for (int i = 0; i < 46; i++) {
            double mid = (lo + hi) / 2;
            if (h(mid) < y) {
                lo = mid;
            } else {
                hi = mid;
            }
        }
        printf("%.9f\n", (lo + hi) / 2);
    }
    return 0;
}
```

## E 十步万度

### 题目

#### 题目背景

《十步万度》是一个关于连锁反应的游戏。在一个二维网格中，每个格子内有一个可以旋转的箭头。箭头有上下左右四个朝向，分别用 ^, >, v, < 表示。游戏开始时，所有箭头都指向上方（^）。点击一个箭头，它会顺时针旋转 90 度，并让此时它指向的箭头发生相同的行为。玩家可以进行不超过 K 次点击操作，目标是让总旋转次数最大。

#### 题目描述

在一个 N 行 M 列的二维网格中有 N × M 个箭头。游戏开始时，所有箭头都指向上方（^）。玩家可以选择一个箭头进行点击操作，具体规则如下： 1. 触发与旋转：点击某个箭头，使其进入触发状态。触发状态的箭头会顺时针旋转 90 度（例如从 ^ 变为 >，从 > 变为 v 等）。2. 信号传递：箭头旋转完毕后，会沿着旋转后的新朝向，将触发信号传递给下一个格子，并退出触发状态。3. 连锁反应：如果接收信号的格子内存在箭头，该箭头也会进入触发状态（即重复前面的步骤）。4. 连锁终止：如果接收信号的格子内不存在箭头，连锁反应终止。可以证明，该游戏不存在死循环，连锁反应一定会终止。现在给定网格的大小 N × M，以及玩家进行的 K 次点击坐标，请你计算游戏结束时，所有箭头装置总共旋转了多少次。

#### 输入格式

第一行包含三个正整数 N, M, K（1 ≤ N, M ≤ 1000，1 ≤ K ≤ 1000），分别表示网格的行数、列数以及玩家的点击次数。接下来 K 行，每行包含两个正整数 r 和 c（1 ≤ r ≤ N，1 ≤ c ≤ M），表示玩家点击的行号和列号。保证每次点击的位置都在网格内。

#### 输出格式

输出一个整数，表示所有箭头旋转的总次数。

### 答案

### 解题思路

这道题的核心是判断循环的终止条件。我们只需要按照题目给定的规则，还原每一次点击的过程即可。

为了方便处理，我们将箭头的四个朝向映射为数字：`0`、`1`、`2`、`3` 分别代表上、右、下、左。那么顺时针旋转 $90$ 度，在数字上就是加 $1$ 并对 $4$ 取模，即 `d = (d + 1) % 4`。

如果某格被无限次访问，它会无限次向四个方向传递。沿相邻格推到边界，必有一次传到网格外，因此连锁一定终止。

设实际旋转总数为 $R$，时间 $O(NM + K + R)$，空间 $O(NM)$。

#### 解法一：二维数组与坐标映射数组

再引入如下的坐标映射数组：

- `dr[4] = {-1, 0, 1, 0}`（行的增量：上 $-1$，右 $0$，下 $+1$，左 $0$）
- `dc[4] = {0, 1, 0, -1}`（列的增量：上 $0$，右 $+1$，下 $0$，左 $-1$）

当方向为 `d` 时，下一步的坐标 `(nr, nc)` 可以通过 `nr = r + dr[d]`，`nc = c + dc[d]` 算出。

我们用一个二维数组 `board[1005][1005]` 代表网格。每次点击用一个 `while(1)` 循环来实现：先通过当前的行号 $r$ 和列号 $c$，读取当前格子的数字 `d=board[r][c]`，将其加 1 并且对 4 取模，更新回数组并累加旋转次数。接着通过更新后的 `d` 来决定下一步的坐标 `nr` 和 `nc`。

如果计算出的新坐标超出了网格边界，就用 `break` 结束连锁；如果没有越界，就把新坐标赋给当前坐标 `r` 和 `c`，重复之前的操作，直到飞出边界为止。

```c
#include <stdio.h>

int board[1005][1005];
int N, M, K;
int ans = 0;

// 坐标映射数组：0上, 1右, 2下, 3左
int dr[] = {-1, 0, 1, 0};
int dc[] = {0, 1, 0, -1};

void trigger(int r, int c) {
    while (1) {
        int d = board[r][c]; // 获取当前方向
        d = (d + 1) % 4; // 顺时针旋转 90 度
        board[r][c] = d; // 更新当前状态
        ans++; // 旋转次数 +1

        // 利用映射数组计算下一个坐标
        int nr = r + dr[d];
        int nc = c + dc[d];

        // 检查是否越界
        if (nr < 1 || nr > N || nc < 1 || nc > M) {
            break;
        }

        r = nr;
        c = nc;
    }
}

int main() {
    scanf("%d %d %d", &N, &M, &K);

    for (int i = 0; i < K; i++) {
        int r, c;
        scanf("%d %d", &r, &c);
        trigger(r, c);
    }

    printf("%d\n", ans);

    return 0;
}
```

#### 解法二：一维展开与哨兵边界

将网格按行展开成一维数组，外加一圈值为 4 的哨兵格子；走到这一圈就结束本次连锁。方向用 `step[4]` 表示为展开后的一维偏移量。

```c
#include <stdio.h>

static unsigned char board[1002 * 1002];

int main() {
    int n, m, k;
    scanf("%d%d%d", &n, &m, &k);
    int stride = m + 2;
    int step[4] = {-stride, 1, stride, -1};
    for (int c = 0; c <= m + 1; c++) {
        board[c] = board[(n + 1) * stride + c] = 4;
    }
    for (int r = 1; r <= n; r++) {
        board[r * stride] = board[r * stride + m + 1] = 4;
    }

    long long total = 0;
    while (k--) {
        int r, c;
        scanf("%d%d", &r, &c);
        int pos = r * stride + c;
        while (board[pos] != 4) {
            int dir = (board[pos] + 1) & 3;
            board[pos] = dir;
            pos += step[dir];
            total++;
        }
    }
    printf("%lld\n", total);
    return 0;
}
```

#### Hint

以防有数学洁癖主义者钻牛角尖，我们对相关内容做严谨定义。
对于两个有限长的序列 a = [a1, a2, …, an], b = [b1, b2, …, bm]，定义：a + b = [a1, a2, … , an, b1, b2, …, bm]可以证明该运算满足结合律。对于一个有限长的序列 a，记 |a| 表示 a 的长度，定义无限长序列 M(+∞)：M(+∞)i = M(t)i, (i ∈ mathbb{N}^+, t = min{k ∈ mathbb{N}: |M(k)| > i})

Author: ExplodingKonjac

### 答案

### 解题思路

设 $L_t$ 为 $M^{(t)}$ 的长度，则 $L_0 = 0$、 $L_1 = 1$，且

$$
L_t = 2L_{t-1} + L_{t-2} + 2.
$$

预计算到长度不小于 $10^{18}$ 的一层。查询时，按构造依次判断位置落在左段、插入的数字、中段、插入的数字还是右段：遇到插入的数字直接返回当前层数；否则减去前面各段的长度，递归查询对应子序列。两侧进入上一层，中段进入上两层；第一层直接返回 $1$。每次都进入包含目标位置的子序列，因此能得到正确答案。

因为序列长度随层数指数增长，所以总时间复杂度为 $O(q \log k_{\mathrm{max}})$。

### 示例代码

```c
#include <stdio.h>

long long length[50] = {0, 1};

int message(int n, long long k) {
    if (n == 1) return 1;
    if (k <= length[n - 1]) return message(n - 1, k);
    k -= length[n - 1] + 1;
    if (k == 0) return n;
    if (k <= length[n - 2]) return message(n - 2, k);
    k -= length[n - 2] + 1;
    if (k == 0) return n;
    return message(n - 1, k);
}

int main() {
    int n = 1;
    while (length[n] < 1000000000000000000LL) {
        ++n;
        length[n] = 2 * length[n - 1] + length[n - 2] + 2;
    }
    int q;
    scanf("%d", &q);
    while (q--) {
        long long k;
        scanf("%lld", &k);
        printf("%d\n", message(n, k));
    }
    return 0;
}
```

### 题目

#### 题目描述

“倒挂天际的笑靥”。
称一个字符串是对称的，如果它的第一个字符和最后一个字符镜像对称、第二个字符和倒数第二个字符

本题范围内，轴对称字符有：AHIMOTUVWXYilmnouvwx，而镜像对称字符对有 b-d 和 p-q。显然，轴对称字符和自身成为镜像对称字符对，故不再列出。对于某个字符串，它连续的一部分（空串、字符串本身亦算）称为它的子串。现在我们想知道，对于给定的字符串 S ，它的所有子串中，最长的对称字符串是什么，以及它有多长。如果最长的子串有多个，输出在 S 中先出现的。

#### 输入

一行一个字符串 S ，仅由大小写字母组成，长度不超过 3000 ，末尾无换行。

#### 输出

第一行， S 的最长对称子串；
第二行，一个自然数，表示它最长对称子串的长度。

#### 输入样例 1

```text
WhatislovoqnInpovoqnIDoyouknoW
```

#### 输出样例 1

```text
ovoqnInpovo 11
```

#### 输入样例 2

```text
pppqqq
```

#### 输出样例 2

```text
pppqqq 6
```

Author: Protoss

### 答案

### 解题思路

本题类似于最长回文子串，仅在字符比对上略有差别。对于此类题目，有中心扩展法、动态规划法以及高效的 Manacher 算法。下面给出前两种方法，感兴趣的同学可以自学第三种方法。

中心扩展法的时间复杂度为 $O(n^2)$，除字符串外只用常数额外空间；动态规划法的时间复杂度为 $O(n^2)$，空间复杂度为 $O(n^2)$。

#### 解法一：中心扩展法（字符判定函数）

我们可以枚举每一个字符作为对称串中心，然后向两边扩展，可以得到以该字符为中心的最长对称子串。遍历每一个字符为中心，即可得到整个字符串的最长对称子串。

```c
#include <stdio.h>
#include <string.h>

char str[3010];

int isaxi(char r); // 判断 r 是否轴对称
int ismir(char r1, char r2); // 判断 r1, r2 是否镜像对称

int main() {
    scanf("%s", str);
    int len = strlen(str);
    int maxlen = 0, maxpos = -1;

    for ( int i = 0; i < len; i++ ) { // 枚举每一个字符为对称串中心
        if ( isaxi(str[i]) ) { // 奇数长度，中心字符必须轴对称
            int l = i - 1, r = i + 1;
            while ( l >= 0 && r < len && ismir(str[l], str[r]) )
                l--, r++;
            // 此时 str[l + 1 .. r - 1] 是对称串
            if ( r - l - 1 > maxlen ) {
                maxlen = r - l - 1;
                maxpos = l + 1;
            }
        }
        if ( i + 1 < len && ismir(str[i], str[i + 1]) ) { // 偶数长度，中心字符镜像对称
            int l = i - 1, r = i + 2;
            while ( l >= 0 && r < len && ismir(str[l], str[r]) )
                l--, r++;
            // 此时 str[l + 1 .. r - 1] 是对称串
            if ( r - l - 1 > maxlen ) {
                maxlen = r - l - 1;
                maxpos = l + 1;
            }
        }
    }

    for ( int i = maxpos; i < maxpos + maxlen; i++ )
        printf("%c", str[i]);
    printf("\n%d", maxlen);
    return 0;
}

int isaxi(char r) {
    return strchr("AHIMOTUVWXYilmnouvwx", r) != NULL;
}
int ismir(char r1, char r2) {
    if ( r1 == r2 )
        return isaxi(r1);
    if ( r1 == 'b' && r2 == 'd' || r1 == 'd' && r2 == 'b' )
        return 1;
    if ( r1 == 'p' && r2 == 'q' || r1 == 'q' && r2 == 'p' )
        return 1;
    return 0;
}
```

#### 解法二：中心扩展法（镜像映射表）

把轴对称字符映射到自身，把 `b` 与 `d`、`p` 与 `q` 分别互相映射。从左到右枚举字符和相邻字符间的空隙作为中心。奇数串先检查中心字符能否与自身匹配，偶数串从空隙两侧开始比较。每次匹配就向外扩展一格。

只在长度严格增加时更新答案。相同长度下，中心越靠左，起点也越靠左。若无非空解，输出空行和 0。

时间 $O(n^2)$，空间 $O(n)$。

```c
#include <stdio.h>
#include <string.h>

int main() {
    char s[3001] = "", mirror[256] = {0};
    const char axis[] = "AHIMOTUVWXYilmnouvwx";
    for (int i = 0; axis[i]; i++) {
        mirror[(unsigned char)axis[i]] = axis[i];
    }
    mirror['b'] = 'd';
    mirror['d'] = 'b';
    mirror['p'] = 'q';
    mirror['q'] = 'p';

    scanf("%3000s", s);
    int n = (int)strlen(s), start = 0, best = 0;
    for (int center = 0; center < 2 * n - 1; center++) {
        int left = center / 2, right = (center + 1) / 2;
        while (left >= 0 && right < n
                && mirror[(unsigned char)s[left]] == s[right]) {
            left--;
            right++;
        }
        int len = right - left - 1;
        if (len > best) {
            best = len;
            start = left + 1;
        }
    }

    printf("%.*s\n%d\n", best, s + start, best);
    return 0;
}
```

#### 解法三：动态规划法

设计状态 $dp_{i,j}$ 表示子串 $str[i \cdots j]$ 是否为对称串。先预处理好长度为 $1, 2$ 的子串，随后通过状态转移方程

$$
dp_{i,j} = dp_{i+1,j-1} \land ismir(str[i], str[j])
$$

计算对称子串，并记录最长的子串。

```c
#include <stdio.h>
#include <string.h>

char str[3010];
int dp[3010][3010];

// 以下二函数定义与上文完全相同，此处省略
int isaxi(char r); // 判断 r 是否轴对称
int ismir(char r1, char r2); // 判断 r1, r2 是否镜像对称

int main() {
    scanf("%s", str);
    int len = strlen(str);
    for ( int i = 0; i < len; i++ ) { // 初始化
        if ( isaxi(str[i]) )
            dp[i][i] = 1;
        if ( i + 1 < len && ismir(str[i], str[i + 1]) )
            dp[i][i + 1] = 1;
    }

    int maxl = 0, left = -1;
    for ( int l = 3; l <= len; l++ ) // 枚举对称子串长度
        for ( int i = len - l, j = len - 1; i >= 0; i--, j-- ) // 倒序排列，确保 left 一定更新在第一次出现的最长对称子串
            if ( dp[i + 1][j - 1] && ismir(str[i], str[j]) ) { // 原本是对称串，左右新增一对对称字符，那么新串也是对称串
                dp[i][j] = 1;
                maxl = l;
                left = i;
            }
    for ( int i = 0; i < maxl; i++ )
        putchar(str[left + i]);
    printf("\n%d", maxl);
    return 0;
}
```

#### 题目描述

有 32 个寄存器，编号为 0 至 31，在指令中分别写作 `$0` 至 `$31`。用 R(d) 表示编号为 d 的寄存器中存储的整数。内存中有 256 个存储单元，地址依次为 0,4,8,…,1020。每个单元存储一个整数，用 M(a) 表示地址为 a 的单元中存储的整数。初始时，所有寄存器和内存单元的值均为 0。其中，寄存器 `$0` 的值始终为 0，任何向它写入的操作都不会改变它的值。给定 n 条指令，按输入顺序依次执行。支持的六种指令如下：

指令格式 执行效果

`li $d, x` 将整数 x 写入寄存器 d。

`move $d, $s` 将 R(s) 写入寄存器 d。

`add $d, $s, $t` 将 R(s)+R(t) 写入寄存器 d。

`sub $d, $s, $t` 将 R(s)-R(t) 写入寄存器 d。

`lw $d, k($s)` 令 a=R(s)+k，将 M(a) 写入寄存器 d。

`sw $t, k($s)` 令 a=R(s)+k，将 R(t) 写入地址为 a 的内存单元。

表中的 d,s,t 表示寄存器编号，x 表示整数，k 表示地址偏移量。同一条指令中的寄存器编号可以相同；每条指令占一行，格式遵循以下规则： · 指令名均为小写，指令名与第一个操作数之间至少有一个空格。 · 行首、行尾以及逗号、左右括号的两侧允许出现任意数量的空格。 · 寄存器中的 `$` 与编号之间、整数的负号与数字之间，以及一个整数的各位数字之间均没有空格。 · 寄存器编号和整数均使用十进制，不带前导零，整数不带正号。 · 一行中可以出现注释：从第一个 # 开始，该行剩余的所有字符都应被忽略。执行完所有指令后，回答 q 次询问，每次给出一个寄存器编号，输出该寄存器最终存储的整数。

- 寄存器编号满足 0≤ d,s,t≤ 31；立即数满足 -109≤ x≤ 109；地址偏移量满足 $-1020 \le k \le 1020$。

### 答案

### 解题思路

用数组 `r[32]` 保存寄存器，用 `m[256]` 保存内存，两个数组初始都填 0。寄存器编号可以直接当下标。内存地址每隔 4 取一个，所以地址 $a$ 对应 `m[a / 4]`。例如，地址 12 对应 `m[3]`。

用 `fgets` 逐行读取指令。遇到第一个 `#` 就截断，再把有效部分中的 `$`、逗号和括号替换成空格。这样，`lw $10, -4($10)` 就可以用 `sscanf` 依次读出指令名 `lw` 和三个整数 `10`、`-4`、`10`。负号需要保留。不同指令的操作数个数不同，执行时只使用该指令实际读到的操作数。

按输入顺序执行指令。`li` 和 `move` 分别写入立即数和源寄存器的值，`add` 和 `sub` 用两个源寄存器当前的值计算结果。`lw` 和 `sw` 都先用基址寄存器的当前值加上偏移量，再除以 4 得到内存下标。`lw` 把内存中的值写入寄存器，`sw` 把寄存器中的值写入内存。即使 `lw` 的目标寄存器也是基址寄存器，也要先用它原来的值计算地址。每条指令执行完就把 `r[0]` 恢复为 0，下一条指令和最后的询问读到的 `$0` 始终为 0。

执行前，两个数组与题目规定的初始状态一致。每条指令都根据执行前的状态计算右侧的值或访存地址，再按指令更新相应的位置。恢复 `r[0]` 后，两个数组就与该条指令执行后的状态一致。依次执行完所有指令后，直接按询问顺序输出 `r[x]` 即可。

题面保证访存地址合法且对齐，加减结果也在 32 位有符号整数范围内，因此示例代码使用 32 位 `int` 即可。设 $L$ 为全部指令行的字符总数，时间复杂度为 $O(L+q)$。寄存器数组、内存数组和单行缓冲区大小固定，额外空间复杂度为 $O(1)$。

### 示例代码

```c
#include <stdio.h>
#include <string.h>

int main() {
    int n, q;
    int r[32] = {0}, m[256] = {0};
    char line[2048], op[8];
    scanf("%d%d", &n, &q);
    fgets(line, sizeof(line), stdin);
    for (int i = 0; i < n; i++) {
        fgets(line, sizeof(line), stdin);
        for (int j = 0; line[j]; j++) {
            if (line[j] == '#') { // 截断注释
                line[j] = '\0';
                break;
            }
            if (line[j] == '$' || line[j] == ',' || line[j] == '(' || line[j] == ')') {
                line[j] = ' ';
            }
        }
        int a, b, c;
        sscanf(line, "%7s%d%d%d", op, &a, &b, &c); // 重新从处理好的字符串读入指令和整数
        if (strcmp(op, "li") == 0) {
            r[a] = b;
        } else if (strcmp(op, "move") == 0) {
            r[a] = r[b];
        } else if (strcmp(op, "add") == 0) {
            r[a] = r[b] + r[c];
        } else if (strcmp(op, "sub") == 0) {
            r[a] = r[b] - r[c];
        } else if (strcmp(op, "lw") == 0) {
            r[a] = m[(r[c] + b) / 4];
        } else {
            m[(r[c] + b) / 4] = r[a];
        }
        r[0] = 0;
    }
    for (int i = 0; i < q; i++) {
        int x;
        scanf("%d", &x);
        printf("%d\n", r[x]);
    }
    return 0;
}
```

### 答案

### 解题思路

#### 倒过来想

正向贴贴纸时，前面贴错的字符可能被后面的贴纸覆盖。因此，每一步都要求贴完后与目标一致，会漏掉合法答案。

可以从目标串出发，反过来「消除贴纸」。先考虑最后贴上去的那张：它上面的所有字符最终都可见，所以一定能在目标串中找到一个与贴纸完全一致的窗口。

把这个窗口消除以后，这些位置原来是什么字符就不再重要了。我们用 `#` 标记它们。接下来消除更早的贴纸时，`#` 可以与任意字符匹配。

这里的 `#` 表示「这个位置的要求已经由后面的贴纸负责」，并不是在实际构造中执行一次擦除操作。

#### 一个窗口何时可以消除

设贴纸起点为 `i`。依次检查 `j = 0, 1, ..., k-1`：

- 若 `t[i+j] == '#'`，跳过这个位置。
- 否则，必须有 `t[i+j] == s[j]`。

还要要求这个窗口里至少有一个字符不是 `#`。如果窗口已经全是 `#`，再次消除没有任何进展，不能把它当作一次有效操作，否则可能重复记录甚至死循环。

#### 反复扫描

用最直接的数组和循环实现即可：

1. 从左到右枚举所有起点 `0` 至 `n-k`。
2. 找到一个可以消除的窗口，就记录起点，并将窗口内所有字符改成 `#`。
3. 扫描完一整轮后，如果还有字符没消除，就重新从起点 0 扫描。
4. 全部消除，说明有解；如果一整轮都没有进展，说明无解。

为什么要重新扫描？一个靠右的窗口被消除后，可能使已经检查过的靠左窗口变得可消除。只从左到右扫描一遍是不够的。

例如，目标串为 `aaab`，贴纸为 `ab`：

```text
第 1 轮：aaab -> aa##   （消除起点 2）
第 2 轮：aa## -> a###   （消除起点 1）
第 3 轮：a### -> ####   （消除起点 0）
```

消除时记录的是 `2 1 0`。实际贴纸要按相反顺序贴，因此输出 `0 1 2`：

```text

#### -> ab## -> aab# -> aaab

```

#### 为什么任选一个可消除窗口都安全

把当前不是 `#` 的位置看作仍需满足的要求；`#` 位置的颜色可以任意。

假设某个窗口可以消除。将其消除，就是撤掉这个窗口内的要求。

如果消除前有构造，消除后显然也有：原来的构造仍满足所有剩余要求。

反过来，如果消除后有构造，那么先完成这个构造，再在刚才的窗口贴上一张贴纸。窗口外的要求没有改变；窗口内尚需满足的字符都与贴纸一致，所以消除前的要求也全部满足。

因此，消除一个合法窗口前后，「是否可构造」完全等价。我们不需要猜它是不是某个特定答案中的最后一张，遇到合法窗口直接消除即可。

#### 为什么没有进展就一定无解

如果还存在未消除的位置，并且当前要求有一个合法构造，那么在这个构造中，选取**最后一张覆盖了任意未消除位置的贴纸**。

这张贴纸覆盖到的所有未消除位置，都不会再被后面的贴纸改变，因此它们的字符必须与贴纸一致；其余位置是 `#`，没有要求。所以这个窗口一定可以消除，而且至少能消除一个新位置。

因此，只要还可构造，就一定能继续消除。一整轮找不到合法窗口时，答案只能是 `NO`。

另一方面，若已经全部消除，将起点记录倒序执行，就能逐步恢复目标串，得到一个合法构造。

#### 复杂度与次数限制

每记录一个起点，至少消除一个新位置，所以记录数最多为 $N$，满足题目要求的 $10N$ 上限。

每一轮成功扫描至少消除一个新位置，因此总扫描轮数不超过 $N$。每轮枚举 $N-K+1$ 个起点，每个起点最多检查 $K$ 个字符。消除窗口的总开销不超过 $NK$。

总时间复杂度为 $O(N^2K)$，空间复杂度为 $O(N+K)$。

本题 $N, K \le 500$。扫描部分的宽松上界为 $500 \times 251 \times 250 = 31375000$ 次字符检查，适合这份直接枚举的做法。

#### 标程中的变量

| 变量 | 含义 |
| --- | --- |
| `n`, `k` | 目标和贴纸的长度 |
| `t`, `s` | 目标串和贴纸串；`t` 会被逐步消除 |
| `a` | 按消除顺序记录的起点 |
| `c` | 已记录的起点数 |
| `r` | 还没消除的位置数 |

| `ok` | 当前窗口是否没有字符冲突 |
| `u` | 当前窗口是否包含未消除的位置 |

### 示例代码

```c
#include <stdio.h>

int main(void) {
    int n, k, i, j, c = 0, r, p, ok, u;
    int a[505];
    char t[505], s[505];

    scanf("%d%d", &n, &k);
    scanf("%s%s", t, s);
    r = n;

    /* 从目标串倒着做：# 表示这个位置已经被消除。 */
    while (r > 0) {
        p = 0;
        for (i = 0; i <= n - k; i++) {
            ok = 1;
            u = 0;
            for (j = 0; j < k; j++) {
                if (t[i + j] != '#') {
                    u = 1;
                    if (t[i + j] != s[j]) {
                        ok = 0;
                        break;
                    }
                }
            }

            /* 没有冲突，而且至少能消除一个新位置。 */
            if (ok == 1 && u == 1) {
                a[c] = i;
                c++;
                p = 1;
                for (j = 0; j < k; j++) {
                    if (t[i + j] != '#') {
                        t[i + j] = '#';
                        r--;
                    }
                }
            }
        }

        /* 一整轮都没有进展，剩余位置就无法消除。 */
        if (p == 0) {
            printf("NO\n");
            return 0;
        }
    }

    /* 消除的顺序与实际贴上去的顺序相反。 */
    printf("YES\n%d\n", c);
    for (i = c - 1; i >= 0; i--) {
        printf("%d ", a[i]);
    }
    printf("\n");
    return 0;
}
```

### 题目

#### 题目描述

在一次扫雷任务中，数轴上有 n 颗地雷。第 i 颗地雷的整数坐标为 ai，地雷按坐标从小到大编号，即 a1≤ a2≤…≤ an。不同地雷的坐标可以相同。你需要依次对这 n 颗地雷进行测试。对于第 i 颗地雷，你可以选择任意整数坐标 bi 作为测试位置（可以是负数或 0），该次测试的误差为 |ai-bi|。对于每个 2≤ i≤ n，给定一个正整数 li。相邻两次测试的位置必须满足 |bi-bi-1|≥ li。你的目标是选择所有测试位置，使得 所有测试误差中的最大值尽可能小。请输出这个最小的最大误差。

### 答案

### 解题思路

二分最大误差 $d$。第 $i$ 步的允许区间为 $[a_i - d, a_i + d]$。设上一步可达位置的最小值和最大值为 $u, v$。位置 $x$ 可达，当且仅当 $x \le v - l_i$ 或 $x \ge u + l_i$。

把允许区间分别与这两个范围求交。两段都空则不可行，否则更新可达位置的最小值和最大值。下一步仍只用这两个极值。第一步的整个允许区间都可达。

二分上界取 $S = \sum_{i=2}^{n} l_i$。从 $b_1 = a_1$ 开始，每步取 $b_i = \max(a_i, b_{i-1} + l_i)$。由于 $a_i$ 不递减，每步的误差最多比前一步增加 $l_i$，所以 $S$ 一定可行。坐标和边界用 `long long`。每组时间 $O(n \log(S + 1))$，空间 $O(n)$。

### 示例代码

```c
#include <stdio.h>

static long long a[100000], gap[100000];

long long min(long long a, long long b) {
    return a < b ? a : b;
}

long long max(long long a, long long b) {
    return a > b ? a : b;
}

int feasible(int n, long long error) {
    long long low = a[0] - error, high = a[0] + error;
    for (int i = 1; i < n; i++) {
        long long left = a[i] - error, right = a[i] + error;
        long long left_end = high - gap[i];
        long long right_start = low + gap[i];

        int can_left = left <= left_end;
        int can_right = right >= right_start;
        if (!can_left && !can_right) {
            return 0;
        }
        low = can_left ? left : max(left, right_start);
        high = can_right ? right : min(right, left_end);
    }
    return 1;
}

int main() {
    int t;
    scanf("%d", &t);
    while (t--) {
        int n;
        scanf("%d", &n);
        for (int i = 0; i < n; i++) {
            scanf("%lld", &a[i]);
        }
        long long upper = 0;
        for (int i = 1; i < n; i++) {
            scanf("%lld", &gap[i]);
            upper += gap[i];
        }

        long long lower = 0;
        while (lower < upper) {
            long long mid = lower + (upper - lower) / 2;
            if (feasible(n, mid)) {
                upper = mid;
            } else {
                lower = mid + 1;
            }
        }
        printf("%lld\n", lower);
    }
    return 0;
}
```
