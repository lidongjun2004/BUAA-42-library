经过深思熟虑，我们决定不告诉你这个定理的名字。你一定会被这个定理难住吧！给定直角三角形中直角边的边长，求斜边长的平方。提示：末尾有提示。以后的题都可能在末尾附加提示。

#### 提示

C 语言中，要计算某个数 x 的平方，不能使用 x^2，因为 ^ 是会在C3讲的位运算——按位异或，你现在不需要了解。那么，如果不能用 ^ 符号，我们还能用什么运算符来计算平方呢？

Author: Windowsredstone

### 答案

### 题目分析

基本是 C1B 的翻版，唯一有区别的就是加了平方。

计算 $a^2 + b^2$ 时，我们不能用符号 ^，因此，我们可以拆成 `a * a + b * b`。

特别地，C语言的运算符大多数和我们常用的运算符顺序是一致的，即先算乘除法，后算加减法。

### 示例代码 1

```c
#include <stdio.h>
int main() {
    int a, b;
    scanf("%d%d", &a, &b);
    printf("%d", a * a + b * b);
    return 0;
}
```

### 示例代码 2

```c
#include <stdio.h>
int main() {
    int a, b;
    scanf("%d%d", &a, &b);
    int answer = a * a + b * b;
    printf("%d", answer);
    return 0;
}
```

### 后记

本来这题需要输出的是 `I'm convinced`，为什么最后改为 `I am` 了呢？

因为在 C 语言中，如果要表示单引号，需要用转义符 \\' ，直接写 `I'm` 是错误的。同样的，要表示一个双引号需要用转义符 \\" ，而要表示一个反斜杠，则需要用转义符 \\\\ 。

特别的，如果像输出一个百分号，则应该写 `printf("%%")` 。

不过这都是后话了，后面的课一定会讲的。

## C 火星鸡兔同笼

| 难度 | 考点 |
| --- | --- |
| 2 | 数学计算 |

### 题目

#### 题目描述

火星上有两种生物，我们把脚较少的那种称作“火星鸡”，脚较多的那种称作“火星兔”。火星鸡有 a 只脚，火星兔有 b 只脚。星际农场在火星上的一次捕猎中收获了 n 个生物，数了数它们的脚发现一共有 m 只。请问，这次捕猎一共捕获了多少火星鸡。多少火星兔？

#### 输入

一共四个正整数 a, b, n, m，1 ≤ a < b ≤ 8，1 ≤ n ≤ 2.5 × 108，1 ≤ m ≤ 109。数据保证答案符合物理规律（不会出现半只鸡、负数只鸡等离谱情况）。

#### 输出

一行两个非负整数 x, y，分别表示火星鸡与火星兔的数目。

#### 输入样例

```text
2
4 30
100
```

#### 输出样例

```text
10
20
```

### 答案

### 题目分析

本题理论上就仅仅是一个最普通的解方程，但是查看同学们的实际提交，我发现了各种各样的奇怪写法，那就都拿出来讲讲。

### 方法一（正确解法）

设火星鸡有 $x$ 只，火星兔有 $y$ 只，列出方程

$$
\begin{cases}
x + y = n \\
ax + by = m
\end{cases}
$$

解得

$$
\begin{cases}
x = \dfrac{bm-m}{b-a} \\
y = \dfrac{m-an}{b-a}
\end{cases}
$$

### 示例代码

```c
#include <stdio.h>
int main()
{
    int a, b, n, m;
    scanf("%d%d%d%d", &a, &b, &n, &m);
    int y = (m - a * n) / (b - a);
    int x = n - y;
    printf("%d %d", x, y);
    return 0;
}
```

### 方法二

纯暴力，从 0 开始枚举火星鸡的个数，然后就能知道火星兔的个数，最后验证此时是否确实是 $m$ 条腿，如果是那么就跳出循环。

采用这种方法，首先需要注意火星鸡与火星兔都有可能是 0 只，不要漏了这个极端情况。

其次，这种方法十分低效。注意到这个方法最坏情况下可能需要尝试 $n$ 次才能得到正确答案，而方法一解出方程之后，只需要进行常数次计算即可得到正确答案。虽然两种方法都能过，但如果本题的 $n$ 再大一点，你的程序就有可能没法在有限的时间内算出答案。因此，这个解法不好，不给出参考代码。

### 方法三

从实际提交中，我发现有些同学选择了一种比纯暴力更暴力的写法：不仅枚举火星鸡的数量，还不从火星鸡的数量直接推出火星兔的数量，而是又枚举火星兔的数量。

```c
for (int x = 0; x <= n; x++) {
    for (int y = 0; y <= n; y++) {
        ...
    }
}
```

这种写法在最坏情况下需要 $n^2$ 次枚举，比方法二还要笨。这样多的枚举次数已经多到无法在本题时限（1s）内枚举完毕了，千万不要这么写。

如果要判断你的程序能否在规定时间内跑完，可以这样大致算一下：评测机 1s 大约能跑 $10^8$ 次左右的循环。如果循环体本身比较简单，可能能再多跑个 $5$ 倍左右的循环。对于方法二，最坏情况 $2.5 \times 10^8$ 次的枚举已经比较极限，但也不是不能跑。而对于方法三，最坏情况 $6.25 \times 10^{16}$ 次循环，那怎么都不可能跑完了。

至于本题正解方法一，它没有循环，程序从开始到结束执行的代码总数是固定的，因此跑的飞快，一瞬间就结束了。

## D 剪彩带

| 难度 | 考点 |
| --- | --- |
| 2 | 最大公约数、循环、整数运算 |

### 题目

#### 题目背景

muzermat 和 SwaitL9 正在布置活动场地。SwaitL9 拿来两条彩带，长度分别为 a 厘米和 b 厘米。「把它们分成一样长的小段吧，每段都要是正整数厘米，两条都要用完。」SwaitL9 把剪刀递给了 muz ermat。 muzermat 把两条彩带的末端凑到了一起。「不许拼接。」他又举起剪刀，打算从第一条彩带上剪下一厘米。「你剪这么碎，等会儿可得自己收拾。」 muzermat 默默放下了剪刀，决定先算一算怎样才能让最后的小段总数最少。所有小段的长度必须相同，包括来自不同彩带的小段。两条彩带都不能有剩余，也不能将彩带或小段拼接起来；如果某条彩带已经符合要求，可以保留整条。请你帮 muzermat 求出最少的小段总数。

#### 题目描述

给定两条长度分别为正整数 a 和 b 的线段，将每条线段分别划分成若干个长度相同的小段，允许不作切分。所有小段具有相同的正整数长度，不允许剩余或拼接。求两条线段划分后的小段总数的最小值。

#### 输入

输入仅一组数据，共一行两个正整数 a 和 b，用一个空格隔开，分别表示两条彩带的长度。保证 1 ≤ a,b ≤ 104。

#### 输出

输出一行一个整数，表示最少的小段总数。

#### 输入样例 1

```text
12
18
```

#### 输出样例 1

```text
5
```

#### 输入样例 2

```text
5
5
```

#### 输出样例 2

```text
2
```

#### 输入样例 3

```text
3
7
```

#### 输出样例 3

```text
10
```

#### 样例解释

样例 1：将每段的长度定为 6 厘米，两条彩带分别分成 2 段和 3 段，共 5 段。不存在总段数更少的合法方案。样例 2：两条彩带均保留整条，共 2 段。样例 3：每段只能是 1 厘米，两条彩带分别分成 3 段和 7 段，共 10 段。

#### Hint

也许 这道题与最大公因数有关

Author: muzermat

### 答案

### 题目分析

设每一小段的长度为 $d$。由于两条彩带都不能有剩余， $d$ 必须同时整除 $a$ 和 $b$，也就是二者的公约数。

此时两条彩带分别得到 $a/d$ 段和 $b/d$ 段。每段越长，总段数越少，因此应该取最大的公约数。令 $g = \gcd(a,b)$，答案就是

$$
\frac{a}{g} + \frac{b}{g}.
$$

从 $a$ 、 $b$ 中较小的数开始向下枚举，只要当前数不能整除其中任意一个数，就继续减一。第一个同时整除两数的正整数就是最大公约数。由于 $1$ 一定是公约数，循环一定能在减到 $0$ 之前结束。

当两条彩带长度相等时，可以均保留整条，答案为 $2$；两数互质时，每段只能长 $1$，答案为 $a+b$。注意题目求的是总段数，不是每段长度，也不是剪切次数。

时间复杂度为 $O(\min(a,b))$，额外空间复杂度为 $O(1)$。每个输入不超过 $10^4$，枚举法可以满足要求，全部运算均可使用 `int`。

### 示例代码

```c
#include <stdio.h>
int main() {
    int a, b;
    scanf("%d%d", &a, &b);
    int gcd = a;
    if (b < gcd) {
        gcd = b;
    }
    while (a % gcd != 0 || b % gcd != 0) {
        gcd--;
    }
    printf("%d\n", a / gcd + b / gcd);
    return 0;
}
```

## E 仰望仰望星空

| 难度 | 考点 |
| --- | --- |
| 3 | 最大值，次大值维护 |

### 题目

#### 题目描述

盐仰望星空，它是那样寥廓而深邃。
盐同学在仰望星空时看见了现在的天空中有 n 颗星星，每颗星星都有一个正整数的亮度，盐同学想知道夜空中最亮的两颗星是什么。有时天空布满乌云，所以天空有时只有一颗星或没有星星可见；不可见的星星视为有无数多个，它们的亮度都是 0 。

#### 输入

共两行。
第一行，一个非负整数 n ，表示盐同学看见的星星的数量，满足 0 ≤ n ≤ 105 。
第二行， n 个正整数，每两个正整数间用一个空格隔开，表示这 n 颗星星的亮度 l1,l2,...,ln ；对任意的 1≤ i≤ n ，满足 1≤ li≤ 700 。

#### 输出

共一行两个整数，输出夜空中最亮的两颗星星的亮度，需满足第一个整数大于等于第二个整数，两个整数之间用一个空格隔开。

#### 输入样例

```text
5
1
2
3
4
5
```

#### 输出样例

```text
5 4
Tip
无需存储所有星星的亮度，维护最大值和次大值即可。
Provider : LCYing
出题人现在还不会唱仰望星空()
```

### 答案

### 题目分析

因为我们还没学过排序，而且只是为了求最大值和次大值而用一个数组记录所有星星的亮度是浪费内存的，所以我们转变思路，只记录当前的亮度最大值和次大值，每轮记录一个星星的亮度后就用它更新当前的最大值和次大值，n 轮后自然就是整体的最大值和次大值了。

先特判：n = 0时，答案为 `0 0`；n = 1时，答案为 $l_1, 0$。

$n \ge 2$ 时，假设我们在第 i 轮，现在我们刚读入了一个新的星星的亮度 $l_i$，我们如何用这个值去更新我们当前的最大值 $max$ 和次大值 $max2$ 呢？

我们想到分类讨论:

如果 $l_i \le max2$，比次大值还小，没有意义，跳过；

如果 $l_i \le max$ 且 $l_i > max2$，那么这个星星的亮度只能更新次大值，最大值不动；

如果 $l_i > max$，特别注意这种情况，新手容易犯的错误是直接更新最大值，但是这样会导致原本的最大值丢失，正确做法是先 `max2 = max;`，再 `max = curr;`

( curr 表示 $l_i$ ) 大家自行体会这个逻辑。

### 示例代码

```c
#include<stdio.h>
int main()
{
    int n;
    scanf("%d",&n);
    if(n == 0)
    {
        printf("0 0");
        // 我们可以在这用return 0; 想想如何用这个简化代码
    }
    else if(n == 1)
    {
        int l1;
        scanf("%d",&l1);
        printf("%d 0",l1);
    }
    else
    {
        int max = 0; // 初始最大值和次大值都是0
        int max2 = 0;
        int curr; // 当前的星星亮度
        // 如果没学过for 这个for的作用仅仅是循环n次 可用while代替
        for(int i = 1;i <= n;i ++)
        {
            scanf("%d",&curr);
            if(curr > max)
            {
                max2 = max;
                max = curr;
            }
            else if(curr > max2)
            {
                max2 = curr;
            }
        }
        printf("%d %d",max,max2);
    }
    return 0;
}
```

## F 想吃糖葫芦的SwaitL9

### 题目

#### 题目背景

「老师，我想吃糖葫芦！」
虽然现在不是冬天，但是这并不能阻挡 SwaitL9 想吃糖葫芦的心。于是，她找到了自己的老师 muzerm at，想让老师给自己买糖葫芦。但是，这家糖葫芦摊位是一家黑心商贩：第一根糖葫芦需要 k 元，第二根需要 2k 元，以此类推，第 i 根需要 ik 元。现在，muzermat 的钱包里有 n 元。请你算算，他是否能满足自家小徒弟买 w 根糖葫芦的要求；如果不能，还需要多少钱？

#### 题目描述

给定整数 k,n,w，购买第 i 根糖葫芦的价格为 ik 元。已有 n 元，需要购买 w 根糖葫芦，求还需要补充的金额。如果已有金额足够，答案为 0。程序需要连续处理若干组购买记录。各组记录相互独立，每组均从第一根开始计价。

#### 输入

输入包含若干行数据。每次先读取整数 k：如果 k=-1，则输入结束，该行只有一个整数 -1；否则，继续读取本行的两个整数 n,w。每组有效数据包含三个整数 k,n,w，用空格分隔，依次表示第一根糖葫芦的价格、已有金额和需要购买的根数。价格和金额的单位均为元。有效数据不超过 105 组，允许输入仅包含结束标记。对每组有效数据，保证 1≤ k≤1000，0≤ n≤10 9，1≤ w≤40000，且购买这 w 根糖葫芦的总费用不超过 109 元。

```text
40 4 3

```

```text

0
0
```


```text

```

#### 样例解释

样例 1：三组记录中，购买 4 根糖葫芦均需要 3+6+9+12=30 元。第一组已有 17 元，还需要 13 元；第二组已有 40 元，金额足够；第三组已有 30 元，恰好足够。样例 2：第一组购买 40000 根糖葫芦共需 800020000 元，已有金额为 0；第二组的已有金额恰好等于所需总费用。

Author: muzermat

### 答案

### 题目分析

第 $i$ 根糖葫芦的价格为 $ik$ 元，购买 $w$ 根的总费用为

$$
S = k + 2k + \cdots + wk = k(1 + 2 + \cdots + w).
$$

将 $1 + 2 + \cdots + w$ 正序和倒序各写一遍，对应位置相加，每对都等于 $w + 1$，一共有 $w$ 对。因此

$$
S = \frac{kw(w+1)}{2}.
$$

直接使用这个公式，每组只需常数次运算。若逐根累加，一组需要 $w$ 次循环；输入有很多组大规模数据时，累计运算量会很大。

已有金额为 $n$。如果 $S > n$，还需要 $S - n$ 元；否则答案为 $0$。可以先计算差额，再将负数改为 $0$。各组购买记录独立计算，不应累加到上一组的总费用中。

输入时先读取 $k$，只有在 $k \ne -1$ 时才读取本组的 $n, w$ 并计算答案。处理完一组后，再读取下一个 $k$；读到结束标记时不输出结果。

题目保证总费用 $S \le 10^9$，所以 `k * w * (w + 1)` 等于 $2S$，不超过 $2 \times 10^9$，其中各次乘法的中间值也不超过这个上界。差额 $S - n$ 位于 $-10^9$ 至 $10^9$ 之间，全部变量均可使用 32 位有符号 `int`。应先计算乘积再除以 $2$；直接将 $w$ 或 $k$ 先除以 $2$，可能因整数除法截断而出错。

设有效数据共有 $T$ 组，每组的时间复杂度为 $O(1)$，整个输入的时间复杂度为 $O(T)$，额外空间复杂度为 $O(1)$。

### 示例代码

```c
#include <stdio.h>
int main() {
    int k;
    scanf("%d", &k);
    while (k != -1) {
        int n, w;
        scanf("%d%d", &n, &w);
        int sum = k * w * (w + 1) / 2;
        int ans = sum - n;
        if (ans < 0) {
            ans = 0;
        }
        printf("%d\n", ans);
        scanf("%d", &k);
    }
    return 0;
}
```

## G 世界杯记分员

| 难度 | 考点 |

| 3 | 不定组输入、循环 |

### 题目

#### 题目描述

zzz还在怀念美加墨世界杯，他想统计一下各支球队的场均进球数。依次输入若干支球队每场比赛的进球数。对于每支球队： · 每场比赛的进球数为非负整数； · 输入 -1 表示当前球队的比赛数据输入结束； · 输入 -2 表示所有球队的数据输入结束。请计算并依次输出每支球队的场均进球数。场均进球数只保留整数部分。例如，某支球队 3 场比赛共进 5 球，其场均进球数为 5 / 3 = 1。保证每支球队至少有一场比赛。

#### 输入

输入若干个整数。
其中：
· 0 或正整数表示当前球队某场比赛的进球数；
· -1 表示当前球队的数据输入结束；
· -2 表示全部输入结束。
保证 -2 只会出现在一支球队的数据结束之后，即不会出现尚未用 -1 结束当前球队就直接输入 -2 的情况。

#### 输出

对于每支球队，输出一行，为该球队的场均进球数。

#### 输入样例

```text
2
1 3 -1 0 1 0 -1 4
3 -1 1 2 2 3 -1 -2
```

#### 输出样例

```text
2 0
3 2
```

#### 数据范围

保证每支球队最多进行 5 场比赛，每场进球数为 0~10，球队总数不超过 10 支。

### 答案

### 题目分析

课件中有这样一个例题：不断输入成绩，当输入 -1 时结束，然后计算这些成绩的平均数。

这道题与课件例题很相似。对于一支球队，我们也可以：

1. 不断输入每场比赛的进球数；
2. 用 sum 记录总进球数，用 n 记录比赛场数；
3. 遇到 -1 时，说明当前球队的数据输入结束；
4. 输出 sum / n ，得到这支球队的场均进球数。

但本题不只有一支球队，所以在课件中的 while 循环外面，还需要再加一层 while 循环：

- 内层循环：处理当前一支球队的所有比赛；
- 外层循环：依次处理所有球队，遇到 -2 时结束。

也就是说，本题可以看成“把课件中的求平均数过程重复若干次”。

### 方法一：双重 while 循环

先读入一个数 goal 。

- 如果 goal 不是 -2 ，说明还有一支球队需要处理，进入外层循环；
- 在内层循环中，只要 goal 不是 -1 ，就把它累加到 sum 中，并令比赛场数 n 加一；
- 当前球队统计完毕后，输出 sum / n ；
- 再读入一个数。这个数可能是下一支球队的第一场进球数，也可能是表示全部结束的 -2 。

循环结构可以概括为：

```text
读入 goal
while (goal 不是 -2)
{
    总进球数和比赛场数清零

    while (goal 不是 -1)
    {
        累加进球数
        比赛场数加一
        读入下一个 goal
    }

    输出当前球队的场均进球数
    读入下一支球队的第一个数据（或 -2）
}
```

注意：每处理一支新球队时，都要把 sum 和 n 重新设为 0 ，否则上一支球队的数据会影响下一支球队。

### 示例代码

```c
#include <stdio.h>
int main()
{
    int goal;
    int sum, n;
    scanf("%d", &goal);
    while (goal != -2)
    {
        sum = 0;
        n = 0;
        while (goal != -1)
        {
            sum = sum + goal;
            n = n + 1;
            scanf("%d", &goal);
        }
        printf("%d\n", sum / n);
        scanf("%d", &goal);
    }
    return 0;
}
```

由于 sum 和 n 都是整数，C 语言中的 sum / n 会进行整数除法，自动舍去小数部分，正好符合题目要求。

### 样例过程

以第一支球队的数据 `2 1 3 -1` 为例：

| 读入的 goal | sum | n |
| --- | --- | --- |
| 2 | 2 | 1 |
| 1 | 3 | 2 |
| 3 | 6 | 3 |
| -1 | 停止统计当前球队 | |

因此，这支球队的场均进球数为：

```text
6 / 3 = 2
```

随后继续读入下一支球队的数据。直到某支球队以 -1 结束后，再读到 -2 ，外层循环才会结束。

### 拓展：使用 break 的写法

break 可以立即结束它所在的那一层循环。这个语句如果还没有学过，可以先了解，不要求作为本题的主要写法。

在下面的代码中：

- 读到 -2 时，第一个 break 结束外层循环；
- 读到 -1 时，第二个 break 结束内层循环。

```c
#include <stdio.h>
int main()
{
    int goal;
    int sum, n;
    while (1)
    {
        scanf("%d", &goal);
        if (goal == -2)
        {
            break;
        }
        sum = 0;
        n = 0;
        while (1)
        {
            sum = sum + goal;
            n = n + 1;
            scanf("%d", &goal);
            if (goal == -1)
            {
                break;
            }
        }
        printf("%d\n", sum / n);
    }
    return 0;
}
```

这里的 while (1) 表示循环条件永远成立，因此必须在适当的位置用 break 结束循环。与第一种写法相比，它更依赖尚未学习的 break ，建议优先掌握前面的双重 while 写法。

#### Hint

可以按照以下步骤思考：

### 答案

### 题目分析

先把访问序号改成从 0 开始计数，记为 `p=k-1` 。

每行有 m 个格子，因此：

- `p/m` 表示从第 0 行开始数的行号；
- `p%m` 表示该格子在当前行中的位置，位置从 0 开始。

所以实际行号为 `p/m+1` 。奇数行从左到右，列号为 `p%m+1` ；偶数行从右到左，列号为 `m-p%m` 。

### 示例代码

```c
#include <stdio.h>
int main()
{
    int n, m, k;
    scanf("%d%d%d", &n, &m, &k);
    int p = k - 1;
    int x = p / m + 1;
    int y = p % m + 1;
    if (x % 2 == 0)
        y = m + 1 - y;
    printf("%d %d\n", x, y);
}
```

「盐巴」遇到了一个天文钟。对于每次询问，天文钟需要她计算 8∑i=1n∑j=1n∑k=1nijk。由于答案可能很大，你只需要输出结果对 10007 取模后的值。

接下来的 t 行，每行包含一个整数 n，满足 1 ≤ n < 998244353。

#### 输出

int 类型能够表示的数据范围为 [-231, 231-1]，而本题算出来的答案可能会远大于这个数字。你可能会需要下面这些关于取模的性质来避免超出 int 类型的表示范围： (a+b) mod m=(a mod m+ b mod m) mod m ab mod m=((a mod m)× (b mod m)) mod m 以及如果不了解多组测试数据是什么，可以在下面给出的代码模板中完成。 #include <stdio.h> int main() { int t; scanf("%d", &t); while (t--) { / 在这里完成一组测试数据 / } return 0; }

### 答案

### 题目分析

原式为 $8\sum_{i=1}^{n}\sum_{j=1}^{n}\sum_{k=1}^{n} ijk$，因为 $i,j,k$ 三个变量彼此独立，三重求和可以拆为 $\left(\sum_{i=1}^{n} i\right)^3$。

又因为 $\sum_{i=1}^{n} i = \dfrac{n(n+1)}{2}$，所以 $8\left(\dfrac{n(n+1)}{2}\right)^3 = n^3(n+1)^3$。

因此，只需计算 $n^3(n+1)^3 \bmod 10007$。每次乘法后立即取模，中间乘积小于 $10007^2$，使用 `int` 就可以安全保存。

### 正确性说明

根据乘法对求和的分配律，

$$
\sum_{i=1}^{n}\sum_{j=1}^{n}\sum_{k=1}^{n} ijk = \left(\sum_{i=1}^{n} i\right)\left(\sum_{j=1}^{n} j\right)\left(\sum_{k=1}^{n} k\right) = \left(\sum_{i=1}^{n} i\right)^3 .
$$

### 示例代码

```c
#include <stdio.h>
int main() {
    int t;
    scanf("%d", &t);
    while (t--) {
        int n;
        scanf("%lld", &n);
        int a = n % 10007;
        int b = (n + 1) % 10007;
        long long ans = 1;
        ans = ans * a % 10007;
        ans = ans * a % 10007;
        ans = ans * a % 10007;
        ans = ans * b % 10007;
        ans = ans * b % 10007;
        ans = ans * b % 10007;
        printf("%lld\n", ans);
    }
    return 0;
}
```

## J 塔塔？

### 题目

#### 题目背景

istina 在游玩《杀戮尖塔》时遇到了一名强大的敌人。他可以用武器直接攻击敌人，也可以不断向敌人施加中毒。为了尽可能减少战斗的风险，他希望用最少的轮数击败敌人，所以想麻烦你帮他算算。

#### 题目描述

敌人初始有 h 点生命值，中毒层数为 0。
在每一轮中，你必须选择以下两种行动中的一种：

1. 施加中毒：使敌人的中毒层数增加 a 层；2. 直接攻击：立即对敌人造成 b 点伤害。你的行动结束后： · 如果敌人的生命值已经小于或等于 0，敌人立即被击败，本轮结束； · 否则，进入敌人的回合。若敌人的中毒层数为 x，敌人受到 x 点伤害，随后中毒层数减少 1（最低减少到 0）。如果这次中毒伤害使敌人的生命值小于或等于 0，敌人也会被击败。敌人不会攻击，也不会产生其他效果。请你计算，最少需要多少轮才能击败敌人。

#### 输入格式

输入一行，包含三个正整数 h,a,b，分别表示敌人的初始生命值、每次施加的中毒层数和每次直接攻击造成的伤害。三个整数之间用一个空格分隔。题目保证 1 ≤ h,a,b ≤ 1000。

#### 输出格式

输出一个整数，表示击败敌人所需的最少轮数。样例 1

#### 输入

20 4 5

7 2 10

#### 输出

3

1

#### 样例解释

可以采用如下行动：
轮数 选择的行动 行动后的生命值 中毒结算 结算后的生命值和中毒层数

1 施加 4 层中毒 20 受到 4 点伤害 生命值为 16，中毒为 3 层

2 施加 4 层中毒 16 受到 7 点伤害 生命值为 9，中毒为 6 层

3 直接造成 5 点伤害 4 受到 6 点伤害 敌人被击败

无法在 2 轮内击败敌人，因此最少需要 3 轮。样例 2

第一轮直接攻击可以造成 10 点伤害，敌人立即被击败，因此不再进行本轮的中毒结算。

### 答案

### 题目分析

这题首先需要发现一个结论：

最优的决策一定是先连续若干回合施加中毒，再连续攻击直至击败敌人/

证明可以从交换的角度考虑：如果某方案中出现先攻击，下一个回合施加中毒的情况，那么我们交换它们的顺序造成的伤害一定不会更少。经历这样反复交换的方案一定是施加中毒在前，直接攻击在后的。

所以我们可以枚举使用了多少次投毒。当投毒次数确定后，需要几次额外的直接攻击才能击败敌人也确定下来了，我们可以模拟这个过程求出答案。

具体的实现细节可以参考下面的代码：

### 示例代码

```c
#include <stdio.h>
int main() {
    int h, a, b;
    scanf("%d%d%d", &h, &a, &b);
    int ans = h; // 用于记录击败敌人的最少回合数（由于 a, b 都不小于 1, 这个数肯定不会超过 h）
    for (int i = 0; i <= h; i++) { // 枚举前几个回合使用毒
        int d = (a + (i * a - (i - 1))) * i / 2;
        // 毒的伤害为 a, 2a - 1, 3a - 2...可用等差数列求和公式
        if (d >= h) {
            if (ans > i) ans = i; // 更新答案的最小值
        } else {
            int ret = h - d; // 前 i 个回合之后敌人的剩余生命
            for (int j = 1; j <= h; j++) {
            // 枚举还要几个回合才能击败敌人（至少还需要一回合）
                int atk = b; // 此回合的攻击伤害
                int poison = i * a - (i - 1) - j; // 此回合的毒伤害
                if (poison < 0) poison = 0; // 中毒层数最低为 0
                ret -= (atk + poison);
                if (ret <= 0) {
                    if (ans > i + j) ans = i + j;
                    break;
                }
            }
        }
    }
    printf("%d\n", ans);
}
```
