## A 课程微信群

### 题目

#### 题目背景

新学期开始了，北航程序设计基础课程的微信群迎来了许多入群申请。为了让选课同学顺利入群，老师请你帮忙核对大家提供的验证码。

#### 题目描述

选修北航程序设计基础课程的同学可以得到加入课程微信群的验证码。

本期课程设定的验证码为数字 $k$，现在一共有 $n$ 个人申请加入微信群，第 $i$ 个人提供的验证码为 $a_i$。

只有提供的验证码与 $k$ 相同，才能通过入群申请。请你计算一共应该通过多少人的申请。

#### 输入

第一行两个整数 $n, k$，由一个空格分隔，分别代表申请入群的人数和课程设定的验证码。

接下来 $n$ 行，每行一个整数 $a_i$，代表第 $i$ 个人提供的入群验证码。

其中 $1 \le n \le 5000$， $1 \le a_i, k \le 10^4$。

#### 输出

一行一个整数，代表应该通过入群申请的人数。

#### 样例输入

```text
4 7
7
7
8
7
```

#### 样例输出

```text
3
```

### 答案

| 难度 | 考点 |
| --- | --- |
| 1 | 循环、条件判断、计数 |

### 解题思路

读取人数 $n$ 和正确验证码 $k$ ，然后循环读入每位申请人提供的验证码。若当前验证码等于 $k$ ，就将答案加一。

本题不需要保存所有验证码，边读边判断即可。时间复杂度为 $O(n)$ ，额外空间复杂度为 $O(1)$ 。

### 示例代码

```c
#include <stdio.h>

int main() {
    int n, k;
    scanf("%d%d", &n, &k);

    int ans = 0;
    for (int i = 0; i < n; i++) {
        int x;
        scanf("%d", &x);
        if (x == k) {
            ans++;
        }
    }

    printf("%d\n", ans);
    return 0;
}
```

## B 测测你的格雷电压等级

### 题目

#### 题目背景

在 GregTech 中，电压被分为若干个等级，每个等级都有属于自己的额定电压。

只不过，在如今的整合包中，muzermat 将其拥有的电压等级大幅度增多，这也导致你的肝即将报废。

现在，你需要求出这些电压等级所对应的额定电压。

#### 题目描述

对于电压等级 0，其对应的基础电压为 8V，电压等级每提升 1，其对应的额定电压将变为原来的 4 倍。

你可能需要下面这个函数：

```c
long long qpow(long long a, int b, long long P) {
    long long ans = 1;
    a %= P;
    while (b > 0) {
        if (b & 1) {
            ans = ans * a % P;
        }
        a = a * a % P;
        b >>= 1;
    }
    return ans % P;
}
```

该函数返回 $a^b \bmod P$ 的值。

#### 输入

输入共 $T + 1$ 行。

第一行，一个正整数 $T$，表示测试数据组数， $1 \le T \le 10^5$。

接下来 $T$ 行，每行一个非负整数 $n$，表示该组数据所对应的等级编号， $0 \le n \le 10^8$。

#### 输出

对于每组数据，输出一行，一个整数，表示第 $n$ 级的额定电压。

答案也许会很大，所以你需要输出答案对 1000000007 取模的结果。

#### 输入样例1

```text
5
0
1
3
14
100000000
```

#### 输出样例1

```text
8
32
512
147483634
882330614
```

#### 输入样例2

```text
1
13
```

#### 输出样例2

```text
536870912
```

#### 样例解释

样例 1：第 0 级的额定电压为 8，第 1 级为 32，第 3 级为 512。第 14 级的额定电压为 2147483648，对 1000000007 取模的结果为 147483634。

样例 2：第 13 级的额定电压为 536870912，取模后仍为 536870912。

Author: muzermat

### 答案

| 难度 | 考点 |
| --- | --- |
| 1 | 题给函数的接口调用、快速幂、取模 |

### 解题思路

第 $0$ 级的额定电压为 $8$ ，每升高一级乘以 $4$ ，所以第 $n$ 级的额定电压为

$$
8 \times 4^n.
$$

题目已经给出了快速幂函数 `qpow` 。对于每组数据，调用 `qpow(4, n, 1000000007)` ，将返回值乘以 $8$ ，再对 $1000000007$ 取模即可。最后一次取模不能省略，因为乘以 $8$ 后可能再次超过模数。

单组数据的时间复杂度为 $O(\log n)$ ，额外空间复杂度为 $O(1)$ 。

### 示例代码

```c
#include <stdio.h>

const long long mod = 1000000007;

long long qpow(long long x, int n, long long p) {
    long long ans = 1;
    x %= p;
    while (n) {
        if (n & 1) {
            ans = ans * x % p;
        }
        x = x * x % p;
        n >>= 1;
    }
    return ans;
}

int main() {
    int T;
    scanf("%d", &T);
    while (T--) {
        int n;
        scanf("%d", &n);
        printf("%lld\n", 8LL * qpow(4, n, mod) % mod);
    }
    return 0;
}
```

## C 测测你的组合数学

### 题目

#### 题目描述

杨辉三角是一种按照如下规则排列数字的三角形：

- 第一行只有一个数字 1。
- 从第二行开始，每行的第一个数和最后一个数都是 1，其余每个数等于上一行中它左上方和正上方两个数之和。

例如，前 5 行为：

```text
1
1 1
1 2 1
1 3 3 1
1 4 6 4 1
```

给定正整数 $n$，请输出杨辉三角的前 $n$ 行。

由于其中的数可能很大，每个数都需要对 998244353 取模后再输出。

#### 输入

第一行，一个正整数 $n$，表示要输出的行数，满足 $1 \le n \le 1000$。

#### 输出

输出 $n$ 行。第 $i$ 行包含 $i$ 个整数，按照从左到右的顺序输出杨辉三角第 $i$ 行的所有数，每个数均对 998244353 取模。

#### 输入样例 1

```text
5
```

#### 输出样例 1

```text
1
1 1
1 2 1
1 3 3 1
1 4 6 4 1
```

#### 输入样例 2

```text
1
```

#### 输出样例 2

```text
1
```

#### hint

取模并不遵循 $\frac{a}{b} \bmod p = \frac{a \bmod p}{b \bmod p}$ 的性质哦。

### 答案

| 难度 | 考点 |
| --- | --- |
| 2 | 数组、递推、取模 |

### 解题思路

杨辉三角每一行的首尾都是 $1$ ，中间的数满足

$$
C(i, j) = C(i - 1, j - 1) + C(i - 1, j).
$$

可以使用一个一维数组保存当前行。生成新的一行时必须从右向左更新： `row[j]` 的新值等于原来的 `row[j]` 与 `row[j-1]` 之和。如果从左向右更新， `row[j-1]` 会先变成新一行的值，导致同一轮使用了错误的数据。

第 $i$ 行更新完成后输出 `row[0]` 至 `row[i-1]` 。每次加法后取模即可，不需要也不能使用带除法的组合数公式。

时间复杂度为 $O(n^2)$ ，额外空间复杂度为 $O(n)$ 。

### 示例代码

```c
#include <stdio.h>

#define N 1005
#define mod 998244353

int a[N];

int main() {
    int n;
    scanf("%d", &n);

    a[0] = 1;
    for (int i = 1; i <= n; i++) {
        for (int j = i - 1; j >= 1; j--) {
            a[j] = (a[j] + a[j - 1]) % mod;
        }

        for (int j = 0; j < i; j++) {
            if (j > 0) {
                putchar(' ');
            }
            printf("%d", a[j]);
        }
        putchar('\n');
    }
    return 0;
}
```

## D Spin 2 Win

### 题目

#### 题目背景

![D 题题目背景配图（QQ 聊天截图）](image/E5-D-题目背景.png)

#### 题目描述

给出两个点 $P = (x_1, y_1)$、 $Q = (x_2, y_2)$，求 $P$ 绕 $Q$ 逆时针旋转 $\alpha^\circ$ 后的点。

#### 输入格式

本题有多组测试数据。

第一行输入一个整数 $T$（ $1 \le T \le 10^5$），表示测试数据组数。

接下来 $T$ 行，每行输入五个整数 $x_1, y_1, x_2, y_2, \alpha$（ $-10^4 \le x_1, y_1, x_2, y_2 \le 10^4$， $0 \le \alpha < 360$），表示一次询问。

#### 输出格式

对于每个询问，输出一行两个浮点数，表示答案的 $x$、 $y$ 坐标。

你的答案被认为正确，当且仅当两个坐标均与参考答案的绝对或相对误差不超过 $10^{-9}$。

#### 样例输入

```text
4
1 0 0 0 90
3 4 1 1 180
5 5 5 5 37
-10000 10000 10000 -10000 270
```

#### 样例输出

```text
0.0000000000 1.0000000000
-1.0000000000 -2.0000000000
5.0000000000 5.0000000000
30000.0000000000 10000.0000000000
```

#### 样例解释

- 第 1 组数据把点 $(1,0)$ 绕原点逆时针旋转 $90^\circ$，得到 $(0,1)$。
- 第 3 组数据中待旋转点恰好是旋转中心，因此旋转角度不会改变答案。

Author: ExplodingKonjac

### 答案

| 难度 | 考点 |
| --- | --- |
| 2 | 函数调用、三角函数、平面坐标旋转、浮点输出 |

### 解题思路

先把旋转中心 $Q = (x_2, y_2)$ 平移到原点。点 $P$ 相对于 $Q$ 的坐标为

$$
dx = x_1 - x_2, \qquad dy = y_1 - y_2.
$$

将角度转换为弧度 $\theta = \alpha\pi/180$ ，逆时针旋转后的相对坐标为

$$
dx' = dx\cos\theta - dy\sin\theta,
$$

$$
dy' = dx\sin\theta + dy\cos\theta.
$$

最后把旋转中心平移回去，答案为 $(x_2 + dx', y_2 + dy')$ 。当 $P = Q$ 时， `dx` 和 `dy` 都为零，上述公式仍然成立，不需要特判。

使用 `double` ，并输出足够多的小数位。单组数据时间复杂度和额外空间复杂度均为 $O(1)$ 。

### 示例代码

```c
#include <math.h>
#include <stdio.h>

int main() {
    const double PI = acos(-1.0);
    int T;
    scanf("%d", &T);
    while (T--) {
        int x1, y1, x2, y2, alpha;
        scanf("%d%d%d%d%d", &x1, &y1, &x2, &y2, &alpha);

        double t = alpha * PI / 180.0;
        double a = x1 - x2, b = y1 - y2;
        double x = x2 + a * cos(t) - b * sin(t);
        double y = y2 + a * sin(t) + b * cos(t);

        printf("%.10f %.10f\n", x, y);
    }
    return 0;
}
```

## E 琪露诺的雪花

### 题目

#### 题目描述

琪露诺作为冰之妖精，每天都在盼着冬天。

可是，在她等了很久之后，却发现现在还只是秋天。因此，她打算向你索要一个巨大的雪花，让这个世界提前变成冬天！

为了保住同学们珍贵的秋天，你决定给她画一个假雪花。很快，你就画出了一个草图。

```text
  *       *
    *   *
*  *  *  *  *
    *   *
  *       *
```

琪露诺很笨——她会把这种六个角的东西都当成雪花。你能完成这个任务吗？

形式化地讲，给定整数 $n$，以雪花中心为原点 $(0,0)$ 建系，定义点集

$$
S = \{(3k, 0) \mid -n \le k \le n\} \cup \{(2d, d), (2d, -d), (-2d, d), (-2d, -d) \mid 1 \le d \le n\}
$$

输出时，对 $-3n \le x \le 3n$， $-n \le y \le n$ 内的坐标 $(x,y)$ 按位置逐个输出：

- 若 $(x,y) \in S$，输出 `*`；
- 否则输出空格，行末空格会被忽略。

#### 输入

一个整数 $n$（ $1 \le n \le 30$）。

#### 输出

输出 $2n + 1$ 行，一个臂长为 $n$ 的“雪花”字符画。字符仅由 `*` 构成。其中水平方向的点位之间有两个空格，倾斜方向的点位之间有一个空格和一个换行。

#### 输入样例

```text
3
```

#### 输出样例

```text
   *           *   
     *       *     
       *   *       
*  *  *  *  *  *  *
       *   *       
     *       *     
   *           *   
```

#### Hint

考虑到代码框里的空格可能看不清楚，你画出来的雪花在网格里其实是这样的:

```text
···*···········*···
·····*·······*·····
·······*···*·······
*··*··*··*··*··*··*
·······*···*·······
·····*·······*·····
···*···········*···
```

Author: The__Flames

### 答案

| 难度 | 考点 |
| --- | --- |
| 3 | 循环、条件判断、字符画 |

### 解题思路

按照题目给出的坐标系，从上到下枚举行，即令纵坐标 $y$ 从 $n$ 递减到 $-n$ ；每行从左到右枚举横坐标 $x$ ，范围为 $-3n$ 到 $3n$ 。

雪花上的点分为两类：

- 水平臂上的点： $y = 0$ ，并且 $x$ 是 $3$ 的倍数；

- 四条斜臂上的点： $y \ne 0$ ，并且 $|x| = 2|y|$ 。

满足任意一个条件就输出 `*` ，否则输出空格。题目允许忽略行末空格，因此可以直接输出整个矩形区域。

时间复杂度为 $O(n^2)$ ，额外空间复杂度为 $O(1)$ 。

### 示例代码

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    int n;
    scanf("%d", &n);

    for (int y = n; y >= -n; y--) {
        for (int x = -3 * n; x <= 3 * n; x++) {
            if ((y == 0 && x % 3 == 0) ||
                (y != 0 && abs(x) == 2 * abs(y))) {
                putchar('*');
            } else {
                putchar(' ');
            }
        }
        putchar('\n');
    }
    return 0;
}
```

## F Exoplanetary Mirage

### 题目

#### 题目背景

> 系外幻象
>
> 收集时间：773.A.P.??.??
>
> 保管单位：鸠
>
> 等级：bold
>
> 两年后，另一支队伍在航行中意外发现了星球Ca-773，但因为当地大气的小信号屏蔽干扰，队伍彻底和地球失去了联系。
>
> 2089年，人们再次收到星球Ca-773的通讯，同年，PhigrOS计划第一次实验正式开启。

#### 题目描述

对于所有不小于 4 的合数 $x$，定义系外拆分 $x = c \times d$， $c \le d$ 且 $c$ 是满足条件最大的正整数。

对于所有不小于 4 的质数 $x$，定义幻象拆分 $x = a + b$， $a \le b$ 且 $a$ 是满足条件最大的质数。

现在给定 $x$ 可以生成算式 $S(x)$，满足：

1. 若 $x \le 3$，则算式 $S(x) = x$；
2. 否则若 $x$ 是质数，则算式 $S(x) = S(a) + S(b)$，其中 $x = a + b$ 是幻象拆分。
3. 否则 $x$ 是合数，则算式 $S(x) = [S(c)]*[S(d)]$，其中 $x = c \times d$ 是系外拆分。

其中，字符 `+`、`*`、`[`、`]` 是输出字符。

对于每个输入的 $x$ 求由以上规则生成的算式 $S(x)$。

#### 输入

本题包含多组测试数据。

第一行一个正整数 $T$，表示数据组数。

接下来 $T$ 行，每行一个正整数 $x$。

数据保证 $1 \le T \le 10^3$， $1 \le x \le 2 \times 10^5$；

#### 输出

对于每组数据，输出一样一个算式，表示 $S(x)$。

#### 输入样例

```text
8
1
2
3
4
5
11
12
49
```

#### 输出样例

```text
1
2
3
[2]*[2]
2+3
2+3+[2]*[3]
[3]*[[2]*[2]]
[3+[2]*[2]]*[3+[2]*[2]]
```

#### 样例说明

1, 2, 3 不需要拆分，直接输出自身。其余几组数据的第一次拆分如下：

| $x$ | 第一次拆分 | 最终算式 $S(x)$ |
| --- | --- | --- |
| 4 | $4 = 2 \times 2$ | `[2]*[2]` |
| 5 | $5 = 2 + 3$ | `2+3` |
| 11 | $11 = 5 + 6$ | `2+3+[2]*[3]` |
| 12 | $12 = 3 \times 4$ | `[3]*[[2]*[2]]` |
| 49 | $49 = 7 \times 7$ | `[3+[2]*[2]]*[3+[2]*[2]]` |

对于 $11 = 5 + 6$，只要求 $a = 5$ 是质数， $b = 6$ 可以是合数。

对于 12，虽然也能拆成 $2 \times 6$，但题目要求 $c$ 尽可能大，因此选择 $3 \times 4$。

对于 49，有 $S(7) = 3 + [2] * [2]$，因此两个乘数的算式都需要用中括号括起来。

Author: Windowsredstone vs. WinRs

### 答案

| 难度 | 考点 |
| --- | --- |
| 3 | 递归、质数判断、因数枚举、递归输出 |

### 解题思路

按照题目对 $S(x)$ 的定义直接递归输出即可。

- 若 $x \le 3$ ，直接输出 $x$ ；

- 若 $x$ 是质数，从 $\lfloor x/2 \rfloor$ 开始向下寻找最大的质数 $a$ ，令 $b = x - a$ ，递归输出 `S(a)+S(b)` ；

- 若 $x$ 是合数，枚举不超过 $\sqrt{x}$ 的因数，最后找到的因数就是最大的 $c \le d$ ，其中 $d = x/c$ ，递归输出 `[S(c)]*[S(d)]` 。

题目要求的是输出算式，因此不需要真的计算加法或乘法。注意合数拆分的两个子表达式外必须输出中括号。

### 示例代码

```c
#include <stdio.h>

int isprime(int x) {
    if (x <= 1) {
        return 0;
    }
    for (int i = 2; i <= x / i; i++) {
        if (x % i == 0) {
            return 0;
        }
    }
    return 1;
}

void s(int x) {
    if (x <= 3) {
        printf("%d", x);
        return;
    }
    if (isprime(x)) {
        int a = x / 2;
        while (!isprime(a)) {
            a--;
        }
        s(a);
        putchar('+');
        s(x - a);
    } else {
        int c = 1;
        for (int i = 1; i <= x / i; i++) {
            if (x % i == 0) {
                c = i;
            }
        }
        putchar('[');
        s(c);
        printf("]*[");
        s(x / c);
        putchar(']');
    }
}

int main() {
    int T;
    scanf("%d", &T);
    while (T--) {
        int x;
        scanf("%d", &x);
        s(x);
        putchar('\n');
    }
    return 0;
}
```

## G 数论函数

### 题目

#### 题目描述

数论函数 $f_{n,m}$ 按如下方式定义

$$
f_{n,m} =
\begin{cases}
m^3, & n \ge 1,\ m > n \\
1, & n \le 0 \\
n^2, & n \ge 1,\ m \le 0 \\
f_{n-1,m} \times f_{n-2,m+1} + f_{n,m-1} \times f_{n-1,m+1} \times f_{n-1,m-2}, & \text{otherwise}
\end{cases}
$$

给定 $n, m$，请求出该数论函数在点 $(n,m)$ 处的值 $f_{n,m}$。

这个函数的增长极为迅速，你只需输出 $f_{n,m} \bmod 998244353$ 的结果即可。

### 解题思路

如果完全按照递推式裸递归，同一个 $f_{n,m}$ 会被反复计算。例如不同的递归分支可能同时需要 $f_{4,4}$ ，从而继续重复计算它下面的所有状态，最终导致超时。

函数的参数相同，返回值就一定相同。因此第一次算出 $f_{n,m}$ 后，可以把结果存入二维数组；以后再次访问同一状态时直接返回已经保存的值。这就是记忆化搜索。

递归函数应当先判断三个边界条件，再访问记忆化数组：

1. $n \ge 1$ 且 $m > n$ 时返回 $m^3 \bmod MOD$ ；

2. $n \le 0$ 时返回 $1$ ；

3. $n \ge 1$ 且 $m \le 0$ 时返回 $n^2$ 。

递归过程中 $m$ 可能因为 `m + 1` 增大，不能只按照输入的 $m \le 2000$ 判断状态范围。不过只有 $1 \le m \le n \le 3000$ 的状态会真正进入记忆化数组，因此将两个维度都开到 $3000$ 是安全的。

乘法必须先转换成 `long long` ，并且每次乘法后及时取模。能够被记忆化的状态不超过 $O(n^2)$ 个，空间复杂度为 $O(n^2)$ 。

#### 递归的三个组成部分

> 从这道题可以学习到递归的几个组成部分：
>
> 1. 结束条件。通常又称为“边界条件”，指的是使得递归函数结束而不再继续递归的条件。结束条件是关键的，如果没有结束条件，那么程序将无限递归而导致永远无法结束。这种情况我们可以大略的统称为“死循环”或者“死锁”，虽然它和循环没有关系。
>
>    注意死循环和超时是有区别的。超时可能只是算法太慢了，终归可以有结束的那一天，哪怕海枯石烂、沧海桑田；但是死循环是永远无法结束的，理论上都没有结束的那一天。从某个角度说，超时只是因此我们现在的计算技术还不够先进、不够快速，所以庞大的计算量我们无法接受。但是死循环，无论你投入多大的算力，都不会有结束的那一天。
>
> 2. 处理段。通常，程序进入递归函数时都是不符合结束条件的（不然不就不用递归了嘛）。为了使程序能满足结束条件，函数必须修改一些参数，可能是内部参数也可能是外部参数。总之一要修改一些东西使得结束条件是可逼近的。如果处理段没写好，程序可能永远无法触及结束条件，发生另外一类的死循环。
>
>    其实循环语句中也是这样，必须要有修改循环变量的途径，不然循环只有执行 `0` 次和执行无限多次两种选择。
>
> 3. 递归体。即函数递归的调用自己本身的语句。递归体和处理段可能无法物理区分，就像本题这样。通常，函数递归调用自己时，传递参数都会发生变化，以保证结束条件是可达的。但是，如果处理段修改了某些和函数递归强相关的外部参数时，有时内部参数（即传递的参数）可以不变。

#### 记忆化数组的范围

为什么 $1 \le m \le 2000$ 但 $f$ 数组需要开到 3000。因为递归 $f_{n,m}$ 的时候，需要计算 $f_{n-2,m+1}$ 和 $f_{n-1,m+1}$ ，也就是说递归的过程中参数 $m$ 是可能在增大的。最极端情况下 $n = 3000, m = 2000$ ， $n$ 每次减小 1， $m$ 每次增大 1，因此 $m$ 最大可能达到 2500。这里直接设置成 3000 有点太保守，但是只设置为 2000 是一定不行的！

#### 取模与初始值细节

代码有不少细节需要注意。

1. 涉及到取模的题目一定要处处小心，那里有可能会爆 int，一定要强制类型转化。
2. 记忆化数组（即代码中的 $f$ ）一定要赋初始值，而且这个初始值最好是正常的函数值不会取到的结果。不然可能会导致这个点的函数值就是这个初始值，但是程序误以为是这个点还没计算过导致重复计算。

#### memset 只能正确赋 0 和 -1

关于 `memset` 函数。从本题中似乎可以认为这个函数的作用就是把某个数组全部赋上一个初始值，第二个参数是多少就赋值多少的初始值。其实不然！这就是这个函数最不好用的地方！

   先说结论，使用 `memset` 赋初始值时，只有当第二个参数是 `0` 和 `-1` 时， $f$ 数组的每一位初始值才等于第二个参数。即 `memset(f,a,sizeof(a))` 当且仅当 $a = 0$ 或 $a = -1$ 时， $f$ 每一位的初始值等于 $a$ 。原因是 `memset` 是按每八位进行赋值的，而不是按照 int 的 `32` 位进行赋值的。用计算机数的二进制补码表示可以容易理解这个结论。不理解也没关系了，记住吧。

   除了 `0` 和 `-1` 外，还有两种情况是常用的，即 $a = 127$ 和 $a = 128$ 。前者会把 $f$ 初始化为一个很大的数（接近 int 最大值的一半），后者会把 $f$ 初始化为一个很小的数（是 $a = 127$ 时的相反数）。前者适合 $f$ 需要和其它数相比较求最小值时的赋初始值，后者适合求最大值。

   如果我就需要把 $f$ 的每一位赋值为 `0` 或者 `-1` 以外的其它数该怎么办办呢？ `memset` 是用不了了，但是不阻止我们可以用 for 循环呐！

### 示例代码 1：使用 -1 表示尚未计算

```c
#include <stdio.h>
#include <string.h>

#define N 3010
#define mod 998244353

int f[N][N];

int calc(int n, int m) {
    if (m > n && n >= 1) {
        return (long long)m * m % mod * m % mod;
    }
    if (n <= 0) {
        return 1;
    }
    if (m <= 0) {
        return n * n;
    }
    if (f[n][m] != -1) {
        return f[n][m];
    }

    return f[n][m] = ((long long)calc(n - 1, m) * calc(n - 2, m + 1) % mod
        + (long long)calc(n, m - 1) * calc(n - 1, m + 1) % mod
        * calc(n - 1, m - 2) % mod) % mod;
}

int main() {
    memset(f, -1, sizeof(f));

    int T;
    scanf("%d", &T);
    while (T--) {
        int n, m;
        scanf("%d%d", &n, &m);
        printf("%d\n", calc(n, m));
    }
    return 0;
}
```

| 4 | 一维数组、双指针、单调性、增量维护区间和 |

### 解题思路

每次只能取走当前序列的一端，因此最终取走的元素一定是原数组的一段前缀和一段后缀，两部分不能重叠。反过来，任意互不重叠的前缀和后缀，都可以通过若干次左端攻击和右端攻击取走。

用 `l` 表示左侧前缀的最后一个下标，取走 $[1, l]$ ；用 `r` 表示右侧后缀的第一个下标，取走 $[r, n]$ 。两部分不重叠要求 `l < r` ，取走数量为

$$
l + n - r + 1.
$$

维护 `pre` 和 `suf` ，分别表示两部分的元素和。固定 `l` 后，希望 `r` 尽可能小，因为这样右侧能取走更多元素。如果两部分重叠，或者总和超过预算，就不断让 `r` 右移，并从 `suf` 中删去原来的 `a[r]` 。

由于所有 $a_i$ 都是正数， `l` 增大后，可行的最小 `r` 只可能保持不变或继续增大，不可能向左回退。因此两个指针都只会单向移动，所有内层循环加起来最多执行 $n$ 次。

如果 `pre > B` ，后续前缀和只会更大，可以直接结束。元素总和可能达到 $10^{14}$ ，预算和两个区间和必须使用 `long long` 。

时间复杂度为 $O(n)$ ，额外空间复杂度为 $O(1)$ （不计存放原数组的空间）。

### 示例代码

```c
#include <stdio.h>

#define N 100005

int a[N];

int main() {
    int n;
    long long b;
    scanf("%d%lld", &n, &b);

    long long suf = 0;
    for (int i = 1; i <= n; i++) {
        scanf("%d", &a[i]);
        suf += a[i];
    }

    long long pre = 0;
    int r = 1, ans = 0;

    for (int l = 0; l <= n; l++) {
        if (l > 0) {
            pre += a[l];
        }
        if (pre > b) {
            break;
        }

        while (r <= l || pre + suf > b) {
            suf -= a[r];
            r++;
        }

        int cnt = l + n - r + 1;
        if (cnt > ans) {
            ans = cnt;
        }
    }

    printf("%d\n", ans);
    return 0;
}
```

### 解题思路

先研究单点的 $f(x)$ 。设正整数 $x$ 的三进制表示共有 $len(x)$ 位，各位数字之和为 $sum(x)$ ，可以证明

$$
f(x) = len(x) + sum(x).
$$

证明可以从三进制最低位考虑。设 $x = 3q + d$ ，其中 $d \in \{0,1,2\}$ ：

- $d = 0$ 时，题目递归式直接得到 $f(x) = f(q) + 1$ ；

- $d = 1$ 时，先减一次变成 $3q$ ，再除以 $3$ ，所以 $f(x) = f(q) + 2$ ；

- $d = 2$ 时，需要先减两次再除以 $3$ ，所以 $f(x) = f(q) + 3$ 。

在三进制表示末尾增加数位 $d$ ，位数增加 $1$ ，数位和增加 $d$ ，总增量恰好是 $d + 1$ 。结合 $f(0) = 1$ ，公式成立。

于是问题变成：在 $[l, r]$ 中寻找“位数 + 三进制数位和”最大的整数。

除了 $r$ 本身，最优数还可能通过以下方式从 $r$ 构造：选择 $r$ 的某一位，将这一位减 $1$ ，并把所有更低位都改成 $2$ 。这样得到的数不超过 $r$ ，并且在固定高位的情况下数位和最大。

为了保证候选数不小于 $l$ ，先找出 $l$ 和 $r$ 的三进制表示中最高的不同位 `p` 。只需要枚举不高于该位置的数位：

- 在更低位置修改时，候选数仍在最高不同位保留 $r$ 的较大数字，因此一定大于 $l$ ；

- 在最高不同位修改时，低位全部填 $2$ ，所得候选也不会小于 $l$ 。

对所有合法候选以及 $r$ 本身计算 $len + sum$ ，取最大值即可。 $10^{18}$ 的三进制表示不超过 $40$ 位，单组时间复杂度为 $O(40^2)$ ，也可以视为 $O(\log^2 r)$ ；额外空间复杂度为 $O(\log r)$ 。

### 示例代码

```c
#include <stdio.h>

#define N 40

void trans(unsigned long long x, int a[]) {
    for (int i = 0; i < N; i++) {
        a[i] = x % 3;
        x /= 3;
    }
}

int calc(int a[]) {
    int p = N - 1;
    while (p > 0 && a[p] == 0) {
        p--;
    }

    int ans = p + 1;
    for (int i = 0; i < N; i++) {
        ans += a[i];
    }
    return ans;
}

int main() {
    int T;
    scanf("%d", &T);
    while (T--) {
        unsigned long long l, r;
        scanf("%llu%llu", &l, &r);

        int a[N] = {0}, b[N] = {0}, c[N] = {0};
        trans(l, a);
        trans(r, b);

        if (l == r) {
            printf("%d\n", calc(a));
            continue;
        }

        int p = N - 1;
        while (a[p] == b[p]) {
            p--;
        }

        int ans = calc(b);
        for (int k = 0; k <= p; k++) {
            if (b[k] == 0) {
                continue;
            }

            for (int i = 0; i < N; i++) {
                c[i] = b[i];
            }
            c[k]--;
            for (int i = 0; i < k; i++) {
                c[i] = 2;
            }

            int now = calc(c);
            if (now > ans) {
                ans = now;
            }
        }

        printf("%d\n", ans);
    }
    return 0;
}
```

### 题目

#### 题目描述

一个 $nk$ 谱面可以用一个 $m \times n$ 的字符矩阵表示。字符矩阵的从下往上第 $i$ 行的从左往右第 $j$ 个字符，表示第 $i$ 拍的第 $j$ 个轨道是否有 note：`_` 表示这里有一个 note，`.` 表示这里没有 note。

定义一个谱面是『仁王盾』，当且仅当这个谱面：

- 每一个拍子都至少存在两个 note；
- 不存在一个轨道，使得这个轨道上存在连续两拍都有 note。

比如下面的谱面是一个『仁王盾』：

```text
_._._
._._.
_._._
._._.
_._._
._._.
_._._
._._.
_._._
```

现在给定 $n, m$，请问有多少种不同的包含 $m$ 拍的 $nk$ 谱面是一个『仁王盾』？由于答案很大，你需要输出答案对 1000000007 取模后的值。

#### 输入格式

本题有多组测试数据。

第一行一个整数 $T$ 表示测试数据组数，满足 $1 \le T \le 10^7$。

接下来 $T$ 行，每行两个整数 $n, m$，分别表示轨道数和拍数，满足 $1 \le n, m \le 500$。

保证同一个测试点中的所有数据满足 $\sum \max\{n,m\}^3 \le 10^7$

#### 输出格式

对于每组数据，输出一行一个整数表示答案对 1000000007 取模后的值。

#### 样例输入

```text
4
2 1
2 2
4 2
5 3
```

#### 样例输出

```text
1
0
6
170
```

#### 样例解释

- 当 $n = 2, m = 1$ 时，唯一的拍子必须在两条轨道上都有 note，因此答案为 1。
- 当 $n = 2, m = 2$ 时，第二拍无法在至少两条与第一拍不同的轨道上放置 note，因此答案为 0。
- 当 $n = 4, m = 2$ 时，两拍都必须恰好有两个 note，第一拍有 $\binom{4}{2} = 6$ 种选择，第二拍随即确定。

Author: ExplodingKonjac

### 答案

| 难度 | 考点 |
| --- | --- |
| 6 | 组合数、动态规划、滚动数组、取模 |

### 解题思路

每一拍可以看成从 $n$ 条轨道中选择一个集合放置 note，要求集合大小至少为 $2$ 。相邻两拍不能在同一轨道放置 note，所以相邻两个集合必须不相交。

只记录上一拍放了多少个 note 即可。设 `dp[j]` 表示已经生成若干拍，并且最后一拍恰好有 $j$ 个 note 的谱面数量。

第一拍从 $n$ 条轨道中任意选择 $j$ 条，因此

$$
dp[j] = \binom{n}{j}, \qquad 2 \le j \le n.
$$

若上一拍有 $j$ 个 note，那么这一拍只能使用其余 $n - j$ 条轨道。若这一拍放 $k$ 个 note，选择方法有

$$
\binom{n - j}{k}
$$

种，因此转移为

$$
next[k] += dp[j]\binom{n - j}{k}, \qquad 2 \le k \le n - j.
$$

重复转移到第 $m$ 拍，最后将所有 `dp[j]` 相加。组合数使用杨辉三角预处理：

$$
\binom{i}{j} = \binom{i - 1}{j - 1} + \binom{i - 1}{j}.
$$

时间复杂度为 $O(mn^2)$ ，符合题目给出的 $\sum \max(n, m)^3 \le 10^7$ ；组合数表空间复杂度为 $O(n^2)$ ，滚动状态空间复杂度为 $O(n)$ 。

### 示例代码

```c
#include <stdio.h>
#include <string.h>

#define MAXN 500
#define MOD 1000000007

int c[MAXN + 1][MAXN + 1];
int f[MAXN + 1], g[MAXN + 1];

int main() {
    c[0][0] = 1;
    for (int i = 1; i <= MAXN; i++) {
        c[i][0] = c[i][i] = 1;
        for (int j = 1; j < i; j++) {
            c[i][j] = c[i - 1][j - 1] + c[i - 1][j];
            if (c[i][j] >= MOD) {
                c[i][j] -= MOD;
            }
        }
    }

    int T;
    scanf("%d", &T);
    while (T--) {
        int n, m;
        scanf("%d%d", &n, &m);

        memset(f, 0, sizeof(f));
        for (int i = 2; i <= n; i++) {
            f[i] = c[n][i];
        }

        for (int i = 2; i <= m; i++) {
            memset(g, 0, sizeof(g));
            for (int j = 2; j <= n; j++) {
                if (f[j] == 0) {
                    continue;
                }
                for (int k = 2; k <= n - j; k++) {
                    g[k] = (g[k] + (long long)f[j] * c[n - j][k]) % MOD;
                }
            }
            memcpy(f, g, sizeof(f));
        }

        int ans = 0;
        for (int i = 2; i <= n; i++) {
            ans += f[i];
            if (ans >= MOD) {
                ans -= MOD;
            }
        }
        printf("%d\n", ans);
    }
    return 0;
}
```
