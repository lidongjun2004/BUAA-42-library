## A 分分？

### 题目描述

给定两个分数 a/b 和 c/d，请计算它们的和，并输出最简分数。
最简分数的分母必须为正数，分子与分母的最大公约数为 1。若结果为 0，统一输出 0/1。分子允许为负数。

### 输入

第一行一个整数 T，表示数据组数，1≤ T≤10000。
接下来 T 行，每行四个整数 a,b,c,d，依次表示两个分数的分子、分母。$-10^6 \le a,c \le 10^6$， $1 \le b,d \le 10^6$。每组数据均只有这四个整数，无其他总规模限制。

### 输出

每组数据输出一行，格式为 p/q，其中 p 为最简分数的分子，q 为正分母。斜杠两侧均不加空格。

### 输入样例

```text
4
1 2 1 3
-1 2 1 2
-3 4 1 6
1000000 1 1000000 1
```

### 输出样例

```text
5/6
0/1
-7/12
2000000/1
```

### 题目描述

一个二维空间由 n 行、 m 列传送锚点组成；行、列坐标编号从 0 开始。
每个锚点 (i,j) 都记录了一个合法的折跃终点 (xi,j,yi,j)。
从一个锚点出发开始一轮折跃的过程为：如果当前点的折跃终点是自身 或 当前点曾在本轮折跃中到达过，终止本轮折跃，否则继续折跃。求出每个锚点作为起点进行一轮折跃后总的折跃次数；不同起点的折跃过程互相独立。

### 输入

第一行包含两个整数 n 和 m ，分别表示空间的行数和列数，满足 1≤ n,m≤ 1000 。
接下来 n 行。对于 0≤ i<n ，第 i+2 行包含 2m 个整数，按列编号从小到大的顺序，依次给出第 i 行各点的折跃终点，即 xi,0 yi,0 xi,1 yi,1 … xi,m-1 yi,m-1. 其中， xi,j 是点 (i,j) 的折跃终点的行编号，满足 0≤ xi,j<n 。 yi,j 是该终点的列编号，满足 0≤ yi,j<m 。同行的整数之间用一个空格分隔。

### 输出

输出 n 行，每行包含 m 个整数。第 i+1 行的第 j+1 个整数为 ai,j ，表示从点 (i,j) 出发，到停止或首次确认循环为止执行的折跃次数，满足 0≤ ai,j≤ nm 。按照行、列编号从小到大的顺序输出，同一行相邻整数之间用一个空格分隔。

### 输入样例 1

```text
3
4 0 1 0 2 0 2 1 3
1 1 1 2 1 0 1 2 2
1 1 1 2 3 2 3
```

### 输出样例 1

```text
2 1 0 5
3 3 3 4
5 4 1 0
```

### 样例解释

点 (0,2) 和 (2,3) 的折跃终点都是自身，因此它们的答案均为 0 。
从点 (0,0) 出发，路径为 (0,0)to(0,1)to(0,2) ，执行 2 次折跃后停止。
点 (1,0) 、 (1,1) 和 (1,2) 构成长度为 3 的环。从其中任意一点出发，执行 3 次折跃后首次回到起点，因此这三个点的答案均为 3 。从点 (0,3) 出发，路径为 (0,3)to(1,3)to(1,2)to(1,0)to(1,1)to(1,2). 执行第 5 次折跃时，点 (1,2) 首次重复出现，因此点 (0,3) 的答案为 5 。 Provider : LCYing

## I Two of Tango

### 题目背景

在《Two of Tango》的 MV 中，{Remielle,Ramiel,Belle,Wise} 四人分别对应国际象棋棋盘上的白后、黑后、白王、黑王。今天我们来考察这四颗棋子构成的棋局。

### 题目描述

国际象棋棋盘大小为 8 × 8。列由左向右依次用小写英文字母 texttt{a} ~ texttt{h} 表示，行由下向上依次用数字 1 ~ 8 表示。棋盘上的每个格子可以用其列和行组成的二元字符串唯一标识（例如 te xttt{a1} 为左下角格子，texttt{h8} 为右上角格子）。场上共有 4 颗棋子：白王 Kw、白后 Qw、黑王 Kb、黑后 Qb。我们首先给出棋子攻击范围的定义，这也是棋子移动的基本规则：若棋子是*王，其攻击范围为棋盘内与其相邻的 8 个格子（即切比雪夫距离为 1 的格子）；* 若棋子是后**，其攻击范围由当前位置沿横向、纵向及两条对角线（共 8 个方向）延伸：沿某一方向上遇到的所有空格，以及遇到的第一个棋子所在的格子（无论该棋子属于己方还是对方），均属于该后的攻击范围；该阻挡棋子后方的格子被遮挡，不属于其攻击范围；* 攻击范围一定在棋盘内，一方对某个格子的攻击范围仅取决于当前盘面上各棋子的几何位置，不受后续合法性规则的限制。棋子的合法移动必须遵循以下规则：行动方必须且只能选择己方场上的一颗存活棋子进行移动； 棋子移动的目标位置必须处于棋盘上该棋子当前的攻击范围内，且不能与原位置重合； 目标位置上不能有己方的棋子，也不能有对方的王（不能直接吃对方的王）； 若目标位置上有对方的后，则视为吃子：移动完成后，对方的后被移出棋盘，后续对局中不再参与任何行动；若目标位置无棋子，则仅移动到该空格。 行动方完成一步移动后，己方的王不能处于对方任意存活棋子的攻击范围内（即不能送将）； 该条件的一种特例：双方的王永远不能在移动后处于相邻（切比雪夫距离为 1）的格子。不满足上述条件的移动均视为不合法移动。我们保证初始状态下，4 颗棋子的位置各不相同，双方的王未在对方任意棋子的攻击范围内。己方 c ∈ {{tt{w}}, {tt{b}}} 作为先手完成一步合法移动后，轮到对方行动。若： 1. 若对方的王正在被己方棋子攻击，且对方无法进行任何合法移动，则己方将死（Checkmate）对方，己方胜利；2. 若对方的王未被己方棋子攻击，但对方无法进行任何合法移动，则己方逼和（Stalemate）对方，双方平局；3. 若对方仍能进行至少一种合法移动，则对局继续。现在给定棋盘的初始状态以及当前的先手行动方 c。先手希望能尽快结束对局，请你判断先手能否通过行一步棋直接终局： + 若先手存在某种合法的移动方式能够将死对方，输出 Checkmate；+ 若无法将死对方，但存在某种合法的移动方式能够逼和对方，输出 Stalemate；+ 若先手无论如何移动，对方在下一回合都至少有一种合法移动，输出 None。

输入包含多组测试数据。第一行包含一个正整数 T（1 ≤ T ≤ 1000），表示测试用例组数。

第一行包含 4 个长度为 2 的字符串 PKw, PQw, PKb, PQb，由空格隔开，依次表示白王、白后、黑王、黑后的初始位置坐标，保证四颗棋子的坐标互不相同；第二行包含一个字符 c ∈ {texttt{w}, texttt{b}}，表示当前轮到行动的一方（texttt{w} 表示白方，texttt{b} 表示黑方）。不保证数据随机。

### 输出格式

对于每组测试数据，输出一行一个字符串（Checkmate、Stalemate 或 None），表示先手行动一步后能达成的最优终局结果。

## J 骰子

### 题目背景

### 题目描述
