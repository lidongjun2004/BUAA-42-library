### A题

1，对于使用while输入多组数据，很多同学还是有疑惑。因为看起来“输入与输出混在一起”。其实可以不用担心，可以理解为评测时，输入是一个窗口，输出在另一个窗口，两者没有混在一起。“输入一个输出一个”与“全部输入再输出”没有区别。

另外，当你使用 `while(scanf("%d", &N) != EOF)` 判断是否输入N时，不需要在循环里再次输入N。

2，输出字符串时“INVISIBLE ！ ”时，最好**直接复制粘贴**题目里的。不要用手敲！！！不要用手敲！！！！

### B题

1，遇到输入整数，输出小数，最粗暴的方法是一律使用double。除了粗暴的方法，这里提供几个写法的测试，大家可以尝试理解为什么。

```c
int a = 10, b = 3;
printf("%.2lf", a / b); //输出0.00

int a = 10, b = 3;
printf("%.2lf", 1.0 * a / b); //输出3.33

int a = 10, b = 3;
printf("%.2lf", (double)a / b); //输出3.33

int a = 10, b = 3;
printf("%.2lf", (double)(a / b)); //输出3.00

int a = 10, b = 3;
printf("%.2lf", a / (double)b); //输出3.33

int a = 10;
printf("%.2lf", a / 3); //输出0.00

int a = 10;
printf("%.2lf", a / 3.0); //输出3.33

int b = 3;
printf("%.2lf", 10 / b); //输出0.00

int b = 3;
printf("%.2lf", (double)10 / b); //输出3.33

int b = 3;
printf("%.2lf", (double)(a / b)); //输出3.00

int b = 3;
printf("%.2lf", 10.0 / b); //输出3.33
```

2，数组定义时，强烈建议确定一个固定的大小，比如 `int a[25]` ，应尽可能避免使用变量作为其大小如 `int a[n+2]` 。

建议将数组设为全局变量（在main函数外部）如：

```c
int a[100];//这种全局数组会自动初始化为0，其他类型的全局变量同理
int main()
{
    int array1[100]; //局部变量需要自己赋初始值，否则可能会出问题。
    int i;
    for(i=0;i<100;i++)
    {
        array1[i]=0;
    }
    //也可以自己学习一下memset函数给数组赋初值
    return 0;
}
```

输入单个的数组元素时，仍要加取地址符&。

访问数组元素时，错误的写法：a5，正确的写法：a[5]。

数组下标是从0开始的。这意味着，比如大小为15的数组，访问时下标最大为14。

举例：

```c
int i, a[15];
for(i = 0; i < 15; i++){
    scanf("%d", &a[i]);
    printf("%d", a[i]);
}
```

强烈建议你学习使用数组时尽量靠自己尝试来解决遇到的奇怪问题。

### C题

1，如何判断一个字符是大写或小写？第一种：百度C语言字符串有关函数。第二种：

```c
if(c >= 'a' && c <= 'z') 则c为小写
if(c >= 'A' && c <= 'Z') 则c为大写
```

2，如何表示“除此之外，其他情况”？

```c
if(c是小写字母){
    ....
}
else if(c是大写字母){
    ....
}
else{
    ....
}
```

执行if的条件只有一个：满足它的判断条件；而执行else if，除了要满足它的判断条件，还得确保它之前任何的if或else if都没执行过，相当于“既然上面的都不满足，那么如果满足...就...” ；else不需要写条件，它相当于“只要上面都不满足，那就...”

### D题
