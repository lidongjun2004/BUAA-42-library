```c
        **    **         **\n\

      ************       **\n\
     **************      **\n\
    **            **     **\n\
   **              **    **\n\
  **                **   **\n\

**                    ** *****************\n");

}
```

#### 题目描述

$\mathrm{ReLU}$ 是神经网络中常用的激活函数，定义为 $\mathrm{ReLU}(x)=\max(0,x)$。给定一个整数 $x$，输出 $\mathrm{ReLU}(x)$ 的值。

#### 输入格式

一行，一个整数 $x$。

#### 输出格式

一行，一个整数，表示 $\mathrm{ReLU}(x)$。

#### 样例输入

```text
-3
```

#### 样例输出

```text
0
```

### 答案

本题考查如何进行输入和输出，以及如何使用 `if` 语句进行条件判断。

### 示例程序

```c
#include <stdio.h>
int main()
{
    int x;
    scanf("%d", &x);

    if (x <= 0)
    {
        printf("0\n");
    }
    else
    {
        printf("%d\n", x);
    }

    return 0;
}
```

## D 生日

### 题目

| 难度 | 考点 |
| --- | --- |
| 1 | 数据输入输出、条件判断 |

#### 题目描述

输入出生日期的年、月、日，按 `My birthday is YYYY.MM.DD.` 的格式输出，其中月和日不足两位时在前面补 0。

#### 输入格式

一行，三个整数 $y,m,d$，依次表示年、月、日。

#### 输出格式

一行，形如 `My birthday is 2001.09.03.` 的字符串。

#### 样例输入

```text
2001 9 3
```

#### 样例输出

```text
My birthday is 2001.09.03
```

### 答案

本题考查如何进行输入和输出，以及如何使用 `if` 语句进行条件判断。

### 解法1：使用if-else语句

示例程序

```c
#include <stdio.h>
int main() {
    int y,m,d;
    scanf("%d%d%d",&y,&m,&d);
    printf("My birthday is %d.",y);
    if(m<=9) printf("0"); //判断月份是否需要补0
    printf("%d.",m);
    if(d<=9) printf("0");//判断日期是否需要补0
    printf("%d\n",d);
    return 0;
}
```

### 解法二：格式符

示例程序

```c
#include <stdio.h>
int main() {
    int y,m,d;
    scanf("%d%d%d",&y,&m,&d);
    printf("My birthday is %d.%02d.%02d",y,m,d);
    return 0;
}
```

## E 真·计算机

| 难度 | 考点 |
| --- | --- |
| 1 | 五种基本运算 |

### 题目分析

注意判断除数是否为 $0$ 。

### 参考程序

```c
#include<stdio.h>

int main() {
    long long a, b;

    scanf("%lld%lld", &a, &b);

    printf("%lld\n%lld\n%lld\n", a + b, a - b, a * b);
    if(0 == b) printf("[Warning] division by zero [-Wdiv-by-zero]");
    else printf("%lld\n%lld", a / b, a % b);

    return 0;
}
```

### 总结

把变量设为 $0$ ，再以之为除数，这是很隐蔽的 BUG 。从现在起请有意识地学习调试方法和小技巧。

此外，上面写的是 `"if(0 == b)"` ，因为若你写成 `"if(b = 0)"` 不会报错，但写成 `"if(0 = b)"` 会。可以养成这个 `"常数 == 变量"` 的习惯，并思考一下为什么。

#### 输入格式

三行，每行两个实数 $x$ 和 $y$，表示一个点的坐标。

```c
#include<stdio.h>

    double x1,y1,x2,y2,x3,y3;

    scanf("%lf%lf",&x2,&y2);
```

## H 打印进度条

### 题目

| 难度 | 考点 |
| --- | --- |
| 2 | 输出字符图案 |

#### 题目描述

打印一个共 102 列的进度条：两端各是一个竖线 `|`，中间 100 列由 $n$ 个 `#` 和 $100-n$ 个 `-` 组成，`#` 在前，`-` 在后。若 $n$ 不在 $1$ 到 $100$ 之间，输出 `Wake Up!`。

#### 输入格式

一行，一个整数 $n$。

#### 输出格式

一行进度条； $n$ 越界时输出一行 `Wake Up!`。

#### 样例输入

```text
30
```

#### 样例输出

```text
|##############################----------------------------------------------------------------------|
```

### 答案

本题考查如何在屏幕上输出字符图案。

程序只能从上至下、从左至右依次输出字符，因此我们首先应将工作分为：

1. 输出竖线
2. 输出警号
3. 输出短横线
4. 输出竖线

由于进度条共有 102 列，除去两个竖线后共有 100 列，而警号共有 $n$ 个，因此短横线应输出 $100 - n$ 个，使用循环语句即可。

### 示例程序

```c
#include <stdio.h>

int main()
{
    int n;
    scanf("%d", &n);

    if (n < 1 || n > 100)
    {
        printf("Wake Up!");
        return 0;
        // 在main函数中使用return 0语句可立刻退出程序
    }

    putchar('|');
    for (int i = 0; i < n; i++)
    {
        putchar('#');
    }
    for (int i = 0; i < 100 - n; i++)
    {
        putchar('-');
    }
    putchar('|');

    return 0;
}
```

## I 有向立方和

### 题目

| 难度 | 考点 |
| --- | --- |
| 3 | 不确定多组数据的读入与计算 |

#### 题目描述

输入若干个整数，直到文件结束。对每个读入的整数 $n$：若 $n$ 是偶数，就把 $n^3$ 加进总和；若 $n$ 是奇数，就把 $n^3$ 从总和中减去。输出最终的总和。

#### 输入格式

若干个整数，用空格或换行分隔，读到文件结束为止。

#### 输出格式

一行，一个整数，表示最终的总和。

#### 样例输入

```text
1 2 3 4
```

#### 样例输出

```text
44
```

#### 数据范围

数据不超过 1000 组，每组数据的绝对值不超过 1000，总和可能超出 `int` 的表示范围。

### 答案

### 要点一：不确定的多组输入

```c
while (scanf("%d", &n) != EOF) {
    // do something
}
```

初学者可以先记住这种输入方式

### 要点二：判断数字的奇偶性

```c
if (n % 2 == 0) {
    // do somethong
} else {
    // do something
}
```

对 2 取模，如果模为 0 则为偶数，否则为奇数

### 要点三：数据范围

观察数据的最大范围，最多为 1000 组 1000，此时结果数量级为 1e12，超过 `int` 的表示范围，因此应当使用 `long long`

### 示例程序

```c
#include <stdio.h>

int main() {
    long long sum = 0;
    int n;
    while (scanf("%d", &n) != EOF) {
        if (n % 2 == 0) {
            sum += n * n * n;
        } else {
            sum -= n * n * n;
        }
    }
    printf("%lld", sum);
    return 0;
}
```

## J 零花钱

| 难度 | 考点 |
| --- | --- |
| 2 | 循环，模拟（或数学） |

### 题目分析

注意 15 块钱是个分界点，需要加入判断。

由题目条件，可以把它看成金字塔求和的问题。第一行一个数 1，第二行两个数 2……所以可以先判断出 k 属于哪一行，之后求和。

### 示例程序

```c
#include<stdio.h>

int main()
{
    int i, k, sum = 0;
    scanf("%d", &k);
    for (i = 1; (i * (i + 1) / 2) <= k && i < 15; i++);//k天所在的“行数”
    for (int j = 1; j <= i - 1; j++) {//把k所在行之前的所有行的零花钱加起来
        sum += j * j;
    }
    sum += (k - (i * (i - 1) / 2)) * i;//把k所在行的零花钱加起来
    printf("%d", sum);
    return 0;
}
```
