## 一、语法

```c
scanf("%d", a);    // 错误，无取址符
scanf("%d, a");    // 错误，双引号不要括住逗号后边的内容
scanf("%d\n", &a); // 错误，字符串中的'\n'可能导致输入无法正常结束
scanf("%d", &a);   // 正确
```

请大家注意观察以上几种正确与错误的写法。

```c
if (a > b)
    b = a;
    a = b;
```

以上写法等价于

```c
if (a > b) {
    b = a;
}
a = b;
```

请注意以上两者的区别，正确使用大括号。

关于 `=` 与 `==` ： `=` 是赋值运算，而 `==` 是条件判断，不要混淆。

`0` 作为除数和模数会导致 REG 等运行时错误，请仔细检查代码逻辑，避免除零导致的错误。

## 二、数据范围

题目给出的数据范围不需要输入到代码中，而是为了让你们自行考虑程序的设计方式，例如：

- 是否会超出 `int` 、 `long long` 等类型的表示范围
- 多重循环是否超出时间限制
- 多维数组是否超出内存限制

## 三、有关OJ

这次 OJ 出现了一些问题，我们会在之后对问题进行排查，并对代码进行重测。

OJ 出现等待是因为评测机的性能有限，无法在短时间内完成全部提交代码的评测。当出现这种情况时请同学们耐心等待，不要重复提交。在比赛时间结束前，只要代码正确提交，就能最终得到结果。

请仔细阅读简介中关于 WA 、 TLE 、 REG 等错误的描述。

## 四、一些建议

- 请大家在上机前做好复习，并准备好课本与PPT，以供上机时参考。
- 代码没有通过编译或出现错误，请不要第一时间提问，要养成自己排查错误的能力。
- 当感到题目难度较高时，可以参考每道题目的通过率与正确率，先做简单题。
- 对于题面上可以复制粘贴的字符串，应当避免手打。
- 养成良好的代码风格，包括但不限于：变量命名符合变量语义、变量、常量、运算符前后用空格分开、正确地缩进代码等，这对程序的阅读与调试都尤为重要。
- 请多多练习，充分的练习可以使你避免许多不必要的问题。
- 在线上提问时，建议不要直接粘贴代码，良好的提问应当给出问题的描述与自己大致的猜想。
