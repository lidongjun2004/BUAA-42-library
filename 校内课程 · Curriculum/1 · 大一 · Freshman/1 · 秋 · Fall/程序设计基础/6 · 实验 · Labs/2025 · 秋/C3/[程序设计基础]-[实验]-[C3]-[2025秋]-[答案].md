### 题目

#### 题目描述

多组数据。每组给出两个非负整数 $a$ 和 $b$ ，按 32 位无符号整数处理，依次输出六个结果： $a$ 的按位取反、 $a$ 与 $b$ 的按位与、 $a$ 与 $b$ 的按位或、 $a$ 与 $b$ 的按位异或、 $a$ 左移 $b$ 位、 $a$ 右移 $b$ 位。

#### 输入格式

第一行一个整数 $t$ ，表示数据组数。接下来 $t$ 行，每行两个非负整数 $a$ 和 $b$ ，用空格分隔。

#### 输出格式

每组输出一行六个非负整数，用空格分隔，依次是 `~a` 、 `a & b` 、 `a | b` 、 `a ^ b` 、 `a << b` 、 `a >> b` 的结果，均按 32 位无符号整数输出。

#### 样例输入

```text
1
12 2
```

#### 样例输出

```text
4294967283 0 14 14 48 3
```

### 答案

### 题目分析

第一个数：一个非负整数，表示 a 的按位取反；使用 `~a`

第二个数：一个非负整数，表示 a 和 b 的按位与；使用 `a & b`

第三个数：一个非负整数，表示 a 和 b 的按位或；使用 `a | b`

第四个数：一个非负整数，表示 a 和 b 的按位异或；使用 `a ^ b`

第五个数：一个非负整数，表示 a 左移 b 位；使用 `a << b`

第六个数：一个非负整数，表示 a 右移 b 位；使用 `a >> b`

### 示例代码

```c
#include <stdio.h>

int main(){
    int t;
    scanf("%d",&t);
    while(t--){
        unsigned int a,b;
        scanf("%u%u",&a,&b);
        printf("%u %u %u %u %u %u\n",~a,a&b,a|b,a^b,a<<b,a>>b);
    }
    return 0;
}
```

| 1 | 位运算 |

### 题目

#### 题目描述

对 $0$ 到 $n$ 的每一个整数，输出它的二进制表示中 $1$ 的个数。

#### 输入格式

一行一个整数 $n$ 。

#### 输出格式

一行 $n + 1$ 个整数，依次是 $0, 1, \ldots, n$ 的二进制中 $1$ 的个数，相邻两数之间用一个空格分隔。

#### 样例输入

```text
5
```

#### 样例输出

```text
0 1 1 2 1 2
```

#### 数据范围

$0 \le n \le 10^{6}$

### 答案

### 解题思路

`a & (1 << k)`（等价于 `a & (1 << k) != 0`）可以判断 $a$ 的第 $k$ 位是否为 $1$。于是我们可以通过循环判断 $a$ 的每一位是否是 $1$ 来进行计数。

### 示例代码

```c
#include<stdio.h>

int main() {
    int n;
    scanf("%d", &n);
    for (int i = 0; i <= n; i++) {
        int k, cnt = 0;
        for (k = 1; k <= (1 << 20); k = (k << 1) ) { // (1 << 20) > 1000000
            if (i & k) cnt++;
        }
        printf("%d ", cnt);
    }
    return 0;
}
```

有信竞或算法基础的同学可以思考动态规划的解法。

| 2 | 补码，二进制，位运算 |

### 题目

#### 题目描述

整数在计算机中以二进制补码的形式存储。给定若干个整数，请按 64 位补码把它们打印出来，从最高位到最低位输出，每 4 位为一组，组与组之间用一个空格分隔。

#### 输入格式

第一行一个整数 $n$ 。接下来 $n$ 行，每行一个整数 $a$ 。

#### 输出格式

$n$ 行，每行 64 个二进制位。每输出 4 位就紧跟一个空格，因此每行末尾也有一个空格。

#### 样例输入

```text
1
1
```

#### 样例输出

```text
0000 0000 0000 0000 0000 0000 0000 0000 0000 0000 0000 0000 0000 0000 0000 0001
```

#### 数据范围

输入的整数超出 `int` 范围，需要用 `long long` 存储。

### 答案

### 题目分析

应当知道，**整数在计算机中存储的形式即为其二进制补码形式**。

也就是说，当程序读入一个整数 $998244353$ 时，它已经以

```text
0000 0000 0000 0000 0000 0000 0000 0000 0011 1011 1000 0000 0000 0000 0000 0001
```

的形式被存储了，因此，你不需要做任何额外的转换操作，只需要逐个获取这个数的每个二进制位并输出即可。HINT 中已经提到可以使用 `(a >> i) & 1` 获取整数 $a$ 的第 $i$ 位，注意最低位是第 $0$ 位。

另外，根据输入的数据范围要求，需要使用 `long long` 来存储输入的整数。

### 注

为什么 `(a >> i) & 1` 可以获取整数 $a$ 的第 $i$ 位呢？不妨这样想： $1$ 的二进制表示就是 $0000\ldots0001$（如果是 `long long` 类型的话，前面有 $63$ 个 $0$），也就是除了最低位为 $1$，其他都是 $0$。由于对任意的 $x \in \{0,1\}$，`0 & x = 0`、`1 & x = x` 都是成立的，因此一个数与 $1$ 做按位与，得到的结果就是它的最低位。而通过左移运算 `a >> i`，我们把 $a$ 的第 $i$ 位（再次强调，在我们的算式的意义下，最低位是第 $0$ 位）移到了结果的最低位，因此就可以通过和 $1$ 做按位与将其取出。

### 示例代码

```c
#include <stdio.h>

int main() {
    int n = 0;
    scanf("%d", &n);
    for (int i = 0; i < n; ++i) {
        long long a = 0;
        scanf("%lld", &a);
        for (int i = 63; i >= 0; --i) {
            printf("%lld", (a >> i) & 1);
            if (i % 4 == 0) {
                printf(" ");
            }
        }
        printf("\n");
    }
    return 0;
}
```

### 题目

#### 题目描述

把给定整数的 32 位补码高低位对调，即第 0 位与第 31 位交换、第 1 位与第 30 位交换，依此类推，输出对调之后得到的数。

#### 输入格式

第一行一个整数 $n$ 。接下来 $n$ 行，每行一个非负整数，表示原数的 32 位补码。

#### 输出格式

$n$ 行，每行一个非负整数，表示补码高低位对调后的结果，按 32 位无符号整数输出。

#### 样例输入

```text
1
1
```

#### 样例输出

```text
2147483648
```

### 答案

### 题目分析

根据题意，我们需要将给定数字的补码高低位对调。

`int` 类型的变量是以补码的形式储存在计算机中，因此我们不需要补码的转化问题。

补码高低位对调的方法详见示例代码。

### 示例代码

```c
#include <stdio.h>
int main() {
    int n;
    unsigned int m;
    scanf("%d", &n);
    while (n--) {
        scanf("%u", &m);
        unsigned int res = 0;
        for (int i = 0; i < 32; ++i) {
            res <<= 1;
            res |= ((m >> i) & 1);
        }
        printf("%u\n", res);
    }
}
```

## E 繁星点点

| 难度 | 考点 |
| --- | --- |
| 2 | 位运算、循环 |

### 题目

#### 题目描述

把一个非负整数拆成若干个 2 的幂之和，也就是按二进制从高位到低位，输出所有为 $1$ 的位对应的 2 的幂。

#### 输入格式

第一行一个整数 $t$ 。接下来 $t$ 行，每行一个非负整数 $n$ 。

#### 输出格式

每组输出一行，把 $n$ 的二进制中为 $1$ 的位从高位到低位对应的 2 的幂依次输出，相邻两数之间用一个空格分隔。

#### 样例输入

```text
1
13
```

#### 样例输出

```text
8 4 1
```

#### 数据范围

$0 \le n \le 2^{30} - 1$

### 答案

### 题目分析

由于 C 语言的 `if` 语句中，可以用 `if(数字)`，其中数字如果非 $0$ 就执行，是 $0$ 就不执行。

我们通常会记最右边的位为第 $0$ 位，这样我们说第 $i$ 位就对应整数拆分中 $2^i$ 的那一个数字。

所以如果我们要找 $n$ 的二进制第 $i$ 位，可以先把 $n$ 右移 $i$ 位，然后将其和 $1$ 做按位与，这样就可以知道这一位是 $0$ 还是 $1$。

例如： $13 = (1101)_2$ 的第 $2$ 个位。我们将 $(1101)_2$ 右移 $2$ 位得到 $(11)_2$，然后把它和 $1$ 做按位与得到 $(1)_2 = 1$。

于是，我们通过 `if((n>>i)&1)` 就可以判断整数 $n$ 是否第 $i$ 个位是 $1$。

此外，如果我们想从 $29$ 倒序循环到 $0$，可以使用 `for` 循环：`for(int i=29;i>=0;i--)`。

如果我们想从 $0$ 正序循环到 $29$，可以使用：`for(int i=0;i<=29;i++)`。

此外，可以证明 `1<<i` 也就是 $1$ 左移 $i$ 位等于 $(10\cdots0)_2$，也就是 $1$ 后面有 $i$ 个 $0$，等于 $2^i$。

### 示例代码

```c
#include <stdio.h>

int main(){
    int t;
    scanf("%d",&t);
    while(t--){
        int n;
        scanf("%d",&n);
        for(int i=29;i>=0;i--)
            if((n>>i)&1)
                printf("%d ",1<<i);
        printf("\n");
    }
    return 0;
}
```

### 题目

#### 题目描述

定义数列 $f$ ： $f_0 = f_0$ （由输入给出），对 $i \ge 1$ ，令 $x = f_{i-1}$ ，依次执行 `x ^= x << 13` 、 `x ^= x >> 17` 、 `x ^= x << 5` （都是 32 位无符号运算），所得结果就是 $f_i$ 。给定 $n$ 、 $f_0$ 和 $q$ 次询问，每次询问给出一个下标 $i$ ，输出 $f_i$ 。

#### 输入格式

第一行三个数：整数 $n$ 、无符号整数 $f_0$ 、整数 $q$ ，用空格分隔。接下来 $q$ 行，每行一个整数 $i$ ，表示一次询问的下标。

#### 输出格式

$q$ 行，每行一个无符号整数，表示对应下标的 $f_i$ 。

#### 样例输入

```text
5 1 3
0
1
2
```

#### 样例输出

```text
1
270369
67634689
```

#### 数据范围

$n \le 1.4 \times 10^{7}$ 。空间限制为 64 MB，需要用 `unsigned int` 数组存下 $f_0$ 到 $f_n$ ，数组要开在 `main` 外面，并用 `%u` 输出。

### 答案

### 题目分析

专坑 `VLA` 和数组开在 `main` 里。

如果你不理解这是什么，请你**务必把大数组开在 `main` 外面**。此外，使用数组定义时，**长度请设成字面意义上的数字**。

那么长度具体可以是多少呢，如何估计？

可以从**题目要求**中看到题目的数据范围。比如本题给出了题目限制 $n \le 1.4 \times 10^7$，你的数组就应该开比 14000000 **大一点**。你可以比这个范围大任意在区间 $[5, 1000]$ 的数字都是合理的。**如果你不知道为什么，请你多开比数据范围多 $5$ 即可**，在此题中可以开 `14000005`。

（为什么不只多开 $1$？原因比较复杂，在此不过多赘述。**如果你不知道为什么，请至少比数据范围多开 $5$**。）

**我们计算分数不会看你的空间使用排名，你只需要保证空间不超限就行了。死扣那几个 `unsigned int`，去纠结加 $1$ 行不行没有意义。如果你激进点，开成数据范围的 $110\%$ 大概率都是可以的。**

示例：`unsigned int F[14000005]`

此外，位运算的题目需要仔细观察是否合适使用 `long long` 范围。本题由于有位截断，所以 `long long` 会错。请你按照题目要求的使用 `unsigned int`。（实际上，即使不 `WA`，`long long` 也会因为空间限制而 `MLE`，`Memory Limit Exceed`。）

对于空间限制紧的题，你还可以估计内存使用：比如上面示例 `unsigned int F[14000005]`，由于 $1$ 个 `unsigned int` 占用 $4$ 字节，使用了 $14000005$ 个 `unsigned int`，所以占用空间 $4 \times 14000005 = 56000020\text{B} \approx 56\text{MB}$，题目限制 $64\text{MB}$，可以通过此题。

（附加提示： $1\text{MB} = 1000\text{KB} = 1000000\text{B}$， $1\text{MiB} = 1024\text{KiB} = 1048576\text{B}$）

此外，本题还有坑点，用 `printf` 输出无符号整数时，应当使用 `%u`。

### 示例代码

```c
#include <stdio.h>

unsigned int f[14000005];
int main(){
    int n,q;
    unsigned int f0;
    scanf("%d%u%d",&n,&f0,&q);
    f[0]=f0;
    for(int i=1;i<=n;i++){
        unsigned int x = f[i-1];
        x ^= x << 13;
        x ^= x >> 17;
        x ^= x << 5;
        f[i] = x;
    }
    while(q--){
        int i;
        scanf("%d",&i);
        printf("%u\n",f[i]);
    }
    return 0;
}
```

### 题目

#### 题目描述

给定 $n$ 个整数，其中恰有一个数出现了奇数次，其余每个数都出现了偶数次。请求出这个出现奇数次的数。本题的空间限制非常严格，无法开数组把所有数都存下来。

#### 输入格式

第一行一个整数 $n$ 。第二行 $n$ 个整数，用空格分隔。

#### 输出格式

一行一个整数，表示唯一出现奇数次的那个数。

#### 样例输入

```text
5
1 2 2 1 3
```

#### 样例输出

```text
3
```

### 答案

### 题目分析

给定一个数列，其中一个数字出现奇数次，其他都是偶数次，找出这个出现奇数次的数字。空间限制严格，无法开一个数组存下所有的内容。

考虑异或具有交换律，结合律，且 `a^a=0`，`0^a=a`。所以如果对于所有的数字做一个异或，则结果就是那个唯一一个出现奇数次的数字。

```c
#include<stdio.h>
int main() {

        scanf("%d",&a);
        ans^=a;
    }

    return 0;

```

## H Rainbow Rush Story

| 难度 | 考点 |
| --- | --- |
| 4 | 位运算 |

### 题目

#### 题目描述

多组询问，每组给出 $l$ 和 $r$ ，求 $l, l+1, \ldots, r$ 这段区间内所有整数的按位或。

#### 输入格式

第一行一个整数 $t$ ，表示询问次数。接下来 $t$ 行，每行两个整数 $l$ 和 $r$ ，用空格分隔。

#### 输出格式

每组输出一行一个整数，表示 $[l, r]$ 中所有整数的按位或。

#### 样例输入

```text
2
1 4
5 5
```

#### 样例输出

```text
7
5
```

#### 数据范围

$t \le 2 \times 10^{5}$ ， $0 \le l \le r < 2^{30}$

### 答案

### 题目分析

本题有很多解法。

约定：下面两种表述等价。

- $x$ 的第 $i$ 位为 $1$
- $x$ 有第 $i$ 个二进制位

#### 解法 1

我们枚举 $0 \le i \le 29$，按位考虑 $[l,r]$ 中是否有包含二进制位 $i$ 的数。

一个基础的思路是，我们计算出**不小于 $l$ 的，最小的包含二进制位 $i$ 的整数**。然后，我们判断这个数是否在 $[l,r]$ 区间内，也就是这个数是否 $\le r$。如果是，那么 $[l,r]$ 中至少存在一个包含二进制位 $i$ 的数，因而， $[l,r]$ 所有数的按位或一定包含二进制位 $i$。反之，则不包含。

那么问题来了。**不小于 $l$ 的，最小的包含二进制位 $i$ 的整数**如何计算？

分类讨论：

1° 如果 $l$ 包含二进制位 $i$，则所求很明显就是 $l$。

2° 如果 $l$ 不包含二进制位 $i$，则所求为 `(l&~((1<<i)-1))|(1<<i)`。让我们仔细分析：

例如二进制 `10101010`，其中蓝色数字为第 $i$ 位。所求是 `10110000`。我们实际就是想把第 $i$ 位设为 $1$，右边的所有位设为 $0$。

那么，`(1<<i)-1` 代表 `00001111`，`~((1<<i)-1))` 代表 `11110000`，`(l&~((1<<i)-1))` 代表 `10100000`。

然后将第 $i$ 位设为 $1$，将其或上 `(1<<i)` 即 `00010000` 即可获得数字 `10110000`。

计算出对于所有 $0 \le i \le 29$，二进制位 $i$ 是否出现在 $[l,r]$ 的按位或中。如果出现，则答案的第 $i$ 个二进制位为 $1$，反之则 $0$。

时间复杂度 $O(T \log_2 r) \le 2 \times 10^5 \times 30 = 6 \times 10^6 \ll 2 \times 10^8$，显然可以通过。

#### 解法 2

注意到集合 $\{l, r\} \cup \{l + 2^i \mid l + 2^i \le r, i \in \mathbb{N}\}$ 所有数的按位或即为答案。该集合数字个数不超过 $32$ 个。

这个定理较为显然，证明留做练习。（提示：自然数序列中，二进制第 $i$ 位的循环节是 $2^{i+1}$）

时间复杂度 $O(T \log_2 r) \le 2 \times 10^5 \times 30 = 6 \times 10^6 \ll 2 \times 10^8$，显然可以通过。

#### 解法 3

注意到随机在 $[l,r]$ 中选出 $50$ 个数按位或起来，再和 $l, r$ 两个数或起来，这 $52$ 个数的按位或有极大概率是答案。

这个做法正确概率很大。正确性很显然。

时间复杂度 $O(50T) \le 2 \times 10^5 \times 50 = 1 \times 10^7 \ll 2 \times 10^8$，显然可以通过。（在系统上测试时间不高于 $490\text{ms}$）

**解法 3 中使用了随机数生成函数 `rand()` 和种子设置函数 `srand()`，不要求掌握。**

### 示例代码 1

```c
#include <stdio.h>

int main(){
    int t; scanf("%d",&t);
    while(t--){
        int l,r;
        scanf("%d%d",&l,&r);
        int ans=l|r;
        for(int i=0;i<=29;i++)
            if(!(l&1<<i)){
                int nxt=l&(~((1<<i)-1))|(1<<i);
                assert(nxt>=l);
                if(nxt<=r) ans|=nxt;
            }
        printf("%d\n",ans);
    }
    return 0;
}
```

### 示例代码 2

```c
#include <stdio.h>

int main(){

        scanf("%d%d",&l,&r);

            if(l+(1<<i)<=r)
```

### 示例代码 3

```c
#include <stdio.h>

#define ll long long

ll rnd(){
    ll rt=(ll)rand()<<16^(ll)rand();
    return rt;
}
int main(){
    srand(998244353);
```

### 做法 3 额外详细证明

哈哈，我猜你不会想去证这玩意的。那么我们证明一下吧。

**引理 1.** 若 $l, r$ 都不含有第 $i$ 位，但是 $[l,r]$ 中存在某一个数二进制第 $i$ 位为 $1$，则 $[l,r]$ 中至少有 $\frac{1}{3}$ 的数拥有第 $i$ 个二进制位；

证明：

**二进制第 $i$ 位是周期性的。**自然数序列中，二进制第 $i$ 位的循环节是 $2^{i+1}$。

我们考虑序列 $0, 1, 2, 3, \cdots$，它们的二进制第 $i$ 位具有周期性

$$0, 0, \cdots, 0, 0, 1, 1, \cdots, 1, 1, 0, 0, \cdots, 0, 0, 1, 1, \cdots, 1, 1, \cdots$$

其中的每一段全 $0$ 和全 $1$ 的长度都是 $2^i$。从中任意截取 $[l,r]$，且 $l, r$ 落在 $0$ 内，那么只要 $[l,r]$ **有一个 $1$，那么 $[l,r]$ 一定包含了至少一个连续段的 $1$**。更具体地，如果 $[l,r]$ 中间隔了 $n \ge 0$ 段 $0$，则 $[l,r]$ 中间一定也间隔了 $n + 1$ 段 $1$。

因此，二进制第 $i$ 位为 $1$ 的比例

$$\ge \frac{(n+1)2^i}{r-l+1} \ge \frac{(n+1)2^i}{(n+2+n+1)2^i} \ge \frac{n+1}{2n+3} \ge \frac{0+1}{0+3} = \frac{1}{3}$$

**引理 2.** 若答案包含第 $i$ 位，则随机 $k$ 次，其中至少 $1$ 次选到了包含第 $i$ 位的数概率不低于 $1 - \left(\frac{2}{3}\right)^k$；

证明：

选一次，没有选到第 $i$ 位的概率不高于 $1 - \frac{1}{3}$。选 $k$ 次，没有选到第 $i$ 位的概率不高于 $\left(\frac{2}{3}\right)^k$。

随机 $k$ 次，其中至少 $1$ 次选到了包含第 $i$ 位的数概率不低于 $1 - \left(\frac{2}{3}\right)^k$。

**引理 3.** 若答案一共 $B$ 位，询问 $T$ 次答案，则随机 $k$ 次，答案正确的概率不低于 $\left(1 - \left(\frac{2}{3}\right)^k\right)^{BT}$；

证明：

每一位都要正确，所以直接求 $B \times T$ 次方即可。

**引理 4.** 取 $k = 50, B = 30, T = 2 \times 10^5$，**答案正确的概率不小于 $99\%$。**

证明：

$$
\begin{aligned}
\left(1 - \left(\frac{2}{3}\right)^k\right)^{BT} &= \left(1 - \left(\frac{2}{3}\right)^{50}\right)^{30 \times 2 \times 10^5} \\
&= \left(1 - \left(\frac{2}{3}\right)^{50}\right)^{6 \times 10^6} \\
&> 1 - 6 \times 10^6 \left(\frac{2}{3}\right)^{50} \qquad (1-x)^n \ge 1 - nx, x \in (0,1), n \ge 1 \\
&> 1 - 6 \times 10^6 \cdot 1.5684 \times 10^{-9} \\
&= 0.9905896 = 99.05896\%
\end{aligned}
$$

实际上上述估计过于极限，且未考虑位之间的影响。真实错误率远小于 $1\%$。我们可以认为这个解法是正确的。

事实上，取 $k = 80$，正确率可以超过 $99.99999\%$。（但在系统上的运行时间达到了 $650\text{ms}$。虽然时间实际上离限制 $1000\text{ms}$ 比较宽松，但按照"标程时间不高于时间限制的一半"原则，上述解法介绍的随机次数 $k$ 仅给到了 $50$。）

### 做法 2 额外证明提示

二进制第 $i$ 位是周期性的。自然数序列中，二进制第 $i$ 位的循环节是 $2^{i+1}$。

如果 $l, r$ 都不具有第 $i$ 位，但答案具有第 $i$ 位，那么一定 $[l,r]$ 的第 $i$ 位序列一定有连续 $2^i$ 个 $1$， $l + 2^i$ 一定落在一个全是 $1$ 的区间内。

## I NAF领域大神

| 难度 | 考点 |
| --- | --- |
| 5 | 数学结论，进制 |

### 题目

#### 题目描述

非相邻形式（NAF）是把整数写成若干个 $\pm 2^i$ 之和的表示：每一位的系数取自 $\{-1, 0, 1\}$ ，并且任意相邻两位不能同时非 $0$ 。给定整数 $n$ ，求它的 NAF 表示，按从低位到高位的顺序输出每一位的系数。

#### 输入格式

一行一个整数 $n$ 。

#### 输出格式

从低位到高位依次输出 NAF 的每一位系数，相邻两数之间用一个空格分隔。若 $n$ 为负数，则把每一位系数取相反数后再输出。

#### 样例输入

```text
3
```

#### 样例输出

```text
-1 0 1
```

#### 数据范围

$n$ 需要用 `long long` 存储。

### 答案

### 题目分析

为了方便，我们只考虑 $n$ 为正整数的情况。负数只需要把答案全部取相反数就好了。

把 $n$ 表示成二进制的形式，这大概率不能直接作为 NAF 表示，因为可能有很多连续的 $1$，这样就不满足相邻成绩为 $0$ 的条件。

单独研究一段极长的 $1$ 的连续段（极长，指这一段都为 $1$，但左右都是 $0$ 或者到头了，不能延伸得更长）。假如二进制中出现 $(0\ 1\ 1\ 1 \cdots 1\ 1\ 0)$ 这样一段，容易看出可以转化为 $(1\ 0\ 0\ 0 \cdots 0\ {-1}\ 0)$，而值保持不变。

这是因为对任意非负整数 $k, t$

$$2^{k+t} + 2^{k+t-1} + 2^{k+t-2} + \cdots + 2^k = 2^{k+t+1} - 2^k$$

可以发现，转化后，这一段连续的 $1$ 被消除了，相邻乘积为 $0$，满足条件。

那么构造方法就很明显了。

我们可以从二进制的低位开始向高位扫描，寻找 $1$ 的极长连续段。然后把这个连续段按上述方式转换，消除连续的 $1$。要注意段首由 $0$ 变为了 $1$，有可能和更高位形成新的 $1$ 的连续段。

同时注意， $(010)$ 这种孤立的 $1$ 的不需要管，我们只需要消除两个以上相邻的 $1$。

重复以上消除过程，直到全部消除，即完成 NAF 构造。实际上，可以证明这是唯一的构造。

### 示例代码 1（容易理解）

```c
#include<stdio.h>
int main(){
    long long n;
    int flag=1,a[65],m=0;
    scanf("%lld",&n);
    if(n<0){
        n=-n;
        flag=-1;
    }
    while(n){
        a[m++]=(n&1);
        n>>=1;
    }
    a[m]=0;
    for(int i=1;i<m;i++)
    if(!a[i+1]&&a[i]&&a[i-1]){//这代表出现了(011)，i是一个连续段的开头
        a[i+1]=1;
        int j=i;
        while(j>=0&&a[j]==1)a[j--]=0;//寻找连续段的末尾
        a[j+1]=-1;
    }
    for(int i=0;i<m;i++)printf("%d ",a[i]*flag);
    if(a[m])printf("%d",a[m]*flag);//NAF的长度可能比原二进制多一位
    return 0;
}
```

### 示例代码 2（简单）

其实有一种非常简单的写法，但理解起来困难一些。学有余力的同学可以研究一下原理，推荐绝大部分同学掌握写法 1 即可。

## J 设计蚂蚁

| 难度 | 考点 |

| 6 | 位运算，异或性质 |

### 题目

#### 题目描述

多组数据。每组给出两个非负整数 $B$ 和 $C$ ，要求找出最大的非负整数 $A$ ，使得存在非负整数 $D$ 满足 $A + D = B$ 且 $A \oplus D = C$ 。若不存在这样的 $A$ ，输出 `Designant.` 。

#### 输入格式

第一行一个整数 $t$ 。接下来 $t$ 行，每行两个整数 $B$ 和 $C$ ，用空格分隔。

#### 输出格式

每组输出一行：存在时输出最大的 $A$ ，否则输出 `Designant.` 。

#### 样例输入

```text
2
5 1
4 5
```

#### 样例输出

```text
3
Designant.
```

### 答案

### 题目分析

这道题的做法很多，这里只讲一种和本次课联系更紧密的解法。

部分同学可能困扰于不知道怎么保证 $A$ 能同时满足 $B$ 和 $C$ 两个限制。事实上，对于任意非负整数 $x, y$，有以下结论

$$x \oplus y = (x + y) - 2(x \& y)$$

证明：

分别记 $x_i, y_i$ 为 $x, y$ 二进制下第 $i$ 位。

如果 $x_i = y_i = 0$，则 $x_i \oplus y_i = 0$， $(x_i + y_i) - 2(x_i \& y_i) = 0 - 2 \times 0 = 0$，相等。

如果 $x_i, y_i$ 中一个为 $1$，另一个为 $0$，则 $x_i \oplus y_i = 1$， $(x_i + y_i) - 2(x_i \& y_i) = 1 - 2 \times 0 = 1$，相等。

如果 $x_i = y_i = 1$，则 $x_i \oplus y_i = 0$， $(x_i + y_i) - 2(x_i \& y_i) = 2 - 2 \times 1 = 0$，相等。

综合所有二进制位的结果，等式左右仍然相等，得证。

有一句话叫"异或是不进位的加法"，指的就是这个性质。

因为 $A + (B - A) = B$， $A \oplus (B - A) = C$，可以直接求出

$$A \& (B - A) = \frac{B - C}{2}$$

也就是说，和、按位与、按位异或，我们只需要满足其中两个条件，就一定可以保证第三个条件成立！

已知两个数的按位与、按位异或，可以通过简单的贪心策略构造出最大的 $A$。

无解条件： $\frac{B-C}{2}$ 不是非负整数；按位与的结果跟按位异或的结果有冲突。

### 示例代码 1（容易理解）

```c
#include<stdio.h>
int main(){
    int t,a,b,c;
    scanf("%d",&t);
    while(t--){
        scanf("%d%d",&b,&c);
        if(b<c||(b-c)&1)printf("Designant.\n");
        else{
            a=0;
            int tmp=(b-c)>>1;
            int flag=1;
            for(int i=0;i<=30;i++){
                if((tmp>>i)&1){
                    if((c>>i)&1)flag=0;
                    else a|=(1<<i);
                }
                else if((c>>i)&1)a|=(1<<i);
            }
            if(flag)printf("%d\n",a);
            else printf("Designant.\n");
        }
    }
    return 0;
}
```
