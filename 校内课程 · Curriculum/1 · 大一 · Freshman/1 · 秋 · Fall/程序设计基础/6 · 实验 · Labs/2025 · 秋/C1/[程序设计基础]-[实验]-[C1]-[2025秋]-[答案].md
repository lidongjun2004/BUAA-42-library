## B 小宇的整除

| 难度 | 考点 |
| --- | --- |
| 1 | 输入输出 基本运算 |

### 题目

#### 题目描述

读入两个 `int` 范围内的整数 $a$ 和 $b$ ，计算 $a$ 整除 $b$ 的结果，即 C 语言中整数除法 `a / b` 的值（向零取整），再按规定格式输出。

#### 输入格式

一行两个整数 $a$ 和 $b$ ，用空格分隔。

#### 输出格式

一行，格式为 `a div b = c` ，其中 `a` 、 `b` 是读入的两个整数， `c` 是 $a$ 整除 $b$ 的结果，等号前后各有一个空格。

#### 样例输入

```text
5 2
```

#### 样例输出

```text
5 div 2 = 2
```

### 答案

### 题目分析

这道题目需要我们读取两个 `int` 范围的整数 $a$ 和 $b$ ，并对其作整除运算并按规定格式输出。

- 读取 $a$ 和 $b$ 。

  读取前我们需要定义好两个变量，用来存储我们读取的内容，题目规定读取的内容均为 `int` 类型，因此定义两个 `int` 类型的变量 `a` 和 `b`。

  ```c
  int a,b;
  ```

  接着使用 `scanf` 函数去读取输入，并赋值给变量 `a` 和 `b` 。`int` 变量的输入要使用 `%d`。同时需要注意变量 `a` 和 `b` 前要加取址符 `&`

  ```c
  scanf("%d%d",&a,&b);
  ```

- 计算 $a$ 整除 $b$

  在C语言中，如果变量 `a` 、 `b` 都是整数类型（ `int` 、 `long long` 等），则 `a/b` 得到的结果就是 $a$ 整除 $b$ 。同时计算结果要赋值给一个变量。

  ```c
  int c;
  c = a / b;
  ```

  或

  ```c
  int c = a / b;
  ```

- 输出

  最终我们要按照题目要求的格式进行输出，格式类似于 `5 div 2 = 2` ，此处的 5、2、2 分别代表 变量 `a` 、变量 `b` 、变量 `c` （或者 `a / b` ）的值，其值需要在输出时给定，在双引号中 `int` 变量用 `%d` 代替，在双引号后面给出其具体的值。即

  ```c
  printf("%d div %d = %d", a, b, c);
  ```

### 示例代码

```c
#include <stdio.h>

int main()
{
    int a, b;
    scanf("%d%d", &a, &b);
    int c = a / b;
    printf("%d div %d = %d", a, b, c);
    // 上面两行也可合并成 printf("%d div %d = %d",a,b,a/b);
    return 0;
}
```

## D It's MyGO!!!!!

### 题目

#### 题目描述

读入一个整数 $n$ ，先输出 `It's MyGO` ，紧接着输出 $n$ 个感叹号 `!` 。

#### 输入格式

一行一个整数 $n$ 。

#### 输出格式

一行，由 `It's MyGO` 和紧跟其后的 $n$ 个 `!` 组成，中间没有空格，末尾不换行。

#### 样例输入

```text
3
```

#### 样例输出

```text
It's MyGO!!!
```

### 答案

### 题目分析

本题输入 `n` ，输出 `It's MyGO` 后加 `n` 个感叹号。

循环最基础板子题，如果本题遇到困难建议复习 while/for 循环的语法。

### 示例代码 1

```c
#include <stdio.h>
int main(void)
{
    int n;
    scanf("%d", &n);
    printf("It's MyGO");
    int i = 0;
    while (i < n)
    {
        printf("!");
        i = i + 1;
    }
    return 0;
}
```

### 示例代码 2

```c
#include <stdio.h>
int main()
{
    int n;
    scanf("%d", &n);
    printf("It's MyGO");
    for (int i = 1; i <= n; ++i)
    {
        printf("!");
    }
    return 0;
}
```

## E Chronologika

| 难度 | 考点 |
| --- | --- |
| 2 | 输入输出 |

### 题目

#### 题目描述

给定 $n$ 、首项 $a_1$ 和公差 $d$ ，输出等差数列 $a_1, a_1 + d, a_1 + 2d, \cdots, a_1 + (n - 1)d$ 的全部 $n$ 项。

#### 输入格式

一行三个整数 $n$ 、 $a_1$ 、 $d$ ，用空格分隔。

#### 输出格式

一行 $n$ 个整数，相邻两项之间用一个空格分隔。行末多出的空格和文末回车会被滤除，不需要特殊处理。

#### 样例输入

```text
5 1 2
```

#### 样例输出

```text
1 3 5 7 9
```

### 答案

### 题目分析

题目给定 $n, a_1, d$ ，要求输出等差数列 $a_1, a_1 + d, a_1 + 2d, \cdots, a_1 + (n - 1)d$

思路 1：我们可以使用一个循环变量 $i$ 从 $1$ 循环到 $n$ ，然后输出对应通项 $a_i = a_1 + (i - 1)d$ 即可。

思路 2：循环 $n$ 次，对于每一轮循环，先输出 $a_1$ ，再让 $a_1$ 增加 $d$ 。

需要注意的是，评测一般滤除行末空格、文末回车。因此不需要特殊判断什么时候不用输出空格的问题。

### 示例代码 1

```c
#include <stdio.h>

int main()
{
    int n, a1, d;
    scanf("%d%d%d", &n, &a1, &d);
    for (int i = 1; i <= n; i++) // i: 1~n
        printf("%d ", a1 + (i - 1) * d);
    return 0;
}
```

### 示例代码 2

```c
#include <stdio.h>

int main()
{
    int n, a1, d;
    scanf("%d%d%d", &n, &a1, &d);
    while (n > 0)
    {
        printf("%d ", a1); // n: n->1
        a1 += d;
        n--;
    }
    return 0;
}
```

## F 小天才的平均身高计算

| 难度 | 考点 |
| --- | --- |
| 2 | 标记循环控制，整除 |

### 题目

#### 题目描述

不断读入学生的性别和身高，直到读入 `-1 -1` 为止。性别用 $g$ 表示， $g = 0$ 表示男生， $g = 1$ 表示女生； $h$ 是该学生的身高。统计结束后输出三行：全班平均身高、男生平均身高、女生平均身高，三者都向下取整。若没有男生，第二行输出 `No boy` ；若没有女生，第三行输出 `No girl` 。

#### 输入格式

若干行，每行两个整数 $g$ 和 $h$ ，用空格分隔。最后一行固定是 `-1 -1` ，表示输入结束，它不参与统计。

#### 输出格式

三行。第一行是全班平均身高；第二行是男生平均身高或 `No boy` ；第三行是女生平均身高或 `No girl` 。所有平均值都是向下取整的整数。

#### 样例输入

```text
0 170
1 160
0 180
1 150
-1 -1
```

#### 样例输出

```text
165
175
155
```

### 答案

### 题目分析

本题要求很简单，就是读入一串数然后计算平均数，再加上对数据根据性别分类。

难点是标记循环控制。由于事先并不知道输入的数据组数，所以我们控制循环的方式就变为了通过判断是否读入 -1 。并且还要加入通过性别对数据分类处理，这就需要多设置几个变量来储存不同性别的数据。

我们用 `g` 和 `h` 来接收每次输入的性别信息与身高信息，并用 `while(g != 0 && h != 0)` 来控制循环。同时，用变量 `sum0` 、 `sum1` 来分别记录男生的身高总数和女生的身高总数，用 `n0` 、 `n1` 来记录男生与女生的身高总数。

数据输入完成后，在输出阶段，用 `int sum = sum0 + sum1` 和 `n = n0 + n1` 来记录全班的总身高和总人数。题目要求向下取整，直接在整数间使用 `/` 相除即可。

注意: `sum0, sum1, n0, n1` 在循环之前应该进行初始化置 0 。

### 示例代码

```c
#include <stdio.h>

int main()
{
    int g, h, n0, n1, n, sum0, sum1, sum;

    //首先读入一组作为循环判断的初始条件
    scanf("%d%d", &g, &h);
    sum0 = 0; sum1 = 0;
    n0 = 0; n1 = 0;
    while (g != -1 && h != -1) //while 循环: 满足()内条件则进入循环，否则跳出循环
    {
        if(g == 0) //判断性别
        {
            n0 = n0 + 1;
            sum0 = sum0 + h;
        }
        else
        {
            n1 = n1 + 1;
            sum1 = sum1 + h;
        }

        scanf("%d%d", &g, &h); //继续读入为下次循环做准备
    }

    n = n0 + n1;
    sum = sum0 + sum1;

    printf("%d\n", sum / n);

    if(n0 == 0)
        printf("No boy\n");
    else
        printf("%d\n", sum0 / n0);

    if(n1 == 0)
        printf("No girl\n");
    else
        printf("%d\n", sum1 / n1);

    return 0;
}
```

## G Squids on that day

| 难度 | 考点 |
| --- | --- |
| 2 | 鸡兔同笼 |

### 题目

#### 题目描述

海里有 $n$ 只软体动物，只有章鱼和鱿鱼两种。章鱼有 8 条触腕，鱿鱼有 10 条触腕。现在数出它们一共有 $m$ 条触腕，求鱿鱼有多少只。若给出的 $n$ 和 $m$ 不可能对应任何一种合理的组合，输出 `ERR0R` （注意是数字 0 而不是字母 O）。

#### 输入格式

一行两个整数 $n$ 和 $m$ ，用空格分隔。

#### 输出格式

一行一个整数，表示鱿鱼的只数；若不存在合法方案则输出 `ERR0R` 。

#### 样例输入

```text
10 84
```

#### 样例输出

```text
2
```

### 答案

### 题目分析

本题实际上相当于解二元一次方程组

$$
\begin{cases}
x + y = n \\
8x + 10y = m
\end{cases}
$$

解方程可得 $y = \frac{m - n \times 8}{2}$ ，但考虑到现实意义，需要保证 $y$ 是小于等于 $n$ 的自然数。因此需要满足以下条件：

$$
\begin{cases}
8n \le m \le 10n \\
m \equiv 0 \ (mod \ 2)
\end{cases}
$$

在计算之前，需要先验证符合有解的条件。

### 示例代码 1

```c
#include <stdio.h>

int main() {
    int n, m;

    scanf("%d%d", &n, &m);

    if ( m % 2 == 1 || // 不可能有奇数条触腕
         n * 8 > m || // 即使全是章鱼，触腕数也不够
         n * 10 < m ) // 即使全是鱿鱼，触腕数也超过了
        printf("ERR0R"); // 注意是 ERR0R 而不是 ERROR
    else
        printf("%d", (m - n * 8) / 2); // 否则输出鱿鱼数

    return 0;
}
```

### 示例代码 2

直接硬解方程组，如果中间有无法整除的部分，那么回代验算的时候就会发现不成立。然后再判断一下解出来的两个未知数是否非负即可。

```c
#include <stdio.h>
int main(void)
{
    int n, m;
    scanf("%d%d", &n, &m);
    int y = m / 2 - 4 * n;
    int x = n - y;
    if (x < 0 || y < 0 || 8 * x + 10 * y != m)
    {
        printf("ERR0R");
    }
    else
    {
        printf("%d", y);
    }
    return 0;
}
```

## H Miku 的最小公倍数

| 难度 | 考点 |
| --- | --- |
| 3 | 循环、最大公约数 |

### 题目

#### 题目描述

读入三个正整数 $a$ 、 $b$ 、 $c$ ，输出它们的最小公倍数。

#### 输入格式

一行三个正整数 $a$ 、 $b$ 、 $c$ ，用空格分隔。

#### 输出格式

一行一个整数，表示 $a$ 、 $b$ 、 $c$ 的最小公倍数。

#### 样例输入

```text
4 6 8
```

#### 样例输出

```text
24
```

### 答案

### 题目分析

我们可以参照 PPT 的代码暴力循环求得三个数的最小公倍数，从三个数中最大的数开始，依次加一，看能否被这三个数整除，只需稍微修改 Hint 下方的代码即可。

### 示例代码

```c
#include <stdio.h>

int main()
{
    int a, b, c, lcm;
    scanf("%d%d%d", &a, &b, &c);

    lcm = a;
    if (lcm < b)
        lcm = b;
    if (lcm < c)
        lcm = c;

    while (lcm % a != 0 || lcm % b != 0 || lcm % c != 0)
    {
        lcm = lcm + 1;
    }
    printf("%d", lcm);

    return 0;
}
```

### 附

实际上，我们可以看出，这种暴力枚举的效率是非常低的，电脑一秒钟计算的次数也是有限的（大约是一秒钟能进行 $10^{8}$ 数量级次数的计算），所以当面对比较大的数时，这种方法往往难以在短时间内找出答案。

通常来说，我们会使用 $lcm(a, b) = \frac{ab}{gcd(a, b)}$ 这样一条结论来计算出两个数之间的最小公倍数。

当然，PPT 里计算最大公约数 $gcd(a, b)$ 的方法也是可以进行优化的，只不过目前鉴于初次接触 C 语言，因此暂且不表，之后的课程会学习更加高效的计算 $gcd(a, b)$ 的方法。

证明： $lcm(a, b) = \frac{ab}{gcd(a, b)}$

设 $a, b$ 的质因数分解为：

$$
a = p_1^{a_1} p_2^{a_2} \cdots p_n^{a_n}
$$

$$
b = p_1^{b_1} p_2^{b_2} \cdots p_n^{b_n}
$$

其中 $p_i$ 为互不相同的质数， $a_i, b_i$ 为非负整数，即 $a_i, b_i \in \mathbb{N}$

例如： $12 = 2^{2} \times 3^{1}$ ， $18 = 2^{1} \times 3^{2}$

那么，最大公约数为：

$$
gcd(a, b) = p_1^{\min(a_1, b_1)} p_2^{\min(a_2, b_2)} \cdots p_n^{\min(a_n, b_n)}
$$

同理，最小公倍数为：

$$
lcm(a, b) = p_1^{\max(a_1, b_1)} p_2^{\max(a_2, b_2)} \cdots p_n^{\max(a_n, b_n)}
$$

其中的 $\min(x, y)$ 为 $x, y$ 两个数中最小的数， $\max(x, y)$ 为 $x, y$ 两个数中最大的数

不难看出：

$$
\min(x, y) + \max(x, y) = x + y
$$

则有：

$$
gcd(a, b) \times lcm(a, b) = p_1^{\min(a_1, b_1) + \max(a_1, b_1)} p_2^{\min(a_2, b_2) + \max(a_2, b_2)} \cdots p_n^{\min(a_n, b_n) + \max(a_n, b_n)} = p_1^{a_1 + b_1} p_2^{a_2 + b_2} \cdots p_n^{a_n + b_n} = ab
$$

得证： $lcm(a, b) = \frac{ab}{gcd(a, b)}$

## I 7 numbers

| 难度 | 考点 |
| --- | --- |
| 3 | 循环 |

### 题目

#### 题目描述

把十进制表示中含有数字 7 的正整数从小到大排列，例如 7、17、27、37、…… 读入 $n$ ，输出这个序列中的第 $n$ 个数。

#### 输入格式

一行一个整数 $n$ 。

#### 输出格式

一行一个整数，表示第 $n$ 个数位中含有 7 的正整数。

#### 样例输入

```text
3
```

#### 样例输出

```text
27
```

### 答案

### 题目分析

本题输入 `n` ，输出第 `n` 个数位含 7 的数字。

题目的 hint 给的非常明确，每个数字一直通过 `/10` 操作右移，每次通过 `%10` 判断个位是否为 7 ，只要出现了 7 即可记录为含 7 的数字 。

### 示例代码

```c
#include <stdio.h>
int main(void)
{
    int n;
    scanf("%d", &n);
    int cnt = 0;
    int i = 1;
    while (cnt < n)
    {
        i = i + 1;
        int flag = 0; // 记录是否为含 7 的数字
        int temp = i; // 临时储存 i
        while (temp > 0)
        {
            if (temp % 10 == 7)
            {
                flag = 1;
            }
            temp /= 10;
        }
        if (flag == 1)
        {
            cnt = cnt + 1;
        }
    }
    printf("%d", i);
    return 0;
}
```

### 题目分析

题目给定 $n$ ，求 $42 \times \sum_{i=1}^{n} \sum_{j=1}^{n} (i + j)ij$ ，其中 $1 \le n < 998244353$ 。

需要注意的是，计算机一秒能够运行的操作数一般估计在 $5 \times 10^{7}$ 到 $5 \times 10^{8}$ 之间。如果我们用双重循环枚举 $i$ 和 $j$ ，则大约需要 $n^{2}$ 次运算，量级在 $10^{18}$ 次左右，这一定会运行超时。我们需要更快的做法。

观察式子。

$$
42 \times \sum_{i=1}^{n} \sum_{j=1}^{n} (i + j)ij = 42 \times \sum_{i=1}^{n} \sum_{j=1}^{n} (i^{2}j + ij^{2})
$$

$$
= 42 \times \left( \sum_{i=1}^{n} \sum_{j=1}^{n} i^{2}j + \sum_{i=1}^{n} \sum_{j=1}^{n} ij^{2} \right)
$$

$$
= 42 \times \left( \sum_{i=1}^{n} i^{2} \sum_{j=1}^{n} j + \sum_{i=1}^{n} i \sum_{j=1}^{n} j^{2} \right)
$$

$$
= 42 \times \left( \left( \sum_{i=1}^{n} i^{2} \right) \left( \sum_{j=1}^{n} j \right) + \left( \sum_{i=1}^{n} i \right) \left( \sum_{j=1}^{n} j^{2} \right) \right)
$$

$$
= 42 \times \left( \frac{(2n + 1)(n + 1)n}{6} \times \frac{(n + 1)n}{2} + \frac{(n + 1)n}{2} \times \frac{(2n + 1)(n + 1)n}{6} \right)
$$

$$
= 42 \times 2 \times \frac{(2n + 1)(n + 1)n}{6} \times \frac{(n + 1)n}{2}
$$

$$
= 42 \times 2 \times \frac{n^{2}(n + 1)^{2}(2n + 1)}{6 \times 2}
$$

$$
= 7n^{2}(n + 1)^{2}(2n + 1)
$$

实际上，我们这里使用了换序求和结论：若 $i$ 与 $j$ 取值范围无关，则

$$
\sum_{i} \sum_{j} f(i)g(j) = \sum_{i} f(i) \sum_{j} g(j) = \left( \sum_{i} f(i) \right) \left( \sum_{j} g(j) \right)
$$

于是，直接输出答案 $7n^{2}(n + 1)^{2}(2n + 1)$ 即可。

此外需要注意的是，类型 `int` 可表示的范围只有 $[-2147483648, 2147483647]$ 。如果对于题目中的 $n$ 计算 $n \times n$ 时使用 `int` 类型，将会导致有符号整型溢出的未定义行为。未定义行为是极其危险的，而且一般会导致答案错误。

因此，我们应当使用范围更大的 `long long` 类型，能够表示 $[-9223372036854775808, 9223372036854775807]$ ，能够满足 $n \times n$ 的正确计算，但是不能满足 $n \times n \times (n + 1)$ ，所以每一步乘法之后都要取模。

### 示例代码 1

```c
#include <stdio.h>

int main()
{
    long long n, p = 998244353;
    scanf("%lld", &n);
    // 运算中间也可能爆 long long，所以中间每一步都要取模。
    // ans = 7*n*n*(n+1)*(n+1)*(2*n+1)
    long long ans = 7 * n % p * n % p * (n + 1) % p * (n + 1) % p * (2 * n + 1) % p;
    printf("%lld", ans);
    return 0;
}
```

### 示例代码 2

```c
#include <stdio.h>

int main() {
    long long n, p = 998244353;
    scanf("%lld",&n);
    // 运算中间也可能爆 long long，所以中间每一步都要取模。
    // ans = 7*n*n*(n+1)*(n+1)*(2*n+1)
    long long ans = 7;
    ans = ans * n % p;
    ans = ans * n % p;
    ans = ans * (n + 1) %p;
    ans = ans * (n + 1) %p;
    ans = ans * (2 * n + 1) %p;
    printf("%lld",ans);
    return 0;
}
```
