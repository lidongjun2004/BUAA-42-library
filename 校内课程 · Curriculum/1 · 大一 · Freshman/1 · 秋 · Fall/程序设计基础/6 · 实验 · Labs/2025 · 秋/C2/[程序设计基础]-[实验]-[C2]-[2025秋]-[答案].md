## A ("%d + %d = %d", a, b, sum)

| 难度 | 考点 |
| --- | --- |
| 1 | 转义字符 |

### 题目

#### 题目描述

题目给出一段完整的 C 语言代码，要求你的程序把这段代码原样打印出来。代码中包含制表符缩进，以及 `\` 、 `"` 、 `%` 这些在字符串里需要转义的字符：打印一个反斜杠要写成 `\\` ，打印一个双引号要写成 `\"` ，打印一个百分号要写成 `%%` 。缩进用制表符或 4 个空格都可以。

#### 输入格式

无。

#### 输出格式

共 8 行，就是题目给出的那段 C 代码：第一行 `#include<stdio.h>` ，第二行 `int main() {` ，随后 6 行带一级缩进的语句，最后一行 `}` 。最后一行末尾不换行。

#### 样例输入

```text

```

#### 样例输出

```text
#include<stdio.h>
int main() {
    int a, b, sum;
    scanf("%d%d", &a, &b);
    sum = a + b;
    printf("%d + %%d = %%d", a, b, sum);
    return 0;
}
```

### 答案

### 题目分析

将题目中要求打印的内容复制到 `printf("")` 的双引号中，然后处理缩进以及 `"` 和 `%` 的转义即可。

### 示例代码

```c
#include<stdio.h>
int main() {
    printf("#include<stdio.h>\n");
    printf("int main() {\n");
    printf("\tint a, b, sum;\n");
    printf("\tscanf(\"%%d%%d\", &a, &b);\n");
    printf("\tsum = a + b;\n");
    printf("\tprintf(\"%%d + %%d = %%d\", a, b, sum);\n");
    printf("\treturn 0;\n");
    printf("}");
    return 0;
}
```

注：将代码中所有 `\t` 替换为 4 个空格也是正确的。

## B 泠涼的偏好 1

| 难度 | 考点 |
| --- | --- |
| 1 | ASCII，不定组输入 |

### 题目

#### 题目描述

泠涼只喜欢字母和数字。输入若干个整数，每个整数是某个字符的 ASCII 码。若该字符是字母或数字，输出一行 `Lingliang likes c!` ，其中 `c` 就是这个字符；否则输出一行 `Eww` 。输入一直读到文件结束。

#### 输入格式

若干个整数，表示字符的 ASCII 码，每行一个或用空格分隔，读到文件结束（EOF）为止。

#### 输出格式

每个输入的整数对应一行输出：字符是字母或数字时输出 `Lingliang likes c!` ，否则输出 `Eww` 。

#### 样例输入

```text
65 97 33
```

#### 样例输出

```text
Lingliang likes A!
Lingliang likes a!
Eww
```

### 答案

### 题目分析

正如「hint」中所说，不定组输入可以参考课件中的例 2-3，使用 `while(scanf(...) != EOF)` 的方式读入。

判断字符是否属于字母或数字可以通过比较来完成（参考例 2-9），注意逻辑或关系间应使用 `||` 连接，逻辑与关系间应使用 `&&` 连接。

每一次输出后应记得换行。

### 示例代码1

```c
#include<stdio.h>
int main() {
    int x;
    while(scanf("%d", &x) != EOF) { // 不定组输入
        if (('0' <= x && x <= '9') || ('A' <= x && x <= 'Z') || ('a' <= x && x <= 'z'))
            printf("Lingliang likes %c!\n", x); // 以字符形式输出
        else
            printf("Ewww\n");
    }
}
```

### 示例代码2

可以利用 `<ctype.h>` 中的 `isalnum` 函数帮助我们简化代码，这个函数功能是判断一个字符是否是字母或数字。

```c
#include <stdio.h>
#include <ctype.h>
int main(void)
{
    int n;
    while (scanf("%d", &n) != EOF)
    {
        if (isalnum(n))
            printf("Lingliang likes %c!\n", n);
        else
            printf("Ewww\n");
    }
    return 0;
}
```

## C 激光炮直瞄

| 难度 | 考点 |
| --- | --- |
| 1 | 多组输入，浮点数 |

### 题目

#### 题目描述

激光炮沿直线瞄准目标。读入 $n$ 个圆的半径 $r$ ，对每个半径输出对应圆的周长 $2 \pi r$ ，保留 4 位小数。

#### 输入格式

第一行一个整数 $n$ 。接下来 $n$ 行，每行一个实数 $r$ ，表示圆的半径。

#### 输出格式

$n$ 行，每行一个实数，表示对应圆的周长，保留小数点后 4 位。

#### 样例输入

```text
2
1
2
```

#### 样例输出

```text
6.2832
12.5664
```

### 答案

### 题目分析

用 `for` 循环计数输入的次数，每次输入一个小数，计算它乘以 $2\pi$ 的结果并输出即可。

### 注意事项

1. 如果题目中没有给出明确的近似值要求，**不建议使用自己定义的** $\pi$。许多计算几何题都要使用到 $\pi$，这些题往往也涉及浮点数，如果使用了自己定义的、精度不够的 $\pi$，就可能会出现一些难以排查的错误。
   可以在代码最前面增加 `#include <math.h>`，之后使用 `acos(-1)` 来获取 $\pi$。
2. 除非题目对内存用量有要求，否则**总是使用 `double` 来存储浮点数**。同样是在计算几何类的题中，往往涉及浮点数做分母，此时微小的误差就容易被放大，造成错误。
3. 输入 `double` 型变量应当用 `%lf` 而不是 `%f`，输出 `double` 型变量则是 `%f` 与 `%lf` 均可使用

### 示例代码 1

```c
#include <stdio.h>
#define MY_PI 3.14159265358979                  // 用 #define 定义常量

int main() {
    int n = 0;
    scanf("%d", &n);
    for (int i = 0; i < n; ++i) {
        double r = 0;                          // 用 double 存储浮点数
        scanf("%lf", &r);
        printf("%.4lf\n", 2 * MY_PI * r);
    }
}
```

### 示例代码 2

```c
#include <math.h>
#include <stdio.h>

int main() {
    int n = 0;
    scanf("%d", &n);
    for (int i = 0; i < n; ++i) {
        double r = 0;
        scanf("%lf", &r);
        printf("%.4lf\n", 2 * acos(-1) * r);   // 在题目没有特殊要求的情况下获取 PI
    }
}
```

## D 楼主别急，有反转！1

| 难度 | 考点 |
| --- | --- |
| 1 | 数组 |

### 题目

#### 题目描述

读入 $n$ 个整数，把它们按输入顺序的相反顺序输出。

#### 输入格式

第一行一个整数 $n$ 。第二行 $n$ 个整数，用空格分隔。

#### 输出格式

一行 $n$ 个整数，顺序与输入完全相反，相邻两数之间用一个空格分隔。

#### 样例输入

```text
5
1 2 3 4 5
```

#### 样例输出

```text
5 4 3 2 1
```

#### 数据范围

元素个数不超过 1000。元素的值超出 `int` 范围，需要用 `long long` 存储。

### 答案

### 题目分析

给定元素个数的数组读入相信大家已经基本掌握了，本题主要考查大家对 `for` 循环的掌握（当然使用 `while` 也是可以的）。

顺序循环时使用 `for(i = h; i <= t; ++i)`，我们也可以类似地实现倒序循环 `for(i = t; i >= h; --i)`（`++` 和 `--` 的用途参见课件）。

当然也可以同样通过顺序循环，但是输出 `a[n - i + 1]` 来实现倒序输出。

注意本题的数据范围超过了 `int` 的 $[-2147483648, 2147483647]$，应当使用 `long long`（记得输入输出时使用 `%lld`）。

同时数组元素最多会用到 1000 个，实际定义时建议把数组开大一点（一般来说是大 5 到 10 个）

### 示例代码

```c
#include<stdio.h>

int main() {
    int n;
    long long a[1008];
    scanf("%d", &n);
    for(int i = 1; i <= n; ++i)
        scanf("%lld", &a[i]);
    for(int i = n; i >= 1; --i) // 倒序循环
        printf("%lld ", a[i]);
}
```

**注意**：如果你的写法会访问到 `a[1000]`，那么在定义数组的时候，至少要定义到 `long long a[1001]`！因为数组下标是从 0 开始计数的。

## E AN-94 的排名

| 难度 | 考点 |
| --- | --- |
| 1 | 循环 |

### 题目

#### 题目描述

读入 $n$ 个成绩和其中一个成绩 $x$ ，输出 $x$ 在这 $n$ 个成绩中的排名。排名的定义是：比 $x$ 大的成绩个数再加 1。

#### 输入格式

第一行两个整数 $n$ 和 $x$ 。第二行 $n$ 个整数，表示 $n$ 个成绩，用空格分隔。

#### 输出格式

一行一个整数，表示 $x$ 的排名。

#### 样例输入

```text
5 90
100 90 80 95 90
```

#### 样例输出

```text
3
```

### 答案

输入 $n$ 和 $x$ 之后，我们需要用一个 `for` 循环输入所有成绩，可以用数组存储，不过也有别的方法，我们继续往下看。

根据排名的定义，我们仅需要统计有多少个数大于 $x$，记这个数大小为 `cnt`，那么答案为 `cnt + 1`。也就是说，对于每个输入的成绩 $a$，我们仅需用一个 `if` 语句判断它和 $x$ 的大小关系，根据情况决定是否对 `cnt` 加 1 之后，就可以把现在输入的这个 $a$ “扔掉” 了。在代码实现里，我们在下一轮循环重复输入 $a$ 就能够覆盖掉原来的值，以达到这个 “扔掉” 的效果，

代码实现：

```c
#include <stdio.h>

int main()
{
    int n, x, a;
    scanf("%d%d", &n, &x);

    int rk = 1;
    for (int i = 1; i <= n; ++i)
    {
        scanf("%d", &a);
        if (a > x)
            ++rk;
    }

    printf("%d\n", rk);

    return 0;
}
```

## F Imitation Game

| 难度 | 考点 |
| --- | --- |
| 2 | ASCII 码与字符常量 |

### 题目

#### 题目描述

一种加密方式把字母按下面的规则替换：把倒数第 $i$ 个小写字母转换成第 $i$ 个大写字母，把倒数第 $i$ 个大写字母转换成第 $i$ 个小写字母，非字母字符保持不变。现在给出用这种方式加密得到的密文，要求解密并输出原文。解密规则相应地为：第 $i$ 个小写字母转换成倒数第 $i$ 个大写字母，第 $i$ 个大写字母转换成倒数第 $i$ 个小写字母，其余字符原样输出。

#### 输入格式

一串字符，可能包含空格和换行，一直读到文件结束（EOF）为止。

#### 输出格式

解密后得到的字符串，按输入顺序输出，不额外添加换行。

#### 样例输入

```text
Hello, World!
```

#### 样例输出

```text
sVOOL, dLIOW!
```

### 答案

### 题目分析

题目的要求是通过 ASCII 码对字符解密，字母字符的加密规则为：

将**倒数**第 $i$ 个小写字母转换为第 $i$ 个大写字母，将**倒数**第 $i$ 个大写字母转换为第 $i$ 个小写字母。

故解密规则应该是：

**第 $i$ 个小写字母转换为倒数第 $i$ 个大写字母；第 $i$ 个大写字母转化为倒数第 $i$ 个小写字母**，非字母字符照原样输出即可

知道了转换的规则，现在来解决具体的转换方法。根据 ASCII 码的相关知识，字符 `'a'` 到字符 `'z'` 的 ASCII 码值是连续的，字符 `'A'` 到字符 `'z'` 的 ASCII 码的连续的；加之字符变量的 ASCII 码值可以进行算数运算，所以对于小写字母字符 `'char1'`，`'char1' - 'a' + 1` 即为 `'char1'` 的编号；大写字母字符 `'char2'`，`'char2' - 'A' + 1` 即为 `'char1'` 的编号。

同时，根据以上的字符变量的 ASCII 码特性，判断字符 `c` 是否是小写字母的方法是

```c
if(c >= 'a' && c <= 'z')
```

大写的字母的判定方式也就不难得到了

由于输入的语句长度未知，循环读入的可以通过判断 `scanf()` 函数的返回值是否等于 `EOF`

### 示例代码

```c
#include <stdio.h>

int main()
{
    char c;

    while(scanf("%c", &c) != EOF)
    {
        char ans;
        if(c >= 'a' && c <= 'z')
        {
            ans = 'Z' - (c - 'a');
            printf("%c", ans);
        }
        else if(c >= 'A' && c <= 'Z')
        {
            ans = 'z' - (c - 'A');
            printf("%c", ans);
        }
        else printf("%c", c);
    }

    return 0;
}
```

## G JDK 的程设作业 ddl

| 难度 | 考点 |
| --- | --- |
| 2 | 时间运算，格式化输出 |

### 题目

#### 题目描述

JDK 要在若干天的空闲时间里完成程设作业。先给出作业的预计用时，再给出 $n$ 天中每一天的空闲时段起止时刻。对每一天，先输出该天空闲时段的时长，再判断这段时间是否够完成作业：够则在同一行输出 `Yes!` ，不够则输出 `No~555~` 。时长一律按 `hh:mm:ss` 格式输出，不足两位补前导零。

#### 输入格式

第一行一个整数 $n$ 。第二行一个时刻 `hh:mm:ss` ，表示作业的预计用时。接下来 $n$ 行，每行两个时刻 `hh:mm:ss` ，分别表示当天空闲时段的起点和终点。

#### 输出格式

$n$ 行，每行形如 `hh:mm:ss Yes!` 或 `hh:mm:ss No~555~` ，时刻与判断结果之间用一个空格分隔。

#### 样例输入

```text
2
01:00:00
08:00:00 12:30:00
09:00:00 09:30:00
```

#### 样例输出

```text
04:30:00 Yes!
00:30:00 No~555~
```

### 答案

### 题目分析

本题需要处理时间差与格式化输出。

关键步骤如下：

1. **读入预计用时**：解析 `hh:mm:ss`，并转换为总秒数 `need`。
2. **处理每天的空闲时间段**：
   - 将起始、结束时间同样转换为秒数 `sl` 和 `sr`；
   - 计算差值 `sub = sr - sl`。
3. **输出空闲时长**：
   - 将 `sub` 秒数还原为 `hh:mm:ss`，并使用 `%02d` 补齐前导零。
4. **判断能否完成**：
   - 若 `sub >= need`，输出 `Yes!`；否则输出 `No~555~`。

时间差计算推荐统一用秒数，避免手动进位麻烦。

本题主要难点在于：

- 输入/输出时间的格式解析与补零。
- 输出格式必须严格对齐，如 `03:04:05`。

### 示例代码

```c
#include <stdio.h>

int main(void)
{
    int n;
    scanf("%d", &n);
    int h, m, s;
    scanf("%d:%d:%d", &h, &m, &s);
    int need = h * 3600 + m * 60 + s;   // 作业预计用时（秒）
    for (int i = 0; i < n; i++) {
        int hh, mm, ss;
        scanf("%d:%d:%d", &hh, &mm, &ss);
        int sl = hh * 3600 + mm * 60 + ss;   // 当天空闲起点
        scanf("%d:%d:%d", &hh, &mm, &ss);
        int sr = hh * 3600 + mm * 60 + ss;   // 当天空闲终点

        int sub = sr - sl;                   // 空闲时长（秒）
        hh = sub / 3600;
        mm = sub / 60 % 60;
        ss = sub % 60;

        if (sub >= need)
            printf("%02d:%02d:%02d Yes!\n", hh, mm, ss);
        else
            printf("%02d:%02d:%02d No~555~\n", hh, mm, ss);
    }
    return 0;
}
```

## H 水库预测-version1

| 难度 | 考点 |
| --- | --- |
| 3 | 贪心、不定组输入、long long |

### 题目

#### 题目描述

水库的初始水位是 $h$ ，低水位预警线是 $p$ ，高水位预警线是 $q$ 。第 0 天水位按顺序变化 $n$ 次，第 $i$ 次的变化量为 $a_i$ ，于是第 0 天各时刻的水位依次是 $h + a_1$ 、 $h + a_1 + a_2$ 、……、 $h + \sum_{i=1}^{n} a_i$ 。此后的每一天，水位都按同样的规律变化，即每天同一时刻的水位比前一天同一时刻多出 $sum = \sum_{i=1}^{n} a_i$ 。只要某一时刻的水位不大于 $p$ 就触发低水位预警，不小于 $q$ 就触发高水位预警。请求出最早触发的预警类型：低水位预警输出 `down` ，高水位预警输出 `up` ，永远不会触发任何预警则输出 `No` 。注意即使 $sum > 0$ ，第 0 天也可能出现水位已经低于 $p$ 的情况，此时最早触发的是低水位预警。输入包含多组数据。

#### 输入格式

多组数据，读到文件结束为止。每组数据第一行是三个整数 $h$ 、 $p$ 、 $q$ ；第二行是一个整数 $n$ ；第三行是 $n$ 个整数 $a_1, a_2, \ldots, a_n$ 。

#### 输出格式

每组数据输出一行，为 `down` 、 `up` 或 `No` 之一。

#### 样例输入

```text
10 5 20
3
1 2 3
```

#### 样例输出

```text
up
```

#### 数据范围

水位、预警线与变化量之和都会超出 `int` 范围，需要用 `long long` 存储。

### 答案

### 题目分析

由题可知，这个水库第 $i$ 天相对于同一时刻的第 $i + 1$ 天将变化 $a_1 + a_2 + \ldots + a_n$ 的水位，我们将这个值记录为 $sum$。

由于没有限制天数，我们很容易得到，当 $sum > 0$ 时，水位总有一天会超过（达到） $q$；当 $sum < 0$ 时，水位总有一天会低于（达到） $p$。但是这时触发的预警并不一定是最早触发的预警。由第三个样例可知，即使 $sum > 0$，也会因为某天中水位最低点低于（达到） $p$ 而触发预警。

此时，我们可以思考以下内容：如果 $sum \ge 0$，那么代表水位每天都不低于上一天同一时刻的水位。如果第 0 天所有时刻的水位均大于 $p$，那么对于任意天任意时刻的水位，其永远不低于第 0 天同时刻的水位，故均大于 $p$；同理，如果 $sum \le 0$，那么代表水位每天都不高于上一天同一时刻的水位。如果第 0 天所有时刻的水位均低于 $q$，那么对于任意天任意时刻的水位，其永远不高于第 0 天同时刻的水位，故均低于 $q$。

由上述分析，我们自然可以想到一种做法：先枚举出第 0 天所有的水位，若此时出现预警，则直接结束；否则，根据 $sum$ 的值将情况分为三类；

1. $sum > 0$：此时任意天任意时刻的水位均大于 $p$，而总有一天水位会超过（达到） $q$，故最早触发的预警为高水位预警。
2. $sum < 0$：此时任意天任意时刻的水位均低于 $q$，而总有一天水位会低于（达到） $p$，故最早触发的预警为低水位预警。
3. $sum = 0$：此时任意天任意时刻的水位均低于 $q$ 且高于 $p$，即始终没有出现任何预警。

在想明白以上内容后还可能出现的错误预测：

1. 没有使用 $long\ long$： $sum$ 的计算会超过 $int$ 范围，导致错误。即使每次计算 $sum$ 前都先判断水位是否大于等于 $q$，也会因为 $2e9 + 1.9e9 = 3.9e9 (\ge 2^{31})$ 而爆 $int$。
2. 枚举判断第 0 天水位时没有判断是否已出现预警：第 0 天是可能既出现低水位预警又出现高水位预警的。
3. 未读取全一组数据的输入：在读取 $a_i$ 时，即使我们只读取了一部分就能够判断出最早出现了什么类型的预警，也要将所有数据进行读入，避免这些未读入的数据影响其他组输入。
4. 字符串大小写错误：注意输出字符串哪些要大写，哪些要小写。（大小写差异较大，估计这么错的人很少）

出题者感言：这题我是根据24届程设我出的C1H题改的，那一题被一些同学称为毒瘤……希望这题在做如此的简单化后（原本要问最早出现预警的时间）能够达到指定难度，至少不再是毒瘤。（通过率在10%左右）

### 示例代码

```c
#include <stdio.h>

int main()
{
    long long h, p, q;
    while (scanf("%lld%lld%lld", &h, &p, &q) != EOF)
    {
        long long n;
        scanf("%lld", &n);
        long long i;
        long long sum = 0;
        long long flag = 0;
        for (i = 0; i < n; i++)
        {
            long long a;
            scanf("%lld", &a);
            sum += a;
            if (h + sum <= p && flag == 0)
            {
                flag = 1;
                printf("down\n");
            }
            if (h + sum >= q && flag == 0)
            {
                flag = 1;
                printf("up\n");
            }
        }
        if (flag == 0)
        {
            if (sum > 0)
                printf("up\n");
            else if (sum < 0)
                printf("down\n");
            else
                printf("No\n");
        }
    }

    return 0;
}
```

## I 逆序列还原全排列

| 难度 | 考点 |
| --- | --- |
| 3 | 数组，循环 |

### 题目

#### 题目描述

对于 $1$ 到 $n$ 的一个全排列，定义它的逆序列：逆序列的第 $k$ 个数表示在原排列中位于 $k$ 前面且比 $k$ 大的数的个数。现在给定一个逆序列，要求还原出对应的全排列。

#### 输入格式

第一行一个整数 $n$ 。第二行 $n$ 个整数，表示逆序列，用空格分隔。

#### 输出格式

一行 $n$ 个整数，表示还原得到的全排列，相邻两数之间用一个空格分隔。

#### 样例输入

```text
5
1 3 0 1 0
```

#### 样例输出

```text
3 1 5 4 2
```

#### 数据范围

$1 \le n \le 10^{4}$

### 答案

### 解题思路

如果没有理解什么是逆序列可以再看看样例解释中的例子。

由逆序列的定义可知，对于一个满足 $1 \le k \le n$ 的数 $k$，如果比 $k$ 小的所有数在原排列中的位置已经确定，那么数 $k$ 的位置一定可以唯一确定。所以我们只要按数的大小从小到大找到它所在的位置即可确定整个排列。

例：逆序列 `1,3,0,1,0`

第 1 位是 1，说明在原排列中有 1 个比 1 大的数在 1 前，我们只需在 1 前面留 1 个空位，所以将 1 填入第 2 个空位：

```text
_   1   _   _   _
```

第 2 位是 3，说明在原排列中有 3 个比 2 大的数在 2 前，我们只需在 2 前面留 3 个空位，所以将 2 填入第 4 个空位：

```text
_   1   _   _   2
```

**注意是第 4 个空位而非第 4 个位置。**

以此类推，便可将所有数填入序列：

```text
3   1   _   _   2
```

```text
3   1   _   4   2
```

```text
3   1   5   4   2
```

用代码模拟以上过程即可。

### 示例代码

```c
#include <stdio.h>
int nums[10010]; // 记录逆序列
int perm[10010]; // 用于存储原排列

int main()
{
    int n;
    scanf("%d", &n);
    for (int i = 1; i <= n; i++)
    {
        scanf("%d", &nums[i]);
    }
    for (int i = 1; i <= n; i++)
    {
        int gap = 0, index = 0; // gap记录已经遍历过了多少个空位
        while (gap <= nums[i])
        {
            index++;
            if (perm[index] == 0)
            {
                gap++;
            }
        }
        perm[index] = i;
    }
    for (int i = 1; i <= n; i++)
    {
        printf("%d ", perm[i]);
    }
    return 0;
}
```

可以注意到这个时间复杂度是 $O(n^2)$ 的，在 $1 \le n \le 10^4$ 的数据范围下是可以接受的。

请有竞赛经历的同学自行思考将 $n$ 的范围扩展到 $1 \le n \le 2 \times 10^5$ 的做法。

## J 言叶的算式

| 难度 | 考点 |
| --- | --- |
| 5 | 数组 |

### 题目

#### 题目描述

给定 $n$ 个数 $a_1, a_2, \ldots, a_n$ ，在相邻两数之间的 $n - 1$ 个空里各填入 $\times$ 、 $+$ 、 $-$ 三种运算符之一，共 $3^{n-1}$ 种填法。每种填法得到一个算式，按通常的优先级先乘后加减求值。求所有填法所得结果的总和，答案对 998244353 取模。

#### 输入格式

第一行一个整数 $n$ 。第二行 $n$ 个整数 $a_1, a_2, \ldots, a_n$ ，用空格分隔。

#### 输出格式

一行一个整数，表示所有填法的结果之和对 998244353 取模的值。

#### 样例输入

```text
3
1 2 3
```

#### 样例输出

```text
16
```

### 答案

### 题解

注意到

$$
\sum_{i=1}^{n-1}\left(2 \times 3^{n-1-i} \times \prod_{j=1}^{i} a_i\right) + \prod_{i=1}^{n} a_i
$$

是答案。下证这是答案。

假如我们考虑序列 $1 \times 2 + 3 \times 4 - 5$，存在唯一对应的序列 $1 \times 2 - 3 \times 4 + 5$，这两者的求和把第一个非乘号后面的全部抵消了！

对于一个可能的填充序列，将 $+$ 和 $-$ 互换，后面直接抵消。因此，我们只需要考虑最后一个乘号在哪里，考虑之前的所有项乘起来，再乘以后面可以填的方案数，加到答案里，求和。

如果第一个加减号在 $a_1, a_2$ 之间，所有的空有 $2 \times 3^{n-2}$ 种填法。

如果第一个加减号在 $a_2, a_3$ 之间，所有的空有 $2 \times 3^{n-3}$ 种填法。

如果第一个加减号在 $a_3, a_4$ 之间，所有的空有 $2 \times 3^{n-4}$ 种填法。

……

如果第一个加减号在 $a_{n-1}, a_n$ 之间，所有的空有 $2 \times 3^{n-n} = 2$ 种填法。

如果没有加减号，有 1 种填法。

求和即为答案。

### 示例代码

```c
#include <stdio.h>

#define ll long long
ll p = 998244353;

ll pow3[200010];
ll a[200010];
int main()
{
    int n;
    scanf("%d", &n);
    for (int i = 1; i <= n; i++)
        scanf("%lld", &a[i]);
    pow3[0] = 1;
    for (int i = 1; i <= n; i++)
        pow3[i] = pow3[i - 1] * 3 % p;
    ll ans = 0, mul = 1;
    for (int i = 1; i <= n - 1; i++)
    {
        mul = mul * a[i] % p;
        ans += 2 * pow3[n - 1 - i] * mul % p;
    }
    mul = mul * a[n] % p;
    ans += mul;
    ans %= p;
    printf("%lld", ans);
    return 0;
}
```
