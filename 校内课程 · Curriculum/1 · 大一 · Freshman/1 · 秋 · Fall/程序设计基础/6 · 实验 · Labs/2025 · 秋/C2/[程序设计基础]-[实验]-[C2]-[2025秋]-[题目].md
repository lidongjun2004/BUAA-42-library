## A ("%d + %d = %d", a, b, sum)

### 题目

#### 题目描述

题目给出一段完整的 C 语言代码，要求你的程序把这段代码原样打印出来。代码中包含制表符缩进，以及 `\` 、 `"` 、 `%` 这些在字符串里需要转义的字符：打印一个反斜杠要写成 `\\` ，打印一个双引号要写成 `\"` ，打印一个百分号要写成 `%%` 。缩进用制表符或 4 个空格都可以。

#### 输入格式

无。

#### 输出格式

共 8 行，就是题目给出的那段 C 代码：第一行 `#include<stdio.h>` ，第二行 `int main() {` ，随后 6 行带一级缩进的语句，最后一行 `}` 。最后一行末尾不换行。

#### 样例输入

```text

```

#### 样例输出

```text
#include<stdio.h>
int main() {
    int a, b, sum;
    scanf("%d%d", &a, &b);
    sum = a + b;
    printf("%d + %%d = %%d", a, b, sum);
    return 0;
}
```

## B 泠涼的偏好 1

### 题目

#### 题目描述

泠涼只喜欢字母和数字。输入若干个整数，每个整数是某个字符的 ASCII 码。若该字符是字母或数字，输出一行 `Lingliang likes c!` ，其中 `c` 就是这个字符；否则输出一行 `Eww` 。输入一直读到文件结束。

#### 输入格式

若干个整数，表示字符的 ASCII 码，每行一个或用空格分隔，读到文件结束（EOF）为止。

#### 输出格式

每个输入的整数对应一行输出：字符是字母或数字时输出 `Lingliang likes c!` ，否则输出 `Eww` 。

#### 样例输入

```text
65 97 33
```

#### 样例输出

```text
Lingliang likes A!
Lingliang likes a!
Eww
```

## C 激光炮直瞄

#### 题目描述

## D 楼主别急，有反转！1

### 题目

#### 题目描述

读入 $n$ 个整数，把它们按输入顺序的相反顺序输出。

#### 输入格式

第一行一个整数 $n$ 。第二行 $n$ 个整数，用空格分隔。

## F Imitation Game

### 题目

#### 题目描述

一种加密方式把字母按下面的规则替换：把倒数第 $i$ 个小写字母转换成第 $i$ 个大写字母，把倒数第 $i$ 个大写字母转换成第 $i$ 个小写字母，非字母字符保持不变。现在给出用这种方式加密得到的密文，要求解密并输出原文。解密规则相应地为：第 $i$ 个小写字母转换成倒数第 $i$ 个大写字母，第 $i$ 个大写字母转换成倒数第 $i$ 个小写字母，其余字符原样输出。

#### 输入格式

一串字符，可能包含空格和换行，一直读到文件结束（EOF）为止。

#### 输出格式

解密后得到的字符串，按输入顺序输出，不额外添加换行。

#### 样例输入

```text
Hello, World!
```

#### 样例输出

```text
sVOOL, dLIOW!
```

## G JDK 的程设作业 ddl

### 题目

#### 题目描述

JDK 要在若干天的空闲时间里完成程设作业。先给出作业的预计用时，再给出 $n$ 天中每一天的空闲时段起止时刻。对每一天，先输出该天空闲时段的时长，再判断这段时间是否够完成作业：够则在同一行输出 `Yes!` ，不够则输出 `No~555~` 。时长一律按 `hh:mm:ss` 格式输出，不足两位补前导零。

#### 输入格式

第一行一个整数 $n$ 。第二行一个时刻 `hh:mm:ss` ，表示作业的预计用时。接下来 $n$ 行，每行两个时刻 `hh:mm:ss` ，分别表示当天空闲时段的起点和终点。

#### 输出格式

$n$ 行，每行形如 `hh:mm:ss Yes!` 或 `hh:mm:ss No~555~` ，时刻与判断结果之间用一个空格分隔。

#### 样例输入

```text
2
01:00:00
08:00:00 12:30:00
09:00:00 09:30:00
```

#### 样例输出

```text
04:30:00 Yes!
00:30:00 No~555~
```

## H 水库预测-version1

### 题目

#### 题目描述

水库的初始水位是 $h$ ，低水位预警线是 $p$ ，高水位预警线是 $q$ 。第 0 天水位按顺序变化 $n$ 次，第 $i$ 次的变化量为 $a_i$ ，于是第 0 天各时刻的水位依次是 $h + a_1$ 、 $h + a_1 + a_2$ 、……、 $h + \sum_{i=1}^{n} a_i$ 。此后的每一天，水位都按同样的规律变化，即每天同一时刻的水位比前一天同一时刻多出 $sum = \sum_{i=1}^{n} a_i$ 。只要某一时刻的水位不大于 $p$ 就触发低水位预警，不小于 $q$ 就触发高水位预警。请求出最早触发的预警类型：低水位预警输出 `down` ，高水位预警输出 `up` ，永远不会触发任何预警则输出 `No` 。注意即使 $sum > 0$ ，第 0 天也可能出现水位已经低于 $p$ 的情况，此时最早触发的是低水位预警。输入包含多组数据。

#### 输入格式

多组数据，读到文件结束为止。每组数据第一行是三个整数 $h$ 、 $p$ 、 $q$ ；第二行是一个整数 $n$ ；第三行是 $n$ 个整数 $a_1, a_2, \ldots, a_n$ 。

#### 输出格式

每组数据输出一行，为 `down` 、 `up` 或 `No` 之一。

#### 样例输入

```text
10 5 20
3
1 2 3
```

#### 样例输出

```text
up
```

#### 数据范围

水位、预警线与变化量之和都会超出 `int` 范围，需要用 `long long` 存储。

## I 逆序列还原全排列

### 题目

#### 题目描述

对于 $1$ 到 $n$ 的一个全排列，定义它的逆序列：逆序列的第 $k$ 个数表示在原排列中位于 $k$ 前面且比 $k$ 大的数的个数。现在给定一个逆序列，要求还原出对应的全排列。

#### 输入格式

第一行一个整数 $n$ 。第二行 $n$ 个整数，表示逆序列，用空格分隔。

#### 输出格式

一行 $n$ 个整数，表示还原得到的全排列，相邻两数之间用一个空格分隔。

#### 样例输入

```text
5
1 3 0 1 0
```

#### 样例输出

```text
3 1 5 4 2
```

#### 数据范围

$1 \le n \le 10^{4}$

## J 言叶的算式

### 题目

#### 题目描述

给定 $n$ 个数 $a_1, a_2, \ldots, a_n$ ，在相邻两数之间的 $n - 1$ 个空里各填入 $\times$ 、 $+$ 、 $-$ 三种运算符之一，共 $3^{n-1}$ 种填法。每种填法得到一个算式，按通常的优先级先乘后加减求值。求所有填法所得结果的总和，答案对 998244353 取模。

#### 输入格式

第一行一个整数 $n$ 。第二行 $n$ 个整数 $a_1, a_2, \ldots, a_n$ ，用空格分隔。

#### 输出格式

一行一个整数，表示所有填法的结果之和对 998244353 取模的值。

#### 样例输入

```text
3
1 2 3
```

#### 样例输出

```text
16
```
