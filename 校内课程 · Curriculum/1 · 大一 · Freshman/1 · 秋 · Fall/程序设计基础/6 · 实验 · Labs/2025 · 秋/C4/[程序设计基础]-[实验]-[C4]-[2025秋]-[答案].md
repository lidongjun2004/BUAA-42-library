## A 第几宇宙速度

| 难度 | 考点 |
| --- | --- |
| 1 | if else |

### 题目

#### 题目描述

物体从静止开始以加速度 $a$ 匀加速运动 $t$ 秒，末速度为 $at$ （单位 m/s）。已知第一宇宙速度为 7900 m/s，第二宇宙速度为 11200 m/s，第三宇宙速度为 16700 m/s。判断末速度达到了第几宇宙速度：小于 7900 输出 `<1` ；不小于 7900 且小于 11200 输出 `1` ；不小于 11200 且小于 16700 输出 `2` ；不小于 16700 输出 `3` 。多组数据，读到文件结束。

#### 输入格式

多组数据，每组一行两个整数 $a$ 和 $t$ ，用空格分隔，读到文件结束（EOF）为止。

#### 输出格式

每组输出一行，为 `<1` 、 `1` 、 `2` 、 `3` 之一。

#### 样例输入

```text
100 80
200 100
```

#### 样例输出

```text
1
3
```

### 答案

### 题目分析

速度 $=$ 初速度 $+$ 加速度 $\times$ 时间，本题初速度为 $0$，因此最终速度为 $at$，将这个结果与三个宇宙速度的边界进行比较即可。

### 示例代码

```c
#include <stdio.h>
int main(void)
{
    int a, t;
    while (scanf("%d%d", &a, &t) != EOF)
  {
        if (a * t < 7900)
            printf("<1\n");
        else if (a * t < 11200)
            printf("1\n");
        else if (a * t < 16700)
            printf("2\n");
        else
            printf("3\n");
  }
    return 0;
}
```

## B pi让你AC喜加一

| 难度 | 考点 |
| --- | --- |
| 1 | 循环控制 浮点数的计算 |

### 题目

#### 题目描述

用莱布尼茨级数计算 $\pi$ 的近似值： $\pi = 4 \times (1 - \frac{1}{3} + \frac{1}{5} - \frac{1}{7} + \cdots)$ 。读入 $n$ ，求该级数前 $n$ 项的部分和并输出。注意计算时要用浮点数除法，整数除法会截断小数部分。

#### 输入格式

一行一个整数 $n$ 。

#### 输出格式

一行一个实数，表示用前 $n$ 项算出的 $\pi$ 的近似值，保留小数点后 9 位。

#### 样例输入

```text
10
```

#### 样例输出

```text
3.041839619
```

### 答案

### 题目分析

题目思路不难，直接定义 `pi` 变量初始化为 $0$，然后依次累加莱布尼茨级数的每一项直到第 $n$ 项

但是常见的问题是很多同学会在写出 `pi += 1 / (2 * i + 1)` 这种代码，显然是不行的，在这里给大家简单总结一下计算时的 **隐式类型转换** 和 **显式类型转换**

1. `double pi = 1 / 3;`

   结果：`pi = 0.00`

   - `1` 和 `3` 都是整数，所以进行的是**整数除法**
   - 整数除法会截断小数部分，`1 / 3 = 0`
   - 然后将整数结果 `0` 转换为 `double` 类型 `0.0`

2. `double pi = 1.0 / 3;`

   结果：`pi = 0.33`

   - `1.0` 是 `double` 类型，`3` 是 `int` 类型
   - C语言会将 `3` 隐式转换为 `double` 类型
   - 然后进行**浮点数除法**，得到正确的结果

3. `double pi = 1 / (double)3;`

   结果：`pi = 0.33`

   - `(double)3` 将整数 `3` 显式转换为 `double` 类型
   - C语言会将 `1` 隐式转换为 `double` 类型
   - 然后进行**浮点数除法**

4. `double pi = (double)(1 / 3);`

   结果：`pi = 0.00`

   - 括号内的 `1 / 3` 先进行**整数除法**，得到 `0`
   - 然后将整数结果 `0` 转换为 `double` 类型

关键点：在C语言中，除法运算的结果类型由操作数的类型决定，而不是由赋值目标的类型决定。要得到正确的浮点数结果，至少需要有一个操作数是浮点类型。

### 示例代码

```c
#include <stdio.h>

int main()
{
    double pi, sign;
    int n;

    scanf("%d", &n);

    pi = 0;
    sign = 1.0;
    for(int i = 0; i < n; i ++)
  {
        pi += sign * (1.0  / (2.0 * i + 1.0)) * 4.0;
        sign *= -1;
  }

    printf("%.9lf\n", pi);

    return 0;
}
```

## C Retribution

| 难度 | 考点 |

| 1 | 双重循环 |

### 题目

#### 题目描述

给定 $n$ 和 $m$ ，输出一个 $n$ 行 $m$ 列的数表，其中第 $i$ 行第 $j$ 列的数为 $i \times j \times (i + j)$ 。

#### 输入格式

一行两个整数 $n$ 和 $m$ ，用空格分隔。

#### 输出格式

$n$ 行，每行 $m$ 个整数，相邻两数之间用一个空格分隔。

#### 样例输入

```text
2 3
```

#### 样例输出

```text
2 6 12
6 16 30
```

### 答案

### 题解

嵌套循环。

首先枚举行 $1 \le i \le n$，然后对于每一行来说， $i$ 便是定值。

然后枚举列 $1 \le j \le m$，然后对于每一列，输出值 $ij(i+j)$ 即可。

枚举列结束后，记得补上换行符。

此外，我们非常建议在循环嵌套时，使用大括号括起来循环语句的作用域。

以及，本题的循环次数是给定的。因为需要知道某次循环是进行的第几轮，我们非常建议使用 `for` 循环而不是 `while`，因为 `for` 更简洁。

让我们复习一下 `for` 循环的写法。

如果我们想让 $i$ 循环里取到 $[L,R]$ 中的每个整数，我们可以使用

```c
for(int i=L; i<=R; i++){
    // 在这里，i 会从 L 循环到 R。
}
// 一些其他的常用循环：
for(int i=R; i>=L; i--){
    // 在这里，i 会从 R 反向循环到 L。
    // R, R-1, ... , L+1, L
}
for(int i=1; i<=n; i++){
    // 在这里，i 会从 1 循环到 n。
    // 1, 2, ..., n-1, n
}
for(int i=0; i<n; i++){
    // 在这里，i 会从 0 循环到 n-1。
    // 0, 1, ..., n-2, n-1
}
for(int i=n; i>=1; i--){
    // 在这里，i 会从 n 反向循环到 1。
    // n, n-1, ..., 2, 1
}
for(int i=n-1; i>=0; i--){
    // 在这里，i 会从 n-1 反向循环到 0。
    // n-1, n-2, ... ,1, 0
    // 这种写法下，i 决不能是 unsigned 之类的无符号类型。这是因为当如果 i 是 unsigned int i=0 时，i-- 会把 i 变为 4294967295，因为无符号类型不能表示 -1，所以 i>=0 恒成立，死循环！
}
```

### 示例代码

```c
#include <stdio.h>

int main(){
    int n,m;
    scanf("%d%d",&n,&m);
    for(int i=1;i<=n;i++){
        for(int j=1;j<=m;j++){
            printf("%d ",i*j*(i+j));
        }
        printf("\n");
    }
    return 0;
}
```

若一个三位数能被它各位数字的立方和整除，就称它为扩展水仙花数。按从小到大的顺序输出所有三位数中的扩展水仙花数。

#### 输入格式

无。

#### 输出格式

每行一个三位数，按从小到大排列。

#### 样例输入

```text

```

#### 样例输出

```text
100
110
111
153
200
221
370
371
407
500
702
```

### 答案

### 题目分析

使用三个循环遍历三个数位，或是循环所有的三位数，分别拆出来三个数位判断均可。

### 示例代码 1

```c
#include <stdio.h>

int main() {
    for ( int i = 100; i <= 999; i++ ) {
        int sum = 0; // 使用 sum 计算所有数位的立方和
        for ( int x = i; x != 0; x /= 10 ) // i 作为循环变量，值不能变，因此用 x 计算
            sum += (x % 10) * (x % 10) * (x % 10);
        if ( i % sum == 0 ) // i 是扩展水仙花数
            printf("%d\n", i);
  }
    return 0;
}
```

### 示例代码 2

```c
#include <stdio.h>

int main() {
    for ( int i = 1; i <= 9; i++ ) // 最高位非 0
        for ( int j = 0; j <= 9; j++ )
            for ( int k = 0; k <= 9; k++ ) {
                int x = i * 100 + j * 10 + k;
                int sum = i * i * i + j * j * j + k * k * k;
                if ( x % sum == 0 )
                    printf("%d\n", x);
            }
    return 0;
}
```

## E Hakua 的怀表 1

| 2 | 日期 |

### 题目

#### 题目描述

给定一个日期和天数 $x$ ，求 $x$ 天之后是星期几。日期用八位整数按 `MMDDYYYY` 的格式给出，即先是两位月份，再是两位日期，最后是四位年份。可以先用蔡勒公式算出给定日期是星期几，再加上 $x$ 天对 7 取模。多组数据，读到文件结束。

#### 输入格式

多组数据，每组一行两个数：八位整数 `date` （格式 `MMDDYYYY` ）和整数 $x$ ，用空格分隔，读到文件结束（EOF）为止。

#### 输出格式

每组输出一行英文星期名，取值为 `Sunday` 、 `Monday` 、 `Tuesday` 、 `Wednesday` 、 `Thursday` 、 `Friday` 、 `Saturday` 之一。

#### 样例输入

```text
11252025 0
```

#### 样例输出

```text
Tuesday
```

### 答案

### 题目分析

本题要求计算一个给定日期 $x$ 天后是星期几。

需要注意的是，我们可以先计算出给定日期的星期数，再加上 $x$ 天，而不是先算出 $x$ 天后的日期，再计算星期数。

第 $1$ 步可以参考 P4 课件中的「例 $4-26$」，**注意日期格式的不同**；第 $2$ 步可以在第 $1$ 步的基础上 $+x$ 再对 $7$ 取模，最后输出结果。

### 示例代码

```c
#include<stdio.h>
int main() {
    int date, y, m, d, c;
    long long x, w;
    while(scanf("%d%lld", &date, &x) != EOF) {
        y = date % 10000;
        m = date / 1000000;
        d = date / 10000 % 100;
        if(m < 3) {
            y--;
            m += 12;
        }
        c = y / 100;
        y = y % 100;
        w = (c / 4 - 2 * c + y + y / 4 + 26 * (m + 1) / 10 + d - 1) % 7;
        if(w < 0)
            w += 7;
        w = (w + x) % 7;
        switch (w) {
            case 0:
                printf("Sunday\n");
                break;
            case 1:
                printf("Monday\n");
                break;
            case 2:
                printf("Tuesday\n");
                break;
            case 3:
                printf("Wednesday\n");
                break;
            case 4:
                printf("Thursday\n");
                break;
            case 5:
                printf("Friday\n");
                break;
            case 6:
                printf("Saturday\n");
                break;
        }
  }
    return 0;
}
```

## F The Chariot ~REVIIVAL~

| 难度 | 考点 |
| --- | --- |
| 3 | 数学，最大公因数 |

### 题目

#### 题目描述

多组数据。每组给出一个等差数列的项数 $n$ 、首项 $a_1$ 和公差 $d$ ，求这个等差数列所有项的最大公约数。

#### 输入格式

第一行一个整数 $t$ 。接下来 $t$ 行，每行三个整数 $n$ 、 $a_1$ 、 $d$ ，用空格分隔。

#### 输出格式

每组输出一行一个整数，表示该等差数列所有项的最大公约数。

#### 样例输入

```text
2
5 12 18
3 7 0
```

#### 样例输出

```text
6
7
```

### 答案

### 题解

注意到等差数列 $a_1, a_1 + d, a_1 + 2d, \cdots, a_1 + (n-1)d$ 所有项的最大公约数是 $\gcd(a_1, d)$，和项数无关！

也就是说， $n$ 根本没用，直接求 $a_1, d$ 的最大公约数即可。

这代表着，这个问题等价于每次输入三个数，把第一个数 $n$ 扔掉，直接求 $a_1, d$ 的最大公因数输出即可。

下证。

**引理.** $\forall n \ge 2, \gcd(a_1, a_1 + d, \cdots, a_1 + (n-1)d) = \gcd(a_1, d)$

设 $q = \gcd(a_1, d)$，则 $q \mid a_1, q \mid d$。

因此， $\forall a_i, a_i = a_1 + (i-1)d$，此时 $a_1$ 和 $d$ 都是 $q$ 的倍数， $i - 1$ 是整数，所以 $a_i$ 是 $q$ 的倍数。这说明 $q$ 是该等差数列的公因数。

现在用反证法证明 $q$ 是等差数列的最大公因数，即不存在 $r > q$ 使得 $r$ 是等差数列的公因数。

反证：假设存在这样的 $r$，那么 $r$ 是等差数列的公因数，就是等差数列所有项 $a_i$ 的因数，应该是 $a_1, a_2$ 的公因数。又有 $r > q$，这代表 $q$ 不是 $a_1, a_2 = a_1 + d$ 的最大公因数。矛盾！因此， $q$ 是等差数列的最大公因数。

### 示例代码

```c
#include <stdio.h>

int main() {
    int t;
    scanf("%d",&t);
    for(int k=1;k<=t;k++){
        int n,a1,d;
        scanf("%d%d%d",&n,&a1,&d);
        int a=a1,b=d;
        while(b!=0){
            int temp=a%b;
            a=b;
            b=temp;
        }
        printf("%d\n",a);
    }
    return 0;
}
```

## G Taco 的算点练习 1

| 难度 | 考点 |
| --- | --- |
| 2 | if else，阅读理解 |

### 题目

#### 题目描述

按番数 $h$ 、符数 $f$ 和附加点数 $t$ 计算总点数。先由 $h$ 和 $f$ 求出基本点 $y$ ：当 $h \le 5$ 时 $y = \min(f \times 2^{2+h}, 2000)$ ；当 $6 \le h \le 7$ 时 $y = 3000$ ；当 $8 \le h \le 10$ 时 $y = 4000$ ；当 $11 \le h \le 12$ 时 $y = 6000$ ；当 $h \ge 13$ 时 $y = 8000$ 。再令 $x = 4y$ ，最终总点数 $s = x + t$ 。

#### 输入格式

一行三个整数 $h$ 、 $f$ 、 $t$ ，用空格分隔。

#### 输出格式

一行一个整数 $s$ ，表示总点数。

#### 样例输入

```text
3 30 2
```

#### 样例输出

```text
3842
```

#### 数据范围

$s \le 10^{5}$ ，用 `int` 存储即可。

### 答案

### 题目分析

本题的关键在于正确计算单位点数 $y$。

$y$ 的计算方式是一个分段函数，具体取决于番数 $h$ 的值：

1. **当 $h \le 5$ 时**： 单位点数 $y$ 的计算公式为 $y = \min(f \cdot 2^{2+h}, 2000)$，其中 $2^{2+h}$ 的计算可以由 P3 学过的位运算 `1 << (2 + h)` 实现， $\min$ 的计算可以由 `if-else` 的分支结构实现。
2. **当 $h \ge 6$ 时**： 可以通过 `if-else if-...-else` 的分支结构实现。

同时可以证明 $s \le 10^5$，无需使用 `long long`。

### 示例代码

```c
#include<stdio.h>
int main() {
    int h, f, t, s, x, y;
    scanf("%d%d%d", &h, &f, &t);
    if (h <= 5) {
        y = f * (1 << (2 + h)); // 注意优先级
        if (y > 2000) { // 取 min
            y = 2000;
        }
    } else if (h <= 7) { // 6 <= h <= 7
        y = 3000;
    } else if (h <= 10) { // 8 <= h <= 10
        y = 4000;
    } else if (h <= 12) { // 11 <= h <= 12
        y = 6000;
    } else { // h >= 13
        y = 8000;
    }
    x = 4 * y;
    s = x + t;
    printf("%d", s);
    return 0;
}
```

## H 不讲‘5’的

| 难度 | 考点 |
| --- | --- |
| 4 | 进制转换，注意力 |

### 题目

#### 题目描述

有一种「不讲 5」的计数方式：可以使用的数字只有 0、1、2、3、4、6、7、8、9 共九个，数到 10 才向前进位。给定十进制整数 $n$ ，输出它在这种计数方式下的写法。多组数据，读到文件结束。

#### 输入格式

多组数据，每行一个整数 $n$ ，读到文件结束（EOF）为止。

#### 输出格式

每组输出一行，表示 $n$ 在「不讲 5」计数方式下的写法。

#### 样例输入

```text
5
100
```

#### 样例输出

```text
6
121
```

#### 数据范围

$n$ 需要用 `long long` 存储。

### 答案

### 题目分析

由于不讲‘5’的，因此可以使用的数字只有 {0, 1, 2, 3, 4, 6, 7, 8, 9} 九个，数到 10 的时候向前进位。

注意到这和九进制很像，不同之处仅在于九进制可以使用的九个数字是 {0, 1, 2, 3, 4, 5, 6, 7, 8}。因此本题变成了十进制转九进制的模板题，只不过当九进制数位是 {5, 6, 7, 8} 中的任何一个时，都需要将数位加一。

如果还没反应过来，那么可以这么思考：如果本题变成不讲‘9’的，那么本题就彻彻底底变成了进制转换模板题。而不讲‘5’的只不过是换了一个数字不讲，可以讲的数字仍然是9个。

### 示例代码 1

```c
#include <stdio.h>
#define ll long long

int main(void)
{
    ll n;
    while (scanf("%lld", &n) != EOF)
  {
        ll base = 1;
        ll ans = 0;
        while (n)
      {
            int c = n % 9;
            if (c < 5)
                ans += base * c; // 01234
            else
                ans += base * (c + 1); // 5678
            n /= 9;
            base *= 10;
            // 使用这种方式来存储进制转换后的数字仅仅是因为你们没学字符串或函数
            // ans 只是输出出来与九进制数相同，ans 不能理解为九进制数！计算机内没有九进制数也没有十进制数！只有二进制数！
      }
        printf("%lld\n", ans);
  }
    return 0;
}
```

### 示例代码 2

一种更优雅但是使用了超纲知识的进制转换方法

```c
#include <stdio.h>
#define ll long long

void write(ll n)
{
    if (n / 9)
        write(n / 9);
    int m = n % 9;
    if (m < 5)
        putchar('0' + m);
    else
        putchar('0' + m + 1);
}

int main(void)
{
    ll n;
    while (scanf("%lld", &n) != EOF)
  {
        write(n);
        putchar('\n');
  }
    return 0;
}
```

## I 可怜鼠鼠的k种状态

| 难度 | 考点 |

### 题目

#### 题目描述

有 $n$ 瓶液体，其中恰好一瓶是毒药。测试时间为 $m$ 分钟，可以动用若干只小鼠：把若干瓶液体混合后喂给一只小鼠，若混合液中含有毒药，这只小鼠会在第 1 到第 $m$ 分钟中的某一分钟死去，否则不会死。一次测试中每只小鼠有 $m + 1$ 种可能结果（ $m$ 种死亡时间加上不死）， $k$ 只小鼠一共能产生 $(m + 1)^k$ 种不同结果。要想一定能把毒药找出来，需要 $(m + 1)^k \ge n$ 。请求出满足条件的最小 $k$ 。当 $n = 1$ 时不需要任何小鼠，答案为 0。

#### 输入格式

一行两个整数 $n$ 和 $m$ ，用空格分隔。

#### 输出格式

一行一个整数，表示最少需要的小鼠数量 $k$ 。

#### 样例输入

```text
1000 9
```

#### 样例输出

```text
3
```

#### 数据范围

计算过程中 $(m + 1)^k$ 可能超出 `int` 范围，需要用 `long long` 存储。

### 答案

### 题目分析

首先从状态的角度进行分析：在液体数量 $n$、测试时间 $m$、小鼠数量 $k$ 都确定的情况下，最终可能产生多少种不同的结果（也即结果可能有多少种不同的状态）？

每只小鼠都有可能在第 $1, 2, \ldots m$ 分钟死去，那么一只小鼠在一次测试中可能有 $m$ 种不同的死亡时间，加上不死，一共 $m + 1$ 种情况。一共 $k$ 只小鼠，由于每只小鼠可以区分，将每只小鼠的死亡时间排列起来作为状态，那么最终可能有 $(m+1)^k$ 个不同的状态，这与液体数量无关。换言之，**在测试时间 $m$、小鼠数量 $k$ 都确定的情况下，一次测试可能产生 $(m+1)^k$ 种不同的结果**。如果可以将每种结果与哪一瓶液体是毒药**一一对应**，那么就可以找出毒药。并且，一次测试只可能产生 $(m+1)^k$ 种不同的结果，如果能一一对应，则我们已经利用了尽可能多的信息，所以若存在一个策略能一一对应，则这个策略一定是最佳策略。

理论存在，实践开始。我们不妨把上文中说到的 小鼠死亡时间的排列 写出来，假设 $m = 3, k = 5$，那么可能的排列就有： $11111, 11112, 11113, 11121, 11122, 11123, 11131, \ldots, 33333$。不难发现，这不就是4进制下从 $(11111)_4$ 数到 $(33333)_4$ 吗。更一般化分析：当 $m, k$ 确定时，小鼠的死亡时间排序 就是 $k$ 位 $m + 1$ 进制整数。 那么如果将每瓶液体按 $m + 1$ 进制进行编号，一种死亡时间序列就能对应一瓶液体。所以本题可以转化成 **求解** $\lceil \log_{m+1}^{n} \rceil$，( $\lceil \ \rceil$ 表示向上取整)。**到此即可完成代码的编写**。

那么策略具体怎么执行呢？

1. 首先将液体按 $m + 1$ 进制编号
2. 将所有编码中第 $i$ 位为 $1$ 的液体混合，喂给第 $i$ 只小鼠。
3. 将所有编码中第 $i$ 位为 $2$ 的液体混合，喂给第 $i$ 只小鼠。（若 $m + 1 \ge 2$）
4. 将所有编码中第 $i$ 位为 $3$ 的液体混合，喂给第 $i$ 只小鼠。（若 $m + 1 \ge 3$）

最终结果一定能按上述方法对应到一个液体编号。

### 示例代码

```c
#include<stdio.h>

int main() {
    int num, round;
    scanf("%d %d", &num, &round);
    if (num == 1) {
        printf("0");
    } else {
        long long stats = round + 1; //注意计算过程中 int 可能会溢出
        int ans = 1;
        while(stats < num) {
            stats *= (round + 1);
            ans++;
        }
        printf("%d", ans);
    }
    return 0;
}
```

## J Taco 的清一色练习 1

| 难度 | 考点 |
| --- | --- |
| 8 | 动态规划，状态压缩 |

### 题目

#### 题目描述

清一色麻将只有一种花色，点数从 1 到 $n$ ，每种点数不限制张数。给定 $3m + 1$ 张手牌，判断这副手牌听哪些牌：若再摸到一张点数为 $i$ 的牌之后，这 $3m + 2$ 张牌可以分解成 $m$ 个面子加 1 个对子，就称这副手牌听 $i$ 。其中面子指顺子（三张连续点数，如 $i, i+1, i+2$ ）或刻子（三张相同点数），对子指两张相同点数。按从小到大的顺序输出所有听的点数；若一个都不听，输出 `Noten` 。

#### 输入格式

第一行两个整数 $n$ 和 $m$ ，用空格分隔。第二行 $3m + 1$ 个整数，表示手牌的点数，用空格分隔。

#### 输出格式

一行，按从小到大的顺序输出所有听牌的点数，相邻两数之间用一个空格分隔；若不存在听牌则输出 `Noten` 。

#### 样例输入

```text
9 1
1 1 1 2
```

#### 样例输出

```text
2 3
```

### 答案

### 题目分析

本题的描述较为复杂，但其本质仅在传统麻将的基础上进行了牌面点数和张数的扩展。

我们补充「面子」的定义：「顺子」和「刻子」统称「面子」。

下面介绍一种使用动态规划，时间复杂度 $\mathcal{O}(n)$ 的解法，其核心思路是先预处理 $3m + 1$ 张手牌，最后分别考虑 $n$ 种牌是否为听牌。

定义 $3$ 个数组：

1. $buc$ 数组： $buc_i$ 维护第 $i$ 种牌的总张数；
2. $pref$ 数组： $pref_i$ 维护处理完 $1 \sim i$ 种牌后，手牌的可能状态；
3. $suff$ 数组： $suff_i$ 维护处理完 $i \sim n$ 种牌后，手牌的可能状态。

最后，我们通过枚举听牌 $i$，结合 $pref_{i-1}$ 和 $suff_{i+1}$，判断能否构成和牌牌型。

#### 状态定义

以 $pref$ 数组为例（ $suff$ 数组同理）， $pref_{i,j,k,w}$ 是一个布尔值，代表只考虑 $1$ 到 $i$ 这几种牌，能否将它们组合成若干个面子，并剩下：

- $j$ 个 $(i-1,i)$ 形式的搭子（需要一个 $i+1$ 来组成顺子），其中 $0 \le j \le 2$；
- $k$ 个单张 $i$（用于后面先组成搭子再组成顺子），其中 $0 \le k \le 2$；
- $w$ 个对子，其中 $0 \le w \le 1$。

> $0 \le j,k \le 2$ 的原因是如果 $j = 3$ 或 $k = 3$，它们自身就可以组成刻子。
>
> $0 \le w \le 1$ 的原因是要和牌只需要 $1$ 个对子。

也就是说，我们不关心能组成面子的部分，只关心不能组成面子的部分，而这些部分一共有 $3 \times 3 \times 2 = 18$ 种情况。

#### 状态转移

$pref_i$ 的状态是由 $pref_{i-1}$ 转移而来。假设我们已经知道了 $pref_{i-1}$ 的所有可能状态，现在我们加入第 $i$ 种牌（共 $buc_i$ 张）来计算 $pref_i$。

对于 $pref_{i-1,j,k,w}$ 这个为真的状态，它表示前 $i - 1$ 种牌处理完后，剩下 $j$ 个 $(i-2,i-1)$ 搭子和 $k$ 个单张 $i-1$。

现在我们用 $buc_i$ 张 $i$ 来处理这些遗留的牌：

1. 用 $j$ 张 $i$ 牌，与 $j$ 个 $(i-2,i-1)$ 搭子组合成完整的顺子 $(i-2,i-1,i)$。
2. 用 $k$ 张 $i$ 牌，与 $k$ 个单张 $i-1$ 组合成新的搭子 $(i-1,i)$。因此， $pref_i$ 状态中的新搭子数 $j'$ 就等于这里的 $k$。
3. 此时还剩下 $buc_i - j - k$ 张 $i$ 牌。这些牌除了组成若干个 $(i,i,i)$ 刻子外，还可能：
   - 留下 $(buc_i - j - k) \bmod 3$ 个单张。所以新的单张数 $k'$ 就是这个值，对子数量 $w' = w$ 不变。
   - 在 $w = 0$ 且剩下的 $i$ 牌至少有 $2$ 张时，可以选择组成 $(i,i)$ 对子。此时 $w'$ 变为 $1$，新的单张数 $k'$ 变为 $(buc_i - j - k - 2) \bmod 3$。

$suff$ 数组的转移逻辑与 $pref$ 类似，只是方向相反。

#### 判断听牌

最后，遍历所有可能的听牌 $i$（从 $1$ 到 $n$）：假设手牌里多了一张 $i$（即有 $buc_i + 1$ 张 $i$），寻找是否存在一个 $pref_{i-1,j_1,k,w_1}$ 状态和一个 $suff_{i+1,j_2,k,w_2}$ 状态（两者都为真），使得：

- 前缀部分的 $k$ 张 $i-1$ 单张和后缀部分的 $k$ 张 $i+1$ 单张与 $k$ 张 $i$ 组成 $(i-1,i,i+1)$ 顺子；
- 前缀部分的 $(i-2,i-1)$ 搭子和后缀部分的 $(i+1,i+2)$ 搭子分别与 $j_1, j_2$ 张 $i$ 组成顺子；
- 剩下的 $buc_i + 1 - j_1 - j_2 - k$ 张 $i$ 和 $w_1 + w_2 \le 1$ 个对子共同组成若干刻子和一个对子：
  1. $w_1 = w_2 = 0$ 时，对子由 $i$ 组成，组成对子后剩余的 $i$ 组成刻子，即 $buc_i + 1 - j_1 - j_2 - k \equiv 2 \pmod 3$；
  2. $w_1 + w_2 = 1$ 时，对子不由 $i$ 组成，剩余的 $i$ 全部组成刻子，即 $buc_i + 1 - j_1 - j_2 - k \equiv 0 \pmod 3$。

只要存在任何一种 $(j_1,j_2,k,w_1,w_2)$ 满足上述条件， $i$ 就是 $a$ 的一种听牌。

当然，由于我们没学过多维数组，我们可以通过压位把 $18$ 个布尔型存在一个整型里，并通过位运算进行操作。

### 示例代码

```c
#include<stdio.h>
#define rep(i, h, t) for(int i = (h); i <= (t); ++i)
#define dep(i, t, h) for(int i = (t); i >= (h); --i)
#define MAXN 100008
int N, M;
int buc[MAXN]; // buc[i] 记录第 i 种牌的张数
int pref[MAXN], suff[MAXN];
#define off(j, k, w) ((j) * 6 + (k) * 2 + (w))
// dp(pref, i, j, k, w) 维护前 i 种牌中能否实现除去 0<=j<=2 个 (i-1,i) 两面搭子、0<=k<=2 个 i 单张、0<=w<=1 个对子其余全是面子
#define dp(arr, i, j, k, w) (arr[i] >> off(j, k, w) & 1)
// upd(arr, i1, j1, k1, w1, i2, j2, k2, w2) 实现 arr(i1, j1, k1, w1) |= arr(i2, j2, k2, w2)
#define upd(arr, i1, j1, k1, w1, i2, j2, k2, w2)\
arr[i1] |= (arr[i2] >> off(j2, k2, w2) & 1) << off(j1, k1, w1)
signed main(void) {
    scanf("%d%d", &N, &M);
    int x;
    rep(i, 1, 3 * M + 1) {
        scanf("%d", &x);
        ++buc[x];
  }
    pref[0] = 1;
    rep(i, 1, N) // pref[i] 从 pref[i-1] 转移而来
        for(int j = 0; j <= 2 && j <= buc[i]; ++j) // 所有 (i-2,i-1) 的两面搭子都要与 i 组成顺子
            for(int k = 0; k <= 2 && j + k <= buc[i]; ++k) { // 所有单张 i-1 都要与 i 组成两面搭子
                rep(w, 0, 1) // 不考虑 i 组成新的对子
                    upd(pref, i, k, (buc[i] - j - k) % 3, w, i - 1, j, k, w); // 原本的单张 i-1 数变成了两面搭子 (i-1,i) 数，剩余的除了组成刻子均视为单张
                if(buc[i] - j - k >= 2) // 若 i 能组成新的对子
                    upd(pref, i, k, (buc[i] - j - k - 2) % 3, 1, i - 1, j, k, 0); // 同理，多了个对子
            }
    suff[N + 1] = 1;
    dep(i, N, 1)
        for(int j = 0; j <= 2 && j <= buc[i]; ++j)
            for(int k = 0; k <= 2 && j + k <= buc[i]; ++k) {
                rep(w, 0, 1)
                    upd(suff, i, k, (buc[i] - j - k) % 3, w, i + 1, j, k, w);
                if(buc[i] - j - k >= 2)
                    upd(suff, i, k, (buc[i] - j - k - 2) % 3, 1, i + 1, j, k, 0);
            }
    int cnt = 0;
    for(int i = 1, flag = 1; i <= N; ++i, flag = 1) // 枚举听牌，flag 记录是否已和牌
        for(int j1 = 0; j1 <= 2 && j1 <= buc[i] + 1 && flag; ++j1) // 所有 (i-2,i-1) 的两面搭子都需要与 i 组成顺子
            for(int j2 = 0; j2 <= 2 && j1 + j2 <= buc[i] + 1 && flag; ++j2) // 所有 (i+1,i+2) 的两面搭子都需要与 i 组成顺子
                for(int k = 0; k <= 2 && j1 + j2 + k <= buc[i] + 1 && flag; ++k) { // 所有 i-1,i+1 的单张（数量必须相同）组成的坎张搭子都需要与 i 组成顺子
                    if(dp(pref, i - 1, j1, k, 0) && dp(suff, i + 1, j2, k, 0) && (buc[i] + 1 - j1 - j2 - k) % 3 == 2) { // 对子为 i
                        flag = 0;
                        ++cnt;
                        printf("%d ", i);
                        break;
                    }
                    rep(w, 0, 1) // 对子不为 i
                        if(dp(pref, i - 1, j1, k, w) && dp(suff, i + 1, j2, k, w ^ 1) && (buc[i] + 1 - j1 - j2 - k) % 3 == 0) {
                            flag = 0;
                            ++cnt;
                            printf("%d ", i);
                            break;
                        }
                }
    if(!cnt)
        return printf("Noten"), 0;
}
```
