## A 2jogger1 的三角形

### 题目描述

三角形是最简洁的几何形状，在建筑学等领域有着重要的应用。现在已知一个三角形的三边长度都是正整数，其中两边长度分别为 $a, b$ ，那么 2jogger1 想要知道第三边长度的可能取值有多少种？

第一行，一个正整数 $T$ 表示数据的组数，保证 $1 \le T \le 10^5$ 。

接下来的 $T$ 行，每行包含两个由空格隔开的正整数 $a, b$ ，保证 $1 \le a, b \le 10^5$ 。

### 输出

$T$ 行，每行一个正整数，表示每组中第三边长度可能取值的个数。

### 输入样例

```text
2
2 4
1 1
```

### 输出样例

```text
3
1
```

### 样例解释

第一组样例中第三边的可能取值为：3, 4, 5。

第二组样例中第三边的可能取值为：1。

## C chaos.exe

### 题目背景

`Norma` 正在为邦布们编写程序！但是她遇到了一些困难，具体地，她有一个递归调用的函数解决不了了，为了防止她写出无限递归导致逻辑芯片爆炸被 `Velina` 抓去关禁闭，你能帮帮她吗？

### 题目描述

给定两个函数 $f(n), n$ 是非负整数，和 $g(k,x), k \in \{0, 1, 2\}, x$ 是非负实数，其中

$$f(n) = \begin{cases} \cos\left(\dfrac{\sqrt{2}}{2}\right), & n \le 1 \\ f\left(\left\lfloor\dfrac{n}{2}\right\rfloor\right) + g(n \bmod 3,\ \sqrt{n}) + \sqrt{\pi}, & n > 1 \end{cases}$$

$$g(k,x) = \begin{cases} \mathrm{e}^k, & x < 2 \\ \lfloor x \rfloor + g\left(k \bmod 3 + 1,\ \dfrac{x}{2}\right) + f(\lfloor x \rfloor), & x \ge 2 \end{cases}$$

式中 $\lfloor x \rfloor$ 表示对实数 $x$ 向下取整， $a \bmod b$ 表示整数取模运算， $\mathrm{e}$ 是自然对数的底。

我们希望求出 $f(n)$ 的值。特别地，好心的出题人为你提供了这两个函数的**正确**实现：

```c
double f(int n) {
    if (n <= 1) return cos(pow(0.5, 0.5));
    return f(n / 2) + g(n % 3, sqrt(n)) + tgamma(0.5);
}
double g(int k, double x) {
    if (x < 2) return exp(k);
    return (int)x + g(k % 3 + 1, x / 2) + f(x);
}
```

> 温馨提示：你应该复制上面的代码，并在程序中调用 `<math.h>` 库。

### 输入

一行一个整数 $n$ ，其中 $0 \le n \le 10^9$ 。

### 输出

一行一个小数 $f(n)$ ，保留 8 位小数。

### 样例输入 1

```text
5
```

### 样例输出 1

```text
43.70149987
```

### 样例输入 2

```text
100
```

### 样例输出 2

```text
290.59896342
```

### 样例输入 3

```text
1000000000
```

### 样例输出 3

```text
325799.83074881
```

## G longlong 山小妖怪

### 题目背景

`muzermat` 正在看《浪浪山小妖怪》。

电影《浪浪山小妖怪》由北航教师执导和编剧，该片的创作全程有大量北航毕业生和师生参与。

同时，这部电影也深受大家喜爱，该片的爆火与成功，被北航官方视为其推进「精品文科发展策略」的代表性成果之一。

### 题目描述

`longlong` 山的大王交给了你一个任务：统计一份物品清单中的馒头总数。

一组物品有以下两种形式：

1. 一组馒头，共有若干个。
2. 一个包裹，里面有 $k$ 种物品，每种物品各有 $m$ 组，共有 $m \times k$ 组物品。内部物品也可以是馒头或包裹。

现在给定一个物品清单，求这个物品清单完全展开后，总共有多少个馒头。

### 输入

第一行输入一个正整数 $n$ ，表示清单最外层共有 $n$ 组物品， $1 \le n \le 10$ 。

接下来依次输入 $n$ 组物品的描述。一组物品描述的输入格式为：

先输入一行两个用空格分隔的整数 $m$ 和 $k$ ， $0 \le m \le 2$ ， $1 \le k \le 10$ 。

- 若 $m = 0$ ，表示这个物品是一组 $k$ 个馒头，该物品的输入到此结束。
- 若 $m > 0$ ，表示这个物品是装有 $m \times k$ 组物品的包裹，其中不同的物品有 $k$ 种，每种物品都有 $m$ 组。接下来按照一组物品描述的输入格式，依次输入这 $k$ 种物品的完整描述。

保证所有物品的描述总共不超过 60 行。

**如果你没有看懂，可以参考输入样例1的详细解释。**

### 输出

输出一行，一个整数，表示清单包含的馒头总数。

### 输入样例1

```text
2
2 2
2 1
0 5
0 2
0 3
```

### 输出样例1

```text
27
```

### 输入样例2

```text
1
0 7
```

### 输出样例2

```text
7
```

### 样例解释

样例 1：

第一行的 `2` 表示清单最外层有两组物品。按输入顺序，它们的结构如下。其中，「每种各 2 组」表示包裹内列出的每一种物品都要计算两组。

```text
清单
|- 第 1 组：包裹（2 2：2 种内部物品，每种各 2 组）
|  |- 第 1 种：包裹（2 1：1 种内部物品，共 2 组）
|  |  |- 第 1 种：一组 5 个馒头（0 5）
|  |- 第 2 种：一组 2 个馒头（0 2）
|- 第 2 组：一组 3 个馒头（0 3）
```

从最内层向外计算：

1. `0 5` 表示一组 5 个馒头。它外面的 `2 1` 表示这样的馒头组有 2 组，因此这个内层包裹共有 $2 \times 5 = 10$ 个馒头。
2. `2 2` 表示外层包裹里有两种物品，每种各 2 组：第一种是刚才的内层包裹，每个含 10 个馒头；第二种是 `0 2` 表示的馒头组，每组含 2 个馒头。因此外层包裹共有 $2 \times 10 + 2 \times 2 = 24$ 个馒头。
3. 最后的 `0 3` 是清单最外层的第 2 组物品，不在前面的包裹中，含有 3 个馒头。

因此，整份清单共有 $24 + 3 = 27$ 个馒头，输出 `27` 。

样例 2：清单中只有一组馒头，共有 7 个，输出 `7` 。

## I δ

### 题目描述

对于一个函数 $f : \mathbb{N} \to \mathbb{R}$ ，我们这样定义它的**差分** $\Delta f$ ：

$$\Delta f(n) = f(n + 1) - f(n)$$

比如， $\Delta(n) = 1$ ， $\Delta(n(n-1)(n-2)) = 3n(n-1)$ 。

若函数 $F$ 满足 $f = \Delta F$ ，那么我们称 $F$ 是 $f$ 的一个**不定求和**，记做：

$$F(n) = \sum f(n)\,\delta n$$

容易发现，不定求和满足下面的性质：

$$\sum_{n=a}^{b-1} f(n) = F(b) - F(a)$$

现在给定 $m$ 个整数 $c_0, c_1, \ldots, c_{m-1}$ 以及正整数 $N$ ，记 $n^{\underline{k}} = n(n-1)\cdots(n-k+1)$ （特别地 $n^{\underline{0}} = 1$ ），定义

$$h(n) = \sum_{k=0}^{m-1} c_k n^{\underline{k}}$$

求 $\sum_{n=0}^{N-1} h(n)$ 对 $10^9 + 7$ 取模的值。

> 提示：不妨考虑一下， $n^{\underline{k}}$ 的差分是什么，不定求和是什么？

### 输入格式

**本题包含多组测试数据。**第一行一个正整数 $T$ 表示测试数据组数。

对于每组数据：

第一行两个整数 $m, N$ （ $1 \le m \le 2000$ ， $1 \le N < 10^9 + 7$ ）。

第二行 $m$ 个整数 $c_0, c_1, \ldots, c_{m-1}$ （ $0 \le c_i < 10^9 + 7$ ）。

保证每个测试点都有 $\sum m^2 \le 10^7$ 。

### 输出格式

对于每组数据，输出一行一个整数表示答案。

### 输入样例

```text
8
1 5
3
3 4
1 2 3
4 1
7 8 9 10
4 2
0 1 2 3
4 4
0 0 0 1
4 3
0 0 0 1
2 40000
0 1
4 1000000006
1 2 3 4
```

### 输出样例

```text
15
40
7
1
6
0
799980000
19
```

### 样例解释

第一组数据中， $h(n) = 3$ ，共有 5 项，总和为 15。

第二组数据中， $h(n) = 1 + 2n + 3n(n-1)$ ， $h(0), h(1), h(2), h(3)$ 分别为 1, 3, 11, 25，总和为 40。注意求和不包含 $h(4)$ 。

第三组数据只计算 $h(0)$ 。由于 $0^{\underline{0}} = 1$ ，其余各项均为零，答案为 7。

第四组数据中， $n$ 只取 0, 1，所有次数至少为 2 的下降阶乘都为零，因此答案为 1。

第五、六组数据均有 $h(n) = n(n-1)(n-2)$ 。第五组包含 $h(3) = 6$ ，答案为 6；第六组只计算 $h(0), h(1), h(2)$ ，答案为 0。

### 题目描述

ChaoGDP 是一款能预测未来的 AI，它是一个基于历史上下文的生成模型，包含了 $m$ 个参数，记作 $c_1, c_2, \ldots, c_m$ 。它会生成一个序列 $a_0, a_1, \ldots$ ，其中第 $n$ 个元素基于它的前面 $m$ 个元素生成：将前面第一个序列元素乘 $c_1$ 、第二个元素乘 $c_2$ 、……以此类推，然后将这些乘积求和，再对 998244353 取模，得到 $a_n$ 的值。形式化地：

$$a_n = \left(\sum_{k=1}^{m} c_k a_{n-k}\right) \bmod 998244353$$

现在，ChaoGDP 的参数和初始上下文 $a_0, a_1, \ldots, a_{m-1}$ 已经给出，小 A 想要通过算出 $a_L, a_{L+1}, \ldots, a_{R-1}$ 的值来预测未来，请你帮助他吧。

第三行 $m$ 个整数 $c_1, c_2, \ldots, c_m$ （ $0 \le c_i < 998244353$ ）。

保证对于一个测试点的所有测试数据，有 $\sum m, \sum (R - L) \le 2 \times 10^5$ 。

### 输出格式

对于每组数据，输出一行 $R - L$ 个整数，表示答案 $a_L, a_{L+1}, \ldots, a_{R-1}$ 对 998244353 取模的值。
