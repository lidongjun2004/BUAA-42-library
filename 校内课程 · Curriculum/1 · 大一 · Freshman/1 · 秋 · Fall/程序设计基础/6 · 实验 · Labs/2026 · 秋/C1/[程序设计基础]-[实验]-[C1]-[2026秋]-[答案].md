### 题目

#### 题目描述

Hello, World! 问题和 A+B 问题被誉为所有程序员的“第一个程序”。几乎所有接触过编程的人所编写的第一个程序，要么是 Hello, World!，要么是 A+B。今天，就让我们以一道 Hello, World! 问题，开启人生的第一段程序。

#### 输入格式

本题没有输入。

#### 输出格式

输出一行，Hello, World!，注意所有字符均为英文半角字符。

#### 输出样例

```text
Hello, World!
```

#### Hint

不必在意行末多余的空格和文件末尾多余的换行，它们都会被评测机忽略。

### 答案

### 题目分析

欢迎同学们走进 C 语言程序设计的世界！

这是课件上的一道例题，不过直接复制课件上的代码是不能通过的。原因是，课件上的代码输出的是 `hello, world`，全是小写，且没有最后的感叹号。

同学们可能会问，这不一个意思嘛？凭什么判我错？

这涉及到 C 语言程序的判别程序。判别程序检查同学们答案的正确与否是一个很机械的过程。准确的说，就是从文件的开头到文件的结尾逐个字符检查是否是一样：如果你的输出和答案文件每个字符都是相同的，那么我们认为你的程序是正确的；只要有一个字符不同，就认为你的答案是错误的。这是最基础的判别程序，但也是目前最常用的判别程序。这种检测手法我们称为黑箱测试：我们不检查你程序究竟怎么写的，只管你输出的结果对不对。程序写得再好，输出不对，就是 0 分；程序写得再一言难尽，输出正确，就是满分。

因此，大小写错误，格式错误，在这门课上，都是 0 分。请一定严格按照输出格式的要求输出你的答案。除非题目特别强调，答案可以不区分大小写。

另外一个新入门的同学常犯的错误就是，输出了中文全角字符。比如，如果你的输出是 `Hello, World！` 或者 `Hello， World!`，那么也会被认为是错误的。在 C 语言的世界里，几乎不会出现中文！所有的符号，都是在英文输入法下输入的半角字符。

### 示例代码

```c
#include <stdio.h>
int main(){
    printf("Hello, World!");
    return 0;
}
```

注意，以下程序也是正确的。

```c
#include <stdio.h>
int main(){
    printf("Hello, World!\n");
    return 0;
}
```

或者

```c
#include <stdio.h>
int main(){
    printf("Hello, World!           ");
    return 0;
}
```

在主流评测平台上，行末多余的空格和文件末尾多余的换行可以被自动忽略。因此，输出最后一行有没有多余的换行，以及每一行末尾是否多余一些空格，这不重要。但是，不建议你像最后那个程序那样，没事干输出这么多多余的空格。

### 答案

### 题目分析

> 本题改编自课件中的「例 1 − 4」。

本题作为大家遇到的第一道有输入的题目，主要考察的是大家对整数的输入输出。

我们在使用 `scanf` / `printf` 时，格式字符串里可以使用转换说明符 `%d` 实现对整数的输入输出。

应当注意的是，使用 `scanf` 输入时，变量前应有字符 `&`。

特别地，对于第一次接触程序设计的同学，我们还提出以下几点：

- 代码中的变量名可以不与题目相同，但与题目相同可以降低理解成本；
  - 例如本题中，`int w, c;` 比 `int a, b;` 更优。
- 位于输入部分的数据范围 / 限制由出题人保证，同学们无需在代码里进行显式地检查；
- 出题人有时会撰写部分提示并放在题面最后的提示 / Hint 部分，请同学们务必不要遗漏。

### 代码示例

```c
#include<stdio.h>
int main() {
    int w, c;
    scanf("%d%d", &w, &c); // 不要忘了 `&` ！
    int p = c / w;
    printf("The price of melon is %d yuan per jin.", p);
    // 也可以直接写: printf("The price of melon is %d yuan per jin.", c / w);
}
```

## C 奇数还是偶数

| 难度 | 考点 |

### 题目

#### 题目描述

给定一个整数 n，请判断它是奇数还是偶数。
如果 n 是偶数，输出 Even；否则输出 Odd。
Hint：如果你不知道如何判断是奇数还是偶数，试着看一下 n 除以 2 的余数有什么规律。

#### 输入格式

输入一行，包含一个整数 n（0 ≤ n ≤ $10^9$）。

#### 输出格式

如果 n 是偶数，输出：Even
否则输出：Odd。
建议大家对这种输出字符串的题目直接复制粘贴，避免出现诸如 YE5、N0、ERR0R 之类的情况。

#### 输入样例 1

```text
13
```

#### 输出样例 1

```text
Odd
```

#### 输入样例 2

```text
100
```

#### 输出样例 2

```text
Even
```

### 答案

### 题目分析

一个整数是否为偶数，只需要判断它除以 2 的余数是否为 0。

如果 $n \bmod 2 = 0$，那么 $n$ 是偶数，输出 `Even`。

否则 $n$ 是奇数，输出 `Odd`。

### 代码示例

```c
#include <stdio.h>
int main() {
    int n;
    scanf("%d", &n);
    if (n % 2 == 0) {
        printf("Even\n");
    } else {
        printf("Odd\n");
    }
    return 0;
}
```

## F 空城计

### 题目

#### 题目描述

小明班长正在统筹晚会，他统计了所有人的到场情况。到场人数有 a、b 两种可能。由于小明十分懒惰，他打算买物料的时候直接一次买够，这样就能避免大家不够分。同时，小明为了不超支班费，只愿意支付 a、b 的最小公倍数的数目。最后，小明会启动紧急预案，如果有可能所有人都不来，他就会上演空城计，什么都不会买。

#### 输入

一行，两个由空格分隔的非负整数 a 和 b，满足 0 ≤ a, b ≤ $10^4$，分别表示两种可能的到场人数。

#### 输出

一行，一个整数，表示小明需要买的物料数目。

#### 输入样例 1

```text
12
18
```

#### 输出样例 1

```text
36
```

#### 输入样例 2

```text
100
0
```

#### 输出样例 2

```text
0
```

#### 输入样例 3

```text
325 799
```

#### 输出样例 3

```text
259675
```

#### 样例解释

样例 1：36 是能同时被 12 和 18 整除的最小正整数，因此答案是 36。

Author:LH132

### 答案

### 题目分析

最小公倍数可以用最大公约数来求： $\mathrm{lcm}(a,b) = a \div \gcd(a,b) \times b$

最大公约数直接暴力枚举。公约数不可能比 $a$ 和 $b$ 中较小的那个还大，所以枚举到 $\min(a,b)$ 就够了，最后一个能同时整除 $a$ 和 $b$ 的数就是最大公约数。

本题中需要注意的有以下几点：

1. $a$ 或 $b$ 为 0 时答案是 0，不是另一个数。0 的倍数只有 0 自己，所以 $\mathrm{lcm}(0,7) = 0$。`0 7`、`7 0`、`0 0` 三种输入都要判，`if (a == 0 && b == 0)` 是错的。
2. 枚举范围是 `i <= m`，不是 `i < m`。输入 `8 24` 时 $\gcd = 8$，写成 `<` 会漏掉 8，gcd 只拿到 4，答案错求为 48。
3. 写 `a / g * b`，不要写 `a * b / g`。本题 $a \times b \le 10^8$ 不会溢出，但保证整除的时候，先除后乘是好习惯，数变大了也不会出事。
4. 输出只有一个整数，用 `%d`。多打任何其它提示文字是 0 分。

### 代码示例

```c
#include <stdio.h>
int main() {
    int a, b;
    scanf("%d %d", &a, &b);
    // 有 0 就什么都不买
    if (a == 0 || b == 0) {
        printf("0\n");
        return 0;
    }
    // 暴力求 gcd，公约数不会超过 min(a, b)
    int m = a;
    if (b < m) {
        m = b;
    }
    int g = 1;
    for (int i = 1; i <= m; i++) {
        if (a % i == 0 && b % i == 0) {
            g = i;
        }
    }
    // lcm = a / gcd * b
    printf("%d\n", a / g * b);
    return 0;
}
```

#### 提示

本题与课件上的例题 1-8 不同的地方在于本题是定组输入，即会在输入的开头首先给出数列长度 n。可以注意到，每经过一项，符号位会变成其相反数。因此，可以定义一个变量，它的初值是 1，每经过一个循环就让它乘上 -1。这样我们直接让 ai 乘以这个变量就可以知道 (-1)n-1 的值。

一个可能的实现如下。（如果你实在没思路再看，这只是一个推荐思路，不代表你必须按照这个写题）

定义整数变量 剩余项数，累加和=0，当前符号=1 输入整数 剩余项数 如果剩余项数不为零则重复执行

定义整数变量 当前项 输入整数 当前项 累加和 加上（当前项 乘以 当前符号） 当前符号 乘以负一

剩余项数 减一 输出 累加和

Author: Windowsredstone

#### 输入

第一行一个正整数，表示序列长度 n。
接下来 n 行，第 i 个数表示一个整数表示 ai。数据保证 1≤ n ≤ 5000,|ai|≤ 5000。

#### 输出

输出一行一个整数表示答案的值。

#### 输入样例

```text
6
3
2
5
7
9
9
```

#### 输出样例

```text
-1
```

#### 样例解释

3-2+5-7+9-9=-1

### 答案

### 题目分析

可以注意到，每经过一项，符号位会变成其相反数。因此，可以定义一个变量，它的初值是 `1`，每经过一个循环就让它乘上 `-1`。这样我们直接让 $a_i$ 乘以这个变量就可以知道 $(-1)^{n-1}$ 的值。

大致的流程如下：

```text
定义整数变量 剩余项数，累加和=0，当前符号=1
输入整数 剩余项数
如果剩余项数不为零则重复执行
    定义整数变量 当前项
    输入整数 当前项
    累加和 加上（当前项 乘以 当前符号）
    当前符号 乘以负一
    剩余项数 减一
输出 累加和
```

### 示例代码

```c
#include <stdio.h>
int main() {
    int n, sum = 0, sign = 1;
    scanf("%d", &n);
    while (n != 0) {
        int ai;
        scanf("%d", &ai);
        sum += sign * ai;
        sign *= -1;
        n--;
    }
    printf("%d\n", sum);
    return 0;
}
```

#### 样例解释

样例 1：从初始时刻开始，各时刻的积分依次为 1800、1818、1806、1831、1823、1813，最高为 1831。样例 2：积分一直下降，最高值为开始记录前的 1800 分。样例 3：积分始终保持为 2000。

#### Hint

求一系列数的最大值时，可以用一个变量保存「目前见过的最大值」：先把它设为第一个数，再依次查看后面的数。如果新看到的数比它大，就更新这个变量；否则保持不变。查看完所有数后，这个变量保存的就是最大值。在本题中，可以分别用两个变量保存「当前积分」和「最高积分」，初始时都设为 s。每场结束后，先将当前积分加上本场的变化量，再与最高积分比较，必要时更新最高积分。注意，比较的是每场结束后的积分，而不是本场的积分变化量；记录开始前的积分也要计入最高值。

Author: muzermat

### 答案

### 题目分析

需要分别保存当前积分和已经达到过的最高积分。一次加分后可能创造新高，后续扣分又可能使积分下降，因此不能直接输出最后一场结束后的积分，也不能只找到最大的单场加分。

令 `score` 表示当前积分，初始为输入的 $s$；令 `ans` 表示最高积分，初始也为 $s$。每读入一个变化量 $d$，先执行 `score += d`，再在 `score > ans` 时更新 `ans`。负数变化量会自动完成扣分，不需要单独判断胜负。

处理完前 $i$ 条记录后，`score` 等于此时的积分，`ans` 等于初始时刻及前 $i$ 场结束时的最高积分。初始状态满足这个性质；每处理一条记录，更新当前积分并比较最大值后，仍然满足这个性质。因此，所有记录处理完后，`ans` 就是所求答案。

最高值可能出现在记录开始前。所有变化量都为负数时，答案就是 $s$，因此不能把 `ans` 初始化为 0。变化量为 0 时积分不变；重复达到同一最高分不会影响答案。

每条记录读入后即可处理，只需要保存当前值和最大值，不需要数组。 $n \le 1000$， $s \le 3000$，每场最多增加 100 分，所以任何时刻的积分都不超过 $3000 + 1000 \times 100 = 103000$，使用 `int` 足够。

### 示例代码

```c
#include <stdio.h>
int main() {
    int n, score;
    scanf("%d%d", &n, &score);
    int ans = score;
    for (int i = 0; i < n; i++) {
        int d;
        scanf("%d", &d);
        score += d;
        if (score > ans) {
            ans = score;
        }
    }
    printf("%d\n", ans);
    return 0;
}
```

## I 多边形判定

| 难度 | 考点 |
| --- | --- |
| 4 | 循环、求最大值、条件判断 |

### 题目

#### 题目描述

给定 n 条线段的长度，判断这些线段能否首尾相接组成一个 n 边形。

#### 输入

第一行，一个整数 n，满足 3≤n≤1000。
第二行，n 个正整数 a1,a2,...,an，表示 n 条线段的长度，满足 1≤ai≤1000。

#### 输出

如果这些线段能够组成一个 n 边形，输出 YES；否则输出 NO。

#### 输入样例 1

```text
5
2
3
4
5
6
```

#### 输出样例 1

```text
YES
```

#### 输入样例 2

```text
4
1
2
3
6
```

#### 输出样例 2

```text
NO
```

#### 样例解释

样例 1 中，最长边为 6，其余线段长度之和为 14，因此可以组成多边形。
样例 2 中，最长边为 6，其余线段长度之和为 6。这些线段最多只能排成一条直线，不能组成非退化多边形。

#### Hint

可以在读入过程中计算所有边长之和与最长边的长度。

Author:auining

### 答案

### 题目分析

设所有边长的总和为 `sum`，最长边的长度为 `max`。

对于一组线段，能够组成非退化多边形，当且仅当最长边小于其余所有边长之和，也就是 `max < sum - max`。

读入每条边时，同时更新 `sum` 和 `max`，最后根据这个条件输出结果。

### 示例代码

```c
#include <stdio.h>
int main()
{
    int n;
    scanf("%d", &n);
    int max = 0, sum = 0;
    for (int i = 1; i <= n; i++)
    {
        int x;
        scanf("%d", &x);
        sum += x;                   // 更新sum的值
        if (x > max) {
            max = x;                // 更新max的值
        }
    }
    if (max * 2 >= sum)             // 答案条件判断
        printf("NO\n");
    else
        printf("YES\n");
}
```

## J 是梦

| 难度 | 考点 |
| --- | --- |
| 5 | 数学 |

### 题目

#### 题目背景

有这样一道题：求 $\sum\limits_{i=0}^{n} f(i/n)$，其中 $f(x)=\dfrac{4x+2}{4x+2}$。泠涼只花了 0.01 s 就看出了 $f(x)\equiv 1$，答案是 $n+1$。结果提交上去喜提 0 分，仔细一看原来是题目读错了，应该是 $f(x)=\dfrac{4^{x+2}}{4^{x}+2}$。大家，一定要认真读题呀！

#### 题目描述

求 $\sum\limits_{i=0}^{n} f(i/n)$，其中 $f(x)=\dfrac{4^{x+2}}{4^{x}+2}$。

#### 输入

一个正整数 n，其中 1≤ n≤ $2.5 \times 10^8$。

#### 输出

一行一个数，表示所求。保证所求为正整数。

#### 样例输入

```text
2
```

#### 样例输出

```text
24
```

#### 样例解释

$f(0)=\dfrac{4^{0+2}}{4^0+2}=16/3$， $f(1/2)=\dfrac{4^{1/2+2}}{4^{1/2}+2}=32/4=8$， $f(1)=\dfrac{4^{1+2}}{4^1+2}=64/6=32/3$，故答案为 $f(0)+f(1/2)+f(1)=24$。

#### Hint / Trivia

本题标题「是梦 {is,dream}」是「误读 {misread}」的重排。有些时候出题人会在各种地方暗示题目做法……

Author: Ender\_hz

### 答案

### 题目分析

> 大家，一定要认真读题呀！

正如提示中所暗示的（或者你注意力惊人的话），我们可以将这 $(n+1)$ 个 $f$ 重排并进行两两配对；具体地，对 $f(1-x)$ 的分子分母同乘 $4^x$，我们有：

$$f(1-x) = \frac{4^{3-x}}{4^{1-x}+2} = \frac{4^3}{4 + 2 \times 4^x} = \frac{32}{4^x+2}$$

因此：

$$f(x) + f(1-x) = \frac{4^{x+2}}{4^x+2} + \frac{32}{4^x+2} = \frac{4^{x+2}+32}{4^x+2} = 16$$

由此可得：

- $n$ 为偶数时，我们将 $(n+1)$ 项首尾配对，得到 $\frac{n}{2}$ 组余 1 个，即原式

  $$= (f(0)+f(1)) + \left(f\left(\frac{1}{n}\right)+f\left(\frac{n-1}{n}\right)\right) + \cdots + f\left(\frac{1}{2}\right) = 16 \times \frac{n}{2} + 8 = 8n+8$$

- $n$ 为奇数时，我们将 $(n+1)$ 项首尾配对，得到 $\frac{n+1}{2}$ 组，即原式

  $$= (f(0)+f(1)) + \left(f\left(\frac{1}{n}\right)+f\left(\frac{n-1}{n}\right)\right) + \cdots + \left(f\left(\frac{n-1}{2n}\right)+f\left(\frac{n+1}{2n}\right)\right) = 16 \times \frac{n+1}{2} = 8n+8$$

综上， $8n+8$ 即为所求。
