## A Hello, World!

### 题目

#### 题目描述

Hello, World! 问题和 A+B 问题被誉为所有程序员的“第一个程序”。几乎所有接触过编程的人所编写的第一个程序，要么是 Hello, World!，要么是 A+B。今天，就让我们以一道 Hello, World! 问题，开启人生的第一段程序。

本题没有输入。

输出一行，Hello, World!，注意所有字符均为英文半角字符。


## H muzermat的挑战赛之旅

### 题目

#### 题目背景

又到了《王者荣耀》巅峰挑战赛开启的时候，muzermat 准备继续冲分。
巅峰挑战赛是在巅峰赛基础上开展的限时玩法，玩家可以通过累计胜场获得额外奖励。对 muzermat 来说，冲战力之外，他还想把自己的巅峰积分打得更高一些。不过，冲分的过程总有起伏。为了看看自己究竟打到过多高的分数，muzermat 保存了一段时间内按先后顺序排列的巅峰赛对局记录，其中也包含挑战赛期间的对局。记录开始前，他的巅峰积分为 s。每场结束后，记录中都会写下这一场实际带来的积分变化：正数表示增加，负数表示减少，0 表示不变。这里记录的是巅峰积分的变化，不是挑战赛额外奖励的战力或系数。「最后的分数不一定是我最高的分数。」muzermat 翻着记录说，「帮我看看，这段时间我最高打到过多少分？」请根据记录，求出从记录开始前到最后一场结束期间，他曾经达到的最高巅峰积分。

#### 题目描述

给定一个初始整数 s 和按时间顺序排列的 n 个整数变化量。初始分数为 s，处理第 i 个变化量 di 时，将当前分数增加 di。求初始分数以及每次更新后的分数中的最大值。

#### 输入

输入仅一组数据。
第一行两个整数 n、s，用空格隔开，分别表示对局记录数量和开始记录前的巅峰积分，1 ≤ n ≤ 1000，1200 ≤ s ≤ 3000。接下来 n 行，第 i 行一个整数 di，表示第 i 场对局实际带来的积分变化，-100 ≤ di ≤ 100。保证从 s 开始依次应用这些变化量后，每个时刻的积分均非负。

#### 输出

输出一行一个整数，表示这段记录期间的最高巅峰积分，包括记录开始前的积分。

#### 输入样例 1

```text
5
1800 18
-12 25
-8 -10
```

#### 输出样例 1

```text
1831
```

#### 输入样例 2

```text
3
1800 -10
-15 -5
```

#### 输出样例 2

```text
1800
```

#### 输入样例 3

```text
4
2000 0
0 0
0
```

#### 输出样例 3

```text
2000
```

#### 样例解释

样例 1：从初始时刻开始，各时刻的积分依次为 1800、1818、1806、1831、1823、1813，最高为 1831。样例 2：积分一直下降，最高值为开始记录前的 1800 分。样例 3：积分始终保持为 2000。

#### Hint

求一系列数的最大值时，可以用一个变量保存「目前见过的最大值」：先把它设为第一个数，再依次查看后面的数。如果新看到的数比它大，就更新这个变量；否则保持不变。查看完所有数后，这个变量保存的就是最大值。在本题中，可以分别用两个变量保存「当前积分」和「最高积分」，初始时都设为 s。每场结束后，先将当前积分加上本场的变化量，再与最高积分比较，必要时更新最高积分。注意，比较的是每场结束后的积分，而不是本场的积分变化量；记录开始前的积分也要计入最高值。

## J 是梦

### 题目

#### 题目背景

有这样一道题：求 $\sum\limits_{i=0}^{n} f(i/n)$，其中 $f(x)=\dfrac{4x+2}{4x+2}$。泠涼只花了 0.01 s 就看出了 $f(x)\equiv 1$，答案是 $n+1$。结果提交上去喜提 0 分，仔细一看原来是题目读错了，应该是 $f(x)=\dfrac{4^{x+2}}{4^{x}+2}$。大家，一定要认真读题呀！

#### 题目描述

求 $\sum\limits_{i=0}^{n} f(i/n)$，其中 $f(x)=\dfrac{4^{x+2}}{4^{x}+2}$。

#### 输入

一个正整数 n，其中 1≤ n≤ $2.5 \times 10^8$。

#### 输出

一行一个数，表示所求。保证所求为正整数。

#### 样例输入

```text
2
```

#### 样例输出

```text
24
```

#### 样例解释

$f(0)=\dfrac{4^{0+2}}{4^0+2}=16/3$， $f(1/2)=\dfrac{4^{1/2+2}}{4^{1/2}+2}=32/4=8$， $f(1)=\dfrac{4^{1+2}}{4^1+2}=64/6=32/3$，故答案为 $f(0)+f(1/2)+f(1)=24$。

#### Hint / Trivia

本题标题「是梦 {is,dream}」是「误读 {misread}」的重排。有些时候出题人会在各种地方暗示题目做法……
