### 题目

#### 题目背景

[图]
这是仪器科学与光电工程学院 2024 级强基班保研综测评定方案里的某一页。
现在，ZSY 知道了自己的科技创新、学科竞赛、社会工作及德育、体育活动及文艺四项成绩。你需要帮她计算她的实际得分 Y。按照方案，四部分成绩分别按 40%、20%、25%、15% 的权重进行加权，再将加权结果向上取整，得到整数原始总分 X。这一次，ZSY 已经完成了上述加权和取整，直接把原始总分 X 告诉了你。你只需要按照下面的分段计分规则，求出对应的实际得分 Y。

#### 题目描述

给定原始总分 X，实际得分 Y 按以下分段函数计算： Y={ X, } 求对应的 Y。

#### 输入

本题为不定组输入，读至文件结束（EOF），保证数据组数不少于 1 且不超过 100。每组数据占一行，包含一个整数 X，表示原始总分，满足 0≤ X≤ 300。

#### 输出

对于每组数据，输出一行一个实数 Y，表示实际得分，保留小数点后一位。

#### 输入样例 1

```text
0 98 100 101 150 151
200 201 218 300
```

#### 输出样例 1

```text
0.0 98.0 100.0 100.8 140.0 140.5
165.0 165.1 166.8 175.0
```

#### 样例解释

样例 1：
· 当 X=98 时，使用第一段公式，得到 Y=98。

- 当 X=101 时，使用第二段公式，得到 Y=100+0.8× 1=100.8。
- 当 X=151 时，使用第三段公式，得到 Y=140+0.5× 1=140.5。
- 当 X=218 时，使用第四段公式，得到 Y=165+0.1× 18=166.8。

### 答案

### 解题思路

输入的 $X$ 就是原始总分。对于每组数据，只需判断 $X$ 所在的区间，再代入相应的公式计算 $Y$。

按区间上界从小到大判断，可以写成一条 if 、 else if 、 else 分支链：

| 判断条件 | 对应区间 | 计算方式 |
| --- | --- | --- |
| x <= 100 | $0 \le X \le 100$ | $Y = X$ |
| x <= 150 | $100 < X \le 150$ | $Y = 100 + 0.8(X - 100)$ |
| x <= 200 | $150 < X \le 200$ | $Y = 140 + 0.5(X - 150)$ |
| else | $200 < X \le 300$ | $Y = 165 + 0.1(X - 200)$ |

执行到第二个分支时，第一个条件已经不成立，所以此时一定有 $X > 100$，只需再判断 x <= 150 。后面的分支同理。这样每组数据只会执行一个分支，而且能够覆盖所有合法的 $X$。注意不能将这几个条件写成互相独立的 if ，否则较小的 $X$ 可能满足多个条件，导致结果被后面的计算覆盖。

边界值 $X = 100$、 $150$、 $200$ 分别归入前三个区间，对应的 $Y$ 为 $100.0$、 $140.0$、 $165.0$。例如， $X = 218$ 属于最后一个区间，因此 $Y = 165 + 0.1 \times (218 - 200) = 166.8$。

本题没有给出数据组数，需要一直读到文件结束。 scanf("%d", &x) 成功读入一个整数时返回 $1$，因此使用 while (scanf("%d", &x) == 1) ，每次读入后计算并输出一次即可。

实际得分可能包含小数，应使用 double 保存，并用 printf("%.1f\n", y) 保留一位小数。由于 $X$ 为整数，各段公式的准确结果最多只有一位小数，在本题范围内直接计算并按这一格式输出即可。

每组数据只进行常数次判断和运算，时间复杂度为 $O(1)$，额外空间复杂度为 $O(1)$。

### 示例代码

```c
#include <stdio.h>

int main() {
    int x;
    while (scanf("%d", &x) == 1) {
        double y;
        if (x <= 100) {
            y = x;
        } else if (x <= 150) {
            y = 100 + 0.8 * (x - 100);
        } else if (x <= 200) {
            y = 140 + 0.5 * (x - 150);
        } else {
            y = 165 + 0.1 * (x - 200);
        }
        printf("%.1f\n", y);
    }
    return 0;
}
```

### 题目

#### 题目背景

[图]
muzermat 在前往颐和园游玩的路上看到了一家麦当劳！在走进去后，他果断点了一杯自己最喜欢吃的麦旋风。只不过，这家店似乎有些特殊，店员告诉他，他们的麦旋风是使用两台机器来制作的，只有这两台机器一起发出提示的时候，麦旋风才能做完。虽然有些失望，但 muzermat 还是找了个位置坐下，摘下了自己的帽子，把玩着帽子上的猫耳，时不时充满期待地看向柜台上的两台装置。现在你有了这两台机器的详细参数，请你帮助muzermat计算，他多久才能吃到麦旋风呢？也许，你需要注意一下可爱的助教大人给你的提示？

#### 题目描述

两个装置分别每隔 a 分钟和 b 分钟执行一次操作。时刻 0 时，两个装置都刚完成一次操作，此后一直按各自的周期运行。现设置一个提示器，从时刻 0 开始，每隔正整数 d 分钟提示一次。要求任意一个装置执行操作时，提示器都恰好发出提示；允许提示器在两个装置都没有操作的时刻发出提示。求满足要求的最大 d，以及时刻 0 之后两个装置首次同时执行操作的时刻 s。s 用从时刻 0 起经过的分钟数表示。也就是说，你需要求出 a 和 b 的最大公因数 gcd(a,b) 和最小公倍数 lcm(a,b)。

#### 输入

第一行一个整数 T，表示数据组数。
接下来 T 行，每行两个整数 a,b，用空格分隔，表示两个装置的操作周期。保证 1 ≤ T ≤ 105，1 ≤ a,b ≤ 108。

#### 输出

对每组数据输出一行两个整数 d,s，用一个空格分隔。

#### 输入样例 1

```text
5
6 8
5 5
1 9
8 12
99999999 100000000
```

#### 输出样例 1

```text
2 24
5 5
1 9
4 24
1 9999999900000000
```

#### 样例解释

样例 1：第一组可以每隔 2 分钟提示一次，从而覆盖两个装置的全部操作时刻，首次再次同时操作是在第 24 分钟。第二组的两个装置周期相等，下一次同时操作在第 5 分钟，不能将时刻 0 作为答案。第三组的统一提示间隔只能为 1 分钟。第五组的两个周期互质，统一提示间隔为 1 分钟，首次再次同时操作是在第 9999999900000000 分钟。

#### Hint

对于正整数 a,b，记它们的最大公约数为 gcd(a,b)，最小公倍数为 lcm(a,b)，则有 gcd(a,b) × lcm (a,b)=a × b，即 lcm(a,b)=a/gcd(a,b) × b。如果本题你获得了 TLE ，不妨打开课件看一看，找一找有没有什么方法来解决这道题。

Author: muzermat

### 答案

### 解题思路

提示器发出提示的时刻都是 $d$ 的倍数。为了覆盖第一个装置在第 $a$ 分钟的操作， $d$ 必须整除 $a$；同理， $d$ 也必须整除 $b$。反过来，只要 $d$ 同时整除 $a, b$，两个装置此后的全部操作时刻就都是 $d$ 的倍数。因此，最长提示间隔是 $a, b$ 的最大公约数。

两个装置同时操作的时刻必须同时是 $a, b$ 的倍数；排除时刻 $0$ 后，第一次同时操作的时刻就是最小公倍数。设最大公约数为 $g$，则最小公倍数为 $a/g \times b$。

用辗转相除法求 $g$：反复将数对 $(x, y)$ 更新为 $(y, x \bmod y)$，直到 $y = 0$，此时 $x = g$。每次更新保持最大公约数不变，而且非零余数比除数小，因此循环必然结束。用临时变量保存余数，以免赋值顺序覆盖仍需使用的旧值。

计算最小公倍数还要使用原来的 $a, b$，所以应复制到 $x, y$ 后再做辗转相除。本题中 $a, b \le 10^8$，最小公倍数可能接近 $10^{16}$，因此必须使用 long long 保存，并用 %lld 输出。先除后乘可以减小中间值，但仅将结果赋给 long long 并不能避免 int 乘法溢出；代码中的 1LL 使乘除运算在 long long 类型下进行。

每组时间复杂度为 $O(\log(\min(a,b) + 1))$，全部 $T$ 组的时间复杂度为 $O(T \log M)$，其中 $M$ 为输入周期的最大值加 $1$；额外空间复杂度为 $O(1)$。逐个枚举公约数或公倍数，以及每组枚举到平方根的做法，在本题的数据规模下都可能超时。

### 示例代码

```c
#include <stdio.h>

int main() {
    int t;
    scanf("%d", &t);
    while (t--) {
        int a, b;
        scanf("%d%d", &a, &b);
        int x = a, y = b;
        while (y != 0) {
            int r = x % y;
            x = y;
            y = r;
        }
        int g = x;
        long long s = 1LL * a / g * b;
        printf("%d %lld\n", g, s);
    }
    return 0;
}
```

## C 好多好多0

### 题目

#### 题目描述

小 M 想检查一个非负整数的十进制数位。你需要求出：
所有数位上的数字之和； 数字 0 出现的次数。
例如，10020 的数位为 1,0,0,2,0，数字之和为 3，数字 0 出现 3 次。数的表示不含多余的前导零。特别地，整数 0 的表示就是一个数字 0，因此数字之和为 0，数字 0 出现 1 次。

#### 输入

第一行为一个整数 T (1≤ T≤ 10000)，表示数据组数。
接下来 T 行，每行一个整数 n (0≤ n≤ 109)。输入的整数不含多余的前导零。

#### 输出

对于每组数据，输出一行两个整数，以一个空格隔开，依次表示所有数位上的数字之和、数字 0 出现的次数。

#### 输入样例

```text
5
0
7
10020
909
1000000000
```

#### 输出样例

```text
0 1
7 0
3 3
18 1
1 9
```

#### 样例解释

909 的数字之和为 9+0+9=18，其中有一个数字 0。

#### 提示

一个数字的最后一位可以用 a % 10 提取出来。使用 a / 10 可以达到十进制上右移一位的效果。

author: 只只小木条

### 答案

### 解题思路

十进制整数除以 $10$ 的余数，就是个位数字；整数除以 $10$ 的商，就是去掉个位后的部分。例如， 10020 % 10 为 $0$， 10020 / 10 为 $1002$。

每次取出一个数字，将它加到 sum ；如果数字为 $0$，就让 s0 加一。然后去掉这一位，继续处理。

**需要考虑整数 0 也有一个数位。** 如果直接使用 while (n > 0) ，它一次也不会执行，错误地得到零个数字 0。也可以对 $0$ 单独判断，再用普通 while 。也可以使用 do/while 。 do/while 会先执行一次，再检查剩余数字，因此能统一处理 $0$。

### 示例代码

```c
#include <stdio.h>

int main() {
    int T;
    scanf("%d", &T);
    while (T--) {
        int n, sum = 0, s0 = 0;
        scanf("%d", &n);
        do {
            int d = n % 10;
            sum += d;
            if (d == 0) {
                s0++;
            }
            n /= 10;
        } while (n > 0);
        printf("%d %d\n", sum, s0);
    }
    return 0;
}
```

## D Entrance to the Chaos

### 题目

破译：Implexrough·线索一
不等指尖触及，那道杂音便兀自从替换数据上剥离，灵巧一扭，径直慢发开来。似泡沫破裂，蚊虫振翅，火花崩溅，粉末晃动，一切非常，交织缠绕，嘈嘈切切，吉诺却意外理解了其中的内容。

#### 题目描述

给定一个正整数 x、一个正整数 c 和两个正整数 l,r。每轮按照本轮开始时 x 的奇偶性，执行下面的一种操作： · 如果 x 为偶数，将 x 替换为 x/2。 · 如果 x 为奇数，将 x 替换为 x+c。且每轮只执行一种操作。请问最少经过多少轮操作，x 会第一次满足 l ≤ x ≤ r？如果初始的 x 已经在区间内，答案为 0。各组询问相互独立。如果执行 104 轮后仍未进入区间，输出 CHAOS。

#### 输入

第一行，一个正整数 t，表示询问组数，满足 1 ≤ t ≤ 1000。
接下来 t 行，每行包含四个由空格分隔的正整数 x,c,l,r，满足 1 ≤ x ≤ 2× 109，1 ≤ c ≤ 2× 109，1 ≤ l ≤ r ≤ 2× 109。

#### 输出

输出 t 行，按照输入顺序，每行输出对应询问的答案。
如果初始值或前 104 轮操作后的某个值属于给定区间，输出首次进入区间的轮数 s，满足 0 ≤ s ≤ 104；否则输出 CHAOS。

#### 输入样例 1

```text
6
5 3 4 6
12 5 6 6
7 3 10 10
1 7 3 5
20 3 6 9
3 2 9 9
```

#### 输出样例 1

```text
0
1
1
2
3
3
```

#### 输入样例 2

```text
7
16 1 1 1
2 7 1 1
1999999997 1999999999 1999999998 1999999998
1 2 19999 19999
1 2 20001 20001
1 2 20003 20003
1 1 3 3
```

#### 输出样例 2

```text
4
1
2
9999
10000
CHAOS
CHAOS
```

#### 样例解释

第一组样例的第四个询问中，x 的变化为 1 to 8 to 4，第一次进入区间 [3,5] 需要 2 轮。
第一组样例的第五个询问中，x 的变化为 20 to 10 to 5 to 8。从 10 变为 5 时虽然越过了区间 [6, 9]，但没有落在区间内，因此此时不能结束。第二组样例的第三个询问中，x 的变化为 1999999997 to 3999999996 to 1999999998。计算过程中的值可能超出 32 位有符号整数的范围。第二组样例的第四至第六个询问中，x 始终是奇数，每轮增加 2，分别需要 9999、10000、10001 轮才能进入目标区间。第六个询问超过轮数限制，因此输出 CHAOS。第二组样例的第七个询问中，x 在 1 与 2 之间循环，始终无法进入给定区间，因此输出 CHAOS。

Author: crimson000 quitting phigros

### 答案

### 解题思路

按照题目给出的规则直接模拟即可。对于每组询问，先判断当前的 x 是否位于闭区间 [l,r] 中；如果已经在区间内，答案就是当前已经执行的轮数。

如果还没有进入区间，则根据 x 的奇偶性进行一次操作： x 为偶数时令 x /= 2 ， x 为奇数时令 x += c ，随后将轮数加一。题目只认可初始值以及前 $10^4$ 轮操作后的值，因此循环条件中还要保证操作次数小于 $10^4$。

循环结束后再次判断 x 是否位于区间中。如果在，就输出首次进入区间时的轮数；否则说明执行 $10^4$ 轮后仍未进入区间，输出 CHAOS 。由于每轮开始前都会先判断是否已经进入区间，输出的轮数一定是最小值。

x 和 c 最大均为 $2 \times 10^9$，奇数情况下执行 x+c 可能超过 int 的范围，因此应使用 long long 保存参与运算的数据。

每组数据最多模拟 $10^4$ 轮，时间复杂度为 $O(10^4)$，额外空间复杂度为 $O(1)$。

### 示例代码

```c
#include <stdio.h>

int main()
{
    int T;
    scanf("%d", &T);
    while(T -- )
    {
        long long x, c, l, r;
        scanf("%lld%lld%lld%lld", &x, &c, &l, &r);

        int ans = 0;
        while((x < l || x > r) && ans < 10000)
        {
            if(x % 2 == 0) x /= 2;
            else x += c;
            ans ++;
        }
        if(l <= x && x <= r) printf("%d\n", ans);
        else puts("CHAOS");
    }

    return 0;
}
```

## E Spider's Thread

### 题目

#### 题目描述

请你画出一张大小为 (2n+1) × (2n+1) 的蜘蛛网字符画，要求如下： · 网的中心用 + 表示； · 过中心的水平方向的蛛丝用 - 表示 · 过中心的竖直方向的蛛丝用 | 表示 · 主对角线的蛛丝用 \ 表示 · 副对角线的蛛丝用 / 表示确定好“米”字形框架后，如果还有空白，则根据它们所在的区域填充字符： · 若该位置更靠近过中心的水平直线，填 | · 若该位置更靠近过中心的竖直直线，填 -

#### 输入格式

输入仅一行，包含一个正整数 n（1 ≤ n ≤ 10）。

#### 输出格式

输出共 2n+1 行，每行 2n+1 个字符（不含换行符），表示一张完整的蜘蛛网。

#### 输入样例 1

```text

```

#### 输出样例 1

```text
\|/ -+- /|\
```

#### 输入样例 2

```text

```

#### 输出样例 2

```text

hint

1. 每一个字符对应一个坐标 (i , j) ，可通过比较 i ，j ， n 的大小关系来判断填什么字符。同

一个位置可能同时满足多个条件，所以需要考虑各个字符的优先级。2. 还记得转义字符吗？
not hint
```

### 答案

### 解题思路

由于网格大小固定为 $(2n + 1) \times (2n + 1)$，我们可以直接用双重循环遍历每一个坐标 $(i, j)$（ $0 \le i, j \le 2n$ ），其中坐标 $(i, j)$ 代表从上往下、从左往右的第 $i$ 行第 $j$ 列。对于每一个位置，我们需要判断它属于哪一部分：

1. 中心点： $(i, j) = (n, n)$，填 + 。

1. 主对角线： $i = j$，填 \ 。

1. 副对角线： $i + j = 2n$，填 / 。

1. 竖直中心线： $j = n$，填 | 。

1. 水平中心线： $i = n$，填 - 。

1. 空白区域：根据到中心线的距离决定：

   - 到竖直中心线的距离为 $|j - n|$，到水平中心线的距离为 $|i - n|$。

   - 如果 $|j - n| < |i - n|$，说明它更靠近竖直中心线，填 - 。

   - 如果 $|j - n| > |i - n|$，说明它更靠近水平中心线，填 | 。

在嵌套的 if...else if...else 结构中，同一个坐标可能同时满足多个条件。例如：中心点 $(n, n)$ 同时满足 $i = n$、 $j = n$、 $i = j$、 $i + j = 2n$。

因此，应该先画米字形框架，再填空白。一旦靠前的条件成立，就执行对应的输出并立即跳过后续判断。如果顺序写反了，对角线会被十字线截断，中心点也会被覆盖。

### 示例代码

```c
#include <stdio.h>
#include <stdlib.h>
int main() {
    int n;
    scanf("%d", &n);
    for (int i = 0; i < 2 * n + 1; i++) {
        for (int j = 0; j < 2 * n + 1; j++) {
            if (i == n && j == n)putchar('+');
            else if (i == j)putchar('\\');
            else if (i + j == 2 * n)putchar('/');
            else if (j == n)putchar('|');
            else if (i == n)putchar('-');
            else if (abs(j - n) < abs(i - n))putchar('-');
            else putchar('|');
        }
        puts("");
    }
    return 0;
}
```

## G 时区转换

### 题目

#### 题目背景

全世界共有 24 个时区，用整数偏移量表示。例如，北京是 UTC+8，伦敦是 UTC+0，纽约是 UTC-5。那么北京的晚上 20 点是伦敦的中午 12 点，是纽约的早上 7 点。在外国旅游的小蕾想要联系在国内的家人，但由于存在时差，为了不打扰家人休息，她需要知道不同地区的时间。本题中我们假定：一个地区只使用固定的一个时间，不存在夏令时。

#### 题目描述

小蕾已知她所在的当地时区（UTC z）和当地时间，请帮她计算出对应的北京时间（UTC+8）。
时间换算规则：北京时间比当地时区快 (8 - z) 小时。例如，纽约是 UTC-5，那么北京比纽约快 8 - (-5) = 13 小时。将当地时间加上这个时差，即可得到北京时间。

#### 输入格式

第一行一个正整数 T (1 ≤ T ≤ 2000) ，代表数据组数。
接下来 T 行，每行包含 5 个整数，用空格分隔，顺序如下：
· 当地时区的偏移量 z（-12 ≤ z ≤ 14）
· 年 y 、月 m 、日 d 、时 h ：表示当地的当地时间。
其中时间采用 24 小时制，即 0 ≤ h ≤ 23 。保证输入的日期是 2000-01-01 00 到 9999-12-31 00 之间的一个合法日期，且转换后的结果年份不会超过 9999 年。

#### 输出格式

输出 T 行，每行格式为 YYYY-MM-DD HH，表示对应的北京时间。注意：月、日、时不足两位需要高位补零。

#### 输入样例

```text
6

-5 2026 10 13 20
-8 9999 4 30 18
-12 2085 12 31 10
-12 2024 2 28 10
14 2100 1 1 0
```

#### 输出样例

```text

2026-10-14 09
9999-05-01 10
2086-01-01 06
2024-02-29 06
2099-12-31 18
```

#### 样例解释

- 第1组 8 2023 6 15 10：当地时区正好是北京时间（z=8），时间差为 0。直接输出 2023-06-15 10。
- 第2组 -5 2026 10 13 20：时差为 8 - (-5) = 13 小时。当地时间 20 点加 13 小时跨天到次日 9 点，输出 2026-10-14 09。
- 第3组 -8 9999 4 30 18：时差为 16 小时。18 点加 16 小时为次日 10 点，并且 4 月只有 30 天，因此跨月到 5 月 1 日，输出 9999-05-01 10。
- 第4组 -12 2085 12 31 10：时差为 20 小时。10 点加 20 小时为次日 6 点。由于输入已经是年底，跨天后进入新的一年，输出 2086-01-01 06。
- 第5组 -12 2024 2 28 10：时差为 20 小时。时间为次日 6 点。由于 2024 年是闰年，2 月有 29 天，因此不跨月，输出 2024-02-29 06。
- 第6组 14 2100 1 1 0：时区为 14，时差为 8 - 14 = -6 小时。 0 点倒退 6 小时，变为前一天的 18 点。倒退跨年后为上一年的 12 月 31 日，输出 2099-12-31 18。

#### 提示

· 跨天次数： z 的范围是 [-12, 14] ，因此 8 - z 的范围是 [-6, 20] 。也就是说时区转换最多只
会跨越一天，不会连续跨越两天。
· 月份天数：为了避免写一大堆冗长的 if-else，建议用一个数组提前存好每个月的天数，这样在跨
月计算时，直接查表即可。遇到闰年的 2 月再分类讨论。
· 闰年规则：年数能被 4 整除但不能被 100 整除，或者能被 400 整除。
· 输出格式：你可以使用 printf("%d-%02d-%02d %02d\n", y, m, d, h); 输出日期，其中 %02d 表示输出宽度至少为 2 位，不足 2 位时左边补 0。

### 答案

### 解题思路

整体思路可以分为以下几步：

1. 建立月份和天数的对照表

   因为时差转换可能导致跨月，我们需要知道每个月有多少天。可以提前用一个数组把平年每个月天数存起来： int day[13] = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31}; （其中下标 1 到 12 对应 1 到 12 月，下标 0 占位不用）

1. 写一个判断闰年的逻辑：如果能被 4 整除但不能被 100 整除，或者能被 400 整除，就是闰年。 int isLeap = (y % 4 == 0 && y % 100 != 0) || (y % 400 == 0);

1. 计算北京时间： h = h + 8 - z 。若计算得到的 h 在正常的范围中则输出，否则根据 h 的取值，分为两种情况讨论：

   - h < 0 ： 由于最多只跨一天， h += 24 即可得到正确的 h ，再把日期减一天 d-- 。如果 d 变成 0，说明需要退到上个月：

     - 如果月份 m 变成 0，说明退到了去年 12 月（ m = 12 , y-- ，日期为 day[12] ）；

     - 如果退到的是 2 月（即 m == 2 ），需要根据当前年份 y 判断闰年，决定 d 是 29 还是 28；

     - 其他情况，直接取 day[m] 。

   - h > 23 ：先 h -= 24 ，再把日期加一天 d++ 。如果 d > day[m] ，说明可能需要跨到下个月：

     - 如果当前是闰年的 2 月 29 日（ m == 2 && d == 29 && isLeap ），说明这个日期是合法的，不需要跨月。

     - 一般情况： d = 1 ， m++ 。如果 m > 12 ，说明跨到了明年，需要 y++ 并重置 m 为 1。

### 示例代码

```c
#include <stdio.h>
int day[13] = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
int main() {
    int T;
    scanf("%d", &T);
    while (T--) {
        int z, y, m, d, h;
        scanf("%d%d%d%d%d", &z, &y, &m, &d, &h);
        int isLeap = (y % 4 == 0 && y % 100 != 0) || (y % 400 == 0); // 判断是否为闰年
        h = h + 8 - z;
        if (h < 0) { // 北京时间在前一天
            h += 24;
            d--;
            if (d == 0) { // 需要跨到前一个月
                m--;
                if (m == 0) { // 一月往前一个月需要跨到去年
                    m = 12;
                    y--;
                    d = day[12];
                } else if (m == 2) { // 三月往前一个月需要考虑闰年
                    d = isLeap ? 29 : 28;
                } else {
                    d = day[m];
                }
            }
        } else if (h > 23) { // 北京时间在后一天
            h -= 24;
            d++;
            if (d > day[m]) { // 可能需要跨到后一个月
                if ((m == 2) && (d == 29) && isLeap) { // 闰年的 2 月 29 日不需要跨一个月

                } else {
                    d = 1;
                    m++;
                    if (m > 12) { // 十二月往后一个月需要跨到明年
                        m = 1;
                        y++;
                    }
                }
            }
        }
        printf("%d-%02d-%02d %02d\n", y, m, d, h);
    }
    return 0;
}
```

### 答案

### 解题思路

用数组 f[j] 表示使用当前已经获得的物品，能否拼出总重量 j 。没有任何物品时，只有总重量 $0$ 可以通过“不选择任何物品”得到，因此初始化 f[0] = 1 ，其余位置均为 $0$，并先输出这一行。

读入一个重量为 $c_i$ 的新物品后，对于每个 $j \ge c_i$，如果原来能够拼出 $j - c_i$，那么再选择当前物品就能够拼出 $j$，因此可以进行转移：

$$
f[j] = f[j]\ \text{or}\ f[j - c_i].
$$

每个物品只能使用一次，所以必须按照 $j = m, m - 1, \ldots, c_i$ 的顺序倒序更新。这样计算 f[j] 时，右侧的 f[j-c_i] 仍然是加入当前物品之前的状态。如果从小到大更新，同一个物品可能在一轮内被重复使用，变成完全背包，与题意不符。

每读入一个物品并完成更新后，输出一次 f[0] 到 f[m] ，即可得到题目要求的 $n + 1$ 行结果。

时间复杂度为 $O(nm)$。使用一维数组后，额外空间复杂度为 $O(m)$。

### 示例代码

```c
#include <stdio.h>
int f[2005];
int main() {
    int n, m;
    scanf("%d%d", &n, &m);

    f[0] = 1;
    print_state(m);

    for (int i = 1; i <= n; i++) {
        int c;
        scanf("%d", &c);
        for (int j = m; j >= c; j--) {
            if (f[j - c]) {
                f[j] = 1;
            }
        }
        for (int j = 0; j <= m; j++) {
            printf("%d%c", f[j], j == m ? '\n' : ' ');
        }
    }

    return 0;
}
```

### 答案

### 解题思路

每次加入的盐水质量相同，所以混合浓度的百分数数值等于各份盐水浓度数值的平均值。下面只讨论百分数前面的数值，例如 $3.00\%$ 对应 $3.00$。

先观察加入份数的奇偶性。加入偶数份时，甲、乙的份数相同，混合后的浓度总是

$$
m = \frac{h + c}{2}.
$$

因此，所有偶数方案只需要保留份数最小的 $2$ 份。

加入 $2k + 1$ 份时，甲有 $k + 1$ 份，乙有 $k$ 份，浓度为

$$
f(k) = \frac{(k+1)h + kc}{2k+1} = m + \frac{h - c}{2(2k+1)}, \qquad k \ge 0.
$$

因为 $h > c$，所以 $f(k)$ 始终大于 $m$，并且随 $k$ 增大严格下降。

如果 $t \le m$，那么每个奇数方案都比偶数方案离目标更远，答案就是 $2$ 份。

如果 $t > m$，令 $f(k) = t$，移项得到实数交点

$$
q = \frac{h - t}{2t - h - c}.
$$

这里分母为正、分子非负。在交点左侧，增加 $k$ 会使浓度接近目标；在交点右侧，增加 $k$ 会使浓度远离目标。因此，理想的精确计算只需要比较 $k = \lfloor q \rfloor$ 与 $k = \lfloor q \rfloor + 1$。当 $q$ 为整数时，前者恰好达到目标。不能直接将 $q$ 四舍五入，因为浓度差与 $k$ 的距离并不成正比。

这两个候选中一定有一个优于 $2$ 份：不高于目标的那个奇数方案，其浓度仍然大于 $m$，所以比浓度为 $m$ 的偶数方案更接近目标。 $t = h$ 时也适用，此时 $q = 0$，一份甲盐水即可。

实际代码中， double 不能准确表示所有三位小数。特别是在 $q$ 很接近整数时，直接转换为 int 可能落在相邻位置。为此，先计算 k = (int)q ，然后检查 k - 1 到 k + 2 ，跳过负值。这里只增加常数次计算，同时覆盖了取整误差两侧的候选。用一份甲盐水初始化当前答案，逐个比较即可。

对候选浓度 $x$，计算 a = fabs(x - t) ；对当前答案浓度 best ，计算 b = fabs(best - t) 。取 eps = 1e-13 。当 a < b - eps 时更新答案；当 fabs(a - b) <= eps 时，保留份数更小的方案。

这个 eps 与本题范围有关。将输入浓度乘以 $1000$，可得到 $0$ 到 $25000$ 之间的整数。在 $t > m$ 的分支中，准确分母 $2t - h - c$ 至少为 $0.001$，交点 $q < 12500$。输入转换和少量运算造成的误差远小于 $1$，检查相邻位置足以覆盖正确候选；程序检查的份数不超过 $25003$。

对于两个这样的候选，如果准确浓度差的绝对值不同，两者误差之差至少为

$$
\frac{1}{1000 \cdot 25003^2} > 1.5 \times 10^{-12}.
$$

这是因为每个准确误差都可以写成一个整数除以 $1000n$，通分后非零的整数分子绝对值至少为 $1$。因此， 1e-13 足以容纳正常的 double 舍入误差，又不会把这两个本来不同的候选误判为并列。判断 $t \le m$ 时，非零差值至少为 $0.0005$，同样可以安全地加入这个容差。不能直接使用输出允许的 1e-6 来选择最优份数。

计算中所有浓度使用 double ，读入用 %lf ，输出用 %.10f 。最大候选份数只有几万， int 足够存放份数和循环变量。每组数据只检查常数个候选，时间复杂度为 $O(1)$；总时间复杂度为 $O(T)$，额外空间复杂度为 $O(1)$。

### 示例代码

```c
#include <stdio.h>
#include <math.h>

int main() {
    const double eps = 1e-13;
    int T;
    scanf("%d", &T);

    while (T--) {
        double h, c, t;
        scanf("%lf%lf%lf", &h, &c, &t);
        int ans = 1;
        double best = h;

        if (t <= (h + c) / 2 + eps) {
            ans = 2;
            best = (h + c) / 2;
        } else {
            int k = (int)((h - t) / (2 * t - h - c));
            // 多检查相邻位置，防止浮点误差影响整数截断。
            for (int j = k - 1; j <= k + 2; j++) {
                if (j >= 0) {
                    int n = 2 * j + 1;
                    double x = ((j + 1) * h + j * c) / n;
                    double a = fabs(x - t), b = fabs(best - t);
                    if (a < b - eps || (fabs(a - b) <= eps && n < ans)) {
                        ans = n;
                        best = x;
                    }
                }
            }
        }

        printf("%d %.10f\n", ans, best);
    }

    return 0;
}
```

### 题目

#### 题目背景

少女站在悬崖顶端，第一次将这纯白的世界尽收眼底：苍白而又静止的广袤大地上矗立着不少建筑，有的笔直，有的歪斜；它们早已被废弃，尘封于历史这厚重的卷轴中。少女的脑中浮现出它们的名字：“ Arcaea”，但有关这个名字的一切，她都不曾了解。当然，还有另一种名为“Arcaea”的东西：那些漂浮在空中的、反映着其他地方的其他人们的事迹的玻璃碎片。这些碎片里存储着的影像一眼看去就像在观赏电影， 虚幻而不真实……这不过是一场梦而已，这一定是一场梦。但，又怎可能有如此真实的梦呢。

#### 题目描述

给定两个正整数 n,m，请计算所有满足 1 ≤ i ≤ n、1 ≤ j ≤ m 的有序数对 (i,j) 的最大公约数之和，即： S=∑i=1n∑j=1mgcd(i,j). 其中，gcd(i,j) 表示 i 和 j 的最大公约数。

#### 输入

#### 输出

输出一个整数 S，表示所求的和。

```text
3
4
```

#### 输出样例 1

```text
16
```

#### 输入样例 2

```text
6
6
```

#### 输出样例 2

```text
61
```

#### 输入样例 3

```text
5
1
```

```text

```

#### 样例解释

样例 1：固定 i=1 时，各项之和为 1+1+1+1=4；固定 i=2 时，各项之和为 1+2+1+2=6；固定 i=3 时，各项之和为 1+1+3+1=6。因此答案为 4+6+6=16。样例 2：当 n=m=6 时，答案为 61。样例 3：由于 gcd(i,1)=1，共 5 项之和为 5。

### 答案

### 解题思路

直接枚举所有有序数对需要计算 $nm$ 次最大公约数，无法处理上限数据。令 $L = \min(n, m)$，将数对按最大公约数分类。定义 $cnt[d]$ 为满足 $1 \le i \le n$、 $1 \le j \le m$ 且最大公约数恰好为 $d$ 的有序数对数量。

$i$ 和 $j$ 均为 $d$ 的倍数的数对共有 $\lfloor n/d \rfloor \lfloor m/d \rfloor$ 个。这些数对的最大公约数一定是 $d$ 的倍数，所以减去最大公约数为 $2d, 3d, \ldots$ 的数对数量，就得到最大公约数恰好为 $d$ 的数对数量：

$$
cnt[d] = \left\lfloor \frac{n}{d} \right\rfloor \left\lfloor \frac{m}{d} \right\rfloor - \sum_{k=2}^{\lfloor L/d \rfloor} cnt[kd].
$$

按照 $d = L, L - 1, \ldots, 1$ 的顺序计算，右侧所有需要的计数均已求出。每种数对恰好归入一个最大公约数类别，故最终答案为：

$$
S = \sum_{d=1}^{L} d \cdot cnt[d].
$$

时间复杂度为 $O(L \log L)$，空间复杂度为 $O(L)$。程序预留上限大小的全局数组。共有不超过 $10^{12}$ 个数对，每个最大公约数不超过 $10^6$，所以答案不超过 $10^{18}$，可以用 long long 保存。数对总数的乘法也必须先转为 long long ，避免在 int 中溢出。上述递推同样适用于 $n < m$、 $n > m$ 以及其中一个参数等于 $1$ 的情况。

### 示例代码

```c
#include <stdio.h>

long long cnt[1000001];

int main() {
    int n, m;
    scanf("%d%d", &n, &m);

    int limit = n < m ? n : m;
    long long ans = 0;
    for (int d = limit; d >= 1; d--) {
        cnt[d] = (long long)(n / d) * (m / d);
        for (int j = d + d; j <= limit; j += d) {
            cnt[d] -= cnt[j];
        }
        ans += (long long)d * cnt[d];
    }

    printf("%lld\n", ans);

    return 0;
}
```
