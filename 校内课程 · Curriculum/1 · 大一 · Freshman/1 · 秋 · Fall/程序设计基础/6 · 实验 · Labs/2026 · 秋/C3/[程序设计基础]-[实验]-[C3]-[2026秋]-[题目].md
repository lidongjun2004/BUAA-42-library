## G 位运算方程

### 题目

#### 题目描述

kanade 在学习了位运算后突发奇想：既然我们能解含有加减乘除的方程，那么能不能解一个含有位运算的方程呢？于是她写下了三种方程： 1. a ^ x = b2. a | x = b3. a & x = b 其中 ^ 表示按位异或，| 表示按位或，& 表示按位与。对于两个给定的非负整数 a 和 b，kanade 发现有时可以找到一个非负整数 x，使得某些方程成立，但有时不能。 kanade 想知道，对于每组 a 和 b，满足对应方程的最小非负整数 x 是多少；如果不存在这样的 x，输出 -1 。请你写一个程序帮帮她！

#### 输入格式

第一行一个正整数 n (1 ≤ n ≤ 104) ，表示数据组数。
接下来 n 行，每行三个整数 op, a, b ，用空格分隔。
op 表示方程类型：
· op=1：a ^ x = b
· op=2：a | x = b
· op=3：a & x = b
a, b 为两个 unsigned int 范围的整数，即 0 ≤ a, b ≤ 232 - 1。

#### 输出格式

输出 n 行，每行一个整数。对于每组数据：

- 若存在满足方程的最小非负整数 x ，则输出这个 x 。
- 若不存在则输出 -1 。

#### 输入样例

```text
6
1 5 3
2 5 7
3 5 4
2 1 2
3 2 3
1 0 4294967295
```

#### 输出样例

```text
6
2
4
-1
-1
4294967295
```

#### 样例解释

为了方便，在样例中，我们用 4 位二进制数表示，从左到右依次标为第1位、第2位、第3位、第4位。

- 1 5 3：5 是 0101，3 是 0011。0101 与未知数异或得到 0011，未知数需要在第2、3位填1，得到 0110，也就是6。
- 2 5 7：5 是 0101，7 是 0111。0101 已满足2、4位，为了满足第3位，未知数只填第3位为1，得到 0010，也就是2。
- 3 5 4：5 是 0101，4 是 0100。目标第2位是1，5 的第2位已经是1，未知数只保留第2位，得到 01 00，也就是4。
- 2 1 2：1 是 0001，2 是 0010。1 的第4位是1，结果第4位必定是1。但 2 的第4位是0，矛盾，无解。输出 -1。
- 3 2 3：2 是 0010，3 是 0011。2 的第4位是0，结果第4位必定是0。但 3 的第4位是1，矛盾，无解。输出 -1。
- 1 0 4294967295：这个样例是为了提醒你输入的数可能大于 int 的最大值，如果你用 %d 输出，这个数会被错误地打印成 -1，请务必使用 %u 输出。

#### 提示

· 数据范围：在常见编译器中：
· int 的范围是 $-2^{31}$ 到 $2^{31}-1$。
· unsigned int 的范围是 0 到 $2^{32}-1$。

- 输入输出格式：注意到 a, b 的范围超过了 int ，所以请使用 unsigned int 存储 a, b ，使用 s canf("%u%u", &a, &b) 读取无符号整数，使用 printf("%u", ans) 输出有解时的答案。
- 独立考虑每一位：位运算对于二进制中的每一位是互相独立的。可以先考虑只有一位的情况，再推广到 32 位。这是解决所有位运算方程的核心思路。

## I Tensorfactory

### 题目

在严谨的程序设计思维下，一切难题都是纸老虎。

#### 题目背景

在现代深度学习框架（如 PyTorch、TensorFlow）中，高维数组（张量，Tensor）无论有多少个维度，底层通常都存储在一块连续的一维内存中。这种设计不仅能提高缓存命中率，还使改变张量形状（Resh ape）成为一种只修改逻辑维度而不移动物理数据的快速操作。 [图]

#### 题目描述

一家张量工厂（Tensorfactory）委托你实现一个简易的张量引擎。
初始时给定一个 k 维张量的形状和数据，张量引擎需要维护这些数据，并支持查询、修改和重塑形状
三种操作。
张量工厂给出张量引擎存储张量的通用标准如下：
张量按行优先存储，下标均从 0 开始。设当前张量共有 c 个维度，形状为 D1 × D2 × … × Dc，坐标为 (x1,x2,…,xc)，则该元素在一维存储空间中的下标为 (((x1D2+x2)D3+x3)…)Dc+xc。例如，形状为 2 × 3 的二维张量依次存储第 0 行的 3 个元素和第 1 行的 3 个元素。重塑操作只改变张量的维度数和各维长度，不改变底层数据的一维顺序；查询、修改和重塑操作的具体要求见输入。

#### 输入

第一行包含一个正整数 k，表示初始张量的维度数，满足 1 ≤ k ≤ 10。
第二行包含 k 个正整数 D1,D2,…,Dk，表示各维的初始长度，满足 $1 \le D_i \le 10^6$，且元素总数 $N=\prod_{i=1}^{k} D_i$ 满足 $1 \le N \le 10^6$。第三行包含 N 个整数，表示张量的初始数据，按行优先顺序给出，保证每个整数均在 int 范围内。第四行包含一个正整数 q，表示操作次数，满足 $1 \le q \le 10^5$。接下来 q 行，每行描述一个操作： · 1 c x_1 x_2 ... x_c：查询操作。尝试查询当前张量中坐标为 (x1,x2,…,xc) 的元素。其中 1 ≤ c ≤ 10，-109 ≤ xi ≤ 109。 · 2 c x_1 x_2 ... x_c val：修改操作。尝试将当前张量中坐标为 (x1,x2,…,xc) 的元素修改为 va l。其中 1 ≤ c ≤ 10， $-10^9 \le x_i \le 10^9$，val 在 int 表示范围内。 · 3 c D'_1 D'_2 ... D'_c：重塑操作。尝试将张量重塑为 c 维，新形状为 D'1 × D'2 × … × D 'c。其中 1 ≤ c ≤ 10， $1 \le D'_i \le 10^9$。对于查询或修改操作，合法性按以下顺序判断： 1. 若 c 不等于当前张量的维度数，则操作非法，不再判断坐标是否越界；2. 否则，若存在 xi<0 或 xi≥ Di，则操作非法；3. 否则，操作合法。对于重塑操作，仅当 ∏i=1cD'i=N 时合法，否则非法。任何非法的修改或重塑操作都不会改变张量的数据或形状。

#### 输出

按操作顺序输出结果：

- 对于合法的查询操作，输出一行该位置的整数值；对于非法的查询操作，输出一行 -1。
- 对于合法的修改操作，不输出任何内容；对于非法的修改操作，输出一行 -1。
- 对于合法的重塑操作，不输出任何内容；对于非法的重塑操作，输出一行 -1。

#### 输入样例
