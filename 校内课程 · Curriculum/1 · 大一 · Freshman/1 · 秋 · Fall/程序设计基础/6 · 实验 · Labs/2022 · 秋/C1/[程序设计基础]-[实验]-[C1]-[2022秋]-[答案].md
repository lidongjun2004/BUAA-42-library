## C 大运村寻家记

### 题目

#### 题目描述

给定三个自然数 $a, m, b$ ，求 $(a \times b) \bmod m$ 。

注意 $a \times b$ 可能超过 `int` 的表示范围，请利用公式

$$(a \times b) \bmod m = ((a \bmod m) \times (b \bmod m)) \bmod m$$

即输出表达式 $((a \bmod m) \times (b \bmod m)) \bmod m$ 的值。

#### 输入格式

一行三个自然数 $a, m, b$ 。

#### 输出格式

一行一个整数，为所求的值。

#### 样例输入

```text
17 5 7
```

#### 样例输出

```text
4
```

### 答案

### 题目分析

1、不要直接使用 $(a*b)\%m$ 进行运算，因为 $a*b$ 可能会超过 int 范围，请根据以下数学公式进行优化。

2、利用公式： $(a*b)\%m = ((a\%m)*(b\%m))\%m$，即在程序中程序中输出表达式 $((a\%m)*(b\%m))\%m$ 的值。

### 示例代码

```c
#include <stdio.h>

int a, m, b;
int main(void) {
    scanf("%d%d%d", &a, &m, &b);
    printf("%d", ((a % m) * (b % m)) % m);
    return 0;
}
```

## D 投球游戏

### 题目

#### 题目描述

投球游戏中，若投出的球与目标的距离为 $a$ ：

- 若 $a < 53$ ，输出 `Too close!` ；
- 若 $a = 53$ ，输出 `Bingo!` ；
- 若 $a > 53$ ，输出 `Too far!` 。

#### 输入格式

一行一个整数 $a$ 。

#### 输出格式

一行，按上述规则输出对应的字符串。

#### 样例输入

```text
53
```

#### 样例输出

```text
Bingo!
```

### 答案

### 题目分析

本题考察学生对 $if$ 的掌握情况。只使用 $if$ 或是使用 $if-else$ 都是可以的。

如果是单个的 $if$ 语句，则会判断 $if$ 后括号内的表达式的值，如果为真则执行接下来的代码块。

如果是 $if-else$ 结构：

$if-else$ 语句执行的步骤如下：

1. 首先判断第一个 if 条件是否成立，如果成立则执行第一个代码块，执行完毕后跳过整个 $if-else$ 代码块。
2. 如果不成立，则判断第二个条件是否成立，如果成立则执行第二个代码块，执行完毕后跳过整个 $if-else$ 代码块。
3. 依次对剩余条件进行判断。如果有任意一个条件成立，那么执行完所属的代码后将不会执行 $if-else$ 结构中剩余的代码。
4. 如果所有条件都不成立，则执行 else 代码块内的内容。
5. 如果所有条件都不成立且没有 else 部分，则不会执行任何代码。

如下所示：

```c
if(/*判断条件1*/) {
     ...//如果判断条件1成立则执行这里
}
else if(/*判断条件2*/) {
     ...//如果判断条件2成立则执行这里
}
else {
     ...//如果判断条件1和判断条件2都不成立则执行这里
}
//如果判断条件1和判断条件2都成立则只会执行代码块1内部的内容
```

### 示例代码

```c
#include <stdio.h>

int main(){
    int a;
    scanf("%d", &a);   //读入数据
    if(a < 53)            //判断第一个条件
        printf("Too close!\n");
    else if(a == 53)   //判断第二个条件
        printf("Bingo!\n");
    else if(a > 53)       //判断第三个条件
        printf("Too far!\n");
    return 0;
}
```

## E 搬书

### 题目

#### 题目描述

搬书时，书被分成了若干堆，每堆的书的本数依次给出，最后一个数 $0$ 表示输入结束（ $0$ 不代表任何一堆）。

请求出这些书堆中书的总本数、书堆的个数，以及平均每堆的本数（整除）。

#### 输入格式

若干个整数，最后一个数为 $0$ 。

#### 输出格式

一行三个整数，依次为书的总本数、书堆个数、平均每堆本数，用空格分隔。

#### 样例输入

```text
10 20 30 0
```

#### 样例输出

```text
60 3 20
```

### 答案

### 题目分析

本题涉及主要考点是输入输出语句，和 while 循环语句，由 $PPT$ 例题"1-8"改编而来.

由于这里我们无法提前预知一共有多少行输入，因此尽量不要使用 for 循环语句，用 while 循环更佳。

首先，设置三个变量： sum , num , a 分别用来存储书籍总数，书堆个数，某一个书堆中的书籍本数。

接着，先读入一个 a ，使其具有非 0 的数值，才能成功进入开始 while 循环；在循环中不断累加 sum 和 num ；循环最后再次读入 a 更新书堆中的书本个数。

最后，按顺序输出所求变量。

### 示例代码

```c
#include<stdio.h>
int a,sum,num;
int main()
{
    scanf("%d",&a);
    while(a!=0)
    {
        num++;
        sum+=a;
        scanf("%d",&a);
    }
    printf("%d %d %d",sum,num,sum/num);
    return 0;
}
```

## F 不要迟到了

### 题目

#### 题目描述

某同学必须在当天 18:55 之前到达教室。他需要先花 3 分钟倒垃圾，再走完 $s$ 米的路程，速度为每分钟 $v$ 米，路程所需时间向上取整。

请求出他最晚应该在几点几分出发（出发时间一定在当天 00:00 之后）。

#### 输入格式

一行两个正整数 $s, v$ 。

#### 输出格式

一行，格式为 `hh:mm` ，时、分各占两位，不足补前导零。

#### 样例输入

```text
1000 100
```

#### 样例输出

```text
18:42
```

### 答案

### 题目分析

由题目中数据范围可以知道出发时间一定在当天00:00之后，因此考虑从00:00开始所经过的分钟数。

从00:00->18:55需要18*60+55=1135分钟，其中有三分钟需要倒垃圾，有 $s/v$ 并向上取整分钟用来赶路，而向上取整的计算方式为 $(s+v-1)/v$，因此出发时间距离00:00的分钟数为 $mins = 1135-3-(s+v-1)/v$，对应的 $h = mins/60, m = mins\%60$。

### 示例代码

```c
#include <stdio.h>

int main()
{
    int s,v;
    scanf("%d%d",&s,&v);
    int tot=1135-3-(s+v-1)/v;
    printf("%02d:%02d",tot/60,tot%60);
}
```

## G 打印字符

### 题目

#### 题目描述

给定正整数 $n$ ，请输出三行字符：

- 第一行先输出一个空格，再输出 $n - 2$ 个 `*` ；
- 第二行输出 $n$ 个 `*` ；
- 第三行与第一行相同。

#### 输入格式

一行一个正整数 $n$ 。

#### 输出格式

按上述规则输出的三行字符。

#### 样例输入

```text
5
```

#### 样例输出

```text
 ***
*****
 ***
```

### 答案

### 题目分析

本题考查如何使用循环语句。注意输出的第一行和第三行左侧有一个空格。

### 示例代码

#### 使用 for 循环

```c
#include<stdio.h>
int main()
{
    int n, i;
    scanf("%d", &n);
    printf(" ");
    for (i = 1; i <= n-2; i++)
        printf("*");
    printf("\n");//第一行输出结束
    for (i = 1; i <= n; i++)
        printf("*");
    printf("\n");//第二行输出结束
    printf(" ");
    for (i = 1; i <= n-2; i++)
        printf("*");
    printf("\n");//第三行输出结束
    return 0;
}
```

#### 使用 while 循环

```c
#include<stdio.h>
int main()
{
    int n, i;
    scanf("%d", &n);
    i = 1;
    printf(" ");
    while (i <= n - 2) {
        printf("*");
        i++;
    }
    printf("\n");//第一行输出结束
    i = 1;
    while (i <= n) {
        printf("*");
        i++;
    }
    printf("\n");//第二行输出结束
    i = 1;
    printf(" ");
    while (i <= n-2) {
        printf("*");
        i++;
    }
    printf("\n");//第三行输出结束
    return 0;
}
```

## H 最大公约数x3

### 题目

#### 题目描述

给定三个正整数 $a, b, c$ ，求它们的最大公约数。

#### 输入格式

一行三个正整数 $a, b, c$ 。

#### 输出格式

一行一个整数，为它们的最大公约数。

#### 样例输入

```text
12 18 24
```

#### 样例输出

```text
6
```

### 答案

### 题目分析

求三个数字的最大公约数。

不妨设 $mx = max(a,b,c)$，最暴力的想法就是从 $mx$ 开始向下枚举，一直枚举到 $1$，如果出现某个枚举项 $i$，使得 $a\%i == 0 \&\& b\%i == 0 \&\& c\%i == 0$，那么 $i$ 就是我们所求的最大公约数

更快速的方法可以考虑辗转相减法/辗转相除法来计算最大公约数，计算三个数的最大公约数，可以先取两个数字，计算出他们的 $gcd$，再将这个 $gcd$ 与第三个数字求 $gcd$ 既可。

枚举法可以如下所示：

```c
// gcd最初为a,b,c中最大的数字
while(gcd>=1){
    if(a%gcd==0&&b%gcd==0&&c%gcd==0)break;
    gcd--;
}
```

辗转相除法：

引理： $gcd(a,b) = gcd(b, a\%b)$

则我们可以写出如下代码来计算两个数字的最大公约数：

```c
int a,b,gcd;
while(a&&b){
    int tmp_a=b;
    int tmp_b=a%b;
    a=tmp_a;
    b=tmp_b;
}
if(a==0)gcd=b;
else gcd=a;
```

### 示例代码

```c
#include<stdio.h>
#include<string.h>
#include<stdlib.h>

int main(){
    int a,b,c;
    scanf("%d%d%d",&a,&b,&c);
    int gcd=a;
    if(gcd<b)gcd=b;
    if(gcd<c)gcd=c;
    while(gcd>=1){
        if(a%gcd==0&&b%gcd==0&&c%gcd==0)break;
        gcd--;
    }
    printf("%d",gcd);
    return 0;
}
```

## I 错误发生（Error Hassei）

### 题目

#### 题目描述

给定两个整数 $x, y$ 。

- 若 $y \ne 0$ ，输出 $x$ 除以 $y$ 向上取整的结果，即 $\left\lceil \frac{x}{y} \right\rceil$ ；
- 若 $y = 0$ ，则连续输出 $x$ 行 `Error Hassei` ，最后再输出一行 `System Breakdown` 。

#### 输入格式

一行两个整数 $x, y$ 。

#### 输出格式

按上述规则输出。

#### 样例输入

```text
3 0
```

#### 样例输出

```text
Error Hassei
Error Hassei
Error Hassei
System Breakdown
```

### 答案

### 题目分析

完成本题前，需要熟悉以下知识点：

- 如何定义 int 变量，并且如何输入？
- 如何使用判断语句？
- 如何使用循环语句？
- 如何输入字符串？
- 如何输出一个整数？

<!-- markdownlint-disable-next-line MD026 -->
#### 如何求上取整？

我们知道，两个 int 类型的整数 x 和 y 通过 x/y 即为下取整；

于是，不难证明， (x+y-1)/y 即是 x 除以 y 的上取整。

如以下代码可以计算 $2$ 除以 $3$ 的上取整：

```c
#include <stdio.h>
int main(){
    int x = 2, y = 3;
    printf("%d", (x+y-1)/y);
}
```

<!-- markdownlint-disable-next-line MD026 -->
#### 如何输出多行？

通过循环控制和换行符 '\n' ，如以下代码可以输出 $100$ 行 Darling ：

```c
#include <stdio.h>
int main(){
    for(int i = 0;i < 100;i++) printf("Darling\n");
}
```

### 示例代码

```c
#include<stdio.h>

int main() {
    // 第一步：定义变量 x、y，然后输入
    int x, y;
    scanf("%d%d", &x, &y);

    // 第二步：判断语句，判断 y 是否为 0，以此执行不同命令
    if (y != 0) {
        // 输出整数（x 除以 y 的上取整）
        printf("%d", (x + y - 1) / y);
    }
    else {
        // 循环语句：循环 x 次，每次输出一个字符串
        for (int i = 0;i < x;i++) {
            printf("Error Hassei\n");
        }
        printf("System Breakdown");
    }
}
```

## J 繁琐的识别mini

### 题目

#### 题目描述

输入是一幅 5 行的字符画，由字符 `x` 和空格组成，横向依次画出了若干个字符，组成一个只含整数、`+` 与 `-` 的算式。

每个字符的画法满足：

- 数字 `1` 只占 1 列，即一列 5 个 `x` ；
- `+` 占 3 列，恰有 3 行在这 3 列里出现 `x` ；
- `-` 占 3 列，恰有 1 行在这 3 列里出现 `x` ；
- 其余数字占 3 列，且 5 行都在这 3 列里出现 `x` 。

字符之间可以有空列。对于占 3 列、5 行都有 `x` 的数字，先数出这 15 个位置中 `x` 的总数：

| `x` 的总数 | 9 | 7 | 13 |
| --- | --- | --- | --- |
| 数字 | 4 | 7 | 8 |

总数为 12 时，看第 2 行的最右列与第 4 行的最左列：两处都是 `x` 则为 `0` ，只有第 4 行最左列是 `x` 则为 `6` ，只有第 2 行最右列是 `x` 则为 `9` 。

总数为 11 时，同样看这两处：两处都是 `x` 则为 `2` ，只有第 2 行最右列是 `x` 则为 `3` ，两处都不是 `x` 则为 `5` 。

请识别出算式并计算它的值。

#### 输入格式

5 行，每行一个由 `x` 与空格组成的字符串。

#### 输出格式

一行一个整数，为算式的值。

#### 样例输入

```text
x ... xxx
x .x. ..x
x xxx xxx
x .x. x..
x ... xxx
```

#### 样例输出

```text
3
```

### 答案

### 题目分析

识别并计算由字符 x 组成的表达式。

步骤：

1. 按照空列把每个字符分开。
2. 逐一比对每一段是哪个字符，并写出表达式。(慢慢写就行)
3. 按照加号和减号分开，然后加起来。

### 示例代码

```c
#include <math.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#define LL long long
#define min(a, b) (a > b ? b : a)
#define max(a, b) (a < b ? b : a)

char s[10][200]; //map
int count[200]; //number of x on each rows

int c2[20] = {0, 5, 0, 0, 9, 0, 0, 7, 13};

int main() {
    for (int i = 1; i <= 5; i++) //input
        if (gets(s[i]) > 0);

    for (int i = 1; i <= 5; i++)
        for (int j = 0; j <= 160; j++)
            if (s[i][j] == 'x')
                count[j]++;

    int l = 0, u; //left;up

    char formula[50] = {};
    int top_of_formula = 0;
    while (l <= 160) {
        if (count[l] == 0) { //no match
            l += 1;
            continue;
        }
        if (count[l + 1]) {
            int total = 0;
            for (int i = 0; i <= 2; i++)
                total += count[l + i];
            int line[10] = {}, line_with_sth = 0;
            for (int i = 1; i <= 5; i++)
                for (int j = 0; j <= 2; j++)
                    line[i] += (s[i][j + l] == 'x');
            for (int i = 1; i <= 5; i++)
                line_with_sth += (line[i] != 0);
            for (int i = 1; i <= 5; i++) {
                if (line[i] > 0) {
                    u = i;
                    break;
                }
            }

            int this_char = 0;
            if (line_with_sth == 1) {
                this_char = '-';
            }
            if (line_with_sth == 3) {
                this_char = '+';
            }
            if (line_with_sth == 5)
                for (int i = 1; i <= 9; i++)
                    if (total == c2[i])
                        this_char = i + 48;
            if (this_char == 0) {
                char ur = s[u + 1][l + 2];
                char lb = s[u + 3][l];
                if (total == 12) {
                    int tmp = 2 * (ur == 'x') + (lb == 'x');
                    if (tmp == 1) this_char = '6';
                    if (tmp == 2) this_char = '9';
                    if (tmp == 3) this_char = '0';
                }
                if (total == 11) {
                    int tmp = (ur == 'x') + (lb == 'x');
                    if (tmp == 0) this_char = '5';
                    if (tmp == 1) this_char = '3';
                    if (tmp == 2) this_char = '2';
                }
            }
            formula[++top_of_formula] = this_char;
            l += 3;
            continue;
        }
        if (count[l + 1] == 0) {
            formula[++top_of_formula] = 49;
            l += 1;
            continue;
        }
    }

    LL ans = 0, cur = 0, sgn = 1; //caculate

    for (int i = 1; i <= 49; i++) {
        if (formula[i] == 0) break;
        if (formula[i] == '+') ans += sgn * cur, cur = 0, sgn = 1;
        else if (formula[i] == '-') ans += sgn * cur, cur = 0, sgn = -1;
        else cur = cur * 10 + formula[i] - 48;
    }
    ans += sgn * cur, cur = 0, sgn = 1;
    printf("%lld", ans);

    return 0;
}
```
