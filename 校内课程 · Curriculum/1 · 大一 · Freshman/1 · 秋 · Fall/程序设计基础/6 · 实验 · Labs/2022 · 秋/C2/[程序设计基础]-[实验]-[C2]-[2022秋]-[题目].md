## A 喵喵喵？

### 题目

#### 题目描述

读入若干个字符直到输入结束，把这些字符的 ASCII 码累加起来得到 $sum$ ，然后按下面的规则输出：

- 若 $sum = 107$ ，输出 `Goldenglow!` ；
- 否则若 $sum$ 等于 `d` 、 `o` 、 `g` 三个字符的 ASCII 码之和，输出 `You, you and you` ；
- 否则若 $sum \ge 2022$ ，输出 `Jellyfish Food` ；
- 否则输出 $sum$ 本身。

#### 输入格式

若干个字符，读到文件结束为止（不含换行符）。

#### 输出格式

一行，按上述规则输出的字符串或整数。

#### 样例输入

```text
aaaaaaaaaaaaaaaaaaaaa
```

#### 样例输出

```text
Jellyfish Food
```

## B 蛋糕店打工

### 题目

#### 题目描述

蛋糕店有 $n$ 个品牌，第 $i$ 个品牌今天的营业额为 $s_i$ 。

现在有 $m$ 次询问，每次给出两个品牌序号 $a, b$ ，请求出这两个品牌营业额之和。

#### 输入格式

第一行两个正整数 $n, m$ 。

第二行 $n$ 个整数，依次为各品牌的营业额。

接下来 $m$ 行，每行两个正整数 $a, b$ 。

#### 输出格式

共 $m$ 行，每行一个整数，为 $s_a + s_b$ 。

#### 样例输入

```text
3 2
10 20 30
1 2
3 3
```

#### 样例输出

```text
30
60
```

#### 数据范围

- 营业额与营业额之和都可能超出 `int` 范围，需要用 `long long`

## C 星幽测试

### 题目

#### 题目描述

星幽对 $N$ 个人进行测试，第 $i$ 个人的能力值为 $x_i$ 。

请求出下面四个统计值：

1. 全部 $N$ 个人能力值的**整均值**，即平均值向上取整；
2. **非方差**，即 $\frac{1}{N}\sum_{i=1}^{N}(x_i - \mathrm{ave})^2$ 的整数部分，其中 $\mathrm{ave}$ 是上面的整均值；
3. 能力值**大于**整均值的人数；
4. 前 $K$ 个人能力值的整均值（同样向上取整）。

#### 输入格式

第一行两个正整数 $N, K$ 。

第二行 $N$ 个整数，依次为各人的能力值。

#### 输出格式

一行四个整数，依次为整均值、非方差、大于整均值的人数、前 $K$ 人的整均值，用空格分隔。

#### 样例输入

```text
5 3
1 2 3 4 5
```

#### 样例输出

```text
3 2 2 2
```

## E Double数

### 题目

#### 题目描述

若一个正整数 $w$ 可以由某个正整数（称为 Single 数）与它的两倍拼接而成，则称 $w$ 为 Double 数。

例如 $48$ 由 $4$ 与 $8$ 拼接而成，而 $8 = 2 \times 4$ ，所以 $48$ 是 Double 数。

给定 $w$ ，判断它是不是 Double 数：设 $w$ 的位数为 $cnt$ ，取 $low = \left\lceil \frac{cnt}{2} \right\rceil$ ， $base = 10^{low}$ ，则前一半为 $single = \left\lfloor w / base \right\rfloor$ ，后一半为 $single_2 = w \bmod base$ 。若 $2 \times single = single_2$ ，则 $w$ 是 Double 数。

#### 输入格式

一行一个正整数 $w$ 。

#### 输出格式

若 $w$ 是 Double 数，先输出一行 `Double` ，再输出一行 Single 数的值；否则先输出一行 `Single` ，再输出一行把 $w$ 与 $2w$ 直接拼接得到的数。

#### 样例输入

```text
48
```

#### 样例输出

```text
Double
4
```

## F ljh算算数

ljh 要检验一批算式。每个算式的格式为 `x c y=` ，其中 $x, y$ 是整数， $c$ 是 `+` 、 `-` 、 `*` 、 `/` 、 `%` 五种运算符之一。

对每个算式，输出完整的等式与计算结果（除法与取模都是整数运算）。若出现除以 0 或对 0 取模，则输出一行 `Runtime Error` 。

#### 输入格式

若干个形如 `x c y=` 的算式，读到文件结束为止。

#### 输出格式

对每个算式输出一行：等式与结果，或 `Runtime Error` 。

#### 样例输入

```text
1+2=3*4=5/0=7%3=
```

#### 样例输出

```text
1+2=3
3*4=12
Runtime Error
7%3=1
```

## G 一元二次方程的求解

### 题目

#### 题目描述

给定方程 $Ax^2 + Bx + C = 0$ 的三个系数（可以是任意实数），求解该方程：

- 若 $A = 0$ 且 $B = 0$ 且 $C = 0$ ，方程有无穷多组解，输出 `+inf!` ；
- 若方程无解，输出 `No Solution!` ；
- 若方程有唯一解，输出该解；
- 若方程有两个不同的解，按从小到大的顺序输出这两个解。

所有实数输出均保留 2 位小数。

#### 输入格式

一行三个实数 $A, B, C$ 。

#### 输出格式

按上述规则输出。

#### 样例输入

```text
1 -3 2
```

#### 样例输出

```text
1.00 2.00
```

## H 名次预测大比拼

### 题目

#### 题目描述

共有 $m$ 位选手参加比赛， $n$ 位助教分别预测了每位选手的名次。第 $i$ 位助教给出的第 $i$ 个预测值记为第 $i$ 题的答案。

按下面的规则为每位助教计分（逐题判断， $i$ 从 1 到 $m$ ， $rank$ 为该助教对第 $i$ 题的预测）：

- 若 $rank = i$ ，得 3 分，且该题算预测正确；
- 否则若 $rank \le 0$ ，扣 1 分；
- 否则若 $rank \bmod m = i$ ，或者 $rank \bmod m = 0$ 且 $i = m$ ，得 1 分，且该题算预测正确；
- 其余情况不得分也不扣分。

若某位助教的总分为负，则按 0 分计。

请求出所有助教中的最高分与最低分，以及预测正确题数最多的助教答对了多少题（记为 $num$ ），并输出评价：

- 若 $num = m$ ，输出 `YES!` ；
- 否则若 $num \ge \lfloor m/2 \rfloor$ ，输出 `Good!` ；
- 否则若 $num > 0$ ，输出 `Not bad!` ；
- 否则输出 `NO~` 。

#### 输入格式

第一行两个正整数 $n, m$ 。

接下来 $n$ 行，每行 $m$ 个整数，为一位助教对 $m$ 道题的预测。

#### 输出格式

第一行两个整数，为最高分与最低分，用空格分隔。

第二行为评价字符串。

#### 样例输入

```text
2 4
1 2 3 4
0 0 0 0
```

#### 样例输出

```text
12 0
YES!
```

## J 作业调度

### 题目

#### 题目描述

采用先来先服务（FCFS）的方式调度作业。每个作业给出到达时间 $a$ 与运行时间 $b$ ，按到达顺序依次处理：

- 若该作业的到达时间早于或等于上一个作业的完成时间，则它立刻开始执行，开始时间等于上一个作业的完成时间；
- 否则它等到到达时间才开始执行。

作业的完成时间等于开始时间加上运行时间，周转时间等于完成时间减去到达时间。

请求出所有作业的平均周转时间。

#### 输入格式

若干行，每行两个整数 $a, b$ ，分别为一个作业的到达时间与运行时间；当到达时间为 $-1$ 时输入结束。

#### 输出格式

一行一个实数，为平均周转时间，保留 2 位小数。

#### 样例输入

```text
0 3 2 4 -1
```

#### 样例输出

```text
4.00
```
