# 理科数学分析(1) 第6章作业题目（2023秋）

> 题目为伍胜健《数学分析》习题六全部题目，**加粗**的是实际布置的作业题。

## 习题六

### 习题六-1

证明：若 $\int f(x)\mathrm{d}x = F(x) + C$，则
$$\int f(ax + b)\mathrm{d}x = \frac{1}{a}F(ax + b) + C \quad (a \neq 0).$$

### **习题六-2**

求下列不定积分：

**(1)** $\int (\sqrt{2x} + \sqrt[3]{3x})\mathrm{d}x$;

**(2)** $\int \left(1 + \frac{1}{x^2}\sqrt{x\sqrt{x}}\right)\mathrm{d}x$;

**(3)** $\int \left(3^{x+1} + 3^{-x} + \frac{1}{3}\mathrm{e}^x\right)\mathrm{d}x$;

**(4)** $\int \frac{2 - \sin^2 x}{\cos^2 x}\mathrm{d}x$;

**(5)** $\int \left(\sqrt{\frac{1 + x}{1 - x}} + \sqrt{\frac{1 - x}{1 + x}}\right)\mathrm{d}x$;

**(6)** $\int \frac{\cos 2x}{\cos^2 x \sin^2 x}\mathrm{d}x$;

**(7)** $\int \sqrt{1 - \sin 2x}\mathrm{d}x$;

**(8)** $\int (x + |x|)\mathrm{d}x$;

**(9)** $\int \operatorname{sgn}(\sin x)\mathrm{d}x$;

**(10)** $\int [x]\mathrm{d}x$.

### **习题六-3**

用换元法求下列不定积分：

**(1)** $\int \frac{2\mathrm{d}x}{3 - 5x}$;

**(2)** $\int \frac{\mathrm{d}x}{\sqrt{2 - x^2}}$;

**(3)** $\int x\sqrt[3]{1 - 3x}\mathrm{d}x$;

**(4)** $\int \frac{\mathrm{d}x}{1 + \sin x}$;

**(5)** $\int x(1 + x^2)^5\mathrm{d}x$;

**(6)** $\int \frac{x\mathrm{d}x}{\sqrt{1 - x^2}}$;

**(7)** $\int \frac{x\mathrm{d}x}{4 + x^4}$;

**(8)** $\int \frac{\mathrm{e}^x}{1 + \mathrm{e}^x}\mathrm{d}x$;

**(9)** $\int \frac{\mathrm{d}x}{\sqrt{x}(1 + x)}$;

**(10)** $\int \frac{\mathrm{d}x}{x\sqrt{x^2 - 1}}$;

**(11)** $\int \sin x \sin 3x\mathrm{d}x$;

**(12)** $\int \sin^2 x \cos^2 x\mathrm{d}x$;

**(13)** $\int \frac{\sin 2x}{\sqrt{1 + \sin^2 x}}\mathrm{d}x$;

**(14)** $\int \frac{\sin x \cos x}{\sqrt{a^2 \sin^2 x + b^2 \cos^2 x}}\mathrm{d}x (a^2 > b^2)$;

**(15)** $\int \frac{\sqrt{a^2 - x^2}}{x}\mathrm{d}x$;

**(16)** $\int \frac{\mathrm{d}x}{x^2\sqrt{1 + x^2}}$;

**(17)** $\int \frac{\mathrm{d}x}{\sqrt{(a^2 + x^2)^3}}$;

**(18)** $\int \frac{x}{1 + \sqrt{x}}\mathrm{d}x$;

**(19)** $\int \sqrt{\frac{2 + x}{2 - x}}\mathrm{d}x$;

**(20)** $\int \frac{\mathrm{d}x}{x\sqrt{4 - x^2}}$.

### **习题六-4**

用分部积分法求下列不定积分：

**(1)** $\int \ln(1 + x^2)\mathrm{d}x$;

**(2)** $\int x\mathrm{e}^{-3x}\mathrm{d}x$;

**(3)** $\int x \cos nx\mathrm{d}x$;

**(4)** $\int \arcsin x\mathrm{d}x$;

**(5)** $\int \frac{x}{\sin^2 x}\mathrm{d}x$;

**(6)** $\int \frac{\arctan x}{x^2(1 + x^2)}\mathrm{d}x$;

**(7)** $\int \frac{\mathrm{e}^{\arctan x}}{(1+x^2)^{3/2}} \mathrm{d}x$;

**(8)** $\int \frac{x^2}{(1+x^2)^2} \mathrm{d}x$;

**(9)** $\int \sin(\ln x)\mathrm{d}x$;

**(10)** $\int \mathrm{e}^x \cos^2 x \mathrm{d}x$.

### **习题六-5**

对下列不定积分建立递推公式:

**(1)** $I_n = \int x^m \ln^n x \mathrm{d}x$;

**(2)** $I_n = \int x^n \mathrm{e}^{-x} \mathrm{d}x$;

**(3)** $I_n = \int \frac{x^n}{\sqrt{1-x^2}} \mathrm{d}x$;

(4) $I_n = \int \frac{\mathrm{d}x}{x^n \sqrt{1+x^2}}$.

### **习题六-6**

求下列有理函数的不定积分:

**(1)** $\int \frac{2x}{(x-1)(x+1)^2} \mathrm{d}x$;

**(2)** $\int \frac{2x^2+2x+13}{(x-2)(1+x^2)^2} \mathrm{d}x$;

**(3)** $\int \frac{x^2-x+1}{2x+1} \mathrm{d}x$;

**(4)** $\int \frac{3x+5}{(x^2+2x+2)^2} \mathrm{d}x$;

**(5)** $\int \frac{x+1}{x^3+2x^2-x-2} \mathrm{d}x$;

**(6)** $\int \frac{\mathrm{d}x}{x(x^3+2)}$;

**(7)** $\int \frac{\mathrm{d}x}{(x-2)^2(x+3)^3}$;

**(8)** $\int \frac{x\mathrm{d}x}{x^3-1}$.

### **习题六-7**

求下列三角函数有理式的不定积分:

**(1)** $\int \frac{\mathrm{d}x}{\sin^2 x \cos x}$;

**(2)** $\int \frac{\mathrm{d}x}{\cos^2 x \sin x}$;

**(3)** $\int \frac{\sin 2x}{1+\cos^2 x} \mathrm{d}x$;

**(4)** $\int \sin 5x \sin 3x \mathrm{d}x$;

**(5)** $\int \frac{\sin^2 x}{1+\cos^2 x} \mathrm{d}x$;

**(6)** $\int \frac{\sin^5 x \mathrm{d}x}{\cos^4 x}$;

**(7)** $\int \frac{1}{1+\cos x} \mathrm{d}x$;

**(8)** $\int \frac{1+\sin x}{1-\sin x} \mathrm{d}x$;

**(9)** $\int \frac{\sin x}{a\sin x + b\cos x} \mathrm{d}x$;

**(10)** $\int \frac{\sin x \mathrm{d}x}{\sin x - \cos x + 2}$.

### **习题六-8**

求下列无理函数的不定积分:

**(1)** $\int \frac{\sqrt{x}}{\sqrt[4]{x^3} + 1}\mathrm{d}x$;

**(2)** $\int \frac{\mathrm{d}x}{1 + \sqrt{x} + \sqrt{x + 1}}$;

**(3)** $\int \frac{\mathrm{d}x}{x^4\sqrt{1 - x^2}}$;

**(4)** $\int \frac{\mathrm{d}x}{x\sqrt{x^2 + x + 1}}$;

**(5)** $\int \frac{\mathrm{d}x}{(x + 1)\sqrt{x^2 + 4x + 5}}$;

**(6)** $\int \frac{\mathrm{d}x}{x + \sqrt{x^2 + x + 1}}$;

**(7)** $\int \sqrt{\frac{1 - x}{1 + x}}\mathrm{d}x$;

**(8)** $\int \frac{\mathrm{d}x}{x\sqrt{4 - x^2}}$;

**(9)** $\int \sqrt{\tan x}\mathrm{d}x$;

**(10)** $\int \sqrt[3]{\frac{2 - x}{2 + x}}\cdot \frac{\mathrm{d}x}{(2 - x)^2}$.
