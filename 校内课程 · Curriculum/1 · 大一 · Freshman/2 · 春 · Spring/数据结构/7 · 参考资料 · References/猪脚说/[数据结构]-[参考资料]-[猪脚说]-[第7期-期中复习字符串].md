<h3 id='id_1'>第一次作业</h3>

- 1.表达式计算——去除空格

  ```c
  //将s1中空格删去，所得结果保存到s2中
   int i, j = 0;
   for(i = 0; s1[i] != '\0'; i++) {
    if(s1[i] != ' ')
    {
     s2[j++] = s1[i];
    }
   }
   s2[j] = '\0';
  ```

  图示为一种可能的写法；**需要强调的是，要注意最后一行代码，即给s2手动加上终止符，防止无效内容干扰后续操作**。

<h3 id='id_2'>第二次作业</h3>

- 2.字符串替换——字符串的替换操作

  本题可以在读入的同时进行替换操作，也可以全部读入后进行替换。以下为全部读入后进行替换的代码示例：

  ```c
  //originStr需要被替换为newStr，s1为原字符串，替换后的结果保存到s2
   //char s2[100] = {0};
   int s2Len = 0;//记录s2当前的长度
   int newLen = strlen(newStr);//newStr的长度
   for(i=0; s1[i] != '\0'; i++){
    //判断s1从当前位置i开始的子串是否与originStr相同
    for(j = 0, k = i; originStr[j] != '\0' && originStr[j] == s1[k]; j++,k++) ;
    //相同则替换
    if(originStr[j] == '\0'){
     strcat(s2, newStr);
     s2Len += newLen;//更新s2长度
     i += newLen - 1;//更新下次循环起始位置
    }
    else s2[s2Len++] = s1[i];//不同则直接复制到s2
   }
   s2[s2Len] = '\0';
  ```

  以上只是一种可能的实现方式；**同样需要注意的是最后一行代码**。

- 5.小型图书管理系统——字符串查找

  int index(char s1[], char s2[])

- 4.文本编辑操作模拟——子串的插入与删除

  关键点：进行操作时要考虑原字符串中字符位置的移动

  子串的删除：

  ```c
  //对字符串s1，以index为起始位置，删除长度为length的子串
   int i;
   for(i = 0; s1[i + index + length] != '\0'; i++) 
    s1[i + index] = s1[i+index+length];
   s1[i + index] = '\0';
  ```

  子串的插入：

  ```c
  //对字符串s1，以index为起始位置，插入子串s2
   int i;
   int s1Len = strlen(s1);
   int s2Len = strlen(s2);
   for(i = s1Len; i >= index; i--) 
    s1[i + s2Len] = s1[i];//此处从s1Len开始，直接完成了终止符的设置
   for(i=0; i<s2Len; i++)
    s1[i+index] = s2[i];
  ```

  以上为一种可行的实现方式；无论使用何种方式，始终注意**所得结果是否有合理的终止符**。

<h3 id='id_5'>其他常见问题</h3>

- 关于strcmp——**判断返回结果时应使用大于、等于、或小于0三种判断方式，而非特定非零值**。

- 关于strlen——**请勿在for循环条件中使用strlen！**这相当于每次循环前遍历了一次字符串，容易导致超时的问题。可行方式包括：

  **判断是否为终止符、在循环外使用strlen**等。

- 关于strcpy、strcat——注意字符串大小，是否有足够空间容纳等

- 关于其他不常用函数——strstr、strtol、strtok、sscanf等，值得尝试学习，但在考试中推荐使用能熟练使用的实现方式。相关知识可查看第六期猪脚说或是百度搜索进行了解，在此不再赘述。
