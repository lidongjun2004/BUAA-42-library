## 变量或数组未初始化就使用

C语言中, 未初始化的全局变量/数组将自动初始化为 `0` , 而未初始化的局部变量/数组存储"垃圾值"(这是由于局部变量在内存的"堆栈"上分配的原因, "堆栈"上的内存不会被自动清理, 因此会残留有上一个程序运行留下的"垃圾值"). 所以请养成**声明时就初始化**的良好习惯.

## `qsort` 函数使用不正确

`qsort` 函数声明如下:

```c
void qsort(
    void * base,                                // 数组首地址
    size_t numOfElements,                       // 数组元素个数
    size_t sizeOfElements,                      // 数组单个元素的大小
    int (*compare)(const void*, const void*)    // 比较函数(重难点)
);
```

前三个参数仅与数组本身有关, 对于一个元素类型为 `T` , 元素个数为 `n` 的数组 `array` , 前三个参数应当填入:

```c
qsort(array, n, sizeof(T), /* compare */);
```

第四个参数是一个函数, 它事实上是定义了一个顺序关系, 该函数接受两个参数:

* 如果返回正数, 则**认为**第一个参数"大于"第二个参数;
* 如果返回负数, 则**认为**第二个参数"小于"第二个参数;
* 如果返回零, 则**认为**两个参数"相等".

随后 `qsort` 将按照这个顺序关系, "从小到大"(这里有引号)排列元素.

下面举例说明, 如何编写比较函数:

```c
/* 定义 int 数组按照整数的单调递增顺序排列 */
int cmp_int_increase(const void *n1, const void *n2) {
    int a = *(int*)n1; // 第一个指针参数指向的整数
    int b = *(int*)n2; // 第二个指针参数指向的整数
    if (a < b) {
        return -1;
    } else if (a > b) {
        return 1;
    } else {
        return 0;
    }
}

/* 定义 int 数组按照整数的单调递减顺序排列 */
int cmp_int_decrease(const void *n1, const void *n2) {
    int a = *(int*)n1; // 第一个指针参数指向的整数
    int b = *(int*)n2; // 第二个指针参数指向的整数
    if (a > b) {
        return -1;
    } else if (a < b) {
        return 1;
    } else {
        return 0;
    }
}

typedef struct _student {
    char name[NAME_MAX];
    int  age;
} student;

/**
 * 定义 student 数组按照如下规范排序:
 * 1. 年龄不同的, 年龄较大者排在前面;
 * 2. 年龄相同的, 按名字的字典序排序.
 */
int cmp_stu(const void *n1, const void *n2) {
    student s1 = *(student*)n1;
    student s2 = *(student*)n2;
    if (s1.age != s2.age) {
        if (s1.age < s2.age) {
            return -1;
        } else {
            return 1;
        }
    } else {
        return strcmp(s1.name, s2.name);
    }
}
```

## 使用 `while` 循环时忘记 "自增"

有些同学遍历链表时采用 `while` 循环:

```c
node *p = head;
while (p != NULL) {
    // do something
}
```

忘记了对 `p` 进行后移操作 `p = p->next` , 建议同学们使用 `for` 循环完成类似的遍历, 书写 `for` 循环时不容易忘记后移:

```c
node *p;
for (p = head; p != NULL; p = p->next) {
    // do something
}
```

## 未开启文件后缀显示, 导致文件被命名为 "filein.txt.txt"

建议同学们在电脑设置中打开"显示文件后缀名".

## 文件操作不熟悉, 钟情于 `freopen`

本课程中很少会用到 `freopen` 进行文件操作. 请同学们使用 `fopen` , `fscanf` , `fprintf` 等文件操作函数进行文件操作!

## 读取数据时, 终结标识符的误用

`scanf` , `getchar` , `fscanf` , `fgetc` 读取到文件末尾(再也读不到数据了)时, 返回 `EOF` , 这是个 `int` 型的返回值;

`gets` , `fgets` 读取到文件末尾(再也读不到数据了), 返回 `NULL` , 这是个指针类型的返回值.

## 输出到记事本中, 观感与控制台不一致

有些同学发现同一段字符输出到文件, 与输出到控制台观感不一致, 那是**没有采用相同字体**的原因.

## 滥用 `malloc` 与 `free`

有同学在声明指针时, 立马 `malloc` , 但随后又让这个指针指向另一个地址, 这样声明时 `malloc` 得到的内存就遗失了(内存泄漏);

有同学对野指针/空指针进行 `free` 操作, 这将引发内存错误. `free` 前请确保该指针指向了你 `malloc` 的某片内存.
