## 二、基础知识

### 2.1 字符串（**期中考查重点**）

#### 三条铁律

1. **字符串必须以 `'\0'` 结尾**——任何修改字符串的操作后，确保末尾是 `'\0'`。
2. **数组要开够**——比字符串长度至少多 1（留给 `'\0'`）。
3. `**\r` 与 `\n` 都要小心**——Windows 是 `\r\n`，Linux 评测机是 `\n`。

#### 字符串库函数

```c
#include <string.h>

// ===== 长度 =====
size_t strlen(const char *s);
// 计算字符串长度（不含末尾 '\0'）。
// 例：strlen("hello") == 5
// 注意：返回值是 size_t（无符号），strlen(a) - strlen(b) 不会是负数！

// ===== 拷贝 =====
char *strcpy(char *dst, const char *src);
// 把 src（含 '\0'）拷贝到 dst，覆盖 dst 原有内容。
// 例：char s[20]; strcpy(s, "hello");  →  s 变成 "hello\0"
// 要求：① dst 空间足够大；② src 和 dst 内存不能重叠。

char *strncpy(char *dst, const char *src, size_t n);
// 最多拷贝 n 个字符。注意：如果 src 长度 ≥ n，**不会自动加 '\0'**！
// 安全写法：strncpy(dst, src, n - 1); dst[n - 1] = '\0';

// ===== 追加 =====
char *strcat(char *dst, const char *src);
// 把 src 接到 dst 末尾（会先去掉 dst 原本的 '\0'）。
// 例：char s[20] = "abc"; strcat(s, "def");  →  s = "abcdef"
// 要求：dst 必须有足够空间容纳 dst + src + '\0'。

char *strncat(char *dst, const char *src, size_t n);
// 最多追加 src 的前 n 个字符，自动加 '\0'。

// ===== 比较 =====
int strcmp(const char *s1, const char *s2);
// 按字典序比较 s1 和 s2，返回:
//   < 0  →  s1 < s2     （切记：不是固定 -1！）
//   == 0 →  s1 == s2
//   > 0  →  s1 > s2     （切记：不是固定 1！）
// 例：if (strcmp(a, b) == 0) ...    // 判断两串相等
//     if (strcmp(a, b) < 0)  ...    // 判断 a 字典序小于 b

int strncmp(const char *s1, const char *s2, size_t n);
// 只比较前 n 个字符。

// ===== 查找 =====
char *strstr(const char *s, const char *sub);
// 在 s 中查找子串 sub 第一次出现的位置。
// 找到 → 返回该位置的指针；找不到 → 返回 NULL。
// 例：char *p = strstr("hello world", "wor");  →  p 指向 "world..."

char *strchr(const char *s, int c);
// 在 s 中查找字符 c 第一次出现的位置。找不到返回 NULL。
// 例：char *p = strchr("hello", 'l');  →  p 指向第一个 'l'

char *strrchr(const char *s, int c);
// 同上，但找的是**最后一次**出现。

// ===== 内存操作（也常用）=====
void *memset(void *s, int c, size_t n);
// 把 s 开头的 n 个字节全部设成 c。
// **常用于数组清零**：memset(arr, 0, sizeof(arr));
// 注意：c 是按字节赋值！memset(int_arr, 1, sizeof) 不是把每个 int 设成 1，
// 而是把每个字节设成 1，得到 0x01010101 = 16843009。所以**只用来清 0**。

void *memcpy(void *dst, const void *src, size_t n);
// 拷贝 n 个字节。比 strcpy 更通用（不限于字符串）。
```

```c
#include <ctype.h>

// ===== 字符判断（返回 0 表示否，非 0 表示是） =====
int isalpha(int c);   // 是不是字母（a-z 或 A-Z）
int isdigit(int c);   // 是不是数字字符（'0'-'9'）
int isalnum(int c);   // 字母 或 数字
int islower(int c);   // 是不是小写字母
int isupper(int c);   // 是不是大写字母
int isspace(int c);   // 是不是空白字符（' ', '\t', '\n', '\r', '\v', '\f'）
int ispunct(int c);   // 是不是标点符号

// ===== 大小写转换 =====
int tolower(int c);   // 大写转小写；非大写字母原样返回
int toupper(int c);   // 小写转大写；非小写字母原样返回
// 例：char lower = tolower('A');  →  lower = 'a'
//     char same  = tolower('5');  →  same  = '5'  （数字不变）
```

```c
#include <stdlib.h>

// ===== 字符串 ↔ 数字 =====
int    atoi(const char *s);    // 字符串转 int，例：atoi("123") == 123
double atof(const char *s);    // 字符串转 double
long   atol(const char *s);    // 字符串转 long
// 注意：遇到非数字就停止；如果开头就不是数字，返回 0。
```

#### 高频易错点

- `strcmp` 返回 `> 0` / `0` / `< 0`，不是 `1 / 0 / -1`。永远写 `if (strcmp(a, b) > 0)`。
- `strlen` 返回的是 `**size_t`（无符号）**！`strlen(a) - strlen(b)` 永远不会是负数。
- `strcpy / strcat` 要求 `src` 和 `dst` **不能内存重叠**。
- 不要把 `strlen(s)` 写在循环条件里：

```c
// 错（O(n²)）
for (int i = 0; i < strlen(s); i++) ...

// 对
for (int i = 0, len = strlen(s); i < len; i++) ...
```

#### 字符串读取

| 方法 | 用途 | 注意 |
| --- | --- | --- |
| `scanf("%s", s)` | 读单词（无空格） | 自动跳过开头空白；遇空格结束 |
| `fgets(s, n, stdin)` | 读整行（含空格） | **会读入 `\n`**，必要时手动去掉 |
| `gets(s)` | ❌ 不要用（其实想用也行，我就经常用） | 不安全，会越界 |

```c
// fgets 去掉末尾的 \n
fgets(s, sizeof(s), stdin);
int len = strlen(s);
if (len > 0 && s[len - 1] == '\n') s[len - 1] = '\0';
```

#### 字符 ↔ 整数

```c
// 字符串 → 整数
int n = 0;
for (int i = 0; s[i]; i++)
    n = n * 10 + s[i] - '0';
// 或：int n = atoi(s);  // #include <stdlib.h>

// 数字字符 ↔ 整数
int d = '7' - '0';  // d = 7
char c = '0' + 5;   // c = '5'

// 大小写转换
char lower = c | 0x20;       // 大转小（位运算技巧，不强求）
char lower = c - 'A' + 'a';  // 大转小（常规）
```

### 2.2 数组与多维数组

#### 一维数组初始化（必须养成习惯）

```c
int a[100] = {0};       // 全 0
char s[100] = {0};      // 全 '\0'
int a[5] = {6, 5, 12};  // {6, 5, 12, 0, 0}
```

#### 二维数组的核心特性

- **本质**：二维数组是「以一维数组为元素的一维数组」。
- **存储**：**行优先连续存储**。
- **作为函数形参时，列数必须写**（行数可以省略）：

```c
void f(int a[][5], int row);  // ✅ 对
void f(int a[][], int row);   // ❌ 错
void f(int a[3][5], int row); // ✅ 对（但行数会被忽略）
```

#### 字符二维数组的隐藏坑

```c
char test[2][26];   // ❌ 26 个字母刚好放下，没有 '\0' 的位置
// printf("%s", test[0]) 会一直打印到 test[1] 里！
// 修正：开 [2][27]，或者每行最后一位手动留 '\0'
```

### 2.3 指针

#### 关键运算符

- `&` 取地址
- `*` 解引用
- `->` 等价 `(*p).member`

#### 几种容易混的「指针 vs 数组」

```c
int *p;             // 普通指针
int a[10];          // 数组
int *arr[10];       // 指针数组：装 10 个 int*
int (*p)[10];       // 数组指针：指向「长度为 10 的 int 数组」
int (*fp)(int);     // 函数指针
int *func(int);     // 返回 int* 的函数
```

**判别口诀**：先看括号，**括起来的是被修饰词**。

#### 指针运算

- `p + n` 偏移 `n × sizeof(*p)` 字节，不是 n 个字节。
- `(low + high) / 2` ❌ 可能溢出 → `low + (high - low) / 2` ✅
- `*p++` 等价 `*(p++)`：先取值，再 p 自增。
- `(*p)++`：取值后**对值加 1**。

#### 指针作为函数参数（实现 swap）

```c
void swap(int *a, int *b) {
    int t = *a; *a = *b; *b = t;
}
swap(&x, &y);  // 调用要传地址
```

#### 字符串常量 vs 字符数组

```c
char *p = "hello";  // p 指向只读区，p[0] = 'X' 会段错误！
char s[] = "hello"; // s 是数组，s[0] = 'X' 没问题
```

#### 动态内存

```c
#include <stdlib.h>

T *p = (T *)malloc(sizeof(T));
T *p = (T *)malloc(n * sizeof(T));
free(p);
// 注意：
// 1. malloc 后内容是脏的
// 2. free 后不能再访问；同一指针不能 free 两次
// 3. free(NULL) 安全
```

### 2.4 结构体（链表的基础）

#### 三种声明形式

```c
// 1. 有名结构体
struct Date { int day, month, year; };
struct Date d1, d2;

// 2. typedef 起别名（推荐）
typedef struct {
    int day, month, year;
} Date;
Date d1, d2;

// 3. 自引用结构体（链表必备）
typedef struct node {
    int data;
    struct node *next;       // 必须用 struct node *，不能用别名
} Node, *Nodeptr;
```

> ⚠ 自引用结构内部不能放本身（`struct node next;` ❌），只能放**指向自身的指针**。

#### 访问成员

```c
Date d, *pd;
d.year = 2026;        // 用 .
pd = &d;
pd->year = 2026;      // 指针用 ->，等价于 (*pd).year
```

### 2.5 qsort

```c
#include <stdlib.h>
void qsort(void *base, size_t n, size_t size, int (*cmp)(const void *, const void *));
```

**cmp 返回值**：

- 返回 **< 0**：a 排在 b 前面（升序时 a < b）
- 返回 **> 0**：a 排在 b 后面
- 返回 **0**：顺序不定

**模板**：

```c
// 整型升序
int cmp_int(const void *a, const void *b) {
    int x = *(int*)a, y = *(int*)b;
    return (x > y) - (x < y);   // 安全做差，避免溢出
}
qsort(arr, n, sizeof(int), cmp_int);

// 结构体单关键字
int cmp_stu(const void *a, const void *b) {
    Student *x = (Student*)a, *y = (Student*)b;
    return x->score - y->score;
}

// 多关键字（先 name 升序，name 相同按 score 降序）
int cmp_multi(const void *a, const void *b) {
    Student *x = (Student*)a, *y = (Student*)b;
    int r = strcmp(x->name, y->name);
    if (r != 0) return r;
    return y->score - x->score;
}
```

**易错**：`(Student*)p1->id` ❌（`->` 优先级高于强转），必须写 `((Student*)p1)->id` ✅。

**对二维数组排序**：

```c
int arr[100][6];
int cmp(const void *a, const void *b) {
    int (*x)[6] = (int(*)[6])a;
    int (*y)[6] = (int(*)[6])b;
    return (*x)[0] - (*y)[0];
}
qsort(arr, 100, sizeof(int) * 6, cmp);
```

## 三、线性表常见操作

### 3.1 顺序存储 vs 链式存储

| 维度 | 顺序存储（数组） | 链式存储（链表） |
| --- | --- | --- |
| 是否需要连续空间 | 是 | 否 |
| 大小是否固定 | 是（事先分配） | 否（动态申请） |
| 按下标访问 | **O(1)** | O(n) |
| 顺序查找 | O(n) | O(n) |
| **折半查找** | **O(log n)（必须有序）** | 不能用 |
| 插入/删除 | **O(n)**（要移动元素） | **O(1)**（已知前驱） |

**结论**：

- 频繁查找、规模已知 → 用数组
- 频繁增删、规模不定（如词频统计、多项式） → 用链表

### 3.2 顺序表平均移动次数

| 操作 | 平均次数 |
| --- | --- |
| 插入第 i 个位置 | **n / 2** |
| 删除第 i 个元素 | **(n - 1) / 2** |

### 3.3 链表三大基本操作（**必须会画图！**）

#### 节点定义

```c
typedef struct node {
    int data;
    struct node *next;
} Node, *Nodeptr;
```

#### 操作 ①：插入（在 p 后插入新结点 q）

```text
插入前：  ... → p → next → ...

q->next = p->next;   // ① 先让 q 接住 p 原本的下一个
p->next = q;         // ② 再让 p 指向 q

插入后：  ... → p → q → next → ...
```

> 顺序**不能颠倒**。如果先做 `p->next = q`，p 原来的 next 就丢了。

#### 操作 ②：删除（删除 p 的下一个结点）

```c
Node *q = p->next;       // 先保存
p->next = q->next;  
p->next = p->next->next     // p 跳过 q 
free(q);                 // 释放
```

> 同样：必须先保存 `q = p->next`，否则 free 完后再访问就崩了。

#### 操作 ③：遍历

```c
for (Node *p = list; p != NULL; p = p->next) {
    // 处理 p->data
}
```

### 3.4 哑结点（dummy node）

**带哑结点 vs 不带哑结点**：

```c
// 不带哑结点：删除头结点要特判
Node* deleteVal(Node *head, int v) {
    if (head == NULL) return head;
    if (head->data == v) {
        Node *t = head; head = head->next; free(t); return head;
    }
    for (Node *p = head; p->next; p = p->next)
        if (p->next->data == v) {
            Node *t = p->next; p->next = t->next; free(t); break;
        }
    return head;
}

// 带哑结点：所有节点统一处理
void deleteVal(Node *dummy, int v) {
    for (Node *p = dummy; p->next; p = p->next)
        if (p->next->data == v) {
            Node *t = p->next; p->next = t->next; free(t); return;
        }
}
```

> 哑结点的好处：**头结点也有「前驱」了**，所有节点处理逻辑统一，代码大幅简化。

### 3.5 循环链表

最后一个结点的 `next` 指回**头结点**，整个链表形成一个环。

```c
// 遍历用 do-while
if (list != NULL) {
    Node *p = list;
    do {
        // 处理 p
        p = p->next;
    } while (p != list);
}
```

### 3.6 双向链表

```c
typedef struct dnode {
    int data;
    struct dnode *prev, *next;
} DNode;
```

#### 插入（在 p 前插入 q）

```c
q->prev = p->prev;
q->next = p;
p->prev->next = q;
p->prev = q;
```

#### 删除（删除 q）

```c
q->prev->next = q->next;
q->next->prev = q->prev;
free(q);
```

> 注意顺序，先把 q 接好两端，再修改 p 周围的指针。

### 3.7 链表使用 5 条铁律

1. **访问指针前一定要保证 `p != NULL`**。
2. **新建结点立即把 `next = NULL`**。
3. **删除前必须保存指针**，删完要 `free`。
4. **最后一个结点 `next` 必须是 NULL**（循环链表除外）。
5. **不要轻易移动头结点**——遍历时用另一个指针 p。

## 四、核心算法（代码模板）

### 4.1 折半查找

```c
int bsearch(int item, int a[], int len) {
    int low = 0, high = len - 1;
    while (low <= high) {
        int mid = low + (high - low) / 2;   // 防溢出
        if (item < a[mid]) high = mid - 1;
        else if (item > a[mid]) low = mid + 1;
        else return mid;
    }
    return -1;
}
```

时间复杂度：**O(log n)**。

### 4.2 朴素串匹配

```c
int index(char s[], char t[]) {
    for (int i = 0; s[i]; i++) {
        int j, k;
        for (j = i, k = 0; t[k] && s[j] == t[k]; j++, k++) ;
        if (t[k] == '\0') return i;
    }
    return -1;
}
```

时间复杂度：**O(n × m)**。

### 4.3 单链表创建（带哑结点）

```c
Node* createList(int n) {
    Node *dummy = (Node*)malloc(sizeof(Node));
    dummy->next = NULL;
    Node *tail = dummy;
    for (int i = 0; i < n; i++) {
        Node *p = (Node*)malloc(sizeof(Node));
        scanf("%d", &p->data);
        p->next = NULL;
        tail->next = p;
        tail = p;
    }
    return dummy;
}
```

### 4.4 链表反转

```c
Node* reverse(Node *head) {
    Node *pre = NULL, *cur = head;
    while (cur) {
        Node *tmp = cur->next;   // 先保存原 next
        cur->next = pre;          // 反转指向
        pre = cur;
        cur = tmp;
    }
    return pre;                   // 新头
}
```

### 4.5 找倒数第 k 个结点

```c
Node* searchKthFromEnd(Node *head, int k) {
    Node *p = head, *q;
    for (int i = 1; i < k; i++) {
        if (p == NULL) return NULL;
        p = p->next;
    }
    if (p == NULL) return NULL;
    for (q = head; p->next; p = p->next, q = q->next) ;
    return q;
}
```

只遍历一趟，O(n)。

### 4.6 两个有序链表合并

```c
Node* merge(Node *a, Node *b) {
    Node dummy, *tail = &dummy;
    dummy.next = NULL;
    while (a && b) {
        if (a->data <= b->data) { tail->next = a; a = a->next; }
        else                    { tail->next = b; b = b->next; }
        tail = tail->next;
    }
    tail->next = a ? a : b;       // 接上没走完的那个
    return dummy.next;
}
```

### 4.7 循环链表创建

```c
Node* createCircular(int n) {
    Node *head = NULL, *tail = NULL;
    for (int i = 1; i <= n; i++) {
        Node *p = (Node*)malloc(sizeof(Node));
        p->data = i;
        if (head == NULL) head = tail = p;
        else { tail->next = p; tail = p; }
    }
    if (tail) tail->next = head;   // 尾连首
    return head;
}
```

### 4.8 全排列

```c
int N, used[11], res[11];

void dfs(int pos) {
    if (pos > N) {
        for (int i = 1; i <= N; i++)
            printf("%d%c", res[i], i == N ? '\n' : ' ');
        return;
    }
    for (int i = 1; i <= N; i++) {
        if (!used[i]) {
            used[i] = 1;
            res[pos] = i;
            dfs(pos + 1);
            used[i] = 0;     // 回溯
        }
    }
}

int main() {
    scanf("%d", &N);
    dfs(1);
    return 0;
}
```

## 五、常见 Bug 与坑点

### 5.1 函数返回值（**warning 一定要看**）

> `Function return with no value in non-void functions` —— **必须改！**

非 void 函数所有分支都要有 `return`，否则会出现各种神奇 bug。

### 5.2 变量初始化

> `Uninitialized variables` —— **必须改！**

```c
int i = 0;
char s[100] = {0};    // 全 '\0'
int a[100] = {0};     // 全 0
```

如果你看到「输出多了奇怪字符」「输出和答案一模一样但 WA」，**很可能是没初始化或越界**。

### 5.3 「新的开始」—— flag 要在循环内重置

```c
// ❌ 错：flag 一旦置 1，再也不会变 0
int flag = 0;
while (scanf("%s", word) > 0) {
    for (int i = 0; i < n; i++)
        if (!strcmp(word, list[i])) flag = 1;
    printf("%s\n", flag ? "YES" : "NO");
}

// ✅ 对
while (scanf("%s", word) > 0) {
    int flag = 0;        // 关键！
    for (int i = 0; i < n; i++)
        if (!strcmp(word, list[i])) flag = 1;
    printf("%s\n", flag ? "YES" : "NO");
}
```

类似的：写完字符串后**记得加 `'\0'`**，否则下次操作会读到上次的脏数据。

### 5.4 结构体声明顺序

> `cmp` 函数中用到了 `struct node`，**结构体声明必须在 `cmp` 之前**！

### 5.5 不要与库函数同名

```c
char tolower(char c) { ... }   // ❌ 和 <ctype.h> 中的 tolower 冲突
char my_tolower(char c) { ... } // ✅ 改名
```

### 5.6 类型转换符 `(type)` 优先级低

```c
(Stu*)p1->id           // ❌ 等价 (Stu*)(p1->id)
((Stu*)p1)->id         // ✅
```

### 5.7 常见运行时错误

| 错误 | 原因 | 排查 |
| --- | --- | --- |
| **SIGSEGV** | 野指针、数组越界、空指针解引用 | 加边界判断、初始化指针 |
| **SIGABRT** | 同一指针 free 两次、free 错误地址 | free 后立即置 NULL |
| **SIGFPE** | 算术错误（除以 0） | 加判断 |
| **TLE 超时** | 通常是死循环 | 在循环内打印变量 |

### 5.8 scanf 的细节

- `%d`、`%s` **自动跳过开头空白**。
- `%c` **不跳过空白**，要写 `scanf(" %c", &c)`（前面有空格）。
- `scanf` 返回值是「成功读取的变量个数」，不是数据值。
- `scanf("%d", ...)` 不会吃换行符，下一个 `gets/fgets` 可能读到空行。

### 5.9 字符串结尾的 `'\0'`

```c
char s[10] = "wangliang";   // 10 字符 + '\0'，但只有 10 格，没地方放 '\0'！
```

最好写 `char s[20] = "wangliang";`，留足空间。

操作字符串后**手动补 `'\0'`**：

```c
s[len] = c;
s[len + 1] = '\0';   // 别忘
```

### 5.10 \r\n 与空白字符

- 空白字符四种： ``、`\t`、`\n`、`\r`
- Windows 文本是 `\r\n`，评测机是 `\n`
- 处理空白符的最好办法：**让 `scanf("%s", ...)` 自动跳过**

### 例题 1：最长回文子串（leetcode 5）

> [https://leetcode.cn/problems/longest-palindromic-substring/](https://leetcode.cn/problems/longest-palindromic-substring/)

**题目**：给一个字符串 s，找出 s 中**最长的回文子串**。

**输入样例**：

```text
"babad"
```

**输出样例**：

```text
"bab"  或  "aba"
```

#### 思路：中心扩展法

回文串的特点：以**某个中心**向两边对称。

- 中心可以是**单个字符**（奇数长度回文，如 `aba`）
- 也可以是**两个字符之间**（偶数长度回文，如 `abba`）

所以我们枚举每一个可能的中心，从中心向两边扩展，直到不是回文为止。

**代码**：

```c
char* longestPalindrome(char* s) {
    int n = strlen(s);
    int start = 0, maxLen = 1;

    for (int i = 0; i < n; i++) {
        // 情况 1：以 s[i] 为中心的奇数长度回文
        int l = i, r = i;
        while (l >= 0 && r < n && s[l] == s[r]) { l--; r++; }
        if (r - l - 1 > maxLen) { maxLen = r - l - 1; start = l + 1; }

        // 情况 2：以 s[i] 和 s[i+1] 之间为中心的偶数长度回文
        l = i; r = i + 1;
        while (l >= 0 && r < n && s[l] == s[r]) { l--; r++; }
        if (r - l - 1 > maxLen) { maxLen = r - l - 1; start = l + 1; }
    }

    char *res = (char*)malloc(maxLen + 1);
    strncpy(res, s + start, maxLen);
    res[maxLen] = '\0';
    return res;
}
```

**关键点**：

- **奇偶两种中心都要枚举**，否则会漏掉 `abba` 这种偶数回文。
- 扩展结束时 l, r 已经多减 / 多加了一次，所以**真实长度是 `r - l - 1`**，**起始位置是 `l + 1`**。
- 时间复杂度：O(n²)。空间 O(1)。
- **不要用动态规划**——空间 O(n²)。

### 例题 2：合并区间（leetcode 56）

> [https://leetcode.cn/problems/merge-intervals/](https://leetcode.cn/problems/merge-intervals/)

**题目**：给一个区间集合（每个区间用 `[start, end]` 表示），合并所有重叠的区间。

**输入样例**：

```text
[[1,3], [2,6], [8,10], [15,18]]
```

**输出样例**：

```text
[[1,6], [8,10], [15,18]]
```

**思路（结构体 + qsort 经典套路）**：

1. **按区间起点 start 升序排序**（用 qsort）。
2. 从左到右扫一遍：

- 如果当前区间的 start ≤ 上一个区间的 end → **重叠**，把上一个区间的 end 更新为 max。
- 否则 → **不重叠**，直接加入结果。

**代码**：

```c
typedef struct { int start, end; } Interval;

int cmp(const void *a, const void *b) {
    return ((Interval*)a)->start - ((Interval*)b)->start;
}

int** merge(int** intervals, int n, int* colSize, int* returnSize, int** returnColSizes) {
    // 1. 排序
    Interval *iv = malloc(n * sizeof(Interval));
    for (int i = 0; i < n; i++) {
        iv[i].start = intervals[i][0];
        iv[i].end   = intervals[i][1];
    }
    qsort(iv, n, sizeof(Interval), cmp);

    // 2. 扫描合并
    int **res = malloc(n * sizeof(int*));
    *returnColSizes = malloc(n * sizeof(int));
    int cnt = 0;
    for (int i = 0; i < n; i++) {
        if (cnt > 0 && iv[i].start <= res[cnt - 1][1]) {
            // 重叠，更新 end
            if (iv[i].end > res[cnt - 1][1])
                res[cnt - 1][1] = iv[i].end;
        } else {
            // 不重叠，新加一个
            res[cnt] = malloc(2 * sizeof(int));
            res[cnt][0] = iv[i].start;
            res[cnt][1] = iv[i].end;
            (*returnColSizes)[cnt] = 2;
            cnt++;
        }
    }
    *returnSize = cnt;
    free(iv);
    return res;
}
```

**关键点**：

- **「先排序再扫描」是处理区间问题的万能套路**。
- 注意「重叠」的判断条件是 `iv[i].start <= res[cnt-1][1]`（要写 `<=`，等于也算重叠）。
- 合并时 end 取**较大值**，不能直接覆盖（考虑 `[1,6]` 和 `[2,3]` 合并后是 `[1,6]` 不是 `[1,3]`）。

### 例题 3：环形链表 II（leetcode 142）

> [https://leetcode.cn/problems/linked-list-cycle-ii/](https://leetcode.cn/problems/linked-list-cycle-ii/)

**题目**：给一个链表，判断它是否有环；如果有，返回**环的入口节点**；如果没有，返回 NULL。

**输入样例**（示意）：

```text
3 → 2 → 0 → -4
    ↑________|     // -4 指回 2，环入口是 2
```

#### 思路：Floyd 快慢指针（神奇的算法）

#### 第一阶段：判断有无环

- 慢指针 slow 每次走 1 步，快指针 fast 每次走 2 步。
- 如果有环，fast 一定会在环里追上 slow。
- 如果 fast 走到 NULL，说明没环。

#### 第二阶段：找环入口

数学结论：fast 和 slow 第一次相遇后，**让一个指针从头开始、一个指针从相遇点开始，都每次走 1 步，它们一定在环入口相遇**。

> 推导：设头到入口距离 a，入口到相遇点 b，相遇点回到入口 c。  
> fast 走的距离 = 2 × slow 走的距离 → `a + b + n(b+c) = 2(a + b)` → `a = c + (n-1)(b+c)`。
> 所以从头走 a 步 = 从相遇点走 c 步绕 n-1 圈，恰好都到入口。

**代码**：

```c
struct ListNode *detectCycle(struct ListNode *head) {
    struct ListNode *slow = head, *fast = head;

    // 阶段 1：判圈
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) break;
    }
    if (!fast || !fast->next) return NULL;   // 无环

    // 阶段 2:找入口
    slow = head;
    while (slow != fast) {
        slow = slow->next;
        fast = fast->next;
    }
    return slow;
}
```

**关键点**：

- **快慢指针**是链表题最常用的技巧之一，**一定要会**。
- 判圈循环条件 `fast && fast->next`：保证 fast 走两步是合法的。
- 这道题考查**指针操作 + 数学思维**，期中如果出链表压轴题，很可能是这种类型。

### 例题 4：两数相加（leetcode 2）

> [https://leetcode.cn/problems/add-two-numbers/](https://leetcode.cn/problems/add-two-numbers/)

**题目**：两个**非空**链表表示两个**逆序**存储的非负整数（每个节点存一位数字），把它们相加，返回相加后的链表（同样逆序）。

**输入样例**：

```text
l1 = [2, 4, 3]      // 表示数 342
l2 = [5, 6, 4]      // 表示数 465
```

**输出样例**：

```text
[7, 0, 8]            // 表示数 807（342 + 465 = 807）
```

**思路（小学竖式加法的链表版）**：

1. 同时遍历两个链表，逐位相加。
2. 维护一个**进位** carry。
3. 一边算一边把结果挂到新链表上。
4. 处理三种「不齐」情况：l1 走完、l2 走完、最后还有进位。

**代码**：

```c
struct ListNode* addTwoNumbers(struct ListNode* l1, struct ListNode* l2) {
    struct ListNode dummy;
    dummy.next = NULL;
    struct ListNode *tail = &dummy;
    int carry = 0;

    while (l1 || l2 || carry) {
        int x = l1 ? l1->val : 0;
        int y = l2 ? l2->val : 0;
        int sum = x + y + carry;
        carry = sum / 10;

        struct ListNode *node = malloc(sizeof(struct ListNode));
        node->val = sum % 10;
        node->next = NULL;
        tail->next = node;
        tail = node;

        if (l1) l1 = l1->next;
        if (l2) l2 = l2->next;
    }

    return dummy.next;
}
```

**关键点**：

- **循环条件 `l1 || l2 || carry`**：三个条件用 `||`——只要还有一个没处理完就继续。这是这题最容易写错的地方。
- 用**哑结点 dummy** 简化「第一个节点」的处理。
- 数字是**逆序存储**的（个位在前），所以**直接从头开始加**就对了，不用反转。

### 例题 5：回文链表（leetcode 234）

> [https://leetcode.cn/problems/palindrome-linked-list/](https://leetcode.cn/problems/palindrome-linked-list/)

**题目**：判断一个单链表是不是回文链表（顺读和反读相同）。要求 **O(1) 空间**。

**输入样例**：

```text
1 → 2 → 2 → 1     →  true
1 → 2 → 3         →  false
```

**思路（链表三大技能的综合应用！）**：

1. **快慢指针找中点**（例题 3 的技巧）。
2. **反转后半段链表**（例题 6 的技巧）。
3. **从两头往中间对比**。

```text
1 → 2 → 3 → 2 → 1

第一步：找中点
1 → 2 → 3 → 2 → 1
        ↑slow

第二步：反转后半段
1 → 2 → 3 ← 2 ← 1

第三步：两头对比
1 → 2 → 3   3 ← 2 ← 1
↑                    ↑
从头开始            从尾开始
```

**代码**：

```c
struct ListNode* reverse(struct ListNode* head) {
    struct ListNode *pre = NULL, *cur = head;
    while (cur) {
        struct ListNode *t = cur->next;
        cur->next = pre;
        pre = cur;
        cur = t;
    }
    return pre;
}

bool isPalindrome(struct ListNode* head) {
    if (!head || !head->next) return true;

    // 1. 快慢指针找中点
    struct ListNode *slow = head, *fast = head;
    while (fast->next && fast->next->next) {
        slow = slow->next;
        fast = fast->next->next;
    }

    // 2. 反转后半段
    struct ListNode *second = reverse(slow->next);

    // 3. 两头对比
    struct ListNode *p1 = head, *p2 = second;
    bool result = true;
    while (p2) {
        if (p1->val != p2->val) { result = false; break; }
        p1 = p1->next;
        p2 = p2->next;
    }

    return result;
}
```

**关键点**：

- **3 个技巧的组合拳**：找中点 + 反转 + 双指针对比。如果你能独立写出这道题，链表基本就过关了。
- 中点的选取：奇数长度时 slow 停在正中间，对比时**只需要比较后半段长度**（前半段会多一个，但不影响结果）。
- 比较循环用 `while (p2)` 而不是 `while (p1 && p2)`——因为可能前半段比后半段多一个节点。

### 例题 6：反转链表（leetcode 206）

> [https://leetcode.cn/problems/reverse-linked-list/](https://leetcode.cn/problems/reverse-linked-list/)

**题目**：反转一个单链表。

```c
struct ListNode* reverseList(struct ListNode* head) {

        cur->next = pre;
        pre = cur;
        cur = tmp;
```

### 例题 7：删除链表的倒数第 N 个结点（leetcode 19）

> [https://leetcode.cn/problems/remove-nth-node-from-end-of-list/](https://leetcode.cn/problems/remove-nth-node-from-end-of-list/)

**题目**：给定链表，删除倒数第 n 个结点，返回新链表头。

**思路（双指针 + 哑结点）**：

1. 用哑结点避免特判头结点。
2. fast 先走 n + 1 步。
3. fast 和 slow 一起走，fast 到底时 slow 就是要删除节点的**前一个**。

**代码**：

```c
struct ListNode* removeNthFromEnd(struct ListNode* head, int n) {
    struct ListNode dummy = {0, head};
    struct ListNode *fast = &dummy, *slow = &dummy;

    for (int i = 0; i <= n; i++) fast = fast->next;
    while (fast) { fast = fast->next; slow = slow->next; }

    struct ListNode *t = slow->next;
    slow->next = t->next;
    free(t);

    return dummy.next;
}
```

**为什么先走 n + 1 步？**——这样 fast 走完时 slow 正好停在「要删除节点的前一个」。

### 例题 8：标识符的识别（**2020 期中真题**）

**题目**：从控制台读入一行 C 语言语句（以分号结束），抽取出所有标识符（变量名、数组名、函数名），重复的只保留一个，按字典序输出。

**输入样例**：

```text
array_sum[i] = array_a[i] + array_a[j] + _next2[ j ]*getArea( x, y , z) – 100*i;
```

**输出样例**：

```text
_next2 array_a array_sum getArea i j x y z
```

**思路**：

1. **遍历**整行字符串，识别标识符的开头：字母或下划线。
2. **连续读取**满足 `[A-Za-z0-9_]` 的字符，组成一个完整标识符。
3. **去重**：在已有标识符表中查找，没找到才加入。
4. **排序**：用 qsort + strcmp 按字典序排。
5. **输出**。

**代码骨架**：

```c
#include <stdio.h>
#include <string.h>
#include <stdlib.h>
#include <ctype.h>

char ids[60][40];
int cnt = 0;

int isIdChar(char c) { return isalnum(c) || c == '_'; }
int isIdStart(char c) { return isalpha(c) || c == '_'; }

int cmp(const void *a, const void *b) {
    return strcmp((char*)a, (char*)b);
}

int main() {
    char s[256], buf[40];
    fgets(s, sizeof(s), stdin);
    int len = strlen(s);

    for (int i = 0; i < len; ) {
        if (isIdStart(s[i])) {
            int k = 0;
            while (isIdChar(s[i])) buf[k++] = s[i++];
            buf[k] = '\0';

            // 去重
            int found = 0;
            for (int j = 0; j < cnt; j++)
                if (!strcmp(ids[j], buf)) { found = 1; break; }
            if (!found) strcpy(ids[cnt++], buf);
        } else if (isdigit(s[i])) {
            // 跳过数字常量（防止把 100 当成标识符）
            while (isIdChar(s[i])) i++;
        } else {
            i++;
        }
    }

    qsort(ids, cnt, 40, cmp);
    for (int i = 0; i < cnt; i++)
        printf("%s%c", ids[i], i == cnt - 1 ? '\n' : ' ');
    return 0;
}
```

**关键点**：

- **标识符开头不能是数字**——所以遇到数字要单独跳过整段。
- 标识符内可以有数字、字母、下划线。
- 用二维字符数组 + qsort 一起排即可。

### 例题 9：两两交换链表中的节点（leetcode 24）

> [https://leetcode.cn/problems/swap-nodes-in-pairs/](https://leetcode.cn/problems/swap-nodes-in-pairs/)

**题目**：给一个链表，**两两交换**其中相邻的节点，返回交换后的链表。**不能修改节点的值**，只能改 next 指针。

**输入样例**：

```text
1 → 2 → 3 → 4 → 5
```

**输出样例**：

```text
2 → 1 → 4 → 3 → 5     （最后一个 5 没有伴，保持不变）
```

**思路**：

1. 用**哑结点**避免特判头结点。
2. 维护一个 `pre` 指针指向「当前要交换的两个节点的前一个」。
3. 每次交换 `pre->next` 和 `pre->next->next` 这两个节点。

**画图**（交换 a 和 b）：

```text
交换前：  pre → a → b → next → ...

交换三步：
  pre->next = b;       // ① pre 接 b
  a->next   = b->next; // ② a 接 b 后面那个
  b->next   = a;       // ③ b 接 a

交换后：  pre → b → a → next → ...
```

**代码**：

```c
struct ListNode* swapPairs(struct ListNode* head) {
    struct ListNode dummy;
    dummy.next = head;
    struct ListNode *pre = &dummy;

    while (pre->next && pre->next->next) {
        struct ListNode *a = pre->next;
        struct ListNode *b = a->next;

        // 三步交换
        pre->next = b;
        a->next   = b->next;
        b->next   = a;

        // pre 跳到下一对的前面（注意：交换后 a 在后面）
        pre = a;
    }

    return dummy.next;
}
```

**关键点**：

- **循环条件 `pre->next && pre->next->next`**：保证后面**至少有 2 个节点**才交换；只剩 1 个就停。
- **三步顺序不能错**：必须是「① pre→b → ② a→原 b 的下家 → ③ b→a」。换顺序会丢指针。
- **更新 pre = a**（不是 b）：因为交换后 a 在后面，下一对的「前一个」是 a。

**举一反三**：题目变成「k 个一组反转链表」（leetcode 25），就是同一个套路 + 反转链表（例题 6）的组合。

### 例题 10：相交链表（leetcode 160）

> [https://leetcode.cn/problems/intersection-of-two-linked-lists/](https://leetcode.cn/problems/intersection-of-two-linked-lists/)

**题目**：给定两个单链表，找它们的相交起点。

**思路**：

1. 分别求两表长度。
2. 长的一边先走 |lenA - lenB| 步。
3. 然后两个指针一起走，相同位置即为相交点。

**代码**：

```c
struct ListNode* getIntersectionNode(struct ListNode *a, struct ListNode *b) {
    int la = 0, lb = 0;
    for (struct ListNode *p = a; p; p = p->next) la++;
    for (struct ListNode *p = b; p; p = p->next) lb++;

    while (la > lb) { a = a->next; la--; }
    while (lb > la) { b = b->next; lb--; }
    while (a && b) {
        if (a == b) return a;
        a = a->next; b = b->next;
    }
    return NULL;
}
```
