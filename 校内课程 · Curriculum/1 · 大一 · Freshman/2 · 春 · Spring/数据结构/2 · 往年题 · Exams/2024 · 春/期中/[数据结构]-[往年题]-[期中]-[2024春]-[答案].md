## 一、选择题

### 1. 以下声明二维数组的语句中，错误的是（　　）

#### 题目

以下声明二维数组的语句中，错误的是（　　）。

(A) `int a[3][2] = {1,2,3,4,5,6};`　　(B) `int a[3][2] = {{1,2},{3,4},{5,6}};`

(C) `int a[][2] = {{1,2},{3,4},{5,6}};`　　(D) `int a[3][] = {{1,2},{3,4},{5,6}};`

#### 答案

**答案：** (D)。二维数组定义时只有第一维可以由初始化列表推断，`int a[3][]` 缺少第二维长度，编译器无法确定每一行的长度。(A) 是合法的按行展开写法，(B)(C) 是合法的按行分组写法。

### 2. 给定如下代码，则输出的结果为（　　）

#### 题目

给定如下代码：

```c
char s[] = "hel/0lo\0world";
printf("%s", s);
```

则输出的结果为（　　）。

(A) `int a[3][2] = {1,2,3,4,5,6};`　　(B) `int a[3][2] = {{1,2},{3,4},{5,6}};`

(C) `int a[][2] = {{1,2},{3,4},{5,6}};`　　(D) `int a[3][] = {{1,2},{3,4},{5,6}};`

#### 答案

**答案：** `hel/0lo`。字符串中的 `\0` 是串结束标志，`%s` 从首字符开始输出、遇到第一个 `\0` 即停止，因此只输出 `hel/0lo` 这 7 个字符。

### 3. 在双向链表中，要在结点 p 后插入结点 s，则以下代码执行顺序正确的是（　　）

#### 题目

若双向链表结点类型定义为：

```c
struct node {
    ElemType data;
    struct node *rlink, *llink;
};
```

那么在双向链表中，要在结点 p 后插入结点 s，则以下代码执行顺序正确的是（　　）。

① `s->llink = p;`　　② `p->rlink = s;`

③ `s->rlink = p->rlink;`　　④ `p->rlink->llink = s;`

(A) ④②③①　　(B) ③①④②

(C) ①③②④　　(D) ②④①③

#### 答案

**答案：** (B)，即 ③①④②。先用 ③ 让 `s->rlink` 记住 p 原来的后继，再用 ① 让 `s->llink` 指向 p，然后用 ④ 把 p 原后继的 `llink` 改为 s（此时 `p->rlink` 仍是原后继），最后用 ② 修改 `p->rlink`。其余三个顺序都会先改掉 `p->rlink`，导致原后继结点丢失或自指。

### 4. C 语言中，想要获得指向 int 类型数组 a 中元素 a[6] 的指针，以下写法正确的是（　　）

#### 题目

C 语言中，想要获得指向 int 类型数组 a 中元素 `a[6]` 的指针，以下写法正确的是（　　）。

(A) `int* p = a+24;`　　(B) `int* p = a+6;`

(C) `int* p = (&a)+6;`　　(D) `int* p = a[6];`

#### 答案

**答案：** (B)。`a` 是数组首元素地址，`a+6` 即 `&a[6]`，类型为 `int*`。(A) `a+24` 按元素偏移 24，指向 `a[24]` 而不是 `a[6]`；(C) `&a` 的类型是 `int (*)[N]`，`(&a)+6` 跳过 6 个整个数组，也不能赋给 `int*`；(D) `a[6]` 是 int 值，不是地址。

### 5. 以下哪一项是错误的结构体定义（　　）

#### 题目

以下哪一项是错误的结构体定义（　　）。

(A)

```c
struct Student {
    char name[20];
    int age;
};
```

(B)

```c
typedef struct {
    int x, y;
}Point;
```

(C)

```c
struct {
    float price;
    char *name;
}Book;
```

(D)

```c
typedef struct {
    int age;
    struct Tree neighbor;
}Tree;
```

#### 答案

**答案：** (D)。在 `typedef struct { int age; struct Tree neighbor; }Tree;` 中，成员声明处的 `struct Tree` 尚未定义（`Tree` 这个 typedef 名在结构体定义结束之前也不可用），编译器无法确定 `neighbor` 的大小，结构体不能包含自身类型的成员。(A)(B) 是合法的结构体定义；(C) 定义匿名结构体类型并同时声明变量 `Book`，同样合法。

## 二、填空题

### 1. 给定一个二维 int 类型数组 a，则 *(*(a+4)+2) 等价于访问该数组的元素\_\_\_\_\_\_\_\_（用数组下标表示）

#### 题目

给定一个二维 int 类型数组 a，则 `*(*(a+4)+2)` 等价于访问该数组的元素\_\_\_\_\_\_\_\_。（用数组下标表示）

#### 答案

**答案：** `a[4][2]`。`a+4` 指向第 4 行，`*(a+4)` 是第 4 行的行首地址，再 `+2` 并解引用即该行下标为 2 的元素。

### 2. 已知字符串 char s1[] = "apple"; char s2[] = "banana";，则 strcmp(s1,s2) 的值\_\_\_\_\_\_\_\_（填「大于」，「等于」或「小于」）

#### 题目

已知字符串 `char s1[] = "apple"; char s2[] = "banana";`，则 `strcmp(s1,s2)` 的值\_\_\_\_\_\_\_\_。（填「大于」，「等于」或「小于」）

#### 答案

**答案：** 小于。`strcmp` 逐字符比较，首个不同字符处 `'a'` 的编码小于 `'b'`，故返回负值。

### 3. 给定如下代码，如果希望该结构体能够实现类似链表的数据结构，则划横线部分应当填写的内容为\_\_\_\_\_\_\_\_

struct Node{

如果希望该结构体能够实现类似链表的数据结构，则划横线部分应当填写的内容为\_\_\_\_\_\_\_\_。

### 4. 在二维数组 `a[3][3]={{1,4,7},{2,5,8},{3,6,9}};` 中，元素 `a[2][1]` 的值为\_\_\_\_\_\_\_\_

### 5. 在单向链表的结点 p 后删除一个非空结点，则划线部分应当填写的语句为\_\_\_\_\_\_\_\_

#### 题目

若单向链表结点类型定义为：

```c
struct Node {
    ElemType data;
    struct Node *next;
};
```

如下代码实现了在单向链表的结点 p 后删除一个非空结点的功能：

```c
struct Node* temp = p->next;
______________;
free(temp);
```

则划线部分应当填写的语句为\_\_\_\_\_\_\_\_。

#### 答案

**答案：** `p->next = temp->next;`（等价写法 `p->next = p->next->next;`）。先用 temp 保存待删结点，再让 p 跳过它指向下一个结点，最后 free(temp)。

### 编程题 1. 简化版「哈佛格式」参考文献提取（href.c）

#### 题目

##### 【问题描述】

论文写作的时经常需要引用前人的文献（称为参考文献），引用时要在论文中以特定的格式表示。一种在人文社科领域常用的论文引用和参考文献格式是「哈佛格式」，其示例如下：

```text
There is a risk the traditional focus on intensification of agriculture to maximize yields
under “normal” conditions may result in greater vulnerability of farms to climate extremes
(Lin, 2008). Often management decisions more focused on minimizing variability or reducing
recovery times in yields of perennial crops are reliant on enhanced ecological knowledge
of a farm (Morel, 2019). Traditional smallholder systems often already use agroecological
methods (Altieri, 2017), hence it is important for extension interventions to complement
this knowledge.
```

本题要求处理一种简化版的「哈佛格式」，其特点是：

1）对文献的引用信息以英文左括号作为开始，以英文右括号作为结束；

2）作者姓名和出版年份一起标记一篇参考文献，作者和年份之间以英文逗号隔开，逗号之后有一个空格，例如：(Lin, 2008)；

3）括号之内没有其他多余的空格。

本题要求分析上述「哈佛格式」的文本，提取文中的参考文献信息并按要求输出文献列表。

##### 【输入形式】

从标准输入中读入一段规范的英文文本。注意：这里约定

1）文本中圆括号里的内容都是参考文献，不会有其他内容；

2）输入内容长度不超过 10000 字符，文本中间不会有换行符，文本的最后有换行符；

3）引用的参考文献不超过 100 篇；

4）作者姓名不超过 31 字符，区分大小写（若大小写不同，可当作不同作者处理）。

##### 【输出形式】

输出文献列表，即作者姓名和出版年份列表：

1）每篇文献输出一行，作者姓名和出版年份之间以一个空格隔开；

2）按参考文献出现的先后次序输出；

3）姓名和年份都一致的文献算一篇文章，只输出一次（按首次出现计算），不可重复输出。

##### 【样例输入】

```text
There is a risk the traditional focus on intensification of agriculture to maximize yields
under “normal” conditions may result in greater vulnerability of farms to climate extremes
(Lin, 2008). Often management decisions more focused on minimizing variability or reducing
recovery times in yields of perennial crops are reliant on enhanced ecological knowledge
of a farm (Morel, 2019). Traditional smallholder systems often already use agroecological
methods (Altieri, 2017), hence it is important for extension interventions to complement
this knowledge. Agroforestry systems are relatively common in smallholder systems and are
considered an effective strategy for achieving climate resilient agriculture(Vaast, 2016),
particularly to temper the impacts of climate shocks for understory crops(Tscharntke,
2011). During dry season conditions, shade trees ameliorate temperature extremes; however,
they may not be able to maintain optimal humidity levels to the same extent as during wet
seasons(Blaser, 2018). For low-input smallholder systems, leguminous trees, or those with
symbiotic relationships with N2-fixing microbes, are an important source of nutrients and
have been planted as shade trees(Blaser, 1998). However, the practice is limited due to
costs(Vaast, 2016) and in some cases has caused mortality events during climate shocks by
outcompeting under story crops for ground water(Abdulai, 2018).
```

##### 【样例输出】

```text
Lin 2008
Morel 2019
Altieri 2017
Vaast 2016
Tscharntke 2011
Blaser 2018
Blaser 1998
Abdulai 2018
```

##### 【样例说明】

输入的文章中有 9 处文献引用，但不同的参考文献只有 8 篇，因为参考文献 (Vaast, 2016) 被引用了两次，只按首次出现输出一次。

##### 【评分标准】

该题考察标准输入输出和字符串处理，提交程序名为：`href.c`。

#### 答案

**答案：**

```c
#include <stdio.h>
#include <string.h>

#define MAXLEN 10005
#define MAXREF 105
#define NAMELEN 32
#define YEARLEN 16

static char name[MAXREF][NAMELEN];
static char year[MAXREF][YEARLEN];

int main(void)
{
    char text[MAXLEN];
    char item[80];
    int cnt = 0;
    int i, j, k, len, dup;

    if (fgets(text, sizeof(text), stdin) == NULL)
        return 0;

    for (i = 0; text[i] != '\0'; i++) {
        char *comma, *p;
        int nlen, ylen;

        if (text[i] != '(')
            continue;

        /* 找到配对的右括号 */
        for (j = i + 1; text[j] != '\0' && text[j] != ')'; j++)
            ;
        if (text[j] != ')')
            break;

        /* 取出括号内的内容 */
        len = j - i - 1;
        if (len >= (int)sizeof(item))
            len = (int)sizeof(item) - 1;
        for (k = 0; k < len; k++)
            item[k] = text[i + 1 + k];
        item[len] = '\0';

        /* 括号内形如 "Author, Year" */
        comma = strchr(item, ',');
        if (comma == NULL) {
            i = j;
            continue;
        }
        *comma = '\0';
        p = comma + 1;
        while (*p == ' ')
            p++;

        nlen = (int)strlen(item);
        ylen = (int)strlen(p);
        if (nlen == 0 || ylen == 0 || nlen >= NAMELEN || ylen >= YEARLEN) {
            i = j;
            continue;
        }

        /* 姓名和年份都一致算一篇文献，只输出一次 */
        for (dup = 0; dup < cnt; dup++)
            if (strcmp(name[dup], item) == 0 && strcmp(year[dup], p) == 0)
                break;
        if (dup == cnt && cnt < MAXREF) {
            strcpy(name[cnt], item);
            strcpy(year[cnt], p);
            cnt++;
        }

        i = j;
    }

    for (i = 0; i < cnt; i++)
        printf("%s %s\n", name[i], year[i]);

    return 0;
}
```

思路：读入整行文本后线性扫描，遇到 `(` 就找到配对的 `)`，取出括号内 `作者, 年份`，按第一个英文逗号切成姓名和年份（逗号后的空格跳过），再用线性表去重，姓名和年份都相同才判为同一篇文献。

### 编程题 2. 银店的白银管理（silver.c）

#### 题目

##### 【问题描述】

一家银店会购入银块、卖出特定重量的白银，以及将散碎的白银熔合成大块。

请用链表形式模拟该店对白银的管理，每个链结点对应一个银块，记录该银块的重量（单位为克）；所有银块构成一个链表，且链表按照每个银块的重量始终保持升序排序。该链表允许如下操作：

1）购入银块：将该银块按重量插入链表的合适位置；

2）卖出 m 克白银：若 m 大于链表银块的总重量，则不处理（忽略该操作）；否则从链表第一个结点开始依次取出银块，直到取出银块的累计重量大于等于 m 为止。若取出的银块的累计重量大于 m，则需要切割最后取出的银块，将切割后剩余银块放在链表的合适位置；

3）熔合白银：将所有重量小于 10 克的银块熔为一块，并插入到链表的合适位置。

注意：不存在银块重量为 0 的链结点。

##### 【输入形式】

从控制台输入由整数构成的序列，整数间以一个空格分隔，其中：

1）正整数表示购入相应重量的银块；

2）负整数表示卖出相应重量的白银；

3）零表示熔合当前所有重量小于 10 克的散碎白银；

4）数字 999999 表示输入结束。

##### 【输出形式】

从链表头开始向控制台输出剩余银块的重量（正整数升序序列），各整数间以一个空格分隔，最后一个整数后有无空格均可。

##### 【样例输入】

```text
10 -10 15 10 -20 5 20 30 -24 8 20 0 5 999999
```

##### 【样例输出】

```text
5 14 20 30
```

##### 【样例说明】

以上输入序列的含义为：购入 10，卖出 10，购入 15，购入 10，卖出 20（此时剩余银块为：5），购入 5，购入 20，购入 30，卖出 24（此时剩余银块为：6,30），购入 8，购入 20，熔合（此时银块为：14,20,30），购入 5，结束。

##### 【评分标准】

该题考察链表操作，提交程序名为：`silver.c`。

#### 答案

**答案：**

```c
#include <stdio.h>
#include <stdlib.h>

struct node {
    int w;
    struct node *next;
};

static struct node *head = NULL;

/* 链表按重量升序，插入到合适位置 */
static void insert(int w)
{
    struct node *q, *p, *prev;

    if (w <= 0)
        return;

    q = (struct node *)malloc(sizeof(struct node));
    q->w = w;
    q->next = NULL;

    if (head == NULL || head->w >= w) {
        q->next = head;
        head = q;
        return;
    }

    prev = head;
    p = head->next;
    while (p != NULL && p->w < w) {
        prev = p;
        p = p->next;
    }
    q->next = p;
    prev->next = q;
}

static int total(void)
{
    int s = 0;
    struct node *p;

    for (p = head; p != NULL; p = p->next)
        s += p->w;
    return s;
}

/* 卖出 m 克：从链表第一个结点开始依次取出，超出部分切割后放回 */
static void sell(int m)
{
    int cum = 0;
    struct node *p;

    if (m > total())
        return;

    while (head != NULL && cum < m) {
        p = head;
        cum += p->w;
        head = p->next;
        free(p);
    }

    if (cum > m)
        insert(cum - m);
}

/* 熔合：所有重量小于 10 克的银块熔为一块 */
static void merge(void)
{
    int sum = 0;
    struct node *p, *prev, *q;

    prev = NULL;
    p = head;
    while (p != NULL) {
        if (p->w < 10) {
            sum += p->w;
            q = p;
            p = p->next;
            if (prev == NULL)
                head = p;
            else
                prev->next = p;
            free(q);
        } else {
            prev = p;
            p = p->next;
        }
    }

    insert(sum);
}

int main(void)
{
    int v;
    int first = 1;
    struct node *p;

    while (scanf("%d", &v) == 1 && v != 999999) {
        if (v > 0)
            insert(v);
        else if (v < 0)
            sell(-v);
        else
            merge();
    }

    for (p = head; p != NULL; p = p->next) {
        if (!first)
            putchar(' ');
        printf("%d", p->w);
        first = 0;
    }
    putchar('\n');

    return 0;
}
```

思路：用单向链表按重量升序存放银块。购入即有序插入；卖出时先比较总重量，m 大于总重量则忽略，否则从表头依次摘下结点并累加，超出部分作为新银块重新有序插入；熔合时一趟遍历摘除所有重量小于 10 克的结点、求和后重新有序插入。
