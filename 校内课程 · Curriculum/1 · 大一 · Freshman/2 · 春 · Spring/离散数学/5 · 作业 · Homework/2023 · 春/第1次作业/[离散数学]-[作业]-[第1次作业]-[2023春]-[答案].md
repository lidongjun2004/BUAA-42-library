## 1

### 题目

判断下列语句是否为命题，并讨论命题的真值：

(1) $2x-3=0$；

(2) 前进！

(3) 如果 $8+7>20$，则三角形有四条边。

(4) 请勿吸烟！

(5) 你喜欢鲁迅的作品吗？

(6) 如果太阳从西方升起，你就可以长生不老。

(7) 如果太阳从东方升起，你就可以长生不老。

### 答案

**答案：** (1) $2x-3=0$ 含有自由变元 $x$，真值随 $x$ 的取值而定，**不是命题**。

(2) 「前进！」是祈使句，没有真假，**不是命题**。

(3) **是命题**。前件 $8+7>20$ 为假（ $8+7=15<20$），蕴含式在前件为假时取真，故该命题为**真**。

(4) 「请勿吸烟！」是祈使句，**不是命题**。

(5) 「你喜欢鲁迅的作品吗？」是疑问句，**不是命题**。

(6) **是命题**。前件「太阳从西方升起」为假，蕴含式为**真**。

(7) **是命题**。前件「太阳从东方升起」为真，后件「你可以长生不老」为假，蕴含式为**假**。

## 2

### 题目

给出以下各式的对偶式：

(1) $\neg(Q\vee R)\vee(\neg Q\wedge\neg R)$；

(2) $(P\wedge(Q\wedge R))\vee((P\wedge Q)\wedge R)\vee 0$。

### 答案

**答案：** 求对偶式时把 $\wedge$ 与 $\vee$ 互换、 $0$ 与 $1$ 互换， $\neg$、括号结构和命题变元保持不变。

(1) $\neg(Q\wedge R)\wedge(\neg Q\vee\neg R)$。

(2) $(P\vee(Q\vee R))\wedge((P\vee Q)\vee R)\wedge 1$。

## 3

### 题目

设计函数，求一个命题合式公式的对偶式（Python 编程实现）。

### 答案

**答案：** 对偶变换只改动联结词与常元，因此逐字符替换即可。

```python
def dual(formula: str) -> str:
    """求命题合式公式的对偶式：∧ 与 ∨ 互换，0 与 1 互换，¬、括号和变元不变。"""
    table = {"∧": "∨", "∨": "∧", "0": "1", "1": "0"}
    return "".join(table.get(ch, ch) for ch in formula)

print(dual("¬(Q∨R)∨(¬Q∧¬R)"))
print(dual("(P∧(Q∧R))∨((P∧Q)∧R)∨0"))
```

输出：

```text
¬(Q∧R)∧(¬Q∨¬R)
(P∨(Q∨R))∧((P∨Q)∨R)∧1
```

说明：输入是以字符串表示的合式公式，只含命题变元、括号、联结词 $\neg,\wedge,\vee$ 和常元 $0,1$；变元名与括号原样保留。

## 4

### 题目

有以下四个命题：

a) "所有科莫多巨蜥都是有毒的"

b) "没有小型蜥蜴会攻击人类"

c) "不攻击人类的蜥蜴都是无毒的"

d) "科莫多巨蜥都是大型蜥蜴"

令 $P(x)$、 $Q(x)$、 $R(x)$ 和 $S(x)$ 分别表示语句 " $x$ 是科莫多巨蜥"、" $x$ 是小的"、" $x$ 会攻击人类" 和 " $x$ 是有毒的"。假定论域是所有蜥蜴的集合。用量词及 $P(x)$、 $Q(x)$、 $R(x)$ 和 $S(x)$ 表示上述命题。

### 答案

**答案：** 论域已限定为所有蜥蜴，故只用量词和四个谓词即可。

a) $\forall x\,(P(x)\to S(x))$。

b) $\forall x\,(Q(x)\to\neg R(x))$；等价的写法是 $\neg\exists x\,(Q(x)\wedge R(x))$。

c) $\forall x\,(\neg R(x)\to\neg S(x))$。

d) "大型" 即 "不是小的"，故为 $\forall x\,(P(x)\to\neg Q(x))$。

## 5

题目描述：

给定一个由命题变元、运算符组成的命题合式公式，编写一个函数 translate_formula，将其翻译成 Python 可以求值的语句。

对运算符的规定如下：

- `~` 表示否定
- `^` 表示合取
- `v` 表示析取
- `->` 表示蕴含
- `<->` 表示互蕴含

函数原型：

```python
def translate_formula(formula):
    """
    将给定的命题合式公式翻译成 Python 可以求值的语句。

    参数:
    formula: 字符串，表示给定的命题合式公式。

    返回值:
    字符串，表示将给定的命题合式公式翻译成的 Python 可以求值的语句。
    """
```

提示：

### 1

#### 题目

在进行符号的翻译时，可以使用 Python 中的字符串替换方法 replace。

#### 答案

在进行符号的翻译时，可以使用 Python 中的字符串替换方法 replace。

### 2

#### 题目

在 Python 中，具体求值时命题变元可以使用 True 和 False 代替，否定运算符可以使用 not 关键字，合取运算符可以使用 and 关键字，析取运算符可以使用 or 关键字，互蕴含运算符可以用 `==`，那蕴含运算符可以用什么来替代呢（提示一下：想一想蕴含的真值表，然后参考一下互蕴含运算符，想想是不是只要稍微改一改就行了）

样例及解释：对于命题合式公式 "(A ^ B) v (~C v D)"，函数应该返回 "(A and B) or (not C or D)"，当给定 ABCD 的值时，这是一个可以直接在 Python 中求值的语句。

#### 答案

**答案：** 互蕴含 $P\leftrightarrow Q$ 用 `==`；而蕴含 $P\to Q$ 的真值表与 `P <= Q` 完全一致（ $P$ 假时恒真， $P$ 真时取 $Q$ 的值），所以蕴含用 `<=`。替换时先替换双字符运算符，避免 `->` 被 `<->` 的替换结果破坏。

```python
def translate_formula(formula):
    """将给定的命题合式公式翻译成 Python 可以求值的语句。"""
    s = formula.replace("<->", " == ")
    s = s.replace("->", " <= ")
    s = s.replace("~", "not ")
    s = s.replace("^", " and ")
    s = s.replace("v", " or ")
    return s

print(translate_formula("(A ^ B) v (~C v D)"))
```

输出：

```text
(A and B) or (not C or D)
```

验证：取 $A=\mathrm{True},B=\mathrm{False},C=\mathrm{True},D=\mathrm{False}$，原公式 $(A\wedge B)\vee(\neg C\vee D)$ 为假，翻译结果求值同样为 False。

## 6

### 题目

设命题逻辑语言 $L=\langle\,|\wedge,\vee,\neg,\to,\leftrightarrow,\oplus|,\ \varphi\,\rangle$，判断如下公式是否是命题合式公式。

(1) $(\neg(P\wedge Q)\wedge R)\to(\neg(P\wedge\neg Q)\wedge R)\leftrightarrow(P\vee Q)\to\neg R$

(2) $\neg(P\to Q)\wedge R=(\neg(P\vee Q)\wedge R)\oplus(P\to(Q\vee R))$

### 答案

**答案：** (1) **是**命题合式公式；(2) **不是**命题合式公式。

(1) 按课件《第 1 章 逻辑语言》给出的联结词优先级（从高到低为 $\neg$、 $\wedge$、 $\vee$、 $\oplus$、 $\to$、 $\leftrightarrow$；同一个联结词连续多次出现且无括号时按从左至右的顺序运算）， $\to$ 的优先级高于 $\leftrightarrow$，所以主联结词是 $\leftrightarrow$，整个符号串唯一地读成

$$\big((\neg(P\wedge Q)\wedge R)\to(\neg(P\wedge\neg Q)\wedge R)\big)\leftrightarrow\big((P\vee Q)\to\neg R\big)$$

其中 $(\neg(P\wedge Q)\wedge R)$、 $(\neg(P\wedge\neg Q)\wedge R)$、 $(P\vee Q)$ 都已带括号， $\neg R$ 由定义 1.2.1(3) 直接得到，四者都是合式公式；最外层的一对括号按课件惯例可以省略（课件第 21 页判断 $(P\to 0)\wedge(Q\to 1)$、第 22 页判断 $\neg(P\wedge Q)\leftrightarrow(\neg P\vee\neg Q)$ 时，都把省略了最外层括号的形式判为合式公式）。故 (1) 是命题合式公式。

(2) 式中出现的 $=$ 不属于语言 $L$ 的符号集合（ $L$ 的联结词只有 $\wedge,\vee,\neg,\to,\leftrightarrow,\oplus$，其余为命题变元与括号），因此整个串不是 $L$ 中的公式，更不是合式公式。
