## 2

### 题目

以下论证错误的为：

a. $(P\vee Q),(P\to R),(Q\to S)\models R\vee S$

b. $(P\to Q),(Q\to R)\models(P\to R)$

c. $\neg R,(Q\to R)\models\neg Q$

d. $P,(Q\to(R\to P))\models(R\to Q)$

### 答案

**答案：** **答案：d。**

a 正确（构造性二难）：由 $P\vee Q$ 分情况， $P$ 真时由 $P\to R$ 得 $R$， $Q$ 真时由 $Q\to S$ 得 $S$，两种情形都得到 $R\vee S$。

b 正确（假言三段论）：设 $P$ 真，则由 $P\to Q$ 得 $Q$，再由 $Q\to R$ 得 $R$。

c 正确（拒取式）：若 $Q$ 真，由 $Q\to R$ 得 $R$，与 $\neg R$ 矛盾，故 $\neg Q$。

d 错误。取 $P=1,\ Q=0,\ R=1$：前提 $P$ 为真； $Q\to(R\to P)=0\to(1\to 1)=0\to 1=1$ 为真；而结论 $R\to Q=1\to 0=0$ 为假。前提真而结论假，故该论证不成立。

## 3

### 题目

如下命题逻辑的等价关系，错误的是：

a. $\neg(Q\wedge R)\Leftrightarrow(\neg Q\vee\neg R)$

b. $(Q\to R)\wedge\neg R\Leftrightarrow\neg Q$

c. $(P\vee(Q\wedge R))\Leftrightarrow((P\vee Q)\wedge(P\vee R))$

d. $(P\to Q)\wedge P\to Q\Leftrightarrow 1$

### 答案

**答案：** **答案：b。**

a 正确（德摩根律）。

b 错误。 $(Q\to R)\wedge\neg R\equiv(\neg Q\vee R)\wedge\neg R\equiv(\neg Q\wedge\neg R)\vee(R\wedge\neg R)\equiv\neg Q\wedge\neg R$，它比 $\neg Q$ 强。反例：取 $Q=0,R=1$，左端为 $(0\to 1)\wedge 0=0$，右端 $\neg Q=1$，两端不等。

c 正确（分配律）。

d 正确。 $(P\to Q)\wedge P\to Q$ 就是分离规则（MP）的形式，永真，故等价于 $1$。

## 4

### 题目

用命题演算方法证明等价式：

(1) $(Q\to R)\Leftrightarrow(\neg R\to\neg Q)$

(2) $(P\wedge Q)\to R\Leftrightarrow(P\to(Q\to R))$

### 答案

**答案：** (1) 两端分别化为析取式：

$$Q\to R\equiv\neg Q\vee R,$$

$$\neg R\to\neg Q\equiv\neg\neg R\vee\neg Q\equiv R\vee\neg Q\equiv\neg Q\vee R.$$

两端都等值于 $\neg Q\vee R$，故 $(Q\to R)\Leftrightarrow(\neg R\to\neg Q)$ 成立（这就是换位律/逆否律）。

(2) 左端：

$$(P\wedge Q)\to R\equiv\neg(P\wedge Q)\vee R\equiv(\neg P\vee\neg Q)\vee R.$$

右端：

$$P\to(Q\to R)\equiv\neg P\vee(\neg Q\vee R)\equiv(\neg P\vee\neg Q)\vee R.$$

两端等值，故 $(P\wedge Q)\to R\Leftrightarrow(P\to(Q\to R))$ 成立。

### 题目

有如下合式公式：

- (1) $p$
- (2) $p\vee q$
- (3) $p\wedge q\vee p$
- (4) $(p\vee q)\wedge(p\vee\neg q)\wedge(\neg p\vee q)\wedge(\neg p\vee\neg q)$
- (5) $\neg p\wedge\neg q\wedge\neg r\vee\neg p\wedge\neg q\wedge r\vee\neg p\wedge q\wedge\neg r\vee\neg p\wedge q\wedge r\vee p\wedge\neg q\wedge\neg r\vee p\wedge\neg q\wedge r\vee p\wedge q\wedge\neg r\vee p\wedge q\wedge r$

其中：

1. 析取范式有：
2. 合取范式有：
3. 主析取范式有：
4. 主合取范式有：

### 答案

**答案：** 按定义：文字是命题变元或其否定；合取项是若干文字的合取，析取项是若干文字的析取；析取范式是若干合取项的析取，合取范式是若干析取项的合取；极小项（极大项）是含公式中全部变元且每个变元恰以一个文字出现一次的合取项（析取项）；主析取范式是极小项的析取，主合取范式是极大项的合取。各式的变元集按式中实际出现的变元计。

| 公式 | 变元集 | 析取范式 | 合取范式 | 主析取范式 | 主合取范式 |
| --- | --- | --- | --- | --- | --- |
| (1) $p$ | $\{p\}$ | 是 | 是 | 是 | 是 |
| (2) $p\vee q$ | $\{p,q\}$ | 是 | 是 | 否 | 是 |
| (3) $p\wedge q\vee p$ | $\{p,q\}$ | 是 | 否 | 否 | 否 |
| (4) | $\{p,q\}$ | 否 | 是 | 否 | 是 |
| (5) | $\{p,q,r\}$ | 是 | 否 | 是 | 否 |

逐条说明：

- (1) $p$ 是单个文字，既可看作一个合取项也可看作一个析取项；在变元集 $\{p\}$ 上它同时是极小项和极大项。
- (2) $p\vee q$ 是两个合取项 $p,q$ 的析取（析取范式），也是一个析取项（合取范式）；作为析取项它含 $p,q$ 各一次，是极大项，故是主合取范式；但其合取项 $p$、 $q$ 都不含全部变元，故不是主析取范式。
- (3) $p\wedge q\vee p$ 按优先级读作 $(p\wedge q)\vee p$，是两个合取项的析取，故是析取范式；它不是析取项的合取，故不是合取范式；合取项 $p\wedge q$ 与 $p$ 都不含全部变元，也不是极小项。
- (4) 是四个析取项的合取，故是合取范式；其中 $(p\vee q)$、 $(p\vee\neg q)$、 $(\neg p\vee q)$、 $(\neg p\vee\neg q)$ 恰是 $\{p,q\}$ 上的四个极大项，故是主合取范式；它不是合取项的析取，故不是析取范式。
- (5) 是八个合取项的析取，故是析取范式；这八个合取项恰是 $\{p,q,r\}$ 上的全部八个极小项，故是主析取范式（其值恒为 $1$）；它不是析取项的合取，故既不是合取范式也不是主合取范式（其主合取范式为空合取，即 $1$）。

所以填空为：

1. 析取范式有：(1)(2)(3)(5)
2. 合取范式有：(1)(2)(4)
3. 主析取范式有：(1)(5)
4. 主合取范式有：(1)(2)(4)

### 题目

实现函数 func(s1:str) -> bool，判断合式公式 s1 是否满足：s1, $P\models Q$。

s1 中的联结词仅可能包含 $\neg,\wedge,\vee$，分别用 not, and, or 表示，s1 中的变元仅可能包含 $P,Q$，返回值为 bool 类型。

样例： $s1=Q$，由于 $Q,P\models Q$ 成立，返回 True。

### 答案

**答案：** $s1,P\models Q$ 的语义是：不存在使 $s1$ 为真、 $P$ 为真而 $Q$ 为假的赋值。变元只有 $P,Q$，枚举四种赋值即可。

```python
def func(s1: str) -> bool:
    """判断 s1, P ⊨ Q 是否成立。"""
    for P in (False, True):
        for Q in (False, True):
            val = eval(s1, {"__builtins__": {}}, {"P": P, "Q": Q})
            if val and P and not Q:
                return False
    return True

print(func("Q"))            # True
print(func("P and not Q"))  # False
```

输出：

```text
True
False
```

第二例说明反例存在：取 $P=1,Q=0$， $s1=P\wedge\neg Q$ 为真且 $P$ 真而 $Q$ 假，故 $s1,P\not\models Q$。

### 题目

实现一个函数 cycleVal(S:str, P, Q, R)。

S 为一般含且仅含 P, Q, R 的合式公式。

S 所使用的联结词仅包括 $\neg,\wedge,\vee$，分别用 not, and, or 表示。

P, Q, R 分别取它们在指派函数下的值。

cycleVal() 应返回 $S[P/R,Q/P,R/Q]$ 的值，返回值为 bool 类型。

```python
# function
def cycleVal(S: str, P: int, Q: int, R: int) -> bool:
    """Sample:
    <<< print(cycleVal('P', 1, 1, 1))
    >>> 1
    """
    pass
```

### 答案

**答案：** 循环代入 $S[P/R,Q/P,R/Q]$ 的含义是：把 $S$ 中所有 $P$ 换成 $R$ 的值、 $Q$ 换成 $P$ 的值、 $R$ 换成 $Q$ 的值。构造代入后的环境再求值即可。

```python
# function
def cycleVal(S: str, P: int, Q: int, R: int) -> bool:
    """返回 S[P/R, Q/P, R/Q] 的值。"""
    env = {"P": bool(R), "Q": bool(P), "R": bool(Q)}
    return bool(eval(S, {"__builtins__": {}}, env))

print(cycleVal('P', 1, 1, 1))
print(cycleVal('P and not Q', 1, 1, 0))
```

输出：

```text
True
False
```

第二例： $P=1,Q=1,R=0$ 时代入后 $P$ 取 $R=0$、 $Q$ 取 $P=1$， $S=0\wedge\neg 1=0$，故返回 False。

### 题目

用 python 编写一个函数 f(s: str) -> str，判断一个合式公式 $s$ 是永真式、永假式还是可满足式。

（在 $s$ 中，命题变元最多有 p,q,r 三个，仅包含与、或、非三种运算，用 and, or, not 来表示）

函数要求：读入满足上述要求的代表 $s$ 的非空字符串，如果是永真式则返回"永真式"，如果不是永真式但是可满足式则返回"可满足式"，如果是永假式则返回"永假式"（不要返回引号）

```python
# function
def f(s: str) -> str:
    """ s: the input string
        return: the type of s
        Sample:
        <<< print(f("p or not p"))
        >>> 永真式
    """
    pass
```

### 答案

**答案：** 变元至多三个，枚举 $2^3=8$ 种赋值：全真为永真式，全假为永假式，其余为可满足式。

```python
# function
def f(s: str) -> str:
    """判断 s 是永真式、永假式还是可满足式。"""
    vals = []
    for p in (False, True):
        for q in (False, True):
            for r in (False, True):
                env = {"p": p, "q": q, "r": r}
                vals.append(bool(eval(s, {"__builtins__": {}}, env)))
    if all(vals):
        return "永真式"
    if any(vals):
        return "可满足式"
    return "永假式"

print(f("p or not p"))
print(f("p and not p"))
print(f("p and q"))
```

输出：

```text
永真式
永假式
可满足式
```

## 9

### 题目

实现一个函数 terms(s:str)，输入 $s$ 为一合式公式，返回 $s$ 的主析取范式中包含合取式的数量。

其中， $s$ 中的联结词仅可能包含 $\neg,\wedge,\vee$，分别用 not, and, or 表示， $s$ 中的变元包含且仅包含 $P,Q,R$。

```python
# function
def terms(s: str) -> int:
    """ s: the input formula,
        return: the number of disjunctions in the conjunctive normal form(CNF) of s
        Sample:
        <<< print(terms('P and Q and R'))
        >>> 1
    """
    pass
```

### 答案

**答案：** 主析取范式是全部极小项的析取，极小项与使公式成真的赋值一一对应，所以"主析取范式中合取式的数量"就是使 $s$ 为真的赋值个数。变元固定为 $P,Q,R$，枚举 8 种赋值计数即可。

```python
# function
def terms(s: str) -> int:
    """返回 s 的主析取范式中合取式（极小项）的数量。"""
    cnt = 0
    for P in (False, True):
        for Q in (False, True):
            for R in (False, True):
                env = {"P": P, "Q": Q, "R": R}
                if eval(s, {"__builtins__": {}}, env):
                    cnt += 1
    return cnt

print(terms('P and Q and R'))
print(terms('P or Q or R'))
print(terms('P and not P'))
```

输出：

```text
1
7
0
```

即 $P\wedge Q\wedge R$ 只在一种赋值下成真，主析取范式只有一个极小项； $P\vee Q\vee R$ 的主析取范式有 7 个极小项； $P\wedge\neg P$ 永假，主析取范式为空（0 个极小项）。
