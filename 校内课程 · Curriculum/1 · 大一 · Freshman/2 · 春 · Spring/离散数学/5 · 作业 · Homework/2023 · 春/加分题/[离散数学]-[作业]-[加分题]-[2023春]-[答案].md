本题评分标准：

1）若可以根据输入的 $m$ 和 $n$ 的随机生成正确的公式，则根据生成公式的多样性评分 0～30 分。
2）输入 $k$ 条测试公式，根据正确判断数得分 $(k_0/k)*20$，其中 $k$ 为测试公式总数， $k_0$ 为程序输出正确结果的公式数目；

- 根据以上得分排序，每个班级选取前 3 名加分，分数相同者按照系统提交时间排序，早提交者排序在前。

### 答案

**答案：** 下面给出一份基于真值表的参考实现（只用标准库，未引入 numpy，因为本题不需要数值运算）。约定：变元名取 $p_1,\dots,p_m$；公式一律写成全括号形式（ $\neg$ 的作用对象也带括号）；公式复杂度按本课程定义（变元复杂度为 0； $\neg A$ 的复杂度为 $A$ 的复杂度加 1； $A\circ B$ 的复杂度为 $\max$ 加 1）。

```python
import itertools
import random
import re

OPS1 = ['¬']
OPS2 = ['∧', '∨', '→', '↔', '⊕']

def _rand(vars_, n):
    """随机生成复杂度恰为 n 的合式公式。"""
    if n == 0:
        return random.choice(vars_)
    if random.random() < 0.3:
        return '¬(' + _rand(vars_, n - 1) + ')'
    k = random.randint(0, n - 1)
    if random.random() < 0.5:
        left, right = _rand(vars_, n - 1), _rand(vars_, k)
    else:
        left, right = _rand(vars_, k), _rand(vars_, n - 1)
    return '(' + left + random.choice(OPS2) + right + ')'

def Produce(m, n):
    """m 为变元数量，n 为公式复杂度；result 为公式字符串列表。"""
    vars_ = ['p%d' % (i + 1) for i in range(m)]
    return [_rand(vars_, n) for _ in range(10)]

def _to_python(f):
    """把全括号写法的公式翻译成可求值的 Python 表达式。

    公式必须写成全括号形式，且 ¬ 的作用对象要带括号（如 ¬(p1∧p2)），
    这样翻译后 not 一定落在括号内，不会与 ==、<= 产生优先级冲突。
    """
    s = f.replace('↔', ' == ').replace('⊕', ' != ')
    s = s.replace('→', ' <= ').replace('∧', ' and ')
    s = s.replace('∨', ' or ').replace('¬', ' not ')
    return s

def _vars_of(f):
    return sorted(set(re.findall(r'p\d+', f)))

def _values(f):
    names = _vars_of(f)
    code = _to_python(f)
    return [eval(code, {'__builtins__': {}}, dict(zip(names, a)))
            for a in itertools.product([False, True], repeat=len(names))]

def TrueOrNot(m):
    """0 永真式，1 永假式，2 可满足式。"""
    vals = _values(m)
    if all(vals):
        return 0
    if any(vals):
        return 2
    return 1

def EqualOrNot(m, n):
    """基于真值表判断两个公式是否逻辑等价。"""
    names = sorted(set(_vars_of(m)) | set(_vars_of(n)))
    cm, cn = _to_python(m), _to_python(n)
    for a in itertools.product([False, True], repeat=len(names)):
        env = dict(zip(names, a))
        if eval(cm, {'__builtins__': {}}, env) != eval(cn, {'__builtins__': {}}, env):
            return False
    return True
```

用法示例：

```python
fs = Produce(2, 3)
print(fs[0], TrueOrNot(fs[0]), EqualOrNot(fs[0], fs[1]))
print(TrueOrNot('(p1∨¬p1)'), TrueOrNot('(p1∧¬p1)'), TrueOrNot('p1'))
print(EqualOrNot('(p1→p2)', '(¬p1∨p2)'))
```

输出中的 `0 1 2` 分别对应永真式、永假式、可满足式，最后一行为 `True`（ $(p_1\to p_2)\equiv(\neg p_1\vee p_2)$）。

说明与评分对应：

- `Produce` 按复杂度定义递归生成，保证每次至少有一侧的复杂度为 $n-1$，因此整式复杂度恰为 $n$；随机选择联结词与两侧复杂度保证了多样性（对应评分标准 1）。
- `TrueOrNot` 枚举全部 $2^m$ 种赋值：全真返回 0，全假返回 1，否则返回 2（对应评分标准 2）。
- `EqualOrNot` 用真值表逐行比较，属于"基于真值表的方法"（对应评分标准 3 中 30 分的一档）。

### 题目

题目 B：

用公理方法证明下述结论（不可用演绎定理）。

$$P\to Q,\ (\neg Q\vee R)\wedge\neg R,\ \neg(\neg P\wedge S)\vdash\neg S$$

本题加分条件：

1）要求写出证明过程，每步证据满足：公理、前提、MP 规则、书中 4.5 节定理、联结词的缩写形式（如 PPT 上例 4.5.35 第 3 步联结词的等价定义）
2）满足条件 1 情况下，按照证明步骤从短到长排序，如果步骤相同情况下，则按照系统提交时间从前到后排序，选择求解过程不同的前 2 人加分。

### 答案

**答案：** 下面给出一个 20 步的推演，全程只用公理、前提、MP 规则与书中已证定理，**不使用演绎定理**。用到的书中定理有：合取消去 $\vdash(U\wedge V)\to U$ 与 $\vdash(U\wedge V)\to V$、逆否律 $\vdash(U\to V)\to(\neg V\to\neg U)$、双重否定 $\vdash\neg\neg U\to U$、合取引入 $\vdash U\to(V\to(U\wedge V))$。

| 步骤 | 公式 | 证据 |
| --- | --- | --- |
| 1 | $P\to Q$ | 前提 |
| 2 | $(\neg Q\vee R)\wedge\neg R$ | 前提 |
| 3 | $\neg(\neg P\wedge S)$ | 前提 |
| 4 | $\vdash((\neg Q\vee R)\wedge\neg R)\to(\neg Q\vee R)$ | 书中定理 $\vdash(U\wedge V)\to U$ |
| 5 | $\neg Q\vee R$，即 $\neg\neg Q\to R$ | MP(2, 4)，再用缩写定义 $U\vee V\equiv\neg U\to V$（取 $U:=\neg Q$） |
| 6 | $\vdash((\neg Q\vee R)\wedge\neg R)\to\neg R$ | 书中定理 $\vdash(U\wedge V)\to V$ |
| 7 | $\neg R$ | MP(2, 6) |
| 8 | $\vdash(\neg\neg Q\to R)\to(\neg R\to\neg\neg\neg Q)$ | 书中定理 $\vdash(U\to V)\to(\neg V\to\neg U)$，取 $U:=\neg\neg Q,\ V:=R$ |
| 9 | $\neg R\to\neg\neg\neg Q$ | MP(5, 8) |
| 10 | $\neg\neg\neg Q$ | MP(7, 9) |
| 11 | $\vdash\neg\neg\neg Q\to\neg Q$ | 书中定理 $\vdash\neg\neg U\to U$，取 $U:=\neg Q$ |
| 12 | $\neg Q$ | MP(10, 11) |
| 13 | $\vdash(P\to Q)\to(\neg Q\to\neg P)$ | 书中定理（逆否律），取 $U:=P,\ V:=Q$ |
| 14 | $\neg Q\to\neg P$ | MP(1, 13) |
| 15 | $\neg P$ | MP(12, 14) |
| 16 | $\vdash\neg P\to(S\to(\neg P\wedge S))$ | 书中定理 $\vdash U\to(V\to(U\wedge V))$，取 $U:=\neg P,\ V:=S$ |
| 17 | $S\to(\neg P\wedge S)$ | MP(15, 16) |
| 18 | $\vdash(S\to(\neg P\wedge S))\to(\neg(\neg P\wedge S)\to\neg S)$ | 书中定理 $\vdash(U\to V)\to(\neg V\to\neg U)$，取 $U:=S,\ V:=\neg P\wedge S$ |
| 19 | $\neg(\neg P\wedge S)\to\neg S$ | MP(17, 18) |
| 20 | $\neg S$ | MP(3, 19) |

证毕。

思路说明：第 4—7 步从第二个前提里拆出 $\neg Q\vee R$ 与 $\neg R$；第 8—12 步用逆否律与双重否定完成析取三段论，得到 $\neg Q$；第 13—15 步由 $P\to Q$ 与 $\neg Q$ 得到 $\neg P$；第 16—20 步把 $\neg P$ 与 $S$ 合取起来，与第三个前提 $\neg(\neg P\wedge S)$ 矛盾，从而得到 $\neg S$。
