## 习题 4.4

### 第 1 题

#### 题目

求下列方程的奇解。

(1) $y = 2x\dfrac{\mathrm{d}y}{\mathrm{d}x} + x^2\left(\dfrac{\mathrm{d}y}{\mathrm{d}x}\right)^4$；

(3) $x\left(\dfrac{\mathrm{d}y}{\mathrm{d}x}\right)^3 - y\left(\dfrac{\mathrm{d}y}{\mathrm{d}x}\right)^2 - 1 = 0$。

#### 答案

**答案：**

**(1)** 令 $p = \dfrac{\mathrm{d}y}{\mathrm{d}x}$，方程为 $y = 2xp + x^2p^4$。下面用 $p$-判别式求奇解。

改用

$$
\begin{cases}
F(x,y,p) = y - 2xp - x^2p^4 = 0, \\[4pt]
\dfrac{\partial F}{\partial p} = -2x - 4x^2p^3 = 0,
\end{cases}
$$

$\therefore x = 0$ 或 $p = \left(-\dfrac{1}{2x}\right)^{1/3} = -(2x)^{-1/3}$。

代入得

$$
y = -\frac{3}{4}(2x)^{2/3},
$$

是解，且满足定理 4.9， $\therefore$ 是奇解。

**(3)** 令 $p = \dfrac{\mathrm{d}y}{\mathrm{d}x}$，则 $xp^3 - yp^2 - 1 = 0$。下面用 $p$-判别式求奇解：

$$
\begin{cases}
xp^3 - yp^2 - 1 = 0 \quad ① \\[4pt]
3xp^2 - 2py = 0 \quad ② \quad \left(\dfrac{\partial F}{\partial p}\right)
\end{cases}
$$

$\therefore p = 0$ 或 $p = \dfrac{2y}{3x}$。

$p = 0$：① 式无解。

$p = \dfrac{2y}{3x}$ 代入 ① 得 $4y^3 + 27x^2 = 0$，即

$$
y = -3\left(\frac{x^2}{4}\right)^{1/3},
$$

是方程的解，且满足定理 4.9， $\therefore y = -3\left(\dfrac{x^2}{4}\right)^{1/3}$ 是奇解。

### 第 2 题

#### 题目

求一曲线，使它上面的每一点的切线截坐标轴得到的两截距之和为 $a$。

#### 答案

**答案：** 设截 $y$ 轴于 $(0, m)$，则截 $x$ 轴于 $(\pm(\alpha - |m|), 0)$（ $\alpha > 0$）。

$\therefore$ 切线方程 $l$：

$$
\pm\frac{x}{\alpha - |m|} + \frac{y}{m} = 1 \qquad (x)
$$
切点 $(x_0, y_0) \in l$。对 $(x)$ 两边关于 $x$ 求导，得 $(x_0, y_0)$ 处斜率 $y'$：

$$
\pm\frac{1}{\alpha - |m|} + \frac{1}{m}y' = 0 \Longrightarrow y' = \mp\frac{m}{\alpha - |m|}.
$$

记切线在 $x$ 轴上的截距为 $n$，条件即 $|n| + |m| = \alpha$，也就是 $n = \pm(\alpha - |m|)$，四种符号组合各对应一支包络线。逐支用 $m$-判别式（ $F = 0$ 与 $\dfrac{\partial F}{\partial m} = 0$）求包络：

**(1)** $m > 0$， $n = \alpha - m$： $F = \dfrac{x}{\alpha - m} + \dfrac{y}{m} - 1$， $\dfrac{\partial F}{\partial m} = \dfrac{x}{(\alpha - m)^2} - \dfrac{y}{m^2} = 0$，故可设 $x = k(\alpha - m)^2$， $y = km^2$；代回 $F = 0$ 得 $k\alpha = 1$，即 $\alpha x = (\alpha - m)^2$， $\alpha y = m^2$。于是 $y - x + \alpha = 2m$，所以 $(y - x + \alpha)^2 = 4m^2 = 4\alpha y$，展开整理即第 1 个解。

**(2)** $m < 0$， $n = \alpha + m$： $F = \dfrac{x}{\alpha + m} + \dfrac{y}{m} - 1$， $\dfrac{\partial F}{\partial m} = -\dfrac{x}{(\alpha + m)^2} - \dfrac{y}{m^2} = 0$，得 $\alpha x = (\alpha + m)^2$， $-\alpha y = m^2$。于是 $x + y - \alpha = 2m$，所以 $(x + y - \alpha)^2 = -4\alpha y$；两边同加 $4\alpha(x + y)$ 得 $(x + y + \alpha)^2 = 4\alpha x$，展开整理即第 2 个解。

**(3)** $m > 0$， $n = m - \alpha$： $F = \dfrac{x}{m - \alpha} + \dfrac{y}{m} - 1$， $\dfrac{\partial F}{\partial m} = -\dfrac{x}{(m - \alpha)^2} - \dfrac{y}{m^2} = 0$，得 $-\alpha x = (m - \alpha)^2$， $\alpha y = m^2$。于是 $x + y + \alpha = 2m$，所以 $(x + y + \alpha)^2 = 4\alpha y$，展开整理即第 3 个解。

**(4)** $m < 0$， $n = -\alpha - m$： $F = -\dfrac{x}{\alpha + m} + \dfrac{y}{m} - 1$， $\dfrac{\partial F}{\partial m} = \dfrac{x}{(\alpha + m)^2} - \dfrac{y}{m^2} = 0$，得 $-\alpha x = (\alpha + m)^2$， $-\alpha y = m^2$。于是 $x - y + \alpha = -2m$，所以 $(x - y + \alpha)^2 = -4\alpha y$，即 $(y - x - \alpha)^2 = -4\alpha y$，展开整理即第 4 个解。
4 个解为：

$$
\begin{aligned}
&(y - x - \alpha)(y - x + \alpha) = 2\alpha(y + x - \alpha), \\
&(y + x + \alpha)(-y - x + \alpha) = 2\alpha(y - x + \alpha), \\
&(y + x + \alpha)(y + x - \alpha) = 2\alpha(y - x - \alpha), \\
&(y - x - \alpha)(x - y - \alpha) = 2\alpha(y + x + \alpha).
\end{aligned}
$$

### 第 3 题

#### 题目

求下列曲线族的包络线并作图。

(2) $(x-c)^2 + (y-c)^2 = 4$；

(3) $(x-c)^2 + y^2 = 4c$。

#### 答案

**答案：**

**(2)** 用 $c$-判别式法。 $F(x,y,c) = (x-c)^2 + (y-c)^2 - 4 = 0$，

$$
\frac{\partial F}{\partial c} = 2(c-x) + 2(c-y) = 0,
$$

$\therefore y = c + \sqrt{2}$ 或 $y = c - \sqrt{2}$； $x = c - \sqrt{2}$ 或 $x = c + \sqrt{2}$。

即 $y = x + 2\sqrt{2}$ 或 $y = x - 2\sqrt{2}$。

且满足非退化条件：① $(\varphi'(c))^2 + (\psi'(c))^2 \ne 0$；② $\dfrac{\partial F}{\partial x} = 2(x-c)$， $\dfrac{\partial F}{\partial y} = 2(y-c)$， $\left(\dfrac{\partial F}{\partial x}\right)^2 + \left(\dfrac{\partial F}{\partial y}\right)^2 \ne 0$。

$\therefore$ 包络线 $y = x \pm 2\sqrt{2}$。

![第3题(2)包络线草图](image/第3题(2)-包络线草图.png)

**(3)** 用 $c$-判别式法。 $F(x,y,c) = (x-c)^2 + y^2 - 4c = 0$，

$$
\frac{\partial F}{\partial c} = 2(c-x) - 4 = 0,
$$

$\therefore y^2 = 4c - 4$， $x = c - 2 = \varphi(c)$。

$\therefore y^2 = 4x + 4$。

且满足非退化条件： $\varphi'(c) = 1 \ne 0$； $\dfrac{\partial F}{\partial x} = 2(x-c)$， $\dfrac{\partial F}{\partial y} = 2y$。

$\therefore$ 包络线 $y^2 = 4x + 4$。

## 习题 4.5

### 第 2 题

#### 题目

设 $y = \varphi(x; x_0, y_0)$ 是方程

$$
\frac{\mathrm{d}y}{\mathrm{d}x} = \sin(xy)
$$

满足 $y(x_0) = y_0$ 的解，求

$$
\left.\frac{\partial \varphi}{\partial x_0}\right|_{x_0 = 0,\, y_0 = 0},\qquad
\left.\frac{\partial \varphi}{\partial y_0}\right|_{x_0 = 0,\, y_0 = 0}.
$$

#### 答案

**答案：** $\dfrac{\mathrm{d}y}{\mathrm{d}x} = f(x,y) = \sin(xy)$， $\dfrac{\partial f}{\partial y} = x\cos(xy)$。

$\dfrac{\partial \varphi}{\partial x_0}$、 $\dfrac{\partial \varphi}{\partial y_0}$ 是

$$
z' = x\cos(xy)\,z
$$

的解，初值分别为 $z(x_0) = -f(x_0, y_0) = 0$、 $z(x_0) = 1$（ $x_0 = y_0 = 0$）。

$\dfrac{\mathrm{d}y}{\mathrm{d}x} = \sin(xy)$ 满足解唯一存在，且 $y \equiv 0$ 过 $(0,0)$， $\therefore y = \varphi(x; 0, 0) \equiv 0$。

$$
z = z(x_0)\,e^{\int_{x_0}^{x} x\cos(xy)\,\mathrm{d}x} = z(x_0)\,e^{\int_{0}^{x} x\cos 0\,\mathrm{d}x} = z(x_0)\,e^{\frac{1}{2}x^2}.
$$

$\therefore$

$$
\left.\frac{\partial \varphi}{\partial x_0}\right|_{x_0 = 0,\, y_0 = 0} = 0,\qquad
\left.\frac{\partial \varphi}{\partial y_0}\right|_{x_0 = 0,\, y_0 = 0} = e^{\frac{1}{2}x^2}.
$$

### 第 3 题

#### 题目

条件为： $f(t)$、 $g(t)$ 在 $[t_0, t_1]$ 上非负连续，且 $x(t) \le g(t) + \int_{t_0}^{t} f(\tau)x(\tau)\,\mathrm{d}\tau$。

(1) 证明

$$
x(t) \le g(t) + \int_{t_0}^{t} f(\tau)g(\tau)\,e^{\int_{\tau}^{t} f(s)\,\mathrm{d}s}\,\mathrm{d}\tau;
$$

(2) 若 $g(t)$ 在 $[t_0, t]$ 上单增，证明

$$
x(t) \le g(t)\,e^{\int_{t_0}^{t} f(s)\,\mathrm{d}s}.
$$

#### 答案

**答案：**

**(1)** 令 $y(t) = \int_{t_0}^{t} f(\tau)x(\tau)\,\mathrm{d}\tau$，则有 $x(t) \le g(t) + y(t)$ ①， $y'(t) = f(t)x(t)$ ②。

由 ①② 知 $f(t)x(t) \le f(t)g(t) + f(t)y(t)$，即

$$
y'(t) \le f(t)g(t) + f(t)y(t),\qquad y'(t) - f(t)y(t) \le f(t)g(t).
$$

同乘 $e^{-\int_{t_0}^{t} f(s)\,\mathrm{d}s}$：

$$
\left(y'(t) - f(t)y(t)\right)e^{-\int_{t_0}^{t} f(s)\,\mathrm{d}s} \le f(t)g(t)\,e^{-\int_{t_0}^{t} f(s)\,\mathrm{d}s},
$$

$$
\therefore \left(y(t)\,e^{-\int_{t_0}^{t} f(s)\,\mathrm{d}s}\right)' \le f(t)g(t)\,e^{-\int_{t_0}^{t} f(s)\,\mathrm{d}s}.
$$

两边从 $t_0$ 到 $t$ 积分：

$$
y(t)e^{-\int_{t_0}^{t} f(s)\,\mathrm{d}s} - y(t_0)e^{-\int_{t_0}^{t_0} f(s)\,\mathrm{d}s}
\le \int_{t_0}^{t} f(\tau)g(\tau)\,e^{-\int_{t_0}^{\tau} f(s)\,\mathrm{d}s}\,\mathrm{d}\tau,
$$

其中 $y(t_0) = 0$， $\therefore$

$$
y(t) \le \int_{t_0}^{t} f(\tau)g(\tau)\,e^{\int_{\tau}^{t} f(s)\,\mathrm{d}s}\,\mathrm{d}\tau.
$$

代入 ①，证毕。

**(2)** 由于 $\tau \le t$， $g(t)$ 在 $[t_0, t]$ 上单增，故 (1) 中有

$$
y(t) \le \int_{t_0}^{t} g(t)f(\tau)\,e^{\int_{\tau}^{t} f(s)\,\mathrm{d}s}\,\mathrm{d}\tau,
$$

$$
\therefore x(t) \le g(t)\left(1 + \int_{t_0}^{t} f(\tau)\,e^{\int_{\tau}^{t} f(s)\,\mathrm{d}s}\,\mathrm{d}\tau\right) \qquad ③
$$

设 $u(t) = \int_{t_0}^{t} f(\tau)\,e^{\int_{\tau}^{t} f(s)\,\mathrm{d}s}\,\mathrm{d}\tau$，则

$$
u'(t) = f(t) + \int_{t_0}^{t} f(\tau)\,e^{\int_{\tau}^{t} f(s)\,\mathrm{d}s}f(t)\,\mathrm{d}\tau = f(t)(1 + u(t)),
$$

$$
\mathrm{d}(\ln(u(t)+1)) = f(t)\,\mathrm{d}t,
$$

在 $t_0$ 到 $t$ 上积分：

$$
\ln(u(t)+1) - \ln(u(t_0)+1) = \int_{t_0}^{t} f(s)\,\mathrm{d}s,
$$

其中 $u(t_0) = 0$， $\therefore$

$$
u(t) + 1 = e^{\int_{t_0}^{t} f(s)\,\mathrm{d}s}.
$$

代入 ③：

$$
x(t) \le f(t)\,e^{\int_{t_0}^{t} f(s)\,\mathrm{d}s},
$$

证毕！
