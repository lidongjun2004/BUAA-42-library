# 计算机系统基础 课程要求（2024春）

## 成绩构成

| 项目 | 占比 | 评分标准 |
| --- | --- | --- |
| 计算机组成理论：平时作业 | 15% | 记为 A，按平时作业完成情况评分，满分 15 分 |
| 计算机组成理论：期终考试 | 85% | 记为 B，课程期末考试卷面成绩，满分 100 分，按 85% 计入 |
| 计算机组成实验 | — | 单次 Project 得分由 SPOC 学习情况、课下 Project Work 完成情况、课上 Project Test 完成及问答情况构成；实验最终成绩由教程及历次 Project 成绩及 SPOC 论坛活跃度综合评定；抄袭行为确认后课程最终成绩清零 |
| 操作系统：平时成绩 | 5% | 理论课平时占理论课 20%，按作业完成情况、参加讨论、回答问题评定，积极参加平时讨论和回答问题最高可加 5% |
| 操作系统：期末考试 | 20% | 理论课期末占理论课 80% |
| 操作系统：实验 | 25% | 详细考试与评分标准在课程实验网站公布 |
| 合计 | — | 操作系统与计算机组成各占 50 分；计算机组成 50 分内部理论与实验的权重未给出 |
