## 作业二：光照与纹理映射

主要考核：光照计算、纹理映射、凹凸纹理、阴影图等。可参考 texture.py 和 shading.py 文件完成相应的功能。具体任务要求如下：

1. 将球面进行三角化（用多个三角形表示球面），并将图片 earthmap.jpg 作为纹理图贴到球面上进行绘制。（3 分）ps：邻近的经纬线会交叉形成多个 4 边形，将四边形其中一对角点连接，形成 2 个三角形。
2. 纹理贴图反走样，解决 texture.py 里的走样问题。（2 分）
3. 实现光照计算（Blinn-Phong）模型。几何可以用球面，实现三种不同采样频率（三角形、顶点、像素）。（3 分）
4. Bump Mapping 的实现，利用纹理实现球面的凹凸效果。（1 分）
5. 在球面的下方，放一个大的平面，然后实现阴影的效果。（1 分）

## 附录：OpenGL 环境配置

1. Anaconda 安装。下载链接 <https://mirrors.tuna.tsinghua.edu.cn/anaconda/archive/>。Windows 上下载 “\*-Windows-x86_64.exe”，例如下载 Anaconda3-2024.06-1-Windows-x86_64.exe，双击运行文件进行安装。
2. 启动 Anaconda 命令行。
3. 用 conda 创建虚拟环境 py_gl：执行命令 `conda create -n py_gl python=3.10`。
4. 激活虚拟环境 py_gl：执行命令 `conda activate py_gl`。
5. 安装 OpenGL，通过源码安装。PyOpenGL 3.1.7，下载链接 <https://pypi.org/project/PyOpenGL/>。PyOpenGL-3.1.7.tar.gz 下载成功后解压，命令行里 cd 进入 PyOpenGL-3.1.7 文件夹后，执行安装命令 `python setup.py install`。（备选）PyOpenGL-accelerate 3.1.7，下载链接 <https://pypi.org/project/PyOpenGL-accelerate/>，安装方法同 PyOpenGL 3.1.7 类似。以上安装操作也可以通过轮子安装，先下载相应的 whl 文件，再直接运行 `pip install *.whl`，例如 `pip install PyOpenGL-3.1.6-cp310-cp310-win_amd64.whl`。
6. 运行本次作业的供参考的 py 文件，如 shading.py：执行命令 `python shading.py`。可能会提示缺少 glm 库，则执行 `pip install PyGLM`。
